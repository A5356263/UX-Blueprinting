# 成员管理已升级为独立一级菜单，raw 文件中旧路径需更新

## 1. 知识讨论背景

用户询问组织架构视图的人员添加途径，回答时引用了 `10_成员加入与邀请.md` 中的路径 `管理后台 → 组织 → 成员管理`。用户指出菜单重构后成员已是独立一级菜单，不在组织之下。经核查，raw 文件中记录的仍是重构前的旧路径。

## 2. 候选知识

- 菜单结构重构后，**"成员"是独立一级菜单**，不与"组织"平级或嵌套于组织之下。
- `knowledge/raw/business/成员管理/10_成员加入与邀请.md` 中记录的三条邀请路径均以 `管理后台 -> 组织 -> 成员管理 ->` 开头，**这些路径已过时**，需要更新为重构后的新路径。
- 同样受影响的 raw 文件可能还包括 `13_外部人员.md`（路径写的是 `管理后台 -> 组织 -> 外部人员`），需要同步确认。

## 3. 影响范围

- 变更类型：修正
- 影响业务域：member、organization
- 影响对象：`knowledge/raw/business/成员管理/10_成员加入与邀请.md`（三条邀请路径）、`knowledge/raw/business/成员管理/13_外部人员.md`（外部人员维护入口路径）、所有引用了这些 raw 文件的 summary 路由卡
- 建议更新位置：knowledge/raw/business/成员管理/10_成员加入与邀请.md
- 处理建议：修正（将旧路径 `管理后台 → 组织 → 成员管理 →` 更新为重构后的新路径）

## 4. 不确定点

- [GAP] 成员作为独立一级菜单后的完整新路径需从产品或帮助中心确认后补全。
- [QUESTION] 外部人员的入口是否也跟随成员模块独立出来，还是保留在其他位置，需确认。
