# 成员协作权限 —「员工可见所在组织人员」子维度

## 1. 知识讨论背景

用户在知识问答中询问"成员协同权限"下"员工可见所在组织人员"选项的完整子维度。当前知识库 `knowledge/raw/业务/权限管理/15_页面载体语义.md` 的"成员协作权限"部分仅记录了主规则区三种互斥选项和"可见外部人员"勾选框，未收录"员工可见所在组织人员"选中后暴露的子维度配置项。用户补充了完整的子维度信息。

## 2. 候选知识

**页面**：成员协作权限（路径：通用权限管理 -> 成员协作权限）

**页面顶层结构**：该页面分为两个 Tab：
- 员工协作权限
- 外部人员协作权限

**主规则**（员工协作权限 Tab 下）为三个互斥单选项：
- 员工可见所有人员
- 员工可见所在组织人员
- 员工不可见任何人员

当主规则选择「员工可见所在组织人员」后，出现以下 **4 个子维度复选框**（可自由组合）：

1. **可见担任"组织负责人"的组织**：员工可查看自己担任组织负责人的组织内的人员
2. **可见所在组织的下级组织**：可见范围向下延伸到子级组织
3. **可见外部人员**：控制是否可看到外部协作人员
4. **可见组织负责人信息**：控制是否可看到组织负责人的信息

四个子项均为复选，不互斥。
