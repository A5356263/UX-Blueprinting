# Edge 状态补强消费细则

仅在 Page Spec Step 0 已核对 `edge_output.md` 与本轮需求同源且有效后读取。Edge 是可选状态补强，不改变页面主方案。

- 从正式 Markdown 中按所属页面或实体吸收状态类型、必要程度、严重程度、界面描述、恢复行为、文案提示、建议落位及关键缺口；建议落位仅供参考。
- 所属实体的`状态与异常恢复`只补主方案尚未明确的 must / should 状态、恢复路径、阻断后的用户出口和已填信息保留。
- 所属实体或共用文案区只补与状态反馈直接相关的文案；在适用位置或状态旁保留“来源：异常态补强”。
- 关键缺口仅在当前主体仍无法落位时进入`不参与本次生成的待确认项`。
- 同一条补强信息只落位一次；已进入状态、恢复或文案的内容，不在待确认项中重复。
- 不由 Edge 增加独立页面实体、改写父页关系、主流程或主方案。
