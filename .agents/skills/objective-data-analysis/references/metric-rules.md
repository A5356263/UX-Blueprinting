# 指标规则

## 指标-2026 默认口径

默认按任务实例去重，所有比例同时保存分子、分母和结果。

| 指标 | 分子 | 分母 |
| --- | --- | --- |
| 任务完成率 | 出现完成事件或 success_event 的任务数 | 有效任务实例数 |
| 一次完成率 | 完成且提交不超过一次、无已记录回退的任务数 | 有效任务实例数 |
| 报错任务率 | 至少出现一次 error_event 的任务数 | 有效任务实例数 |
| 草稿率 | 出现 draft_event 的任务数 | 有效任务实例数 |
| 退出率 | 出现 exit_event 的任务数 | 有效任务实例数 |

目标参考值、健康分和旧异动指标规则不得进入计算。用户提供的业务阈值必须保留来源、版本、适用场景和时间窗口，并与历史基线分开表达。

## 可靠性与推断

- 默认输出描述性统计。
- 每个比例必须展示样本量和影响任务数；可靠性直接表达样本量、覆盖率、缺失率、映射置信度和规则确认状态，不生成跨场景通用综合分数。
- 分群低于 minimum_segment_sample 时标记 low_sample_risk，不隐藏结果。
- 统计推断只在用户问题需要、分组独立、样本和分布条件支持时执行。
- 未做推断时不得使用“显著”“证明”“导致”等词。
- 同深度报错对比只表示相关关系。

## 时长

- 任务时长使用任务内首末有效时间戳。
- 步骤时长使用固定漏斗相邻首次命中点。
- 默认输出 P50/P70/P90，不用均值替代长尾分布。
- 无效时间戳必须计入 data_quality，并对顺序和时长结果增加限制。
