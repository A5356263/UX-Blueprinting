# HTML/SVG 视觉规则

## 目录

1. 总体布局
2. 节点与文字
3. 连线
4. 流程切换
5. 交互与可访问性
6. 打印与导出
7. 禁止项

## 1. 总体布局

- 使用严格横向泳道：每个角色、团队或系统占一条连续横向区域。
- 时间与流程推进方向固定为从左到右。
- 泳道名称固定在左侧，滚动时保持可辨认。
- 正式 HTML 使用画布优先布局：画布占满整个视口，不为常驻标题、说明区或 footer 预留高度。
- 流程与缩放控制使用文档流中的单行紧凑工具栏；工具栏占据真实高度，不设置浮动定位或高层级覆盖画布。
- 工具栏必须可收起，流程过多时横向滚动，不得换行挤压画布。
- 节点详情、待确认项、校验指标和来源摘要放入默认关闭的覆盖式信息抽屉，不得作为常驻底部区域。
- 使用统一网格计算节点位置，不由模型提供像素坐标。
- 可读密度默认参数使用约 180px 节点宽、88px 列间距、14px 同列垂直间距和 168px 角色栏。
- 节点未缩放正文不得低于 12px、标题不得低于 14px；1920px 及以上视口的默认缩放不得低于 90%。
- 节点高度按标题与摘要行数自动计算，短文本最小 84px；不得为压缩泳道而截断长文本。
- 画布超宽时允许水平滚动和缩放，不压缩到文字不可读。

## 2. 节点与文字

- 使用真实 SVG `<g>`、`<rect>`、`<foreignObject>`。
- 业务文字放在 `foreignObject` 内，以 HTML 自动换行。
- 标题和摘要不得使用省略号截断。
- 节点内边距至少 12px。
- `action`、`system_process`、`decision`、`result` 通过形状标签和轻量颜色区分，不能只靠颜色。
- 流程类别是卡片与连线的一级颜色编码：主流程使用蓝色、次流程使用青绿色、异常流程使用红色。
- 节点同时属于多类流程时，“显示全部”按主流程、次流程、异常流程的稳定优先级着色；切换具体流程后，所选路径统一使用该流程类别颜色。
- 节点详情通过点击展示来源数量、摘要和流程归属。

## 3. 连线

- 使用真实 SVG `<path>` 与箭头 marker。
- 主流程使用实线；条件、回流和异常同时使用线型与文字标签区分。
- 每条跨泳道关系必须显示标签。
- 标签带不透明背景，避免压在线条上。
- 关系标签必须放入节点间缝隙或独立路由区，不得遮挡节点正文或其他关系标签。
- 关系标签默认使用约 80×32px 的横向信息框，优先减少中文关系文本的过早换行。
- 正向关系优先使用正交折线。
- 回流关系使用下沉或上抬通道，避免穿过节点正文。
- “显示全部”模式下，关系必须经过确定性占用规划；具有共同起点或终点的关系允许复用共同线段，没有共同端点的关系不得共享超过 8px 的同向线段。
- 多条无共同端点的关系使用同一列缝隙时必须分配不同通道；有共同端点的关系优先汇聚，避免为强行分线制造视觉噪声。
- 可见业务线保持约 1.8px；用于悬停的透明命中轨道可以更宽，但必须始终透明、无箭头。
- 回流关系放入最后一条泳道下方的独立路由区；路由区随回流数量动态增高，首条回流线距泳道正文至少 48px，最外层线路距画布底部至少 48px。
- 不使用无方向装饰箭头。

## 4. 流程切换

- 单 HTML 保存全部流程。
- 流程选择区首位固定为“全部”，但不默认选中。
- 默认高亮唯一主流程。
- 每条次流程和异常流程有独立选择按钮。
- 主流程、次流程和异常流程的按钮、卡片边框、卡片浅色底、连线与箭头必须使用一致且明显不同的类别颜色。
- 切换只改变 `is-active`、`is-muted` 等样式，不增删 DOM。
- 选择具体流程后，非当前节点和关系透明度应不高于 0.04，当前流程的可见线宽不得放大。
- 同属多条流程的节点和关系在任一对应流程激活时保持高亮。
- 提供“显示全部”模式，但不作为默认状态。
- “显示全部”时主流程保持最高视觉权重，次流程和异常流程降低静态权重，非主流程关系标签默认隐藏但 DOM 不删除。
- 在“显示全部”状态悬停或键盘聚焦任一关系时，高亮该关系所属完整流程并显示其全部关系标签，其他流程降噪。

## 5. 交互与可访问性

- 所有按钮可通过键盘访问，并有清晰焦点样式。
- SVG 提供 `<title>` 与 `<desc>`。
- 颜色满足浅色背景下的正文对比度。
- 状态通过文字、形状或线型重复表达。
- 不使用 `localStorage`、`sessionStorage` 或外部服务。
- 不把变量数据拼入 `innerHTML`；模板内业务数据已经由渲染器转义。

## 6. 打印与导出

- 单文件通过 `file://` 直接打开。
- CSS、JavaScript 和 SVG 全部内联。
- 打印时隐藏浮动工具栏和信息抽屉，只保留完整泳道图。
- 导出 SVG 时复制当前完整 SVG，并补齐必要命名空间和样式。
- 导出的 SVG 必须包含全部节点和关系，不只导出当前高亮流程。

## 7. 禁止项

- 不使用 Mermaid、ASCII 或截图代替正式 SVG。
- 不加载 CDN、远程字体、外部脚本或外部样式。
- 不采用已有/一期/二期颜色图例。
- 不把所有页面、按钮、字段和 Toast 平铺成节点。
- 不因画布拥挤删除次流程或异常流程。
- 不用视觉“简化”掩盖语义缺口。
- 不增加常驻页头、footer 或底部信息卡片压缩核心画布。
