# 页面与字段

**菜单分组**：仅用于组织下级菜单，不独立承载内容区页面。
**页面**：具有独立内容区，后续可建立页面详情。

### 1.1 首页

- 页面名：首页
- 页面类型：Page
- 菜单/功能位置：公文 -> 首页
- 上游入口：-
- 谁会进入：员工/个人用户、公文管理人员
- 页面目标：查看公文总览及不同处理状态下的公文，并提供发文拟稿和收文的快捷入口。
- 关键操作：搜索公文、切换公文状态、发文拟稿、收文。
- 下游跳转：发文拟稿页、收文办理页
