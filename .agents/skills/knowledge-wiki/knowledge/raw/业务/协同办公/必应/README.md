# 必应

## 这是什么

这是必应子域的固定文件级路由入口，用来说明本子域承载什么知识、遇到什么问题该优先看哪些语义文件。

本 README 承载领域契约与任务路由；具体业务规则仍保留在对应语义文件中。

## 领域契约

### 领域定义

必应领域回答的是：
企业员工如何通过薪福通平台的必应完成待办的创建、列表管理和协同处理。

必应支持待办创建/列表/协同处理、重复规则和智能提醒。

### 解决的问题

必应领域主要用于解释以下问题：

- 待办事项如何创建
- 如何配置处理人、抄送人和重复规则
- 待办列表如何按发起人/处理人/抄送人查看
- 待办如何协同处理（催办、转处理人、评审、评论）

### 为什么独立成域

必应需要独立沉淀，是因为它同时具备以下特征：

- 必应是企业日常办公的任务协同工具，承载待办的创建与处理
- 涉及重复规则和智能提醒等独立逻辑

### 与上游领域的关系

- 工具开通或使用授权补读权限管理

这里描述的是上游依赖事实，不等于具体规则已经由其他领域定义完成。

### 稳定结论

- 必应是企业日常办公协同的任务工具
- 其核心价值是为待办创建、列表管理和协同处理提供稳定输入
- 它可以服务业务分析、产品设计、体验解释和排障分析，但本文件本身不承载下游消费说明
