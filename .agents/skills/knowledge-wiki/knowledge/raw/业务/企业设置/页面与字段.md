## 定制方案

定制方案属于企业设置模块，用于企业选择和切换预置的行业解决方案及行业特性。

设计意图：企业每次只应用一个方案（单选），因此首屏结构分层——头部展示当前方案版本，中间以卡片列表展示其他可选方案欢迎用户尝试（发现模式），下方为独立的行业特性开关。

- 来源：用户提供的产品事实
- 来源类型：产品交互规格
- 最近更新：2026-06-22

### 1. 页面结构

#### 1.1 头部信息区

展示当前企业正在使用的版本（默认为「标准版」），并告知用户"你可切换以下解决方案"。

#### 1.2 组装方案选择

提供行业预置方案供企业选用。以卡片列表形式展示，每张卡片包含：

- 方案名称（如人力资源行业版、律所行业版、医疗行业版等）
- 方案简介
- 「详情」按钮
- 「启用」按钮

##### 详情

点击「详情」按钮后，跳转至**应用中心**的对应方案详情页。

##### 启用

点击「启用」按钮后，弹出确认弹窗，弹窗内容分为两部分：

**1. 包含的应用**

表格字段：

| 字段 | 说明 |
|------|------|
| 业务分类 | 应用所属业务分类 |
| 应用 | 应用图标 + 应用名称，横向平铺展示 |

**2. 个性化配置项**

表格字段：

| 字段 | 说明 |
|------|------|
| 个性化配置项 | 涉及的配置类型：工作台、主题、登录页 |
| 方案配置 | 展示各项配置对应的具体方案 |

用户确认启用后，页面展示成功提示 alert「xxx行业版启用成功」，alert 下方展示两个模块：

**模块一：应用添加**

对应方案中需开发者审核后才可启用的应用。展示待审核应用列表，并提供「前往应用中心」查看的按钮。

**模块二：渠道使用**

告知用户已开通的使用渠道：

| 渠道 | 说明 |
|------|------|
| PC 客户端 | 提供「去下载」入口 |
| App 端 | 提供「去下载」入口 |
| Web 端 | 提供「复制链接」按钮 |

#### 1.3 启用后页面状态

完成启用流程后，页面切换为「已选方案详情」模式，发生以下变化：

**头部变化：**

头部区域新增两个按钮：

| 按钮 | 行为 |
|------|------|
| 切换方案 | 唤起承载各方案列表的弹窗（已启用的方案不可再次选择） |
| 查看更多解决方案 | 跳转应用中心 |

**方案详情区：**

原应用添加和渠道使用模块被替换为当前已选方案的详情，包含以下设置项：

- 应用管理
- 个性化设置
- 工作台管理
- 企业文化
- 行业特性
- 使用渠道

#### 1.4 行业特性选择

提供三种行业特性开关，企业可按需开启。三种特性之间无互斥关系，可同时开启。

- 开启前无需二次确认，关闭时无数据影响提示
- 切换组装方案后，当前已开启的行业特性将被重置

**央国企：**

开启后，将在花名册中预置以下字段信息：
- 职业资格
- 职业技能等级
- 出国（境）人员信息
- 党员信息

**零售连锁：**

开启后，将产生以下变化：
- 支持员工门店信息展示
- 考勤和算薪可按门店统计数据
- 限制在员工花名册中直接修改转正、调动及离职相关信息

**制造业：**

开启后，将支持在假勤管理中使用常见的制造业考勤规则及班次。

> 注：制造业特性即将上线。

### 缺口 / 待确认

- [GAP] 组装方案中卡片列表的完整枚举（人力资源行业版/律所行业版/医疗行业版以外的方案名称）未采集

## 个性化展示

个性化展示属于企业设置模块，包含企业文化和企业信息展示两部分，用于企业对外展示的品牌表达和个性化配置。

- 来源：用户提供的产品事实
- 来源类型：产品交互规格
- 最近更新：2026-06-23

### 0. 入口页面

个性化展示的首屏为总览式卡片列表页，每个配置项对应一张卡片。设计意图：企业的可个性化内容较多，总览页让用户自由挑选想自定义的项，采用浏览挑选模式（多选）。卡片有三种可见状态：

| 状态 | 触发条件 | 表现 |
|------|---------|------|
| 正常 | 企业已开通且用户有权限 | 可点击进入配置 |
| 禁用 | 企业已开通但用户无权限 | 卡片灰底 + 标题前小锁头图标，悬停提示"请联系客户经理开通功能" |
| 隐藏 | 企业未开通 | 卡片不展示 |

### 1. 页面通用布局

各配置项的详情页基本采用「左编辑 + 右预览」的结构：

- **左侧**：配置编辑区
- **右侧**：预览/示例图区，实时反映左侧配置变化

**企业文化部分的预览差异：**

| 配置项 | 右侧展示 |
|--------|---------|
| 企业品牌配置 | 可预览（logo 替换效果实时反映） |
| 网页页签配置 | 可预览（favicon 和标题实时反映） |
| 工作台文化墙配置 | 静态示例图（仅示意图片摆放位置，因用户最多可上传 5 张图片，无法滚动预览） |
| 企业登录页配置 | 可预览（登录页效果实时反映） |
| 主题色配置 | 可预览（主题色切换效果实时反映） |
| 客户端启动页配置 | 可预览（启动页效果实时反映） |

### 1. 企业文化

#### 1.1 企业品牌配置

企业自行上传 logo 图片，用于切换企业、企业列表等场景展示。

- 规格：120 × 120px，JPG / JPEG / PNG，2MB 以内

#### 1.2 网页页签配置

企业可配置以下两项：

- **页签图标**：上传网页端左上角 favicon。规格：32 × 32px，JPG / JPEG / PNG，10KB 以内，文件名不超过 20 字
- **页签标题**：设置网页标签栏显示的标题文字，字数无限制

#### 1.3 工作台文化墙配置

分为移动端和电脑端两部分，二者仅尺寸不同，配置项完全一致：

- 移动端尺寸：400 × 126px
- 电脑端尺寸：1048 × 144px
- 格式：JPG / JPEG / PNG，5MB 以内
- 可上传最多 5 张图片
- 每张图片可附带跳转链接（非必填项）
- 支持单张编辑和单张删除

#### 1.4 企业登录页配置

企业可按需配置专属登录页。不是默认开放能力，需要联系客户经理或服务人员申请开通。配置后企业用户需通过指定地址访问专属登录页。未配置时，企业使用平台官方默认登录 / 注册页。

登录页配置分为两大端：电脑端和移动端。

##### 1.4.1 电脑端

电脑端下分为网页端和客户端。

**电脑 - 网页端：**

| 配置项 | 说明 |
|--------|------|
| 背景图 | 上传登录页背景图片 |
| 登录页主题色 | 选择登录页主题颜色 |
| 登录方式 | 勾选需展示的登录方式（密码登录 / 验证码登录 / 扫码登录） |
| 启动客户端按钮 | 勾选是否展示「启动客户端」按钮 |

**电脑 - 客户端：**

| 配置项 | 说明 |
|--------|------|
| 同步网页端配置 | 确定是否持续同步网页端的配置（开启后网页端的后续修改会自动同步到客户端） |
| 背景图 | 上传登录页背景图片 |
| 登录页主题色 | 选择登录页主题颜色 |
| 登录方式 | 勾选需展示的登录方式（密码登录 / 验证码登录 / 扫码登录） |

##### 1.4.2 移动端

移动端下分为网页端和 App 端。

**移动 - 网页端：**

| 配置项 | 说明 |
|--------|------|
| 企业 logo | 上传企业 logo 图片 |
| 背景图 | 上传登录页背景图片 |
| 欢迎语/应用名称 | 设置登录页欢迎语或应用名称 |
| 登录页主题色 | 选择登录页主题颜色 |
| App 入口展示 | 勾选是否展示 App 入口 |

**移动 - App 端：**

| 配置项 | 说明 |
|--------|------|
| 同步网页端配置 | 确定是否持续同步移动-网页端的配置（开启后移动-网页端的后续修改会自动同步到 App 端） |
| 企业 logo | 上传企业 logo 图片 |
| 背景图 | 上传登录页背景图片 |
| 欢迎语/应用名称 | 设置登录页欢迎语或应用名称 |
| 登录页主题色 | 选择登录页主题颜色 |
| 登录方式 | 勾选需展示的登录方式（密码登录 / 验证码登录） |

#### 1.5 主题色配置

当前仅可选 2 种主题：

1. **系统默认主题色**
2. **党政红**

党政红主题包含以下变更：

- 系统框架色切换为党政红
- 工作台快捷方式图标切换为党政红风格（应用图标 + 菜单/功能图标）

党政红主题不包含以下内容的修改：

- 开放平台应用图标
- OA 表单图标
- 报表图标

> 上述内容因涉及第三方应用或企业自建内容，暂无法统一覆盖。

#### 1.6 客户端启动页配置

企业可自行上传 .. App 端的启动页图片。

- 客户端规格：2880 × 1432px，JPG / JPEG / PNG，500KB 以内，文件名不超过 20 字
- App 端规格：375 × 812px，其余同客户端（JPG / JPEG / PNG，500KB 以内，文件名不超过 20 字）

### 2. 企业信息展示

#### 2.1 企业名称展示配置

按需设置企业名称在平台中的展示方式，可用于区分总公司与子公司等组织层级关系。

**适用场景：**

- 员工打卡场景中展示的企业名称
- 邀请员工加入企业时展示的企业名称
- 员工日常使用平台时左上角的企业名称展示

**支持 5 种展示规则：**

| 规则 | 说明 |
|------|------|
| 按认证企业展示 | 使用企业认证时的名称 |
| 按企业简称展示 | 使用企业设置的简称 |
| 按合同公司展示 | 使用合同公司名称（依赖已维护合同公司基础数据） |
| 按法人公司展示 | 使用法人公司名称（依赖已维护法人公司基础数据） |
| 按组织架构展示 | 使用组织架构中的名称（依赖已维护组织架构基础数据） |

> 后三种规则依赖企业已维护对应的基础数据，未维护时不可用。

#### 2.2 企业详情展示配置

按需设置企业详情信息的可见范围。企业管理可根据需要配置以下五项内容的展示权限：

| 字段 |
|------|
| 统一社会信用代码 |
| 详细地址 |
| 法人姓名 |
| 法人证件类型 |
| 法人身份证号码 |

每项字段支持三级可见范围：

- **全员可见**（默认）
- **部分人员可见**
- **全员不可见**

## 消息设置

消息设置属于企业设置模块，用于企业配置消息通知的发送渠道和业务消息规则。

- 来源：用户提供的产品事实
- 来源类型：产品交互规格
- 最近更新：2026-06-23

### 1. 页面结构

消息设置页面包含三个 Tab：

- 消息渠道设置
- 业务消息设置
- 企业内部消息收发

### 2. 消息渠道设置

向员工发送本企业所有相关信息的渠道设置。四种渠道均采用开启/关闭的交互方式。

包含四种渠道：

#### 2.1 短信

企业通过短信为员工发送消息提醒。用户可开启或关闭。

- 默认状态：待确认

#### 2.2 微信公众号

开启后支持两种消息类型推送：

| 消息类型 | 推送范围 |
|---------|---------|
| 待办事项提醒 | OA 审批、费控、人事等待办提醒 |
| 通知消息提醒 | OA 审批、费控、人事、薪酬、工资、福利、权限、抄送等提醒 |

开启前提：员工需要关注本公众号并登录。

#### 2.3 邮件

开启后支持两种消息类型推送：

| 消息类型 | 推送范围 |
|---------|---------|
| 待办事项提醒 | OA 审批、费控、人事等待办提醒 |
| 通知消息提醒 | OA 审批、费控、人事、薪酬、工资、福利、权限、抄送等提醒 |

#### 2.4 AI 电话语音

开启后支持以下消息类型推送：

| 消息类型 | 推送范围 |
|---------|---------|
| 待办事项提醒 | OA 审批待办提醒 |

### 3. 业务消息设置

业务消息设置包含通知设置和待办设置两部分。

#### 3.1 通知设置

以表格展示，表格字段：

| 字段 | 说明 |
|------|------|
| 规则名称 | 通知规则的名称 |
| 设置操作 | 点击后弹出设置弹窗 |

**设置弹窗：**

用户可在弹窗中勾选各类关注的通知类型。

勾选为关注的通知后，将产生以下效果：

1. 关注的通知会展示在员工工作台「关注的通知」区域，供员工查看
2. 关注的通知提供弹窗提醒
3. 员工将默认订阅企业设置的关注的通知，且无法取消订阅

#### 3.2 待办设置

以表格展示，表格字段：

| 字段 | 说明 |
|------|------|
| 消息名称 | 待办消息的名称 |
| 业务模块 | 所属业务模块 |
| 消息类型 | 消息的类型分类 |
| 范围 | 消息的覆盖范围 |
| 状态 | 当前启用状态 |
| 操作 | 编辑 / 删除 |

提供「新增规则」功能，新增/编辑规则的表单包含以下字段：

| 字段 | 可选值 |
|------|--------|
| 消息名称 | 待办汇总通知 / 待办超时汇总通知 |
| 业务板块 | OA 审批 / 所有待办 |
| 统计周期 | 天 / 周 / 月 |
| 提醒时间 | 0 点至 12 点之间选择整点汇总发送 |
| 提醒范围 | 全部成员 / 部分成员 |
| 提醒渠道 | 可多选，详见下方说明 |
| 状态 | 开关（开启 / 关闭） |

提醒渠道选项说明：

| 渠道 | 说明 |
|------|------|
| 平台消息 | 薪福通 PC、APP 通知提醒和 IM 通知助手 |
| 短信 | 请联系分行客户经理申请开通短信提醒 |
| 邮件 | 您的企业当前未开启邮件通知消息提醒，请先前往「消息渠道设置」开启功能 |

### 4. 企业内部消息收发

#### 4.1 企业内部消息收发（聊天消息）

用户可自行开启或关闭。

- 包含 PC 端和移动端的私聊和群聊
- 关闭后全体成员无法发送或接收聊天消息
- 机器人消息不受此开关影响

#### 4.2 群聊合规管理

**建群、入群合规内容提示：**

- 用户可开启或关闭
- 开启后，新建群及邀请新用户入群，当群组成员数达到提醒数量时，在会话窗口增加合规管理内容提示
- 群组成员人数小于等于 N 人时不会触发合规内容提示，N 值可由用户自行编辑

**建群合规管理提示文案：**

- 系统提供默认文案
- 用户可自行编辑

**入群合规管理提示文案：**

- 系统提供默认文案
- 用户可自行编辑

- [QUESTION] 短信/微信公众号/邮件/AI电话语音四种渠道的默认开关状态待确认
- [GAP] 群聊合规管理中合规提示的默认文案内容未采集

## 企业登录页自定义

企业登录页个性化配置用于让企业拥有专属登录页展示。

### 1. 维护入口
路径：管理后台 -> 企业设置 -> 企业文化 -> 企业登录页配置

### 2. 开通方式
该能力通常需要联系专属客户经理或服务人员申请开通。

### 3. 支持范围
支持配置：
- Web 登录页
- H5 登录页

### 4. Web 页面可配置项
- 登录背景图
- 网页名
- 登录方式
- 按钮展示方式

### 5. H5 页面可配置项
- 应用名
- 网页标签
- 按钮展示方式

### 6. 使用效果
未配置时，企业使用平台官方默认登录 / 注册页。
配置后，企业用户需通过指定地址访问专属登录页。

## 企业文化

企业文化用于承接企业品牌与文化展示。

### 1. 维护入口
路径：管理后台 -> 企业设置 -> 企业文化

### 2. 企业 logo 配置
支持上传新的企业 logo。
建议：
- 尺寸 120 * 120
- 格式 JPG、JPEG、PNG
- 大小 2M 以内

### 3. 企业文化墙配置
支持同时调整：
- PC 端企业文化墙
- 移动端企业文化墙

企业文化内容可在员工端查看，用于增强企业品牌识别和归属感。

## 企业信息展示

企业信息展示配置用于控制员工在不同场景下看到的企业名称和企业详情信息。

### 1. 维护入口
路径：管理后台 -> 企业设置 -> 企业信息展示配置

### 2. 适用场景
- 员工打卡场景中的企业名称展示
- 邀请员工加入企业时的企业名称展示
- 员工日常使用平台时左上角的企业名称展示
- 对企业敏感信息进行保密控制

### 3. 企业名称展示规则
当前支持：
- 按认证企业展示
- 按企业简称展示
- 按合同公司展示
- 按法人公司展示
- 按组织架构展示

### 4. 企业详情展示规则
可对以下信息配置可见范围：
- 统一社会信用代码
- 详细地址
- 法人姓名
- 法人证件类型
- 法人身份证号码

常见可见范围包括：
- 全员可见
- 部分成员可见
- 对企业全员均不展示

### 5. 规则依赖
按合同公司、法人公司、组织架构展示时，依赖企业已维护对应基础数据。
