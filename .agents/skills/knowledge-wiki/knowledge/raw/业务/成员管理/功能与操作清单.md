# 功能与操作清单

## 适用范围与维护边界

本文件记录成员组和外部人员管理明确支持的功能与操作。

## 快速导航

- [成员组](#成员组)
- [外部人员](#外部人员)

## 成员组

成员组用于对成员进行分类管理，并可与审批流程、权限管理等能力联动。

### 维护入口

路径：管理后台 -> 成员管理 -> 成员组

### 新增方式

#### 单个新增

维护成员组名称及成员组说明信息。

#### 批量新增

通过“批量操作 -> 批量导入”下载模板、填写并上传，可批量导入成员组及组内成员。

### 添加成员方式

#### 直接添加

适用于企业已经有明确、固定成员的场景。

#### 规则匹配自动添加

可按以下维度配置关联规则：

- 岗位
- 职位
- 法人公司等

当成员满足规则时，可自动归属到对应成员组。

## 外部人员

### 维护入口

路径：管理后台 -> 成员管理 -> 外部人员

### 支持能力

- 添加外部人员
- 维护外部人员类型
- 邀请外部人员加入企业
- 查看邀请记录
- 对外部人员授权
- 外部人员转为内部员工
- 内部员工转为外部人员

### 人员类型管理

路径：管理后台 -> 成员管理 -> 外部人员 -> 添加类型

可对外部人员进行分类。

### 邀请方式

#### 手机号邀请

输入被邀请人手机号后，对方登录平台即可收到邀请加入信息。

#### 二维码邀请

将企业二维码或邀请链接发送给被邀请人，对方发起加入申请后，管理员需审批通过。

### 邀请记录

管理员可查看被邀请人信息，并支持：

- 提醒被邀请人
- 撤销邀请
- 审批二维码 / 链接申请

### 身份转换

外部人员可以直接转为企业员工。

进入花名册后需要补充维护组织机构信息。

## [GAP] / [CONFLICT] / [QUESTION]
