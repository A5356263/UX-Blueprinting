# 任务与路径

本文件以跨页面任务为主线，并补充各页面内部已确认的操作顺序。流程中的建议性复核步骤不等同系统强制状态机；未确认的成功反馈、回滚与恢复保留缺口。

## 快速导航

- FL01—FL08：跨页面业务流程
- 页面内路径：按菜单分组查找

## 跨页面业务流程

### FL01 企业首次启用

角色：企业管理员、考勤管理员、表单管理员。触发：新企业准备上线假勤。

前置：组织架构和花名册资料齐备；明确企业考勤周期。

流程：维护组织与员工资料 → 配置统计周期 → 设置司历、班次及所需打卡/加班/外勤规则 → 配置考勤组并匹配人员 → 设置假期类型及方案 → 排班制完成排班或确认适用自动对班配置 → 开放前配置审批 → 检查考勤人员异常信息 → 开放员工使用。

分支与边界：设备打卡需接入考勤机并关联人员；手机打卡需先设上班地点和移动方案。自由工时不套用普通班制的异常和加班规则。

结果与缺口：关键员工资料及适用规则已具备；启用后的验收记录仍需团队补充。

相关页面：配置总览、考勤组管理、班次管理、司历管理、考勤人员、假期方案设置、排班表。

业务约束：R01 初始化依赖；R02 考勤组唯一性；R03 三类班制；R04 排班制例外；R31 审批配置权限。

### FL02 配置手机打卡

角色：考勤管理员、员工。触发：新增办公地点或启用手机打卡。

前置：明确GPS、Wi-Fi或蓝牙方式及适用人员。

流程：建立上班地点 → 配置地址范围/Wi-Fi/蓝牙 → 新增或维护移动打卡方案 → 选择地点及方式 → 考勤组关联方案 → 员工依规则打卡。

分支与边界：蓝牙只能App配置；移动端加Wi-Fi前PC需已有考勤组与地点。已有组关联方案时，维护方案可自动更新组。异常拍照打卡按所设审批通过后生效。

结果与缺口：目标员工适用的地点和打卡方式完成关联；[GAP] 首次验证结果未提供。

相关页面：上班地点、移动打卡方案、考勤组管理、原始打卡记录。

业务约束：R10 移动打卡依赖；R11 GPS与Wi-Fi；R12 移动配置与审批条件。

### FL03 初始化和运营假期额度

角色：考勤管理员、考勤专员。触发：新建假期或迁移历史余额。

前置：确认假期是否有余额概念。

流程：设置假期类型 → 建立方案和适用范围 → 配置时长与申请限制 → 有余额时设置发放、有效期、提醒和结薪 → 迁移时核对方案是否已发放 → 按模板初始化或调整 → 在额度明细核查。

分支与边界：已发放再初始化会重复；初始数据管控可采用原文建议的当年发放0再导入，具体实施须先核对实际余额。无余额的类型以申请限制控制。

结果与缺口：额度和方案对应；差异处置、回退待补。假期计算、折算与取整支持配置和批量处理，闰年、入离职、跨年细节本次暂不展开。结薪金额在XFT算薪模块按默认或自定义公式计算，公式不在本库展开。

相关页面：假期类型设置、假期方案设置、假期额度明细。

业务约束：R17 假期方案前置与范围；R18 请假时长与限制；R19 额度发放；R20 额度初始化与调整；R21 到期提醒与结薪。

### FL04 管理员批量代请假

角色：管理员。触发：为多人提交相同假期时间的申请。

前置：对应员工的考勤组、假期适用和审批配置齐备。

流程：请假记录 → 发起请假流程/批量填写 → 选择员工 → 填写假期类型、开始结束时间和事由等 → 提交校验 → 查看通过/失败人员与失败原因 → 修改失败项或继续提交通过人员 → 确认请假 → 在批量请假记录查看状态并刷新。

分支与边界：单条采用“发起单条”；未选员工时假期等字段不可修改。用户已确认页面展示失败人员及原因、支持修改失败项，并允许继续提交通过人员；具体重新校验、失败数据保留及重复提交防护规则待补。批次完成不等于单据审批通过。

结果与缺口：得到批次处理结果；后续审批结果另查申请单。

相关页面：请假记录、考勤组管理、假期方案设置、勤务数据。

业务约束：R22 批量申请与审批颗粒度；R31 审批配置权限。

### FL05 管理员批量代加班

角色：管理员、审批人员。触发：为多名员工代发起加班申请。

前置：明确人员、时间和审批颗粒度。

流程：加班记录 → 发起加班流程 → 时间原因一致选批量填写，不一致选模板导入 → 校验员工及加班信息 → 校验成功后继续发起 → 选择拆分或合并发起 → 进入审批。

分支与边界：拆分为多条单据分别审批；合并为一条一次审批。校验失败的完整修复与再次提交过程待补。

结果与缺口：申请进入对应审批，不能把提交成功记为审批成功。

相关页面：加班记录、加班规则、勤务数据。

业务约束：R22 批量申请与审批颗粒度。

### FL06 考勤异常和业务异常处理

角色：管理员、员工。触发：出现异常记录或规则班次变更。

前置：先识别异常类型和受影响记录。

流程：缺卡/迟到等考勤异常 → 查打卡、请假和相关记录 → 按实际原因采用补卡等已提供能力；规则/班次变更导致业务异常 → 查业务异常 → 依据现有规则重算 → 对比前后结果 → 必要时更新日月统计。

分支与边界：添加补卡直接生效，发起补卡需审批。最后更新日月统计是依据依赖关系建议的检查步骤。业务异常中的删除对象已确认为业务单据；删除对审批、统计及恢复的影响未确认，不把删除作为保留单据并消除异常的方式。

结果与缺口：异常来源及处理结果可解释；未提供的申诉、回滚、无影响关闭分支为[GAP]。

相关页面：考勤异常、业务异常、原始打卡记录、补卡记录、日考勤统计。

业务约束：R15 添加与发起不同；R24 日月核算依赖；R25 业务异常与重算。

### FL07 月度核算确认与发布

角色：考勤专员、考勤员、员工。触发：考勤周期结算及算薪取数。

前置：明确统计周期、单据状态、截止及发布开关。

流程：查勤务数据中的在途审批 → 根据企业截止策略完成单据处理 → 核算整月日统计 → 核算月汇总 → 刷新并检查明细/汇总 → 按企业配置使用或跳过考勤确认（使用时通过该功能处理异议） → 开启发布时发布月汇总 → 智能算薪取数。

分支与边界：日核算在月汇总前是明确依赖；用户确认全员确认不是所有企业统一适用的发布硬门槛；是否使用考勤确认由企业自定义，员工异议通过该功能处理。具体企业采用的确认与发布顺序按其配置。跨店操作归属由管理模式决定。

结果与缺口：月考勤结果可供核查和取数；考勤确认内的异议处理步骤、发布撤回、锁定解锁及算薪变更同步待补。

相关页面：勤务数据、日考勤统计、月考勤汇总、月考勤明细、配置总览。

业务约束：R24 日月核算依赖；R26 截止和发布；R27 跨店管理权限。

### FL08 考勤机员工关联

角色：考勤管理员。触发：接入新设备或设备已有存量人员。

前置：支持的考勤机已接入并连接；版本兼容条件已核查。

流程：添加考勤机 → 设置员工、部门、地点及同步 → 已有人员则归集员工 → 未关联员工与花名册对应 → 按需下发人脸 → 同步打卡记录 → 查询原始记录。

分支与边界：已有设备侧人脸不自动显示到App人脸列表；跨设备版本不一致可能无法识别。无设备的企业可跳过这条流程。

结果与缺口：打卡可对应到正确的花名册员工；失败时查看记录并补充处置信息。

相关页面：考勤机管理、人脸管理、考勤人员、原始打卡记录。

业务约束：R29 人脸审核与同步；R30 设备关联与同步。

## 考勤统计的页面内路径

### 勤务数据

选择需核算周期的相关单据 → 筛选未完成审批或撤销状态 → 按企业流程处理 → 回到核算。

关联页面：月考勤汇总、配置总览、请假记录、加班记录。

跨页面流程：FL07 月度核算确认与发布。

### 日考勤统计

确认考勤周期与待处理记录 → 核算对应日数据 → 供月考勤汇总核算。

关联页面：月考勤汇总、月考勤明细、勤务数据、考勤异常。

跨页面流程：FL07 月度核算确认与发布。

### 统计项管理

检查系统项是否满足需求 → 维护适用统计项或新增自定义项 → 对相关考勤结果核对口径。

关联页面：日考勤统计、月考勤汇总、假期类型设置。

### 月考勤汇总

检查在途单据与异常 → 核算整月日统计 → 核算月汇总 → 核查结果 → 按企业配置选择是否使用考勤确认处理确认与异议 → 按发布配置发布 → 算薪取数。

关联页面：日考勤统计、月考勤明细、勤务数据、配置总览。

跨页面流程：FL07 月度核算确认与发布。

### 月考勤明细

先核算日考勤 → 再核算月汇总 → 刷新后查看月明细。

关联页面：日考勤统计、月考勤汇总、统计项管理。

跨页面流程：FL07 月度核算确认与发布。

## 异常管理的页面内路径

### 考勤异常

定位异常员工/日期 → 检查原始记录与申请 → 根据实际原因处理 → 复核相关统计。

关联页面：原始打卡记录、补卡记录、业务异常、考勤人员、日考勤统计。

跨页面流程：FL06 考勤异常和业务异常处理。

### 业务异常

定位业务异常 → 核对班次/规则变化 → 重算 → 比较结果 → 复核日月统计。

关联页面：班次管理、请假记录、外出记录、加班记录、日考勤统计。

跨页面流程：FL06 考勤异常和业务异常处理。

## 打卡记录的页面内路径

### 补卡记录

确认需补卡的员工和日期 → 选择添加或发起 → 录入/导入 → 按选择直接生效或进入审批 → 查询记录并复核异常。

关联页面：打卡规则、考勤异常、原始打卡记录、勤务数据。

跨页面流程：FL06 考勤异常和业务异常处理。

### 拍照打卡记录

按同一年内的日期范围查询 → 检查图片/审批 → 按需要催办、导出或删除。

关联页面：移动打卡方案、原始打卡记录、勤务数据。

### 外勤记录

检查外勤打卡记录与照片地点 → 有审批时查看审批详情/催办 → 按需要导出或处理记录。

关联页面：外勤规则、外出记录、原始打卡记录、日考勤统计。

### 原始打卡记录

设置日期和人员等条件 → 查询记录 → 按需要添加/导入或核查异常记录 → 复核统计关联。

关联页面：补卡记录、外勤记录、拍照打卡记录、考勤机管理、日考勤统计。

## 加班管理的页面内路径

### 加班记录

选择单条/批量填写/模板导入 → 填写 → 校验 → 选择拆分或合并 → 发起审批。

关联页面：加班规则、勤务数据、月考勤汇总。

跨页面流程：FL05 管理员批量代加班。

## 外勤管理的页面内路径

### 出差记录

出差记录 → 发起出差流程 → 选择表单 → OA填写申请与行程 → 提交审批。

关联页面：配置总览、勤务数据、日考勤统计。

### 外出记录

外出记录 → 发起外出流程 → OA选择申请人并填写时段/原因 → 提交审批。

关联页面：外勤规则、外勤记录、勤务数据、日考勤统计。

## 排班管理的页面内路径

### 班次调整记录

定位员工与时间范围 → 查询调整记录 → 核对相关排班和申请。

关联页面：排班表、划线排班、班次管理。

### 划线排班

进入划线排班 → 划定或调整出勤时段 → 核对类型、分割点和时长 → 保存操作及反馈待补。

关联页面：排班表、班次管理、班次调整记录。

### 排班表

选择考勤组/人员与日期 → 按班次或周期编辑，或模板导入 → 保存生效 → 核查班次调整记录。

关联页面：考勤组管理、班次管理、司历管理、划线排班、班次调整记录。

跨页面流程：FL01 企业首次启用。

## 假期管理的页面内路径

### 假期额度明细

先核对方案发放与历史余额 → 初始化或调整 → 在额度明细核查结果与有效期 → 按规则处理结薪。

关联页面：假期方案设置、假期余额、请假记录。

跨页面流程：FL03 初始化和运营假期额度。

### 假期方案设置

确认类型 → 定义范围和申请规则 → 按需设置额度及提醒/结薪 → 应用到适用人员 → 核查额度和申请结果。

关联页面：假期类型设置、假期额度明细、假期余额、请假记录。

跨页面流程：FL03 初始化和运营假期额度。

### 假期类型设置

配置类型与基础要求 → 在假期方案设置适用规则 → 供员工和管理员申请。

关联页面：假期方案设置、请假记录、统计项管理。

跨页面流程：FL03 初始化和运营假期额度。

### 假期余额

[GAP] 入口、主要操作与下游任务待补。

关联页面：假期额度明细、假期方案设置。

### 请假记录

请假记录 → 发起单条或批量填写 → 填写并核对 → 单条提交；批量校验后查看成功/失败情况、修改失败项或继续提交通过人员 → 查询申请/批次。

关联页面：假期方案设置、假期类型设置、假期额度明细、勤务数据、考勤组管理。

跨页面流程：FL04 管理员批量代请假。

## 考勤设置的页面内路径

### 班次管理

定义班次基本信息 → 选择全天/半天及班段 → 设置时间和适用规则 → 关联考勤组/排班 → 核对时长和异常。

关联页面：考勤组管理、排班表、划线排班、打卡规则、加班规则。

跨页面流程：FL01 企业首次启用。

### 打卡规则

按人员制度设置打卡和补卡规则 → 关联考勤组 → 员工申请/打卡 → 核查统计。

关联页面：考勤组管理、补卡记录、班次管理、考勤异常。

跨页面流程：FL01 企业首次启用。

### 加班规则

定义日期类型下的加班规则 → 关联考勤组 → 依据当日排班、打卡或申请核算加班。

关联页面：考勤组管理、班次管理、加班记录、月考勤汇总。

跨页面流程：FL01 企业首次启用。

### 节假日管理

设置方案/年度节日 → 核对法定假日和调休 → 司历关联 → 如跨年更新，重新保存司历并刷新日期。

关联页面：司历管理、考勤组管理。

### 考勤机管理

连接设备 → 配置人员/地点 → 归集并关联员工 → 按需下发人脸 → 同步打卡 → 核查原始记录。

关联页面：考勤人员、人脸管理、上班地点、原始打卡记录。

跨页面流程：FL08 考勤机员工关联。

### 考勤人员

查询人员 → 检查异常 → 缺组则设置组，缺基础资料则前往花名册 → 复核关联及资料。

关联页面：考勤组管理、上班地点、考勤机管理。

跨页面流程：FL01 企业首次启用。

### 考勤组管理

定义组及适用人员 → 选择班制 → 关联各项规则 → 保存 → 到考勤人员检查匹配结果。

关联页面：考勤人员、司历管理、班次管理、打卡规则、移动打卡方案、加班规则、外勤规则。

跨页面流程：FL01 企业首次启用。

### 配置总览

确定统计周期 → 按企业要求配置规则与相关参数 → 核查对申请、统计、发布和算薪的影响。

关联页面：月考勤汇总、勤务数据、出差记录、考勤组管理、班次管理。

跨页面流程：FL01 企业首次启用、FL07 月度核算确认与发布。

### 人脸管理

录入或同步 → 检查是否符合标准 → 后续录入需审核 → 生效供打卡 → 可查变更记录。

关联页面：考勤人员、考勤机管理、移动打卡方案。

### 上班地点

建立地点 → 配置GPS或Wi-Fi等方式 → 由移动方案或考勤机关联 → 员工在有效地点打卡。

关联页面：移动打卡方案、考勤组管理、考勤机管理。

跨页面流程：FL02 配置手机打卡。


### 司历管理

先设置节假日方案 → 选择应出勤天数规则 → 配工作日/天数并关联方案 → 保存刷新 → 应用于考勤组。

关联页面：节假日管理、考勤组管理、排班表、月考勤汇总。

跨页面流程：FL01 企业首次启用。

### 外勤规则

设置外勤打卡与外出申请规则 → 关联考勤组 → 员工按适用规则使用 → 查看对应记录。

关联页面：考勤组管理、外勤记录、外出记录。

跨页面流程：FL01 企业首次启用。

### 移动打卡方案

先建地点 → 方案选择地点/方式及验证规则 → 关联考勤组 → 员工打卡 → 查询记录。

关联页面：上班地点、考勤组管理、人脸管理、拍照打卡记录、原始打卡记录。

跨页面流程：FL02 配置手机打卡。

## 已确认的移动端能力与路径

以下只记录材料已确认的路径或作用，不由此推导完整 App 信息架构。

| 能力 | 已知路径或作用 | 未确认范围 |
| --- | --- | --- |
| 手机打卡 | 工作台 → 员工自助 → 打卡；按移动方案执行 GPS、Wi-Fi、蓝牙及相关验证 | 全部状态、系统权限、离线及异常流程 |
| Wi-Fi 管理 | 打卡 → 设置 → Wi-Fi 管理；选择组和地点后添加 | 编辑、删除、权限与完整表单 |
| 蓝牙管理 | 打卡 → 设置 → 蓝牙管理；蓝牙配置只能在 App 完成 | 配对发现、失败与设备要求 |
| 人脸录入 | 打卡 → 设置 → 人脸管理 | 上传及真人验证的全部反馈 |
| 移动排班 | 管理员可按人员或自定义范围排班 | 精确页面路径与操作字段 |
| 员工请假和余额 | 假期方案适用范围内可移动端申请和查看余额 | 完整申请、撤销、变更与余额页面 |
| 考勤确认 | 考勤专员核算后可发给员工确认 | 异议反馈、超时、重新确认及版本关系 |
