## 领域契约

### 领域定义

智能算薪领域回答的是：
企业如何通过薪福通智能算薪模块，根据自身业务需求创建不同薪资组并为每个薪资组配置专属薪资规则，每月自动获取系统数据、快速采集算薪所需的浮动数据，完成高效、精准的薪资计算，并与现有信息系统对接实现考勤等数据自动同步。

它覆盖的不是单一算薪功能，而是一整套与薪资计算生命周期相关的业务语义，包括：

- 数据采集：把产量、销售额、绩效、奖金、津贴补助等浮动算薪数据项设计为采集表模板，支持通过 API 对接、员工移动端提报、部门负责人录入等方式获取，自动生成以员工为维度的合计项直接用于薪资计算
- 档案管理：对基本工资和岗位工资等稳定工资项进行定薪调薪，根据岗位、职级自动生成薪资档案，实现薪资变动留痕及薪资档案线上化管理，支持在线开具薪资证明
- 薪资计算：根据企业不同薪资规则创建多个薪资组，在薪资组中设置多个工资项，工资项可直接来源于人事、考勤、社保数据，也可编写自定义公式
- 联动个税服务与薪资代发：计算完税前应发工资后可一键核算个税和实发工资，生成税后工资后可一键推送至代发
- 权限控制：按部门、薪资组、管理人员等维度进行权限隔离，仅可查看和操作权限范围内的数据，保证薪资保密性
- 人力成本分摊：按部门、项目、成本中心等多维度分摊，设定自定义成本分摊规则，系统自动计算并分配薪资成本，数据实时更新并同步到财务系统
- 社保公积金：内置多个城市的标准化参保方案，也支持自定义多套方案，同步核算五险一金，生成的数据可引用至算薪
- 薪酬报表中心：企业可自定义报表规则，系统自动按多维度生成人力成本表、部门社保公积金明细表、薪资合并表等
- 算薪结果拆分：算薪结果支持按合同公司、税局企业等多种维度快速拆分，自动匹配代发协议并提交代发，满足集团代发场景

### 解决的问题

智能算薪领域主要用于解释以下问题：

- 企业如何创建薪资组并为薪资组配置专属薪资规则
- 算薪所需的浮动数据如何设计采集表并完成采集
- 员工薪资档案如何设置、定薪调薪及定岗定薪如何完成
- 当期工资如何计算（核对计薪人员、计算税前、计算税后、算薪后处理）
- 已在线下算好应发工资时如何通过税前工资算税计算个税和实发工资
- 算薪完成后如何联动审批、薪资代发和电子工资单
- 社保公积金参保方案、参停保、月结账单和调基补差如何管理
- 人力成本如何按部门、项目、成本中心等维度分摊
- 薪酬报表如何生成与下载
- 算薪相关权限如何按部门、薪资组、业务分组隔离

### 为什么独立成域

智能算薪需要独立沉淀，是因为它同时具备以下特征：

- 是薪福通平台的核心独立产品模块，覆盖薪资计算完整能力
- 包含多个内部模块（算薪管理、档案管理、数据采集、薪酬设置、税前工资算税、成本分摊、社保公积金、薪酬报表中心），各模块在算薪主流程内形成业务闭环
- 与人事服务、审批管理、权限管理、考勤管理等多个领域存在交叉依赖
- 具有独立帮助中心产品文档和持续维护责任，41 个场景操作指引印证其独立维护价值

### 与相邻领域的关系

- 与人事服务交叉：智能算薪基于员工花名册数据算薪，员工入转调离、部门调动、考勤数据可实时同步至薪资计算；员工花名册维护、组织架构搭建由人事服务承接
- 与审批管理交叉：算薪审批、定调薪审批、数据采集审批的审批流在管理后台通用审批中配置，审批机制由审批管理承接
- 与权限管理交叉：功能权限与数据权限在管理后台通用权限管理中配置，权限治理由权限管理承接
- 与考勤管理交叉：智能算薪直接对接考勤数据，可调取考勤管理中的考勤汇总数据算薪
- 与个税服务交叉：智能算薪算好的工资数据自动同步到个税服务的个税核算与个税申报中；人员报送、扣缴义务人管理等由个税服务承接
- 与薪资代发、电子工资单交叉：算税后的实发工资可推送至薪资代发模块，工资表可推送至电子工资单模块，二者为独立模块

这里描述的是上下游依赖事实，不等于具体规则已经由其他领域定义完成。

### 稳定结论

- 智能算薪是薪福通平台薪资计算的核心产品模块
- 其内部按算薪管理、档案管理、数据采集、薪酬设置、税前工资算税、成本分摊、社保公积金、薪酬报表中心、操作日志等模块组织
- 智能算薪人员基于花名册员工，需先在花名册维护员工信息后才能在薪资档案和薪资计算中管理员工薪资信息
- 核心价值是为薪资计算各场景提供稳定的业务事实输入
- 它可以服务业务分析、产品设计、体验解释和排障分析，但本文件本身不承载下游消费说明
