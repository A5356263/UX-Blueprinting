## 开通路径

平台提供管理员和员工两类快速启用路径。

### 1. 管理员四步启用
管理员快速启用步骤包括：
1. 注册账号及实名认证
2. 创建企业及认证企业
3. 企业初始化设置
4. 分配用户权限

其中第三步通常包括：
- 创建组织架构
- 新增员工花名册
- 邀请员工加入企业

### 2. 员工两步启用
员工快速启用步骤包括：
1. 注册账号及实名认证（如需）
2. 接受邀请加入企业

## 企业创建与认证

企业管理员完成个人账号注册与实名认证后，可创建企业并申请企业认证。

### 1. 创建企业
路径：头像 -> 我的企业 -> 去创建企业

初次创建企业时，需填写：
- 企业名称
- 所在地区等基础信息

创建成功后，可查看平台功能模块。
未认证企业可试用部分功能，但有时间限制。

### 2. 企业认证方式
企业认证支持以下方式：
- 普通认证
- 已开招行对公户快捷认证
- 电子营业执照认证

### 3. 认证发起路径
路径：头像 -> 我的企业 -> 企业中心 -> 申请企业认证

### 4. 认证过程常见环节
- 选择认证方式
- 选择组织类型
- 填写相关信息
- 上传证照文件
- 按需补充代理人委托书
- 等待审核

### 5. 审核
通常需要 3 个工作日左右完成审核。
审核完成后，可在“我的企业”中查看企业认证状态。

### 6. 认证补充规则
- 若上传材料准确无误，系统可先进行机审
- 若机审未通过，后续可进入人工审核
- 未加盖企业公章的营业执照原件照片，无法完成企业认证
- 平台支持一人管理多个企业，但未认证企业数量达到上限后，继续创建会受限

## 超级管理员变更

超级管理员变更用于处理企业管理责任主体的调整。

### 1. 变更方式

#### 1.1 原超级管理员自行变更
路径：我的企业 -> 变更管理员

可分为：
- 变更后的管理员为企业法定代表人
- 变更后的管理员为非法定代表人，需要补充代理委托书

#### 1.2 非管理员主动申请变更为超级管理员
路径：我的企业 -> 申请管理员

该方式通常需要审批通过后方可成为企业管理员。

### 2. 补充限制
- 企业只有一位管理员且该管理员无法自行提交申请时，通常需要客户经理协助
- 双管理员模式下，业务管理员暂不支持直接主动申请成为超级管理员
- 双管理员模式下如存在审批障碍，可能需要先关闭双管理员模式，再由新管理员发起申请

### 3. 管理员变更的前置建议
原超级管理员离职前，建议先完成管理员变更，再处理离职或停用。

## 个人账号安全

个人账号相关安全能力包括修改手机号、找回账号、修改密码、忘记密码和注销账号。

### 1. 修改手机号
入口包括：
- Web：头像 -> 个人账号 -> 修改手机号
- App：我的 -> 账号安全 -> 修改手机号

修改手机号前需要进行身份验证，通常包含：
- 人脸验证
- 短信验证码验证

新手机号若已在平台中注册，通常不能直接替换复用。

### 2. 账号找回
适用于：
- 原手机号无法接收验证码
- 忘记登录密码

常见入口包括：
- 短信验证码登录 -> 找回账号
- 密码登录 -> 忘记密码 -> 找回账号
- App 登录页 -> 找回账号

找回过程通常包括：
- 原账号信息校验
- 实名信息校验
- 人脸识别
- 新手机号验证

### 3. 修改密码与忘记密码
入口包括：
- Web：头像 -> 个人账号 -> 修改密码 / 忘记密码
- App：我的 -> 账号安全 -> 修改 / 重置
- 登录页 -> 忘记密码

重置密码时通常需要：
- 短信验证
- 人脸验证

密码要求通常包括：
- 长度 8-20 个字符
- 至少包含三种字符类型（大写字母、小写字母、数字、特殊字符）

### 4. 注销个人账号
注销前通常需要：
- 若本人是管理员，先完成管理员转让
- 退出所有企业 / 组织

注销过程通常需要：
- 人脸识别
- 短信验证码验证

注销成功后，个人账号的相关数据通常无法恢复。
