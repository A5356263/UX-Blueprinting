## 常用入口与配置操作

- 创建审批：管理后台 → 审批管理 → 通用审批 → 创建审批。
- 数据管理：管理后台 → 审批管理 → 数据管理。
- 审批角色：管理后台 → 审批管理 → 审批角色。
- 动态流程：OA 审批 → 审批管理 → 通用审批 → 流程设计 → 高级设置。
- 自动化任务：OA 审批 → 审批管理 → 通用审批 → 流程设计 → 添加自动化任务节点。
- 流程模拟：流程设计页面右上角的“流程模拟”。
- 智能分析：OA 审批 → 智能分析，仅管理员可用。

### 配置审批角色

1. 在审批角色页面新增角色。
2. 添加用户，并在左侧列表选中审批角色。
3. 通过用户后的“审批权限设置”配置审批范围。

## 员工端操作

### 发起审批

- PC 端：全部应用 → OA 审批；或工作台 → 我的常用、我的申请、草稿箱。
- 移动端：工作台 → OA 审批、草稿箱。

### 处理审批

- PC 端：工作台 → 最近待办快速审批；或 OA 审批 → 审批中心 → 待处理。
- 移动端：工作台 → 待办；或 OA 审批 → 审批中心 → 待处理。

### 委托审批

先授权 OA 审批的委托审批功能权限，再在 OA 审批高级设置中新建委托。管理员可进入管理员委托操作界面，为审批人设置委托。

### 管理员审批

OA 审批 → 高级功能 → 管理员审批。该入口用于处理部分异常审批任务，且只展示操作人有权限的数据。

## 审批人变更与意见配置

### 如何变更审批人？

- 长期变更：审批管理员或审批角色在数据管理中变更；组织负责人或审批主管在组织架构中变更；汇报上级、成员组、岗位或职位在对应成员或花名册信息中变更。
- 审批中临时变更：原审批人在 OA 审批 → 审批中心 → 批量操作中转派，或管理员在数据管理 → 待处理审批交接中转派。

### 如何设置审批意见必填？

可在表单高级设置中开启“审批/处理意见必填”，或在流程设计中选择审批人并在高级设置中开启“审批意见必填”。开启后通过审批需要填写审批意见。

## 批量发起

入口：OA 审批 → 高级功能 → 批量发起。

1. 新建批次，设置批次号并选择需要批量发起的审批。
2. 下载审批模板并按模板填写内容。
3. 上传前检查单元格格式为文本，并排除空格等非法字符。
4. 完成发起。
