# 报错与状态文案模板

## 4. 文案模板库

| 类型 | 模板 | 适用说明 |
| --- | --- | --- |
| 权限告知 | 暂无【{功能名称}】的{操作/查看}权限，请联系{管理员角色}开通。 | 用于功能权限不足，优先在操作入口说明，弹窗只做兜底。 |
| 数据权限占位 | 暂无此{数据范围}的查看权限。如需获取权限，请联系{管理员角色}。 | 用于列表、详情、数据区域空状态。 |
| 登录失效 | 登录已失效，请重新登录。 | 不暴露 token、签名、session。 |
| 页面加载失败 | 数据加载失败，请稍后重试。 | 可配“重新加载”按钮。 |
| 操作失败 | 网络异常，操作未成功，请稍后重试。 | 用于轻量可恢复失败。 |
| 服务繁忙 | 服务繁忙，请稍后重试。 | 保持短句，不堆客服话术。 |
| 必填为空 | 请填写{字段名}。 | 字段附近红字。 |
| 格式错误 | 请输入正确的{格式说明}，如 {示例}。 | 字段附近红字。 |
| 长度超限 | 最多可输入{max}个字符，当前已输入{current}个。 | 字段附近红字或实时计数。 |
| 重复冲突 | 「{名称/编码}」已被使用，请更换。 | 字段附近红字。 |
| 文件格式 | 不支持此文件类型，请上传 {支持的格式} 格式文件。 | 上传区域提示。 |
| 文件过大 | 文件大小超过 {max}MB 限制，请压缩后上传。 | 上传区域提示。 |
| 文件解析失败 | 文件内容解析失败，请检查文件是否完整或使用标准模板。 | 上传区域或解析结果区提示。 |
| 单字段金额 | 金额不能为0。 | 字段附近红字。 |
| 跨字段金额 | 不含税金额（{A}）+ 税额（{B}）与含税金额（{C}）不一致，差额为 {D}。 | 弹窗或集中校验区。 |
| 数据不存在 | 该{业务对象}已被删除或不存在。 | 配返回列表/上一页/首页。 |
| 已处理 | 该任务已被处理，页面已更新。 | Toast 或轻量提示。 |
| 状态不允许 | {业务对象}当前状态为{当前状态}，需在{允许状态}下才能{目标操作}。 | 阻断时说明当前状态和允许条件。 |
| 流程中 | 该记录正在{流程名}中，暂不可操作。 | 操作入口说明或兜底弹窗。 |
| 已结账/锁定 | 当前{期间}已{状态}，{数据}不可编辑。如需修改，请联系{角色}。 | Banner 或状态区提示。 |
| 配置缺失 | 当前缺少{配置项}，请先完成设置后再继续。 | 页面占位或状态提示。 |
| 外部系统失败 | {外部系统}处理失败：{用户可理解的具体原因}。请核对后重试。 | 需要展示外部原因时使用。 |

## 5. 当前报错文案主要问题

| 问题类型 | 典型表现 | 建议改进 |
| --- | --- | --- |
| 技术裸错误透传 | `Network Error`、`timeout of 120000ms exceeded`、`Request failed with status code 500/502/504` | 转成“网络异常”“处理超时”“服务繁忙”等用户语言。 |
| 技术术语暴露 | “接口异常”“远程服务异常”“token不能为空”“签名已过期” | 替换成具体业务功能、登录状态或用户可理解的信息。 |
| 模糊引导 | “请检查”“请刷新后重试” | 明确下一步，例如返回列表、前往设置、联系角色、稍后重试。 |
| 责备语气 | “请勿重复处理”“不能进行操作” | 改为中性状态说明，例如“该任务已被处理”。 |
| 字段名不可读 | `CERTYP`、`PAMPRJCOD`、成员 id | 替换为用户可见字段名。 |
| 信息缺失 | 金额不一致但不列数值；状态不可操作但不说当前状态；编号重复但不说哪个编号 | 补充定位问题所需的关键上下文。 |
| 形式单一 | 字段错误、终态提醒、持续状态都使用弹窗 | 字段错误用 inline，终态提醒用 toast，持续状态用 banner。 |
| 时机滞后 | 用户提交后才知道字段为空、权限不足或状态不可用 | 在任务路径中更早说明限制或错误。 |
| 文案过长 | toast 或弹窗承载大量客服话术和背景说明 | 轻量提示只写重点，复杂说明分层展示。 |
