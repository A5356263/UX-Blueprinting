## 2. Table 表格


### 2. Table 表格

#### 2.1 何时使用

Table 用于多行、多列、结构化数据展示，适合承载数据密集、需要横向比较、需要批量选择或行级操作的业务信息。

适合使用 Table 的场景包括：

- 展示列表型数据，如订单列表、单据列表、客户列表、发票列表、人员列表。
- 对数据进行行级操作，如查看详情、编辑、删除、审批、下载。
- 需要表头筛选、排序、分页、勾选、批量操作。
- 需要展示多种字段类型，如文本、数值、日期、状态、标签、图片、开关、操作按钮。
- 需要展示空状态、加载状态、固定列、横向滚动或分页。

不适合使用 Table 的场景包括：

- 只展示少量字段详情，应优先使用 Descriptions。
- 展示层级目录或树状关系，应优先使用 Tree。
- 只提示未读数量或状态点，应优先使用 Badge。
- 内容主要是图文卡片或强视觉浏览场景，不应强行使用表格。

#### 2.2 组件结构

Table 的基础结构包括：

1. 表头：展示字段名称，可承载排序、筛选等操作。
2. 表体：展示数据行和单元格内容。
3. 选择列：用于单选或多选行数据。
4. 操作列：用于承载详情、编辑、删除、审批等行级操作。
5. 横向滚动区域：用于列较多时保持内容可访问。
6. 分页区域：用于数据量较大时分页展示。
7. 底部统计或批量操作区：用于展示已选项、总数、金额等汇总信息。

#### 2.3 尺寸与布局规则

表格应保持清晰的信息层级和稳定的阅读路径。

##### 行高与单元格间距

| 属性 | 规格 | 说明 |
|------|------|------|
| 表头行高 | 固定 40px | 与数据行保持一致 |
| 数据行行高 | 固定 40px | 与表头保持一致 |
| 单元格左右 padding | 16px | 表头和数据行统一 |
| 单元格上下 padding | 8px | 表头和数据行统一 |
| 换行规则 | 不支持换行展示 | 超长内容省略，hover Tooltip 展示全文 |

##### 列宽规则

- 选择列、操作列、状态列等功能列建议固定宽度。
- 重要字段建议保持可见，避免被横向滚动隐藏。
- 多文本、标签、标签/操作等复杂列建议自定义固定宽度，保证重要内容可见。
- 当列数较多时，可使用横向滚动。
- 当操作列内容较多时，应控制操作项数量，必要时使用更多操作入口。

#### 2.4 表头规则

表头用于说明列字段含义，并可承载排序、筛选等功能。

表头类型包括：

- 普通表头：仅展示字段名称。
- 分组表头：用于复杂表头结构，如一级分类下包含多个子字段。
- 带筛选表头：字段右侧展示筛选 icon。
- 带排序表头：字段右侧展示排序控件。
- 带提示表头：字段旁展示说明 icon。

表头设计原则：

- 表头文案应短而明确。
- 表头与列内容语义必须一致。
- 表头筛选 icon 应靠近字段名称，避免用户误解筛选对象。
- 表头有筛选或排序时，应给出明确的激活状态。

#### 2.5 单元格类型

Table 支持多种单元格内容类型：

| 单元格类型 | 使用场景 | 设计要求 |
|---|---|---|
| 常规文本 | 普通字段展示 | 保持对齐一致，文本过长时省略或换行 |
| 数值 | 金额、数量、统计值 | 建议右对齐或统一对齐，格式保持一致 |
| 日期时间 | 日期、时间、创建时间、更新时间 | 格式统一，如 YYYY-MM-DD 或 YYYY-MM-DD HH:mm |
| 状态 | 审批状态、业务状态、处理状态 | 可使用状态点、标签或文字 |
| 标签 | 多状态、多分类、属性标记 | 标签不宜过多，必要时折叠展示 |
| 图片 | 商品图、头像、凭证图、附件缩略图 | 支持固定尺寸，如 24px、36px、48px |
| 开关 | 启用/停用、打开/关闭 | 适合直接变更状态的字段 |
| 链接 | 可跳转字段，如单据编号 | 使用明显链接样式 |
| 操作 | 查看、编辑、删除等 | 操作项需清晰，危险操作需谨慎处理 |

#### 2.6 图片列规则

图片列用于展示头像、缩略图、商品图、凭证图等图片信息。

推荐尺寸：

- 小尺寸图片：24px。
- 中尺寸图片：36px。
- 大尺寸图片：48px。

图片展示规则：

- 图片尺寸应统一。
- 图片无法加载时应显示占位图。
- 支持点击预览时，鼠标悬停应有可点击反馈。
- 多图场景可显示多张缩略图，也可折叠为数量提示。
- 点击图片可进入图片预览弹层。
- 图片预览弹层可支持切换上一张、下一张、关闭、下载等操作。

#### 2.7 操作列规则

操作列用于承载行级操作。

推荐规则：

- 常用操作可直接展示，如“详情”“编辑”。
- 高风险操作如“删除”需谨慎展示，必要时加入确认。
- 操作项过多时，应收敛为“更多”。
- 操作列建议固定在右侧，保证用户在横向滚动时仍可访问。
- 不建议在一个单元格内放置过多视觉权重相同的操作。

#### 2.8 空状态规则

当表格无数据时，应展示空状态。

空状态应包含：

- 空状态图标或插画。
- 空状态文案，如“暂无内容”“暂无数据”。
- 可选操作按钮，如“新建”“导入”“刷新”。

设计要求：

- 空状态应居中展示。
- 空状态不应造成页面跳动。
- 若表格有表头，空状态应在表体区域显示。
- 若筛选后无结果，应优先提示“暂无相关内容”或“无相关选项”。

#### 2.9 分页规则

当数据量较大时，应使用分页。

分页区域通常包含：

- 总条数。
- 当前页码。
- 页码切换。
- 每页条数选择。
- 上一页、下一页。

设计要求：

- 常规设计中，分页信息应靠近表格底部。
- 页码不宜过多展示，可使用省略号。
- 每页条数入口应清晰。
- 批量操作与分页同时存在时，需要保持区域分工明确。

#### 2.10 表格列宽规则

表格列宽应根据内容重要性和内容长度合理配置。

推荐规则：

- 文本较长、标签较多、操作项较多的列应配置固定宽度。
- 关键字段应优先保证完整展示。
- 次要字段可允许省略。
- 多列场景中，应避免平均分配导致重要字段不可读。
- 表头与内容宽度需要匹配，避免内容明显错位。

#### 2.11 标签显示规则

表格中的标签用于展示状态、分类或属性。

规则：

- 单个状态可使用单标签。
- 多个标签可并列展示。
- 标签过多时可折叠为“+N”。
- 鼠标悬停可展示全部标签。
- 标签颜色应有语义，不应过度使用高饱和颜色。
- 多状态标签应保证颜色与业务含义一致。

#### 2.12 表格适配场景

Table 常见业务场景：

- 账单列表。
- 对账列表。
- 入库单列表。
- 审批单列表。
- 人员列表。
- 合同列表。
- 发票列表。
- 预算列表。
- 结算列表。
- 付款明细。
- 明细清单。

## 3. 表格-表头筛选


### 3. 表格-表头筛选

#### 3.1 何时使用

表格-表头筛选用于在表格中对某一列数据进行筛选。它通常依附于表头筛选 icon，用户点击后打开筛选浮层。

适合使用的场景：

- 用户需要快速过滤某一列数据。
- 表格字段数量较多，但筛选条件与具体列强相关。
- 不希望在页面顶部放置大量筛选表单。
- 需要支持文本、数值、日期、时间、单选、多选、树选择等多类型筛选。
- 表格字段存在状态、分类、部门、人员、时间区间等筛选需求。

不适合使用的场景：

- 筛选条件是全局复杂组合，应使用页面级高级筛选。
- 筛选项跨多个字段并且强依赖组合逻辑。
- 筛选条件需要复杂表达式或大量输入。
- 移动端空间不足时，不宜直接照搬桌面表头筛选浮层。

#### 3.2 组件结构

表头筛选浮层通常包含：

1. 筛选内容区域：承载输入框、选项列表、日期选择、树选择等。
2. 操作区域：承载重置、确定、取消、主按钮等。
3. 确定按钮：点击后应用筛选。
4. 重置按钮：恢复默认筛选状态。
5. 自定义操作区域：可根据业务配置额外操作。
6. 空白区域关闭规则：点击其他空白区域可关闭筛选浮层。

#### 3.3 尺寸布局

筛选浮层尺寸规则：

- 默认宽度：240px。
- 可配置宽度：240px、320px。
- 高度根据筛选内容自适应。
- 最大高度：400px。
- 当内容超出最大高度时，内部滚动。
- 操作区应固定在底部，避免滚动后不可见。

#### 3.4 筛选类型

##### 3.4.1 文本筛选

用于普通文本字段。

规则：

- 提供输入框。
- 用户输入关键词后点击确定进行筛选。
- 支持重置。
- 输入框占据主要区域。
- 文本过长时不应撑破浮层。

##### 3.4.2 数值筛选

用于金额、数量、比例等数值字段。

规则：

- 支持最小值和最大值输入。
- 可使用区间筛选。
- 数值输入需限制非法字符。
- 区间字段之间应有明确连接符。
- 支持重置和确定。

##### 3.4.3 日期筛选

日期筛选适用于日期区间，不支持秒级时间。

规则：

- 支持开始日期和结束日期。
- 支持快捷标签，如近三天、近一周、近一个月、近一年。
- 可以输入开始和结束中的其中一项。
- 日期格式应统一。
- 日期区间必须合法。

##### 3.4.4 日期时间筛选

日期时间筛选适用于包含时分秒的日期字段。

规则：

- 支持开始日期时间和结束日期时间。
- 支持快捷标签。
- 可用于精确时间区间筛选。
- 日期时间格式应统一。
- 适合订单创建时间、提交时间、审批时间等字段。

##### 3.4.5 时间筛选

用于单独的时间字段。

规则：

- 支持开始时间和结束时间。
- 适用于非日期维度的时间段筛选。
- 与日期筛选分开使用。

##### 3.4.6 单选筛选

用于互斥选项。

规则：

- 选项以列表形式展示。
- 用户只能选择一个选项。
- 可支持搜索。
- 选中项需要有明显状态。
- 若无相关选项，应显示空状态。

##### 3.4.7 多选筛选

用于多个可并行选择的选项。

规则：

- 选项前展示复选框。
- 支持多项选择。
- 底部可展示全选。
- 可支持搜索。
- 多选后点击确定生效。
- 可配置取消和主按钮。

##### 3.4.8 树选择筛选

用于层级选项，如部门、分类、组织架构。

规则：

- 支持展开和收起。
- 支持父子层级展示。
- 可支持搜索。
- 可支持单选或多选。
- 底部可展示全选、取消、主按钮。
- 可支持自定义扩展设置项，如展示已删除、展示已停用等。

#### 3.5 选项文本规则

当选项文本过长时，支持两种规则：

1. 默认规则：限制一行显示，超出部分省略，鼠标悬停展示全文。
2. 换行规则：文本自动换行展示。

推荐：

- 常规列表使用一行省略。
- 业务上必须完整阅读的选项可使用换行。
- 选项很多时优先使用省略，避免浮层过高。

#### 3.6 空状态规则

无相关选项时，应展示空状态。

空状态可出现在：

- 无搜索结果。
- 无可用选项。
- 数据加载为空。
- 筛选项被扩展设置隐藏后无结果。

空状态文案建议：

- “无相关选项”。
- “暂无数据”。
- “暂无内容”。

#### 3.7 特殊字段筛选

特殊类型字段如选择人员、选择部门等，在表头筛选时，可点击筛选 icon 后直接打开对应选择器弹窗。

适用场景：

- 选择人员。
- 选择部门。
- 选择组织。
- 选择项目。
- 选择复杂业务对象。

规则：

- 不强行在小浮层内承载复杂选择。
- 优先打开专门选择器弹窗。
- 选择结果返回后同步到表格筛选条件。

## 4. 父子 & 嵌套表格 (Parent-child & Nested Table)


### 4. 父子 & 嵌套表格 (Parent-child & Nested Table)

#### 设计知识

- **设计目标**：展示存在**层级关系**的多级数据，优化纵向空间的利用率。
- **设计策略与决策逻辑（核心）**：根据"子级表头与父级是否一致"进行决策。

**类型一：父子表格（Tree Table）**
- **使用场景**：父子层级的信息维度/表头一致。
- **对齐方式**：左对齐。
- **视觉规范**：子级缩进 16px，展开图标（箭头）与一级展开箭头相同且缩进 16px。
- **交互**：点击展开/折叠子级，建议层级不过 3 层，避免多级嵌套。

**类型二：嵌套表格（Nested Table）**
- **使用场景**：子级的数据结构与表头和父级不一致（如"工单详情"下是"操作日志"）。
- **对齐方式**：左对齐，子表格左侧边缘统一缩进 48px；上方、下方缩进 20px。
- **交互**：点击父级展开/折叠子级表格。
- **规则警告**：不推荐通过嵌套表格来展示过于复杂的表格层级。

#### 资产清单

**[ID: pattern.table.hierarchy.nested]** 层级嵌套表格
- **包含信息**：父行数据、展开/收起图标、嵌入式子表（含独立表头）、内缩进样式。
- **描述**：点击父行后在下方"炸开"展示关联明细。

## 6. 可编辑表格页 (Editable Table)


### 6. 可编辑表格页 (Editable Table)

#### 设计知识

- **设计目标**：满足高频、批量、所见即所得的编辑需求，不跳转页面直接在表格中修改。
- **设计策略**：明确区分"编辑模式"和"展示模式"。

**模式一：默认展示-编辑模式**
- 页面初始加载为展示态。点击行或操作按钮后，该行切换至"编辑态"（输入框、下拉框等组件的组合）。

**模式二：悬停激活编辑**
- 默认状态为展示态，鼠标**悬停（Hover）**在单元格上时，显示编辑图标或输入框，点击直接录入。

- **交互组件支持**：单元格内支持嵌入输入框、日期选择器、下拉框、数字输入框等表单组件。
- **报错机制**：
  - **单个字段报错**：单元格内输入框变红，并在单元格下方或右上角展示错误提示气泡（Tooltip）。
  - **表单级报错**：在表格底部、页面侧边或顶部展示全局性的错误提示。
  - **必填校验**：当用户提交或切换焦点时，触发非空校验，通过提示气泡报错。
- **禁用状态**：当某行或某列数据不可编辑时，置灰该单元格（禁用态）。

#### 资产清单

**[ID: pattern.table.editable.inline]** 行内编辑表格
- **包含信息**：单元格输入框、下拉选择器、保存/取消按钮、错误校验红框、错误提示 Tooltip。
- **描述**：表格单元格即表单，支持 hover 或点击直接修改。
