# 组件

## 这是什么

这是组件设计规范的二级路由入口，用来解释可复用交互单元的结构、尺寸、状态、行为和选型。

本 README 承载组件分类契约与任务路由；具体组件规则保留在对应主题文件中。

## 分类契约

### 分类定义

组件回答的是：一个可跨页面复用的设计单元，在什么条件下使用，由哪些部分组成，具有什么尺寸、状态和交互规则。

### 解决的问题

- 某个组件是否适合当前信息或操作
- 组件应采用什么结构、尺寸和状态
- 多个相近组件之间如何选择
- 页面或场景需要依赖哪个具体组件承载
- 组件在异常、禁用、加载和空状态下如何表现

### 为什么独立成类

- 组件可以跨页面和场景复用，不应散落在单个页面说明中
- 组件具有稳定结构、状态和交互契约
- 页面和场景需要引用组件事实，但不应复制组件正文

### 与相邻分类的关系

- 样式提供组件共同依赖的视觉尺度、排版、颜色和布局基础
- 典型页面定义页面整体组织，组件提供其中可复用的局部单元
- 场景模式定义任务路径、状态与反馈，组件提供任务步骤的具体承载
- 样式、页面或场景引用组件时，最终组件结构和状态必须回到本分类确认

### 稳定结论

- 组件文件按稳定对象或稳定组件族组织，不按旧材料文件边界组织
- 单个组件事实以本分类主题文件为唯一正文
- 页面级布局和任务流程不得写入组件 README

### 显式缺口

- [GAP] 部分旧组件材料缺少统一的产品版本和适用范围标记

## 任务触发索引

- Button、按钮优先级、尺寸、状态或按钮布局：读 `按钮.md`
- Steps、顶部导航、返回、Tabs、Anchor、Menu、分页或多页签：读 `导航.md`
- Form、Input、Select、Checkbox、上传或其他录入控件：读 `数据录入.md`
- Descriptions、Tree、Badge、Empty、图片、标签或其他展示控件：读 `数据展示.md`
- Table、表头筛选、嵌套表格或可编辑表格：读 `表格.md`
- 表头字段显示、列配置、分组或设置弹窗：读 `表头设置.md`
- Drawer、Modal、Result、Message、Notification、Loading 或反馈选型：读 `反馈.md`
- 详情页或信息页顶部信息区域：读 `页面头部.md`

## 条件依赖与回主类

- 命中视觉取值时补读样式；命中页面整体结构时补读典型页面；命中任务步骤、状态或恢复路径时补读场景模式
- 相邻分类只补充组件使用上下文；最终结构、尺寸、状态和交互必须回到本分类确认

## 维护原则

- README 只承载分类契约和路由，不展开组件规则正文
- 同一组件不得在页面或场景目录复制维护
- 新组件只有具备独立检索和维护价值时才单独成文；否则进入稳定组件族
- 来源中的旧检索命令、回答模板和 AI 提示不得成为组件事实
