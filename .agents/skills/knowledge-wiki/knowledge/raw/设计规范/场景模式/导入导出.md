## 导入导出 · 场景指南（知识整理）


> 适用场景：数据管理类功能中「导入 / 导出」交互的设计参考

### 一、设计目标

1. 导入功能的使用能够提升「强依赖本地数据的业务场景」的操作效率，因此导入功能设计时要尽可能减少出错的概率。
2. 如果导入流程较长较复杂，需要减少流程的断点，避免用户重复导入。

### 二、设计策略

1. 为减少本地数据导入出错的几率，可提供标准导入模板。
2. 在导入前明确导入规则，包括业务规则、文件格式、大小等；由于涉及本地操作，模板中也要有相应规则的说明。
3. 导入数据触发规则校验报错时，需要明确提示用户如何修改。
4. 导入的数据与原有数据有冲突，或校验后有错误数据：前置提示，或明确提示错误原因并采取相应操作。如数据出错数量较大，支持导出后在 Excel 中修改更方便。
5. 导入的数据与原有数据有冲突，或校验后有错误数据：如数据错误数量不多，支持用户在线修改错误数据，减少「修改 → 重新导入」的重复操作。
6. 导入流程较长时，需要增加自动化操作，降低流程的复杂度。

### 三、何时使用

- 适用于数据管理中对数据进行的**导入导出**，注意区别于文件的**上传和下载**。
- 满足以下任一场景时使用导入模式：
  - 导入前有复杂配置
  - 导入中有复杂步骤
  - 导入后有复杂校验逻辑

### 四、两种导入模式

| 模式 | 说明 |
| --- | --- |
| **页面导入模式** | 导入流程以完整页面承载，适合流程长、步骤多、需要大量操作的场景 |
| **弹窗导入模式** | 导入流程以弹窗（Modal）承载，适合轻量、步骤少的场景 |

### 五、页面框架结构

#### 1. 页面导入模式（整页承载）

```
┌──────────────────────────────────────────────────────┐
│ 页签名称 | 页签名称 | 页签名称 …                         │
│ ＜返回 | 页面名称                                       │
├──────────────────────────────────────────────────────┤
│ 按需添加整体说明（区块整体说明文案）                        │
├──────────────────────────────────────────────────────┤
│ ① 导入前                                               │
│   1. 导入「业务名称」数据                                 │
│      · 请选择调度表单（下拉） + 说明文案（最大宽552px）       │
│   2. 请使用系统提供的模板 [下载模板] + 说明文案             │
│   [导入]（主按钮）  文件需小于50M，支持Excel（2003以上版本）、txt格式 │
│   新手小贴士（指引文案，区块最大宽580px）                    │
├──────────────────────────────────────────────────────┤
│ ② 导入中（步骤条：1 上传数据 → 2 匹配数据 → 3 核对数据 → 4 导入结果）│
│   数据范围：Excel表单 sheet1 / 表头起始行 1 / 数据起始行 2 [修改范围] │
│   匹配表头：系统表头字段 | 导入表头字段（映射表）  ☑ 隐藏已匹配表头 │
│   [上一步] [下一步]                                     │
├──────────────────────────────────────────────────────┤
│ ③ 导入后（结果页）                                      │
│   结果标题：全部成功 / X条成功，X条失败 / 全部失败           │
│   描述说明文字（保持一行内）                               │
│   Tab：成功 | 失败                                       │
│   结果表格：内容 | 失败原因（分页：共100条）                │
│   [返回列表] [导出错误数据]                               │
└──────────────────────────────────────────────────────┘
```

**在线修改页（错误数据处理）框架**

```
＜返回 | 在线修改
共X笔错误数据，错误数据可在线编辑，修改后点击【重新校验】，校验成功后在校验通过数据显示。
Tab：错误数据 | 校验通过数据
可编辑错误表格：错误信息(错误原因) | 姓名 | 员工号 | 证件类型 | 证件号码 | 部门 | 岗位
[上一步] [重新校验]
```

#### 2. 弹窗导入模式（弹窗承载）

```
┌─ 弹窗 ─────────────────────────────────────┐
│ 导入「业务名称」数据                    ×    │
├────────────────────────────────────────────┤
│ 1. 请使用系统提供的模板 [下载模板]             │
│    说明文案（最大宽 440px）                   │
│ 2. 上传文件                                  │
│   ┌──────────────────────────────────┐     │
│   │ 点击或拖拽到此区域上传              │     │
│   │ 这里是描述文案                     │     │
│   └──────────────────────────────────┘     │
│   已上传文件：yyy.png（可删除）               │
│   文件需小于50M，支持Excel（2003以上版本）、txt格式 │
│   新手小贴士                                │
├────────────────────────────────────────────┤
│                [取消]  [确认/导入]           │
└────────────────────────────────────────────┘
```

> 弹窗模式的导入中 / 导入后与页面模式结构一致，仅承载容器由页面变为弹窗。

#### 3. 导入结果反馈框架

- **弹窗结果（带明细表格）**：标题（导入结果 / 可自定义文案）→ 描述说明文字（保持一行内）→ Tab（成功/失败）→ 结果表格（表头/正文）→ [次按钮][主按钮]
- **轻量结果**：标题 → 描述说明文字 → 全部成功（3 秒后自动关闭弹窗）/ X条成功X条失败（前往、关闭）/ 全部失败（关闭）

### 六、模式详情

#### 1. 页面导入模式

> 可「按需添加整体说明」，在页面顶部放整体说明文案。

##### 导入前（导入前的说明）

- 页面结构：页签（页签名称 ×N）、`＜返回 | 页面名称`
- **1. 导入「业务名称」数据**
  - 1. 请选择调度表单，系统将根据表单匹配模板（下拉选择）
  - 说明文案：言简意赅的说明文案，文案不可过长，说明文案的最大宽 **552px**，以确保文字的可阅读性
- **2. 请使用系统提供的模板** `[下载模板]`
  - 说明文案同上（最大宽 552px）
- 主按钮：`导入`
- 约束提示：文件需小于 50M，支持 Excel（2003 以上版本）、txt 格式
- **新手小贴士**（提示区块）：
  1. 言简意赅的指引文案，文案不可过长，区块容器最大宽 **580px**，确保文字的可阅读性
  2. 言简意赅的指引文案

##### 导入中（导入中的说明）

- **步骤条**：`1 上传数据 → 2 匹配数据 → 3 核对数据 → 4 导入结果`
- **数据范围**：当前数据范围
  - Excel 表单：sheet1
  - 表头起始行：1
  - 数据起始行：2
  - `[修改范围]`
- **匹配表头**：
  - 说明：请将导入文件中的「表头字段」与「系统表头字段」相匹配。若无对应字段，请尝试切换数据范围
  - 字段映射表：

    | 系统表头字段 | 导入表头字段 |
    | --- | --- |
    | *证件号 | 请选择 |
    | 系统表头字段名称 | 导入的表头字段 |
    | 系统表头字段名称 | 请选择 |

  - 勾选项：`☑ 隐藏已匹配表头`
- 底部按钮：`上一步` `下一步`

##### 导入后（导入后的说明）

结果分为三种状态：

1. **全部成功**
   - 描述说明文字（保持一行内）
   - 操作：`返回列表`、`前往`
2. **X 条成功，X 条失败**
   - 描述说明文字（保持一行内）
   - 分区 Tab：`成功` / `失败`
   - 结果表格：`内容` / `失败原因`
   - 分页：共 100 条 `1 2 3 4 5 >`
   - 操作：`返回列表`、`导出错误数据`
3. **全部失败**
   - 描述说明文字（保持一行内）
   - 结果表格：`内容`
   - 操作：`返回列表`、`导出错误数据`

**在线修改（错误数据处理）**

- 页面标题：`＜返回 | 在线修改`
- 顶部说明：共 X 笔错误数据，错误数据可在线编辑，修改后点击【重新校验】，校验成功后在校验通过数据显示。
- 分区 Tab：`错误数据` / `校验通过数据`
- 错误列表表格（可编辑）：
  - 错误信息（错误原因）
  - 姓名
  - 员工号（如 WS030864）
  - 证件类型（如 身份证）
  - 证件号码（如 410423199410260923）
  - 部门（如 研发部）
  - 岗位（如 IT 工程师 / IT 高级工程师）
- 操作：`上一步`、`重新校验`

#### 2. 弹窗导入模式

> 可「按需添加整体说明」。

##### 导入前（导入前的说明）

- 弹窗标题：`导入「业务名称」数据`（示例：`1. 导入员工证件照`、`导入数据`）
- **1. 请使用系统提供的模板** `[下载模板]`
  - 说明文案：言简意赅的说明文案，文案不可过长，说明文案的最大宽 **440px**，以确保文字的可阅读性
- **2. 上传文件**
  - 上传区：`点击或拖拽到此区域上传`
  - 描述文案：这里是描述文案
  - 已上传文件列表（可删除）：如 `yyy.png`
  - 约束提示：文件需小于 50M，支持 Excel（2003 以上版本）、txt 格式
- **新手小贴士**：指引文案（区块容器最大宽 580px，确保文字可阅读性）
- 底部按钮：`取消`、`确认 / 导入`

##### 导入中 / 导入后

- 与「页面导入模式」的步骤条、字段匹配、结果状态、在线修改逻辑一致，仅承载容器由页面变为弹窗。

### 七、导入结果反馈

#### 弹窗结果（带明细表格）

| 状态 | 弹窗内容 | 操作 |
| --- | --- | --- |
| 全部成功 | 标题（可自定义文案）+ 描述说明文字（保持一行内）+ 结果表格 | `次按钮` |
| X 条成功，X 条失败 | 标题 + 描述说明文字（保持一行内）+ `成功/失败` Tab + 结果表格（表头/正文） | `次按钮`、`主按钮` |
| 全部失败 | 标题 + 描述说明文字（保持一行内）+ 结果表格 | `次按钮`、`主按钮` |

#### 轻量结果反馈

| 状态 | 反馈内容 | 操作 |
| --- | --- | --- |
| 全部成功 | 标题 + 描述说明文字 | 3 秒后自动关闭弹窗 |
| X 条成功，X 条失败 | 标题 + 描述说明文字 | `前往`、`关闭` |
| 全部失败 | 标题 + 描述说明文字 | `关闭` |

### 八、关键交互要点（速记）

1. **先给模板再给上传**：提供标准导入模板，降低出错率；模板内同步说明业务规则、文件格式、大小等。
2. **前置规则说明**：导入前明确业务规则与文件约束（如 50M、Excel 2003+、txt）。
3. **文案宽度规范**：说明文案最大宽 552px（弹窗内 440px），指引/提示区块最大宽 580px，保持一行内。
4. **错误可修**：错误数量少 → 在线修改 + 重新校验；错误数量多 → 导出错误数据到 Excel 修改。
5. **减少断点**：长流程用步骤条（上传数据 → 匹配数据 → 核对数据 → 导入结果），避免用户重复导入。
6. **结果分级反馈**：成功/部分失败/全部失败三种状态清晰区分，失败时提供「导出错误数据」与「返回列表」。
