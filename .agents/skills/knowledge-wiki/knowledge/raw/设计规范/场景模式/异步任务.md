## 异步处理 · 场景指南（知识整理）


> 适用场景：耗时操作（批量导入/导出、批量审批等）的「异步处理」交互设计参考

### 一、设计目标

规范异步处理的使用场景。

### 二、设计策略

1. **状态可感知**：清晰展示异步操作状态；
2. **轻量非模态**：使用非模态浮窗，支持展开 / 收起，避免遮挡页面；
3. **减少等待焦虑**：通过进度反馈缓解用户焦虑；
4. **一致性体验**：统一交互模式，降低用户学习成本。

### 三、页面框架结构

#### 1. 整体页面布局

```
┌──────────────────────────────────────────────────┐
│ 顶部应用栏（企业名称… / 全部应用 | Q 搜索）          │
│                                  ┌──────────┐   │
│                                  │ 异步处理浮窗 │  │ ← 默认收起，右上角
│                                  └──────────┘   │   （距页面右侧16px）
├──────────────────────────────────────────────────┤
│ 内容区（业务表格 / 页面内容）                        │
│                                                    │
├──────────────────────────────────────────────────┤
│ 分页器（浮窗默认收起位置：分页器右侧，距分页8px）        │
└──────────────────────────────────────────────────┘
```

- 浮窗默认**收起**，默认位置为**右上角**：距页面右侧 **16px**、距分页 **8px**；
- 浮窗在客户端、Web 端**可拖动**。

#### 2. 异步处理浮窗框架

**收起状态**

```
┌─ 异步处理浮窗（收起） ─────────────┐
│ 任务进度（0/4）               [展开] │
│ · 全部任务成功 ×12                 │
│ · 部分任务成功                     │
│ × 全部任务失败（单条可删除）        │
└──────────────────────────────────┘
```

**展开状态**

```
┌─ 异步处理浮窗（展开） ─────────────────────────────┐
│ 任务进度（4/9） Q搜索任务名称 全部▾ 清空记录 收起 关闭 刷新 │
│ 说明：任务需等待一段时间…记录保留7天后自动清除。清空记录    │
│ ┌────────────────────────────────────────────┐  │
│ │ 任务名称 | 任务内容 | 处理状态 | 完成时间 | 操作 │  │
│ │ 确认入职「李四」 | … | 待开始 | 2026-12-11 …  │  │
│ └────────────────────────────────────────────┘  │
│ 分页：共55条  1 2 … >  50/页                     │
└────────────────────────────────────────────────┘
```

- 头部功能区：任务进度、搜索、业务筛选（可配置）、清空记录、收起、关闭、刷新；
- 中部说明文案：任务需等待一段时间，您可以先办理其他业务，稍后回来查看。记录保留 7 天后将自动清除；
- 列表字段：`任务名称 | 任务内容 | 处理状态 | 完成时间 | 操作`；
- 分页：任务超过 50 条显示分页器，少于 50 条不显示。

### 四、设计模式说明

#### 异步处理浮窗（展开状态）

- ① **任务进度**：统计列表处理完成状态（如：任务进度（4/9））；
- ② **支持搜索**（如：Q 搜索任务名称）；
- ③ **支持按业务筛选**（可配置，如：全部）；
- ④ **清空记录**：仅可清空已完成记录；当无已完成任务时，清空按钮置灰不可操作；
- ⑤ **收起浮窗**；
- ⑥ **关闭浮窗**：当有任务进行中或待开始时，不会显示关闭 icon；
- ⑦ **刷新任务列表**；
- 说明文案：任务需等待一段时间，您可以先办理其他业务，稍后回来查看。记录保留 **7 天**后自动清除。[清空记录]
- 列表字段：`任务名称 | 任务内容 | 处理状态 | 完成时间 | 操作`；
- ⑨ **处理状态**：支持自定义说明提示；
- ⑩ **分页**：任务超过 50 条，表格显示分页器；少于 50 条不显示分页器；
- ⑪ **展开浮窗**。

#### 异步处理浮窗（收起状态）

- 展示汇总状态与任务进度（如：任务进度（0/4））；
- 汇总类型：`全部任务成功 ×12` / `部分任务成功` / `全部任务失败 ×`（可删除单条记录）。

#### 任务列表常见状态

- **任务等待中**：任务均「待开始」，任务进度（0/4）；
- **任务完成**：任务进度（4/4）；
- **任务混合列表 + 分页**：共 55 条，50/页；
- **无任务**：空状态展示。

#### 2. 处理状态

| 状态 | 说明 |
| --- | --- |
| 待开始 | 异步任务在处理队列中，尚未开始处理 |
| 处理中，请稍后 | 异步任务正在处理中 |
| 成功 | 异步任务处理完成且处理结果为全部成功 |
| 部分成功 | 异步任务处理完成且处理结果为部分成功 |
| 失败 | 异步任务处理完成且处理结果为全部失败 |
| 任务超时 | 任务执行时长超过 X 小时，自动识别为已超时 |

> 处理状态支持业务自定义说明提示（如：`自定义提示` + 状态标识）。

#### 3. 浮窗展开状态高度

- 浮窗展开状态高度根据表格内容高度**自适应**，最大高度限制 **600px**。

#### 4. 浮窗位置

- 浮窗默认**收起**，默认位置为**右上角**：距离页面右侧 **16px**，距离分页 **8px**；
- 浮窗在客户端、Web 端**可拖动**，拖动范围以页面可视区域为限。

#### 5. 任务完成通知

- 发起的任务完成后，在「通知」中发送通知消息：
  - a. **标题**：异步任务完成；
  - b. **内容**：您发起的“任务名称”已完成，请及时查看结果。（任务名称超过 **10 个字符**省略显示）；
- 通知示例：通知助手（机器人）→ 应用名称 → 「异步任务完成」→ 内容摘要 → `查看`。

### 五、关键交互要点（速记）

1. **非模态浮窗**承载异步任务状态，默认收起在右上角（右 16px、距分页 8px），可展开查看明细、可拖动；
2. **状态全覆盖**：待开始 / 处理中 / 成功 / 部分成功 / 失败 / 超时，且状态文案支持业务自定义；
3. **清空记录仅限已完成**，无已完成任务时置灰；
4. **任务进行中或待开始时不显示关闭按钮**，防止用户误关丢失任务感知；
5. **结果通知**：完成后通过「通知」触达用户，任务名称过长省略（>10 字符）；
6. **记录保留 7 天**自动清除，同时明确告知用户可先处理其他业务。

## 异步处理 (Async Processing)


- **【异步处理 (Async Processing)】**
  - **设计策略**：用于解决后台耗时任务的交互反馈问题，避免用户长时间等待或误操作。
  - **交互形态**：
    - 场景一：**异步列表**（显示任务进度状态条及日志）。
    - 场景二：**悬浮窗**（全局悬浮，可拖动，支持最小化、关闭）。
    - 场景三：**小窗模式**（侧边栏浮层或底部抽屉式通知）。
  - **反馈**：任务开始时锁定相关操作，提供“查看进度”、“中断”或“重试”按钮，任务结束给予成功/失败状态的强提示。
