## 大批量上传 / 下载 · 场景指南（知识整理）


> 适用场景：大批量数据「上传 / 下载（导入 / 导出）」异步任务的设计参考

### 一、设计目标

各业务存在需要处理大批量导出导入时，任务进行时**不耽误其他业务的处理**，平台提供**异步上传下载组件**。

### 二、上传 / 下载 / 导入 / 导出 概念区分

| 操作 | 说明 | 数据量 | 特点 |
| --- | --- | --- | --- |
| **上传** | 提供给用户一个界面，选择本地文件并通过网络传输到系统；需处理文件格式、大小、类型等限制 | 用户手动选择的少量文件/数据 | 更专注于处理用户选择的文件，不涉及复杂映射和数据验证；可能触发文件处理、图像识别等业务逻辑 |
| **下载** | 将特定文件、文档或其他媒体从系统服务器传输到用户设备并保存到本地 | 单个文件或小量数据 | 主要涉及系统中特定文件或媒体内容 |
| **导入** | 使用数据导入工具，映射外部数据字段与系统内部字段，确保数据正确性和一致性 | 大规模数据引入（批量迁移、初始化系统、大规模更新） | 可能触发预处理步骤或数据验证过程；涉及外部数据映射 |
| **导出** | 将系统中数据/信息以 CSV、Excel、JSON 等格式导出到外部文件或存储介质 | 较大量的数据（整个数据表或查询结果） | 允许用户在系统外部使用、备份或共享数据 |

### 三、页面框架结构

#### 上传 / 下载窗口（组件信息结构）

```
┌─ 上传下载窗口（840PX 宽，固定最大高度 592PX）───────────────┐
│ 上传 | 下载（2 个 Tab 切换）              [收起图标]  [清空记录] │
│ Q 搜索文件名、所属功能（内容实时搜索）                        │
│ 说明：上传/下载数据文件较大时，会在列表中记录进度与结果。       │
│       记录保留 7 天后将自动清除。                            │
│ ┌──────────────────────────────────────────────┐        │
│ │ 文件名/所属功能 | 大小 | 处理状态 | 完成时间 | 操作 │        │
│ │ 江海全员工年终奖金.excel | 28MB | 上传中，请稍等 | 16:30:24 | 前往 │
│ │ 薪资代发-大批量代发      |      | 上传成功       | 2024-08-08 │
│ └──────────────────────────────────────────────┘        │
│ （数据多时鼠标滚动查看）                                   │
└────────────────────────────────────────────────────────┘
```

- 容器内容切换：「上传」「下载」2 个 Tab；
- 点击图标，收起面板；
- 内容实时搜索；
- 清空记录：一键清除，删除焦点 Tab 下所有的任务；
- 面板尺寸：宽度 840PX；固定最大高度 592PX，数据多时鼠标滚动查看。

#### 收起面板与徽标

- 收起面板时，若还有**进行中的任务**，入口处和菜单列表需展示徽标；没有则不显示；
- 展开时，非当前页签下有任务时，该页签右上角显示**圆点徽标**。

### 四、异步任务触发与位置

1. **位置 / 平台**：顶部导航（企业名称最长显示十六个文字… / 工作台 / 我的应用 / 开发者后台）；
2. **位置 / 业务**（智能记账为例，支持配置）：智能记账 → 账套名称 → 全部应用；迁账申请 / 初始化指引公告等；
3. **异步任务触发平台上传下载**：平台或业务点击执行大数据的异步处理时，**上传下载窗口自动唤起**；
   - 在平台相关页面触发异步任务；
   - 在业务相关页面触发异步任务：
     - a. 接入平台上传下载组件，则在当前顶部导航展示；
     - b. 若没有，则平台顶部导航自动展开。

### 五、上传 / 下载流程

#### 上传流程图

```
点击上传/导入 → 告知平台上传任务 → (上传)(上传完成) → 本地文件解析 → 生成数据包 → 后台准备数据包
→ 数据准备（平台不会显示此阶段状态）
数据上传：是否准备完成 → YES → 上传中 / 导入数据库中 → 是否上传成功 → YES → 成功反馈
                                                          → NO → 失败反馈
```

#### 下载流程图

```
点击导出/下载 → 告知平台下载任务 → 下载完成 → 后台准备数据包 → 本地文件解析生成数据包 → 数据准备
数据下载：是否准备完成 → YES → 下载中 → 是否下载成功 → YES → 下载成功 → 本地执行下载
                                          → NO → 失败反馈 → 下载反馈
```

### 六、列表字段与状态

#### 上传场景（字段及状态表）

| 字段 | 说明 |
| --- | --- |
| 文件名 / 所属功能 | 文件名称 + 功能名称，业务侧可定义 |
| 大小 | 文件大小 |
| 处理状态 | 状态名称：业务侧可定义，否则默认平台状态描述；结果或进度说明：业务侧预估大约进度时间 |
| 完成时间 | 任务完成时间，当日任务只显示时分秒；当日之前日期显示年月日 |
| 操作 | 对应状态的可操作项，业务可根据需求配置，暂支持跳转业务页面、下载错误文件；若业务没有提供下载错误文件的接口，则不显示 |

- 上传状态：`上传中，请稍等` / `上传成功` / `部分上传成功` / `上传失败`；
- 失败操作示例：`前往`、`下载错误文件`。

#### 下载场景（字段及状态表）

- 下载状态：`下载准备中，请稍等` / `下载准备失败` / `任务超时` / `下载成功` / `下载失败`；
- 操作：`前往`。

### 七、任务进程结束的反馈

#### 1. 面板关闭时有任务完成 / 失败反馈

- 反馈类型：`上传成功` / `下载成功` / `上传失败` / `下载失败` / `部分上传成功` / `任务超时`；
- 交互：面板收起时，有任务完成 / 失败时反馈如上；**下载时的「下载准备失败」状态不会气泡提示**。

#### 2. 面板展开时有任务完成 / 失败反馈

- 在面板列表内更新状态与提示。

### 八、上传下载窗口交互状态

#### 1. 清除记录

- 没有任务时，展示**空状态页**，「清空记录」文字按钮**置灰**；
- 空状态文案：`暂无上传记录` / `暂无下载记录`。

#### 2. 搜索

- 支持按文件名、所属功能实时搜索（`Q 搜索文件名、所属功能`），可一键清除。

### 九、关键交互要点（速记）

1. 大批量上传 / 下载采用**异步组件**，不阻塞其他业务；
2. 窗口 840PX 宽、最大高度 592PX，上传 / 下载双 Tab，支持搜索、清空记录；
3. 任务保留 **7 天**自动清除，并在列表/说明中明确告知；
4. 有进行中任务时入口/菜单显示徽标，非当前页签有任务显示圆点徽标；
5. 上传失败支持「下载错误文件」；无错误文件接口则不显示；
6. 完成 / 失败通过气泡（面板收起时）或列表状态（面板展开时）反馈。

## 批量上传/下载 (Batch Operation)


- **【批量上传/下载 (Batch Operation)】**
  - **设计策略**：专注于“数据导入”和“数据导出”场景。需统一导入/导出模板规范。
  - **交互流程**：
    - 上传：文件选择 → 数据校验（错误行标红/提示） → 校验报告 → 异步处理。
    - 下载：生成数据包 → 前端自动触发下载或提供“立即下载”按钮。
  - **状态**：校验中、上传中、成功、失败（列明失败原因，如“第 5 行数据格式错误”）。
