# 样式

## 这是什么

这是样式设计规范的二级路由入口，用来解释组件、页面和场景共同依赖的视觉基础规则。

本 README 承载样式分类契约与任务路由；所有具体样式事实统一保留在 `基础样式.md` 中。

## 分类契约

### 分类定义

样式回答的是：产品界面的视觉基础使用什么尺度、取值和组合规则，包括间距、排版、颜色、圆角、投影、图标、分割线和布局。

### 解决的问题

- 页面或组件应采用什么间距和对齐尺度
- 文字字号、字重、行高和颜色如何选择
- 品牌色、中性色和功能色如何使用
- 圆角、投影、图标和分割线如何表达层级
- 基础布局和响应式适配遵循什么规则

### 为什么独立成类

- 样式是组件、页面和场景共同依赖的视觉基础，不属于某个具体组件
- 样式规则具有跨对象复用性，应保持唯一事实来源
- 样式取值变化可能同时影响多个组件和页面，需要独立维护

### 与相邻分类的关系

- 组件使用样式规则形成具体结构、状态和交互单元
- 典型页面使用样式与组件形成页面整体布局
- 场景模式在具体任务中使用样式表达状态、层级和反馈
- 样式只提供视觉基础，不替代组件、页面或场景的对象判断

### 稳定结论

- 当前样式内容统一保留在一个正文文件中，不按间距、排版或颜色继续拆分
- 样式是跨分类依赖，不要求每次问答都从样式开始读取
- 具体对象的结构与行为必须回到组件、典型页面或场景模式确认

### 显式缺口

- [GAP] 部分样式规则缺少统一的终端和产品版本标记
- [QUESTION] 设计变量是否需要同步维护机器可读 Token 真源，仍需确认维护责任

## 任务触发索引

- 间距、边距、内边距或对齐：读 `基础样式.md` 的间距章节
- 字体、字号、字重、行高或文字颜色：读 `基础样式.md` 的排版章节
- 品牌色、中性色或功能色：读 `基础样式.md` 的颜色章节
- 圆角、投影、图标或分割线：读 `基础样式.md` 的对应章节
- 页面基础布局、栅格、断点或适配：读 `基础样式.md` 的布局章节

## 条件依赖与回主类

- 问题主体是具体控件时补读组件；主体是页面整体时补读典型页面；主体是任务过程时补读场景模式
- 样式只补充视觉约束；读取后必须回到主分类确认对象结构、状态、任务和结果

## 维护原则

- README 只承载分类契约和路由，不复制样式正文
- 所有样式事实统一维护在 `基础样式.md`
- 当前内容量未达到拆分条件，不建立间距、排版、颜色等独立文件
- 新增样式事实时进入对应章节，并同步更新文档导航

## 停止条件

- 命中 `基础样式.md` 的目标章节并读完相关规则后停止
- 未命中组件、页面或场景依赖时不扩读相邻分类；无法定位时记录 `[GAP]`
- 补读相邻分类后必须回到主分类确认最终对象和已知缺口
