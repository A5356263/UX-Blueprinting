# 来源契约、风险与质量规则

## 1. 权威来源

正式上游必须为本轮明确关联的生产者报告。核对项目、范围、版本或运行标识、来源条目及上游允许用途。多份来源逐一列明。消费范围限于本轮请求和来源授权的交集。客观完整报告须能引用分析结果、发现和局限。用户整理的数据注明直接来源。

## 2. 阻断与降级

- 分母、单位、时间窗或关系方向存在会改变结论的歧义，来源无法追溯，或展示缺少必要授权时，停止受影响的正式数值表达，列出待补或待审项。
- 样本量不足、置信度较低、缺少可选维度时，在图表规格、数据表和摘要中注明限制。
- 只有表达目标和方案草图时，可输出规格，数值结果待输入完整后再确定。

## 3. 继承事实状态和隐私

保留观测、上报、启发式发现、候选、估算、预测、已验证与未知的区别。只有上游明确给出已验证，才可以这样展示。继承上游敏感等级、脱敏状态与披露限制；不得写入本地绝对路径、访问令牌或未脱敏定位信息。需要人工确认时，受影响内容暂不发布。

## 4. 正式报告

唯一正式产物为 `spark-output/data-visualization.md`。校验后在同一报告保留图表规格、来源条目、可复核的数据表、口径与限制。只有实际生成并检查过可视化才可报告渲染成功。
