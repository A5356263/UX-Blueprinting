# 输出说明

本文件用于解释项目为什么采用固定输出结构。  
正式输出合同请见 [05_output_contract.md](E:/AI设计/体验蓝图构建思路/specs/05_output_contract.md)。

## 核心思路

固定输出结构的目标是：

- 让不同 AI 工具能稳定产出
- 让设计师能去固定位置查看结果
- 让执行中枢能稳定校验与归档
