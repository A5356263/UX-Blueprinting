# 项目总览

## 项目目标

本项目用于以固定工程结构支持：
- 需求事实提炼
- 业务蓝图构建
- 体验蓝图构建

## 项目范围

- 单仓库
- 文档主导
- 讨论稿与规格分层
- `docs/sdd/` 与根级 `specs/` 分层
- packages 执行中枢独立
- Knowledge 独立
- Wiki 编译层独立
- 项目真相独立
- 产物留档

## 当前阶段

当前阶段为 v1，重点是把目录、模板、检查清单、执行中枢与项目工作区落盘。

## 适用方式

- 由 `packages/` 执行固定逻辑
- 由 `docs/sdd/` 提供解释层导读
- 由 `specs/` 提供唯一正式规则
- 由知识包、设计指南与 Wiki 页面共同提供判断依据
- 由模板与检查清单约束输出结构
- 由 `projects/` 承接项目输入、运行产物与最终交付
