# 主链路定义

## 阶段链路

1. 原始需求输入
2. Wiki / 领域知识对齐
3. 需求事实提炼
4. 业务蓝图构建
5. 体验蓝图构建
6. 检查与归档

## 输入输出

- 输入：任务工单与原始材料
- 上游知识：`knowledge/wiki/index.md`、`knowledge/wiki/summaries/**`，必要时沿 `source_refs` 回查 `knowledge/raw/**`
- 中间产物：`facts.md`
- 结果产物：`business_blueprint.md`、`experience_blueprint.md`
- 检查产物：`check_report.md`
