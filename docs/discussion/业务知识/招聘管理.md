# 招聘管理产品介绍
一、招聘管理产品介绍

薪福通与Moka招聘无缝集成，为企业提供高效的一体化招聘及入职管理解决方案。HR可直接通过薪福通免密登录Moka系统，轻松完成职位发布、邀约面试、Offer发放及人才库搭建等招聘全流程管理。在Moka发放Offer后，可将候选人信息同步到薪福通，无缝衔接入职办理流程，让企业招聘更高效、更简单。

二、招聘管理核心功能介绍

1.全流程协作，招聘管理与人事管理打通：

企业用户通过薪福通平台直接跳转至Moka官网，无需重复登录。

HR可在Moka统一发布和刷新各招聘平台的职位信息，管理并下载各招聘渠道的简历。

系统自动抓取员工投递的简历信息，HR可一键转发至用人部门，筛选后同步符合要求的简历，并快速发送面试邀请。

2.面试安排与反馈

HR可直接在Moka平台上安排面试，面试通知自动发送给求职者和面试官。

面试结果可实时同步，HR可快速跟进招聘进展并做出决策。

3.人才库管理

Moka提供灵活的人才库管理，企业可根据需要灵活设置人才库的结构和层级。

三、招聘管理核心优势介绍

1.系统间无缝集成，提升招聘效率

薪福通与Moka系统深度对接，即可通过薪福通直接跳转至Moka平台，实现招聘功能的免密登录和无缝使用。

2.人事管理闭环

在薪福通中设置企业组织架构后，信息可同步至Moka，则职位可按部门维度聚合，便于招聘部门的数据分析。

Moka发放Offer待入职人员可直接同步至薪福通，快速完成入职办理，实现招聘与入职流程的高效衔接。

3.数据驱动，优化招聘体验

通过系统化的简历管理和面试安排，减少人工操作，提升招聘效率。

人才库的管理搭建帮助企业沉淀优质候选人资源，为后续招聘提供可靠储备。

# 招聘管理全流程操作指引

MOKA是招聘软件的头部厂商，不是招聘网站，购买招聘软件不能替代向招聘网站付费。

1.薪福通开通MOKA操作路径

路径：【全部应用-招聘管理】-“开通MOKA”。

注：仅企业超级管理员有权限开通MOKA，且企业认证状态为高级认证。

2.薪福通推送组织架构至MOKA

路径：【全部应用-招聘管理】-“对接设置”-“同步组织架构”-“保存”。

（如需系统自动同步后续的新增、修改和已删除组织，需同时勾选“自动推送更新”）

注：薪福通已停用组织暂未同步，需在MOKA手工调整。

3.MOKA添加账号

该界面可以添加超级管理员、HR、用人经理等账号。

MOKA系统内的角色划分：

①超级管理员：开通试用人会默认为MOKA超级管理员，超级管理员可以继续添加其他超级管理员，超级管理员会占用HR账号名额；

②HR：由超级管理员添加，HR账号不能进行后台设置类的操作；

③用人经理：主要作为面试官参与简历评估与面试。

3.1添加账号

路径：MOKA界面【设置-组织机构管理-团队成员管理】-“添加成员”

注：如未收到邮件，如下图方式重新发送邮件。

路径：MOKA界面【设置-组织机构管理-团队成员管理】-“重新发送邀请”

3.2MOKA界面操作流程

其他相关操作，例如：创建职位、获取简历、招聘流程推进等操作均在MOKA界面完成操作。

操作链接：https://alidocs.dingtalk.com/i/p/6gYG93eQlQeykXo9

4.MOKA界面同步人员入职信息到薪福通

MOKA支持将待入职人员的信息一键同步至薪福通的待入职模块。

路径：MOKA界面【招聘职位】-“待入职”-“同步至薪福通”

注：目前支持同步到薪福通的信息有：姓名、手机号、部门、工作地、入职日期、证件信息教育经历、工作经历。

5.薪福通查看待入职人员

路径：【员工管理-任职管理-入职管理】-“待入职”

# 开启组织架构同步指引
（1）进入人事服务的“招聘管理”模块；

（2）点击页面右侧“对接设置”按钮；

（3）开启“同步组织架构”（如需系统自动同步后续的新增、修改和已删除组织，需同时勾选“自动推送更新”）；点击保存。

注：薪福通已停用组织暂未同步，需在MOKA手工调整。

# 常见问题
1.Moka账号角色如何更改？

答：支持通过手机号匹配HR角色；同时支持超级管理员更改账号对应的角色。

2.如何创建HR和面试账号？

答：超级管理员账号默认为开通试用人，HR和面试官账号都需要超级管理员提前在Moka创建。

3.Moka哪个版本有AI功能？

答：标准版有AI功能，mini版（薪福通专版）暂不支持。

4.Moka的数据到薪福通待入职，可以同步的字段包括哪些？

答：目前支持同步姓名、手机号、部门、工作地、入职日期、证件信息等个人信息、教育经历、工作经历。

5.开通Moka功能后，进入Moka显示用户不存在是什么问题？

答：①超级管理员在 Moka提前创建HR和面试官账号，用户授权后，Moka通过手机号匹配账号是否为HR角色；

②首次登录后，通过用户ID 绑定，在薪福通变更手机号不影响用户登录；

③同时 Moka 支持超级管理员在 Moka界面更改账号对应的角色。

6.Moka面试通过的人员信息会自动同步到薪福通待入职列表吗?

答：需要在Moka操作同步，点击“同步薪福通”按钮同步。

7.企业之前已经购买了Moka标准版，现在登录Moka官网和薪福通两边数据不同步，这个是需要重新对接吗？

答：是的，数据对接的话要单独开发。（薪福通专版和Moka标准版的功能范围和价格有较大差异，最终看哪个产品能满足企业需求。）
