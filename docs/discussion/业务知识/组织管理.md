# 一、组织管理产品介绍

薪福通组织管理功能提供组织架构、编制管理和岗位管理解决方案，支持灵活搭建组织架构，制定编制计划，实时监控各部门的缺编、超编、满编情况，同时支持创建岗位和职级体系，帮助企业实现科学高效的组织管理。

# 二、组织管理核心功能介绍

1.组织架构：支持自定义设计组织架构，系统可自动生成架构图并存档，同时记录架构变动历史，便于企业追溯和管理。

2.编制管控：按部门或岗位灵活设置编制，实时统计企业及部门的编制数据，帮助企业全面掌握编制概况。

3.岗位管理：系统支持岗位和职位的创建与维护，可按部门设置不同的岗位或职位，助力企业实现岗位信息的规范化管理。

4.职级管理：HR可通过系统管理职级名称及编码，构建管理通道（M级）和专业通道（P级）等内部职级体系。实时统计各职级的在职人数，清晰掌握人员配置情况。

# 三、组织管理核心优势介绍

1.灵活可追溯的组织架构管理：自定义设计组织架构，并通过系统自动生成架构图存档。完整记录架构变动历史，帮助企业随时追溯架构演变，提升管理透明度。

2.智能化的编制管控：实时监控企业及部门的人员编制情况，支持灵活调整编制计划。根据需求设置兼任是否占编，帮助企业实现编制管理的智能化与精细化。

3.系统化的岗位与职级管理：通过岗位和职位的规范化创建与维护，帮助企业构建清晰的内部职级体系（如管理通道M级、专业通道P级）。实时统计各职级的人员分布，为人力资源规划提供数据支持。

# 组织管理全流程操作指引

1.组织

1.1组织架构

路径：【管理后台-组织-组织架构】或【人事服务-组织管理-组织-组织架构】

1.1.1组织架构字段设置

可自定义设置需要展示的字段。

1.1.2创建组织架构

组织架构字段设置完成后，可以单个新增组织，也可通过导入方式批量新增组织。

1.1.3修改组织架构

在完成组织架构的创建后，若需要对已有组织架构进行调整，可选择“导入/导出修改组织”“批量停用”“批量删除”等功能进行调整。

①导入/导出修改组织：适用于批量新增/调整组织架构，点击“导入/导出修改组织”按钮后，可按需选择导入组织，导出组织，批量修改等功能进行调整。

②批量停用/批量删除：适用于针对作废的组织架构批量进行停用或者删除，勾选需要停用或者删除的企业后，点击批量停用/批量删除即可。

1.2架构图

在完成组织架构的导入后，系统会根据导入的组织架构，自动生成组织架构图。

显示直属成员

通过显示直属成员按钮，可以将各个组织架构中的直属成员显示在架构图中。

组织显示范围

在选择对应的组织后，只显示勾选的组织。

组织字段设置

在勾选了对应的组织字段后，组织架构图中会展示相应的字段。

视图设置

在视图设置当中，可以选择“自适应视图”、“横向视图”、“纵向视图”等三种组织架构展示方式。

修改排序

针对已生成的组织架构图，可以通过“修改排序”功能，手动拖拉拽调整架构图结构。

2.编制管理

路径：【人事服务-组织管理-编制管理】

2.1功能背景

具有一定规模的大型企业、国有企业等出于优化企业发展、控制企业人力成本等目的，会设置编制数量，通过编制对企业员工数量进行控制。

当前薪福通的编制管理，主要通过录入编制数，可在员工的入转调离流程以及员工花名册增删改等操作中进行提醒或限制，以便于企业根据当前企业的编制数进行管理。

2.2操作指引

2.2.1申请开通

编制管理功能使用需要申请开通。已实名认证的企业在编制管理页点击“申请开通”，填写相关信息后，需经过后台审核即可使用。

2.2.2组织管理设置

如下图，以下设置功能是使用编制管理前的基本设置操作。

步骤一：启用编制管理

启用编制管理开关开启后，如果当前日期有设置编制计划，开启后员工异动以及花名册调整会按照当前编制数据进行提示或者控制；若已录入编制方案以及相关的编制数，暂时还不需要提示或者控制，请关闭开关。

步骤二：编制维度控制

当前编制控制的维度包含：组织、组织+岗位两种维度进行管理。

注意：

设置编制维度后，建议请在【员工管理-员工管理设置-基础设置】-“员工信息字段设置”中将对应的字段勾选，否则编制管理数据可能不准确。（例如编制的管理维度是“组织+岗位”，如果岗位字段非必填，当部门编制有余量但岗位编制已满时，员工还是可以加入企业）

如果编制方案已经设置为“组织+岗位”维度进行管理，若调整为组织维度进行管理，岗位编制信息将清空，请谨慎处理。

步骤三：强弱控制

若超编仅做提示，员工是否可以进入，则可选弱控制；

若超编后做限制，不能进入企业，则需要选择强控制。

点击细分，可以选择具体哪一类校验点需要进行编制的校验的提醒或控制，已满足企业更细分的场景管理需求。

步骤四：编制占用设置

占编人数公式固定如图中列表所示，其中由于录用审批中、待入职、待离职的人员当前是否占编不同企业定义不相同，故可勾选配置。

兼任是否占编：如下图当前员工信息可设置兼任部门、兼任岗位。由于不同企业是否占编情况不同，故可设置兼任是否占编。不占编时，员工只在主部门主岗位占编；占编时，除了主部门主岗位，在兼任部门兼任岗位也对应占1个编制。

2.2.3创建编制计划及编制数量

步骤一：创建编制计划

填写计划名称以及计划周期。设置周期后，对应的周期范围将按照该计划进行控制。

步骤二：编制控制节点设置

场景说明：不同的企业，或者同一个企业的不同部门在编制控制的节点上有不同的选择。

第一种：企业的每一个组织层级都进行了编制管理。

第二种：企业没有在叶子部门进行编制的管理，而是在中间部门，例如某一级部门/事业部/中心等进行统一的管理编制，这一级部门下的所有子部门共用总的编制。

针对以上场景：

系统默认设置编制控制节点均为叶子节点部门（最子一级节点部门），此时每一级编制都只需设置本部门的直属编制，本组织层级总编制=本层级的直属编制+下级编制之和，层层累加，直到根部门。

针对企业从中间某一层级作为编制控制的节点的场景，用户可勾选中间某一级部门作为控制节点。例如下图中，某公司下有多个部门，若企业希望以A部门作为编制管理的节点，例如这个部门下总编制数为80人，下方的子部门可共用该额度，则勾选A部门后，下方子部门的勾选框为禁用状态，且下方子部门不能再设置编制数。该部门可设置总编制数为80人。从该节点向上可继续累加，到根部门。

注意：

1.当编制的管理维度为部门+岗位时，不支持编制从中间部门开始控制；仅能从根部门开始控制。

2.在设置编制数前，先确认控制上的编制管理维度，确认当前的模式是从某个中间节点设置，还是从精确到某一层；如果中间层级设置为控制节点管理编制时，其下级部门无法设置编制。若下级有设置编制后又修改为中间部门控制，其下级设置的编制将清空。

步骤三：组织编制数编辑

点击“操作”列的编辑按钮，可以编辑编制数。

当该部门层级为中间部门控制节点，可设置总编制数，直属编制数，例如该部门总编制80人，其中直属经理1人，则总编制数可设置为80人，直属编制可设置为1人，调整原因及备注仅供记录。

当每一级部门都设置其直属编制时，可设置直属编制，总编制不可设置，由下级编制和直属编制汇总得出（如下图下级部门编制数为2，设置直属编制为3，则总编制累计为5）。

步骤四：组织编制列表数据查看

列表可查看直属编制、下级编制、总编制、直属编制情况、部门总编制、部门编制情况等相关数据。

步骤五：岗位编制数编辑

当编制维度设置为“部门+岗位”时，可点击设置和查看部门下的岗位编制情况。

设置岗位编制前应先做好岗位与部门的关联处理。（例如上图中，根部门关联了系统设计岗、开发岗、产品经理岗三个岗位）

在【组织管理-岗位管理】菜单下，先做好岗位的维护，然后需要关联所属组织，关联后才可以设置对应岗位的编制。

点击“编辑”可设置该岗位的岗位编制数。

该部门下各个岗位编制编制总数应小于等于该级部门的直属编制数。

步骤六：岗位编制列表数据查看

列表可查看岗位编制数、编制情况，以及该岗位当前在职，各种在途异动情况的实时统计结果。

2.2.4编制管理审批

在【OA审批】或【组织管理-编制管理】页面均可以进入“编制管理审批”页面。

用户选择编制计划，审批单根据编制计划以及对应的组织展示直属编制、总编制、岗位编制是否可调整。

提交审批审批通过后，对应的结果将更新至对应列表。

2.2.5编制变更记录

如下图，在【计划管理-编制变更记录】中可查询到通过编辑或者审批修改编制的情况。

2.2.6超编提示或限制

编制设置好后，在人员异动、人员信息录入及修改等场景中将会进行超编的提示或限制。

开启强校验时，人员将无法继续进入系统。

开启弱校验时，在录用和调动审批将会进行提示。

3.岗位管理

路径：【人事服务-组织管理-岗位管理】

3.1岗位管理

岗位(position)是指组织要求每个员工完成的详细工作职责，例如“人力资源部招聘经理”，可通过新增单条或导入的方式新增岗位信息，针对已有的岗位信息也可修改。

3.2职位管理

职位(job)是指关键职责的集合，与需要的知识技能、绩效衡量标准和相应待遇挂钩，例如“经理”、“总经理”，可通过新增单条或导入的方式新增职位信息，针对已有的职位信息也可修改。

4.职级管理

路径：【人事服务-组织管理-职级管理】

4.1管理职级通道

可通过管理职级通道按钮，新增职级通道，并赋予职级通道代码。

4.2新增职级

完成新增职级通道后，可点击新增职级，为对应的职级通道添加职级编码及职级名称，支持单笔新增以及批量导入。

# 新增岗位操作指引
岗位支持通过岗位管理、员工花名册等多种方式新增。

1.直接新增

在【组织管理-岗位管理】中“新增岗位”。

2.花名册新增人员时新增岗位

在【员工花名册】-“新增员工”，选择“岗位”时，快捷新增岗位。


3.批量导入花名册时，系统自动生成

批量导入员工花名册时，检测到系统中不存在的岗位，可选择“自动新增岗位”。

注：在员工花名册新增岗位时，操作人需有新增岗位的权限，如无权限，请管理员授权【组织管理-岗位管理】。

1.部门展示功能介绍

部门展示设置功能可以满足您的企业对于部门信息展示的个性化需求，除展示部门（末级部门）、部门编码（末级部门）、部门全路径等基础展示方式外，您还可以设置更多选项，来展示特定组织类型与组织层级的部门。

2.部门展示设置方法

2.1进入部门展示设置主页

进入【组织管理-组织管理设置】，点击“部门展示设置”下方的设置链接。

2.2基础展示设置

首次进入部门展示设置时，“更多设置项”默认收起；此时您可以选择同步展示员工的部门编码和部门全路径；其中，部门编码指的是员工所在末级部门的部门编码。

2.3更多设置项

点击更多设置项，查看“组织层级”与“组织类型”相关项目；此时，组织类型选项展示是您系统中已存在的组织类型，您可以根据需要进行选择。

2.4展示效果

保存配置后，相关部门信息将在花名册列表与员工花名册详情等页面生效并展示。展示效果示意图如下：

注：部门展示设置是企业级配置，您在组织管理中配置的展示方式将在员工管理等多个模块生效，并影响您企业中的其他管理员。

3.表头设置

在花名册以及其他类似的列表页，您可以在列表右上方找到“表头设置”入口。利用此功能，您可以根据当前需要调整列表展示形式。

操作路径：【员工花名册】-“表头设置”-“部门展示层级”。

注：表头设置是用户级配置，您可以根据您的需要设定列表页的展示形式，不影响企业的其他管理员；表头设置中可配置的部门字段选项，与【组织管理】中开启的选项保持一致。

4.花名册自定义导出功能升级

花名册自定义导出，部门相关字段支持更加灵活的导出方式。

操作路径：【员工花名册】-“导出”-“自定义导出”，导出字段勾选“部门”。

点击“部门导出设置”，选择需要导出的组织字段。

注：在自定义导出中，您可以选择组织架构中当前所有存在的组织类型和组织层级，不受【组织管理-组织管理设置】-“部门展示设置”中的配置影响。

5.生效页面

目前部门展示设置可以在员工花名册列表以及员工花名册详情页面生效，其他涉及部门展示的页面将陆续优化上线。

# 如何添加入职岗位？
两种方式可以添加入职岗位：
1.在【组织管理-岗位管理】中新增岗位；



2.花名册单个添加人员选择岗位处，快捷新增


3.批量导入花名册时，系统中不存在的岗位，系统自动创建。



注：花名册新增岗位操作者需有新增岗位的权限，如无权限，请管理员授权【组织管理-岗位管理】
