# 预览层文件落位与目录合同

## 1. 文档定位

本合同用于规定“体验蓝图预览层”在仓库中的文件落位、目录边界、运行时产物位置、可选归档位置，以及与主链路目录的关系。

本合同只约束预览层相关文件，不改动主链路正式产物的既有目录语义。

## 2. 适用范围

本合同适用于以下两类对象：

1. 预览层能力本身的仓库级实现文件。
2. 某个具体项目在主链路完成后生成的预览层运行时产物。

## 3. 目录边界原则

### 3.1 总原则

预览层是正式体验蓝图的只读派生扩展层，不属于主链路正式产物，不参与主链路校验，不改变正式蓝图内容。

因此，预览层相关文件必须遵守以下边界：

- 不得污染正式主产物目录语义。
- 不得使预览层文件看起来像主链路强制输出。
- 不得将运行时预览文件混入正式检查结果目录。
- 不得将本地预览服务信息写入正式业务蓝图或体验蓝图正文。

### 3.2 目录语义要求

预览层文件落位必须体现以下语义区分：

- 规则与合同类文件：仓库级规范层。
- 代码实现类文件：仓库级能力层。
- 运行时预览产物：项目级运行时层。
- 可选镜像归档：项目级导出层。

## 4. 仓库级文件落位

### 4.1 规则合同文件

预览层相关规范、合同、规则文档应落在：

```text
specs/
```

推荐命名：

```text
specs/12_experience_preview_contract.md
```

若预览层存在进一步拆分的规则文档，也应保持在 `specs/` 下统一管理，不得散落在项目目录中。

### 4.2 实现代码文件

预览层实现代码应落在：

```text
packages/experience_preview/
```

推荐结构：

```text
packages/experience_preview/
  __init__.py
  build_preview_model.py
  render_html.py
  serve_preview.py
  write_preview_runtime.py
```

说明：

- `build_preview_model.py`：从正式体验蓝图中提取并构建预览层中间结构。
- `render_html.py`：将预览模型渲染为静态 HTML 页面。
- `serve_preview.py`：启动本地预览服务并返回端口地址。
- `write_preview_runtime.py`：写入运行时文件与元数据。

### 4.3 使用说明文件

预览层运行说明、使用说明、人工排查说明应落在：

```text
docs/runbook/
```

推荐命名：

```text
docs/runbook/experience_preview_flow.md
```

## 5. 项目级运行时产物落位

### 5.1 主落位

某个具体项目在主链路完成后生成的预览层文件，主落位必须为：

```text
projects/<project-id>/runtime/preview/
```

这是预览层运行时产物的唯一推荐主目录。

### 5.2 推荐结构

```text
projects/<project-id>/runtime/preview/
  index.html
  assets/
  preview_model.json
  preview_runtime.json
  preview_build_log.md
```

各文件含义如下：

- `index.html`：本地浏览器预览入口页。
- `assets/`：静态资源目录，例如样式文件、图标、脚本、图片等。
- `preview_model.json`：从正式体验蓝图抽取出的预览结构数据。
- `preview_runtime.json`：运行信息，例如端口、启动时间、构建状态、入口地址。
- `preview_build_log.md`：本次预览生成的简要构建日志。

### 5.3 主落位要求

运行时预览产物必须满足以下要求：

- 必须与正式蓝图文件分离。
- 必须在项目目录内自洽可读。
- 必须允许 Code Agent 在聊天窗口输出其本地访问地址。
- 必须允许后续重复生成并覆盖更新。

## 6. 项目级可选归档落位

### 6.1 可选镜像目录

若项目需要在最终导出阶段保留静态预览镜像，可额外复制一份到：

```text
projects/<project-id>/exports/final/preview/
```

推荐结构：

```text
projects/<project-id>/exports/final/preview/
  index.html
  assets/
```

### 6.2 归档边界

此目录仅用于保留静态预览镜像，不得承载本地端口运行信息，不得作为预览服务的主运行目录。

以下文件不建议进入 `exports/final/preview/`：

- `preview_runtime.json`
- 临时端口信息
- 临时构建缓存
- 调试日志

## 7. 明确禁止的落位

### 7.1 禁止落入正式工作产物目录

预览层运行时文件不得落入：

```text
projects/<project-id>/workspace/
```

原因：

- `workspace/` 用于主链路正式工作产物。
- 将预览文件写入该目录会模糊正式产物与扩展层的边界。
- 容易使后续流程误将预览层视为主链路正式输出。

### 7.2 禁止落入正式检查目录

预览层文件不得落入：

```text
projects/<project-id>/exports/checks/
```

原因：

- 预览层不属于正式检查对象。
- 预览层不参与 Gate 或 Validate。
- 将预览层写入检查目录会错误暗示其属于质量闸门的一部分。

### 7.3 禁止散落在项目根目录

预览层文件不得直接散落在：

```text
projects/<project-id>/
```

例如以下形式均不推荐：

```text
projects/<project-id>/preview.html
projects/<project-id>/preview.json
projects/<project-id>/preview_assets/
```

原因：

- 破坏项目目录层次。
- 增加人工理解成本。
- 不利于后续自动清理与重复生成。

## 8. 运行与地址输出关系

### 8.1 本地预览入口

Code Agent 启动本地预览服务后，必须以 `runtime/preview/` 下的 `index.html` 或其服务路由作为浏览器访问入口。

### 8.2 聊天窗口输出要求

当预览服务启动成功后，Code Agent 必须在聊天窗口中明确输出本地访问地址。

推荐格式：

```text
本地预览地址： http://127.0.0.1:<port>
```

若存在具体页面路径，也可输出完整地址：

```text
本地预览地址： http://127.0.0.1:<port>/index.html
```

### 8.3 地址输出边界

聊天窗口中不得仅输出以下信息：

- “预览服务已启动”
- “文件已生成，请本地查看”
- “端口已开启”
- 单纯文件路径而非 URL

必须给出可直接访问的完整本地 URL。

## 9. 覆盖与清理策略

### 9.1 重复生成

同一个项目在重复生成预览层时，应默认覆盖：

```text
projects/<project-id>/runtime/preview/
```

中的旧文件，而不是在同级目录不断堆积多个版本目录。

### 9.2 归档镜像策略

若需要保留历史版本，应通过外部归档策略处理，不应在 `runtime/preview/` 下长期堆积多个时间戳目录，除非仓库另有明确的版本策略。

### 9.3 失败清理

若预览生成失败：

- 可以保留 `preview_build_log.md` 供排查。
- 不应保留误导性的成功入口地址。
- 不应输出不可访问的伪地址给聊天窗口。

## 10. 最小落地合同

预览层落地至少必须满足以下目录与文件要求：

### 10.1 仓库级

```text
specs/12_experience_preview_contract.md
packages/experience_preview/
docs/runbook/experience_preview_flow.md
```

### 10.2 项目级运行时

```text
projects/<project-id>/runtime/preview/index.html
projects/<project-id>/runtime/preview/preview_model.json
projects/<project-id>/runtime/preview/preview_runtime.json
```

### 10.3 聊天窗口输出

```text
本地预览地址： http://127.0.0.1:<port>
```

## 11. 一句话定义

预览层功能本身应落在仓库级规范与能力目录中；每个项目生成出的预览页面应主落位于 `projects/<project-id>/runtime/preview/`；如需保留交付镜像，可选复制到 `projects/<project-id>/exports/final/preview/`；预览层不得进入 `workspace/`、不得进入正式检查目录、不得被视为主链路正式产物。
