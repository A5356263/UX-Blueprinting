# 体验蓝图预览层执行清单（通用版）

## 1. 文档目的

本文档用于指导体验蓝图预览层的实际落地，覆盖从输入确认、规则实现、渲染实现到最终交付的执行步骤。

---

## 2. 实施阶段总览

建议按以下五个阶段推进：

1. 输入与边界确认。
2. 解析与映射实现。
3. 预览渲染实现。
4. 本地服务与地址输出实现。
5. 验收与回归。

---

## 3. 阶段一：输入与边界确认

### 3.1 输入确认

- [ ] 确认正式输入文件为体验蓝图正式文档。
- [ ] 确认预览层只读，不回写正式蓝图。
- [ ] 确认预览层不参与正式业务判断。
- [ ] 确认预览层作为主链路完成后的附加步骤执行。
- [ ] 确认预览层输出目录。
- [ ] 确认预览层是否需要单页应用或静态页面形式。

### 3.2 边界确认

- [ ] 不做交互模拟。
- [ ] 不做高保真视觉。
- [ ] 不做真实组件设计。
- [ ] 不新增业务规则。
- [ ] 不替代正式蓝图。
- [ ] 不进入正式 Gate / Validate。

### 3.3 内容可用性检查

- [ ] 是否存在流程说明。
- [ ] 是否存在页面或节点清单。
- [ ] 是否存在页面结构说明或区块说明。
- [ ] 是否存在状态或反馈信息。
- [ ] 是否存在文案或提示语义信息。
- [ ] 是否存在风险、限制、阻断或异常说明。
- [ ] 是否存在原则、判断或追踪说明。

---

## 4. 阶段二：解析与映射实现

### 4.1 解析器实现

- [ ] 实现章节识别器。
- [ ] 实现表格提取器。
- [ ] 实现列表项提取器。
- [ ] 实现页面对象识别。
- [ ] 实现流程对象识别。
- [ ] 实现状态、文案、风险、原则、追踪项识别。

### 4.2 归属规则实现

- [ ] 实现页面强绑定规则。
- [ ] 实现页面弱绑定规则。
- [ ] 实现流程级信息归属规则。
- [ ] 实现全局说明区回退规则。
- [ ] 实现无法归属项的收集机制。

### 4.3 中间结构实现

- [ ] 生成预览文档级中间结构。
- [ ] 生成全局流程结构。
- [ ] 生成页面预览结构集合。
- [ ] 生成全局说明集合。
- [ ] 确认每个页面结构字段完整。

---

## 5. 阶段三：预览渲染实现

### 5.1 页面输出实现

- [ ] 实现总入口页。
- [ ] 实现全局流程图区域。
- [ ] 实现页面预览卡模板。
- [ ] 实现页面摘要区模板。
- [ ] 实现线框草图区模板。
- [ ] 实现关键理解区模板。
- [ ] 实现状态区模板。
- [ ] 实现文案区模板。
- [ ] 实现风险与阻断区模板。
- [ ] 实现原则与追踪区模板。
- [ ] 实现开放问题 / 缺口区模板。

### 5.2 草图渲染实现

- [ ] 页面类承载渲染为纵向草图。
- [ ] 抽屉类承载渲染为右侧抽屉草图。
- [ ] 弹窗类承载渲染为居中弹窗草图。
- [ ] 子页面类承载渲染为页面草图并标注类型。
- [ ] 单页块数控制在建议范围内。
- [ ] 块内仅保留短标签。

### 5.3 流程图渲染实现

- [ ] 输出全局流程图。
- [ ] 若蓝图具备分流程结构，则支持分流程视图。
- [ ] 主路径使用实线。
- [ ] 阻断路径使用虚线。
- [ ] 连线支持规则、异常或判断标签。
- [ ] 节点正文不超过两行。

### 5.4 样式控制

- [ ] 统一页面宽度与留白。
- [ ] 统一卡片间距。
- [ ] 统一标题层级。
- [ ] 统一草图色块风格。
- [ ] 统一流程节点风格。
- [ ] 不引入品牌视觉或高保真表现。

---

## 6. 阶段四：本地服务与地址输出实现

### 6.1 本地服务准备

- [ ] 生成可本地打开的预览页面。
- [ ] 启动本地静态服务或前端开发服务。
- [ ] 确认服务使用本地端口可访问。
- [ ] 确认页面资源无断链。

### 6.2 地址输出实现

- [ ] 在 Code Agent 聊天窗口输出预览已生成说明。
- [ ] 在 Code Agent 聊天窗口输出明确的本地预览地址。
- [ ] 说明该地址对应的用途。
- [ ] 避免只输出文件路径而不输出地址。

### 6.3 地址验收

- [ ] 地址可复制。
- [ ] 地址可直接在浏览器访问。
- [ ] 打开后可看到流程图与页面预览内容。
- [ ] 地址对应内容与当前蓝图版本一致。

---

## 7. 阶段五：验收与回归

### 7.1 基础验收

- [ ] 浏览器本地访问正常。
- [ ] 总入口页可打开。
- [ ] 全局流程图可读。
- [ ] 页面预览卡可读。
- [ ] 页面信息区顺序一致。
- [ ] 无明显断链或错链。

### 7.2 语义验收

- [ ] 页面名称与正式蓝图一致。
- [ ] 流程名称与正式蓝图一致。
- [ ] 状态名称与正式蓝图一致。
- [ ] 规则、异常、原则引用不偏离正式蓝图。
- [ ] 不存在预览层自创状态、规则或页面。

### 7.3 缺失与降级验收

- [ ] 某页面缺少草图来源时仍可降级渲染。
- [ ] 某页面缺少专属状态项时可稳定显示。
- [ ] 某页面缺少专属文案项时可稳定显示。
- [ ] 无法归属信息会进入全局说明区。
- [ ] 无法解析项会进入待人工确认列表。

### 7.4 回归检查

- [ ] 蓝图章节名轻微变化后仍可识别。
- [ ] 蓝图表格顺序轻微变化后仍可识别。
- [ ] 页面数变化后预览结构仍稳定。
- [ ] 新增角色域或流程域后可按规则分组展示。

---

## 8. 交付完成定义

满足以下条件时，可视为预览层交付完成：

1. 正式体验蓝图已成功解析。
2. 预览中间结构已成功生成。
3. 浏览器预览页已成功生成。
4. 本地服务已成功启动。
5. Code Agent 已在聊天窗口提供本地预览地址。
6. 地址对应内容可正常打开并阅读。
