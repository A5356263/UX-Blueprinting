# 体验蓝图预览实现用字段映射表（通用版）

## 1. 文档目的

本文档用于定义“正式体验蓝图 -> 预览中间结构 -> 前端预览视图”的字段映射规则。

该文档主要供 Code Agent、预览生成脚本实现者和主链路集成实现者使用。它不是业务说明文档，而是实现规范文档。

换句话说，这份文档回答的是：

- 正式蓝图中的哪类信息映射到预览中的哪个位置。
- 字段缺失时如何处理。
- 何时挂到页面下，何时挂到全局说明区。
- 哪些字段是必选，哪些字段允许为空。

---

## 2. 适用对象

本字段映射表主要供以下对象使用：

- Code Agent。
- 预览渲染脚本。
- 蓝图解析脚本。
- 预览验收人员。

它不是面向业务方阅读的主说明文档，但也应保持清晰可审阅。

---

## 3. 映射目标结构

推荐先从正式蓝图抽取出统一的中间结构，再进行渲染。

推荐结构如下：

```text
preview_document
- meta
- global_flow
- page_views[]
- global_notes[]
- unresolved_items[]

page_view
- view_id
- view_name
- view_type
- audience
- summary
- sketch_blocks[]
- key_understanding[]
- states[]
- copy_items[]
- risks[]
- blockers[]
- principles[]
- trace_items[]
- open_items[]
- gap_items[]
- source_refs[]
```

---

## 4. 文档级字段映射

| 蓝图来源 | 目标字段 | 必填性 | 说明 |
| --- | --- | --- | --- |
| 蓝图标题或文件名 | `meta.title` | 建议必填 | 用于预览标题 |
| 蓝图主题或目标说明 | `meta.subject` | 可选 | 用于入口摘要 |
| 蓝图版本、时间、上下文 | `meta.context` | 可选 | 用于辅助说明 |
| 全局通用说明 | `global_notes[]` | 可选 | 无法归属页面的信息进入此处 |
| 无法解析或无法归属项 | `unresolved_items[]` | 可选 | 用于人工确认 |

---

## 5. 流程级字段映射

### 5.1 流程节点映射

| 蓝图来源 | 目标字段 | 必填性 | 说明 |
| --- | --- | --- | --- |
| 流程名称 | `global_flow.nodes[].name` | 必填 | 节点名 |
| 页面 / 节点类型 | `global_flow.nodes[].type` | 建议必填 | 页面、抽屉、弹窗、节点等 |
| 节点任务目标 | `global_flow.nodes[].goal` | 可选 | 一句说明 |

### 5.2 流程关系映射

| 蓝图来源 | 目标字段 | 必填性 | 说明 |
| --- | --- | --- | --- |
| 步骤顺序 | `global_flow.edges[].from/to` | 必填 | 定义前后关系 |
| 成功路径 | `global_flow.edges[].path_type` | 建议必填 | 取值可为 `success` |
| 阻断 / 回退 / 失败路径 | `global_flow.edges[].path_type` | 建议必填 | 取值可为 `blocked`、`fallback`、`failure` |
| 规则、异常、判断标签 | `global_flow.edges[].label` | 可选 | 连线旁说明 |

---

## 6. 页面级字段映射

### 6.1 页面基础信息映射

| 蓝图来源 | 目标字段 | 必填性 | 说明 |
| --- | --- | --- | --- |

| 页面类型 | `page_views[].view_type` | 建议必填 | 页面、抽屉、弹窗、子页面 |
| 面向角色 / 目标用户 | `page_views[].audience` | 可选 | 角色说明 |
| 主任务、入口、退出、上下游 | `page_views[].summary` | 可选 | 页面摘要内容 |

### 6.2 草图区映射

| 蓝图来源 | 目标字段 | 必填性 | 说明 |
| --- | --- | --- | --- |
| 区块布局示意 | `page_views[].sketch_blocks[]` | 建议必填 | 草图主来源 |
| 页面结构描述 | `page_views[].sketch_blocks[]` | 可选 | 当缺布局示意时可降级使用 |
| 区块标签 | `page_views[].sketch_blocks[].label` | 必填 | 必须简短 |
| 区块类型 | `page_views[].sketch_blocks[].block_type` | 可选 | Header、Intro 等 |

### 6.3 关键理解区映射

| 蓝图来源 | 目标字段 | 必填性 | 说明 |

| 首屏必须理解 | `page_views[].key_understanding[]` | 可选 | 首屏应传达的重点 |
| 决策必需信息 | `page_views[].key_understanding[]` | 可选 | 用户必须知道的内容 |
| 关键动作 | `page_views[].key_understanding[]` | 可选 | 页面主动作概览 |

### 6.4 状态区映射

| 蓝图来源 | 目标字段 | 必填性 | 说明 |
| --- | --- | --- | --- |
| 状态名称 | `page_views[].states[].name` | 建议必填 | 状态展示名称 |
| 触发条件 | `page_views[].states[].trigger` | 可选 | 何时进入该状态 |
| 页面反馈 | `page_views[].states[].feedback` | 可选 | 页面如何提示 |
| 下游结果 | `page_views[].states[].outcome` | 可选 | 状态后的结果 |

### 6.5 文案区映射

| 蓝图来源 | 目标字段 | 必填性 | 说明 |
| --- | --- | --- | --- |

| 场景 | `page_views[].copy_items[].scene` | 可选 | 文案发生场景 |

| 必含信息 | `page_views[].copy_items[].must_include` | 可选 | 关键语义 |
| 禁止写法 | `page_views[].copy_items[].forbidden` | 可选 | 应避免的表达 |

### 6.6 风险与阻断区映射

| 风险触发场景 | `page_views[].risks[].trigger` | 可选 | 何时发生 |
| 困惑原因 | `page_views[].risks[].confusion_reason` | 可选 | 用户为何会误解 |

## 7. 页面归属判断规则

### 7.1 强绑定

当内容中明确出现页面标识、页面名称或明确页面对象时，直接归属到该页面。

### 7.2 弱绑定

当内容未显式写出页面，但语义明显服务于单一页面时，可弱绑定到该页面。

### 7.3 提升为全局说明

若内容同时作用于多个页面，或无法稳定判断归属，则写入 `global_notes[]`，不得强行挂在任一页面下。

---

## 8. 缺失值处理规则

### 8.1 必填缺失

若 `view_name` 或流程节点名称缺失，应视为解析异常，并进入 `unresolved_items[]`。

### 8.2 建议必填缺失

若 `view_type`、状态名称、草图区块来源等建议必填项缺失，可降级显示，但需标记来源不足。

### 8.3 可选项缺失

可选项缺失时允许为空，但前端预览应明确展示“无直接项”或空区占位。

---

## 9. 前端渲染约束

### 9.1 页面卡固定顺序

前端必须按以下顺序渲染页面卡内容：

1. 页面摘要。
2. 线框草图。
3. 关键理解。
4. 状态。
5. 文案。
6. 风险与阻断。
7. 原则与追踪。
8. 开放问题 / 缺口。

### 9.2 不允许的渲染行为

- 不允许因字段少而改变区块顺序。
- 不允许把整段原文原封不动塞进单一区块。
- 不允许将阻断伪装为普通风险。
- 不允许把缺失信息伪装成已解析结果。

---

## 10. 本地预览地址输出字段

为了满足主链路完成后的交付要求，建议在实现层保留一组运行输出字段：

```text
preview_runtime
- output_dir
- server_host
- server_port
- preview_url
- ready_state
```

推荐说明如下：

| 字段 | 说明 |
| --- | --- |
| `output_dir` | 预览文件输出目录 |
| `server_host` | 本地服务地址，如 `127.0.0.1` |
| `server_port` | 本地服务端口 |
| `preview_url` | 聊天窗口最终输出的预览地址 |
| `ready_state` | 是否已完成生成并可访问 |

最终在 Code Agent 聊天窗口中，应以 `preview_url` 作为对外地址输出，而不是只输出文件路径。

---

## 11. 这份文档是否属于规范文档

是。

但它不是业务规范文档，而是实现规范文档。它主要供 Code Agent 和实现脚本消费，用于保证预览层从正式蓝图到前端展示的过程稳定、一致、可回归。
