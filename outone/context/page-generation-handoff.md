# 页面事实交接

- 项目：企业财富+商机中心
- 来源：outone/requirements_baseline.md
- 事实数量：22

## 页面事实

### HF-001
- 类型：页面结构
- 事实：企业财富+新增商机中心模块，包含客户营销、策略管理、数据回检三个页签。
- 基线来源：§2 / 商机中心

### HF-002
- 类型：条件与权限
- 事实：进入商机中心时，拥有"商机中心-查看客户营销"权限的用户默认展示客户营销页签；无该权限时默认展示其第一个有权页签。
- 基线来源：§2 / 商机中心

### HF-003
- 类型：条件与权限
- 事实：无查看权限的用户不展示商机中心菜单；直接访问页面地址时提示"暂无权限"，接口不返回业务数据。
- 基线来源：§3 / 其他行内普通用户、EX-009

### HF-004
- 类型：内容与操作
- 事实：策略管理页签展示策略列表，字段含策略名称/编号、优先级、规则说明、跟进期限、当前适配客户数、新增匹配客户数、即将过期客户数、已过期未营销客户数、更新频率、操作；默认按优先级从高到低、相同优先级按预置顺序排列。
- 基线来源：§4 / FN-001、§5 / BR-001

### HF-005
- 类型：校验
- 事实：策略管理支持按策略名称/编号（模糊搜索）、优先级（多选）筛选或搜索策略。
- 基线来源：§4 / FN-001

### HF-006
- 类型：内容与操作
- 事实：策略详情展示基本信息（优先级、优先级说明、更新频率、统计周期、跟进期限）、标签组合规则和规则说明。
- 基线来源：§4 / FN-002

### HF-007
- 类型：内容与操作
- 事实：策略详情商机记录筛选区支持按客户名称/编号、所属机构、优先级、商机有效性、商机营销状态、生效时间、过期时间筛选，不支持按商机编号筛选。
- 基线来源：§4 / FN-002、§5 / BR-012

### HF-008
- 类型：内容与操作
- 事实：策略详情商机记录列表展示商机编号、客户名称/编号、优先级、商机有效性、商机营销状态、生效时间、过期时间、跟进期限、规则说明、关联活动数、操作；默认按生效时间倒序，每页10条。
- 基线来源：§4 / FN-002

### HF-009
- 类型：内容与操作
- 事实：客户营销页签顶部展示新增匹配客户数、待营销客户数、已过期未营销客户数、公金五星客户数、企业财富重点客户数五项统计；统计范围按客户号去重，不随列表筛选变化。
- 基线来源：§4 / FN-003

### HF-010
- 类型：内容与操作
- 事实：客户营销筛选区支持按客户名称/客户号、商机策略名称/编号、营销状态、公金星级、企业财富星级、所属机构、客户经理、商机最新触发时间、商机最晚过期时间、年日均余额、时点余额、历史最高时点余额筛选客户。
- 基线来源：§4 / FN-003

### HF-011
- 类型：内容与操作
- 事实：客户营销统一客户列表字段含客户名称/客户号、有效商机、商机最新触发时间、商机最晚过期时间、营销状态、公金星级、企业财富星级、年日均余额、时点余额、历史最高时点余额、所属机构、客户经理、操作；默认按客户营销状态分组（待营销、营销中、其他状态）、公金星级降序、企业财富星级降序、商机最新触发时间降序排序。
- 基线来源：§4 / FN-003

### HF-012
- 类型：条件与权限
- 事实：客户营销列表仅客户营销状态为"待营销"的客户可勾选；非待营销状态客户选择框置灰并提示"仅待营销状态客户可批量处理"；未选择客户时点击批量操作统一提示"请选择至少一名客户"。
- 基线来源：§4 / FN-003、§5 / BR-008

### HF-013
- 类型：内容与操作
- 事实：客户营销批量操作区含已选择客户数、选择本页全部、选择全部筛选结果、已线下处理、暂不处理、去营销；选择客户后按用户权限和客户状态执行对应操作。
- 基线来源：§4 / FN-004、FN-005、FN-006

### HF-014
- 类型：状态与结果
- 事实：首次点击去营销时展示操作说明，用户确认并继续；确认前重新计算客户营销状态，因状态变化没有客户仍为待营销时提示"没有客户有待营销商机，默认不做处理"，确认按钮置灰。
- 基线来源：§4 / FN-004、§5 / BR-013、EX-005

### HF-015
- 类型：内容与操作
- 事实：点击暂不处理、已线下处理并确认时展示确认提示；执行后客户不再在待营销下展示。
- 基线来源：§4 / FN-005、FN-006

### HF-016
- 类型：内容与操作
- 事实：客户详情展示客户名称/客户号、企银编号、所属机构、客户经理、公金星级、企业财富星级、年日均余额、时点余额、时点余额数据日期、历史最高时点余额、客户营销状态。
- 基线来源：§4 / FN-007

### HF-017
- 类型：内容与操作
- 事实：客户详情商机记录筛选区支持按策略名称/编号、优先级、商机有效性、商机营销状态、生效时间、过期时间筛选，不支持按商机编号筛选；商机记录默认按生效时间倒序，每页10条。
- 基线来源：§4 / FN-007、§5 / BR-012

### HF-018
- 类型：内容与操作
- 事实：客户详情商机记录操作列按商机营销状态展示：营销中、营销成功、营销失败、无经营价值时展示"查看关联活动"；已线下处理、暂不处理时展示"查看人工处理记录"；待营销、已过期未营销时显示"-"。
- 基线来源：§4 / FN-007、§6 / 商机营销状态

### HF-019
- 类型：条件与权限
- 事实：客户详情顶部操作区固定展示去营销、暂不处理、已线下处理按钮（对拥有相应权限的用户）；客户营销状态为"待营销"时按钮可用，非待营销时按钮置灰并提示"只有待营销客户可以操作"。
- 基线来源：§4 / FN-007、AC-007

### HF-020
- 类型：内容与操作
- 事实：点击商机记录的"查看关联活动"后，右侧展示该商机的活动与任务（活动按发起时间倒序，每个活动下展示当前客户对应的全部任务）。
- 基线来源：§4 / FN-007

### HF-021
- 类型：页面结构
- 事实：数据回检页签点击后获取可信跳转地址和必要参数，打开CRM营销回检中心；无权限或跳转失败时不跳转。
- 基线来源：§4 / FN-008、EX-007

### HF-022
- 类型：状态与结果
- 事实：数据回检跳转失败时用户留在当前页面，提示"暂时无法打开数据回检，请稍后重试"；无权限时提示"暂无权限"。
- 基线来源：§4 / FN-008、EX-007、EX-009
