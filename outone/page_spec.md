# 页面生成规格：企业财富+商机中心

## 1. 页面摘要

- **产品领域**：企业财富+ — 商机中心（商机营销经营）
- **页面类型**：父级承载页（商机中心）、列表页（客户营销 / 策略管理）、详情页（客户详情 / 策略详情）、确认弹窗（去营销 / 暂不处理 / 已线下处理）、展示弹窗（有效商机 / 人工处理记录）
- **用户角色**：总分行产品经理及领导、系统管理员、客户经理
- **核心任务**：产品经理从客户维度统一查看商机与营销状态，筛选客户并批量去营销、暂不处理、已线下处理，查看客户详情与商机记录，并查看商机策略与数据回检

---

## 2. 生成范围

### 生成

1. 商机中心（父级承载页）——承载客户营销、策略管理、数据回检三个平级页签
2. 客户营销页（Tab）——客户维度统一列表、筛选、批量操作
3. 去营销说明与确认弹窗——首次说明营销渠道与数据留存并确认去营销
4. 暂不处理确认弹窗——确认批量暂不处理，明确不可逆
5. 已线下处理确认弹窗——确认批量已线下处理，明确不可逆
6. 有效商机弹窗——查看单个客户当前全部有效商机
7. 客户详情（修改现有页面）——查看客户信息、商机记录、活动任务与人工处理记录
8. 策略管理页（Tab）——只读展示3条商机策略
9. 策略详情页——查看策略规则信息与商机记录
10. 人工处理记录弹窗——查看单条商机的人工处理记录

### 只引用不生成

- 数据回检（跳转CRM营销回检中心）：跨应用外部系统，任务可在跳转入口处结束，只需说明跳转目标与返回结果。
- CRM新建活动页：跨应用外部系统，名单传输成功后任务在跳转入口处结束。
- CRM营销回检中心：跨应用外部系统，仅由数据回检跳转打开。

### 不生成

- 上游商机同步（三室产品系统同步）：后台系统处理，非可见界面。

## 4. 商机中心（父级承载页）

### 页面目标

作为企业财富+内商机统一经营入口，承载客户营销、策略管理、数据回检三个平级页签。

### 页面结构

```text
企业财富+ ＞ 商机中心
┌─────────────────────────────────────────────────────┐
│ [客户营销]  [策略管理]  [数据回检]                     │
├─────────────────────────────────────────────────────┤
│ {当前页签内容区域}                                    │
│                                                     │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 区域说明

- 页签导航区：客户营销、策略管理、数据回检三个平级页签，进入商机中心默认落在客户营销页签（拥有客户营销权限时）；无客户营销权限时落在第一个有权页签。
- 页签内容区：承载当前选中页签内容。

### 关键操作

- 进入商机中心：系统按权限决定默认页签并展示对应内容。
- 切换页签：点击 [客户营销] / [策略管理] / [数据回检]，切换到对应页签内容。
- 无权限访问：直接访问页面地址时展示"暂无权限"提示，不返回业务数据。

## 5. 客户营销页（Tab）

### 页面目标

从客户维度统一查看商机与营销状态，筛选客户并批量处理其待营销商机。

### 页面结构（ASCII 主结构）

```text
客户营销
┌─────────────────────────────────────────────────────┐
│ 顶部统计：新增匹配{数} 待营销{数} 已过期未营销{数}     │
│          公金五星{数} 企业财富重点客户{数}             │
├─────────────────────────────────────────────────────┤
│ 筛选：客户名称/编号 策略 营销状态 星级 机构 客户经理    │
│       商机最新触发时间 商机最晚过期时间                │
│       年日均余额 时点余额 历史最高时点余额              │
├─────────────────────────────────────────────────────┤
│ 已选择 {数量} 人  [选择本页全部] [选择全部筛选结果]      │
│ [已线下处理] [暂不处理] [去营销]                       │
├─────────────────────────────────────────────────────┤
│ 客户列表（每行一名客户）：                            │
│ □ 客户名称/客户号 有效商机 最新触发 最晚过期            │
│   营销状态 公金星级 财富星级 年日均 时点 历史最高       │
│   所属机构 客户经理 [详情]                            │
└─────────────────────────────────────────────────────┘
```

### 区域说明

- 顶部统计区：五项统计（新增匹配客户数、待营销客户数、已过期未营销客户数、公金五星客户数、企业财富重点客户数），统计范围按客户号去重；置于筛选区上方，作为稳定信息不随筛选变化，只随用户权限和业务数据变化。
- 筛选区：客户名称/编号（模糊搜索）、商机策略名称/编号、营销状态、公金星级、企业财富星级、所属机构、客户经理、商机最新触发时间、商机最晚过期时间、年日均余额、时点余额、历史最高时点余额。
- 批量操作区：已选择客户数、选择本页全部、选择全部筛选结果、已线下处理、暂不处理、去营销。
- 客户列表区：每行一名客户，按客户号去重；默认按营销状态分组（待营销、营销中、其他状态）、公金星级降序、企业财富星级降序、商机最新触发时间降序。

### 信息与字段

- 顶部统计：新增匹配客户数、待营销客户数、已过期未营销客户数、公金五星客户数、企业财富重点客户数。
- 列表字段：客户名称/客户号、有效商机、商机最新触发时间、商机最晚过期时间、营销状态、公金星级、企业财富星级、年日均余额、时点余额、历史最高时点余额、所属机构、客户经理、操作。
- 有效商机列：按生效时间倒序拼接有效商机策略名称，名称间用顿号分隔，最多展示前10个字符，超出加"..."，末尾追加"|共X项"；无有效商机显示"-"。

### 关键操作

- 查看顶部统计：统计不随筛选变化，只随权限和业务数据变化。
- 筛选客户：设置筛选条件后查询，重置后清空条件并从第一页展示。
- 勾选客户：仅待营销状态客户可勾选；支持单行、选择本页全部、选择全部筛选结果（两个全选只选中当前结果中的待营销状态客户）；修改筛选或重置后清空选择。
- 点击 [去营销] / [暂不处理] / [已线下处理]：未选择客户时提示"请选择至少一名客户"，不发起后续处理。
- 点击客户名称/客户号：新窗口打开客户详情。
- 点击有效商机列：打开有效商机弹窗。

## 6. 去营销说明与确认弹窗

### 弹窗目标

首次使用时前置说明营销渠道与数据留存，并确认批量去营销。

### 区域结构（ASCII 主结构）

```text
前往CRM营销平台创建活动
┌─────────────────────────────────────────────────────┐
│ CRM营销平台支持客户经理、企微、企银栏位等营销渠道，    │
│ 可同时选择多个。                                      │
│ 如需选择客户经理渠道，请先选择其他渠道；从第二个渠道   │
│ 开始可选择客户经理。                                 │
│ 通过系统开展营销，可留存营销数据，用于追踪营销过程及   │
│ 后续回检优化。                                       │
│ □ 不再提示                                          │
│                    [取消] [确认并继续]                │
└─────────────────────────────────────────────────────┘
```

### 区域说明

- 说明文案区：营销渠道支持说明与数据留存意义说明。
- 不再提示勾选区：勾选后后续点击去营销不再展示说明弹窗。
- 操作区：取消、确认并继续。

### 关键操作

- 首次使用点击 [去营销]：打开本弹窗展示说明。
- 勾选 [不再提示]：后续去营销不再展示说明。
- 点击 [确认并继续]：系统校验权限、客户去重、1—10000名上限及待营销商机；为每名客户固定当前全部待营销商机快照；分批传输名单（每批最多1000名）。
- 全部批次成功：返回可跳转结果，打开CRM新建活动页（只引用不生成）。
- 任一批失败：不跳转，就地展示失败并允许重新提交。
- 点击 [取消]：关闭弹窗，回到客户营销页，已选客户与筛选条件保留。

## 7. 暂不处理确认弹窗

### 弹窗目标

确认对所选待营销客户批量暂不处理，明确不可逆结果。

### 区域结构（ASCII 主结构）

```text
确定暂不处理？
┌─────────────────────────────────────────────────────┐
│ 本次将对已选{数量}位待营销客户执行暂不处理操作，执行后  │
│ 该批客户将不在待营销状态下展示，确认继续吗？           │
│                    [取消] [确认]                      │
└─────────────────────────────────────────────────────┘
```

### 区域说明

- 确认说明区：受影响客户数与执行结果说明。
- 操作区：取消、确认。

### 关键操作

- 点击 [确认]：对客户全部待营销商机逐条保存操作类型、操作人、操作时间、客户号、商机编号；重算商机及客户营销状态；客户不再在待营销下展示。
- 点击 [取消]：关闭弹窗，已选客户与筛选条件保留。
- 操作不可撤销：确认后无恢复入口。


### 区域说明

- 确认说明区：受影响客户数与执行结果说明。
- 操作区：取消、确认。

### 关键操作

- 点击 [确认]：对客户全部待营销商机逐条保存操作类型、操作人、操作时间、客户号、商机编号；重算商机及客户营销状态；客户不再在待营销下展示。
- 点击 [取消]：关闭弹窗，已选客户与筛选条件保留。

## 9. 有效商机弹窗

### 弹窗目标

查看单个客户当前全部有效商机的候选集合。

### 区域结构（ASCII 主结构）

```text
有效商机（{客户名称}）
┌─────────────────────────────────────────────────────┐
│ 商机编号 策略名称/编号 优先级 生效时间 过期时间         │
│ OPP-{编号} {策略名称} 极高 {时间} {时间}              │
│ ...（每页10条）                                      │
└─────────────────────────────────────────────────────┘
```

### 区域说明

- 商机列表区：展示该客户当前全部有效商机，默认按生效时间倒序，每页10条；不提供筛选、排序和批量操作。

### 信息与字段

- 商机编号、策略名称/编号、优先级、生效时间、过期时间。

### 关键操作

- 点击策略名称/编号：新窗口打开对应策略详情。
- 关闭弹窗：保留客户列表原有筛选、排序和分页状态。

## 10. 客户详情（修改现有页面）

### 页面目标

查看单个客户的信息、营销状态、商机明细与关联活动任务。

### 页面结构（ASCII 主结构）

```text
客户详情（新窗口）
┌─────────────────────────────────────────────────────┐
│ 顶部操作区：[已线下处理] [暂不处理] [去营销]           │
│ 客户名称/客户号 企银编号 所属机构 综支机构 客户经理     │
│ 公金星级 企业财富星级 年日均余额 时点余额              │
│ 时点余额数据日期 历史最高时点余额 客户营销状态          │
├─────────────────────────────────────────────────────┤
│ 商机记录（每页10条，默认按生效时间倒序）              │
│ 筛选：策略名称/编号 优先级 有效性 营销状态 时间范围     │
│ ┌──────┬──────────┬────┬──────┬─────────┐          │
│ │商机编号│策略名称/编号│优先级│有效性│营销状态│          │
│ │生效时间│过期时间│跟进期限│规则说明│关联活动数│操作│   │
│ └──────┴──────────┴────┴──────┴─────────┘          │
│  操作列：[查看关联活动] / [查看人工处理记录] / "-"     │
└─────────────────────────────────────────────────────┘
```

### 条件结构（查看关联活动）

```text
客户详情（右侧就地展示区）
┌─────────────────────────────────────────────────────┐
│ 商机记录（主区域保持）                              │
│ ...                                                  │
├─────────────────────────────────────────────────────┤
│ 右侧关联活动区：                                     │
│ 活动名称/编号 发起时间 发起人 活动状态                │
│   └─任务名称/编号 任务渠道 任务状态                   │
└─────────────────────────────────────────────────────┘
```

### 区域说明

- 顶部操作区：已线下处理、暂不处理、去营销，位于客户信息区上方；对拥有相应操作权限的用户固定展示。
- 客户信息区：客户名称/客户号、企银编号、所属机构、综支机构、客户经理、公金星级、企业财富星级、年日均余额、时点余额、时点余额数据日期、历史最高时点余额、客户营销状态。
- 商机记录区：全部当前及历史商机，每页10条，默认按生效时间倒序；筛选支持策略名称/编号、优先级、商机有效性、商机营销状态、生效时间、过期时间（不支持商机编号筛选）。
- 查看关联活动：点击后右侧就地展示该商机的活动与任务，不跳离页面。

### 信息与字段

- 客户信息：客户名称/客户号、企银编号、所属机构、综支机构、客户经理、公金星级、企业财富星级、年日均余额、时点余额、时点余额数据日期、历史最高时点余额、客户营销状态。
- 商机记录筛选：策略名称/编号、优先级、商机有效性、商机营销状态、生效时间、过期时间。
- 商机记录字段：商机编号、策略名称/编号、优先级、商机有效性、商机营销状态、生效时间、过期时间、跟进期限、规则说明、关联活动数、操作。
- 活动与任务：活动名称/编号、发起时间、发起人、活动状态、任务名称/编号、任务渠道、任务状态。

### 关键操作

- 顶部操作区：客户营销状态为"待营销"时三个按钮可用；非待营销时按钮置灰并提示"只有待营销客户可以操作"。
- 查看商机记录：设置筛选后查询，重置后清空条件。
- 点击 [查看关联活动]（营销中/营销成功/营销失败/无经营价值时展示）：右侧就地展示该商机的活动与任务，活动按发起时间倒序，每个活动下展示当前客户对应的全部任务。
- 点击 [查看人工处理记录]（已线下处理/暂不处理时展示）：弹窗展示该商机的人工处理记录。
- 待营销/已过期未营销时：操作列显示"-"。
- 客户权限已变化：客户详情接口重新校验，提示"暂无权限"且不返回客户数据。

## 14. 跨页面交互流程

### 流程 1 · 批量去营销

来源实体：客户营销页 → 触发动作：点击 [去营销] → 经过实体：去营销说明与确认弹窗 → 返回位置：全部成功后打开CRM新建活动页（只引用不生成）；任一批失败就地展示失败并允许重新提交 → 最终稳定界面：CRM新建活动页或客户营销页

分支：

- 未选择客户 → 点击 [去营销] → 提示"请选择至少一名客户"，不打开确认弹窗，停留在客户营销页。
- 所选客户超过10000名 → 提示"单次最多选择10000名客户"，不上传。
- 确认前部分客户状态已变化 → 弹窗提示实际处理数量，只处理仍为待营销客户。
- 确认前全部客户状态已变化 → 提示"没有客户有待营销商机，默认不做处理"，确认按钮置灰。
- 任一批名单传输失败 → 不跳转，就地展示失败，允许重新提交。

### 流程 2 · 批量暂不处理 / 已线下处理

来源实体：客户营销页 → 触发动作：点击 [暂不处理] 或 [已线下处理] → 经过实体：暂不处理确认弹窗 / 已线下处理确认弹窗 → 返回位置：客户营销页 → 最终稳定界面：客户营销页（处理客户不再在待营销下展示）

分支：

- 未选择客户 → 提示"请选择至少一名客户"。
- 确认前部分客户状态已变化 → 只处理仍为待营销客户并提示数量。
- 确认前全部客户状态已变化 → 确认按钮置灰。

### 流程 3 · 查看客户详情及商机记录

来源实体：客户营销页或策略详情页 → 触发动作：点击客户名称/客户号 → 经过实体：客户详情 → 返回位置：客户详情（新窗口） → 最终稳定界面：客户详情

分支：

- 客户营销状态非待营销 → 顶部操作按钮置灰，提示"只有待营销客户可以操作"。
- 客户权限已变化 → 提示"暂无权限"且不返回客户数据。
- 点击 [查看关联活动] → 客户详情右侧就地展示活动与任务。
- 点击 [查看人工处理记录] → 打开人工处理记录弹窗。

### 流程 4 · 查看商机策略与策略详情

来源实体：商机中心 → 触发动作：切换策略管理页签 → 经过实体：策略管理页 → 点击 [详情] → 经过实体：策略详情页 → 最终稳定界面：策略详情页

分支：

- 策略尚无用户有权查看的商机 → 商机记录展示空状态，不提供批量操作。
- 点击商机记录客户名称/客户号 → 新窗口打开客户详情。

### 流程 5 · 查看有效商机

来源实体：客户营销页 → 触发动作：点击有效商机列 → 经过实体：有效商机弹窗 → 返回位置：客户营销页（保留原有筛选、排序和分页状态） → 最终稳定界面：客户营销页

分支：

- 点击策略名称/编号 → 新窗口打开对应策略详情。

### 流程 6 · 数据回检（只引用不生成）

来源实体：商机中心 → 触发动作：切换数据回检页签并点击 [数据回检] → 经过实体：CRM营销回检中心（跨应用） → 返回位置：商机中心 → 最终稳定界面：CRM营销回检中心或商机中心

分支：

- 无权限 → 提示"暂无权限"，不跳转。
- 跳转失败 → 提示"暂时无法打开数据回检，请稍后重试"，允许重试。

## 17. 异常恢复

### 异常 1 · 无权限访问商机中心

- 触发条件：无对应功能权限（查看客户营销、查看商机策略、查看商机数据回检）。
- 判断依据：后端校验功能权限。
- 系统反馈：不展示菜单；直接访问页面地址时页面级提示"暂无权限"，接口不返回业务数据。
- 用户出口：用户无处理路径，按权限申请或联系管理员由现有权限体系承接。

### 异常 2 · 去营销名单传输任一批失败

- 触发条件：批量去营销分批传输名单中任一批失败。
- 判断依据：批次结果失败。
- 系统反馈：不跳转CRM新建活动页并就地展示失败；名单交接成功但活动尚未创建时不改变商机营销状态。
- 用户出口：允许重新提交，重复提交由接口幂等机制处理。

### 异常 3 · 去营销超过人数上限

- 触发条件：所选去重客户超过10000名。
- 判断依据：数量校验。
- 系统反馈：就地提示"单次最多选择10000名客户"，不上传。
- 用户出口：调整选择后重新发起。

### 异常 4 · 批量操作确认前客户状态变化

- 触发条件：已选客户在确认弹窗打开前部分或全部不再为待营销状态。
- 判断依据：提交前重新计算客户营销状态。
- 系统反馈：部分变化时提示实际处理数量，只处理仍为待营销客户；全部变化时提示"没有客户有待营销商机，默认不做处理"并置灰确认按钮。
- 用户出口：确认后只处理仍为待营销的客户；无需其他动作。

### 异常 5 · CRM活动组建失败、审批不通过或审批已撤回

- 触发条件：活动组建失败、审批不通过或审批已撤回，且无其他进行中证据。
- 判断依据：CRM活动状态回流。
- 系统反馈：状态回流后，有效商机恢复待营销，按商机营销状态计算顺序重算。
- 用户出口：可重新发起去营销。

### 异常 6 · 数据回检跳转失败

- 触发条件：跳转地址或参数获取失败、CRM不可访问。
- 判断依据：后端跳转处理失败。
- 系统反馈：终止跳转并记录失败日志，就地提示"暂时无法打开数据回检，请稍后重试"。
- 用户出口：允许重试，用户留在当前页面。

### 异常 7 · 客户无有效商机

- 触发条件：客户没有新增匹配或持续有效商机。
- 判断依据：有效商机为空。
- 系统反馈：有效商机列显示"-"，点击区域不可用；客户营销状态仍按最近30日商机聚合。
- 用户出口：可查看商机历史记录了解状态依据。

### 异常 8 · 客户权限发生变化

- 触发条件：用户打开客户详情后失去该客户数据权限。
- 判断依据：客户详情接口重新校验数据权限。
- 系统反馈：页面级提示"暂无权限"，不返回客户数据。
- 用户出口：用户无处理路径，由现有权限体系承接。

### 异常 9 · 上游商机同步异常（系统处理）

- 触发条件：三室产品系统延迟、补发、重复同步或缺少商机生成时间。
- 判断依据：技术方案幂等识别与字段校验。
- 系统反馈：后台告警，用户无直接感知；重复同步不生成新商机、不重置生效时间；缺少商机生成时间时同步失败并告警，不生成不完整商机。
- 用户出口：由双方技术方案保证幂等与告警处理。
