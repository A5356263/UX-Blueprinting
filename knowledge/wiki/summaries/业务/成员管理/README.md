## 3. 覆盖内容

本文件覆盖成员管理域知识库的组织与维护规范：

- 目录组成：领域总览层 -> 成员接入与退出层（加入与邀请、退出与离职交接）-> 成员分类治理层（成员分组、外部人员）
- 阅读顺序：00_领域概述 -> 10_成员加入与邀请 -> 11_成员退出与离职交接 -> 12_成员分组 -> 13_外部人员
- 维护原则：
  - 只记录成员身份接入、成员分类和成员关系变化知识
  - 不在本目录中写组织主数据、组织视图或平台组织底座规则
  - 涉及多维组织时，只记录"成员挂载到组织底座"的边界事实，不越界描述组织建模
  - 新知识优先落到对应编号模块，不回写为大一统长文
- 迁移原则：
  - 先保证成员生命周期主链路清晰，再补充分类与特殊成员场景
  - 与组织域交叉时保持分域，避免把组织底座写入成员域

## 4. 可直接使用的稳定结论

- 成员域知识库按三层组织：领域总览层 -> 成员接入与退出层 -> 成员分类治理层。
- 成员域与组织域的硬分界：成员域只写成员身份与关系变化，不写组织主数据、组织视图或底座建模。
- 新增材料按编号模块补齐，不写成长文或复述组织域的职责。
