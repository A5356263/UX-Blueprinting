## 1. 知识定位

这是一份成员加入与邀请能力的描述卡，用来回答"成员如何进入企业、有哪些邀请方式、每种方式的路径与规则差异是什么"。

它帮助后续任务判断成员加入链路的设计完整性、不同邀请方式的适用场景，以及快速加入企业的开关行为。

## 2. 任务触发线索

当任务属于以下情况时，应优先读取本文件：

- 需要了解成员加入企业的完整流程（注册 -> 加入 -> 分配权限）
- 需要选择或设计成员邀请方式（手机号 / 二维码 / 快速加入）
- 需要评估不同邀请方式的审批要求差异
- 需要分析成员加入体验中的摩擦点（如等待邀请、审批环节）
- 需要理解"快速加入企业"开关对员工入职流程的影响

## 3. 覆盖内容

本文件覆盖成员加入与邀请的完整能力面：

- 三阶段模型：用户完成平台注册 -> 用户加入企业 -> 管理员为用户分配权限
- 手机号邀请：
  - 路径：管理后台 -> 成员管理 -> 成员 -> 添加成员 -> 手机号邀请
  - 支持发送短信提醒，用户登录后弹窗确认加入
- 二维码 / 链接邀请：
  - 路径：管理后台 -> 成员管理 -> 成员 -> 添加成员 -> 二维码邀请
  - 用户扫码/点击链接发起申请，管理员审批通过后加入
- 快速加入企业：
  - 路径：管理后台 -> 成员管理 -> 成员设置 -> 快速加入企业
  - 开启后：HR/管理员在花名册导入含手机号的员工资料，员工登录后默认收到邀请
  - 关闭后：必须管理员主动邀请
- 员工侧操作：有邀请时直接点击加入，无邀请时需等待管理员或主动联系

## 4. 可直接使用的稳定结论

- 成员加入企业有三条路径：手机号邀请、二维码/链接邀请、快速加入企业。
- 手机号邀请无需审批，用户登录后弹窗确认即可加入。
- 二维码/链接邀请需要管理员审批，与手机号邀请的即时性不同。
- 快速加入企业是一个开关型设置，影响花名册导入时是否自动触发邀请。
- 无论哪种方式，权限分配均在加入后由管理员单独完成，不是邀请流程的一部分。
