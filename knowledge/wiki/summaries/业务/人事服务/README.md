## 1. 知识定位

人事服务域知识库的目录入口，提供子域结构总览、阅读顺序和维护原则。解决"从哪个子域开始看、各子域对应什么产品模块"的导航判断问题。

## 2. 任务触发线索

- 首次进入人事服务域知识库，需要了解整体结构时
- 需要确定某个具体问题应该查阅哪个子域时
- 判断新增知识应归入哪个子域目录时
- 评估各子域的知识入库状态时

## 3. 覆盖内容

- **子域目录**：org_management（组织管理）、employee_management（员工管理）、recruitment（招聘管理）、attendance（假勤管理）、customer_management（客户管理），共5个子域
- **阅读顺序**：00_领域概述 → 按需深入各子域
- **入库状态**：招聘管理和客户管理已入库；组织管理、员工管理、假勤管理为部分入库
- **维护原则**：按帮助中心产品模块结构组织，保持与用户可见产品语言一致；不交叉写入其他一级模块知识；新知识优先落到对应子域

## 4. 可直接使用的稳定结论

- 5个子域均对应薪福通帮助中心"人事服务"下的产品模块，结构直接映射
- 知识来源统一为 help/modules/人事服务/，均属于帮助中心采集产物
- 子域知识不覆盖与其他一级模块（如协同办公、费用管理）交叉的内容
- 当前为部分入库状态，假勤管理仅产品介绍入库，需注意信息完整性
