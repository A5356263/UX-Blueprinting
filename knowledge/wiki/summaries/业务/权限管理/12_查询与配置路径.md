## 1. 知识定位

这是一份权限域的查询与配置路径卡，用来回答“当前哪些查询路径和配置路径已经可行、哪些只是部分可行、哪些仍存在结构性缺口”。

它既是路径索引，也是可行性说明卡。

## 2. 任务触发线索

当任务需要确认某类权限问题应该从哪里查、从哪里配，或者需要说明某条查询/配置链路是否已经闭环时，应优先读取本文件。

它也适合用于识别当前权限域的查询缺口。

## 3. 覆盖内容

本文件覆盖权限域的主要查询路径和配置路径，重点包括：

- 查询路径：
  - 按用户查：`权限查询 -> 按用户查询结果 -> 权限详情`，可行
  - 按角色查：依赖 `角色管理`，仅部分可行
  - 按应用查：`应用管理 -> 应用设置页`，可行
  - 按变更查：跨权限域与审批域，部分可行
  - 按权限查 / 按功能点查：当前仍有明确缺口
- 配置路径：
  - 用户配置：`用户授权 -> 功能授权 -> 数据授权`
  - 角色配置：`角色管理 -> 功能权限 / 数据权限 -> 授权规则`
  - 治理配置：`权限管理模式 -> 子管理 / 双管理员 / 权限变更审批`
  - 协作配置：`成员协作权限`
  - 应用配置：`应用管理 -> 应用设置页`
- 现状缺口：
  - 按权限查 / 按功能点查的结果承载待核实
  - 按角色查的独立查询语义与视图未完全明确
  - 按变更查在权限域内缺少统一变更台账页

## 4. 可直接使用的稳定结论

- 权限域必须同时区分“查询路径”和“配置路径”，两者不能混写成单一入口。
- 当前最完整的解释链路是按用户查询；按角色查、按变更查仍存在部分缺口。
- 用户授权、角色配置、治理配置、协作配置、应用配置是五类稳定配置主路径。
- 权限域当前还缺一个统一的按变更查台账视图，且按权限查承载仍待核实。
- 路径是否存在，不等于对应语义已经完整闭环，summary 需要显式写出 `feasible` / `partial` / `[GAP]` 这类状态。

- [GAP] 按权限查 / 按功能点查现状承载待进一步核实

- [GAP] 按变更查当前分散在权限域与审批域之间，权限域内缺少统一变更台账页
