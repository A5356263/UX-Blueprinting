## 1. 知识定位

薪福通产品优势归纳与服务模式描述文档，从专业、智能、开放、安全四大维度阐述平台核心竞争力，并说明三位一体专属服务模式。用于对外沟通、销售材料、竞品对比等场景，也帮助内部团队理解平台差异化价值。

## 2. 任务触发线索

- 需要阐述或引用薪福通平台优势（专业/智能/开放/安全）时
- 需要了解平台安全保障能力与资质认证时
- 需要了解客户服务模式（三位一体微信服务群）时
- 做竞品对比、销售材料、产品介绍、方案应标时
- 需要理解平台覆盖的行业和服务闭环时

## 3. 覆盖内容

**五大维度**：专业（行业化解决方案 / 覆盖制造业/零售连锁/国企/科技/人力资源/医院等 / 员工管理→考勤→薪社税代发→差旅报销→对公报账闭环 / 集团多层级适配）、智能（AI小云智能助手 / 高频业务场景数字化智能助手能力）、开放（开放平台 / CodeFriend低代码 / 智数平台 / 灵活搭建与集成）、安全（银行级安全 / 加密/租户隔离/数据灾备/同城多点多活/TLS1.2-1.3 / CQC A级 / ISO20000 / 等保三级）、三位一体服务模式（每客户专属微信群 / 1客户经理+1服务顾问+1产品专家 / 系统演示/问题解答/实施配置/需求反馈/使用报告/满意度跟踪）。

## 4. 可直接使用的稳定结论

- 五大产品优势：专业、智能、开放、安全、三位一体服务
- 行业覆盖（至少）：制造业、零售连锁、国有企业、科技、人力资源、医院
- 服务闭环链路：员工管理→人事考勤→薪社税代发→差旅报销→对公报账
- 安全资质：CQC A级、ISO20000、等保三级
- 安全措施：加密、租户隔离、数据灾备、同城多点多活、TLS1.2/1.3传输保护
- 三位一体服务：专属微信群含1客户经理+1服务顾问+1产品专家
- 服务内容覆盖六项：系统演示、问题解答、实施配置、需求反馈、使用报告、满意度跟踪
