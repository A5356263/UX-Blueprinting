## 1. 知识定位

这是一份企业登录页自定义能力的描述卡，用来回答"企业如何获得专属登录页、支持哪些端、可配置哪些项目"。

它帮助后续任务理解登录页个性化的开通方式、Web/H5 两端的配置差异，以及配置后对用户登录体验的影响。

## 2. 任务触发线索

当任务属于以下情况时，应优先读取本文件：

- 需要了解企业登录页自定义的开通方式
- 需要设计登录页的品牌化方案
- 需要区分 Web 端和 H5 端的可配置项差异

## 3. 覆盖内容

- 维护入口：管理后台 -> 企业设置 -> 企业文化 -> 企业登录页配置
- 开通方式：需联系专属客户经理或服务人员申请开通
- 支持范围：Web 登录页、H5 登录页
- Web 端可配置项：登录背景图、网页名、登录方式、按钮展示方式
- H5 端可配置项：应用名、网页标签、按钮展示方式
- 使用效果：未配置时使用平台官方默认登录/注册页，配置后企业用户需通过指定地址访问专属登录页

## 4. 可直接使用的稳定结论

- 企业登录页自定义不是默认开放能力，需要联系客户经理或服务人员申请开通。
- Web 端和 H5 端的可配置项不同：Web 端多出"登录背景图"和"登录方式"两项。
- 配置后企业用户需通过指定地址访问专属登录页，不再使用平台通用登录页。
