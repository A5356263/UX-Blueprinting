## 2. 任务触发线索

当任务涉及以下问题时，应优先读取本 summary，并按需回查 raw：

- 需要了解成员域的整体结构和阅读路径时

- 需要了解成员域知识的维护和迁移原则时

## 3. 覆盖内容

本 raw 覆盖：

- 成员域的组成结构和各模块说明
- 推荐阅读顺序：领域总览 -> 成员接入与退出 -> 成员分类治理
- 维护原则：只记录成员身份/分类/关系变化，不写组织主数据或后台权限规则
- 迁移原则：优先保证成员生命周期主链路清晰，再补充分类与特殊场景

不涉及：

- 具体的业务规则和操作流程（需查各子模块 raw）

## 4. 可直接使用的稳定结论

- 成员域由 5 个子模块组成：领域总览、成员加入、成员退出、成员组、外部人员
- 推荐按「领域总览 -> 接入退出 -> 分类治理」顺序阅读
- 成员域不承载组织主数据，与组织域交叉时保持分域
- 新知识优先落到对应编号模块，不写回大一统长文
- 后续新增材料按编号模块继续补齐，不额外创建新文件
