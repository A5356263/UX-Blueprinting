## 1. 知识定位

描述企业专属登录页的配置方式、可配置项和开通流程，回答「企业如何获得专属登录页」这一判断问题。

## 2. 任务触发线索

当任务涉及以下问题时，应优先读取本 summary，并按需回查 raw：

- 需要为企业配置专属登录页时
- 需要了解 Web 和 H5 登录页各自可配置哪些内容时
- 需要了解专属登录页的开通方式时
- 需要了解配置前后的使用差异时

## 3. 覆盖内容

本 raw 覆盖：

- 开通方式：需联系专属客户经理或服务人员申请开通
- 支持范围：Web 登录页、H5 登录页
- Web 可配置项：登录背景图、网页名、登录方式、按钮展示方式
- H5 可配置项：应用名、网页标签、按钮展示方式
- 使用效果：未配置时使用官方默认页，配置后企业用户需通过指定地址访问

不涉及：

- 联系客户经理的具体流程
- 配置审核的流程

## 4. 可直接使用的稳定结论

- 维护入口：管理后台 -> 企业设置 -> 企业文化 -> 企业登录页配置
- 该能力需联系专属客户经理或服务人员申请开通
- 支持 Web 和 H5 两类登录页的独立配置
- Web 页面可配：背景图、网页名、登录方式、按钮展示方式
- H5 页面可配：应用名、网页标签、按钮展示方式
