## 3. 覆盖内容

本 raw 覆盖：

- 组织域的组成结构和各模块说明
- 推荐阅读顺序：领域总览 -> 组织架构 -> 结构主数据（法人公司、成本中心）
- 维护原则：只记录企业结构主数据及其业务语义和边界，不写成员接入和权限授权
- 迁移原则：优先保证组织主干知识稳定，再逐步补充结构扩展维度

不涉及：

- 具体的业务规则和操作流程（需查各子模块 raw）

## 4. 可直接使用的稳定结论

- 组织域由 4 个子模块组成：领域总览、组织架构、法人公司、成本中心
- 推荐按「领域总览 -> 组织架构 -> 结构主数据」顺序阅读
- 组织域只承载企业结构主数据，不承载成员接入和成员分类治理
- 与成员域交叉时保持分域，不混写身份治理知识
- 新知识优先落到对应编号模块，不写回大一统长文
