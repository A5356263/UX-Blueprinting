# 16_employment_lifecycle

任职管理覆盖员工从入职到离职的全生命周期人事异动，支持全流程在线申请和审批。

- 来源：help/modules/人事服务/员工管理/
- 来源类型：帮助中心产品介绍 + 入职/协同操作指引
- 最近更新：2026-05-05

## 1. 人事异动类型

系统支持以下异动场景：
- 入职、转正、调动、兼任、临时调店、离职

## 2. 入职设置

路径：【员工管理-员工管理设置-基础设置-任职管理设置-入职设置】

### 2.1 入职流程设置
四项流程均可独立开启或关闭：
1. HR新增待入职
2. 员工扫码登记
3. 入职审批
4. 确认入职

### 2.2 扫码登记设置
- 可选择员工扫码时是否进行身份验证
- 可选择是否限制待入职人员扫码

### 2.3 待入职字段设置
勾选员工入职过程中需要填写的字段（按需选择）

### 2.4 入职事项设置
员工入职后可选择开启或关闭提示办理该事项。

### 2.5 新版本独有功能
- 入职年龄设置（避免用工风险）
- 自动确认入职（入职日期当天自动确认）

## 3. 入职办理

路径：【人事服务-员工管理-入职管理】

### 方式一：扫码登记（员工自助）
- 点击"新增待入职" → "录入基本信息并邀请员工补充"
- 选择"扫码登记"
- 分享二维码或复制链接给员工
- 由待入职员工填写并提交

### 方式二：手工录入
- 点击"添加待入职" → "录入待入职信息"
- 手工录入员工信息并提交

## 4. 入职协同

### 4.1 权限开启
路径：【管理后台-通用权限设置-用户授权-员工管理-基础设置】

### 4.2 协同事项设置
路径：【员工管理设置-基础设置-协同事项设置】

**系统预置事项（8类）：**
| 事项 | 默认启用 |
|------|---------|
| 合同签订 | ✓ |
| 考勤组设置 | ✓ |
| 考勤机设置 | ✓ |
| 生物特征采集 | ✓ |
| 社保方案 | ✓ |
| 入职定薪 | |
| 薪资组 | |
| 个税档案 | |

- 系统事项不支持删除，仅支持不启用（关闭启用开关）
- 可创建自定义事项，关联自定义字段和行政信息分组字段
- 配置仅对设置完成后的新入职员工生效

### 4.3 发起与处理
- 管理员确认员工入职后，系统根据设置的协同事项推送待办至工作台或手机提醒
- 协同事项看板展示每个入职事项办理进度
- 系统自动检查记录，有数据时自动更新为"已处理"
- 全部事项为已处理时，办结状态为"已办结"

### 4.4 协同看板时间字段
- 生成时间 = 员工确认入职后生成入职事项记录的时间
- 办结时间 = 最后一个入职事项完成的时间
- 办结周期 = 全部入职事项完成所耗总时长

## 5. 任职信息轻管理模式

用于简化员工任职信息管理流程，减少不必要的字段填写，提升HR操作效率。适用场景：人事管理需求相对简单的企业。

## 6. 任职记录

- 完整的任职记录查询
- 历史任职变动可追溯
- 入离职数据源为主岗任职记录（快照）

## 7. 证明开具

四种类型：转正通知、在职证明、离职证明、收入证明。

功能特点：
- 自定义模板
- 选择员工后系统自动填充信息
- 系统内直接电子签署
- 员工移动端发起申请
- 新版支持自定义打印

## 8. 招聘→入职衔接

Moka Offer后手动同步至待入职模块（参见 recruitment/10_recruitment_management）
