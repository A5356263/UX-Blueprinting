# organization

## 这是什么

这是平台组织底座知识库的结构化目录，用于沉淀多维组织、职能、视图、组织范围生成以及旧组织能力迁移后的领域知识。

## 怎么用

- 先读 `00_domain_overview.md` 了解组织域边界已经从“结构主数据”升级为“平台组织底座”
- 再读 `10_organization_architecture.md`、`11_legal_entities.md` 了解旧组织对象如何归位到新底座
- 再读 `13_function_and_view_model.md`、`14_member_binding_and_scope_generation.md` 理解职能、视图、成员挂载、组织范围生成
- 最后读 `15_runtime_flow_and_legacy_mapping.md` 把初始化、发布、过滤、业务消费与菜单重构串成完整主流程

## 阅读顺序

1. 领域总览层
2. 旧对象归位层
3. 平台底座模型层
4. 运行流转与迁移层

## 维护原则

- 优先记录平台组织底座中的稳定对象、关系、状态和迁移语义
- 旧组织能力进入新底座后，按“职能 -> 视图”结构表达，不再回到旧菜单语义
- 组织与成员必须分域表达，不把成员生命周期写成组织知识
- 涉及权限与业务消费时，只记录组织域作为上游输入的事实，不代写权限规则或业务规则
- 当前材料没有明确证据的关系不新增，必要时使用 `[GAP]` 标记

## 迁移原则

- 先保证平台组织底座主模型清晰，再补充旧能力迁移与消费链路
- 与成员域交叉时，明确“成员独立成域、挂载到多维组织”的边界
- 与权限域交叉时，只描述组织范围和视图作为上游输入，不越界定义授权合同
- 后续新增平台组织材料按编号模块继续补齐
