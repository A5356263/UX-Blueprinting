# 00_领域概述

## 领域定义

考勤管理领域回答的是：
企业如何通过薪福通平台完成排班、打卡、请休假、加班、异常处理、考勤核算与考勤确认的全流程管理。

它覆盖的不是单一考勤动作，而是一整套与考勤结果相关的业务语义，包括：

- 排班管理
- 多种打卡方式
- 假期管理
- 加班管理
- 考勤核算与确认

## 解决的问题

考勤管理领域主要用于解释以下问题：

- 企业如何配置排班规则
- 员工如何通过多种方式完成打卡
- 请假、休假、加班的规则如何设定与审批
- 考勤数据如何核算并同步至算薪

## 为什么独立成域

考勤管理需要独立沉淀，是因为它同时具备以下特征：

- 有独立的业务流程：排班 → 打卡 → 异常处理 → 考勤核算 → 考勤确认
- 与智能算薪深度集成，考勤数据是薪资计算的关键输入
- 涉及与钉钉/企微等外部平台的单点登录和第三方打卡信息 API 同步
- 规则配置性强，排班、假期、加班等均有独立的规则体系

## 与上游领域的关系

- 与智能算薪深度集成：考勤数据实时同步至薪资计算
- 与钉钉/企微对接：单点登录、第三方打卡信息 API 同步
- 与审批域交叉：请假、加班等需要审批流支持

这里描述的是上游依赖事实，不等于具体规则已经由其他领域定义完成。

## 稳定结论

- 考勤管理是薪资计算的关键上游数据来源
- 其核心价值是为考勤规则配置、打卡数据采集和考勤核算提供稳定输入
- 它可以服务业务分析、产品设计、体验解释和排障分析，但本文件本身不承载下游消费说明
