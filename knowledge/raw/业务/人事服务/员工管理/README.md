# 员工管理

## 这是什么

这是员工管理子域的二级路由入口，用来说明这个目录里各编号段分别承载什么知识、遇到什么问题该优先看哪些文件。

它不承载正式业务事实正文，也不承载主链路消费说明。

## 编号段

- `00-09`：领域定义、范围与边界
- `10-19`：员工花名册、合同管理、任职异动与证明开具
- `50-59`：常见问题与异常排障

## 任务触发索引

- 需要理解员工管理子域的边界与覆盖范围：读 `00_领域概述.md`
- 需要理解花名册与员工关怀：读 `14_员工花名册.md`
- 需要理解合同管理（纸质/电子合同）：读 `15_合同管理.md`
- 需要理解任职异动与证明开具：读 `16_入职生命周期.md`
- 需要排查常见问题：读 `50_常见问题.md`

## 与成员域的关系

成员接入/退出/成员组等基础知识保留在 `knowledge/raw/业务/成员管理/` 中。本子域仅包含帮助中心"员工管理"模块中的产品知识。

## 维护原则

- README 只做领域内路由，不写正式业务规则正文
- 正式业务事实写入对应编号文件
- 不在本目录中写成员身份治理的通用抽象概念（这些保留在成员域）
- 不在本目录中沉淀主链路消费地图、蓝图移交说明或下游执行指令
- 做结构替换时不保留兼容层，确认替换后直接移除旧知识位
