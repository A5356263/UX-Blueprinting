# 组织架构

## 这是什么

这是平台组织底座知识库的二级路由入口，用来说明这个目录里各编号段分别承载什么知识、遇到什么问题该优先看哪些文件。

它不承载正式业务事实正文，也不承载主链路消费说明。

## 编号段

- `00-09`：领域定义、范围与边界
- `10-19`：多维组织、法律实体、成本中心、职能与视图模型、成员绑定与范围生成、运行时流程与遗留映射

## 任务触发索引

- 需要理解组织域边界已经从"结构主数据"升级为"平台组织底座"：读 `00_领域概述.md`
- 需要理解旧组织对象如何归位到新底座：读 `10_组织架构设计.md`、`11_法律实体.md`、`12_成本中心.md`
- 需要理解职能、视图、成员挂载、组织范围生成：读 `13_职能与视图模型.md`、`14_成员绑定与范围生成.md`
- 需要理解初始化、发布、过滤、业务消费与菜单重构的完整主流程：读 `15_运行时流程与遗留映射.md`

## 维护原则

- README 只做领域内路由，不写正式业务规则正文
- 正式业务事实写入对应编号文件
- 优先记录平台组织底座中的稳定对象、关系、状态和迁移语义
- 组织与成员必须分域表达，不把成员生命周期写成组织知识
- 涉及权限与业务消费时，只记录组织域作为上游输入的事实，不代写权限规则或业务规则
- 不在本目录中沉淀主链路消费地图、蓝图移交说明或下游执行指令
- 做结构替换时不保留兼容层，确认替换后直接移除旧知识位
