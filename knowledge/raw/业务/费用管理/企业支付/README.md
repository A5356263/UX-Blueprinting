# 企业支付

## 这是什么

这是企业支付（对公报账）子域的二级路由入口，用来说明这个目录里各编号段分别承载什么知识、遇到什么问题该优先看哪些文件。

它不承载正式业务事实正文，也不承载主链路消费说明。

## 编号段

- `00-09`：领域定义、范围与边界
- `10-19`：企业支付全流程产品知识（供应商、合同、付款申请、对公付款）

## 任务触发索引

- 需要理解企业支付子域的边界与覆盖范围：读 `00_领域概述.md`
- 需要理解企业支付产品功能：读 `10_企业支付.md`

## 维护原则

- README 只做领域内路由，不写正式业务规则正文
- 正式业务事实写入对应编号文件
- 新知识优先落到对应编号模块
- 不在本目录中沉淀主链路消费地图、蓝图移交说明或下游执行指令
- 做结构替换时不保留兼容层，确认替换后直接移除旧知识位
