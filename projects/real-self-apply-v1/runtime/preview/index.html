页面摘要

在一个上下文完整的抽屉里完成“选申请对象 -> 填申请原因 -> 提交审批”。

关键理解

  • 主任务是提交角色或功能权限申请；次任务是查看申请限制和申请记录。
  • 申请人是谁、当前申请的是角色还是功能权限、允许申请的范围是什么。
  • 申请原因必填、功能权限申请默认连同所有数据权限一起申请、范围外对象不可提交。
  • 不要把“范围外不可申请”误解成系统故障；不要误以为提交后立即生效。
