# 领域：平台门户

## 底层基座

- 应用目录
- 身份识别
- SSO
- 角色可见性
- 菜单 / 卡片分组
- 跨端工作台
- 收藏 / 常用
- 深链分发

## 核心链路

身份识别 → 入口分发 → 应用启动 → 任务返回 → 常用沉淀

## 关键元数据

- 应用类型
- 端类型
- 分组
- 可见范围
- 收藏状态
- 深链参数
- 租户
- 应用 ID

## 高复杂度触发点

- 改角色化可见性模型
- 改 SSO / 应用分发
- 统一桌面端、移动端、微信侧门户规则
- 从静态菜单改成可配置工作台
- 引入卡片 / 自建应用体系
- 跨企业 / 集团共享应用
- 改应用启动上下文和深链规则

## 中等复杂度触发点

- 新增导航分组
- 新增角色首页
- 新增常用入口
- 新增推荐卡片
- 新增搜索聚合
- 在现有门户挂入新入口，但不改身份、权限和应用分发规则

## 低复杂度触发点

- 图标
- 卡片尺寸
- 分组名称
- 入口排序
- 首页文案
- 引导页
- 视觉强调

## UXB 判断提醒

- 不因为“门户、首页、应用入口”直接判复杂。
- 先看是否改角色可见性、身份识别、应用分发或跨端规则。
- 纯卡片布局和排序按低复杂度处理。
- 如果需求是“按角色展示不同首页”，先确认它只改展示，还是同时改变应用可见性和入口分发规则。
