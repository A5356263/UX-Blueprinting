## 任务概述

本次需求要解决的问题：当前企业员工权限由管理员或超管集中分配。在中大型企业中，员工数量多、流动性大，集中分配和核对的工作量很大，效率和时效都有提升空间。本次计划支持员工自行申请权限、自行核对权限，将分配和核对工作分散到员工端。

涉及角色：
- 超级管理员 / 权限管理员：当前集中分配权限的人，本次需要开启和配置"自助申请权限模式"
- 员工：权限的使用者，本次需要能查看自己的权限、提交权限申请
- 审批人：员工提交申请后，负责审批的人（预设为员工所在组织的组织负责人）
- 实施/运维同事：企业的对接方，关注功能的推广可行性和培训成本

主要场景：管理员开启自助申请权限模式并配置可申请的范围和审批流程 → 员工在个人中心查看自己的权限 → 员工提交权限申请 → 审批人审批 → 通过后自动分配权限。

## 功能范围

### 3.1 自助申请权限模式（优先级：中）

由超管专属的功能。在权限管理模式中新增"自助申请权限模式"入口。

**启用前校验**：点击"立即启用"时，需校验"双管理员互审模式"和"权限变更审批模式"是否已开启。如果任一已开启，则阻断启用并提示冲突。通过后进入设置页，此时模式仍未正式开启。

**设置页包含三个步骤**：

第一步 — 选择申请方式：两个互斥选项——"申请角色"或"申请功能权限"。默认选中"申请角色"。此选择决定后续员工申请页展示哪种申请内容。

第二步 — 配置可申请范围：
- 如果选了"申请角色"，则设置角色范围：全部角色或部分角色。部分角色需弹窗选择，支持搜索、分页、展示角色名称/说明/状态。角色范围包含已启用和已停用角色。可设置"后续新增角色自动加入"（默认勾选）。
- 如果选了"申请功能权限"，则设置应用范围：全部应用或部分应用。部分应用需弹窗选择，支持搜索、分页、展示应用名称/终端/启用状态。应用范围包含已添加的应用（含已启用和已停用）。可设置"后续新增应用自动加入"（默认勾选）。

第三步 — 配置审批流程：系统预设审批人为员工所在组织的组织负责人。可点击"修改审批流程"跳转到表单编辑页。

启用：再次校验互斥模式，通过后 toast 提示成功，页面刷新为已开启状态，个人中心增加"我的权限"入口，员工提交申请后可发起审批流程。

**已开启状态**：页面变为不可编辑，展示"关闭模式"和"编辑"按钮。关闭模式需二次确认，如存在在途审批流程则关闭失败。编辑进入可编辑状态，底部出现"取消编辑"和"确认编辑"按钮。

### 3.2 我的权限（优先级：中）

"我的权限"是个人中心的新增功能。仅在开启"自助申请权限模式"的企业中展示，无需额外授权，属于全员功能。服务人员无此入口。入口位于"我的企业"下方。

进入后为独立页面，包含三个 tab：功能权限、数据权限、角色。默认选中功能权限 tab。各 tab 无数据时展示空状态提示。

### 3.3 申请权限（优先级：中）

点击"申请权限"打开抽屉。申请人默认当前用户不可编辑。申请原因必填，最多 500 字。

申请方式取决于管理端的配置——如果配置了"申请角色"，则展示角色列表（仅展示已启用角色）；如果配置了"申请功能权限"，则展示功能权限设置组件，应用范围仅限管理端配置的范围。

申请功能权限时默认申请该功能的所有数据权限，如需部分数据权限需联系管理员。

提交后需校验：资金用户校验、子管理员模式权限校验、特殊身份默认权限、实名要求。

申请记录支持按日期和审批状态筛选，状态包括已通过、已拒绝、审批中、已撤销。审批中的申请可以撤销。

### 3.4 数据埋点（优先级：中）

功能新增，不涉及交互。

### 3.5 操作记录（优先级：中）

功能新增，不涉及交互。

## 关键业务规则

**互斥规则**：自助申请权限模式不能与"双管理员互审模式"和"权限变更审批模式"同时开启。启用时校验，设置完成点击"开启"时再次校验。

**关闭阻断规则**：关闭自助申请权限模式时，如果存在在途的申请审批流程，则关闭失败，提示管理员等待审批完成后再关闭。

**申请范围约束**：员工只能申请管理员在设置中配置的角色或应用范围内的权限。角色范围仅包含已启用的角色；功能权限的应用范围仅限管理端配置的应用。

**审批链路**：员工提交申请后进入审批流程，预设审批人为员工所在组织的组织负责人。

**提交校验规则**：
- 资金用户校验：非资金用户授予"代发付款"时报错
- 子管理员模式权限校验：子管理员不能被授予子管理员模式权限
- 特殊身份默认权限校验
- 实名要求校验

**撤销规则**：仅审批中状态的申请可以撤销，其他状态（已通过、已拒绝、已撤销）不可操作。

**申请记录规则**：申请功能权限时，申请内容展示"查看详情"链接，点击打开静态抽屉；申请角色时，直接展示角色名称。

**自动加入规则**：设置页可选择"后续新增角色/应用自动加入员工可申请范围"，默认勾选。

## 状态流转

**自助申请权限模式的状态**：
- 未启用 → 点击"立即启用" → 校验互斥模式 → 进入设置页（仍未启用）
- 设置页 → 完成配置 → 点击"开启" → 再次校验 → 已开启
- 已开启 → 点击"编辑" → 编辑中（可修改配置）
- 已开启 → 点击"关闭模式" → 确认关闭 → 校验在途流程 → 已关闭（或关闭失败）

**权限申请的状态**：
- 员工提交申请 → 审批中
- 审批人同意 → 已通过（权限自动生效）
- 审批人拒绝 → 已拒绝
- 员工撤销审批中的申请 → 已撤销

**我的权限入口的可见性**：
- 企业开启自助申请权限模式 + 企业下的用户 → 可见
- 企业未开启模式 → 不可见
- 服务人员 → 不可见

## 异常与边界

**启用阻断**：企业已开启"双管理员互审模式"或"权限变更审批模式"时，不能启用自助申请权限模式。提示文案：`企业已开启「双管理员互审模式」，不能同时开启此模式`。用户需要先关闭互斥模式。

**关闭阻断**：关闭模式时，如果当前有申请流程未完成审批，关闭失败。弹窗标题"关闭失败"，正文：`当前有申请流程未完成审批，请联系审批人审批完成，再关闭模式`，按钮"知道了"。

**提交校验失败**：
- 非资金用户申请"代发付款"时报错
- 子管理员申请子管理员模式权限时报错
- 实名要求不满足时报错
- 特殊身份默认权限冲突时报错

**空状态**：我的权限各 tab 无数据时，展示空状态提示——"您没有功能权限"、"您没有数据权限"、"您没有关联的角色"。

**培训成本风险（调研反馈）**：有实施同事认为，超管设置权限只需教 1 人，放给员工申请需要教全员，培训成本高。小企业和流动性大的企业尤其突出。这是产品推广层面的风险，不影响功能本身的实现逻辑。
