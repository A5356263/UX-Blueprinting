# 信息架构与可发现性原则

## IA-01 信息气味（Information Scent）

- 来源：信息觅食理论
- 定义：用户用线索判断入口是否值得点、内容是否匹配预期。
- 触发：导航命名、列表摘要、搜索结果、配置入口。
- 推导输出：入口命名可预测；结果提供范围/来源/状态等线索。
- 文档落点：IA｜命名｜列表信息要求
- 自检问句：用户能否在点击前判断点进去会得到什么？
- 反模式：入口名含糊、点进去才发现不相关。
- 取舍提示：线索太多会噪音，优先关键线索。

## IA-02 分块（Chunking）

- 来源：认知策略
- 定义：按任务与语义分组信息。
- 触发：长表单、规则说明、配置页。
- 推导输出：同组强相关；组与组边界清晰；标题表达组意图。
- 文档落点：信息结构
- 自检问句：用户是否需要来回对照才能理解字段关系？
- 反模式：字段散落、说明与字段分离过远。
- 取舍提示：分块要服务任务顺序，不要只按数据结构分。

## IA-03 单一语义源（Single Source of Meaning）

- 来源：一致性原则延伸
- 定义：同一概念的定义与解释应一致可复用。
- 触发：跨模块复用、多人协作、长期演进。
- 推导输出：术语表与规则表可引用；避免不同处不同解释。
- 文档落点：术语表｜规则库
- 自检问句：同一概念是否出现两套定义？
- 反模式：各模块自行解释，产生漂移。
- 取舍提示：需要治理机制维护“定义源”。
