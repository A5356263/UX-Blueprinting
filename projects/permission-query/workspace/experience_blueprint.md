# Experience Blueprint

> 输入来源：`workspace/facts.md`、`workspace/business_blueprint_lite.md`

## 0. 本次关键设计判断

**判断：**

三个查询维度各自独立承载，共用后台数据源，但前端信息架构不强行统一。核心原则：查得到不够，查得明白才算数。

**主要影响：**

1. 三个查询维度需要三个独立的结果页模板，不是一套模板套三个 tab
2. 权限来源和覆盖规则的可视化展示是整个体验的核心——如果用户看不懂来源和覆盖，查询价值归零
3. 查询只读，不嵌入任何配置操作，查询结果与配置页之间通过导航跳转衔接

**建议方案：**

- 主入口页提供三个查询起点（查人、查角色、查权限），不做通用搜索框
- 每条查询结果标注来源标签、生效状态图标和覆盖说明（如有）
- 查询结果按应用两级聚合（应用 → 权限类型），默认折叠，逐层展开
- 三条查询路径之间支持交叉跳转（如查人结果中点击角色名 → 跳到按角色查）

**不建议方案：**

- 不做一个万能搜索框统一所有查询维度——不同维度的"问题心智"完全不同，强行统一会让每个场景都别扭
- 不在查询结果中嵌入"编辑"或"删除"按钮——查询页与配置页必须保持清晰边界，否则查询页会退化成另一个配置页

**关键待确认：**

1. 查询结果是否支持导出？影响结果页的操作区设计
2. 子管理员的查询数据范围如何控制？影响空状态和权限提示文案
3. 按权限项反查时的权限树粒度？直接影响信息承载量和搜索交互

> 更多待确认问题详见 `## 8. 待确认问题`。

## 1. 旅程图

```md
- 权限管理员：发现需要核对某人权限 → 选择查询维度（按人/按角色/按权限） → 输入查询条件 → 浏览查询结果 → 展开查看详情（来源、时间、操作人） → 如需修改，跳转到对应配置页
- 超级管理员：进行全局权限审计 → 按权限项反查高风险权限持有者 → 查看持有人分布 → 对异常项跳转配置页处理
- 审计人员：定期核对权限分布 → 按人或按权限维度查询 → 如需留档，导出查询结果 → 异常项标记并跟进
```

### 旅程缺口

- 导出功能未确认，审计人员的留档需求在当前旅程中缺少终点
- 子管理员查询范围未确认，如果子管理员只能查管辖范围，需要在旅程起点增加"识别当前可查范围"的节点

## 2. 交互流程总览

**分角色交互流程：**

- 权限管理员：进入权限查询主页 → 选择"按人查询" → 搜索并选择目标用户 → 查看按应用聚合的权限清单（默认折叠） → 2.1 展开应用查看权限明细 → 2.2 点击单条权限查看来源详情 → 如需修改，点击"去配置"跳转用户授权页
- 超级管理员：进入权限查询主页 → 选择"按权限项查询" → 搜索或浏览权限树选择权限项 → 查看持有者列表 → 点击人员进入按人查详情
- 审计人员：进入权限查询主页 → 选择"按角色查询" → 选择目标角色 → 查看权限清单 / 人员列表（双 tab 切换） → 如需留档，导出查询结果

**异常流程重点：**

- 查无结果时：区分"该用户无权限"、"搜索条件无匹配"、"该权限类型暂不支持查询"三种空状态
- 权限来源冲突时：覆盖关系中标注"当前不生效"并解释原因
- 数据缺失时：对应权限类型区域显示"暂不支持"标记，不沉默为空

## 3. 主交互流程

### 节点 1：选择查询维度

**用户动作：**

进入权限查询主页，根据当前任务选择查询入口。

**系统反馈：**

展示三个查询入口卡片：
- 查人："查看某个员工拥有哪些权限"
- 查角色："查看某个角色包含哪些权限和成员"
- 查权限："反查某项权限被哪些人持有"

**需要前置解释的信息：**

每个入口下方附带一句话说明使用场景，如"查人"下方写"适用场景：离职核对、权限排障、入职后验证"。

**建议文案：**

- 页面标题：「权限查询」
- 入口卡片标题：「按人员查询」「按角色查询」「按权限项查询」
- 入口说明：各附加一行适用场景说明

**下一步：**

点击任一入口进入对应查询条件页。

---

### 节点 2：按人查询 —— 输入条件

**用户动作：**

在搜索框中输入员工姓名或 ID，从下拉建议中选择目标用户。

**系统反馈：**

- 搜索框支持模糊搜索（姓名、工号、邮箱）
- 下拉建议展示匹配的用户列表（头像 + 姓名 + 部门）
- 选择用户后，自动加载查询结果

**需要前置解释的信息：**

搜索框下方提示："可搜索姓名、工号或邮箱"，空状态时提示："请输入关键词搜索员工"。

**建议文案：**

- 搜索框占位符：「输入姓名、工号或邮箱搜索」
- 空状态：「请输入关键词搜索员工」
- 无匹配：「未找到匹配的员工，请尝试其他关键词」

**下一步：**

选择用户后进入节点 3（查看查询结果）。

---

### 节点 3：按人查询 —— 查看结果

**用户动作：**

浏览按应用聚合的权限清单，逐层展开查看详情。

**系统反馈：**

- 页面顶部：用户基本信息条（头像 + 姓名 + 部门 + 岗位）
- 主体区域：应用列表，每个应用一行，显示应用名称和权限数量
- 展开应用：按权限类型（功能权限 / 数据权限 / 表单权限 / 字段权限 / 报表权限）分组展示
- 每条权限：权限名称 + 来源标签 + 生效状态图标
- 来源标签样式区分：直授（蓝色）、角色继承（绿色）、应用可见性（灰色）、协作规则（橙色）
- 生效状态：已生效（绿色勾）、未生效（灰色圈）、覆盖不生效（橙色感叹号）

**需要前置解释的信息：**

- 在结果区顶部放置图例说明："来源标签说明：蓝色=直授，绿色=角色继承，灰色=应用可见性，橙色=协作规则"
- 覆盖规则说明放在受影响条目的 tooltip 中

**建议文案：**

- 来源标签文案：「直授」「角色：财务主管」「应用可见性（当前不生效）」
- 覆盖说明：「该权限来自角色授权，但因应用不可见，当前不生效」
- 展开/折叠操作：「展开全部」/「收起全部」

**下一步：**

- 点击单条权限 → 节点 4（查看权限详情）
- 点击角色标签 → 跳转按角色查

---

### 节点 4：按人查询 —— 权限详情面板

**用户动作：**

点击某条权限，从右侧滑出详情面板。

**系统反馈：**

详情面板展示：
- 权限名称和当前生效状态
- 来源链路：一条时间线展示该权限的获取路径（如"2025-03-15 由管理员张三通过用户授权添加" → "2025-04-01 因角色变更覆盖为不生效"）
- 完整来源列表：列出所有授予该权限的来源，标注优先级
- 操作人：每次变更的操作人和时间
- 审批记录：如有审批，展示审批编号和审批状态

**建议文案：**

- 面板标题：「权限详情」
- 来源链路标题：「权限来源链路」
- 无来源链路变化时：「该权限仅有一个来源，无覆盖关系」
- 跳转按钮：「前往配置」

**下一步：**

点击「前往配置」→ 打开新标签页跳转到对应的配置页（用户授权 / 角色管理）。

---

### 节点 5：按角色查询

**用户动作：**

搜索并选择目标角色，查看权限清单和人员列表。

**系统反馈：**

- 页面顶部：角色基本信息（角色名称、角色描述、关联成员数）
- Tab 切换：「权限清单」和「人员列表」
- 权限清单 Tab：按应用聚合展示该角色包含的所有权限，格式与按人查结果一致
- 人员列表 Tab：表格展示持有该角色的所有人员（姓名 + 部门 + 获得方式：手动分配 / 规则自动授予）

**建议文案：**

- 权限清单 Tab：「权限清单（共 X 项）」
- 人员列表 Tab：「人员列表（共 X 人）」
- 获得方式：「手动分配」「规则自动授予（组织负责人）」

**下一步：**

- 权限清单中点击单条权限 → 详情面板
- 人员列表中点击人员 → 跳转按人查

---

### 节点 6：按权限项反查

**用户动作：**

通过搜索或浏览权限树选择目标权限项，查看持有者列表。

**系统反馈：**

- 权限选择区：搜索框 + 按应用组织的权限树（树形选择器或级联选择）
- 选择权限项后，下方展示持有者列表：表格展示（姓名 + 部门 + 获得方式 + 来源角色 + 授权时间）
- 高危权限项（导出、删除、批量操作等）的行首有红色标记
- 支持按组织范围过滤（仅看某部门内的持有者）

**建议文案：**

- 权限搜索占位符：「搜索权限项名称」
- 权限树空状态：「请选择或搜索权限项开始查询」
- 持有者列表空状态：「该权限项当前无人持有」
- 高危标记提示：「此权限为高危操作权限，请谨慎核对」

**下一步：**

- 点击持有者姓名 → 跳转按人查
- 点击来源角色 → 跳转按角色查

## 4. 次交互流程

### 交叉跳转

三条查询路径之间通过标签和链接互相跳转：
- 按人查结果中的角色标签 → 点击跳转按角色查
- 按角色查人员列表中的姓名 → 点击跳转按人查
- 按权限项反查结果中的姓名 → 点击跳转按人查
- 按权限项反查结果中的角色 → 点击跳转按角色查

### 查询历史

- 在查询主页底部或侧边展示"最近查询"，方便管理员快速回到上次查询
- 最多保留 5 条，点击直接加载该查询维度和条件
- 查询历史仅本地存储，不跨设备同步（考虑安全）

### 查询结果导出（如确认支持）

- 在结果页右上角放置"导出"按钮
- 点击后弹出导出选项：导出当前页（PDF / Excel）
- 导出需记录操作日志（谁在什么时间导出了谁的权限数据）

## 5. 异常与阻断流程

### 异常 1：查无结果 —— 用户无权限

**发生时机：** 按人查询时，选择用户后
**触发条件：** 该用户未被分配任何权限
**判断依据：** 来自 facts.md 异常与边界第 1 条、business_blueprint_lite.md 第 4 节异常第 1 条
**反馈形式：** 页面空状态
**系统反馈：** 空状态插图 + 文案"该用户暂未分配任何权限" + 可能原因提示："请确认该用户是否已完成企业注册和权限分配。如需为其授权，可前往用户授权页。"
**用户下一步：** 点击"前往用户授权"跳转配置页，或返回查询主页选择其他查询

---

### 异常 2：查无结果 —— 权限项无人持有

**发生时机：** 按权限项反查时，选择权限项后
**触发条件：** 该权限项当前未被授予任何人
**判断依据：** 来自 facts.md 异常与边界、business_blueprint_lite.md 第 2 节规则
**反馈形式：** 结果区空状态
**系统反馈：** "该权限项当前无人持有。如果这是预期内的权限项，可在角色管理或用户授权中分配。"
**用户下一步：** 返回权限项选择，或跳转配置页

---

### 异常 3：权限来源冲突 / 覆盖不生效

**发生时机：** 查询结果中包含多来源权限时
**触发条件：** 同一权限存在多个来源，最终只有部分生效（对应 RISK-003）
**判断依据：** 来自 business_blueprint_lite.md 第 2 节、knowledge/raw/业务/权限管理/30_体验风险模式.md 中的 RISK-003
**反馈形式：** 权限条目旁橙色感叹号图标 + tooltip 说明
**系统反馈：** 不生效的权限条目显示为灰色 + 删除线，tooltip 说明覆盖原因："该权限来自角色「财务主管」授权，但因应用「财务系统」整体不可见，当前不生效。如需生效，请先前往应用管理调整可见范围。"
**用户下一步：** 点击 tooltip 中的"前往应用管理"跳转，或忽略

---

### 异常 4：权限类型暂不支持查询

**发生时机：** 查询结果中涉及数据查询链路未打通的权限类型时
**触发条件：** 报表权限或其他外部系统权限的查询链路未打通
**判断依据：** 来自 business_blueprint_lite.md 第 3 节边界、"暂不支持查询"
**反馈形式：** 权限类型分组标记"暂不支持"
**系统反馈：** 在对应权限类型分组区域显示灰色提示条："报表权限查询暂不支持，如需核对报表权限，请前往报表管理后台。"
**用户下一步：** 点击链接跳转外部系统，或忽略

---

### 异常 5：无查询权限

**发生时机：** 当前操作者尝试使用查询功能时
**触发条件：** 操作者不具备查询权限（如子管理员超出管辖范围尝试查全企业）
**判断依据：** 来自 facts.md 开放问题第 2 条
**反馈形式：** 页面阻断提示（如已进入查询页但数据范围受限，则在结果区顶部横幅提示）
**系统反馈：** "当前仅可查询您管辖范围内的权限数据。如需查询全企业权限数据，请联系超级管理员。"
**用户下一步：** 在许可范围内继续查询，或联系超级管理员

## 6. 页面 / 弹窗 / 抽屉设计

### 页面 1：权限查询主页

**页面目标：** 让管理员快速选择查询维度和入口。

**页面结构：**
- 顶部：页面标题「权限查询」+ 副标题"选择查询维度"
- 主体：三个入口卡片横向排列，每个卡片包含图标 + 标题 + 适用场景说明
- 底部：最近查询记录（如有），点击直接进入上次查询

**具体文案：**
- 页面标题：「权限查询」
- 卡片 1 标题：「按人员查询」说明："查看某个员工当前拥有的所有权限。适用场景：离职核对、权限排障、入职后验证。"
- 卡片 2 标题：「按角色查询」说明："查看某个角色包含的权限清单和持有人员。适用场景：角色治理、权限模板核对。"
- 卡片 3 标题：「按权限项查询」说明："反查某项权限当前被哪些人持有。适用场景：安全审计、高风险权限排查。"

**按钮：** 无主次按钮，三个卡片均可点击进入

---

### 页面 2：按人查询结果页

**页面目标：** 展示目标用户的完整权限清单，支持来源追溯和详情查看。

**页面结构：**
- 顶部信息条：用户头像 + 姓名 + 部门 + 岗位 + 「切换用户」按钮
- 操作区：导出按钮（如支持）、展开/收起全部按钮
- 主体：应用列表，每个应用可折叠。展开后按权限类型分组展示权限条目
- 每条权限：名称 + 来源标签 + 生效状态图标 + 可点击查看详情
- 右侧：详情抽屉（点击权限条目时滑出）

**具体文案：**
- 用户信息区格式：「张三 | 财务部 | 会计」
- 应用折叠标题：「财务系统（3 项权限）」
- 来源标签：蓝色「直授」/ 绿色「角色：财务主管」/ 橙色「协作规则」

**按钮：**
- 主按钮：「切换用户」（返回搜索）
- 次按钮：「展开全部」/「收起全部」
- 链接按钮：「导出」

**成功反馈：** 查询结果加载完成，按应用渐进展示
**失败反馈：** 查询加载失败时显示"加载失败，请重试" + 重试按钮

---

### 抽屉：权限详情面板

**页面目标：** 展示单条权限的完整来源链路和变更历史。

**页面结构：**
- 面板标题：「权限详情」
- 权限基本信息：权限名称 + 当前生效状态
- 来源链路时间线：按时间展示权限获取和变更路径
- 来源列表：列出所有授予来源，标注优先级和生效状态
- 操作记录：每次变更的操作人、时间
- 底部：「前往配置」按钮

**具体文案：**
- 时间线格式：「2025-03-15 管理员张三通过用户授权添加 —— 生效中」
- 覆盖说明：「2025-04-01 因应用【财务系统】不可见，该权限当前不生效」
- 跳转按钮：「前往用户授权」

**按钮：**
- 主按钮：「前往配置」（新标签页打开）
- 次按钮：「关闭」

---

### 页面 3：按角色查询结果页

**页面目标：** 展示角色的权限清单和人员构成。

**页面结构：**
- 顶部信息条：角色名称 + 角色描述 + 「切换角色」按钮

## 7. 状态与反馈文案

| 状态 | 含义 | 适用对象 | 用户可操作 | 统一反馈口径 |
|---|---|---|---|---|
| 已生效 | 权限当前可用 | 所有查询维度 | 查看详情 | 绿色勾 + "已生效" |
| 未生效 | 权限未到生效时间或已过期 | 按人查、按角色查 | 查看详情 | 灰色圈 + "未生效" |
| 覆盖不生效 | 权限被其他规则覆盖，当前不可用 | 按人查 | 查看详情 + 查看覆盖原因 | 橙色感叹号 + "当前不生效" |
| 审批中 | 权限变更在审批流程中 | 按人查 | 查看审批进度 | 蓝色时钟 + "审批中" |
| 暂不支持 | 该权限类型查询链路未打通 | 所有查询维度 | 跳转外部系统 | 灰色提示条 + "暂不支持查询" |

## 8. 待确认问题

1. **查询结果是否需要支持导出？**

   影响：如确认支持导出，按人查询结果页和按角色查询结果页需要增加"导出"按钮，导出交互（弹窗选择格式）和操作日志记录需要一并设计。如不支持导出，审计人员的旅程缺少终点，可能需要提供替代方案（如打印样式）。
   建议确认方：产品

2. **子管理员的查询数据范围如何控制？**

   影响：如果子管理员只能查管辖范围内的数据，查询主页不需要做入口限制（三个入口都可进入），但在结果页需要做数据过滤 + 范围提示。如果任何人都能查全企业，需要在权限安全层面额外评估。
   建议确认方：产品 + 技术

3. **按权限项反查时，权限项的最低粒度？**

   影响：如果是菜单/页面级（粒度较粗），权限树信息量可控；如果是按钮/操作级（如"删除按钮"、"导出按钮"），权限树会非常庞大，搜索和导航的设计复杂度显著提高，可能需要引入二级搜索和收藏机制。
   建议确认方：产品 + 技术
