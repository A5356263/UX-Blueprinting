# 领域：管理后台

## 底层基座

- 租户 / 企业配置
- 组织与身份
- 权限与数据权限
- 模板与开关
- 日志审计
- 接口密钥
- 监控告警
- 回滚机制

## 核心链路

配置 → 审核 → 发布 / 生效 → 监控 → 审计 → 回滚

## 关键元数据

- 配置版本
- 操作人
- 生效范围
- 生效时间
- 权限项
- 日志事件
- 密钥状态
- 回滚标记
- 租户标识

## 高复杂度触发点

- 改角色与数据权限边界
- 改配置生效机制
- 从保存即生效改为审核 / 定时 / 灰度生效
- 引入多租户隔离
- 引入多法人 / 多项目隔离
- 改审计留痕
- 改操作日志和回滚机制
- 接入新的 API 凭证体系
- 改应用授权模型

## 中等复杂度触发点

- 新增配置项但复用现有生效机制
- 新增批量授权
- 新增监控看板
- 新增模板复制
- 新增异常告警
- 扩展日志查询能力但不改审计逻辑

## 低复杂度触发点

- 帮助文案
- 字段排序
- 默认筛选
- 分组折叠
- 控件样式
- 表单布局
- 配置项说明

## UXB 判断提醒

- 不因为“后台、权限、配置”直接判高复杂度。
- 先看是否改生效机制、隔离边界、审计或回滚。
- 纯说明文案和布局优化按低复杂度处理。
