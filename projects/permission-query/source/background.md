# 背景与领域上下文

## 权限管理领域概述

权限管理领域回答的是：谁在什么条件下，对什么资源，可以做什么，以及结果何时生效。

当前系统权限能力已覆盖：
- 用户直授（按人授权、功能授权、数据授权）
- 角色授权（角色模板、成员管理、授权规则）
- 全局治理（子管理、双管理员互审、权限变更审批）
- 协作可见性（成员协作权限）
- 应用级治理（应用管理、应用设置）
- 查询排障（权限查询入口、按用户查询结果）

## 当前查询能力现状

现有知识库记录了五种查询路径，但成熟度不同：

| 查询路径 | 现状 | 说明 |
|---------|------|------|
| 按用户查 | feasible | 已有「权限查询」入口和「按用户查询结果」页 |
| 按角色查 | partial | 角色管理页可查看角色成员，但缺少独立查询页和结果视图 |
| 按应用查 | feasible | 应用管理页可查看应用台账和可见范围 |
| 按变更查 | partial | 分散在权限域和审批域之间，缺少统一变更台账 |
| 按权限项查 | GAP | 缺少按功能点反查持有者的独立承载页 |

## 关键业务对象

- 主体（subject）：用户、成员、子管理员
- 资源（resource）：应用、菜单、操作点、数据对象
- 动作（action）：查看、编辑、导出、审批等
- 范围（scope）：权限最终可作用的数据边界
- 来源（source）：直授、角色继承、应用可见性、协作规则
- 修饰因子（modifier）：影响生效、责任边界的治理因子

## 已知体验风险

1. RISK-001 入口选择困难：同一目标可能出现在多个入口
2. RISK-002 权限来源不透明：同一权限来自多来源时排错成本高
3. RISK-003 覆盖规则违背直觉：应用不可见覆盖个人权限
4. RISK-005 跨模块散落导致查询分裂：查一个人要跑多个地方
5. RISK-007 批量操作安全风险：误配扩大影响面
