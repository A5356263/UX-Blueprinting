# 背景与策略约束

## 需求定性

本次是**既有能力扩展**，不是底层业务重构。权限的分配、生效、回收规则都不变，核心是在现有权限体系上新增统一查询视角。

## 已确认的策略约束

### 1. 数据源与实时性

- 查询时实时穿透各域取数，不强制要求各域数据源统一
- 允许部分域查不到时做降级展示，标注「该域暂不支持查询」
- 不同域的权限颗粒度不同是客观事实，查询结果用分类/分区展示，不强行统一格式

### 2. 查询权限控制

- 权限管理员：只能查自己管辖范围内的权限数据
- 超级管理员和审计人员：可查全局
- 不对「谁能查谁」做更细粒度控制，避免查询工具本身变成配置负担

### 3. 分步建设策略

- 第一版必须包含：导出能力（审计场景硬需求）
- 后续版本补充：查询操作留痕
- 不在此次范围：权限变更历史追溯（独立需求，可在结果中预留跳转入口）

### 4. 输入参考

- 竞品参考：飞书多主体查询方向、泛微多维度权限清单方向
- 当前知识库已有权限管理领域完整模型（对象、关系、能力地图、查询路径、角色边界、页面载体语义）
