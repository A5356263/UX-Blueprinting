# 需求文档：权限查询

## 1. 需求背景

当前权限分散在多个功能域中，不同功能的权限颗粒度不同，既有应用、菜单、页面、操作等功能权限，也有数据权限、表单权限、字段权限、报表权限等细分权限。

对于安全性要求较高的企业，管理员需要清晰核对人员与权限之间的归属关系。但现有系统缺少统一的权限查询视角，管理员需要在不同设置页面之间切换、逐项核对，查找效率低，也不利于权限审计和风险排查。

## 2. 目标

本次希望补齐权限查询能力，支持管理员从多个维度查看权限归属关系，提升权限核对和审计效率。

核心目标：
- 帮助管理员快速了解某个人拥有哪些权限
- 帮助管理员快速了解某个角色包含哪些权限
- 帮助管理员快速反查某项权限被哪些人拥有
- 帮助企业快速核对员工权限，降低安全风险

## 3. 用户与角色

### 3.1 权限管理员
负责查看、核对、调整员工或角色的权限配置，是本能力的主要使用者。

### 3.2 超级管理员
拥有更高权限，可用于全局权限审计、异常权限排查和权限治理。

### 3.3 审计 / 安全管理人员
在安全性要求高的企业中，需要核对人员权限、角色权限和高风险权限分布情况。

## 4. 查询维度

### 4.1 按人查权限
输入：人员
输出：该人员拥有的全部权限清单，含功能权限、数据权限、表单权限、字段权限、报表权限

### 4.2 按角色查权限
输入：角色
输出：该角色包含的全部权限清单，含功能权限、数据权限、表单权限、字段权限、报表权限

### 4.3 按功能权限反查
输入：功能权限（支持两个层级）
- 功能点维度：如"谁能删除员工"
- 应用/菜单维度：如"谁有这个页面的权限"
输出：拥有该权限的全部人员和角色列表

## 5. 查询范围

覆盖全部权限类型：
- 功能权限（应用、菜单、页面、操作）
- 数据权限
- 表单权限
- 字段权限
- 报表权限

## 6. 竞品参考

### 6.1 飞书
- 支持权限验证
- 支持按主体、客体查询权限结果
- 适用于组织可见范围、协作范围等场景

### 6.2 泛微
- 支持多主体维度查询
- 支持查看详细权限清单
- 适合权限审计和权限核对场景
