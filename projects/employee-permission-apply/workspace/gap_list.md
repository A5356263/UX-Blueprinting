# Gap List

> 汇总本任务所有已识别的信息缺口，按影响严重程度分级。

## Blockers

none——当前缺口均不阻塞方案方向判断，但部分缺口需要在详细设计前关闭。

## Warnings

1. **模式互斥范围未确认**：自助申请模式与哪些已有权限治理模式互斥，是全部互斥还是部分互斥。影响开启检测逻辑。
2. **申请范围维度未确认**：员工可申请角色、功能权限还是两者都支持。影响管理端配置界面和员工端申请表单结构。
3. **审批人默认规则未确认**：审批人来源是组织负责人、指定管理员还是自定义审批流。影响审批路由。
4. **关闭时权限是否保留未确认**：管理员关闭能力后，已通过自助申请获得的权限是否保留。影响关闭逻辑和员工体验。
5. **员工端入口位置未确认**：员工端功能应该放在个人中心、工作台还是独立菜单。影响信息架构设计。

## 待补信息

1. **敏感权限排除机制**：是否需要单独标记某些权限为不可申请。建议提供默认标记机制。
2. **申请撤销规则**：审批中的申请是否支持员工撤销，撤销是否有时间限制。
3. **审批超时阈值**：审批多久未处理算超时，超时后的兜底策略。
4. **服务人员范围**：服务人员是否完全不支持该能力。
5. **附件上传**：申请权限时是否需要支持上传附件（如审批需要的证明文件）。
6. **数据权限范围**：员工申请权限时是否可以选择数据权限范围。
7. **申请统计需求**：管理员是否需要申请统计仪表盘，需要哪些统计指标。
8. **权限来源展示**：员工端"我的权限"是否需要展示权限来源和获得方式。
