# Requirement

- Project ID: permission-quick-search
- Task Name: 功能权限设置页面内查找定位
- Domain: 权限管理

## 需求来源

本次需求来自权限管理员在日常工作中的实际操作痛点，经与操作者确认交互方式后整理如下。

## 核心需求

在功能权限设置页面中增加页面内关键词查找定位能力。管理员输入关键词后，页面中匹配的文字以高亮样式标记，同时页面视觉焦点自动滚动到第一个命中位置，支持在多个命中项之间上下切换。

查找行为不改变页面数据展示范围，所有权限项始终可见。权限的勾选、取消、保存、取消保存逻辑完全沿用现有流程。

## 当前问题

功能权限设置页面末级菜单约 1100+，操作功能点约 1200+。企业开启所有标准应用后，权限管理员需滚动约 35 屏才能完整浏览。逐屏查找已勾选权限或特定权限项效率低、容易遗漏。

## 目标用户

- 权限管理员：负责为员工、管理员或其他授权对象配置功能权限
- 实施 / 运营人员：在客户实施或权限核对过程中辅助检查权限配置

## 核心场景

1. 管理员需要确认某个授权对象当前拥有哪些功能权限，输入关键词后快速定位到匹配项
2. 实施人员协助客户核对权限配置是否正确，通过查找快速跳转到目标权限项
3. 管理员发现权限配置错误时，通过查找定位目标项进行调整
4. 大量权限场景下，通过页面内查找降低逐屏浏览压力

## 交互方式（已与操作者确认）

- 查找入口：在功能权限设置区域提供查找输入框
- 输入关键词后实时高亮页面中所有匹配文字，不等待回车
- 页面视觉焦点自动定位到第一个命中位置
- 支持在多个命中项之间上下切换
- 关键词清空后高亮消失，页面恢复常规展示
- 查找行为不触发权限保存或变更
- 查找期间未保存的勾选操作不受影响

## 不明确事项

以下事项待设计时给出建议方案：

1. 该能力只支持员工功能权限设置，还是也支持管理员、角色、组织等其他授权对象？
2. 查找范围是否包含操作功能点名称？
3. 查找是否支持同时匹配多个关键词？
4. 查找是否区分大小写？
5. 查找输入框是常驻展示还是通过快捷键或按钮呼出？
6. 命中切换是否需要显示计数信息（如"第 3/15 个"）？
7. 是否需要支持查找历史记录？
8. 是否纳入数据权限页面，还是仅限功能权限页面？
9. 查看模式和编辑模式是否都支持该查找能力？
10. 折叠节点内命中时，是否需要自动展开对应层级？
