# Background

- Project ID: permission-quick-search
- Task Name: 功能权限设置页面内查找定位
- Domain: 权限管理

## 业务背景

功能权限设置是企业权限管理系统的核心页面之一。随着系统功能持续增加，权限项数量已达 1100+ 末级菜单和 1200+ 操作功能点。权限管理员在大量权限项中查找特定内容的操作成本显著上升。

## 现状约束

- 功能权限设置页面已有完整的权限树展示、勾选、保存、取消保存流程
- 权限树支持展开/折叠，部分节点默认折叠
- 权限项存在全选、半选、未选三种状态
- 本次新增的查找定位能力不得改变现有权限配置流程和数据结构

## 相关说明

- 本需求最初以"筛选已勾选权限"的表述提出，经与操作者确认后，实际交互方式为页面内关键词查找高亮 + 焦点跳转（类似 Ctrl+F），非数据过滤切换
- 需求文档原文见 input/快捷查看功能权限/功能权限设置支持筛选已勾选权限_需求文档.md（已按确认后的交互方式改写）

## 缺失信息

- 查找功能的适用范围（是否覆盖所有授权对象类型和所有权限配置入口）
- 查找功能在移动端或平板端的交互要求
- 对查找响应时间的性能要求
