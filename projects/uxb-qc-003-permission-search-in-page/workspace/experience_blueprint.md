## 0. 本次关键设计判断

本次是页面内查找定位（Ctrl+F体验），不是筛选权限、不是改变数据范围、不是权限规则变更。核心交互：查找输入→实时高亮→焦点跳转→上下切换→折叠节点自动展开→清空恢复。基于 U-02（真实世界惯例）：用户已有Ctrl+F的心智模型，交互应尽量接近这个体验。

## 1. 交互流程总览

管理员在功能权限设置页面→在查找输入框输入关键词→页面实时高亮所有命中文字→焦点自动跳到第一个命中项→可通过↑↓或Enter切换命中项→如果命中项在折叠节点内，自动展开→清空关键词恢复。

## 2. 主交互流程

### 2.1 查找入口

- 查找输入框常驻功能权限设置页面顶部（权限树上方），与权限树同宽
- 左侧搜索图标，placeholder："查找权限项或功能点"
- 输入关键词后实时高亮所有命中文字，不需要按回车
- 输入框右侧展示命中计数"第 1/8 个"和 ↑↓ 切换按钮

### 2.2 命中高亮

- 所有匹配关键词的文字以黄色高亮背景标记
- 当前焦点命中项以深黄色/橙色边框标记（与其余命中视觉区分——承接facts中"当前命中与其余命中有明显视觉区分"的要求）
- 权限树折叠节点内如果有命中项，自动展开该节点及其所有父级节点后再显示高亮

### 2.3 焦点跳转

- 输入第一个字符后页面自动滚动，将第一个命中项定位到视口中央
- 如果命中项在折叠节点内，先展开节点再滚动定位

### 2.4 命中切换

- ↑↓按钮切换上一个/下一个命中项，也支持Enter/Shift+Enter
- 切换时页面跟随滚动到对应命中项
- 当前焦点命中项视觉上加深标记
- 到最后一个命中项后再按↓回到第一个（循环）

### 2.5 清空恢复

- 点击输入框的✕按钮或清空关键词
- 所有高亮立即消失，页面恢复常规展示
- 折叠节点保持展开状态不变（不自动折叠回去——应用 U-03 用户可控）
- 不触发任何保存或回滚——承接编辑状态保护

## 3. 次交互流程

### 3.1 折叠节点内命中自动展开

- 用户输入关键词时，系统遍历权限树的可见和折叠节点
- 如果命中项在折叠节点内：自动展开该节点→展开所有父级节点→显示高亮
- 清空关键词后节点保持展开——用户可能后续还要查看

### 3.2 查找期间编辑权限

- 用户可能在查找前已修改权限勾选（未保存）
- 查找输入框的输入、清空、切换命中项均不影响已修改的勾选状态
- 关闭查找或导航离开时，未保存的编辑状态保持不变

## 4. 异常与阻断流程

### 4.1 无命中

- 用户输入关键词后系统在权限树中未找到任何匹配
- 输入框下方显示提示："未找到匹配内容"（红色文字）
- 页面不改变当前展示和滚动位置
- 用户可修改关键词重试

### 4.2 大量命中（>50个）

- 用户输入短关键词（如单个汉字），系统检测到超过50个命中项
- 仍正常高亮所有命中，但输入框下方提示："找到 N 个匹配项，输入更多字符缩小范围"
- 切换命中项时优先在可见视口区域内的命中项之间循环

### 4.3 编辑状态保护

- 用户查找前已修改权限勾选但未保存
- 用户在查找输入框中输入关键词——不触发保存
- 用户清空关键词——不触发回滚
- 用户关闭查找——不触发任何权限变更
- 这是本需求最关键的"不干扰"行为——查找是纯辅助定位，不影响权限数据

### 4.4 折叠节点全部展开性能

- 用户输入通用关键词（如"管理"），权限树中超过200个折叠节点需要展开
- 系统检测到需要展开的节点超过200个
- 分批展开：每批50个节点，间隔50ms
- 展开过程中在查找输入框下方展示进度："正在展开匹配节点...（120/200）"
- 展开完成后进度消失，显示正常的命中计数
- 如果展开过程中用户清空关键词，停止展开并恢复页面

### 4.5 仅有一个命中项

- 用户输入关键词后系统仅找到1个匹配项
- 页面自动跳转到该命中项并高亮
- ↑↓切换按钮置灰（无可切换的命中项）
- 命中计数显示"第 1/1 个"而非隐藏

### 4.6 用户尝试在查找中修改权限（阻断场景）

- 用户在查找高亮状态下点击权限项的勾选框
- 系统允许勾选/取消勾选——查找不阻断正常的权限编辑
- 但查找输入框不清空，高亮不消失——用户可继续查找下一个权限项
- 如果用户保存了权限修改，查找状态保持不变
- 这是关键设计：查找是辅助工具，不应阻断用户的主要任务（权限配置）

## 6. 状态与反馈文案

| 场景 | 文案/表现 |
|------|----------|
| 查找输入框placeholder | 查找权限项或功能点 |
| 命中切换计数 | 第 N/M 个 |
| 无命中 | 未找到匹配内容 |
| 大量命中 | 找到 N 个匹配项，输入更多字符缩小范围 |
| 清空关键词 | 高亮消失，页面恢复常规展示，折叠节点保持展开 |
| 折叠节点展开中 | 正在展开匹配节点... |
| 查找期间编辑保护 | 无文案提示——静默保护，不打扰用户 |

## 附录：设计指南消费说明

- **U-02（真实世界惯例）**：交互形态接近Ctrl+F——输入框在顶部常驻、实时高亮、↑↓切换、Esc关闭——用户已有心智模型
- **U-01（系统状态可见）**：命中高亮+焦点标记+命中计数让用户明确知道"找到了什么、现在在哪"
- **U-03（用户可控）**：清空关键词恢复页面、折叠节点保持展开不自动折叠——用户操作是可逆的
- **C-03（减少认知负荷）**：查找不改变数据范围、不干扰编辑状态——用户不需要理解新的权限规则，只需理解查找=定位
- **IA-01（信息气味）**：高亮标记的命中项让用户一眼看到"匹配了什么"——不需要点击进去才知道
- **反馈原则**：无命中提示"未找到匹配内容"——说明状态但不打断用户
