# Background

## 业务背景

目前企业员工的权限分配主要由权限管理员或超级管理员集中处理。在中大型企业中，员工数量多、人员流动频繁，权限新增、变更、核对的工作量较大。部分企业的超级管理员可能是老板本人，业务人员需要权限时需私下找老板或管理员处理，沟通成本高，授权时效不稳定。

通过支持员工自助查看和申请权限，把部分权限申请工作从管理员侧分散到员工侧，同时保留管理员对申请范围和审批流程的控制。

## 目标

- 员工可查看自己当前拥有的权限
- 员工可主动申请所需权限
- 通过审批后系统自动授权
- 员工可查看自己的申请记录和审批状态
- 管理员可控制是否开启、可申请范围、审批流程

## 涉及角色

- 超级管理员 / 权限管理员：配置自助申请模式的开关、范围和审批规则
- 员工：查看自己的权限，发起权限申请
- 审批人：处理员工提交的权限申请

## 关键约束

1. 员工申请权限是现有权限体系的一部分，不另起炉灶
2. 权限申请范围需要管控（白名单模式）
3. 申请权限必须经过审批才可生效
4. 敏感权限（超管角色、审计相关权限）系统级硬排除
5. 与双管理员模式互斥，不可同时开启
6. 服务人员第一期不开放

## 竞品参考

部分主流协同办公产品暂未提供类似能力。金蝶有相近功能，支持用户查看自己的权限，并通过申请单申请角色或组织数据权限，审批通过后系统自动授权。

## 价值指标

希望推动至少 3 家客户使用。
