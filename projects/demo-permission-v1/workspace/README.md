- `business_blueprint.md`：业务蓝图
- `experience_blueprint.md`：体验蓝图
- `gap_list.md`：信息缺口
- `check_report.md`：检查报告

- `02_business_gate.md`：业务阶段报告
- `03_experience_gate.md`：体验阶段报告

建议评审顺序：facts → business → experience → check_report。
