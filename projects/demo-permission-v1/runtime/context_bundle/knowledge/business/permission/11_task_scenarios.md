# 11_task_scenarios

## 文件定位

本文件从“任务场景 -> 页面 / 路径”的角度，说明权限域中的高频任务分别落在哪些页面与链路中。

## 1. 给单个用户开权限

- 任务目标：给指定用户开通应用、功能权限、数据权限
- 主要页面 / 路径：
  - `用户授权`：先检索并定位目标用户
  - `功能授权`：配置功能点
  - `数据授权`：配置数据范围
  - `权限详情`：核对最终结果
- 关键说明：这是按人配置的主路径，适合单体排查与单体治理

## 2. 批量给人授权 / 移除

- 任务目标：对一批用户进行批量角色关联、批量授权或批量移除
- 主要页面 / 路径：
  - `用户授权`：通过全局批量操作区发起批量动作
  - `角色/人员选择器`：完成批量对象选择
  - `权限详情`：[GAP] 现有事实只明确了详情查看入口，未说明批量结果核对页
- 关键说明：批量操作属于高风险治理动作，需要同步考虑审计与可回溯性

## 3. 查看某人为什么有 / 没有权限

- 任务目标：解释某个用户最终为什么能看、能做、不能做或未生效
- 主要页面 / 路径：
  - `权限查询`：选择按用户查询
  - `按用户查询结果`：查看按应用聚合的结果
  - `权限详情`：查看更细粒度的只读明细
- 关键说明：这是解释与排障链路，不承担配置职责

## 4. 用角色批量分发权限

- 任务目标：通过角色模板为多个人批量分发权限
- 主要页面 / 路径：
  - `角色管理`：创建或选中角色
  - `功能权限`：配置角色功能权限
  - `数据权限`：[GAP] 页面事实待补，但角色管理已明确存在该入口
  - `角色成员管理区`：添加成员到角色
- 关键说明：角色页承担模板化授权职责

## 5. 配角色自动授权规则

- 任务目标：让角色随部门、职务、成员组等条件自动授予与回收
- 主要页面 / 路径：
  - `角色管理`：选中目标角色
  - `授权规则`：配置条件组与规则组
- 关键说明：规则组内取交集，规则组之间取并集

## 6. 开启子管理员分权

- 任务目标：给指定人员下放可管理的组织范围与可授权功能上限
- 主要页面 / 路径：
  - `权限管理模式`：启用子管理员模式
  - `子管理配置页`：配置子管理员、人、组织范围、功能上限
- 关键说明：这是配置“权限的权限”，不是直接配置业务权限

## 7. 开启双管理员互审

- 任务目标：让高危权限操作进入互审链路
- 主要页面 / 路径：
  - `权限管理模式`：选择双管理员互审模式
  - `双管理员模式配置页`：配置互审搭档与互审范围
- 关键说明：该任务改变的是高危操作的生效机制

## 8. 开启权限变更审批

- 任务目标：把权限变更纳入审批流治理
- 主要页面 / 路径：
  - `权限管理模式`：选择权限变更审批模式
  - `权限变更审批模式配置页`：进入模式说明与路由枢纽
  - `审批管理 / 通用审批`：配置审批流程
- 关键说明：该路径依赖外部审批中台，不在权限域内重复配置流程引擎

## 9. 控成员之间可见性

- 任务目标：控制员工与外部协作对象之间的可见性边界
- 主要页面 / 路径：
  - `成员协作权限`：配置主规则、补充规则、适用应用
- 关键说明：这是协作可见性治理，不等于后台管理授权

## 10. 控应用入口与应用管理员

- 任务目标：控制应用在前台是否可见，以及谁能管理该应用后台
- 主要页面 / 路径：
  - `应用管理`：管理应用台账、可见范围、启停状态
  - `应用设置页`：配置单应用入口治理与单应用管理员
  - `功能权限 / 数据权限`：为应用管理员配置具体管理权限
- 关键说明：应用入口治理与后台管理权限治理需要分开理解

## 11. 当前缺口

- [GAP] 批量授权后的统一结果核对页尚未在现有页面事实中明确
