# 需求文档：员工自助申请权限

## 原始需求

当前企业员工权限均由超管或权限管理员统一分配。对中大型企业，员工多、流动大，集中分配和核对的工作量较大，时效和效率都有提升空间。

本次计划支持员工自行申请权限、自行核对权限，将分配和核对工作分散到员工端。

### 核心功能单元

1. **自助申请权限模式**（管理端）：超管专属功能，开启后员工可自助申请权限。包含三步设置：选择申请方式（申请角色/申请功能权限）、设置角色或应用范围、设置审批流程。与双管理员互审模式和权限变更审批模式互斥。
2. **我的权限**（员工端）：个人中心新增入口，展示员工当前的功能权限、数据权限、角色。属于查询解释链路，全员可用。
3. **申请权限**（员工端）：员工发起权限申请，填写申请原因，选择角色或功能权限，提交后进入审批流程。审批通过后系统自动分配权限。
4. **申请记录**（员工端）：查看申请历史，支持按日期和审批状态筛选，审批中的申请可撤销。

### 竞品参考

金蝶是唯一支持此功能的竞品，钉钉、飞书、泛微均不支持。

## 用户确认目标

- 在保持集中管控安全性的前提下，新增"员工申请→审批确认→自动授予"的权限获取路径
- 员工侧体验必须简单到无需培训即可使用
- 权限来源可解释——"我的权限"页面需能区分和解释不同来源的权限
- 审批状态对员工可见，降低"为什么还没生效"的焦虑

## 本次任务范围

本次正式蓝图任务覆盖：
- 管理端：自助申请权限模式的配置与开关
- 员工端：我的权限、申请权限、申请记录
- 审批对接：OA审批流程的预设与联动
- 不覆盖：移动端独立设计（但需考虑OA审批跨端兼容）
