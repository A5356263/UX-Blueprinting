# 原始需求：员工自助申请权限

## 需求来源
- 文件：`input\自助权限申请\需求文档_员工自助申请权限2.md`
- 需求提出方：产品团队

## 核心目标
支持员工自行申请权限，将权限分配和核对的工作从管理员分散到员工，提升权限分配效率。

## 任务范围
1. **自助申请权限模式（管理端）**：超管可开启/关闭该模式，配置员工申请权限的方式（申请角色/申请功能权限）、角色范围/应用范围、审批流程
2. **我的权限（员工端）**：个人中心新增入口，展示功能权限、数据权限、角色三个tab
3. **申请权限（员工端）**：员工通过抽屉表单提交权限申请，经审批后系统自动分配
4. **审批对接**：对接流程引擎，默认审批人为组织负责人

## 互斥约束
- 不可与「双管理员互审模式」同时开启
- 不可与「权限变更审批模式」同时开启

## 关键规则
- 服务人员无此入口
- 存在资金用户校验（为非资金用户授予代发付款时报错）
- 存在子管理员模式校验（子管理员授予子管理员模式时报错）
- 申请人默认当前用户，不可编辑
- 申请原因为必填项，限500字
- 支持申请记录查询与撤销
