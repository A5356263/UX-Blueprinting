体验蓝图

0. 本次关键设计判断

判断：

这次核心是给权限管理员增加一条高效率的批量配置路径，体验方案重点在入口够不够直接、弹窗信息够不够清晰、校验失败时用户能不能快速修正。

主要影响：

  1. 子管理员列表操作列新增一个操作项，需要确保操作列的信息层级不乱
  2. 复制弹窗需要同时承载复制信息和复制对象两组选择，信息结构比单纯的添加弹窗更复杂
  3. 四级顺序校验意味着用户可能多次被阻断，需要让每次阻断都有明确的修正路径

建议方案：

  • 复制入口放在操作列最左侧，作为高频批量操作的优先入口
  • 弹窗采用上下分区结构：上半部分选复制信息（两个复选框），下半部分选复制对象（人员选择器）
  • 校验报错在弹窗内即时展示，不关闭弹窗，允许用户直接修正后重试
  • 双管理员互审的审批体验不在本次方案中展开，仅标注审批入口的承接位置

不建议方案：

  • 不建议把复制做成独立页面的形式，弹窗即可承载当前信息量
  • 不建议在复制弹窗中展示复制来源的完整权限明细，避免信息过载
  • 不建议采用逐个复制对象的逐条确认模式，批量操作应一次确认

需要确认：

  1. 加入状态报错文案中"加入状态不是已加入"是否需要统一为"已启用"？
  2. 部分用户校验失败时是全部阻断还是跳过失败用户？影响反馈形式的选择
  3. 复制成功后是否需要展示结果明细（如成功人数、失败人数）？影响结果反馈的设计

1. 交互流程总览

涉及角色：

  • 权限管理员/超级管理员：在子管理员列表中找到来源子管理员 → 点击复制 → 选择复制信息和复制对象 → 确认 → 查看结果

主流程：

  1. 权限管理员在子管理员模式列表的操作列点击「复制」
  2. 系统打开复制弹窗，复制信息默认全选，复制对象为空
  3. 权限管理员根据需要调整复制信息选项，通过员工选择器选择复制对象
  4. 点击「确认」，系统按顺序校验：复制信息 → 复制对象 → 加入状态 → 认证状态
  5. 校验全部通过后执行复制，toast 提示「复制成功」，弹窗关闭
  6. 系统后台生成操作记录

异常流程重点：

  • 复制信息未勾选：弹窗内阻断，提示「请选择复制信息」
  • 复制对象未选择：弹窗内阻断，提示「请选择至少一名复制对象」
  • 部分用户加入状态不符：弹窗内阻断，提示具体用户名
  • 部分用户认证状态不符：弹窗内阻断，提示具体用户名

2. 主交互流程

节点 1：复制入口

用户动作：
权限管理员在子管理员模式列表中，找到目标来源子管理员所在行，点击操作列中的「复制」。

系统反馈：
系统打开复制弹窗。

需要前置解释的信息：

  • 复制操作会将来源子管理员的权限配置复制给其他用户
  • 复制对象原本不是子管理员的，复制后将成为子管理员
  • 复制对象原本已是子管理员的，复制后在其原有权限上叠加，不会覆盖

建议文案：

  • 操作按钮：「复制」

下一步：
进入复制弹窗，开始选择复制信息和复制对象。

节点 2：复制弹窗 — 复制信息选择

用户动作：
权限管理员在复制弹窗上半部分，查看复制信息的默认勾选状态。默认「可授权组织」和「可授权功能」均勾选。如果只需要复制其中一项，可取消另一项的勾选。

系统反馈：

  • 两项默认均为勾选状态
  • 至少保留一项勾选，如果用户取消所有勾选，确认时会阻断并提示「请选择复制信息」
  • 没有在取消时即时报错，而是在确认时统一校验

需要前置解释的信息：

  • 可授权组织：复制来源子管理员被授权管理的组织范围
  • 可授权功能：复制来源子管理员被授权使用的功能范围
  • 取消某项表示不复制该类权限

建议文案：

  • 区域标签：「复制信息」
  • 选项一：「可授权组织」
  • 选项二：「可授权功能」

下一步：
在下半部分选择复制对象。

节点 3：复制弹窗 — 复制对象选择

用户动作：
权限管理员点击复制对象选择器，打开「选择员工」弹窗。在选择员工弹窗中勾选目标用户（最多 200 名），点击确认后返回复制弹窗，已选用户展示在选择器输入框中。

系统反馈：

  • 选择器提示「最多可以复制给 200 名用户」
  • 选择员工弹窗仅展示加入状态为已启用且认证状态为已认证的员工
  • 返回复制弹窗后，已选用户以名称/手机号形式展示在选择器中
  • 支持再次点击选择器编辑已选用户

需要前置解释的信息：

  • 只有满足加入状态（已启用）和认证状态（已认证）的员工才会出现在可选列表中
  • 最多可选 200 名用户

建议文案：

  • 区域标签：「复制对象」
  • 选择器提示：「最多可以复制给 200 名用户」
  • 选择员工弹窗标题：「选择员工」

下一步：
点击弹窗底部的「确认」按钮提交。

节点 4：校验与确认

用户动作：
权限管理员确认复制信息和复制对象无误后，点击弹窗底部的「确认」按钮。

系统反馈（正常结果）：
校验全部通过 → 执行复制 → toast 提示「复制成功」→ 弹窗关闭 → 返回列表页。

系统反馈（异常结果，按校验顺序）：

校验一：复制信息未勾选

  • 弹窗内展示报错：「请选择复制信息」
  • 弹窗不关闭，用户可直接勾选后重新确认

校验二：复制对象未选择

  • 弹窗内展示报错：「请选择至少一名复制对象」
  • 弹窗不关闭，用户可点击选择器选择后重新确认

校验三：部分用户加入状态不符

  • 弹窗内展示报错：「张三、李四 加入状态不是已加入，不能成为子管理员」
  • 弹窗不关闭，用户可从选择器中移除不符合的用户后重新确认

校验四：部分用户认证状态不符

  • 弹窗内展示报错：「王五、赵六 未完成实名认证，不能成为子管理员」
  • 弹窗不关闭，用户可从选择器中移除不符合的用户后重新确认

需要前置解释的信息：

  • 校验是顺序进行的，只有通过前一项才会进入下一项校验
  • 每次只会报当前校验环节的错误，不会一次性展示所有校验结果

建议文案：

  • 确认按钮：「确认」
  • 成功 toast：「复制成功」
  • 校验一报错：「请选择复制信息」
  • 校验二报错：「请选择至少一名复制对象」
  • 校验三报错：「XXX、XXX 加入状态不是已加入，不能成为子管理员」
  • 校验四报错：「XXX、XXX 未完成实名认证，不能成为子管理员」

下一步：
成功后返回子管理员列表页。失败后留在弹窗中修正。

3. 次交互流程

节点 S1：选择员工弹窗

用户动作：
权限管理员在复制弹窗中点击复制对象选择器，打开「选择员工」弹窗。在弹窗中浏览可选员工列表，通过搜索或筛选找到目标用户，勾选后点击确认。

系统反馈：

  • 弹窗样式与「添加子管理员」弹窗一致
  • 列表中仅展示加入状态为已启用且认证状态为已认证的员工
  • 已选中的用户高亮展示
  • 点击确认后返回复制弹窗，已选用户展示在选择器输入框中

建议文案：

  • 弹窗标题：「选择员工」
  • 搜索框提示：「搜索员工姓名或手机号」
  • 确认按钮：「确认」

下一步：
返回复制弹窗，继续操作。

节点 S2：编辑已选复制对象

用户动作：
权限管理员在复制弹窗中再次点击选择器，打开「选择员工」弹窗，增删已选用户后点击确认。

系统反馈：
与首次选择一致，已选项保留，支持增删。

下一步：
返回复制弹窗，已选用户更新。

节点 S3：操作记录查看

用户动作：
复制成功后，权限管理员可从操作记录入口查看复制操作记录。

系统反馈：

  • 「复制-可授权组织」和「复制-可授权功能」分别生成一条记录
  • 记录展示操作功能、操作类型、操作对象、操作内容

建议文案：

  • 操作功能：「子管理员模式」
  • 操作类型：「复制-可授权组织」/「复制-可授权功能」
  • 操作对象：「权限管理模式」
  • 操作内容：「将子管理员【XXX/手机号】可授权组织复制给【XXX/手机号】【XXX/手机号】...」

下一步：
返回操作记录列表。

4. 异常与阻断流程

异常 1：复制信息未勾选

发生时机：用户在复制弹窗中取消所有复制信息勾选后点击确认
触发条件：复制信息中「可授权组织」和「可授权功能」均未勾选
判断依据：需求文档校验规则第 1 条，至少选择一项复制信息
反馈形式：弹窗内报错提示
系统反馈：「请选择复制信息」
用户下一步：勾选至少一项复制信息后重新点击确认

异常 2：复制对象未选择

发生时机：用户未选择任何复制对象直接点击确认
触发条件：复制对象选择器为空
判断依据：需求文档校验规则第 2 条，至少选择一名复制对象
反馈形式：弹窗内报错提示
系统反馈：「请选择至少一名复制对象」
用户下一步：点击选择器选择至少一名复制对象后重新确认

异常 3：复制对象加入状态不符

发生时机：用户在复制对象中选择了加入状态不符合要求的用户
触发条件：选择员工弹窗中不应该出现不符合条件的员工，但如果数据在用户选择后发生变化（如被其他管理员禁用），确认时会命中校验
判断依据：需求文档校验规则第 3 条，复制对象的加入状态必须均为已启用
反馈形式：弹窗内报错提示，列出具体不符合的用户
系统反馈：「张三、李四 加入状态不是已加入，不能成为子管理员」
用户下一步：从复制对象中移除不符合的用户后重新确认

异常 4：复制对象认证状态不符

发生时机：用户在复制对象中选择了未完成实名认证的用户
触发条件：类似异常 3，选择后数据变化导致认证状态不满足要求
判断依据：需求文档校验规则第 4 条，复制对象的认证状态必须均为已认证
反馈形式：弹窗内报错提示，列出具体不符合的用户
系统反馈：「王五、赵六 未完成实名认证，不能成为子管理员」
用户下一步：从复制对象中移除不符合的用户后重新确认

异常 5：复制对象超过数量上限 [GAP]

发生时机：用户在选择员工弹窗中尝试勾选超过 200 名用户
触发条件：已选用户数达到 200 时继续勾选
判断依据：需求文档规定最多选择 200 名用户
反馈形式：选择员工弹窗内即时提示
系统反馈：建议提示「最多可选择 200 名用户」
用户下一步：确认当前选择或减少选择

异常 6：部分用户校验失败的处理 [GAP]

发生时机：多个复制对象中部分用户不满足校验条件
触发条件：存在部分用户加入状态或认证状态不符
判断依据：需求文档未明确，当前默认全部阻断
反馈形式：弹窗内报错提示，列出所有不符合的用户
系统反馈：列出不符合条件的用户名及原因
用户下一步：移除不符合的用户后重新确认，或取消操作
注意：如果后续确认采用"跳过失败用户"策略，此处需改为部分成功的结果反馈（展示成功/失败明细）

异常 7：双管理员互审场景 [GAP]

发生时机：系统开启双管理员互审模式时，复制完成
触发条件：复制成功后
判断依据：需求文档第 10 节，但规则不完整
当前假设：复制即生效，审批作为事后审计记录
注意：如果后续确认审批前置，需要在复制确认和结果生效之间增加审批中状态，体验方案需重新设计

5. 页面 / 弹窗 / 抽屉设计

页面：子管理员模式列表 — 操作列

页面目标：展示子管理员列表及每行的操作入口，新增的复制入口作为批量配置的高频操作放在最左侧。

页面结构：

  • 列表行包含子管理员基本信息（姓名、手机号、可授权范围摘要等）
  • 操作列包含多个操作按钮，复制放在最左侧

具体文案：

  • 复制按钮：「复制」

成功反馈：点击后打开复制弹窗，无即时反馈。

弹窗：复制弹窗

页面目标：让权限管理员选择复制内容和复制对象，完成批量复制操作。

页面结构（从上到下）：

  1. 弹窗标题
  2. 复制信息区域：标签 + 两个复选框（默认全选）
  3. 复制对象区域：标签 + 选择器（含提示文案）
  4. 底部按钮区：确认按钮

具体文案：

  • 弹窗标题：「复制」

6. 状态与反馈文案

状态：复制操作 — 待确认

含义： 复制弹窗已打开，用户正在选择复制信息和复制对象，尚未提交。

用户可做： 调整复制信息选项、选择/编辑复制对象、点击确认提交，或关闭弹窗取消。

页面反馈： 弹窗内展示当前选择状态，确认按钮可点击。

---

状态：复制操作 — 校验中

含义： 用户点击确认后，系统正在按顺序校验。

用户可做： 等待校验结果。

页面反馈： 确认按钮展示加载态（建议），或短暂等待后展示校验结果。

---

状态：复制操作 — 校验失败

含义： 校验未通过，弹窗内展示具体报错。

用户可做： 根据报错修正选择（勾选复制信息、选择复制对象、移除不符合的用户），修正后重新点击确认。

页面反馈： 弹窗内对应位置展示报错文案，确认按钮恢复可点击状态。

---

状态：复制操作 — 复制成功

含义： 校验全部通过，复制已执行完成。

用户可做： 关闭弹窗后继续操作其他子管理员，或查看操作记录。

页面反馈： toast 提示「复制成功」，弹窗自动关闭。

状态：复制操作 — 双管理员互审中 [GAP]

含义： 系统开启双管理员互审模式，复制完成时生成了一条审批。

用户可做： 待确认。

页面反馈： 待确认。

7. 待确认问题

  1. 加入状态口径：报错文案中"加入状态不是已加入"是否需要与选择器筛选条件统一为"已启用"？影响报错文案和筛选逻辑的一致性。建议由产品经理确认。
  1. 部分校验失败策略：多个复制对象中部分用户校验不通过时，是全部阻断还是跳过失败用户？影响异常反馈形式（报错阻断 vs 部分成功结果展示）。建议由产品经理和业务方确认。
  1. 复制来源权限粒度：是否允许只复制来源子管理员的部分组织或功能？如果允许，复制弹窗需要增加权限明细选择和预览。建议由产品经理根据用户场景判断。
  1. 重复权限去重：已有子管理员被复制已在范围内的权限时是否自动去重？影响后端实现策略，对前端暂无直接影响。建议由后端确认数据处理策略。
  1. 复制结果明细：成功后是否需要在弹窗内或后续步骤中展示结果明细（成功/失败/跳过用户列表）？如果后续改为跳过失败用户策略，结果明细是必需的。影响结果反馈的设计。建议由产品经理确认。
  1. 双管理员互审完整规则：审批前置还是事后审计、审批通过前权限状态、拒绝后是否回滚。这组问题会显著影响体验方案，建议作为独立需求跟进。
