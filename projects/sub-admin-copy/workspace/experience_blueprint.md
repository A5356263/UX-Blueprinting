# Experience Blueprint

## 0. 本次关键设计判断

- **建议方案**：复制弹窗采用单步完成设计——弹窗内同时展示复制信息和复制对象两个区域，所有配置在一屏完成。员工选择器复用「添加子管理员」已有的弹窗样式。校验失败时按顺序逐项阻断并标注具体失败用户。
- **不建议方案**：分步弹窗（步骤一选复制内容、步骤二选复制对象）。复制操作的信息量不大，单选/多选 + 人员选择的组合不需要分步引导，一步完成效率更高。
- **核心理由**：本功能的核心价值是效率，操作路径越短越好。弹窗内信息结构清晰（上下分区），管理员一眼就能看到所有需要配置的内容。分步反而增加操作步数，与效率目标矛盾。
- **必须确认**：双管理员互审场景下复制结果是否需要即时反馈审批状态——如果审批是前置的，确认提交后管理员需要一个"已提交审批，等待审核"的状态和反馈文案，而不是 toast「复制成功」。

## 1. 交互流程总览

本次体验围绕以下角色展开：

**权限管理员（含超级管理员）**：在子管理员列表中，对已有子管理员执行复制操作。核心路径是"列表 → 点击复制 → 选择复制内容 → 选择目标员工 → 确认 → 完成"。

主流程：
- 复制子管理员权限：在子管理员列表操作列点击「复制」→ 复制弹窗（选择复制内容和复制对象）→ 校验 → 执行 → toast 反馈 → 回到列表

次流程：
- 从复制弹窗进入员工选择弹窗再返回：点击选择器 → 员工选择弹窗（搜索/筛选/勾选）→ 确认选择 → 回到复制弹窗
- 在复制弹窗中修改已选员工：在输入框中删除已选用户 → 重新点击选择器添加

异常流程重点关注：
- 未勾选复制信息就确认
- 未选择复制对象就确认
- 复制对象中存在未加入状态的用户
- 复制对象中存在未认证状态的用户
- 复制对象超过 200 人上限

## 2. 主交互流程

### 节点 1：触发复制

用户动作：
权限管理员进入「权限管理模式 > 子管理配置页」，在子管理员列表中找到要复制的来源子管理员，点击其操作列中的「复制」按钮。

系统反馈：
系统打开「复制」弹窗。弹窗以模态方式覆盖在列表页上方。弹窗标题为「复制子管理员权限」。弹窗内展示两个区域：上半部分为复制信息（可授权组织、可授权功能两个勾选项，默认全部勾选），下半部分为复制对象（员工选择器输入框，当前为空，提示"最多可以复制给 200 名用户"）。

本节点需要前置解释：
- 管理员需要知道复制的是什么——弹窗标题和复制信息中的勾选项已经说明。
- 管理员不需要知道叠加规则，但如果对"复制给已有子管理员会不会覆盖"有顾虑，可以在复制信息区域下方添加一行说明文字。

建议页面文案：
- 弹窗标题：「复制子管理员权限」
- 复制信息区域标题：「复制信息」
- 勾选项：「可授权组织」「可授权功能」
- 复制对象区域标题：「复制对象」
- 选择器提示：「请选择复制对象」
- 上限提示：「最多可以复制给 200 名用户」
- 叠加说明（建议添加）：「复制给已有子管理员时，不会覆盖其原有配置」
- 取消按钮：「取消」
- 确认按钮：「确认」

下一步：
管理员配置复制信息和复制对象后，点击「确认」进入校验流程（节点 4）。如果点击「取消」，关闭弹窗，回到列表页。

### 节点 2：选择复制对象

用户动作：
管理员在复制弹窗中点击员工选择器输入框，触发「选择员工」弹窗。

系统反馈：
系统打开「选择员工」弹窗，样式与「添加子管理员」弹窗中的员工选择弹窗一致。弹窗内展示：
- 顶部搜索框，支持按姓名或手机号搜索。
- 员工列表，每个员工行展示姓名、手机号、部门，行首有勾选框。
- 列表仅展示已启用且已认证的员工。
- 列表顶部有提示文字说明筛选范围。
- 底部展示已选人数统计和确认/取消按钮。
- 支持多选，已选中的员工行为高亮状态，勾选框为选中态。

本节点需要前置解释：
- 为什么有些员工搜不到——弹窗顶部明确说明"仅展示已启用且已认证的员工"。
- 最多能选多少人——列表顶部或底部显示"最多可选 200 人"，选中接近上限时给出提示。

建议页面文案：
- 弹窗标题：「选择员工」
- 搜索框提示：「搜索姓名或手机号」
- 筛选说明：「仅展示已启用且已认证的员工」
- 列表为空时：「未找到符合条件的员工」
- 底部已选统计：「已选 N 人」（N 为已选人数，未选时显示"已选 0 人"）
- 确认按钮：「确认」（已选人数为 0 时置灰不可点击）
- 取消按钮：「取消」

下一步：
管理员勾选目标员工后，点击「确认」回到复制弹窗。已选员工展示在复制对象的输入框中（以标签形式展示每个已选用户的姓名和手机号，支持点击 × 移除）。如果管理员在员工选择弹窗中点击「取消」，不保存选择结果，回到复制弹窗时复制对象保持之前的状态。

### 节点 3：修改已选复制对象

用户动作：
回到复制弹窗后，管理员查看已选员工，发现有选错的，点击某个员工标签右侧的「×」移除。需要补充选择时，再次点击选择器输入框。

系统反馈：
- 点击「×」移除员工后，该标签从输入框中消失，已选人数减少。
- 再次点击选择器打开员工选择弹窗时，之前的选择状态保留（已选员工在弹窗中仍为选中态）。
- 如果管理员已选满 200 人，选择器输入框置灰或显示"已达到上限 200 人"，不再响应点击。

本节点需要前置解释：
- 管理员需要知道已选人数和上限，输入框下方持续显示"已选 N/200 人"。

建议页面文案：
- 已选人数提示：「已选 N/200 人」
- 达到上限提示：「已达到上限 200 人，无法继续添加」

下一步：
管理员确认选择无误后，点击「确认」进入校验流程（节点 4）。

### 节点 4：校验与确认

用户动作：
管理员在复制弹窗中点击「确认」按钮。

系统反馈：
系统按顺序执行以下校验，任一未通过即阻断并弹出提示，不继续后续校验也不会执行复制。

**正常结果（全部校验通过）**：
系统关闭弹窗，执行复制操作，toast 提示「复制成功」。根据 business 蓝图的建议，如果复制对象数量较多，toast 可扩展为「已成功复制给 N 人」。

**异常结果一：未勾选复制信息**
触发条件：管理员未勾选任何复制信息项（可授权组织和可授权功能都未勾选）就点击确认。
系统反馈：在复制信息区域高亮提示，并弹出 toast 或行内错误提示「请选择复制信息」。
用户下一步：勾选至少一项后重新点击确认。

**异常结果二：未选择复制对象**
触发条件：管理员未选择任何目标员工就点击确认。
系统反馈：在复制对象区域高亮提示，并弹出 toast 或行内错误提示「请选择至少一名复制对象」。
用户下一步：点击选择器添加至少一名员工后重新点击确认。

**异常结果三：部分复制对象未加入**
触发条件：选中的复制对象中存在加入状态不是"已加入"的用户。
系统反馈：阻断提交，toast 提示「XXX、XXX 加入状态不是已加入，不能成为子管理员」。其中 XXX 替换为实际用户名/手机号。
用户下一步：在复制对象输入框中移除这些不符合条件的用户，或关闭弹窗后先处理这些用户的加入问题再回来复制。

**异常结果四：部分复制对象未认证**
触发条件：选中的复制对象中存在未完成实名认证的用户。
系统反馈：阻断提交，toast 提示「XXX、XXX 未完成实名认证，不能成为子管理员」。其中 XXX 替换为实际用户名/手机号。
用户下一步：移除不符合条件的用户，或关闭弹窗后通知这些用户完成实名认证再回来复制。

本节点需要前置解释：
- 校验是顺序执行的，管理员一次只能看到一个错误。修正当前错误后重新点击确认，如果还存在下一个校验失败，才会看到下一个错误提示。

下一步：
校验全部通过后进入节点 5（执行复制）。校验失败后管理员修正问题并重新点击确认，直到通过或取消。

### 节点 5：复制完成

用户动作：
校验通过后，复制自动执行，管理员无需额外操作。

系统反馈：
- 弹窗关闭，回到子管理员列表页。
- 页面顶部 toast 提示「复制成功」（如有多人，建议显示「已成功复制给 N 人」）。
- 操作记录已自动生成。
- 如果系统开启了双管理员互审模式，审批记录已自动生成（具体审批状态展示取决于产品确认的审批规则）。

本节点需要前置解释：
- 如果复制对象中包含已有子管理员，其原有权限保持不变，仅叠加了本次复制的内容。这一点在弹窗中的叠加说明文字中已提前告知。

下一步：
管理员回到子管理员列表页，可以查看复制结果（目标用户已出现在列表中或权限已更新），或在操作记录中查看本次复制的记录。

## 3. 次交互流程

### 次流程 A：复制后查看操作记录

用户动作：
管理员复制成功后，想要确认操作记录是否正确生成。从导航进入「安全管理 > 操作记录」，在操作记录列表中按操作模块筛选"子管理员模式"或按操作类型筛选"复制"。

系统反馈：
操作记录列表展示本次复制记录。记录行显示：操作时间、操作人、操作类型（"复制-可授权组织"或"复制-可授权功能"）、操作对象。点击详情可查看完整记录，包含来源子管理员和目标用户列表。

建议页面文案：
- 操作类型筛选项：「复制-可授权组织」「复制-可授权功能」
- 记录详情弹窗标题：「操作记录详情」
- 记录详情中操作内容示例：「将子管理员【张三/138xxxx1234】可授权组织复制给【李四/139xxxx2345】【王五/137xxxx3456】」

下一步：
管理员确认记录无误后关闭详情，操作记录查看完成。

### 次流程 B：复制对象超过 200 人上限

用户动作：
管理员需要复制给超过 200 名用户，第一次复制选择了 200 人完成。需要继续复制给更多用户。

系统反馈：
第一次复制完成后，管理员可以再次点击同一来源子管理员的「复制」按钮，第二次复制剩余用户。流程与第一次完全一致。

建议：如果这类分批复制场景频繁出现，未来可考虑增加「复制历史」快速入口，让管理员可以基于上一次复制配置快速追加目标用户。本次不做。

## 4. 异常与阻断流程

### 异常一：未选择复制信息

发生时机：在复制弹窗中点击「确认」按钮时。
触发条件：可授权组织和可授权功能两项均未勾选。
系统反馈：在复制信息区域下方显示行内错误提示，该区域高亮。提示文案：「请选择复制信息」。确认按钮不执行提交，弹窗保持打开状态。
用户下一步：至少勾选一项后重新点击「确认」。

### 异常二：未选择复制对象

发生时机：在复制弹窗中点击「确认」按钮时。
触发条件：复制对象输入框为空，未选择任何员工。
系统反馈：在复制对象区域下方显示行内错误提示，该区域高亮。提示文案：「请选择至少一名复制对象」。确认按钮不执行提交，弹窗保持打开状态。
用户下一步：点击员工选择器，选择至少一名员工，然后重新点击「确认」。

### 异常三：复制对象加入状态不符

发生时机：在复制弹窗中点击「确认」按钮时。
触发条件：选中的复制对象中有 1 名或多名员工的加入状态不是"已加入"。
系统反馈：阻断提交，toast 提示。提示文案：「张三、李四 加入状态不是已加入，不能成为子管理员」（其中"张三、李四"为实际不符合条件的用户名/手机号）。弹窗保持打开状态，复制对象区域中不符合条件的员工标签高亮或标注异常状态。
用户下一步：
- 点击异常员工标签上的「×」将其从复制对象中移除。
- 如果管理员认为这些用户应该符合条件，取消本次操作，先去成员管理页面处理这些用户的加入状态，再回来复制。

### 异常四：复制对象认证状态不符

发生时机：在复制弹窗中点击「确认」按钮时。
触发条件：选中的复制对象中有 1 名或多名员工未完成实名认证。
系统反馈：阻断提交，toast 提示。提示文案：「张三、李四 未完成实名认证，不能成为子管理员」。弹窗保持打开状态，复制对象区域中不符合条件的员工标签高亮或标注异常状态。
用户下一步：
- 点击异常员工标签上的「×」将其从复制对象中移除。
- 通知这些用户完成实名认证后再回来复制。

### 异常五：复制对象超过 200 人上限

发生时机：在员工选择弹窗中继续勾选时。
触发条件：已选人数已达到 200 人，管理员继续尝试勾选更多员工。
系统反馈：勾选操作被阻止，toast 提示「已选人数已达上限 200 人」。新增勾选动作不生效。
用户下一步：确认当前已选的 200 人，完成本次复制。如有剩余用户需要复制，返回列表后再次发起复制操作。

### 异常六：所有可选员工均不满足条件（员工选择弹窗为空）

发生时机：管理员打开员工选择弹窗时。
触发条件：企业内当前没有同时满足"已加入"和"已认证"条件的员工（或搜索关键词没有匹配结果）。
系统反馈：弹窗列表区域展示空状态，文案：「未找到符合条件的员工」。
用户下一步：如果是因为搜索关键词不匹配，修改搜索词重试。如果确实没有符合条件的员工，关闭弹窗，告知管理员需要先确保目标用户已加入企业并完成实名认证。

### 异常七：双管理员互审模式下审批链路异常（待确认）

发生时机：复制成功后生成审批时。
触发条件：[GAP] 审批系统不可用或审批流程配置异常。当前需求对双管理员互审的审批规则不明确，无法完整描述此异常的处理方式。
系统反馈：[GAP] 取决于审批规则的最终确定。
用户下一步：[GAP] 取决于审批规则的最终确定。

## 5. 页面 / 弹窗 / 抽屉设计

### 复制弹窗

页面目标：让管理员选择要复制的权限内容和目标员工，一步完成复制操作。

页面结构：
从上到下分为四个区域：
1. 弹窗标题栏：标题"复制子管理员权限"，右侧关闭按钮。
2. 复制信息区：标题"复制信息"，两个勾选项（可授权组织、可授权功能），默认勾选。下方一行叠加说明文字。
3. 复制对象区：标题"复制对象"，员工选择器输入框（以标签形式展示已选员工，未选时为空），下方显示已选人数和上限提示。
4. 底部按钮区：取消按钮（次要按钮）和确认按钮（主要按钮）。

具体文案：
- 弹窗标题：「复制子管理员权限」
- 复制信息区标题：「复制信息」
- 勾选项 1：「可授权组织」
- 勾选项 2：「可授权功能」
- 叠加说明：「复制给已有子管理员时，不会覆盖其原有权限配置」
- 复制对象区标题：「复制对象」
- 选择器占位提示：「请选择复制对象」
- 已选人数：「已选 N/200 人」
- 上限提示（悬停或已满时）：「最多可以复制给 200 名用户」
- 确认按钮：「确认」
- 取消按钮：「取消」

按钮：
- 主按钮：确认（蓝色/品牌色），始终可点击（校验失败时通过错误提示反馈，不通过置灰方式阻止点击）。
- 次按钮：取消（灰色/边框样式），始终可点击，点击后关闭弹窗不保存。

成功反馈：
弹窗关闭，页面顶部 toast：「复制成功」。如有多人：「已成功复制给 N 人」。

失败反馈：
详见「异常与阻断流程」中异常一至异常四的系统反馈文案。

### 员工选择弹窗

页面目标：让管理员在多选模式下从符合条件的员工中选择复制目标，支持搜索、浏览、勾选。

页面结构：
从上到下分为四个区域：
1. 弹窗标题栏：标题"选择员工"，右侧关闭按钮。
2. 搜索区：搜索输入框，支持按姓名或手机号搜索。
3. 列表区：员工列表，每行展示勾选框、姓名、手机号、部门。顶部一行筛选说明文字。列表为空时展示空状态。
4. 底部操作区：左对齐"已选 N 人"，右对齐取消和确认按钮。

具体文案：
- 弹窗标题：「选择员工」
- 搜索框占位提示：「搜索姓名或手机号」
- 筛选说明：「仅展示已启用且已认证的员工」
- 列表空状态：「未找到符合条件的员工」
- 已选统计：「已选 N 人」
- 确认按钮：「确认」
- 取消按钮：「取消」

## 6. 状态与反馈文案

- 状态：复制弹窗的初始状态
  含义：弹窗刚打开，复制信息默认全选，复制对象为空。
  用户可做：取消勾选某项复制信息、点击选择器选择复制对象。
  页面反馈：复制信息两项均勾选，复制对象输入框显示占位提示"请选择复制对象"，下方显示"已选 0/200 人"。

- 状态：复制弹窗的已配置状态
  含义：复制信息和复制对象均已配置完成，可以提交。
  用户可做：修改复制信息勾选、添加或移除复制对象、点击确认提交、取消关闭。
  页面反馈：复制对象输入框中展示已选员工标签，下方显示"已选 N/200 人"。确认按钮可点击。

- 状态：校验中
  含义：点击确认后，系统正在校验。
  用户可做：等待。
  页面反馈：确认按钮显示加载状态（如转圈），弹窗不可关闭。校验通常很快完成（毫秒级），此状态短暂出现。

- 状态：校验失败
  含义：校验命中某一项不通过条件。
  用户可做：查看错误提示、修正问题、重新提交。
  页面反馈：对应区域高亮，错误提示展示。弹窗保持打开。

- 状态：复制执行中
  含义：校验通过，正在执行复制操作。
  用户可做：等待（通常很快完成，但如果复制对象超过百人可能需要短暂等待）。
  页面反馈：确认按钮显示加载状态。

- 状态：复制成功
  含义：复制已全部执行完成，权限已生效，操作记录已生成。
  用户可做：返回列表，查看复制结果，或继续其他操作。
  页面反馈：弹窗关闭，页面顶部 toast 提示「复制成功」。

- 状态：员工选择弹窗的空状态
  含义：没有符合条件的员工，或搜索无结果。
  用户可做：修改搜索条件，或关闭弹窗。
  页面反馈：列表区域中央展示空状态图（如无搜索结果图标）和文案"未找到符合条件的员工"。

- 状态：员工选择弹窗的选择中状态
  含义：管理员正在浏览和勾选员工。
  用户可做：勾选/取消勾选、搜索、翻页。
  页面反馈：已勾选的员工行高亮，底部已选人数实时更新。

- 状态：员工选择弹窗的达上限状态
  含义：已选满 200 人。
  用户可做：确认当前选择、取消勾选部分员工后重新选择。
  页面反馈：未勾选的员工勾选框置灰不可点击，底部提示"已选人数已达上限 200 人"。

## 7. 待确认问题

1. **双管理员互审审批规则**：审批前置还是后置？审批期间权限是否生效？这直接影响提交后的反馈文案——是"复制成功"还是"已提交审批，等待审核"。

2. **加入状态术语**：需求文件中"已启用"和"已加入"表述不一致。校验错误提示中使用"已加入"，员工选择弹窗筛选说明中使用"已启用"，需要统一。建议统一为"已加入"。

3. **部分失败处理**：校验三和四命中的用户是否允许管理员在弹窗内直接移除后继续提交（无需重新打开员工选择弹窗）？当前方案假设可以。如果系统要求全部对象满足条件才能提交，则需要调整交互——不符合条件的员工不应出现在选择弹窗中（即在选择阶段就过滤掉），而不是到校验阶段才暴露。

4. **复制结果明细**：复制成功后是否需要展示明细（如成功/失败人数）？当前方案仅使用 toast「复制成功」。如果需要明细，需要在弹窗关闭前增加一个结果摘要步骤。

5. **批量复制时的性能体验**：如果复制对象达到 200 人上限，复制操作可能需要较长时间。是否需要进度提示（如"正在复制... 50/200"）？当前需求未涉及，建议根据实际接口性能评估决定。
