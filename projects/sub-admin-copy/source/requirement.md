# 需求：子管理员支持复制

## 原始需求

集团型企业使用「子管理员模式」下放权限管理能力。部分客户子管理员数量较多（如广西交投 200+），这些子管理员的「可授权功能」通常一致，但「可授权组织」不同。当前需逐个子管理员单独勾选相同功能权限，配置效率低。

本次新增「复制」能力，使权限管理员可以：
- 复制某个子管理员的可授权组织
- 复制某个子管理员的可授权功能
- 批量复制给多个用户（最多 200 名）
- 将普通用户快速设置为子管理员
- 对已有子管理员叠加授权范围
- 记录复制操作，满足审计和追溯要求

## 确认后的目标

在子管理员列表的操作列增加「复制」入口，通过弹窗选择复制内容（可授权组织/可授权功能）和复制对象，批量完成子管理员权限配置，并在操作记录中留痕。

## 本次任务范围

聚焦「子管理员复制」单次操作的设计：复制弹窗交互、校验反馈、操作记录、双管理员互审审批衔接。不涉及角色模板、自动授权规则等其他批量授权手段的对比或改造。
