# 需求文档：子管理员支持复制

## 原始需求

集团型企业使用「子管理员模式」下放权限管理能力。部分客户子管理员数量较多（如广西交投 200+），这些子管理员的「可授权功能」通常一致但「可授权组织」不同。当前配置需逐个手动勾选相同功能权限，实施工作量大、效率低。

本次新增「复制」能力，使权限管理员可以复用已配置子管理员的权限信息，降低批量配置成本。

### 核心功能单元

1. **复制入口**：子管理员模式列表「操作」列新增「复制」，展示在操作项最左侧
2. **复制弹窗**：分为「复制信息」（可授权组织/可授权功能）和「复制对象」（用户选择器）两部分
3. **复制信息**：默认全选，至少选一项，支持多选
4. **复制对象**：通过员工选择弹窗选择，最多 200 人，目标需满足加入状态（已启用）和认证状态（已认证）
5. **复制校验**：按复制信息→复制对象→加入状态→认证状态顺序校验
6. **复制结果**：成功 toast 提示「复制成功」；普通用户复制后成为子管理员；已有子管理员叠加不覆盖
7. **操作记录**：复制成功生成操作记录，区分「复制-可授权组织」和「复制-可授权功能」
8. **双管理员互审**：若开启则复制完成时生成审批

## 用户确认目标

- 权限管理员可一次操作将某个子管理员的权限配置复制给多个目标用户
- 复制行为可追溯——操作记录能区分复制来源
- 已有子管理员接收复制时叠加而非覆盖，且用户能理解叠加后的结果

## 本次任务范围

本次正式蓝图任务覆盖：
- 管理后台：子管理员模式列表的复制入口、复制弹窗、员工选择弹窗
- 校验流程：四层顺序校验及异常反馈
- 复制结果处理：新建子管理员、已有子管理员叠加
- 操作记录：复制操作的操作记录生成
- 双管理员互审对接：审批生成与生效时机

不覆盖：
- 移动端独立设计
- 复制来源的部分权限选择（当前仅支持完整配置复制）
