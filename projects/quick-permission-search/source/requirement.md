# Requirement

- Project ID: quick-permission-search
- Task Name: 功能权限全局关键词命中高亮
- Domain: 业务/权限管理

## 要解决什么

权限管理员需要在 1100+ 菜单项和 1200+ 功能点中快速定位到特定功能权限，避免翻 35 屏逐行查找。

## 核心需求

在功能权限设置页面增加全局关键词搜索与高亮能力：管理员输入关键词后，页面上所有命中该关键词的文本（包括左侧锚点区和右侧内容区）全部高亮标记，实现快速定位。

## 页面结构

- 左侧为锚点区，右侧为类表格数据展示
- 无分页，全部数据已在页面上
- 非真正表格，不存在分页逻辑

## 已知事实

- 本次改动不涉及权限模型、业务规则、审批或数据范围变化
- 关键词策略：纯文本命中高亮，不改变任何权限配置逻辑
- 用户真正关心的是快速定位功能权限，不是筛选已勾选项

## 不确定点（不阻塞先做）

- 搜索框具体放置位置
- 多命中结果的导航方式（上一个/下一个）
- 命中和锚点区联动展开逻辑
