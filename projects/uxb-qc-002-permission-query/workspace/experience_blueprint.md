## 0. 本次关键设计判断

本次不是设计一个标准后台的"筛选区+表格+详情抽屉"——这是本用例测试的核心关注点。三种查询视角的信息展示结构不同：按人查询是"权限清单+来源"，按角色查询是"人员列表"，按权限项反查是"人员列表+获得方式"。不能用同一套列表模板套三个维度。

基于 IA-01（信息气味）：查询结果每项必须展示名称+来源标签+生效状态，让用户在不点击的情况下就能判断是否需要进一步查看。
基于 U-01（系统状态可见）：无结果/权限不足/查询超时等状态必须给出用户可见提示。

## 1. 交互流程总览

权限管理员进入权限查询页 → Tab切换查询视角（按人员/按角色/按权限项）→ 输入查询条件 → 查看查询结果 → 可选：点击"查看配置"跳转到对应配置页。

## 2. 主交互流程

### 2.1 查询入口与视角切换

**入口**：权限管理导航 > 权限查询（新增独立导航项）

**视角切换**：页面顶部Tab切换——使用Tab而非下拉，因为三种视角的查询条件输入方式和结果展示结构不同（承接 business 规则3）

- Tab 1：按人员查询（默认选中，对应 01_范围与边界 People-centric 入口模式）
- Tab 2：按角色查询（对应 Role-centric）
- Tab 3：按权限项查询（对应 按权限项反查——12_查询与配置路径中标记为[GAP]的维度）

### 2.2 按人员查询

条件：人员选择器（搜索姓名/账号），单选
结果：人员基本信息（姓名、部门）+ 权限列表按分类（角色/功能/数据）分组
每项展示：权限名称、来源标签（管理员分配/角色继承/自助申请）、生效状态、获取时间

### 2.3 按角色查询

条件：角色下拉选择器，单选
结果：角色基本信息 + 拥有该角色的人员列表
每项展示：人员姓名、部门、获得方式（直接分配/继承）、生效状态

### 2.4 按权限项查询

条件：权限项搜索选择器（支持关键词搜索），单选
结果：权限项基本信息 + 拥有该权限的人员列表
每项展示：人员姓名、部门、获得方式、生效状态

## 3. 次交互流程

### 3.1 跳转配置页

- 查询结果每项后提供"查看配置"链接（不是按钮——视觉上区分查询与配置）
- 点击后跳转到对应配置页
- 跳转前保存查询条件和结果，浏览器返回时恢复查询状态

### 3.2 导出

[GAP] 如支持导出：查询结果上方提供"导出"按钮，导出为Excel，仅导出当前查询条件下的结果。

## 4. 异常与阻断流程

### 4.1 无查询结果
- 用户输入查询条件后点击搜索
- 系统返回空结果
- 页面展示空状态：图标 + "未找到匹配结果，请修改查询条件后重试"
- 用户可修改查询条件重新搜索，或切换到其他查询视角
- 不改变当前页面滚动位置

### 4.2 查询权限不足
- 用户进入权限查询页面
- 系统检测当前用户角色，判断其可查看的查询维度
- 如果用户无权查看某维度（如审计人员不能按人查），该Tab置灰
- 置灰Tab hover展示提示："你没有权限查看此维度的信息，请联系管理员"
- [GAP] 不同角色的查询范围待产品确认

### 4.3 查询结果过多（超过500条）
- 用户输入通用查询条件，系统返回大量结果
- 系统分页展示，每页50条，底部展示分页器
- 查询加载中展示骨架屏
- 如果结果超过1000条，顶部提示："找到超过1000条结果，建议输入更精确的查询条件缩小范围"

### 4.4 数据覆盖不完整
- 管理员在查询结果中注意到某些权限模块的数据未出现
- 结果列表上方展示提示条："以下结果仅覆盖功能权限和角色权限，数据权限、表单权限等暂未包含在查询范围内"
- 提示条可关闭，但每次查询后重新展示
- 这是承接 business 中的风险"跨功能域数据聚合失败"——通过透明告知管理预期

## 6. 状态与反馈文案

| 场景 | 文案 |
|------|------|
| 查询无结果 | 未找到匹配结果，请修改查询条件后重试 |
| 查询加载中 | 正在查询... |
| 查询权限不足 | 你没有权限查看此维度的信息 |
| 数据覆盖不完整 | 以下结果仅覆盖功能权限和角色权限，数据权限等暂未包含 |
| 跳转配置页 | "查看配置"链接（文字链，非按钮——区分于配置操作） |

## 7. 待确认问题

| 问题 | 当前处理 |
|------|----------|
| 查询维度是否覆盖数据权限 | 初期仅覆盖功能权限+角色权限，数据权限标注为暂未包含 |
| 查询结果是否允许跳转配置页 | 提供"查看配置"链接，跳转需受控 |
| 不同角色查询范围是否不同 | Tab按权限展示/隐藏 |
| 是否支持导出 | 方案建议支持 |
| 敏感权限是否需要脱敏 | 方案中标记为GAP |

## 附录：设计指南消费说明

- **IA-01（信息气味）** → 查询结果每项展示名称+来源+状态三要素，用户不点击即可判断
- **IA-02（分块）** → 按角色/功能/数据权限分组展示，不同来源用颜色标签区分
- **U-01（状态可见）** → 无结果/权限不足/数据不完整均给出明确提示
- **C-01（Hick's Law）** → 三种查询视角用Tab而非平铺，减少同时展示的选择
- **反馈与报错** → 空状态/错误状态文案包含"原因+下一步"
