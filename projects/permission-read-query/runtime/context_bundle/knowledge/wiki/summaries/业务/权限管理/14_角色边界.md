## 1. 知识定位

这是一份权限域的角色边界卡，用来回答“超级管理员、子管理员、普通管理员、员工等不同角色分别看到什么、能做什么，以及哪些边界彼此独立”。

它用于澄清角色视角下的可见边界与操作边界。

## 2. 任务触发线索

当任务需要解释不同管理角色的权限边界、子管理员隔离范围、协作可见性与后台管理权限的区别时，应优先读取本文件。

## 3. 覆盖内容

本文件覆盖权限域中的角色视角与边界说明，重点包括：

- 超级管理员：默认可见完整权限域，新任超管会自动继承系统级全量功能权限与部分审批管理能力
- 子管理员：可见与可操作范围取决于超管配置，包括组织管辖范围和应用管辖范围
- 普通管理员：能力边界以产品配置为准，不应假设默认全能
- 员工：通常由角色或默认全员可见应用决定基础可见性
- 边界说明：
  - 可见边界与可操作边界不必然一致
  - 子管理员隔离会同时影响谁能看、谁能改、谁能授予
  - 协作类应用中的员工可见性还要参考协作可见性模型

## 4. 可直接使用的稳定结论

- 角色边界至少要分开理解超管、子管理员、普通管理员和员工四类视角。
- 子管理员的核心约束不是“是不是管理员”，而是其组织范围与应用范围的交叉边界。
- 可见边界与可操作边界不是同一个概念，不能因为看得见就默认能改。
- 协作可见性会对成员之间的可见边界产生额外影响，不能只看后台管理角色。
- 任何角色边界说明都应优先落到“谁能看、谁能改、谁能授予”三个问题上。
