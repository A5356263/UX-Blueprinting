# 页面事实交接

- 项目：支持管理员对订单标记作废
- 来源：spark-output/requirements_baseline.md
- 事实数量：12

## 页面事实

### HF-001
- 类型：内容与操作
- 事实：消费平台的月结对账权限配置中新增“订单作废”权限项。
- 基线来源：§2 / BO-003

### HF-002
- 类型：条件与权限
- 事实：“订单作废”对新客户和历史客户均默认不勾选。
- 基线来源：§5 / BR-001

### HF-003
- 类型：条件与权限
- 事实：只有已配置“订单作废”权限的管理员可以执行订单作废。
- 基线来源：§3 / RP-001、RP-002

### HF-004
- 类型：条件与权限
- 事实：订单同时满足未结算、员工未提报、财务未提报、未作废和未占用预算时，才允许进入作废确认。
- 基线来源：§5 / BR-002

### HF-005
- 类型：内容与操作
- 事实：订单作废必须经过二次确认，并说明操作不可撤销及订单将无法报销或对账结算。
- 基线来源：§4 / FN-002

### HF-006
- 类型：校验
- 事实：作废原因可以不填写；填写时不超过 500 字。
- 基线来源：§5 / BR-005

### HF-007
- 类型：状态与结果
- 事实：作废成功后，订单结算状态显示为“已作废”。
- 基线来源：§6 / ST-002

### HF-008
- 类型：内容与操作
- 事实：已作废订单支持查看作废时间、作废操作人和作废原因。
- 基线来源：§6 / ST-002

### HF-009
- 类型：状态与结果
- 事实：已作废订单不提供恢复、变更、手工结算、占用预算和批量选择。
- 基线来源：§6 / ST-002

### HF-010
- 类型：状态与结果
- 事实：员工个人订单列表不展示已作废订单。
- 基线来源：§10 / AC-006

### HF-011
- 类型：状态与结果
- 事实：费用或单据选择订单时，已作废订单不可选择。
- 基线来源：§10 / AC-006

### HF-012
- 类型：状态与结果
- 事实：确认作废时订单已不满足条件，本次作废失败，订单保留变化后的状态。
- 基线来源：§7 / EX-004
