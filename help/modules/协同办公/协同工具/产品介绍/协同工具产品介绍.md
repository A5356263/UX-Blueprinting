## 一、协同工具产品介绍

薪福通协同工具是辅助办公的一系列工具，主要包含：通讯录、企业公告、公文、信息收集、必应、智能会议室、日程等多个产品。

### 1. 通讯录
通讯录是用于存储企业内部员工信息的管理工具，包括员工的基本信息、联系方式、职位等信息，在薪福通通讯录中，您可以方便的管理和查找企业内部员工信息，以便于进行内部沟通和协作。

- **路径**：登录薪福通在底部导航栏点击"通讯录"，进入列表页面可查看部门，员工等信息。

### 2. 企业公告
企业公告是为企业设计的协同办公软件产品，旨在帮助企业高效、便捷地发布和管理内部公告信息。通过集中化的公告平台，企业能够快速传达重要通知、政策变动、活动安排等关键信息，确保所有员工都能及时获取并了解公司动态。

### 3. 公文
公文是实现组织内部文件的电子化管理与流转，提高办公效率和规范性，确保信息传递的安全性和及时性。通过公文，可以完成文件的起草、审核、签发、归档等全过程管理，支持多级审批流程，方便查询和统计分析，有效促进部门间的协同工作。

### 4. 信息收集
信息收集可以帮助企业业务人员方便快捷地针对员工满意度、活动、薪酬核算、福利等场景收集员工建议和反馈，改进公司管理，提高公司工作效率和管理水平。

- **路径**：登录薪福通在工作台在全局搜索中，搜索"信息收集"即可使用，如未搜索到可联系管理员开通权限后使用。

### 5. 必应
必应支持企业进行个人/团队待办事项的创建、完成及验收全流程管理。

- **路径**：登录薪福通在工作台在全局搜索中，搜索"必应"，即可使用。

### 6. 智能会议室
智能会议室是企业内部会议室资源的数字化管理工具，提供包括会议室创建、预约及会议通知等全流程功能，便于企业管理和使用会议室。

- **路径**：应用中心-协同办公-智能会议室，需企业管理员订阅后，企业员工才可使用。

### 7. 日程
日程可以帮助用户高效管理日常工作和生活，它可以创建工作日程，安排会议，查看待办事项并进行提醒，让用户更好地掌控自己的时间和任务。

- **路径**：工作台—协同办公—日程，点击进入可查看和创建日程事项。

## 二、协同工具核心功能介绍

### 1. 通讯录
1. **组织架构**：展示企业内的组织及成员信息，可提升企业内的沟通效率。
2. **我的部门**：展示与"我"直接相关的部门及成员信息，可提升部门内的沟通效率。
3. **常用联系人**：可以自定义添加常用联系人，可提升日常高频协作场景的沟通效率。

### 2. 企业公告
1. **公告发布**：支持文字、图片、附件等多种形式的公告内容发布，满足企业多样化的信息传达需求。
2. **分类管理**：提供公告分类功能，便于员工快速查找和浏览相关公告信息。
3. **发布范围**：支持按部门、岗位、员工类型等维度设置公告查看权限，确保信息的精准传达。
4. **提醒功能**：员工可以通过多端的工作台卡片、消息提醒等查看企业公告，确保员工不会错过重要信息。
5. **历史记录**：保存公告历史记录和每条公告的已读、未读情况，便于企业随时查阅和追溯。

### 3. 公文
1. 支持发文拟稿、收文、签报等公文管理能力，有效实现企业公文的在线流转与发布，确保企业公文规范化管理。
2. 支持企业公文字号管理、密级管理、文种管理、紧急程度管理等能力，支持企业公文的分类与列表展示等功能。
3. 支持功能的多级、多部门审批能力，能够按照管理诉求实现公文的多部门会签审批，自定义审批流程。

### 4. 信息收集
招乎信息收集助手作为招乎平台信息收集及问卷调查应用，目前分为两个模块：问卷调查、补录表单。

1. **问卷调查**：多种题型可选，企业可灵活编辑问卷，适用于意见收集、需求调研、投票打分等场景。
2. **补录表单**：创建人通过Excel导入数据，适用于资料补填、数据审核、信息核对等场景。

### 5. 必应
1. **创建待办**：自定义提醒时间节点、配置处理人、抄送人与重复规则。
2. **待办列表**：支持发起人、处理人、抄送人等多列表呈现。
3. **协同处理**：支持催办、转处理人、评审等待办协同处理操作。

### 6. 智能会议室
1. **会议室管理**：支持楼栋、会议室等会议资产的数字化信息录入。
2. **会议室预约**：可视化忙闲视图展示会议室情况，可快速预约会议室。
3. **预约展示**：日历视图呈现用户预约情况。

### 7. 日程
1. **创建工作日程**：进入日程页面点击"新建"弹出创建弹窗，输入日程，会议，活动等标题，设置提醒时间段，选择参与人，地点，会议号等信息，薪福通通知助手会给每位参与人发送消息通知，提醒参与人进行协同。
2. **订阅日程**：可订阅团队、部门的日程，进行协同工作，查看同事日程待办事项完成情况。
3. **设置日程**：可以对日程进行日历视图、默认项、语音设置等。

## 三、协同工具核心优势介绍

### 1. 通讯录
1. **高效管理**：通讯录与人事花名册数据实时互通，实现一处管理多系统同步更新，提升联系人管理效率。
2. **精准搜索**：支持多种搜索方式，可以根据姓名，拼音、工号，电话，快速找到需要联系的人。
3. **权限管理**：可以为不同的员工，团队分配不同的查看权限，让信息更安全可靠。

### 2. 企业公告
1. **高效传达**：通过集中发布和管理公告，大幅提升企业内部信息的传达效率。
2. **形式多样**：支持多种公告形式，满足企业不同场景下的信息传达需求。

### 3. 公文
1. 灵活的自定义流程配置，满足企业个性化流程需求。
2. PC与App双终端服务支持，高效移动办公。
3. 提供在线拟稿、模板套红等多种，快速生成符合要求的格式。
4. 依托金融云服务，系统及数据安全级别高。

### 4. 信息收集
1. **题型丰富，操作便捷，创建效率高**：支持多种问卷题型，满足不同的使用场景。拖拽式排序，编辑，更容易上手！
2. **补录表单，用于表格数据的快速核对、高效补充录入**：表格数据精准发放至对应填写人录入，重要信息背对背收集，快速完成数据的拆分下发与汇总。
3. **投票评选，赋能组织人员，给大型活动增色添彩**：多场景下支持快捷创建视频、图片类投票评选，通过投票排行榜实时查看当前排名情况，参与者可在评论区互动。
4. **多种方式发送问卷，满足各类场景，收集效率翻倍**：通过系统邮件、招乎机器人等渠道向指定人员发送填写通知；可手动分享二维码、链接给填报人，提升回收效率。
5. **收集结果及自动统计数据分析，皆在掌控之中**：便捷查看收集进度，一键催办。支持数据自动统计分析，自定义快速导出结果。

### 5. 必应
1. **灵活的任务创建与管理**，用户可以自定义提醒时间节点、指定处理人和抄送人等配置，确保任务安排灵活高效，减少遗漏。
2. **多角色任务视图**，支持多个视角的任务查看，明确责任分工，提升团队协作效率。
3. **高效的协同处理功能**，提供催办、转处理人和评论功能，确保任务及时处理和调整，提高任务完成效率。
4. **智能化提醒与重复机制**：自动提醒和重复任务创建减少用户负担，帮助用户专注于任务执行，避免拖延。

### 6. 智能会议室
1. **数字化资产管理**，实现会议室及楼栋信息的数字化录入，便于统一管理和查询，提升资产管理效率。
2. **可视化预约界面**，用户可快速查看会议室使用情况，减少沟通成本，提高预约效率。
3. **提升资源利用率**：优化会议室分配，减少空置，确保资源高效利用。
4. **权限管理**：保障系统安全，仅授权用户可进行预约或管理操作，防止资源滥用。

### 7. 日程
1. 月、周、日等多种视图，多样化展示呈现。
2. 提供安排时间、日程授权、时间冲突提醒等功能，满足查看他人忙闲场景。
3. 会邀、变更、开始等全流程自动提醒。
4. 自定义公共日历管理，适配多场景公共事务管理需求。

## 明确规则

1. 通讯录与人事花名册数据实时互通。
2. 智能会议室需企业管理员订阅后，企业员工才可使用。
3. 信息收集如未搜索到可联系管理员开通权限后使用。
4. 公文依托金融云服务，系统及数据安全级别高。
5. 必应支持个人/团队待办事项全流程管理。
