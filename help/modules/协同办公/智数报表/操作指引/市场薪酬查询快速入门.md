# 市场薪酬查询快速入门

- 所属模块：协同办公 > 智数报表 > 操作指引
- 页面路径：https://xft.cmbchina.com/helpapp/help.html#/help-main/help-detail?category=COD0000000770
- 最近更新时间：2025-10-12

## 1. 使用步骤

1. 首先您可以输入自己关心的岗位名称，点击搜索后，可以查看与该岗位名称相关的所有岗位薪酬信息。您也可以选择自己感兴趣的职能分类，点击后查看该职能下所有岗位薪酬信息。
2. 当您想定位更加明确的岗位信息时，可以在筛选条件处针对市场范围、职能、职级进行筛选。
3. 点击卡片，可以看到与该岗位相关的更详细的信息（没有加入认证企业的用户无法查看此页面）。

## 2. 指标含义

| 指标 | 含义 |
|---|---|
| **年固定薪酬** | 年基本薪酬 + 年固定现金津贴 |
| **年基本薪酬** | 全职员工的税前12个月基本薪酬或固定薪酬 |
| **年固定现金津贴** | 包括固定发放的13薪、岗位津贴、住房津贴、餐补、通讯津贴、交通及其它固定发放的津贴或补贴 |
| **年总现金收入** | 年固定薪酬 + 年浮动薪酬（如：奖金、佣金/销售激励）。不含股票期权等长期激励 |
| **25分位** | 将适用的样本数据从小到大排列后，只有25%的数据小于此数值。反映市场较低水平 |
| **50分位** | 将适用的样本数据从小到大排列后位置居中的数，又称"中位值"，反映市场的中等水平 |
| **75分位** | 将适用的样本数据从小到大排列后，75%的数据小于此数值。反映市场的高端水平 |
| **90分位** | 将适用的样本数据从小到大排列后，90%的数据小于此数值。反映市场的极高端水平 |
| **平均值** | 平均值是样本值之和除以样本个数得出的。平均值不同于中位值。平均值受到样本中所有数值的影响，容易受极端值影响；而中位值仅代表中点的值，不受极端值影响。 |

## 明确规则

1. 没有加入认证企业的用户无法查看岗位详细信息。
2. 筛选条件支持市场范围、职能、职级三个维度。
