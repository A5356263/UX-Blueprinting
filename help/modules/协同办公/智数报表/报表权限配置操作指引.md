# 报表权限配置操作指引

- 所属模块：协同办公 > 智数报表
- 页面路径：https://xft.cmbchina.com/helpapp/help.html#/help-main/help-detail?category=COD0000000769
- 最近更新时间：2025-10-12

## 1. 权限角色介绍

薪福通权限中心及智数报表定义了多种具有管理功能的角色。按权限由小到大，下文介绍了各个角色的定义及在智数报表中的权限。

### 1.1 普通员工

普通员工仅能根据被授予的权限，查看智数报表应用中的菜单和菜单中的报表。

员工若无法看见期望的菜单或报表，一般原因为该员工没有对应报表的查看权限。可联系以下的有权角色赋权。

### 1.2 单张报表管理员

智数报表每张报表都可以有管理员，管理哪些员工可以查看、导出此报表，以及进行对应的数据权限控制。

单张报表管理员可以在报表入口右上角中见到齿轮图标，点击后即可打开权限设置界面，添加人员与角色，授予查看、导出、授权、数据访问等权限。

### 1.3 智数报表应用管理员

智数报表应用管理员对其他普通员工进行报表授权操作。超级管理员可在"报表管理员设置"菜单中设置。

### 1.4 业务管理员

业务管理员参与企业日常业务管理，比如薪资代发、人事管理、财务管理等。

超级管理员可从内部员工或外部人员中添加业务管理员，并分配权限。智数报表管理相关的功能权限也包含在其中。

### 1.5 超级管理员

超级管理员是能够进行企业创建、解除、认证的最高权限人员，在薪福通企业中仅有一位，默认拥有薪福通企业的所有控制权限，负责薪福通企业体系整体管理。可以增减业务管理员。

超级管理员在智数报表应用中拥有最高权限。具体来看，超级管理员可以查看企业下所有报表，可以查看智数报表应用所有的管理菜单。

## 2. 授权路径

### 2.1 单张报表管理员

单张报表管理员可在报表卡片下方的操作，将报表授权给其他员工。

### 2.2 业务管理员

当业务管理员被勾选上"权限管理"菜单时，可进行报表授权。

"权限管理"菜单可找超级管理员、其他业务管理员在管理后台授权。

"权限管理"菜单可对企业下所有报表进行授权。

### 2.3 超级管理员

超级管理员可以查看企业下所有报表、所有报表的管理菜单，可通过上文提到的单张报表管理员授权方式或业务管理员"权限管理"菜单授权方式，对普通员工进行报表授权。

## 3. 针对员工或角色授权

### 3.1 针对某几个员工授权

有权管理员可通过报表卡片下方的操作或"权限管理"菜单的"设置权限"，打开报表授权侧边栏，在"用户授权"标签页中，分别对几位员工进行单独授权。

**注意**：在单张报表中，此方法仅限授权最多20位员工。如需批量授权，请使用下文介绍的"角色授权"方式。

### 3.2 针对一类员工批量授权

**角色**：在薪福通中，作为一批员工的集合，用于批量管理用户的权限。角色由超级管理员、业务管理员在管理后台的角色管理菜单中进行管理。

有权限的管理员可通过报表卡片下方的操作或"权限管理"菜单的"设置权限"，打开报表授权侧边栏，在"角色授权"标签页中选择已经定义好的角色，并针对某个角色进行授权。此角色范围内的所有员工都会被赋予对应的报表权限。

## 明确规则

1. 普通员工只能看到被授予权限的菜单和报表。
2. 单张报表管理员最多可对20位员工单独授权，超出需使用角色授权。
3. 超级管理员在企业中仅有一位，默认拥有所有控制权限。
4. 业务管理员需要有"权限管理"菜单权限才能进行报表授权。
5. 角色由超级管理员、业务管理员在管理后台管理。
