# OA审批管理员使用手册

- 所属模块：协同办公 > OA审批 > 使用手册
- 最近更新时间：2025-10-14

企业使用表单前，需由企业超级管理员或表单审批管理员对相应表单进行提前配置，表单发布后员工才可正常发起使用。

## 1. 审批设置

路径：【管理后台-审批管理-审批设置】

### 1.1 审批操作设置
- **批量处理审批**：开启后审批人可批量审批，范围可选"全部人员"或"部分员工"
- **人员信息卡**：开启后审批人可在审批流中查询相关人员信息

### 1.2 消息通知设置
- **短信通知限制**：可限制每人每小时/每天最多收到的短信条数
- **代发审批汇总通知**：开启后，系统在设置时间发送一条汇总审批短信通知（如每隔1小时）
- **流程变动通知**：审批被退回/拒绝/撤销/撤回时通知已审批用户

## 2. 消息通知

PC端入口：工作台-最近待办 / 工具箱-待办
移动端入口：掌上薪福通APP

## 3. 处理审批

- **PC端**：工作台-最近待办快速审批、OA审批-审批中心-待处理
- **移动端**：工作台-待办、OA审批-审批中心-待处理
- 支持批量审批（需管理员开启功能）

## 4. 委托审批

当审批人无法处理审批时可委托他人。需先授权【OA审批-委托审批】功能权限，然后在【OA审批-高级设置-委托审批】新建委托。

管理员可切换至"管理员委托操作"界面为所有审批人设置委托。

## 5. 流程转派

针对已离职或无法处理待审批单据的情况，可设置批量转派或单个审批转派。
路径：【管理后台-审批管理-数据管理】

## 6. 流程交接

审批人离职或需替换审批角色时使用。路径：【管理后台-审批管理-数据管理】

## 7. 智能分析

路径：【OA审批-智能分析】，查看企业整体审批效率。
- 审批明细统计：通过率、完成率、审批耗时及趋势
- 超时明细统计：节点完成率、平均耗时、超时率及趋势

## 明确规则

1. 委托审批需单独授权功能权限
2. 批量审批功能需管理员开启
3. 管理员可代理所有审批人设置委托
