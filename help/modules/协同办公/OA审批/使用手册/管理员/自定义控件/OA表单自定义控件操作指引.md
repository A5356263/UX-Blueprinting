# OA表单自定义控件操作指引

- 所属模块：协同办公 > OA审批 > 使用手册 > 管理员 > 自定义控件
- 页面路径：https://xft.cmbchina.com/helpapp/help.html#/help-main/help-detail?category=COD0000001562
- 最近更新时间：2025-10-12

## 1. 功能说明

自定义控件支持企业自建表单控件，在OA审批表单设计页面直接拖拽使用，能够将企业自有系统的数据在OA审批表单中引用，打通企业系统数据连接到薪福通审批的通道。

## 2. 使用场景

- 企业存在自有的ERP系统，需要将ERP系统中的商品、客户、价格等信息在薪福通OA审批中展示，可自定义一个企业的"ERP"控件，通过接口的形式将ERP中的数据接入薪福通OA审批，以便审批申请人选择ERP系统中的数据以及领导审批时查看。
- 企业的采购、考勤、合同、绩效等其他系统也都可以通过自定义控件的形式，连接企业自有系统与薪福通OA审批。

## 3. 操作指引

### 3.1 新增自定义控件

1. **新增控件**：点击"新增控件"，创建企业自定义控件。
2. 在新增控件的弹窗中配置控件的名称、交互方式、引用的数据源、展示字段等。
3. 新增企业数据源，方便在上面的自定义控件时引用。
4. 配置数据源接口等信息。
5. 保存后即可在自定义控件的列表中查看已创建的自定义控件。

### 3.2 使用自定义控件

1. 在【管理后台-审批管理-通用审批】页面点击"创建审批"-"创建2.0自定义审批"，即可在表单设计的页面中看到创建的自定义控件。
2. 将自定义的控件拖入表单设计页面、配置相关的属性。
3. 如果自定义控件"ERP采购"中包含多个字段信息，且需要在表单内同时呈现多个字段，可拖拽多个"关联字段"控件，并将"引用对象"设置为自定义控件"ERP采购"，"关联字段"则选择需要展示的字段。
4. 点击发布按钮，发布此审批流程。

### 3.3 提交申请与处理审批

1. 在【OA审批-发起审批】界面中，您可以找到新建的审批单；进入后，直接选择对应的字段内容即可获取自定义字段"ERP采购"数据源中字段的信息。
2. 处理审批时查看详情页，直接展示ERP中的数据。

## 明确规则

1. 自定义控件需在"创建2.0自定义审批"中才能使用。
2. 自定义控件通过接口连接企业自有系统数据。
3. 关联字段控件可引用自定义控件中的多个字段。
