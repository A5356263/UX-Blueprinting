# OA审批自定义打印模板设置指引

- 所属模块：协同办公 > OA审批 > 使用手册 > 管理员 > 表单模板
- 页面路径：https://xft.cmbchina.com/helpapp/help.html#/help-main/help-detail?category=COD0000001562
- 最近更新时间：2025-10-14

## 1. 自定义打印模板使用须知

- OA自定义打印目前还在内测阶段，需申请开放白名单后才能使用（可联系市场经理或客服申请开通）。
- 暂不支持表单页面没有"表单设计"的表单（例如：请假、加班等系统自带表单，无"表单设计"按钮）。
- 暂不支持包含人事和考勤套件的表单。
- 暂不支持"表格"控件，员工在填写表单时可以增加多行，所以无法进行自定义打印模板设置。
- 审批信息暂不支持打印签名。

## 2. 流程配置

**步骤1**：企业超级管理员或表单审批管理员从【管理后台-审批管理-通用审批】，打开表单点击"高级设置"-"打印设置"。

**步骤2**：点击"自定义打印模板"，会提示：使用自定义打印模板需先发布审批表单，后续修改表单或流程需手动更新打印模板。仔细阅读提示信息后，点击"知道了"关闭提示信息（如果已经开启了自定义打印，此步骤略过）。

**步骤3**：点击"配置模板"，如果表单还未发布，会提示需要先发布表单才可以配置，按照提示点击"发布并配置"即可。

**步骤4**：进入配置模板页面：
- **模板名称**：与表单名称保持一致，不可修改。
- **表单字段与系统字段切换tab**：表单字段从表单自动获取（套件和表格控件字段自动过滤），系统字段为系统自带（当前时间、当前用户等）。
- **字段拖动模式切换**：标题和变量（如"姓名+$姓名"）或仅字段变量（如"$姓名"）。
- **字段列表**：从表单或系统获取的字段，可按需添加。
- **模板编辑功能区**：设置字体、字号、单元格宽/高等，类似Excel表格。
- **模板排版区**：按需拖入字段、删除不需要的字段，以Excel样式组合排版。
- **历史/预览/保存**：查看恢复历史模板、预览模板样式、保存模板。
- 第一次进入自动生成默认自定义模板，自动排版已有字段。
- 默认A4纸纵向排版，可在【页面布局】设置纸张参数，勾选"分页预览"查看是否超出纸张区域。
- 手动拖入的字段变量显示蓝色，可通过格式刷统一字体颜色。
- **审批信息和评论暂不支持手动拖入**。如需打印请勿删除；误删可通过历史记录恢复。

## 明确规则

1. 自定义打印模板处于内测阶段，需白名单开通。
2. 不支持请假、加班等系统自带表单（无表单设计按钮）。
3. 不支持包含人事和考勤套件的表单。
4. 不支持"表格"控件和打印签名。
5. 审批信息和评论不能手动拖入，误删需通过历史记录恢复。
