# OA审批员工使用手册

- 所属模块：协同办公 > OA审批 > 使用手册
- 最近更新时间：2025-10-14

## 1. 发起审批

### 1.1 PC端发起入口
- 入口1：【全部应用-OA审批】
- 入口2：【工作台-我的申请-前往审批中心】或【工作台-我的常用】
- 入口3：【OA审批-发起审批】- 从"草稿箱"发起

### 1.2 移动端发起入口
- 入口1：工作台选择【OA审批】进入
- 入口2：从草稿箱补充后发起

## 2. 填写表单

1. 选择具体表单进入
2. 填写内容，可从"草稿箱"或以往表单"快速导入"
3. 未完成可"存草稿"，完成点"提交"

## 3. 确认流程

提交后弹窗展示审批流及人员信息，需核对审批流程。部分审批节点为发起人自选，可在此处点"+"添加。

## 4. 撤销审批

当发起的审批流程尚未完成时可撤销。
- 移动端：【OA审批-审批中心-我发起的】- 点击撤销
- PC端：【OA审批-审批中心】- "我发起的" - 点击撤销

## 5. 员工消息通知

员工接收到待办、通知或在表单中被@时可通过以下入口查看：
- 移动端：工作台-最近待办/关注的通知、OA审批-审批中心、消息-通知助手/待办助手
- PC端：工作台-最近待办/关注的通知、OA审批-审批中心

## 明确规则

1. 发起审批三方式：直接发起、草稿箱、快速导入
2. 流程确认时可自选审批节点添加审批人
3. 处理中的审批可撤销
