# OA审批产品介绍

- 所属模块：协同办公 > OA审批 > 产品介绍
- 最近更新时间：2025-10-14

## 一、产品介绍

薪福通OA审批系统是一个综合性的在线审批平台，不仅支持业务审批需求，还支持企业根据需要自定义各类审批表单。通过灵活多变的功能设计，企业可以轻松构建符合需求的审批流程，提升管理效率。

## 二、核心功能

1. **联动多个业务版块**：除考勤、报销、人员异动外，还支持定薪调、离职交接、耗材领用等场景
2. **预置多种表单模板**：内置用车申请、开票申请等常用表单，可直接使用
3. **自定义表单样式**：拖拽即可快速设计表单，组件之间可配置关联关系
4. **自定义审批流**：按岗位、职级、角色指定审批流，根据表单内容、申请人信息设定分支流程，支持审批人修改限定内容
5. **线上审批，多渠道提醒**：支持PC端、手机端审批，待办通知+短信通知
6. **审批报表**：汇集审批报表，方便查询历史审批信息，综合管理所有审批单

## 三、核心优势

1. **审批流程效率高**：电子化审批消除纸质冗余，内置提醒与任务看板实时追踪
2. **全流程自动化**：审批内容关联员工档案/企业系统，自动带入业务数据；审批后自动发起下一流程；审批结束自动更新花名册
3. **流程标准化，信息安全**：校验规则降低人为失误，设定数据访问范围保护敏感信息
4. **全流程可追溯**：所有操作留痕，满足内外部审计需求
