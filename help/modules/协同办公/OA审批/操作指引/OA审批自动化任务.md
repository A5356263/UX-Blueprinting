# OA审批自动化任务：将审批表单内的数据与其他业务数据联动

- 所属模块：协同办公 > OA审批 > 操作指引
- 页面路径：https://xft.cmbchina.com/helpapp/help.html#/help-main/help-detail?category=COD0000001633
- 最近更新时间：2025-12-29

## 1. 使用场景介绍

当审批流程到达任意环节后，系统自动触发预设的自动化任务，该功能可以达到以下效果：

1. 自动发起一个新的审批流程。
2. 更新薪福通业务板块的数据（人员花名册数据等）。
3. 将审批完成的数据同步至企业其他业务系统中。

通过自动化任务配置，可实现审批数据与其他业务数据的联动，确保企业各项业务顺利衔接。

## 2. 操作步骤

### 2.1 新增自动化任务节点

1. 根据任务触发时间，选择在"审批流程的过程中"或"审批流程结束后"创建自动化任务。
   - **操作路径**：【OA审批—审批管理—通用审批—流程设计】或【管理后台—审批管理—通用审批—流程设计】
2. 配置自动化任务节点的触发动作，设置节点达到时的执行规则。
3. 增加执行动作，目前已支持："**发起审批**"、"**更新业务数据**"、"**HTTP请求**"三种类型的动作。

### 2.1.1 执行动作：发起审批

**使用场景**：在当前审批流程结束后，自动发起一个新的审批流程。

**示例**：当"名片申请"的审批结束后，可向指定经办人员发送"名片采购"的待办任务提醒，点击待办后能够将"名片申请"中的关键信息自动带入"名片采购"表单中，减少经办人员需要填写的内容，避免填写错误。

**操作步骤**：
1. 配置执行动作"发起审批"：在"名片申请"表单中添加"自动化任务"，确定后续需要执行的表单，将"名片申请"中需要自动带入到"名片采购"的内容进行匹配设置，并选择下个表单的经办人。
2. 提交"名片申请"，并填写相关的字段内容。
3. 审批到达自动化任务的节点时，给指定的经办人发送待办任务。
4. 经办人点击待办任务后，进入"名片采购"提交页面，系统自动带入"名片申请"中设置的关联信息，经办人只需要补充其他信息后提交名片采购申请。
5. 经办人提交流程后，任务执行完成。

### 2.1.2 执行动作：更新业务数据

**使用场景**：当在审批流程中或审批完成后，自动更新薪福通业务数据，无需人工维护，确保企业信息的一致性。

**示例**：在"员工补助申请"审批完成后，系统自动更新花名册中的"补助金额"字段，无需HR手动维护每位员工的补助信息。

**操作步骤**：
1. 在"员工补助申请"单中，创建一个审批结束后执行的自动化任务。
2. 配置任务触发条件，当"员工补助申请"需要补助时触发任务。
3. 配置执行动作为"更新业务数据"（目前支持更新花名册信息、写入假勤外出记录及低代码平台连接器），确定需要更新的目标。
4. 配置更新规则，即确定"员工补助申请"中的哪些字段需要更新到花名册的哪个字段中；配置中需要建立员工唯一标识（例如员工号），确保数据能够准确更新到花名册的指定字段。
5. 保存任务并发布表单。
6. 提交"员工补助申请"，填写关键信息。
7. 审批通过后，系统自动更新花名册中对应的字段，无需人工操作。

### 2.1.3 执行动作：HTTP请求

**使用场景**：当审批流程结束或达到指定节点后，需要将审批状态或数据同步至企业其他系统，则可通过配置HTTP请求动作实现。

**示例**："员工补助申请"审批结束后，系统将"补助金额"等数据通过API接口同步至企业其他系统。

**操作步骤**：
1. 添加一个HTTP请求的动作，配置请求地址、入参、出参等关键参数。
2. 当"员工补助申请"审批结束后，系统将根据企业配置的接口请求地址自动调用API，同步审批状态、表单数据至企业其他系统中。

## 明确规则

1. 自动化任务可在"审批流程的过程中"或"审批流程结束后"触发。
2. 已支持三种执行动作：发起审批、更新业务数据、HTTP请求。
3. "更新业务数据"目前支持：更新花名册信息、写入假勤外出记录、低代码平台连接器。
4. 更新花名册数据时需配置员工唯一标识（如员工号），确保数据准确更新。
5. HTTP请求支持配置请求地址、入参、出参等参数。
