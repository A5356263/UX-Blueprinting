# OA表单审批人设置

- 所属模块：协同办公 > OA审批 > 操作指引
- 页面路径：https://xft.cmbchina.com/helpapp/help.html#/help-main/help-detail?category=COD0000001633
- 最近更新时间：2025-10-14

为了满足不同企业的需求，薪福通提供了多种审批人配置选项。以下将重点介绍几种特殊的审批人设置。

- **设置路径**：【管理后台-审批管理-通用审批】-"表单"-"流程设计"-"审批人"-"审批人设置"

## 1. 普通审批

### 1.1 成员组
企业可根据实际需求创建不同的"成员组"（例如：项目负责人、部门负责人等）来进行审批工作，选择成员组后，该成员组的所有成员都将纳入该节点审批人行列。

- **设置路径**：【管理后台-组织-成员组】-"新增成员组"-"新增成员"

### 1.2 角色
企业可以根据实际需求，为不同的角色（例如：行政人员、财务人员、总经理等）配置审批权限。如果选择了某个角色作为审批人，该角色的所有成员都将纳入该节点审批人行列。

- **设置路径**：【管理后台-通用权限管理-角色管理】-"新增角色"-"添加员工"

## 2. 组织架构内用户

### 2.1 组织架构负责人
企业组织架构层级清晰，各分子公司的部门负责人/主管都明确的情况下，可选择在组织架构中给各层级设置"组织负责人"或"审批主管"作为审批人。

- **设置路径**：【管理后台-组织-组织架构】

### 2.2 审批角色
对审批人员进行归类或调整其审批权限，可对角色内的不同人员分别设置责任部门。

- **设置路径**：【管理后台-审批管理-审批角色】-"新增角色"-"添加用户"-"审批权限设置"

## 3. 表单内用户

在表单设计过程中，可将表单中的人员信息引用为审批人。例如，在表单中添加一个"人员选择"的控件，用户在提交表单时选择相关人员，系统即可自动将该人员设为审批人。

## 4. 审批人指定

可在审批中由上一级审批人指定下一级审批人，指定时可选择1人或多人。

## 5. 多人审批时的审批方式

在同一级审批中，若审批人员涉及多位时，例如当审批人为"成员组"或"角色"时，企业可以根据实际需求，选择"会签"、"或签"或者"依次审批"的方式进行操作。

## 明确规则

1. 成员组的所有成员都将纳入该节点审批人行列。
2. 角色的所有成员都将纳入该节点审批人行列。
3. 表单内的"人员选择"控件可动态引用为审批人。
4. 上一级审批人可指定下一级审批人（1人或多人）。
5. 多人审批支持三种方式：会签、或签、依次审批。
