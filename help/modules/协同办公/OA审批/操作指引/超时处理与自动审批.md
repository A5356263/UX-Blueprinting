# 超时处理与自动审批：流程超时提醒与智能审批处理

## 功能背景

企业在审批过程中，经常会遇到因审批人未及时处理导致流程受阻，影响业务效率。

薪福通OA审批支持超时处理功能，能够有效解决此类问题，通过提前设置审批节点的超时时间和对应的超时策略，当审批环节超过预定时限后，系统可自动触发审批动作，并可对相关人员进行提醒，确保审批流程能够及时、高效推进，避免因人员延误造成业务风险。

## 1. 使用场景介绍

当审批环节超过预定时限后，针对单个审批节点，可以提前配置审批超时之后的自动处理：超时提醒、超时转派、超时通过、超时拒绝。

### 1.1 管理员流程配置阶段
审批管理员在表单流程设计中，审批人节点的高级设置中可打开超时处理功能，管理员可通过配置超时规则模板库来选择自定义超时模板，或是添加单条超时规则来提前设置审批节点的超时处理策略。

### 1.2 员工提交审批阶段
审批管理员发布自定义的审批，员工在提交审批表单后，流程进行中若审批人超时未处理，系统自动触发超时处理，支持超时提醒、超时转派、超时通过、超时拒绝。

## 2. 设置步骤

管理员对审批人节点设置超时处理功能。

- **路径**：【管理后台-审批管理-通用审批】选择对应的表单进入"流程设计"界面。

### 2.1 单条超时规则的配置
支持超时提醒、超时转派、超时通过、超时拒绝。

- **路径**：【管理后台-审批管理-通用审批】选择对应的表单进入"流程设计"界面。在流程设计点击审批节点，在【高级设置】开启"超时处理"功能，点击"添加单个超时规则"。

#### 2.1.1 超时提醒
支持对超时未处理的时长进行设置、支持对被提醒人员名单进行设置、以及是否通过短信通知。

#### 2.1.2 超时转派
支持对超时未处理的时长进行设置、支持对被转派人及被提醒人员名单进行设置、以及是否通过短信通知。

#### 2.1.3 超时通过
支持对超时未处理的时长进行设置、支持对被提醒人员名单进行设置、以及是否通过短信通知。

#### 2.1.4 超时拒绝
支持对超时未处理的时长进行设置、支持对被提醒人员名单进行设置、以及是否通过短信通知。

### 2.2 选择超时规则模板
- **路径**：【管理后台-审批管理-通用审批】选择对应的表单进入"流程设计"界面。在流程设计点击审批节点，在【高级设置】开启"超时处理"功能，点击"选择超时规则模板"。

#### 2.2.1 添加规则模板
点击"规则模板-添加规则模板"，输入规则模板名称后，系统自动新增一组规则模板。

在每组规则模板的下方，点击"添加规则"，即可创建超时规则。

## 4. 超时处理效果

员工在提交审批表单后，流程进行中若当前节点审批人超时未处理，系统自动触发预设好的超时处理机制。

- 审批流程超时转派显示
- 审批流程超时同意显示
- 审批流程超时拒绝显示

## 明确规则

1. 同一规则组：超时提醒可以添加多个，超时转派只能添加1个，超时通过和超时拒绝只能添加其中1个。
2. 超时处理的4种策略：提醒、转派、通过、拒绝。
3. 超时处理在审批人节点的"高级设置"中开启。
4. 支持单条规则和规则模板两种配置方式。
5. 超时提示支持客户端弹框和移动端显示。
