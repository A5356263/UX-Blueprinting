# OA审批动态流程操作指引

## 一、使用场景介绍

在企业日常审批过程中，存在人员角色或岗位变更，或者审批表单内数据随业务实时变化等情况；在审批中开启"动态流程"功能后，系统会根据人员或业务变化，在每个审批节点实时计算并更新最新的审批人员及路径，确保审批流程灵活高效，减少人工调整。

## 二、操作步骤

以采购申请单为例：当采购金额≤10000元由行政审批，采购金额＞10000元由分管领导审批。

### 步骤1：配置流程设计
管理员进行采购申请表单的"流程设计"，设置条件分支节点，分别设置每个条件对应的审批人。

- **路径**：【OA审批—审批管理—通用审批】/【管理后台—审批管理—通用审批】

### 步骤2：开启动态流程
在审批表单的"高级设置"中，开启"动态流程"功能。

### 步骤3：员工提交审批
员工提交审批时，系统根据表单设置自动匹配对应分支条件中的审批人进行审批。

示例：在采购金额≤10000时，审批人张三审批后由李四（行政）审批。

### 步骤4：动态调整
在审批过程中，审批人张三将采购金额改为20000元，系统实时计算最新的审批分支和审批人，将原有的审批人李四（行政）改为由王五（分管领导）审批。

## 明确规则

1. 动态流程在审批表单的"高级设置"中开启。
2. 开启后系统在每个审批节点实时计算并更新审批人员及路径。
3. 适用于人员角色/岗位变更或表单数据随业务变化等场景。
4. 条件分支中字段被修改时，系统自动切换到对应分支的审批人。
