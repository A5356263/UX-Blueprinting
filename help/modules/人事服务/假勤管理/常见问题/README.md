## 独立FAQ（3条，答案已采集）

### 如何排查加班时长核算为0
三种核算方式：需申请按申请单时长生成、需申请结合申请单与打卡时长取交集、无需申请按打卡时长自动生成。排查步骤：①加班记录核实打卡时间 ②加班规则核实有效时间范围 ③班前加班打卡记录被前一天取走 ④加班申请单时间填写错误。

### 非全天外出/出差/请假期间员工应该在什么时间点打卡？
检查打卡规则中"非全天外出/出差/请假覆盖的打卡点无需打卡"设置。勾选后覆盖打卡点无需打卡；未勾选则无论是否覆盖都需要打上下班卡。

### 考勤机添加考勤人员失败的排查
①检查员工状态是否为空 ②花名册信息是否同步到假勤 ③员工号是否在考勤机中被其他员工占用。

### 考勤打卡有哪些方式？
支持4种：GPS、考勤打卡机、蓝牙打卡（仅掌上薪福通APP）、WiFi打卡（仅掌上薪福通APP）。

### GPS打卡定位不准问题排查
1. 手机定位设置：重新开关GPS定位
2. 手机系统：清理内存、下拉刷新、开关飞行模式
3. App版本：升级到新版本
4. 环境因素：开启WiFi增强GPS信号、换开阔地段
5. 打卡精度设置：管理员调整打卡范围，建议300米以上

### 补卡功能可以关闭审批吗？
可以。在【管理后台-审批管理-通用审批-假勤管理-补卡】流程中将审批人节点删除后发布即可。

### 员工如何请假？
登录薪福通移动端→工作台→点击"请假"。支持掌上薪福通APP和招商银行个人APP。

### 考勤支持按小时请假吗？
支持，请假最小单位为0.5小时。

### 年假方案如何设置
路径：【假期管理-假期类型设置】启用年假→【假期方案设置】新增方案→选择"按工龄递增发放"→设置发放规则（工龄满1年5天/满10年10天/满20年15天，每年1月1日发放，次年6月30日失效）→新员工入职按日折算。

### 考勤打卡可以核算出员工的考勤结果吗？
可以。管理员可按月统计迟到、早退、缺卡、请假次数，员工可在移动端"打卡-统计"查看。

### 打卡记录按考勤日显示和按自然日显示的区别
按考勤日：以考勤日为单位，合并显示取卡范围内的打卡记录（适合排班制/跨天班次）。按自然日：以自然天为单位，仅显示当天实际打卡（适合正常班次）。

### 移动端支持查看考勤统计吗?
支持。员工在移动端首页"本月考勤统计"查看，点击"更多"可按日/周/月查看详细数据。

### 如何设置考勤周期？
【假勤管理-考勤设置-配置总览】→界面最上方考勤规则区域设置。

### 考勤异常是否有自动提醒？
两种方式：①员工在APP工作台首页【打卡-设置-缺卡提醒】②管理员在【假勤管理-异常管理-考勤异常】设置自动提醒。

### 如何排查加班时长核算为0
三种核算方式：需申请按申请单、需申请取交集、无需申请自动生成。排查：①加班记录核实打卡时间 ②加班规则核实有效时间 ③班前加班被前一天取走 ④申请单时间错误。

### 非全天外出/出差/请假期间打卡规则
勾选"覆盖打卡点无需打卡"后，被覆盖打卡点自动标"正常"；未勾选则无论是否覆盖都需打卡。

### 考勤机添加考勤人员失败排查
①员工状态是否为空 ②花名册是否同步到假勤 ③员工号是否被其他员工占用。
