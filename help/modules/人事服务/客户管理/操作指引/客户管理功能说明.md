# 客户管理功能说明

- 所属模块：人事服务 > 客户管理 > 操作指引
- 最近更新时间：2025-10-14

## 1. 客户管理概述

客户管理模块专为人力资源服务企业设计，可进行客户、合同、项目、项目人员和用工记录的管理、账单模板设置、账单管理，跟踪客户全生命周期。

主要业务流程：客户档案管理 → 合同管理 → 项目管理 → 人员用工分配 → 薪资计算 → 账单生成 → 推送账款 → 回款/开票

## 2. 使用前准备

- 注册薪福通并完成认证
- 在员工管理中维护员工信息
- 生成客户账单前先在智能算薪/税前工资算税完成薪资计算
- 仅有社保数据的月结账单也可生成客户账单

## 3. 核心功能

### 3.1 基本设置
- **客户项目档案字段配置**：自定义客户档案字段（是否展示、是否必填），支持新增分组和字段
- **客户编码自动生成规则**：自动补码（断号自动补）或手动补码
- **权限设置**：按客户档案权限或客户专员权限控制可见范围
- **账单推送设置**：开启后自动推送至账款管理
- **审批设置**：可选开启账单审批流

### 3.2 维护客户档案（有效客户/归档客户）
- 新增/批量导入客户档案（含开票信息、联系人、银行信息、客户专员）
- 编辑、归档、恢复、删除客户档案
- 导出客户档案（可直接重新导入）
- 关键概念：**全额纳税** vs **差额纳税**，差额部分不得开具增值税专用发票

### 3.3 合同管理
框架销售合同或普通合同，支持中止、续约、临期管理。表单字段可在账款管理-自定义配置中设置。

### 3.4 项目管理
项目生命周期管理（运行中/已结项）。收费标准：按人收取或按工资百分比收取。支持创建、编辑、结项、删除项目。

### 3.5 用工管理
- 人员集中分配项目（可分配人员清单）
- 花名册上指定项目
- 用工记录管理：调整项目、退出项目、编辑/删除用工记录

### 3.6 账单模板管理
- 模板来源：智能算薪、税前工资算税、社保月结账单、导入账单项目
- 创建方式：新建或复制已有模板
- 字段配置：来源规则、值类型、可见性、分组、汇总项、排序
- 批量创建、批量关联客户、编辑模板
- **导出样式配置**：自定义导出模板（类似Excel操作，支持多Sheet页）

### 3.7 客户账单管理
- **新增账单**：单笔或批量生成。预收类型需选参考月份；差额账单可自动合并到当期
- **账单详情**：预收账单含预收/实收/差额三个tab
- 支持：重新生成、导出（列表/详情）、锁定/解锁
- **账单审批**：开启审批流后发起审批
- **推送应收单**：推送至账款管理
- **账单确认/取消确认**、**开票/开票确认**、**回款/回款确认**
- 联动账款模块时自动回写状态

### 3.8 垫款管理
- 已确认且未/部分回款的账单可申请垫款
- 需在OA配置审批流，支持编辑、删除、重新创建
- 垫款审批完成后账单回写垫款金额和状态，回款后自动结清

## 明确规则

1. 专为人力资源服务企业（劳务派遣/人力外包）设计
2. 删除客户档案需确保无执行中合同、无进行中费用结算、无在职人员
3. 归档客户需确保无未执行/执行中合同、无在职人员
4. 差额纳税：差额部分不得开具增值税专用发票，可开普通发票
5. 客户编码自动补码时不允许修改编码，手动补码时允许修改
6. 审批完成的账单修改后不支持二次发起审批
7. 锁定后的账单不会被批量删除
8. 联动账款模块时，回款和开票状态自动回写
