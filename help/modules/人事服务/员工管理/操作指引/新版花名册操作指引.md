# 新版花名册操作指引

- 所属模块：人事服务 > 员工管理 > 操作指引
- 最近更新时间：2026-04-08

## 版本说明

新版花名册将数据分为五个部分：员工档案、任职记录、合同档案、个税档案、项目用工记录。各档案数据源：任职记录→任职管理，合同档案→合同台账，个税档案→个税人员，项目用工记录→客户管理/用工管理。

## 1. 如何新增员工

点击"新增"员工按钮，填写员工档案信息。提交选项：①提交 ②提交并补充其他档案 ③提交并新增下一个员工。

- 合同档案需在详情页维护（需开通合同台账权限）
- 个税档案需在详情页维护（需开通个税服务权限）

## 2. 如何查看详情

路径：【人事服务-员工管理-员工花名册】选择员工姓名进入，上方可选"员工档案、任职记录、合同档案、个税档案、项目用工记录"。

自定义字段路径：【员工管理-员工管理设置-基础设置-字段设置】

## 3. 新版导入说明

新版导入支持多Sheet页模式、批量导入多条信息分组数据，融入AI智能解析能力。

### 3.1 新增
- 极简模板：仅包含企业必填及常用字段
- 标准模板：根据选中字段动态生成

### 3.2 修改
修改已有员工信息，需先下载已有数据修改后上传，导入时校验"流水号"列。

### 3.3 无则新增，有则修改
同时支持新增和修改，通过流水号匹配。

### 3.4-3.7 导入流程
智能解析(15秒) → 确认导入任务 → 表头匹配 → 业务校验(在线编辑) → 导入结果。系统自动记忆模板和匹配关系，后续导入自动跳过。

### 3.8-3.9 个税与合同导入
- 个税导入无表头匹配步骤，业务校验列表按国税模板字段展示
- 合同导入前需在字段设置中开启合同档案开关
- 个税导入前需授权个税服务权限

## 4. 新旧版本功能差异（关键变更）

| 功能 | 变更说明 |
|---|---|
| 新增员工 | 个税与合同信息需保存后前往详情页补充 |
| 导入花名册 | 整合到同一入口，融入AI能力 |
| 导入合同/税局/更多员工信息 | 取消原有入口，通过新版导入支持 |
| 导出全部信息 | 更名为全景档案导出 |
| 历史花名册 | 不再备份合同和个税分组 |
| 打印员工档案 | 不再打印合同和个税分组 |
| 个税人员 | 新增数据来源花名册和个税人员 |

## 5. 新版本独有功能

1. 入职年龄设置（避免用工风险）
2. 自动确认入职（入职日期当天自动确认）
3. 合同自动发起（入职后自动发起电子合同）
4. 员工档案修改审批
5. 新版岗职体系
6. 国企版员工档案字段
7. 学历学位验真
8. 自定义打印
9. 反向生成花名册

> 注：后续人事应用规划建设的新功能均只在新版本上实现。
