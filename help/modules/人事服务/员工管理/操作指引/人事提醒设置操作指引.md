# 人事提醒设置操作指引

- 所属模块：人事服务 > 员工管理 > 操作指引
- 路径：【员工管理-员工管理设置-基础设置-人事提醒设置】
- 最近更新时间：2025-10-14

## 1. 系统预设提醒

分为【业务提醒】和【员工信息提醒】。设置方法：点击提醒后的编辑按钮，设置通知范围、通知人、通知时间、通知方式及内容，保存后打开提醒按钮。

## 2. 自定义提醒

若系统预设无法满足需求，可点击【新增提醒类型】命名新类型 → 添加规则 → 设置通知范围/通知人/通知时间/通知方式及内容 → 保存。

## 明确规则

1. 提醒类型分系统预设和自定义两种
2. 每个提醒可独立配置：通知范围、通知人、通知时间、通知方式、通知内容
