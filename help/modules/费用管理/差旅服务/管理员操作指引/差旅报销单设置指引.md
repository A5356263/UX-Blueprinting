# 差旅报销单设置指引
- 所属模块：费用管理 > 差旅服务 > 管理员操作指引
- 最近更新：2025-10-14

## 1. 创建报销费用
### 1.1 创建费用分组和类型
- **路径**：【系统设置-单据设置-费用管理】
### 1.2 设置允许费用报销的单据
在"可见范围"的"可用范围"中选单据名称

## 2. 创建补贴费用
若差旅政策有补贴内容，创建补贴分组及补贴费用类型

## 3. 创建报销单据
### 3.1 新建单据
- **路径**：【系统设置-单据设置-表单流程】-"报销单"-"新增"
### 3.2 设计单据字段
- 选择单据可报销的费用名称和补贴名称
- 添加表单字段/附件/关联单据
- 收款组件：支持多人收款（最多15个个人账户）
### 3.3 单据管控设置
报销时如对发票签收有管控需求，可在"单据管控-管控设置"处设置

## 4. 设计审批流程
参考：单据审批流程设置操作指引
