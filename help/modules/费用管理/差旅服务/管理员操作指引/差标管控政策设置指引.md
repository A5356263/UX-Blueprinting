# 差标管控政策设置指引
- 所属模块：费用管理 > 差旅服务 > 管理员操作指引
- 最近更新：2025-10-14

以某公司差旅政策为例（高管/部门负责人/普通员工三级政策，不同城市不同标准）。

## 1. 设置城市级别
- **路径**：【系统设置-管控设置-城市级别】
- 自定义城市级别（如一级北上广深、二级省会城市），未分级归为"未分级城市"

## 2. 确定适用用户
- **路径**：【员工管理-员工花名册】
- 按职位/岗位确定适用人员

## 3. 创建差旅及补贴费用
### 3.1 差旅费用及可用单据配置
### 3.2 补贴费用及关联单据配置

## 4. 设置差旅政策
### 4.1 住宿费：【系统设置-管控设置-费用政策】-"住宿政策-新增"
### 4.2 机票费：选择"机票政策-新增"
### 4.3 火车费：选择"火车政策-新增"
### 4.4 市内交通费：选择"其他政策-新增"，选择"按天管控"

## 5. 设置差旅补贴
- **路径**：【系统设置-管控设置-差补政策】-"新增"

## 政策配置四部分
1. **基础信息**：政策名称、适用单据及费用、管控力度
2. **标准配置**：按系统逻辑设置标准化政策
3. **条件规则**：为政策实现设定条件，条件字段为单据字段
4. **自定义模式**：标准配置无法实现时切换自定义模式

## 明确规则
1. 高管级别如为实报实销无需设置差旅政策
2. 城市级别用于不同城市不同标准
3. 需先创建费用并将费用关联到单据才能配置政策
