# 里程补贴设置操作指引
- 所属模块：费用管理 > 差旅服务 > 管理员操作指引
- 最近更新：2025-10-14

员工自驾出差时，系统支持在线进行里程打卡，记录行驶路线及里程数，关联进报销单自动计算里程补贴金额。

## 1. 里程补贴基础配置
### 1.1 创建补贴费用分组和类型
### 1.2 设置报销单据
### 1.3 新增里程补贴：【系统设置】-【管控设置】-【里程补贴】-【新增】
### 1.4 设置里程补贴内容
- **标准规则**：按公里数制定固定补贴金额
- **阶梯规则**：按公里数范围制定不同补贴金额
- **多重里程补贴**：针对不同车型（如油车/电车）设置不同补贴标准

## 2. 打卡规则管控
可配置"自驾备注"和"打卡图片"管控规则
- **路径**：【系统设置-管控设置-里程补贴】-"打卡规则管控"
