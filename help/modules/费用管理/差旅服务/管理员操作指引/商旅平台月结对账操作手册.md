# 商旅平台月结对账操作手册
- 所属模块：费用管理 > 差旅服务 > 管理员操作指引
- 最近更新：2025-10-12

## 流程
1. 创建对账任务：【消费平台-月结对账-月结对账】-"创建对账任务"
2. 生成账单：选择供应商、订单类型、所属公司、对账周期
3. 选择对账模板（可新增/编辑/删除模板）
4. 上传供应商数据（仅xls/xlsx，不大于10MB）
5. 查看对账结果（4个页面：对账成功/失败/只存在于企业/只存在于供应商）
6. 发起结算：对账成功后可发起结算/批量结算
7. 对账单导出/批量导出（最大10个同时导出）

## 明确规则
1. 已生成账单的订单无法再进行手工结算
2. 已生成账单的订单不能重复生成账单
3. 存在"只存在于供应商"数据必须重新对账
4. 仅未结算对账单可发起结算
5. 批量结算仅支持同公司同平台同类型
