# 商旅订单报销管控设置指引
- 所属模块：费用管理 > 差旅服务 > 管理员操作指引
- 最近更新：2025-11-25

## 五种场景配置

| 场景 | 说明 |
|---|---|
| 场景一 | 允许关联企业月结订单和个人支付订单 |
| 场景二 | 允许关联企业月结订单，不允许关联个人支付订单 |
| 场景三 | 只能选择关联申请单下的企业月结和个人支付订单 |
| 场景四 | 只能选择关联申请单下的企业月结订单，且必须选择所有企业支付订单 |
| 场景五 | 只能选择关联申请单下的订单，且必须选择所有企业及个人支付订单 |

配置路径：【智能费控】-【系统设置】-【单据设置】-【表单流程】-"表单编辑-表单设计"
