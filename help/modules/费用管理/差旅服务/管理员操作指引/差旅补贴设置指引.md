# 差旅补贴设置指引
- 所属模块：费用管理 > 差旅服务 > 管理员操作指引
- 最近更新：2025-10-14

## 1. 设置城市级别
- **路径**：【系统设置-管控设置-城市级别】

## 2. 确定适用用户
在员工花名册中确认已配置对应职位/岗位

## 3. 补贴费用及关联单据配置
- 先添加补贴费用
- 再将该补贴费用关联到差旅报销单中

## 4. 设置差旅补贴
- **路径**：【系统设置-管控设置-差补政策】-"新增"
- 选择适用单据及补贴费用类型
- 填写补贴方式、补贴规则等
- 可勾选"员工可修改补助金额"

## 5. 差补自动计算
员工填写差旅报销单中的行程后，系统自动根据出差地点和天数计算补贴，支持补贴分摊与编辑
