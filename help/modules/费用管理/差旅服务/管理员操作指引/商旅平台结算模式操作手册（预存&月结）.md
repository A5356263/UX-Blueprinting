# 商旅平台结算模式操作手册（预存&月结）
- 所属模块：费用管理 > 差旅服务 > 管理员操作指引
- 最近更新：2025-10-14

## 1. 基础设置
设置付款账号和录入商旅平台收款账户

## 2. 预存模式
设置预付单据（借款类型+预付申请单）→财务提交预付单并支付→员工消费后财务提交核销单核销预充值

## 3. 月结模式
配置绑定月结订单费用类型→配置对公报账单据（勾选"允许添加批量月结订单"+"自动分摊"）→财务提交对公报账单关联月结订单→完成月结对账后发起结算

## 4. 员工自行提交报销关联月结订单
管理员在差旅报销单中勾选"允许添加月结订单"→员工提交报销单关联月结订单（不涉及员工支付金额）

## 明确规则
1. 月结订单的费用承担人/部门/项目优先取事前申请单信息，无则取预订人信息
2. 员工关联月结订单不作为费用不计入报销金额
