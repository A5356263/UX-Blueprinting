# 薪福通+招行CBS支付操作指引
- 所属模块：费用管理 > 通用配置 > 操作指引 > 支付管理
- 最近更新：2025-10-14

## 对供应商款项支付
1. 确认付款信息：【财务处理-支付管理-对公支付】-"未支付"
2. 批量发送支付→进入"支付中"
3. 登录CBS8→【集中支付受理】→【同意】
4. 查看支付状态：成功自动同步回单，失败可重新支付

## 员工报销款支付
1. 确认付款信息，付款方式选择"线上支付-招行CBS代发"（仅招行账户）
2. 批量发送支付（推荐按明细发送，一明细一流水一回单）
3. 登录CBS8完成审批后付款
4. 查看支付状态

## 失败重新支付方案
方案一：在CBS操作重新支付→薪福通手工支付确认
方案二：关闭CBS再经办功能→从薪福通重发支付

## 明确规则
1. 支持多主体支付，公司名称须与CBS一致
2. CBS支付失败后暂不支持薪福通直接重新支付
3. 推荐按明细发送实现一明细对应一流水一回单
