# 手工标记单据支付状态操作指引

- 所属模块：费用管理 > 通用配置 > 操作指引 > 支付管理
- 最近更新时间：2025-10-14

## 适用场景

企业在日常运营中可能遇到：费控单据审批中已提前付款、现金支付、承兑汇票/支票支付、代理扣款协议自动扣款、以欠款冲抵货款、使用非招行网银/第三方支付等。

## 手工标记"支付成功"

### 1. 设置自定义线下支付方式
- **路径**：【系统设置-支付设置-支付方式】，自定义现金、支付宝、微信等付款方式

### 2. 修改付款方式
- **路径**：【财务处理-支付管理-对私支付/对公支付】-"未支付"
- 单笔修改：点击"编辑付款信息"选择"线下付款-XX"
- 批量修改：勾选多笔→"更多操作-修改付款方式"

### 3. 发起支付
筛选自定义付款方式，点击"发起支付"，支付状态直接变为"支付成功"

### 4. 确认付款状态
- **路径**：【财务处理-支付管理-对私支付/对公支付】-"支付成功"
- 可手动上传回单

## 手工标记"支付成功/失败"

### 1. 开启【招行网银模板支付】方式
### 2. 修改付款方式为"线下付款-招行网银模板支付"
### 3. 发起支付→进入"支付中"页面
### 4. 确认支付状态
- 单笔确认/批量确认
- 三种状态：支付成功、支付失败、退回待支付

## 导出支付数据
- **路径**：【财务处理-支付管理-对公支付】-"未支付"-"数据下载"
- 在下载中心下载支付数据文件

## 明确规则
1. 线下支付需先自定义支付方式
2. 支持单笔和批量修改付款方式
3. 支付失败后可退回待支付重新发起
