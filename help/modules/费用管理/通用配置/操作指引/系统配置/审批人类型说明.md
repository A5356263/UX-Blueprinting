# 审批人类型说明

- 所属模块：费用管理 > 通用配置 > 操作指引 > 系统配置
- 最近更新时间：2025-10-14

## 各审批人类型说明

| 审批人类型 | 逻辑说明 |
|---|---|
| **自选** | 用户提交表单时，自行选择需要审批的人员 |
| **用户** | 指定一名或多名具体用户进行审批，在审批规则变动不频繁的情况下推荐使用，配置难度较低 |
| **部门** | 指定某一个部门的所有用户都可以进行审批 |
| **主管** | 指定审批人为提单用户所在部门的主管。主管配置可见薪福通管理后台→组织机构 |
| **连续多级主管** | 指定需要提单用户的连续几级主管进行审批，例如指定二级主管时，依次将由提单用户的一级主管（本部门主管）、二级主管（上级部门主管）进行审批 |
| **连续多级汇报上级** | 指定需要提单用户的连续几级汇报上级进行审批，例如指定二级汇报上级时，依次将由提单用户的一级汇报上级（直接上级）、二级汇报上级（上级汇报上级）进行审批 |
| **岗位** | 指定某一个岗位的用户进行审批，会根据提单人所在部门进行筛选，如无匹配则提供平级部门的其他同岗位人员供选择 |
| **职位** | 指定某一个职位的用户进行审批，会根据提单人所在部门进行筛选，如无匹配则提供平级部门的其他同职位人员供选择 |
| **分工模式** | 某人分管不同企业/部门的审批，可用于集团企业，总公司不同高管/财务审核不同子公司情况 |
| **项目角色** | 在【档案设置】→【项目】中维护项目信息，在项目角色中添加人员，提单时可在指定的角色中选择（需在表单设计中加入"项目"字段并勾选"作为单据项目"） |
| **角色** | 在门户中配置的角色，可单一选择也可多选 |
| **业务条线** | 在基础设置中配置业务条线，指定业务条线作为审批人类型 |
