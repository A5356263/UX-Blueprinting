# 无法击中预算排查操作指引

- 所属模块：费用管理 > 通用配置 > 操作指引 > 系统配置
- 最近更新时间：2025-10-14

企业配置预算方案后，系统通常会根据单据信息自动击中相应的预算方案。以下是可能导致未命中预算的原因及排查思路：

## 1. 预算科目原因

**费用未在预算科目允许占用的费用/补贴类型范围内**

- 排查路径：【智能费控-系统设置-预算设置-预算科目】

## 2. 预算组织原因

**承担部门、项目未在预算组织允许占用的范围内**

- 排查路径：【智能费控-系统设置-预算设置-预算组织】

## 3. 预算方案原因

1. **预算组织不在预算方案内** — 排查路径：预算方案→更改设置→查看预算组织
2. **预算科目不在预算方案范围内** — 排查路径：预算方案→更改设置→查看预算科目
3. **预算占用期间不在预算期间内** — 排查路径：预算方案→预算执行规则
4. **单据不在适用的单据类型范围内** — 排查路径：预算方案→更改设置→查看适用单据类型
5. **预算未审批** — 未审批完成的预算无法生效
6. **预算未过账** — 排查路径：预算方案→更改设置→查看是否需要过账后生效
