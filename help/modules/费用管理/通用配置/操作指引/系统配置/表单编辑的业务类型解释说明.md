# 表单编辑的业务类型解释说明
- 所属模块：费用管理 > 通用配置 > 操作指引 > 系统配置
- 最近更新：2025-10-14

## 申请单类型
| 类型 | 配置项 |
|---|---|
| 差旅申请 | 行程组件、时间规则、同行人、费用预估、自定义档案 |
| 费用申请 | 事前申请单组件、预算管控 |
| 招待申请 | 业务招待组件、招待费用预估 |
| 用车申请 | 用车申请组件、代申请、多车型、跨城用车 |
| 其他通用申请 | 自定义配置 |

## 报销单类型
| 类型 | 配置项 |
|---|---|
| 差旅报销 | 费用组件+行程组件+关联申请、月结订单、费用分摊、同行人 |
| 日常报销 | 费用套件+收款账户 |

## 借还款单、对公单据、财务处理、档案管理
各业务类型均有预置必要组件和字段
