# 反冲单设置操作指引

- 所属模块：费用管理 > 通用配置 > 操作指引 > 系统配置
- 最近更新时间：2025-10-14

当报销单的状态为"审批完成"，需要作废时，可通过提交反冲单完成。

## 1. 新建单据

- **路径**：【系统设置-单据设置-表单流程】-"财务处理-反冲单"

## 2. 设置反冲组件

进入"表单设计"界面，点击"附件"旁的空白处，页面右侧出现"反冲组件"设置栏，选择允许反冲的单据类型。

## 3. 设置审批流程

参考：如何设置单据审批流程？

## 4. 反冲/作废的条件

报销类型的单据都可以通过反冲单作废，但原单据需要满足以下条件：

1. 审批通过的
2. 未支付的、支付失败、或完全退款的
3. 未被其他单据关联的
4. 反冲单设置的可见范围包含该提单人的
5. 未生成财务凭证的

报销单被作废后，会释放相应发票，可重新发起报销。

## 明确规则

1. 反冲单用于作废已审批完成的报销单。
2. 必须满足5个条件才能反冲：已审批、未支付/失败/已退款、未被关联、可见范围内、未生成凭证。
3. 作废后发票释放，可重新报销。
