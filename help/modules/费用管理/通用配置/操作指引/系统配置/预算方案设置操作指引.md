# 预算方案设置操作指引
- 所属模块：费用管理 > 通用配置 > 操作指引 > 系统配置
- 最近更新：2025-10-14

## 1. 设置预算组织（部门/项目/个人/成本中心）
三种方式：自动同步部门、手动新增、批量导入

## 2. 设置预算科目
新增科目分类→新增预算科目→选择允许包含的费用类型

## 3. 创建预算方案
- 方案名称、编制维度（单维度或双维度）、预算组织、科目、区间（5年内）
- 注意：预算组织和科目同一时间不能配置于多个方案
- 支持添加子方案、选择管控模式、新增/导入预算金额

## 4. 设置预算执行规则
- 允许提单人查看预算使用情况
- 预算占用期间：按提单日期/审批通过日期/费用发生日期
- 借/预付款核销时预算转移规则
- 报销单关联申请单时预算转移规则
- 月结订单自动占用预算

## 5. 查看预算报表：【数据报表-预算报表】
已占用=已审批完结、冻结=审批中、保留=申请单已击中
