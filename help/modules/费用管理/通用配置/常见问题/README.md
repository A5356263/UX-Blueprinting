# 常见问题（通用配置）

- 所属模块：费用管理 > 通用配置
- 内容类型：FAQ
- 共56条

## 1. 发票收取失败是什么原因？
最近更新：2025-10-13

发票收取失败常见原因：
1. 发票开票日期已超过5年，无法查验收取
2. 发票查验不存在，查无此票
3. 除区块链发票外，当日开具的发票，无法查验
4. 发票已被报销，无法重复采集
5. 链接收票只可收取无需登录即可查看的发票，单次解析一条链接发票

## 2. 【手动占用预算】失败排查指引
最近更新：2026-02-12

### 无法选择单据
1. 检查单据是否审批完结
2. 检查单据是否已占用过当前预算方案（数据报表-预算报表中查看）
3. 检查是否为员工借款/预付款单（暂无法手动占用这两种类型）

### 手动占用失败
1. 单据未击中预算方案
2. 检查剩余预算金额是否充足
3. 差旅申请/费用申请检查组件是否未开启"预算管控"
4. 报销单费用组件是否勾选了"费用关联申请"
5. 是否核销了保留预算的借款/预付款单
6. 费用上是否关联了保留预算的事前申请单

温馨提示：手动占用预算仅支持"按提单日期"占用，与预算规则配置无关。

## 3. 报销时单据部门选不到想要报销的部门该怎么处理？
最近更新：2026-01-20

1. 未给员工开启该部门的数据权限：【智能费控-系统设置-基础设置-数据权限】→编辑权限→"我的单据-按部门"
2. 法人公司和部门未设置关联关系：【管理后台-组织-法人公司-修改】检查适用组织

## 4. 费控申请单填错了，但已走完审批流程，怎么处理？
最近更新：2025-12-12

1. 管理员：【系统设置-单据设置-表单流程】→申请单→单据管控→开启"允许发起人废弃"
2. 申请人：【工作台-我的报销-申请单】→找到单据→点击"作废"→重新提交

## 5. 发票采集失败，显示已被用户使用
最近更新：2025-12-03

- 员工排查：检查采集界面信息与票面是否一致，不一致则手工修改
- 管理员排查：①【台账管理-发票台账】按发票号码查询 ②【档案导出】按用户号查询对应员工

## 6. 如何设置审批超时提醒及超时汇总提醒？
最近更新：2025-12-08

- 单个审批节点：【流程设计】→审批节点"高级设置-超时处理"
- 全局设置：【流程设计】→右上角"全局配置-超时处理"
- 注意：单个节点设置优先级最高，但以最后设置的为准
- 超时汇总提醒：【管理后台-企业管理-消息设置】→"业务消息设置"

## 7. 报错：无法占用预算，仅支持费用发生日期为同季度
最近更新：2025-12-02

原因：预算方案周期为"季度预算"，预算规则按"费用发生时间占用"，但多笔费用消费日期不属于同一季度。
解决：①修改消费日期为同一季度 ②按季度分别提交单据

## 8. 员工和管理员看到的支付状态不一致
最近更新：2025-12-08

原因：对私支付失败后重新发起支付时，单据状态不会实时更新。
管理员查询路径：【财务处理-支付管理-对私支付】-"支付中"→查看"支付记录"

## 9. 对私报销单推送薪资代发，失败后如何重新发起？
最近更新：2025-12-11

情景一（银行账户错误）：员工在报销账户中重新维护正确账户→经办人在"支付失败"界面点击"修改收款账户"→重新发起
情景二（其他原因）：直接在"支付失败"界面勾选单据→重新发起支付

## 10. 智能费控的页面导航模式支持调整吗？
最近更新：2025-11-04

支持2种模式：面包屑式（层级导航）、多页签式（标签切换）
路径：【智能费控-工作台-个人设置-导航模式】
仅支持本人调整，管理员无法统一配置
