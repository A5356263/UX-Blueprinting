# 费用事前申请单填写指引
- 所属模块：费用管理 > 日常报销 > 员工操作指引
- 最近更新：2025-10-14

## PC端
1. 在【工作台】点击新建单据→选择费用事前申请单
2. 填写字段→"添加费用"→选择申请费用类型→保存
3. 如需分摊：在"新增费用"界面填写分摊信息
4. 提交

## 移动端
1. 掌上薪福通App【工作台】→"智能费控"→"更多"→"提单据"→选择费用申请单
2. 完善表单→"添加费用事前申请单明细"→选择费用→填写金额→保存
3. 如需分摊：在"记费用"界面填写分摊信息
4. "确认提交"

## 明确规则
1. 单据将按已配置的审批流依次流转
2. 分摊要求根据企业需要填写
