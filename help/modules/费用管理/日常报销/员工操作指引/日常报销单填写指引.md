# 日常报销单填写指引
- 所属模块：费用管理 > 日常报销 > 员工操作指引
- 最近更新：2025-10-14

## PC端
1. 上传发票：参考发票采集操作指引
2. 在【工作台】点击"费用报销"选择报销单据类型
3. 填写字段→选择费用类型→添加发票→金额自动填充→保存
4. 如需分摊：在"新增费用"界面填写分摊信息

## 移动端（掌上薪福通App）
1. 上传发票
2. 进入【工作台】→"日常报销"→"我要报销"→选择单据
3. 填写字段→"添加费用"→选择类型→添加发票→保存
4. 分摊按需填写：在"添加分摊"填写分摊信息

## 明确规则
1. 单据提交后按已配置的审批流依次流转
2. 发票金额可自动填充到费用中
