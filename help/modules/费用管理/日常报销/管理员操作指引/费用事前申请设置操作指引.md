# 费用事前申请设置操作指引
- 所属模块：费用管理 > 日常报销 > 管理员操作指引
- 最近更新：2025-10-14

## 三大场景
| 场景 | 说明 |
|---|---|
| 场景1 | 先申请后报销，费用来自申请单，金额受申请管控 |
| 场景2 | 先申请后报销，报销时需关联事前申请单 |
| 场景3 | 出差申请时填写预估金额，报销金额受预估管控 |

## 核心设置步骤
1. 费用类型开启"可事前申请费用"（可设置"申请后才可报销"强制管控）
2. 创建费用申请单/通用申请单→表单设计→选择费用
3. 设置"总金额超出管控"（支持自定义管控力度和超出比例）
4. 报销单中勾选"费用信息是否关联申请"（标准管控/严格管控）
