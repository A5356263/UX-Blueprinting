# 管理员工借款/供应商预付款指引
- 所属模块：费用管理 > 对公报账 > 管理员操作指引
- 最近更新：2025-10-14

## 1. 借款类型及额度管控
【系统设置-管控设置-借款类型】自定义借款类型、关联方（按员工/按供应商）、额度设置

## 2. 借款规则
"前款不清，后款不借"、"逾期未还，后款不借"（可设不得提交/警示提醒）

## 3. 借款管理：【财务处理-借还款管理-借款管理】
- 待还款/待核销/已结清三个列表
- 提醒还款/核销（支持单笔和批量）
- 确认还款/核销（支持手动确认）
- 借款/预付款转交（离职/转岗场景）
- 借款/预付关闭（不可恢复）

## 4. 还款管理
- 自动核销/还款：开启后报销完成自动确认状态
- 手动确认：管理员点击确认核销/还款
