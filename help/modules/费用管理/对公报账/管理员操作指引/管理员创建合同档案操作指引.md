# 管理员创建合同档案操作指引
- 所属模块：费用管理 > 对公报账 > 管理员操作指引
- 最近更新：2025-10-14

## 1. 维护合同类型
- **路径**：【系统设置】-【档案设置】-【字段设置】-"合同"-"合同类型"
- ①新增合同类型分组 ②点击分组旁"＋"新增合同类型
- 当前仅支持付款合同及框架合同类型

## 2. 维护供应商
录入合同前需先创建供应商

## 3. 录入合同档案
- **路径**：【系统设置】-【档案设置】-【合同】-【新增合同】
- 新增付款类合同须填写合同信息及付款条款
- 先点击"新增条款"填写付款阶段和金额，"合同金额"根据付款条款自动合计
