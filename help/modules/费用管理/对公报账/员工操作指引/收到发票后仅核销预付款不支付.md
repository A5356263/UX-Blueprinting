# 收到供应商开具的发票后，仅核销预付款不支付

- 所属模块：费用管理 > 对公报账 > 员工操作指引
- 最近更新：2025-10-14

## 场景举例
已预付全款，收到发票后仅需核销预付款，不需要额外支付。

## 操作
1. 进入对公报账单→添加费用→上传发票
2. 填写付款明细→核销预付→选择预付申请单→关联
3. 付款明细显示"本次实付0元、应付金额、核销预付金额"
4. 提交审批

## 对公报账四大场景
| 场景 | 说明 |
|---|---|
| 场景一 | 已预付部分款项，核销预付并支付剩余 |
| 场景二 | 收到发票后直接支付发票金额 |
| 场景三 | 收到发票后分期支付 |
| 场景四 | 已预付全款，仅核销预付款不支付 |
