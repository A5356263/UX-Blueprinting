# 模块依赖关系图

> 记录模块间的前置条件、数据依赖和影响关系，按来源模块排列。

## 新手引导 → 其他模块

| 来源模块 | 依赖/影响模块 | 关系类型 | 原文依据 |
|---|---|---|---|
| 管理员注册账号 | 实名认证 | 前置条件 | 管理员需先完成实名认证才能创建企业 |
| 创建企业 | 企业认证 | 前置条件 | 创建企业后可申请企业认证 |
| 企业认证 | 全部功能使用 | 前置条件 | 未认证企业仅有60天试用期和基础功能 |
| 企业认证 | 招聘管理(Moka) | 前置条件 | 仅高级认证企业可开通Moka |
| 邀请员工加入 | 员工使用薪福通 | 前置条件 | 员工需被邀请并加入企业后才能使用 |
| 邀请员工加入 | 分配权限 | 前置条件 | 员工加入后才能分配权限 |
| 企业内网访问 | 防火墙配置 | 前置条件 | 需防火墙放行相关域名 |
| 关闭企业 | 数据安全 | 影响 | 关闭后删除所有账号/组织/业务数据，不可恢复 |

## 组织管理 → 其他模块

| 来源模块 | 依赖/影响模块 | 关系类型 | 原文依据 |
|---|---|---|---|
| 组织架构 | 员工花名册 | 数据依赖 | 员工入职时需选择所属组织 |
| 组织架构 | 编制管理 | 前置条件 | 编制按组织/组织+岗位维度设置 |
| 组织架构 | Moka招聘 | 数据依赖 | 组织架构同步至Moka用于职位发布 |
| 编制管理 | 员工入职/异动 | 状态影响 | 超编时根据强弱控制提示或限制 |
| 岗位管理 | 编制管理（部门+岗位维度） | 前置条件 | 岗位编制需先关联组织 |
| 部门展示设置 | 员工花名册 | 配置影响 | 部门展示设置影响花名册列表和详情展示 |
| 部门展示设置 | 所有管理员 | 配置影响 | 企业级配置影响所有管理员 |
