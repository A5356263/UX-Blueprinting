# 体验蓝图：子管理员配置复制

---

## §0 本次关键设计判断

### 判断 1：复制操作采用弹窗（Modal）而非抽屉

复制操作包含信息选择、目标选择和确认执行三个独立步骤，放在弹窗中可以让超管的注意力集中在当前操作上，不受列表上下文干扰。

- **主要影响**：复制弹窗的设计复杂度（信息选择区 + 目标选择区 + 确认按钮）
- **建议方案**：采用弹窗承载复制流程，弹窗内分上下两个区域：上区选择复制内容，下区选择复制目标；确认按钮固定在弹窗底部
- **不建议方案**：抽屉（Drawer）——抽屉适合信息查看和局部编辑，不适合需要确认操作的提交型场景
- **关键待确认**：员工选择弹窗是否复用现有组件

### 判断 2：批量复制结果采用弹窗内汇总视图

200 个目标的批量复制必然有部分成功/部分失败的情况，在弹窗内直接展示汇总结果可以让超管在同一个上下文中完成后续操作。

- **主要影响**：复制弹窗在确认后的状态切换（从编辑态 → 结果汇总态）
- **建议方案**：复制执行完成后，弹窗展示结果汇总——成功数量/失败数量，失败原因按用户展开，支持对失败用户单独重新复制
- **不建议方案**：toast 提示"部分成功"——信息量不足，超管无法快速定位失败原因
- **关键待确认**：批量复制 200 目标的后端处理方式（同步/异步）

### 判断 3：叠加后的配置采用"生效配置 + 来源说明"双层展示

叠加策略的核心问题是超管需要同时知道"子管理员最终有什么权限"和"这些权限分别来自哪里"。

- **主要影响**：子管理员详情页/编辑页的信息结构
- **建议方案**：在子管理员详情页中，功能权限和组织范围展示"最终生效状态"，并提供"查看来源构成"的入口，展示每次复制叠加的时间线
- **不建议方案**：仅展示当前配置，不展示来源——超管无法追踪权限构成；仅展示来源不展示汇总——超管需要自己算总和
- **关键待确认**：叠加后的配置在列表页是否也需要展示摘要

### 判断 4：双管理员互审模式下，复制操作后不关闭弹窗，改为展示审批提交状态

在双管理员模式下，复制不是即时生效。超管需要明确知道"复制已成功提交，待审批后生效"。

- **主要影响**：复制弹窗在双管理员模式下的结束态
- **建议方案**：复制写入成功后不关闭弹窗，弹窗展示审批提交状态——"已提交审批，等待另一位管理员审批"，并提供"查看审批进度"的链接
- **不建议方案**：弹窗关闭 + toast 提示"复制成功"——超管会误以为已生效
- **关键待确认**：双管理员审批流程的具体边界（谁审批、审批什么、审批后通知谁）

## §1 旅程消费摘要

来源：`journey-analysis` 正式产出（`spark-output/journey_analysis.md`）

### 信心最低点

| 角色 | 阶段 | 信心 | 原因 | 蓝图落点 |
|------|------|------|------|----------|
| 超级管理员 | 验收与确认 | 中 | 缺少批量核对视图，200+只能抽样检查 | §6 子管理员列表页 → 配置摘要展示 |
| 超级管理员 | 持续管理 | 中 | 时间长了记不清谁复制了谁 | §4 配置来源查看 → 来源标记和时间线 |

这两个信心最低点驱动 §5 异常流程的设计优先级——验收阶段的配置不透明可能让超管遗漏配置错误。

### 关键转折

| 从 | 到 | 转折触发 | 蓝图落点 |
|----|----|----------|----------|
| 准备基准配置 | 执行配置复制 | 第一个子管理员配置完成 | §3 主流程 → 复制入口触发 |
| 执行配置复制 | 微调组织范围 | 复制操作完成 | §4 次流程 → 复制后微调 |

转折点提示：复制完成后超管需要明确知道"下一步做什么"——在结果反馈中提供微调入口。

### 流失风险

| 角色 | 阶段 | 风险 | 蓝图落点 |
|------|------|------|----------|
| 超级管理员 | 执行配置复制 | 仅支持单目标复制时 200+ 超管仍可能不满意 | §3 主流程 → 默认支持多目标选择 |
| 超级管理员 | 微调组织范围 | 入口深、路径长时易疲劳，可能漏掉部分目标 | §4 次流程 → 提供待微调快捷列表 |

## §2 交互流程总览

本次设计包含以下交互路径：

### 主路径（1条）

**子管理员配置复制**

子管理配置页列表 → 点击行操作"复制" → 打开复制弹窗 → 选择复制内容（可授权组织/可授权功能） → 选择目标用户 → 点击确认 → 顺序校验 → 执行复制 → 展示结果 → 关闭弹窗

### 分支路径（3条）

**分支 A：批量复制 200 目标**

与主路径一致，目标选择器支持多选（1-200 人），执行后结果汇总展示成功/失败明细

**分支 B：双管理员互审模式**

主路径执行完毕后，不退出弹窗，展示"已提交审批"状态，提供审批进度查看入口

**分支 C：叠加目标查看配置**

主路径完成后，超管进入目标子管理员详情页，查看叠加后的最终生效配置和来源构成

## §3 主交互流程

### 节点 1：进入子管理配置页

- **用户动作**：在薪福通管理后台依次进入「权限管理 → 权限管理模式 → 子管理配置页」
- **系统反馈**：展示子管理员列表，包含姓名、手机号、可授权功能摘要、可授权组织摘要、操作列
- **需要前置解释的信息**：无
- **建议文案**：无
- **下一步**：超管定位到要作为复制来源的子管理员

### 节点 2：触发复制操作

- **用户动作**：在目标子管理员的操作列点击「复制」按钮（位于操作项最左侧）
- **系统反馈**：弹出「复制」弹窗
- **需要前置解释的信息**：复制是将该子管理员的配置复制给其他用户，不会影响当前子管理员的配置
- **建议文案**：弹窗标题：「复制子管理员配置」
- **下一步**：超管在弹窗中选择复制内容和目标

### 节点 3：选择复制内容

- **用户动作**：在弹窗的"复制信息"区域勾选要复制的内容——「可授权组织」和/或「可授权功能」，默认全选
- **系统反馈**：勾选框响应选择状态
- **需要前置解释的信息**：至少选择一项，否则确认按钮不可点击
- **建议文案**：选项标签「可授权组织」「可授权功能」
- **下一步**：超管选择目标用户

### 节点 4：选择目标用户

- **用户动作**：点击弹窗中的「选择员工」输入框或按钮，打开「选择员工」弹窗
- **系统反馈**：打开员工选择弹窗（与"添加子管理员"弹窗一致），支持按组织树或搜索定位用户，已选用户在底部展示已选列表
- **需要前置解释的信息**：最多选择 200 名用户；可以选择普通用户（复制后成为子管理员）或已有子管理员（叠加配置）
- **建议文案**：选择器标签「复制对象」
- **下一步**：关闭选择弹窗后，已选用户出现在复制弹窗的复制对象区域

### 节点 5：执行复制

- **用户动作**：确认复制内容和目标后，点击弹窗底部的「确认」按钮
- **系统反馈**：触发顺序校验：
  1. 校验复制信息是否已勾选 → 如未选提示"请选择复制信息"
  2. 校验复制对象是否已选择 → 如未选提示"请选择至少一名复制对象"
  3. 校验每个目标用户的加入状态 → 已加入的继续，未加入的标记失败
  4. 校验每个目标用户的认证状态 → 已认证的继续，未认证的标记失败
  校验通过后执行复制写入
- **需要前置解释的信息**：校验按顺序执行，只有上一步通过才进入下一步；失败的不会阻塞成功的
- **建议文案**：按钮文案「确认」
- **下一步**：展示复制结果

### 节点 6：展示复制结果

- **用户动作**：查看复制结果
- **系统反馈**：
  - **全部成功** → Toast「复制成功」，复制弹窗关闭；生成操作记录
  - **部分成功** → 弹窗切换为结果汇总视图：展示「复制完成（{成功数}/{总数}）」；成功列表和失败列表分开展示，失败项标注失败原因；提供「关闭」按钮和「重新复制失败项」按钮
  - **全部失败** → 弹窗切换为结果汇总视图：展示「复制失败」，列出所有失败原因；提供「关闭」按钮
  - **双管理员模式** → 弹窗切换为审批提交态：展示「已提交审批」，提供「查看审批进度」链接
- **需要前置解释的信息**：部分成功/全部失败时，失败目标的配置不会被写入
- **建议文案**：见 §7 状态与反馈文案
- **下一步**：超管根据结果决定后续操作（关闭弹窗 / 重试失败项 / 查看审批进度）

## §4 次交互流程

### 流程 1：复制后微调目标子管理员组织范围

- **触发条件**：复制操作完成后，目标子管理员的组织范围与预期不完全匹配
- **用户动作**：从子管理员列表找到目标子管理员 → 点击编辑 → 修改组织范围 → 保存
- **系统反馈**：加载该子管理员的当前生效配置（含叠加来源），组织范围可编辑，保存后 Toast「保存成功」
- **需要前置解释的信息**：修改组织范围只影响当前子管理员，不影响其他复制来源
- **建议文案**：无
- **下一步**：超管可继续编辑其他子管理员

### 流程 2：查看子管理员叠加配置来源

- **触发条件**：超管需要了解某个子管理员的配置是如何构成的（原始配置 + 叠加来源）
- **用户动作**：在子管理员详情页点击「配置来源」或「查看来源构成」
- **系统反馈**：展示配置变更时间线，每次复制的来源、时间和内容：
  - 初始配置（手动创建）：{时间} — {功能}/{组织}
  - 叠加来源（从 XXX 复制）：{时间} — {功能}/{组织}
  - 当前生效配置汇总
- **需要前置解释的信息**：叠加不覆盖原有配置，每次叠加独立记录
- **建议文案**：区域标题「配置来源」「配置变更记录」
- **下一步**：超管可关闭详情返回列表

### 流程 3：重试复制失败项

- **触发条件**：批量复制后部分目标失败
- **用户动作**：在复制结果汇总视图中点击「重新复制失败项」
- **系统反馈**：仅对失败项重新执行校验和复制，成功和已处理的不会被影响
- **需要前置解释的信息**：重新复制仅处理失败项，已成功的目标不受影响
- **建议文案**：按钮文案「重新复制失败项」
- **下一步**：展示重新复制的执行结果

### 流程 4：查看审批进度（双管理员模式）

- **触发条件**：双管理员模式下复制完成，进入审批状态
- **用户动作**：在复制弹窗的审批提交态中点击「查看审批进度」
- **系统反馈**：跳转至审批管理页，展示该条审批的当前状态和处理人
- **需要前置解释的信息**：审批通过后复制结果才正式生效
- **建议文案**：链接文案「查看审批进度」
- **下一步**：超管等待审批结果

## §5 异常与阻断流程

### 异常 1：复制信息未选择

- **发生时机**：点击确认时
- **触发条件**：复制组织和复制功能均未勾选
- **判断依据**：勾选框为空
- **反馈形式**：Inline 提示
- **系统反馈**：复制信息区域下方显示错误提示，确认按钮不可点击
- **用户下一步**：至少勾选一项复制内容
- **恢复路径**：勾选后确认按钮恢复可点击，原路恢复，无信息丢失

### 异常 2：复制对象未选择

- **发生时机**：点击确认时
- **触发条件**：复制对象为空（未选择任何用户）
- **判断依据**：目标列表为空
- **反馈形式**：Inline 提示
- **系统反馈**：复制对象区域下方显示错误提示，确认按钮不可点击
- **用户下一步**：点击选择员工，至少选择一名用户
- **恢复路径**：选择目标后确认按钮恢复可点击，原路恢复，无信息丢失

### 异常 3：目标用户加入状态异常

- **发生时机**：点击确认后，校验阶段
- **触发条件**：目标用户未加入企业或已离职
- **判断依据**：加入状态不是已加入
- **反馈形式**：弹窗内结果汇总
- **系统反馈**：标记该目标失败，继续处理其他目标，最终在结果汇总中列出所有加入状态异常的目标及原因
- **用户下一步**：确认目标实际状态，确认是否需要该用户成为子管理员；等待用户加入企业或更换目标
- **恢复路径**：用户完成加入后，通过"重新复制失败项"重试；或更换目标后重新发起复制。已成功的不受影响

### 异常 4：目标用户认证状态异常

- **发生时机**：点击确认后，校验阶段
- **触发条件**：目标用户未完成实名认证
- **判断依据**：认证状态不是已认证
- **反馈形式**：弹窗内结果汇总
- **系统反馈**：标记该目标失败，继续处理其他目标，最终在结果汇总中列出所有认证状态异常的目标及原因
- **用户下一步**：通知目标用户完成实名认证
- **恢复路径**：用户完成认证后，通过"重新复制失败项"重试。已成功的不受影响

### 异常 5：全部目标状态异常

- **发生时机**：点击确认后，校验阶段
- **触发条件**：所有目标均未通过加入状态或认证状态校验
- **判断依据**：全部目标在 3 和 4 中均失败
- **反馈形式**：弹窗内结果汇总
- **系统反馈**：提示全部失败，列出所有目标的失败原因
- **用户下一步**：检查所有目标的加入和认证状态，解决问题后重新发起复制
- **恢复路径**：关闭弹窗，解决问题后重新选择目标执行复制。无部分成功数据需要处理

### 异常 6：复制来源异常

- **发生时机**：触发复制操作时
- **触发条件**：来源子管理员被删除或状态异常
- **判断依据**：系统检测到来源子管理员不可用
- **反馈形式**：Toast + 阻断
- **系统反馈**：提示「该子管理员状态异常，无法作为复制来源」，复制弹窗不打开
- **用户下一步**：选择其他正常的子管理员作为来源
- **恢复路径**：返回列表，选择其他来源

### 异常 7：批量复制超限

- **发生时机**：选择目标用户时
- **触发条件**：已选用户数达到 200 人限制后继续添加
- **判断依据**：选择器已达上限
- **反馈形式**：选择器阻止添加
- **系统反馈**：选择器中将已选数量展示为「200/200」，无法继续选择
- **用户下一步**：减少部分目标后再尝试添加，或分批操作
- **恢复路径**：移除已选目标中的部分再添加新目标

## §6 页面 / 弹窗 / 抽屉设计

### 6.1 子管理配置页（列表）

**页面目标**：展示所有子管理员列表，支持新建、编辑、复制、删除等操作

**进入条件**：超管进入权限管理 → 权限管理模式 → 子管理员已开启

**页面结构**：

```
┌──────────────────────────────────────────────────────────┐
│  权限管理模式  >  子管理员配置                             │
│                                                          │
│  [+ 添加子管理员]                   搜索框 [   ]          │
│                                                          │
│  ┌────┬────────┬──────────┬──────────┬────────┬────────┐ │
│  │ 姓名 │ 手机号 │ 可授权功能 │ 可授权组织 │ 来源标记 │ 操作   │ │
│  ├────┼────────┼──────────┼──────────┼────────┼────────┤ │
│  │ 张三 │ 138*** │ 3 项     │ 5 个部门  │ 手动   │ 复制编辑│ │
│  │ 李四 │ 139*** │ 3 项     │ 3 个部门  │ 复制自…│ 复制编辑│ │
│  │ 王五 │ 137*** │ 5 项     │ 8 个部门  │ 复制自…│ 复制编辑│ │
│  │ ...  │ ...    │ ...      │ ...      │ ...    │ ...    │ │
│  └────┴────────┴──────────┴──────────┴────────┴────────┘ │
│                                                          │
│  共 {总数} 个                             < 1  2  3 ... > │
└──────────────────────────────────────────────────────────┘
```

**按钮**：
- 「添加子管理员」→ 打开新增弹窗
- 「复制」→ 打开复制弹窗（操作列最左侧）
- 「编辑」→ 打开编辑详情

**成功反馈**：Toast「保存成功」

**失败反馈**：Toast「保存失败，请重试」

**状态反馈区**：

## §7 状态与反馈文案

### 统一状态口径

| 状态 | 含义 | 适用对象 | 用户可操作 | 统一反馈口径 |
|------|------|----------|-----------|-------------|
| 复制前（待操作） | 超管选中来源，待执行复制 | 复制弹窗 | 选择内容和目标，点击确认 | 弹窗就绪，等待确认 |
| 复制中（执行中） | 系统正在处理批量复制 | 复制弹窗 | 等待 | "正在复制…" |
| 复制完成（全部成功） | 所有目标复制成功 | 复制弹窗 → Toast | 关闭弹窗 | Toast：「复制成功」 |
| 复制完成（部分成功） | 部分目标成功，部分失败 | 复制弹窗结果视图 | 查看失败明细、重试 | 弹窗：「复制完成（{成功数}/{总数}）」 |
| 复制完成（全部失败） | 所有目标复制失败 | 复制弹窗结果视图 | 查看失败原因，调整后重试 | 弹窗：「复制失败」 |
| 审批中 | 复制完成，需审批后生效 | 复制弹窗审批态 | 查看审批进度 | 弹窗：「已提交审批」 |
| 审批通过 | 审批通过，复制结果生效 | 审批管理 → 子管理员列表 | 查看结果 | — |
| 审批驳回 | 审批未通过 | 审批管理 | 查看驳回原因 | — |

### 反馈文案

| 场景 | 反馈类型 | 文案 |
|------|----------|------|
| 复制信息未勾选 | Inline Error | "请选择复制信息" |
| 复制对象未选择 | Inline Error | "请选择至少一名复制对象" |
| 目标加入状态异常（批量结果） | 失败列表项 | "{姓名} 加入状态不是已加入，不能成为子管理员" |
| 目标认证状态异常（批量结果） | 失败列表项 | "{姓名} 未完成实名认证，不能成为子管理员" |
| 复制成功全部 | Toast | "复制成功" |
| 复制中 | Toast/进度 | "正在复制…" |
| 来源异常 | Toast | "该子管理员状态异常，无法作为复制来源" |
| 保存成功（编辑页） | Toast | "保存成功" |
| 保存失败（编辑页） | Toast | "保存失败，请重试" |
| 批量超限 | 选择器提示 | "最多选择 200 名复制对象" |
