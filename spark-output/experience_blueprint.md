# 体验蓝图：子管理员权限复制

## §0 本次关键设计判断

**判断**：复制弹窗的信息可见性是本次体验设计的核心杠杆——管理员在确认前需要看到"来源有什么"和"目标已有什麼"，确认后需要看到"谁成功、谁跳过、为什么"，这两层可见性决定了操作的安全感和效率。

**主要影响**：弹窗需要承载比常规确认对话框更多的信息（来源权限摘要、目标人员状态预览），结果反馈需要从 toast 升级为区分全部成功/部分成功的结果摘要。

**建议方案**：单弹窗双区结构——上方展示来源子管理员的授权范围摘要和复制内容选择，下方承载人员选择器和目标用户状态预览；确认后按顺序校验并部分执行，结果以弹窗内结果摘要或 toast+详情入口两种方式呈现。

**不建议方案**：不做步骤条分步（不符合强依赖/不可逆/高风险门禁）；不将校验失败全部做成弹窗阻断（字段级用 inline，执行级用结果摘要）。

**关键待确认**：双管理员互审审批后，目标用户权限的生效时机和审批被拒后的处理，影响结果反馈是否需要"审批中"中间态。

## §1 旅程图

### 权限管理员：批量配置子管理员权限

**阶段一：识别模板**

- 用户目标：找到"配置最完整、最典型"的子管理员作为复制来源
- 关键触点：子管理员列表页，浏览各子管理员的授权组织范围和功能范围概览
- 用户信心：中。需要逐行扫描判断哪个子管理员的配置最适合作为模板
- 痛点：列表中外露的授权范围概览可能被截断，管理员需要点进详情才能确认完整配置

**关键转折**：决定复制 → 点击操作列的"复制"。从浏览模式切换到操作模式。

**阶段二：确认复制内容**

- 用户目标：确认要复制的内容（组织范围/功能范围/两者），并理解来源子管理员当前配置了什么
- 关键触点：复制弹窗的复制信息区，展示来源子管理员的授权摘要和两个复选框
- 用户信心：高。默认全选减少了操作步骤，来源摘要提供了确认依据
- 痛点：如果来源子管理员的授权范围非常复杂（如选了大量特定组织），摘要可能不够直观

**关键转折**：确认复制内容 → 选择目标人员。从"确认模板"切换到"指定目标"。

**阶段三：指定目标人员**

- 用户目标：挑选需要获得相同授权范围的人员，并了解哪些人可能不符合条件
- 关键触点：人员选择器（复用添加子管理员的员工选择弹窗），已选人员列表
- 用户信心：中高。选择器提供了搜索和批量能力，但如果目标人员已有子管理员身份或状态不符，管理员可能不知情
- 痛点：选择时看不到目标用户是否已是子管理员、加入状态和认证状态是否满足条件——这些信息在确认后才校验，可能导致操作后才发现有人被跳过

**关键转折**：确认执行 → 等待结果。从"配置"切换到"等待系统处理"。

**阶段四：查看结果**

- 用户目标：确认复制是否成功、多少人成功、多少人被跳过及原因
- 关键触点：结果反馈区域（弹窗内结果摘要或 toast+详情入口）
- 用户信心：取决于结果反馈是否清晰。全部成功时信心高；部分成功时，如果能清楚看到跳过名单和原因、且知道下一步怎么处理，信心仍可维持
- 痛点：部分成功时，如果只看到"复制成功"的简单 toast 而不知道有人被跳过，会导致管理员误以为全部完成，后续审计时才发现遗漏

## §2 交互流程总览

### 权限管理员路径

```text
子管理员列表页 → 点击某行"复制" → 复制弹窗
  → 查看来源权限摘要 → 确认/调整复制内容
  → 选择目标人员 → 点击确认
  → 顺序校验 → 执行复制
  → 查看结果（全部成功/部分成功）
  → 关闭弹窗 → 列表刷新
```

### 异常流程重点

- 校验阻断：复制信息未选 / 对象未选 → inline 提示，不关闭弹窗
- 校验跳过：部分人员加入状态/认证状态不符 → 展示跳过名单，确认后继续执行
- 全部跳过：所有目标人员均不符合条件 → 不执行，展示不合规名单
- 系统异常：执行过程中系统错误 → 提示异常，已执行部分需确认状态

## §3 主交互流程

### 节点 1：进入复制

**用户动作**：在子管理员列表页，点击某行操作列的"复制"按钮。

**系统反馈**：打开复制弹窗，自动将该子管理员设为复制来源，加载其当前授权范围摘要。

**需要前置解释的信息**：
- 弹窗标题区显示来源子管理员的姓名和手机号，帮助管理员确认选对了人
- 复制信息区默认全选"可授权组织"和"可授权功能"
- 如果来源子管理员的组织范围为"全部"，摘要显示"全部组织"；如果为部分组织，显示组织数量（如"已指定 15 个组织"）及前几个组织名称

**建议文案**：
- 弹窗标题：`复制子管理员权限`
- 来源信息行：`复制来源：张三 / 138****1234`
- 组织范围摘要：`可授权组织：全部组织` 或 `可授权组织：已指定 15 个组织（研发部、市场部、销售部...）`
- 功能范围摘要：`可授权功能：已启用 8 项功能`

**下一步**：确认复制内容选择 → 进入节点 2。

### 节点 2：确认复制内容

**用户动作**：查看来源权限摘要，确认或调整"可授权组织""可授权功能"的勾选状态。

**系统反馈**：
- 复选框支持独立切换
- 至少保留一项勾选，取消最后一项时阻止并提示
- 无其他即时反馈

**需要前置解释的信息**：
- 复选框旁标注辅助说明："可授权组织"指来源子管理员当前可管理的组织范围；"可授权功能"指来源子管理员当前可授权的功能上限
- 如果取消某项勾选，最终复制的内容将不包含该项

**建议文案**：
- 复选框标签：`可授权组织` / `可授权功能`
- 辅助说明：`将来源子管理员的授权范围复制给目标用户`
- 取消最后一项时的 inline 提示：`请至少选择一项复制内容`

**下一步**：选择目标人员 → 进入节点 3。

### 节点 3：选择目标人员

**用户动作**：在人员选择器中搜索并选择目标用户（1-200 人）。

**系统反馈**：
- 点击选择器打开"选择员工"弹窗（复用添加子管理员的样式）
- 已选人员以标签形式展示在选择器下方
- 支持单个移除已选人员
- 超过 200 人时选择器阻止继续添加

**需要前置解释的信息**：
- 已选人员列表中，如果某用户已是子管理员，在其标签旁显示"已是子管理员"标记——帮助管理员预判"叠加"效果
- 人员选择器不支持展示加入状态和认证状态（这两个状态在确认时才校验），但在选择器下方可增加轻量提示：`目标用户的加入状态和认证状态将在确认时校验，不满足条件的人员将被跳过`

**建议文案**：
- 选择器占位文字：`选择员工`
- 空状态提示：`请选择至少一名复制对象`
- 已达到上限提示：`最多可选择 200 名复制对象`
- 已是子管理员标记：`已是子管理员`
- 轻量提示：`确认时将校验加入状态和认证状态，不符合条件的人员将被跳过`

**下一步**：点击确认 → 进入节点 4。

### 节点 4：校验与执行

**用户动作**：点击弹窗右下角的"确认"按钮。

**系统反馈**：按以下顺序校验，并根据校验结果执行：

**第 1 步：校验复制信息**
- 至少一项被勾选 → 通过，进入第 2 步
- 无勾选 → 在复制信息区下方显示 inline 红色提示，阻断，不关闭弹窗

**第 2 步：校验复制对象**
- 至少选择 1 人 → 通过，进入第 3 步
- 未选择 → 在人员选择器下方显示 inline 红色提示，阻断，不关闭弹窗

**第 3 步：校验加入状态**
- 遍历所有目标用户，标记加入状态非"已加入"的用户
- 全部通过 → 进入第 4 步
- 部分不通过 → 在弹窗中展示不合规人员名单（姓名 + 当前状态 + 原因），询问"是否跳过不合规人员并继续复制？"

**第 4 步：校验认证状态**
- 对通过第 3 步的人员继续校验认证状态
- 全部通过 → 执行复制
- 部分不通过 → 合并展示不合规人员名单，确认后执行

**第 3/4 步确认区域**：
- 展示不合规人员汇总（每条包含姓名、不通过原因："加入状态为 XX"或"未完成实名认证"）
- 按钮：`跳过并继续复制（N 人）` / `取消`
- 如果全部不合规，按钮改为：`知道了`

**执行阶段**：
- 确认后显示执行中状态
- 完成后展示结果

**建议文案**：
- 校验中：`正在校验...`
- 执行中：`正在复制...`
- 复制信息未选：`请选择复制信息`
- 复制对象未选：`请选择至少一名复制对象`
- 加入状态不符：`{姓名} 加入状态为"{当前状态}"，不能成为子管理员`
- 认证状态不符：`{姓名} 未完成实名认证，不能成为子管理员`
- 不合规汇总标题：`以下 {N} 名人员不符合复制条件，将被跳过`
- 全部不合规标题：`所选人员均不符合复制条件，无法执行复制`
- 跳过并继续按钮：`跳过并继续复制（{N}人）`
- 全部不合规按钮：`知道了`

**下一步**：查看结果 → 进入节点 5。

### 节点 5：查看结果

**用户动作**：查看复制执行结果。

**系统反馈**：根据执行结果分为两种形态。

**形态 A — 全部成功**：
- 弹窗内展示成功摘要
- 关闭弹窗后 toast "复制成功"
- 列表自动刷新

**形态 B — 部分成功**：
- 弹窗内展示执行结果摘要：成功 N 人，跳过 M 人
- 跳过明细列表：每人一行，包含姓名、跳过原因
- 关闭弹窗后 toast "已复制 N 人，M 人被跳过"

**形态 C — 全部跳过**（校验阶段已处理，不进入执行）

**需要前置解释的信息**：
- 结果反馈需要让管理员清楚知道"谁获得了权限"和"谁没有、为什么"
- 如果开启了双管理员互审，需额外提示"已生成审批，审批通过后生效"（如果审批不即时生效）或"审批记录已生成"（如果即时生效）

**建议文案**：
- 全部成功标题：`复制成功`
- 全部成功摘要：`已成功将权限复制给 {N} 名用户`
- 部分成功标题：`复制完成`
- 部分成功摘要：`成功 {N} 人，跳过 {M} 人`
- 跳过明细列标题：`跳过人员 / 跳过原因`
- 双管理员互审提示：`已生成审批记录，审批通过后权限生效`

**下一步**：关闭弹窗 → 返回列表页，列表已刷新。

## §4 次交互流程

### 次流程 1：从校验不合规名单返回调整

**触发条件**：校验阶段发现不合规人员，管理员不想跳过，希望先处理这些人员的问题。

**用户动作**：在"不合规人员确认"区域点击"取消"。

**系统反馈**：关闭不合规确认区域，保留弹窗内容和已选人员，管理员可移除不合规人员或关闭弹窗先处理问题。

**建议文案**：
- 取消后无额外提示，弹窗恢复到校验前的状态

**下一步**：管理员从已选列表中移除不合规人员，重新确认；或关闭弹窗暂不操作。

### 次流程 2：复制后查看操作记录

**触发条件**：管理员想核实复制操作是否被正确记录。

**用户动作**：前往操作记录/审计日志页面，按"子管理员模式"功能筛选，查看"复制-可授权组织"或"复制-可授权功能"操作。

**系统反馈**：操作记录列表中展示复制操作的详情，包含操作人、操作时间、来源子管理员、目标用户列表、复制内容类型、执行结果。

**需要前置解释的信息**：
- 如果一次复制产生部分成功的结果，操作记录需要体现成功/跳过的明细——不能只写"复制成功"
- 建议操作记录中保留完整的成功名单和跳过名单，或至少保留"成功 N 人，跳过 M 人"的摘要

**建议文案**：
- 操作内容格式：`将子管理员【张三/138****1234】可授权组织复制给【李四/139****5678】【王五/137****9012】，成功 2 人`
- 部分成功格式追加：`，跳过 1 人（赵六：未完成实名认证）`

### 次流程 3：双管理员互审审批链路

**触发条件**：系统开启了双管理员互审模式，复制完成后生成审批。

**用户动作**：[GAP] 依赖双管理员互审的具体审批流程——审批人收到审批通知 → 审批通过/拒绝。

**系统反馈**：[GAP] 如果审批通过后权限才生效，目标用户在审批期间不获得授权范围，子管理员列表中也不出现；如果即时生效后被拒则需回滚。

**建议文案**：[GAP] 待确认审批生效时机后补充。

## §5 异常与阻断流程

### 异常 1：复制信息未勾选

- **发生时机**：点击确认按钮后，校验第 1 步
- **触发条件**：可授权组织和可授权功能均未勾选
- **判断依据**：[FACT] 需求文档 §6.3：至少选择一项
- **反馈形式**：inline 红色提示，显示在复制信息区下方；不关闭弹窗
- **系统反馈**：提示"请选择复制信息"
- **用户下一步**：勾选至少一项复制信息后重新确认

### 异常 2：复制对象未选择

- **发生时机**：点击确认按钮后，校验第 2 步
- **触发条件**：未选择任何目标用户
- **判断依据**：[FACT] 需求文档 §7：至少选择一名复制对象
- **反馈形式**：inline 红色提示，显示在人员选择器下方；不关闭弹窗
- **系统反馈**：提示"请选择至少一名复制对象"
- **用户下一步**：通过人员选择器添加目标用户后重新确认

### 异常 3：目标用户加入状态不符

- **发生时机**：点击确认按钮后，校验第 3 步
- **触发条件**：部分或全部目标用户的加入状态不是"已加入"
- **判断依据**：[FACT] 需求文档 §7 校验规则第 3 条；[CONFIRMED] 部分执行策略
- **反馈形式**：弹窗内确认区域，展示不合规名单；不直接阻断
- **系统反馈**：展示"以下 N 名人员不符合复制条件"的不合规名单，列出姓名和具体原因（"加入状态为 XX"），提供"跳过并继续复制"和"取消"按钮
- **用户下一步**：选择跳过不合规者继续执行；或取消后手动移除不合规者

### 异常 4：目标用户认证状态不符

- **发生时机**：点击确认按钮后，校验第 4 步
- **触发条件**：部分或全部目标用户未完成实名认证
- **判断依据**：[FACT] 需求文档 §7 校验规则第 4 条；[CONFIRMED] 部分执行策略
- **反馈形式**：同异常 3，合并展示不合规名单
- **系统反馈**：在同一个不合规确认区域中展示（与异常 3 合并），列出姓名和原因（"未完成实名认证"），提供"跳过并继续复制"和"取消"按钮
- **用户下一步**：同异常 3

### 异常 5：全部目标用户不合规

- **发生时机**：校验第 3/4 步后
- **触发条件**：所有目标用户均不满足加入状态或认证状态要求
- **判断依据**：[CONFIRMED] 部分执行策略的边界情况
- **反馈形式**：弹窗内确认区域，展示完整不合规名单；不执行复制
- **系统反馈**：展示"所选人员均不符合复制条件，无法执行复制"，列出全体不合规人员及原因，提供"知道了"按钮
- **用户下一步**：关闭确认区域，更换目标用户或先处理人员状态问题

### 异常 6：超出人数上限

- **发生时机**：在人员选择器中选择第 201 名用户时
- **触发条件**：已选人数达到 200 人上限
- **判断依据**：[FACT] 需求文档 §12 第 5 条
- **反馈形式**：inline 轻量提示（toast 或选择器下方提示）
- **系统反馈**：提示"最多可选择 200 名复制对象"，选择器阻止继续添加
- **用户下一步**：确认当前已选的 200 人，或移除部分人员后继续添加

### 异常 7：系统执行异常

- **发生时机**：复制执行过程中
- **触发条件**：网络异常、服务端错误等导致复制中断
- **判断依据**：[CONFIRMED] 设计判断，需求文档未覆盖
- **反馈形式**：弹窗内错误提示或 toast
- **系统反馈**：提示"复制过程中发生异常，部分权限可能未完成复制。请查看操作记录确认结果，或稍后重试。"已执行部分的处理方式需技术确认（当前标记为 GAP）
- **用户下一步**：关闭弹窗，查看操作记录确认已执行情况；对未完成的目标用户重新执行复制

### 异常 8：双管理员互审审批阻塞

- **发生时机**：复制完成，生成审批后
- **触发条件**：开启双管理员互审模式，审批流程中
- **判断依据**：[FACT] 需求文档 §10；[GAP] 审批生效时机待确认
- **反馈形式**：[GAP] 如审批不即时生效，需在复制结果中提示"审批中"状态
- **系统反馈**：[GAP] 需要在复制结果中补充提示文案
- **用户下一步**：[GAP] 等待审批完成 / 联系审批人

- 确认按钮：`确认`
- 取消按钮：`取消`

## §7 状态与反馈文案

### 统一状态口径表

| 状态 | 含义 | 适用对象 | 用户可操作 | 统一反馈口径 |
|------|------|----------|-----------|-------------|
| 弹窗就绪 | 弹窗已打开，复制信息默认全选，等待选择目标 | 复制弹窗 | 调整复制内容、选择目标人员、确认或取消 | 无提示，正常展示弹窗内容 |
| 校验阻断-无复制信息 | 复制信息未勾选任何项 | 确认按钮点击后 | 勾选至少一项复制信息 | "请选择复制信息"（inline 红字，弹窗不关闭） |
| 校验阻断-无复制对象 | 未选择任何目标用户 | 确认按钮点击后 | 选择至少一名目标用户 | "请选择至少一名复制对象"（inline 红字，弹窗不关闭） |
| 校验不合规 | 部分目标用户不满足加入状态或认证状态 | 确认按钮点击后 | 跳过不合规者继续，或取消 | "以下 N 名人员不符合复制条件，将被跳过"（弹窗内确认区） |
| 全部不合规 | 所有目标用户均不满足条件 | 确认按钮点击后 | 关闭确认区，更换目标用户 | "所选人员均不符合复制条件，无法执行复制"（弹窗内确认区） |
| 执行中 | 系统正在执行复制操作 | 确认执行后 | 等待完成 | "正在复制..."（弹窗内加载态） |
| 全部成功 | 所有合规目标用户均成功接收权限 | 复制执行完成后 | 关闭弹窗 | "复制成功"（弹窗结果区 + toast） |
| 部分成功 | 部分目标成功，部分被跳过 | 复制执行完成后 | 关闭弹窗，查看跳过明细 | "已复制 N 人，M 人被跳过"（弹窗结果区 + toast） |
| 系统异常 | 执行过程中发生系统错误 | 复制执行过程中 | 关闭弹窗，查看操作记录确认结果 | "复制过程中发生异常，请查看操作记录确认结果"（弹窗内 + toast） |

### 关键文案模板

**弹窗标题**：`复制子管理员权限`

**来源摘要**：
- 全部组织：`可授权组织：全部组织`
- 部分组织：`可授权组织：已指定 15 个组织（研发部、市场部、销售部...）`
- 功能范围：`可授权功能：电脑端 5 项 / 移动端 3 项`

**校验提示**：
- 未选复制信息：`请选择复制信息`
- 未选复制对象：`请选择至少一名复制对象`
- 加入状态不符：`{姓名} 加入状态为"{当前状态}"，不能成为子管理员`
- 认证状态不符：`{姓名} 未完成实名认证，不能成为子管理员`

**执行反馈**：
- 全部成功：`已成功将权限复制给 {N} 名用户`
- 部分成功：`成功 {N} 人，跳过 {M} 人`
- 全部跳过：`所选人员均不符合复制条件，无法执行复制`

**按钮文案**：
- 主操作：`确认`
- 取消：`取消`
- 跳过并继续：`跳过并继续复制（{N}人）`
- 全部不合规确认：`知道了`
- 结果关闭：`关闭`

**操作记录文案**：
- 全部成功：`将子管理员【{姓名}/{手机号}】{复制内容}复制给【{目标1}】【{目标2}】，成功 {N} 人`
- 部分成功：`将子管理员【{姓名}/{手机号}】{复制内容}复制给【{目标1}】【{目标2}】，成功 {N} 人，跳过 {M} 人（{跳过者}：{原因}）`
