# 完整体验方案：财富专区-资产配置面客版

---

## §0 本次关键设计判断

### 判断 1：按"概览→诊断→推荐"的决策主线组织页面，而非按数据来源组织

- **判断**：页面模块的排列顺序应当模拟企业客户做投资决策的心理过程——先了解全局，再发现问题，最后看建议和行动——而不是按"理财数据放一起、基金数据放一起"的数据源逻辑。
- **主要影响**：页面结构、模块顺序、信息层级。影响资产配置页面的主体布局。
- **建议方案**：页面自上而下依次为：账号选择器（全局控制）→ 持仓表现（概览）→ 投资分布与期限分布（资产构成）→ 持仓诊断 → 产品推荐。底部统一放置免责声明，浮动按钮固定下载入口。
- **不建议方案**：按资产类型分Tab（理财一个Tab、基金一个Tab），这会割裂用户对整体资产状况的认知，也不利于诊断和推荐在统一上下文中的呈现。
- **关键待确认**：无——决策主线已有 UXB 确认。

### 判断 2：诊断模块"有则展示、无则不展示"用页面其他模块的正常加载状态暗示数据就绪

- **判断**：当所有诊断规则均未命中时，诊断模块整体不展示。用户不应因此怀疑页面异常，而应通过其他模块（如持仓表现、分布）的正常展示自然感知"数据已加载，只是没有问题需要告警"。
- **主要影响**：诊断模块的展示/隐藏逻辑、用户对"无问题"状态的感知方式。
- **建议方案**：诊断模块的上方或附近不额外放置"暂无诊断问题"的空状态占位。如果用户需要确认诊断是否已执行，可以通过页面其他模块的数据更新时间来推论。不单独为"无问题"状态设计反馈。
- **不建议方案**：用空状态组件或提示条表示"暂无诊断问题"，这会占用页面空间并可能让用户困惑。
- **关键待确认**：无。

### 判断 3：范围差异通过模块头部标签表达，而非集中说明

- **判断**：持仓表现、持仓诊断、产品推荐仅支持理财，但投资分布与期限分布覆盖全量资产。这个范围差异不应在页面底部统一说明，而应在每个模块的头部或标题旁用标签清晰标注。
- **主要影响**：每个受范围限制的模块的标题区设计。
- **建议方案**：在持仓表现、持仓诊断、产品推荐模块的标题行，以轻量标签形式标注"仅理财"。投资分布和期限分布标题旁标注"含理财/基金/资管/信托"。
- **不建议方案**：页面底部或弹窗中统一写"持仓表现仅支持理财"，用户需要自己回头看哪个模块受影响。
- **关键待确认**：无。

## §2 交互流程总览

### 主路径（1 条）

**企业客户查看资产配置建议书并采取行动**

资产配置页面 → 选择账号 → 查看持仓表现 → 调整时间区间 → 查看投资分布 → 查看期限分布 → 查看持仓诊断 → 查看产品推荐 → 购买/下载/关闭

关键分支点：
- 选择账号后全页面数据切换
- 调整时间区间后持仓表现及其趋势图联动刷新
- 产品推荐处可单独购买、批量购买或下载

### 次路径（3 条）

**次路径 1：下载建议书**
资产配置页面 → 点击浮动下载按钮 → 选择格式（PDF/PNG）→ 系统生成文件 → 浏览器下载

**次路径 2：单独购买产品**
产品推荐模块 → 点击单个产品购买按钮 → 新开页签跳转购买页 → 用户完成购买 → 关闭页签回到资产配置页面

**次路径 3：批量购买产品**
产品推荐模块 → 勾选多个产品 → 点击批量购买 → 新开页签跳转购物车 → 用户完成结算 → 关闭页签回到资产配置页面

## §3 主交互流程

### 节点 1：进入资产配置页面

| 字段 | 内容 |
|------|------|
| **用户动作** | 从财富专区菜单点击"资产配置"，或从持仓列表页面点击"资产配置"入口 |
| **系统反馈** | 进入资产配置页面，默认加载全部账号的资产数据 |
| **需要前置解释的信息** | 从持仓列表进入时自动选中当前查看的账号；从菜单进入时默认全部账号 |
| **建议文案** | （入口文案）"资产配置"——原理财月报更名，在菜单中标注"原月报"辅助过渡 |
| **下一步** | 页面加载完成后，用户看到账号选择器和各数据模块 |

### 节点 2：选择银行账号

| 字段 | 内容 |
|------|------|
| **用户动作** | 在账号选择器中选择单个银行账号或保持"全部账号" |
| **系统反馈** | 全页面数据切换为选中账号的数据，各模块展示加载态后更新 |
| **需要前置解释的信息** | 账号选择器展示账号数量；无可访问账号时引导权限申请 |
| **建议文案** | 选择器标签："选择账号（共{N}个可用账号）"；默认项："全部账号（{N}个账号）" |
| **下一步** | 用户查看已更新的持仓表现数据 |

### 节点 3：查看持仓表现

| 字段 | 内容 |
|------|------|
| **用户动作** | 浏览持仓表现区域的数据卡片（时点资产、区间收益、年化收益率等） |
| **系统反馈** | 展示当前账号在所选时间区间内的核心指标和趋势图 |
| **需要前置解释的信息** | 时间区间默认近一个月，支持近两年内的自定义区间。模块标题标注"仅理财" |
| **建议文案** | 标题："持仓表现（仅理财）"；时间区间："近一个月"（下拉可选自定义） |
| **下一步** | 用户可调整时间区间查看不同时段数据，或继续向下浏览 |

### 节点 4：调整时间区间

| 字段 | 内容 |
|------|------|
| **用户动作** | 点击时间区间选择器，选择预设区间或自定义起止日期 |
| **系统反馈** | 持仓表现模块内的各数据卡片和趋势图独立加载更新，模块级展示加载态 |
| **需要前置解释的信息** | 时间区间的数据范围限制在近两年。调整区间只影响持仓表现模块，不改变其他模块 |
| **建议文案** | 选择器标签："时间区间（近两年数据）" |
| **下一步** | 各数据卡片更新完成，用户继续浏览 |

### 节点 5：查看投资分布与期限分布

| 字段 | 内容 |
|------|------|
| **用户动作** | 浏览投资分布的饼图与列表，浏览期限分布列表；可选择切换 Tab 在投资分布和期限分布之间切换 |
| **系统反馈** | 展示各资产类型的持仓金额和占比（饼图+列表形式）；按产品期限汇总的持仓数据 |
| **需要前置解释的信息** | 两个模块覆盖理财、公募基金、资管计划、信托计划。标题标注"含理财/基金/资管/信托" |
| **建议文案** | 标题："投资分布（含理财/基金/资管/信托）"；此处的"其他业务"按资产类型展开 |
| **下一步** | 用户继续向下浏览持仓诊断模块 |

### 节点 6：查看持仓诊断

| 字段 | 内容 |
|------|------|
| **用户动作** | 查看诊断结果卡片（集中度/到期/时长），如有问题点击展开查看产品列表 |
| **系统反馈** | 诊断有结果时展示对应卡片和产品列表，无问题时诊断模块不展示 |
| **需要前置解释的信息** | 诊断仅支持理财。模块标题标注"仅理财"。如果当前展示的诊断问题为空（无问题），模块整体不展示 |
| **建议文案** | 标题："持仓诊断（仅理财）"；诊断卡片标题示例："持仓集中度过高"、"产品即将到期"、"持仓时间过长" |
| **下一步** | 用户了解持仓问题后，进入产品推荐模块查看优化建议 |

### 节点 7：查看产品推荐

| 字段 | 内容 |
|------|------|
| **用户动作** | 查看推荐产品列表，对比各产品的收益率、期限、推荐理由；点击产品名称跳转产品详情 |
| **系统反馈** | 展示建议持有类型、产品信息、收益率、最大回撤、推荐理由 |
| **需要前置解释的信息** | 推荐仅支持理财。推荐基于实时数据，过滤不可购买或额度不足的产品。净值精度有限，收益率仅供参考 |
| **建议文案** | 标题："产品推荐（仅理财）"；底部提示："收益率数据基于产品最新净值测算，仅供参考" |
| **下一步** | 用户选择购买、下载建议书或关闭页面 |

### 节点 8：购买产品

| 字段 | 内容 |
|------|------|
| **用户动作** | 点击单个产品的"购买"按钮，或勾选多个产品后点击"批量购买" |
| **系统反馈** | 新开页签跳转购买页（单独购买）或购物车（批量购买）。原页签维持当前页面状态 |
| **需要前置解释的信息** | 购买在新页签中完成，用户可随时切换回资产配置页面；原页面状态保持不变 |
| **建议文案** | 按钮文案："购买"、"批量购买（已选{N}个）" |
| **下一步** | 用户在新页签中完成购买流程，完成后关闭新页签回到资产配置页面 |

## §4 次交互流程

### 次路径 1：下载建议书

| 字段 | 内容 |
|------|------|
| **触发条件** | 用户在任何时候需要保存建议书离线查看 |
| **用户动作** | 点击页面右下角的浮动下载按钮 → 在弹窗中选择 PDF 或 PNG 格式 → 确认下载 |
| **系统反馈** | 生成文件并触发浏览器下载。文件命名格式：`资产配置建议书{YYYYMMDDHHmmss}` |

### 次路径 2：查看产品详情

| 字段 | 内容 |
|------|------|
| **触发条件** | 用户在产品推荐列表中对某个产品感兴趣，想了解更多信息 |

| **下一步** | 用户查看详情后返回资产配置页面 |

## §5 异常与阻断流程

### 异常 1：接口超时（企业财富+ 响应超过 5 秒）

| 字段 | 内容 |
|------|------|
| **发生时机** | 页面加载时或切换账号时，请求企业财富+接口超时 |
| **触发条件** | 接口响应时间 > 5 秒 |
| **判断依据** | 系统超时设置 |
| **反馈形式** | 模块级加载态 → 自动重试 → 失败后降级 |
| **系统反馈** | 系统自动重试 3 次（间隔 1 秒）。若重试仍失败，受影响模块展示空状态。底部显示提示条："数据加载中，请稍后重试" |
| **用户下一步** | 用户可继续浏览其他已加载模块，或稍后刷新页面重试 |
| **恢复路径** | 原路返回，无信息丢失。用户刷新页面或等待后重新进入即可 |

### 异常 2：接口返回错误码（401/403/500/503）

| 字段 | 内容 |
|------|------|
| **发生时机** | 请求企业财富+数据时 |
| **触发条件** | 接口返回错误码 |
| **判断依据** | HTTP 状态码 |
| **反馈形式** | 页面级提示或模块级空状态（取决于错误严重程度） |
| **系统反馈** | • 401：提示"登录已过期，请重新登录"，引导重新登录<br>• 403：提示"您暂无权限访问该功能"，引导联系管理员<br>• 500/503：提示"系统繁忙，请稍后再试"或"系统维护中，请稍后再试" |
| **用户下一步** | • 401：重新登录<br>• 403：联系管理员<br>• 500/503：稍后重试 |
| **恢复路径** | 401 和 403 需要重新认证或获取权限后返回；500/503 原路返回，无信息丢失 |

### 异常 3：接口无响应

| 字段 | 内容 |
|------|------|
| **发生时机** | 请求企业财富+数据时 |
| **触发条件** | 接口完全无响应（网络不可达或服务宕机） |
| **判断依据** | 网络连接状态或超时 |
| **反馈形式** | 页面级空状态 |
| **系统反馈** | 页面展示空状态，提示"系统繁忙，请稍后再试" |
| **用户下一步** | 稍后再试。确认网络连接正常 |
| **恢复路径** | 原路返回，无信息丢失。服务恢复后自动可用 |

### 异常 4：部分数据缺失

| 字段 | 内容 |
|------|------|
| **发生时机** | 接口返回数据但部分字段为空 |
| **触发条件** | 个别数据字段无值 |
| **判断依据** | 数据完整性校验 |
| **反馈形式** | 字段级展示"--"，无全局提示 |
| **系统反馈** | 缺失字段展示"--"，其他可用数据正常展示 |
| **用户下一步** | 浏览可用数据，缺失部分可稍后再查看 |
| **恢复路径** | 系统后台异步补全数据，用户下次查看时自动更新 |

### 异常 5：无持仓数据

| 字段 | 内容 |
|------|------|
| **发生时机** | 页面加载完成后，检测到选中账号下无持仓 |
| **触发条件** | 账号下所有持仓产品数量为 0 |
| **判断依据** | 持仓数据返回为空 |
| **反馈形式** | 空状态页面/区域 |
| **系统反馈** | 展示空状态：图标 + "暂无持仓数据" + "购买理财产品，开启投资之旅"，附 [去购买] 按钮 |
| **用户下一步** | 点击"去购买"跳转产品列表页，选择产品开始投资 |
| **恢复路径** | 购买产品后返回资产配置页面即可看到持仓数据 |

### 异常 6：数据计算异常

| 字段 | 内容 |
|------|------|
| **发生时机** | 企业财富+计算资产配置数据时 |
| **触发条件** | 数据计算内部异常 |
| **判断依据** | 计算服务返回异常 |
| **反馈形式** | 模块级空状态 |
| **系统反馈** | 异常模块展示空状态，提示"该功能暂时不可用" |
| **用户下一步** | 稍后重试 |
| **恢复路径** | 原路返回，无信息丢失。修复后重新计算 |

### 异常 7：下载失败

| 字段 | 内容 |
|------|------|
| **发生时机** | 用户点击下载，文件生成或传输过程中 |
| **触发条件** | 文件生成失败 / 网络中断 / 浏览器拦截 |
| **判断依据** | 文件生成状态 / 网络状态 / 浏览器行为 |
| **反馈形式** | Toast 或下载弹窗内提示 |
| **系统反馈** | • 文件生成失败：Toast"文件生成失败，请稍后重试"<br>• 网络中断：Toast"网络异常，下载已中断"<br>• 浏览器拦截：Toast"请允许浏览器下载文件" |
| **用户下一步** | 检查网络或浏览器设置后重试 |
| **恢复路径** | 原路返回，无信息丢失。点击下载按钮重新开始 |

### 统一状态口径表

| 状态 | 含义 | 适用对象 | 用户可操作 | 统一反馈口径 |

| U-09 可行动恢复路径 | 每个异常提供具体的恢复路径和下一步 | §5 异常流程的"恢复路径"和"用户下一步" |

### 上游承接追踪

| 上游判断（来自 UXB §7） | 对体验意味着什么 | 体验设计决策 | 落点章节 |
|------------------------|----------------|-------------|---------|
| 数据精度受上游净值约束 | 用户可能对数据准确性质疑 | 关键数据点就近标注；推荐模块标注"仅供参考" | §3 节点7、§6 底部 |
| 持仓表现/诊断/推荐仅理财 | 用户看到全量分布却只拿到理财建议 | 模块标题标注"仅理财"或覆盖范围 | §0 判断3、§6 模块标题 |
| 购买新开页签跳转 | 购买后与建议书的上下文可能丢失 | 原页签维持页面状态，页签标题提示"来自资产配置" | §3 节点8 |
| 时间区间联动多模块 | 用户不确定哪些模块正在更新 | 模块级加载态，独立刷新 | §3 节点4、§5 异常1 |
| 下载内容平铺展示 | 用户在线下找不到信息对应关系 | 下载产物保留模块标题和层级 | §4 次路径1 |
| 无诊断问题时模块不展示 | 用户无法区分"没问题"和"出错了" | 靠其他模块正常展示暗示数据就绪 | §0 判断2、§6 诊断模块 |
