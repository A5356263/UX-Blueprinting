# 体验蓝图：子管理员复制

---

## §0 本次关键设计判断

### 判断 1：批量复制操作采用弹窗承载

复制操作从子管理员列表行发起，完成后需回到列表继续管理。弹窗能在不离开列表上下文的前提下完成选择和确认，且信息量适中（复制信息 + 复制对象）。不采用抽屉（会过度占用侧边空间）也不采用独立页面（会切断列表上下文）。

- **主要影响：** 复制弹窗、员工选择弹窗（子弹窗）、结果展示三个容器的衔接设计
- **建议方案：** 复制弹窗 → 内嵌员工选择弹窗 → 结果替换弹窗内容，三步在同一弹窗层级内闭环
- **不建议方案：** 把员工选择和复制拆成两个独立弹窗或跳转到独立选人页面，会割裂操作流
- **关键待确认：** 员工选择弹窗是否前置标识未加入/未认证用户（影响选择阶段的交互复杂度）

### 判断 2：复制结果按成功/失败分组展示，不用统一 toast

部分成功是已确认的处理原则。一个笼统的 toast "复制成功" 在部分失败场景下会误导用户。成功项和失败项需要各自有明确的视觉分组和操作状态。

- **主要影响：** 复制确认后的结果反馈设计
- **建议方案：** 复制弹窗的执行结果区域替换为"成功列表 + 失败列表"分组视图，失败项显示原因
- **不建议方案：** 只弹一个 toast 提示"部分成功"，让用户在操作记录里找失败详情
- **关键待确认：** 失败列表是否提供"复制失败项"快捷入口（用户已确认需重新开始完整流程，但界面上可提供一键携带失败用户重新进入复制流程的能力）

### 判断 3：双管理员互审模式下，"已提交审批"和"已生效"用不同状态节点表达

用户已确认审批通过后才生效。这意味着在互审模式下，"复制成功"的 toast 必须改为"已提交审批"，并在审批通过时才有第二次通知。不能把两个节点合并为一个反馈。

- **主要影响：** Toast 文案、审批等待期的状态展示、审批结果通知
- **建议方案：** 非互审模式 → Toast "复制成功，授权已生效"；互审模式 → Toast "已提交审批，审批通过后生效"，审批通过后系统通知
- **不建议方案：** 两套模式共用同一个"复制成功" toast
- **关键待确认：** 审批通过后的通知方式（站内信/系统通知/审批中心）

### 判断 4：操作记录详情使用结构化快照

审计要求不只记录"谁复制了谁"，还需要记录复制时点的完整配置。操作记录的"详情"字段不应留空。

- **主要影响：** 操作记录的字段设计和查看入口
- **建议方案：** 详情字段保存 JSON 快照：复制来源、复制信息（可授权组织/可授权功能）、目标用户列表、复制时间、复制结果
- **不建议方案：** 详情留空或仅记录"无"
- **关键待确认：** 详情字段的具体结构格式

## §1 旅程消费摘要

以下信息提取自主角色"权限管理员"的旅程分析（5 阶段），驱动后续章节的设计决策。

| 提取项 | 来源阶段 | 在本蓝图中的落点 |
|--------|---------|----------------|
| **信心最低点：** 圈选复制目标时无法预知用户状态 | 阶段三 | 驱动 §6 员工选择弹窗加入/认证状态前置标识 |
| **信心最低点：** 提交后校验等待长，结果反馈不清晰 | 阶段四 | 驱动 §5 校验异常流程、§3 分步校验反馈设计 |
| **信心最低点：** 失败项重新开始时操作流断裂 | 阶段四→五 | 驱动 §5 部分失败恢复路径设计 |
| **关键转折：** 点击复制按钮打开弹窗 | 阶段一→二 | 驱动 §3 弹窗打开时的前置说明 |
| **关键转折：** 确认复制对象开始校验 | 阶段三→四 | 驱动 §3 确认按钮的前置信息展示 |
| **流失风险：** 部分失败且需重试时放弃批量配置 | 阶段四 | 驱动 §5 部分失败流程的恢复引导力度 |

## §2 交互流程总览

### 主路径：权限管理员复制子管理员授权

```
子管理员列表页（定位来源行）
→ 点击 [复制]
→ 打开 复制弹窗（初始态：复制信息默认全选，复制对象为空）
→ 确认或调整复制信息勾选
→ 点击 [选择员工]
→ 打开 员工选择弹窗
→ 筛选并勾选目标用户（多选，上限 200 人）
→ 点击 [确定]
→ 员工选择弹窗关闭，复制弹窗更新已选人数
→ 点击 [确认复制]
→ 弹窗进入校验态（分步反馈）
→ 校验通过 → 执行复制
   → 非互审模式：直接生效 → Toast "复制成功，授权已生效"
   → 互审模式：提交审批 → Toast "已提交审批，审批通过后生效"
→ 弹窗展示复制结果（成功/失败分组）
→ 关闭弹窗，回到子管理员列表页
```

分支：
- 复制信息未勾选 → [确认复制] 不可点击，提示"请选择复制信息"
- 复制对象未选择 → [确认复制] 不可点击，提示"请选择至少一名复制对象"
- 校验部分失败 → 成功项继续执行，失败项列出，需重新开始
- 全部校验不通过 → 全部失败列表展示，不执行复制

### 次路径：查看操作记录

```
子管理员列表页 或 操作记录入口
→ 点击操作记录查看入口
→ 查看操作记录列表
→ 点击某条记录的"详情"展开结构化快照
```

## §3 主交互流程

### 节点 1：点击复制，打开弹窗

**用户动作：** 在子管理员列表页中，找到目标来源子管理员，点击操作列的"复制"按钮

**系统反馈：** 打开复制弹窗，弹窗标题为"复制"。复制信息区域默认勾选"可授权组织"和"可授权功能"。复制对象区域为空。

**需要前置解释的信息：**
- 弹窗顶部提示："将复制 {来源子管理员名称} 的授权范围给目标用户"
- 说明复制信息的含义：可授权组织 = 子管理员可管理的组织范围；可授权功能 = 子管理员可授权的功能上限

**建议文案：**
- 弹窗标题：复制
- 顶部提示：将复制「{来源子管理员名称}」的授权范围给目标用户

**下一步：** 用户勾选或调整复制信息，然后选择复制对象

---

### 节点 2：选择复制对象

**用户动作：** 点击复制对象的"选择员工"按钮，打开员工选择弹窗。在弹窗中通过姓名、手机号、部门筛选目标用户，勾选后点击"确定"。

**系统反馈：** 员工选择弹窗关闭，复制弹窗中的复制对象区域更新为已选用户标签列表（如"已选 5 人：张三、李四、王五……"）。

**需要前置解释的信息：**
- 员工选择弹窗中，如果用户加入状态或认证状态不满足条件，需要前置标识（如标签 "未加入" / "未认证"）

**建议文案：**
- 员工选择弹窗标题：选择员工
- 已选人数文案：已选 {N} 人（上限 200 人）
- 超限提示：最多选择 200 人

**下一步：** 点击"确认复制"提交操作

---

### 节点 3：确认并执行复制

**用户动作：** 确认复制信息已勾选、复制对象已选择后，点击"确认复制"

**系统反馈（分步执行）：**

1. **校验中：** 弹窗显示校验进度提示
   - Toast / 内联提示："正在校验…"
   - 依次校验：复制信息 → 复制对象 → 加入状态 → 认证状态

2. **校验通过：** 执行复制
   - 非互审模式：后端执行授权授予/叠加，弹窗切换到结果展示
   - 互审模式：提交审批，弹窗切换到结果展示

3. **校验不通过（部分）：** 成功项继续执行，失败项列出

4. **校验不通过（全部）：** 全部失败列表展示，不执行复制

**需要前置解释的信息：**
- 点击确认前，在按钮旁或弹窗底部提示"即将为 {N} 名用户复制授权范围"
- 互审模式下追加提示："当前为双管理员互审模式，复制需审批后生效"

**建议文案：**
- 确认按钮文案：确认复制
- 校验中反馈："正在校验 {N} 名用户的条件…"
- 互审模式提醒："当前为双管理员互审模式，复制需审批通过后生效"

**下一步：** 查看复制结果

---

### 节点 4：查看复制结果

**用户动作：** 阅读复制结果展示区，了解成功和失败情况

**系统反馈：** 弹窗内容从配置态切换到结果态，分为两个区域：
- 成功区域：成功人数 + 成功用户列表
- 失败区域：失败人数 + 失败用户列表 + 失败原因

**需要前置解释的信息：**
- 失败项的处理说明："失败项需重新开始完整复制流程"
- 失败原因应明确是"加入状态不通过"还是"认证状态不通过"

**建议文案：**
- 成功标题：复制成功 ✓（{N} 人）
- 失败标题：复制失败 ✗（{N} 人）
- 失败原因：{用户姓名} — {加入状态不是已加入 / 未完成实名认证}
- 底部提示：失败项需重新开始完整复制流程
- 互审模式额外提示：审批已提交，待审批通过后生效

**下一步：** 关闭弹窗回到列表，或查看操作记录

---

## §4 次交互流程

### 次流程 1：查看操作记录详情

**触发条件：** 复制完成后，权限管理员需要查看操作日志进行追溯

**用户动作：** 在操作记录列表中找到对应的复制记录，点击"详情"或展开操作

**系统反馈：** 展示结构化快照，包含：
- 复制来源：{来源子管理员名称}（{手机号}）
- 复制信息：可授权组织 / 可授权功能（或两者）
- 复制目标：{用户列表}
- 复制时间：{时间}
- 复制结果：成功 {N} 人 / 失败 {N} 人
- 审批状态（互审模式）：已提交审批 / 审批通过 / 审批拒绝

**需要前置解释的信息：** 操作记录详情是只读信息，不可编辑

**下一步：** 关闭详情返回操作记录列表

## §5 异常与阻断流程

### 异常 1：复制信息未勾选

**发生时机：** 点击"确认复制"时

**触发条件：** "可授权组织"和"可授权功能"均未勾选

**判断依据：** UXB 规则"复制信息至少选择一项"

**反馈形式：** 按钮级阻止提交

**系统反馈：** "确认复制"按钮置灰不可点击

**用户下一步：** 至少勾选一项复制信息

**恢复路径：** 原路恢复，无信息丢失

### 异常 2：复制对象未选择

**发生时机：** 点击"确认复制"时

**触发条件：** 未选择任何目标用户

**判断依据：** UXB 规则"复制对象至少选择一名用户"

**反馈形式：** 按钮级阻止提交

**系统反馈：** "确认复制"按钮置灰不可点击

**用户下一步：** 点击"选择员工"添加至少一名目标用户

**恢复路径：** 原路恢复，无信息丢失

### 异常 3：部分用户校验不通过（加入状态 / 认证状态）

**发生时机：** 点击"确认复制"后，校验阶段

**触发条件：** 部分选定用户不满足"加入状态已启用"或"认证状态已认证"

**判断依据：** UXB 确认的部分成功原则

**反馈形式：** 弹窗内容切换到结果态，显示失败分组

**系统反馈：** 成功项继续执行复制，失败项列出并标注原因

**用户下一步：** 查看失败列表，点击"重新复制"重新开始完整流程

**恢复路径：** 失败项需重新开始完整复制流程（用户确认），但系统中可"携带失败用户名单"作为新复制的默认对象，减少重复搜索成本。重新复制时，之前成功项不会重复执行（去重保障）。

### 异常 4：全部用户校验不通过

**发生时机：** 点击"确认复制"后，校验阶段

**触发条件：** 所有选定用户均不满足加入或认证条件

**判断依据：** UXB 状态表中已列出的异常

**反馈形式：** 弹窗展示全部失败列表，不做复制执行

**系统反馈：** 弹窗展示"全部失败"结果，列出每位用户的失败原因

**用户下一步：** 检查失败原因，修正后重新选择目标用户

**恢复路径：** 关闭弹窗，重新选择符合条件的用户再操作

### 异常 5：双管理员互审模式未完成搭档配置

**发生时机：** 确认复制后，提交审批时

**触发条件：** 系统已开启双管理员互审模式，但未完成互审搭档和受控范围配置

**判断依据：** UXB §6 异常表

**反馈形式：** Toast 提示，复制执行结果仍为直接生效或阻断

**系统反馈：** 提示"当前双管理员互审模式未完成配置，请联系系统管理员"

**用户下一步：** 联系系统管理员完成互审配置，或确认是否需要审批

**恢复路径：** 本次复制不丢失，但需要确认实际生效方式

## §6 页面 / 弹窗 / 抽屉设计

### 6.1 子管理员列表页（复制入口）

**页面目标：** 查看和管理已配置的子管理员，定位来源子管理员并发起复制

**进入条件：** 开启子管理员模式后，通过权限管理模式页进入或直接通过菜单进入

**页面结构（参考知识库 §4.2 子管理员列表页）：**

```
+-------------------------------------------------------------------+
| [Tab: 子管理员模式] [Tab: 双管理员互审模式] [Tab: 权限变更审批模式] |
+-------------------------------------------------------------------+
| {业务介绍提示文本} [帮助文档]              [关闭子管理员模式]       |
+-------------------------------------------------------------------+
| 姓名：[输入框]  手机号：[输入框]  部门：[下拉框]  [重置] [查询]   |
+-------------------------------------------------------------------+
| [+ 添加子管理员]                                                    |
+-------------------------------------------------------------------+
| 姓名 | 手机号 | 部门 | 可授权组织 | 可授权功能 | 操作              |
|------|--------|------|-----------|-----------|-------------------|
| 张三  | 138..  | 技术部 | 全部组织   | 全部功能   | [复制] [编辑] [移除] |
| 李四  | 139..  | 产品部 | 技术部     | 考勤管理   | [复制] [编辑] [移除] |
+-------------------------------------------------------------------+
```

**按钮：**
- 操作列「复制」：打开复制弹窗，置于操作项最左侧

**成功反馈：** 复制完成后弹窗关闭，列表页保持原状态，用户可继续操作

**失败反馈：** 复制弹窗内展示失败结果，不回到列表页

### 6.2 复制弹窗

**弹窗目标：** 选择复制信息和复制对象，发起复制操作，展示复制结果

**触发条件：** 点击子管理员列表行操作列的"复制"按钮

**弹窗结构——配置态：**

```
+-------------------------------------------------------+
| 复制                                          [关闭]   |
|                                                        |
| 将复制「{来源子管理员名称}」的授权范围给目标用户           |
+-------------------------------------------------------+
| 复制信息                                                |
| [v] 可授权组织  — 子管理员可管理的组织范围               |
| [v] 可授权功能  — 子管理员可授权的功能上限               |
+-------------------------------------------------------+
| 复制对象                                                |
| 已选 {N} 人（上限200人）              [选择员工]         |
| {标签: 张三} {标签: 李四} {标签: 王五} ...             |
+-------------------------------------------------------+
| {互审模式提示：当前为双管理员互审模式，复制需审批后生效}  |
| [取消]                          [确认复制]              |
+-------------------------------------------------------+
```

**弹窗结构——结果态（部分成功）：**

```
+-------------------------------------------------------+
| 复制结果                                      [关闭]   |
+-------------------------------------------------------+
| ✅ 复制成功（{N}人）                                    |
|   张三、李四、王五                                      |
|                                                        |
| ❌ 复制失败（{N}人）                                    |
|   赵六 — 加入状态不是已加入                              |
|   孙七 — 未完成实名认证                                  |
|                                                        |
| 失败项需重新开始完整复制流程                             |
| {互审模式：审批已提交，待审批通过后生效}                  |
+-------------------------------------------------------+
| [关闭]                       [重新复制（携带失败用户）]  |
+-------------------------------------------------------+
```

**具体文案：**
- 弹窗标题：复制
- 顶部提示：将复制「{来源子管理员名称}」的授权范围给目标用户
- 复制信息说明：可授权组织 — 子管理员可管理的组织范围；可授权功能 — 子管理员可授权的功能上限
- 互审模式提示：当前为双管理员互审模式，复制需审批通过后生效
- 确认按钮：确认复制
- 结果-成功标题：复制成功（{N} 人）
- 结果-失败标题：复制失败（{N} 人）
- 结果-失败项提示：失败项需重新开始完整复制流程
- 结果-互审模式提示：审批已提交，待审批通过后生效

**按钮：**
- 配置态：[取消] [确认复制]
- 结果态：[关闭] [重新复制（携带失败用户）]

**成功反馈：**
- 非互审模式：Toast "复制成功，授权已生效"
- 互审模式：Toast "已提交审批，审批通过后生效"

**失败反馈：**
- 弹窗内结果态展示失败分组，不关闭弹窗

### 6.3 员工选择弹窗

**弹窗目标：** 选择一名或多名用户作为复制目标

## §7 状态与反馈文案

### 统一状态口径

| 状态 | 含义 | 适用对象 | 用户可操作 | 统一反馈口径 |
|------|------|---------|-----------|------------|
| 复制弹窗-初始 | 弹窗打开，可配置 | 复制弹窗 | 勾选/选择/取消 | — |
| 复制弹窗-待确认 | 已配置完毕，待提交 | 复制弹窗 | 确认/修改/取消 | — |
| 校验中 | 系统顺序校验 | 复制弹窗 | 等待 | "正在校验{N}名用户的条件…" |
| 校验部分失败 | 部分用户条件不满足 | 复制弹窗-结果 | 查看结果 | "成功{N}人，失败{N}人"，展示失败原因 |
| 校验全部失败 | 所有用户条件不满足 | 复制弹窗-结果 | 查看结果 | "复制失败"，展示全部失败原因 |
| 复制生效（非互审） | 授权已生效 | 系统 | 查看操作记录 | "复制成功，授权已生效" |
| 审批已提交（互审） | 待审批 | 系统 | 在审批中心查看 | "已提交审批，审批通过后生效" |
| 审批通过（互审） | 审批通过，授权已生效 | 系统 | 查看操作记录 | "审批通过，授权已生效" |
| 审批拒绝（互审） | 审批不通过，授权未生效 | 系统 | 查看原因 | "审批拒绝，授权未生效" |

### 反馈文案汇总

| 场景 | 反馈类型 | 文案 |
|------|---------|------|
| 复制成功（非互审） | Toast | "复制成功，授权已生效" |
| 复制成功（互审-提交） | Toast | "已提交审批，审批通过后生效" |
| 审批通过（互审） | 系统通知 | "复制审批通过，授权已生效" |
| 审批拒绝（互审） | 系统通知 | "复制审批拒绝" |
| 复制信息未勾选 | 按钮置灰 | —（提示"请选择复制信息"） |
| 复制对象未选择 | 按钮置灰 | —（提示"请选择至少一名复制对象"） |
| 部分用户不满足条件 | 弹窗内展示 | 失败项逐条显示失败原因 |
| 超200人 | 选择器拦截 | "最多选择200人" |
| 操作记录-详情 | 结构化展示 | 来源、信息、目标、结果、时间快照 |
