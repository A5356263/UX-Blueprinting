# 体验蓝图：子管理员复制

---

## §0 本次关键设计判断

**判断**：复制弹窗采用「浮层确认 + 结果反馈」模式，不做分步向导。

- **主要影响**：复制弹窗以单层浮层承载内容选择和目标选择两个区域；员工选择器复用现有弹窗，与添加子管理员体验一致。结果反馈通过 Toast + 结果详情实现，而非跳转结果页。
- **建议方案**：弹窗分为上下两区（复制信息 + 复制对象），默认全选。确认后 Toast 反馈，校验失败用 InlineError。互审模式下 Toast 改为「已提交审批」，审批状态在来源子管理员行上标注「审批中」标签。
- **不建议方案**：不使用步骤条分步向导（任务流程短，一次弹窗足够）；不为复制结果单独新建结果页（Toast + 结果详情抽屉即可）；不在非互审模式下也加审批状态标签（不必要的信息噪音）。
- **关键待确认**：部分校验不通过时的策略（全部退回/部分提交）会影响第 5 节的异常反馈设计方向，当前基于最严策略（全部退回）推进。

## §2 交互流程总览

本次设计包含以下交互路径：

### 主路径

**复制子管理员权限**

子管理员列表页（Page）
→ 点击操作列「复制」
→ 打开复制弹窗（Modal）
→ 勾选复制内容（可授权组织 / 可授权功能）
→ 点击复制对象选择器
→ 打开员工选择弹窗（Modal，复用现有）
→ 选择目标用户（1–200 名）
→ 确认后员工选择弹窗关闭，已选用户显示在复制弹窗中
→ 点击「确认」
→ 四项顺序校验（复制信息→复制对象→加入状态→认证状态）
→ 校验通过
→ 场景 A（非互审）：Toast「复制成功」，弹窗关闭
→ 场景 B（互审中）：Toast「已提交审批」，弹窗关闭

分支：
- 复制信息未选 → 阻断，Toast「请选择复制信息」
- 复制对象未选 → 阻断，Toast「请选择至少一名复制对象」
- 目标用户未加入 → 阻断，Toast 列出未加入用户
- 目标用户未认证 → 阻断，Toast 列出未认证用户

### 次路径

**查看操作记录**

操作记录列表页（已有页面）
→ 在列表中查看复制产生的操作记录（分条存储，按操作聚合展示）

**审批复制申请（互审模式）**

审批列表（已有页面）
→ 互审管理员查看复制审批
→ 通过 / 驳回
→ 通过：写入权限，目标用户成为子管理员或叠加权限
→ 驳回：Toast 通知权限管理员

## §3 主交互流程

### 3.1 定位并选中来源子管理员

| 字段 | 内容 |
|------|------|
| **用户动作** | 进入子管理员列表页，在列表中搜索或浏览，找到作为复制来源的子管理员 |
| **系统反馈** | 列表正常展示子管理员数据，每行包含姓名、手机号、部门、可授权组织、可授权功能和操作列 |
| **需要前置解释的信息** | 无（已有操作，非新增） |
| **建议文案** | 无 |
| **下一步** | 点击操作列「复制」按钮 |

### 3.2 点击「复制」打开复制弹窗

| 字段 | 内容 |
|------|------|
| **用户动作** | 在目标子管理员的操作列中点击「复制」按钮 |
| **系统反馈** | 打开复制弹窗，复制信息区默认全选（可授权组织 + 可授权功能），复制对象区为空 |
| **需要前置解释的信息** | 无（弹窗标题和区域标题已说明用途） |
| **建议文案** | 弹窗标题：「复制」；复制信息区提示：「复制该子管理员的可授权组织和/或可授权功能给其他用户」 |
| **下一步** | 勾选复制内容，或直接选择复制对象 |

### 3.3 选择复制对象

| 字段 | 内容 |
|------|------|
| **用户动作** | 点击复制对象区的「选择」按钮，在员工选择弹窗中查找并选择目标用户（1–200 名），确认后弹窗关闭 |
| **系统反馈** | 员工选择弹窗关闭，已选用户以标签形式展示在复制弹窗的复制对象区（每个用户标签含姓名、手机号、部门），并标注当前身份（普通用户/子管理员） |
| **需要前置解释的信息** | 「当前身份」说明：普通用户复制后将「成为子管理员」，已有子管理员将「叠加权限」 |
| **建议文案** | 复制对象区下方轻提示：「已选 {N} 人（最多 200 人）。其中 M 名普通用户将成为子管理员，K 名已有子管理员将叠加权限。」 |
| **下一步** | 点击「确认」提交复制 |

### 3.4 确认并提交复制

| 字段 | 内容 |
|------|------|
| **用户动作** | 点击复制弹窗「确认」按钮 |
| **系统反馈** | 系统顺序执行四项校验：①复制信息已选 → ②复制对象已选 → ③目标用户加入状态 → ④目标用户认证状态。通过后进入执行阶段。 |
| **需要前置解释的信息** | 无（校验过程中用户等待即可） |
| **建议文案** | 无（校验为静默执行） |
| **下一步** | 等待校验结果 |

### 3.5 校验通过后执行复制

**场景 A：非互审模式**

| 字段 | 内容 |
|------|------|
| **用户动作** | 等待系统处理 |
| **系统反馈** | 对每个目标用户执行写入（普通用户→成为子管理员并写入权限；已有子管理员→叠加权限）。所有目标处理完成后，Toast「复制成功」，弹窗关闭。 |
| **需要前置解释的信息** | 无 |
| **建议文案** | Toast：「复制成功」（绿色成功图标） |
| **下一步** | 可在子管理员列表中查看目标用户已生效，或在操作记录中查看详情 |

**场景 B：双管理员互审模式**

| 字段 | 内容 |
|------|------|
| **用户动作** | 等待系统处理 |
| **系统反馈** | 生成审批实例，弹窗关闭，Toast「已提交审批」，操作记录写入 |
| **需要前置解释的信息** | 复制操作已提交审批，另一位管理员审批通过后权限才会写入 |
| **建议文案** | Toast：「已提交审批」（蓝色信息图标），副文本：「等待另一位管理员确认后生效」 |
| **下一步** | 等待另一位管理员审批，审批通过后目标用户生效 |

## §4 次交互流程

### 4.1 查看复制操作记录

| 字段 | 内容 |
|------|------|
| **触发条件** | 权限管理员希望追溯某次复制操作的结果 |
| **用户动作** | 进入操作记录列表页，筛选或搜索复制相关记录 |
| **系统反馈** | 按操作聚合展示：同一复制操作的两条记录（可授权组织 + 可授权功能）默认合并为一条记录，可展开查看明细 |
| **需要前置解释的信息** | 合并记录中同时显示复制了哪些内容（组织/功能） |
| **建议文案** | 记录标题：「将子管理员【XXX】权限复制给 N 名用户」；展开后按内容和目标展示明细 |
| **下一步** | 查看完后返回列表或关闭 |

### 4.2 审批复制申请（互审管理员视角）

| 字段 | 内容 |
|------|------|
| **触发条件** | 系统处于双管理员互审模式，权限管理员提交了复制申请 |
| **用户动作** | 互审管理员在审批列表中查看待审批的复制申请，点击查看详情 |
| **系统反馈** | 展示复制申请的完整信息：来源子管理员、复制内容、目标用户列表及当前身份 |
| **需要前置解释的信息** | 展示「复制内容预览」和「目标用户清单」，帮助互审管理员判断是否合理 |
| **建议文案** | 审批详情标题：「子管理员复制审批」；内容区展示「复制来源」「复制内容」「复制目标（N 人）」 |
| **下一步** | 审批通过或驳回 |

### 4.3 审批驳回后权限管理员收到通知

| 字段 | 内容 |
|------|------|
| **触发条件** | 互审管理员驳回了复制申请 |
| **用户动作** | 权限管理员收到驳回通知（消息/审批通知），查看驳回原因 |
| **系统反馈** | 驳回通知中展示驳回原因、复制内容摘要和驳回时间 |
| **需要前置解释的信息** | 被驳回的复制申请不会写入任何权限，需要重新发起 |
| **建议文案** | 通知：「您的子管理员复制申请已被驳回」，副文本显示驳回原因 |
| **下一步** | 根据驳回原因修正后重新发起复制，或放弃操作 |

## §5 异常与阻断流程

### 5.1 复制内容未选

| 字段 | 内容 |
|------|------|
| **发生时机** | 用户点击「确认」，但未勾选任何复制内容 |
| **触发条件** | 可授权组织和可授权功能均未勾选 |
| **判断依据** | 需求文档：复制信息至少选择一项 |
| **反馈形式** | Toast |
| **系统反馈** | 阻断确认，Toast「请选择复制信息」 |
| **用户下一步** | 勾选至少一项后重新点击「确认」 |
| **恢复路径** | 原路恢复，无信息丢失。直接在弹窗中勾选即可。 |

### 5.2 复制对象未选

| 字段 | 内容 |
|------|------|
| **发生时机** | 用户点击「确认」，但未选择任何目标用户 |
| **触发条件** | 复制对象列表为空 |
| **判断依据** | 需求文档：复制对象至少选择一名 |
| **反馈形式** | Toast |
| **系统反馈** | 阻断确认，Toast「请选择至少一名复制对象」 |
| **用户下一步** | 点击选择器添加目标用户后重新点击「确认」 |
| **恢复路径** | 原路恢复，无信息丢失。当前弹窗中输入的其他信息不受影响。 |

### 5.3 目标用户未加入

| 字段 | 内容 |
|------|------|
| **发生时机** | 用户点击「确认」，校验到部分目标用户的加入状态为未加入 |
| **触发条件** | 已选目标用户中存在加入状态 ≠ 已加入的用户 |
| **判断依据** | 需求文档：复制对象的加入状态必须均为已启用 |
| **反馈形式** | Toast + 弹窗内错误提示 |
| **系统反馈** | 阻断确认，子管理员列表页 Toast：「XXX、XXX 加入状态不是已加入，不能成为子管理员」；复制弹窗中目标用户区，未加入用户标签标红，旁注「未加入」 |
| **用户下一步** | 移除未加入用户（在弹窗中点击标签上的移除按钮），或退出弹窗确认该用户已加入后再重新操作 |
| **恢复路径** | 移除无效用户后直接重新确认，已输入的其他选择不丢失。弹窗不关闭。 |

### 5.4 目标用户未认证

| 字段 | 内容 |
|------|------|
| **发生时机** | 用户点击「确认」，校验到部分目标用户的认证状态为未认证 |
| **触发条件** | 已选目标用户中存在未完成实名认证的用户 |
| **判断依据** | 需求文档：复制对象的认证状态必须均为已认证 |
| **反馈形式** | Toast + 弹窗内错误提示 |
| **系统反馈** | 阻断确认，子管理员列表页 Toast：「XXX、XXX 未完成实名认证，不能成为子管理员」；复制弹窗中目标用户区，未认证用户标签标红，旁注「未认证」 |
| **用户下一步** | 移除未认证用户，或确认该用户已完成认证后重新操作 |
| **恢复路径** | 移除无效用户后直接重新确认，已输入的其他选择不丢失。弹窗不关闭。 |

### 5.5 多重校验不通过

| 字段 | 内容 |
|------|------|
| **发生时机** | 用户点击「确认」，校验时同时命中多个异常 |
| **触发条件** | 同时存在未加入用户和未认证用户，或复制信息和复制对象均未选择 |
| **判断依据** | 需求文档：校验按顺序执行 |
| **反馈形式** | Toast + 弹窗内错误提示 |
| **系统反馈** | 按顺序优先阻断最先不通过的校验。用户修正第一个问题后再次提交时，如果第二个问题仍然存在，继续阻断。不会同时展示所有错误。 |
| **用户下一步** | 按提示顺序依次修正每个校验问题 |
| **恢复路径** | 逐次修改后重新确认，每次修正后已填信息不丢失。 |

### 5.6 部分校验不通过（200 名目标中部分异常）

| 字段 | 内容 |
|------|------|
| **发生时机** | 用户选择大量目标用户，点击确认后其中部分用户校验不通过 |
| **触发条件** | 批量中混杂了不满足条件的用户 |
| **判断依据** | 当前按「全部退回」策略推进 |
| **反馈形式** | Toast + 弹窗内错误提示 |
| **系统反馈** | 阻断确认，toast 列出所有校验不通过的用户及原因。弹窗中不通过的用户标签标红，表明原因。通过的用户保持正常。 |
| **用户下一步** | 移除不通过的用户，保留通过的用户后重新确认 |
| **恢复路径** | 移除异常用户后直接重新确认，已通过的用户的校验不重做。当前设计基于「全部退回」策略。 |

### 5.7 审批驳回

| 字段 | 内容 |
|------|------|
| **发生时机** | 互审模式下，另一位管理员审批不通过 |
| **触发条件** | 互审管理员在审批中驳回复制申请 |
| **判断依据** | UXB 确认：审批驳回后不写入权限 |
| **反馈形式** | 系统通知 + 审批系统状态更新 |
| **系统反馈** | 权限管理员收到通知「你的子管理员复制申请已被驳回」，副文本显示驳回原因。审批系统将该审批标记为已驳回。 |
| **用户下一步** | 查看驳回原因，根据原因调整后重新发起复制 |
| **恢复路径** | 重新发起复制需要重新走一遍完整流程（选择来源→选择内容→选择目标→确认）。无法在原申请上修改后再次提交。 |

### 5.8 审批超时

| 字段 | 内容 |
|------|------|
| **发生时机** | 互审模式下，复制申请提交后审批人长期未处理 |
| **触发条件** | 审批在系统超时阈值内未获得处理 |
| **判断依据** | UXB：依赖审批系统的超时机制 |
| **反馈形式** | 无独立反馈，依赖于审批系统的超时机制 |
| **系统反馈** | 按审批系统既有超时规则处理 |
| **用户下一步** | 联系互审管理员处理审批，或视系统是否支持自行撤回后重新提交 |
| **恢复路径** | 依赖于审批系统的超时机制和撤回能力 |

## §7 状态与反馈文案

### 状态口径

| 状态 | 含义 | 适用对象 | 用户可操作 | 统一反馈口径 |
|------|------|----------|-----------|-------------|
| 复制弹窗打开 | 用户进入复制流程，已加载来源配置 | 权限管理员 | 勾选内容、选择目标、取消关闭 | 弹窗标题「复制」+ 提示文本 |
| 校验通过（非互审） | 所有校验通过，权限已写入 | 权限管理员 | 查看列表确认、查看操作记录 | Toast「复制成功」 |
| 校验通过（互审中） | 所有校验通过，已提交审批 | 权限管理员 | 等待审批 | Toast「已提交审批，等待另一位管理员确认后生效」 |
| 校验不通过 | 某项校验失败，未执行复制 | 权限管理员 | 根据提示修正后重新确认 | Toast + 弹窗内错误标注 |
| 审批中 | 复制申请已提交，等待审批 | 权限管理员 + 互审管理员 | 等待审批、联系审批人 | 子管理员列表行内标签「审批中」 |
| 审批通过 | 另一位管理员通过审批，权限已写入 | 权限管理员 | 确认生效 | 系统通知「子管理员复制审批已通过」 |
| 审批驳回 | 另一位管理员驳回申请，权限未写入 | 权限管理员 | 查看原因、重新发起 | 系统通知「子管理员复制申请已被驳回」+ 驳回原因 |

### 反馈文案汇总

| 场景 | 反馈形式 | 文案 |
|------|----------|------|
| 复制成功（非互审） | Toast | 复制成功 |
| 复制提交成功（互审） | Toast | 已提交审批 — 等待另一位管理员确认后生效 |
| 复制内容未选 | Toast | 请选择复制信息 |
| 复制对象未选 | Toast | 请选择至少一名复制对象 |
| 目标未加入 | Toast | XXX、XXX 加入状态不是已加入，不能成为子管理员 |
| 目标未认证 | Toast | XXX、XXX 未完成实名认证，不能成为子管理员 |
| 审批通过 | 系统通知 | 子管理员复制审批已通过 |
| 审批驳回 | 系统通知 | 子管理员复制申请已被驳回：[驳回原因] |
| 身份分布提示 | 弹窗内轻提示 | 已选 {N} 人，其中 {M} 名已有子管理员将叠加权限，{K} 名普通用户将成为子管理员 |
| 审批中状态 | 列表行标签 | 审批中 |
