# 体验蓝图：员工自助申请权限

---

## §0 本次关键设计判断

### 判断一：申请入口采用"现场触发 + 独立模块"双路径

**判断**：员工端权限申请入口不单独依赖"权限中心"独立模块，而是在功能受限的页面直接提供"申请权限"入口，同时在"我的权限"页面保留完整的申请入口。

**主要影响**：影响"我的权限"页面、"申请权限"抽屉、功能受限页面的嵌入点的设计。

**建议方案**：功能页面受限时，错误提示中附带"申请权限"文字链接或按钮，点击后直接进入权限申请流程；"我的权限"页面顶部操作栏放置"申请权限"主按钮作为第二入口。

**不建议方案**：只在独立模块放入口，要求员工主动找到"权限中心"去申请——这会回到"员工不知道去哪"的老问题。

**关键待确认**：功能页面的受限提示是否具备嵌入交互条件（纯文案提示还是支持按钮跳转）。

### 判断二：权限列表采用"分类聚合 + 搜索辅助"替代纯列表

**判断**：可申请权限列表不直接展示为扁平列表，而是按业务域分类聚合，配合关键词搜索。

**主要影响**：影响申请权限 Drawer 的信息结构设计。

**建议方案**：按"人事管理、考勤管理、审批管理"等业务域分类展示权限组，展开后看到具体权限项，每项附带一句话用途说明。顶部提供搜索框。

**不建议方案**：把几百个权限名放在一个下拉框或一张长列表里——员工无法理解也找不到需要的项。

**关键待确认**：现有权限是否有清晰的业务域分类和用途说明。

### 判断三：审批卡片附带申请人权限上下文

**判断**：审批人收到的权限申请审批卡片，不只有"XX 申请了 XX 权限"，还需要展示申请人当前已有的相关权限、申请原因、该权限的用途说明。

**主要影响**：影响审批端审批卡片的展示结构设计。

**建议方案**：审批卡片/页面中嵌入"申请人权限现状"摘要区块（该员工已有相关权限的简表），以及"权限说明"区块（所申请权限的用途和影响范围）。

**不建议方案**：沿用通用审批模板，只展示"XX 提交了权限申请"——审批人无法判断该不该批。

**关键待确认**：审批端是否支持定制化审批卡片内容。

## §1 旅程消费摘要

以下提取自 journey-analysis 对普通员工角色的旅程分析，用于驱动本章蓝图的设计决策。

### 信心最低点 → 驱动异常流程优先级

| 阶段 | 信心等级 | 原因 | 在本蓝图中驱动 |
|------|---------|------|--------------|
| 定位申请 | 中 | 入口位置和权限命名标准化程度未确认 | §5 异常流程中"找不到入口/看不懂权限名"须优先处理 |
| 等待审批 | 中 | 审批时长、催办机制、超时处理未定义 | §5 异常流程中"审批超时/状态不更新"须明确恢复路径 |

### 关键转折 → 驱动交互流程前置说明

| 转折 | 触发 | 在本蓝图中驱动 |
|------|------|--------------|
| 发现受限 → 定位申请 | 员工决定主动申请 | §3 主流程第 1 节点需要附带"系统已检测到你缺少XX权限"的前置说明 |
| 等待审批 → 获得结果 | 审批人做出决定 | §3 主流程"等待"阶段需要前置说明预计时长和审批人信息 |

### 流失风险 → 驱动页面引导策略

| 阶段 | 流失风险 | 在本蓝图中驱动 |
|------|---------|--------------|
| 定位申请 | 高 | §6 "我的权限"页面需要提供强引导（搜索、分类、说明） |
| 等待审批 | 高 | §6 申请记录页需要展示清晰的审批流转路径和催办入口 |

## §2 交互流程总览

### 主路径（1 条）

**员工提交权限申请**

功能受限页面 → 点击[申请权限] → 打开权限申请 Drawer → 选择权限分类 → 选择具体权限项 → 填写申请原因 → 点击[提交] → 系统校验 → Drawer 关闭 → Toast 提示提交成功 → 申请记录列表新增"待审批"记录

分支：
- 未选择权限项 → [提交]按钮置灰
- 申请原因为空/不足 → 原因输入区下方 InlineError
- 所选权限不在可申请范围 → Drawer 内提示并不可提交
- 审批人不存在/流程无效 → Toast 提示配置异常，引导联系管理员

### 次路径（3 条）

**1. 管理员配置自助申请**
自助申请配置 Page → 开启能力 → 配置可申请范围 → 配置审批流程 → 保存

**2. 员工查看自有权限**
我的权限 Page → 默认展示当前有效权限列表 → 可按分类筛选/搜索 → 点击权限项查看说明

**3. 管理员关闭自助申请**
自助申请配置 Page → 点击关闭 → 检查进行中申请 → 有则弹窗提示 → 确认关闭

## §3 主交互流程

### 节点 1：触发申请

| 字段 | 内容 |
|------|------|
| **用户动作** | 员工在功能页面遇到权限不足的提示，点击"申请权限" |
| **系统反馈** | 打开权限申请 Drawer，自动选中提示中所缺的权限项（如支持）；或打开 Drawer 并定位到对应分类 |
| **前置说明** | "你缺少使用此功能所需的权限，你可以选择下方已推荐的权限项，或浏览其他可申请权限" |
| **建议文案** | 提示文字："你暂无 XX 权限。你可以立即申请，审批通过后即可使用。" |
| **下一步** | 进入权限选择步骤 |

### 节点 2：选择权限

| 字段 | 内容 |
|------|------|
| **用户动作** | 在 Drawer 中浏览权限分类 → 展开分类 → 选择具体权限项 |
| **系统反馈** | 选中后权限项高亮，显示该权限的用途说明 |
| **前置说明** | 权限按业务域分组，每项附带一句话说明 |
| **建议文案** | 权限项说明："此权限允许你进行 XX 操作，适用于 XX 场景" |
| **下一步** | 填写申请原因 |

### 节点 3：填写申请原因

| 字段 | 内容 |
|------|------|
| **用户动作** | 在申请原因文本框中输入申请理由 |
| **系统反馈** | 输入字数实时统计，输入框提供示例引导 |
| **前置说明** | "请简要说明你需要此权限做什么，帮助审批人更快做出决定" |
| **建议文案** | 示例提示："例如：我需要此权限来完成每月的考勤统计工作" |
| **下一步** | 提交申请 |

### 节点 4：提交申请

| 字段 | 内容 |
|------|------|
| **用户动作** | 点击[提交申请]按钮 |
| **系统反馈** | 校验所选权限是否在可申请范围内 → 校验通过则创建申请单 → Drawer 关闭 → Toast "申请已提交" → 申请记录列表刷新 |
| **前置说明** | 提交前无额外说明 |
| **建议文案** | Toast："申请已提交，审批人：{审批人姓名}，预计处理时间：{时长}" |
| **下一步** | 跳转到申请记录页 |

### 节点 5：等待审批

| 字段 | 内容 |
|------|------|
| **用户动作** | 查看申请记录页 → 关注审批状态 |
| **系统反馈** | 状态标签显示"待审批"或"审批中"；状态变更时主动推送通知 |
| **前置说明** | "你的申请已提交至 {审批人姓名}，审批通过后权限自动生效" |
| **建议文案** | 状态栏说明："当前审批人：{审批人姓名}，提交时间：{时间}，已等待 {时长}" |
| **下一步** | 等待审批结果或催办 |

### 节点 6：获得结果

| 字段 | 内容 |
|------|------|
| **用户动作** | 收到审批结果通知 |
| **系统反馈** | （通过）状态变更为"已通过"，自动执行授权，通知申请人 → 短信/应用内通知；（被拒）状态变更为"已拒绝"，推送拒绝原因 |
| **前置说明** | 无（结果通知） |
| **建议文案** | 通过通知："你的 {权限名} 申请已通过，权限已生效，可立即使用。[回到功能]" 拒绝通知："你的 {权限名} 申请已被拒绝。原因：{拒绝原因}。[重新申请]" |
| **下一步** | 通过：回到原功能使用；被拒：查看原因后决定是否重新申请 |

## §4 次交互流程

### 4.1 管理员配置自助申请

| 字段 | 内容 |
|------|------|
| **触发条件** | 超管进入"自助申请配置"页面 |
| **用户动作** | 开启"允许员工自助申请权限"开关 → 配置可申请范围（按业务域选择权限）→ 选择/绑定审批流程 → 点击[保存] |
| **系统反馈** | 保存成功 → Toast "配置已保存，员工可开始自助申请权限" |
| **前置说明** | "开启后，员工可在权限中心查看自有权限并提交权限申请。开启前请先配置可申请范围和审批流程。" |
| **建议文案** | 范围配置说明："选择你可以开放的权限范围。不在范围内的权限，员工无法自助申请。" |
| **下一步** | 配置完成后可继续调整或关闭能力 |

### 4.2 员工查看自有权限

| 字段 | 内容 |
|------|------|
| **触发条件** | 员工进入"我的权限"页面 |
| **用户动作** | 查看权限列表 → 按分类筛选或搜索 → 点击某权限项查看详情 |
| **系统反馈** | 展示当前员工有效权限（功能权限 + 数据范围），按业务域分组。权限项显示来源标签（如"系统授予""角色继承""自助申请"） |
| **前置说明** | 无（首页数据展示） |
| **建议文案** | 来源标签说明："自助申请"来源的权限附带"由你于 {日期} 申请"的说明 |
| **下一步** | 可发起新的权限申请 |

### 4.3 管理员关闭自助申请

| 字段 | 内容 |
|------|------|
| **触发条件** | 超管在配置页面关闭"允许员工自助申请权限"开关 |
| **用户动作** | 关闭开关 → 系统检测是否有进行中申请 → 弹窗确认 |
| **系统反馈** | 有进行中申请时弹窗："当前有 {N} 个进行中的申请。关闭后，新申请入口将隐藏，已提交的申请将继续流转。" → 确认后关闭能力 |
| **前置说明** | 关闭前弹窗提示，避免误操作 |
| **建议文案** | 关闭确认弹窗："确定关闭自助申请权限？关闭后，员工将无法提交新的权限申请，已提交的申请将继续正常审批。" |
| **下一步** | 关闭后员工端入口隐藏，已有申请继续流转 |

## §5 异常与阻断流程

### 异常 1：所选权限不在可申请范围

| 字段 | 内容 |
|------|------|
| **发生时机** | 员工在权限申请 Drawer 中选择权限并点击提交时 |
| **触发条件** | 所选权限不在管理员配置的可申请范围列表中 |
| **判断依据** | 系统校验权限范围配置 |
| **反馈形式** | Drawer 内 Inline 提示，不关闭 Drawer |
| **系统反馈** | "该权限暂不支持自助申请，如需此权限请联系管理员" |
| **用户下一步** | 可重新选择其他权限或关闭 Drawer |
| **恢复路径** | 原路恢复，无信息丢失 |

### 异常 2：审批人缺失或审批流程无效

| 字段 | 内容 |
|------|------|
| **发生时机** | 员工提交申请时或系统尝试路由审批时 |
| **触发条件** | 审批流程中指定的审批人不存在、已离职，或流程配置不完整 |
| **判断依据** | 系统检查审批流程配置状态 |
| **反馈形式** | Toast 提示 + 申请单标记异常 |
| **系统反馈** | "审批流程配置异常，无法提交申请。请联系管理员检查审批配置。" 系统同时通知管理员修复 |
| **用户下一步** | 联系管理员处理。申请单不创建或标记为"已失效" |
| **恢复路径** | 管理员修复审批流程后，员工可重新提交。已填信息丢失（需重新填写） |

### 异常 3：自动授权失败

| 字段 | 内容 |
|------|------|
| **发生时机** | 审批通过后，系统执行自动授权时 |
| **触发条件** | 调用授权接口失败（系统异常、权限冲突等） |
| **判断依据** | 授权接口返回异常 |
| **反馈形式** | 系统通知管理员 + 员工端展示授权异常状态 |
| **系统反馈** | 申请单状态标记为"已通过-授权异常"；通知管理员手动处理；通知员工"你的申请已通过，但授权过程中出现异常，管理员正在处理" |
| **用户下一步** | 等待管理员处理完成或联系管理员 |
| **恢复路径** | 管理员手动执行授权或重试。员工无需重新申请 |

### 异常 4：申请后权限被删除

| 字段 | 内容 |
|------|------|
| **发生时机** | 员工的申请正在审批中或已通过但未生效时 |
| **触发条件** | 管理员在后台删除了该权限项 |
| **判断依据** | 权限定义表中该权限状态变更为"已删除" |
| **反馈形式** | 系统自动标记申请异常 + 通知员工 |
| **系统反馈** | 申请单状态变更为"已失效"；通知员工"你申请的 {权限名} 已不存在，无法完成授权。" |
| **用户下一步** | 联系管理员确认或选择其他权限重新申请 |
| **恢复路径** | 无法自动恢复，需要重新提交申请 |

### 异常 5：关闭能力时有进行中申请

| 字段 | 内容 |
|------|------|
| **发生时机** | 管理员关闭自助申请能力时 |
| **触发条件** | 当前存在进行中的权限申请（待审批/审批中） |
| **判断依据** | 系统查询进行中申请单数量 |
| **反馈形式** | 弹窗确认 |
| **系统反馈** | "当前有 {N} 个进行中的申请。关闭后，新申请入口将隐藏，已提交的申请将继续流转直至结束。" 弹窗提供[确认关闭]和[取消]按钮 |
| **用户下一步** | 确认关闭或取消操作 |
| **恢复路径** | 确认后关闭，已有申请不受影响 |

## §7 状态与反馈文案

### 申请单状态

| 状态 | 含义 | 适用对象 | 用户可操作 | 统一反馈口径 |
|------|------|---------|-----------|------------|
| 待审批 | 申请已提交，等待审批人处理 | 员工 | 查看详情、等待 | "你的申请已提交，正在等待 {审批人姓名} 审批" |
| 审批中 | 多人审批场景，部分节点已通过 | 员工 | 查看详情、等待 | "你的申请正在审批中，当前节点：{审批人姓名}" |
| 已通过 | 审批全部通过，权限生效 | 员工 | 回到功能、查看权限 | "你的 {权限名} 申请已通过，权限已生效" |
| 已拒绝 | 审批人拒绝申请 | 员工 | 查看原因、重新申请 | "你的 {权限名} 申请已被拒绝。原因：{拒绝原因}" |
| 已撤回 | 员工在审批前主动撤回 | 员工 | 重新提交 | "你已撤回 {权限名} 的申请" |
| 已失效 | 能力关闭或权限已删除 | 员工 | 联系管理员 | "该申请已失效，如需帮助请联系管理员" |
| 授权异常 | 审批通过但授权失败 | 员工、管理员 | 等待管理员处理 | "审批已通过，但授权时出现异常，管理员正在处理中" |

### Toast 文案

| 场景 | 文案 |
|------|------|
| 申请提交成功 | "申请已提交，审批人：{姓名}，可在申请记录中查看进度" |
| 范围校验失败 | "该权限暂不支持自助申请" |
| 审批流程异常 | "审批流程配置异常，无法提交，请联系管理员" |
| 配置保存成功 | "配置已保存" |
| 范围未配置 | "请先选择可申请范围" |
| 流程未配置 | "请先选择审批流程" |
| 关闭确认 | "已关闭自助申请能力，进行中的申请将继续流转" |
| 授权失败通知（管理员） | "员工 {姓名} 的权限申请审批已通过但自动授权失败，请手动处理" |
