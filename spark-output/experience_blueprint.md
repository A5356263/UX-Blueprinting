# 体验蓝图：资产配置面客版

## §0 本次关键设计判断

**判断：** 资产配置页面采用"摘要导航 + 纵向分段"的信息架构——将六大模块按浏览优先级分为两级：概览摘要区（顶部综合信息）和详情分段区（可滚动纵向区块），让用户先看全貌再逐段深入。

**主要影响：** 这个决策影响整个页面的布局骨架、模块间的浏览顺序、以及用户对信息密度的感知节奏。

**建议方案：** 页面顶部设置摘要卡片栏（时点资产 + 三大核心指标），下方按"表现 → 分布 → 期限 → 诊断 → 推荐"的决策链顺序纵向排列区块。账号选择器和时间筛选器固定在页面顶部，切换时各模块同步刷新并显示加载态。投资分布和期限分布内部使用 Tab 切换理财/其他业务。

**不建议方案：** 不建议所有模块平铺展开不做优先级区分；不建议把投资分布和期限分布做成独立页面跳转（打断浏览连续性）；不建议诊断和推荐拆成分离的 Tab 页。

**关键待确认：** 账号"全部"选项的数据含义（影响摘要卡汇总展示方式）；下载快照的数据范围（按当前筛选还是全量平铺）；诊断与推荐的关联逻辑（是否按诊断结果定向推荐）。

## §2 交互流程总览

### 交互路径

**主路径（1条）：**

企业客户从入口进入 → 选择/切换账号 → 浏览资产配置概览 → 查看持仓表现（含时间筛选） → 查看投资分布 → 查看期限分布 → 阅读持仓诊断 → 查看产品推荐 → 执行购买或下载

**分支路径（4条）：**

- **路径 A - 下载建议书：** 悬浮按钮 → 选择下载格式 → 确认下载范围 → 下载文件
- **路径 B - 诊断详情查看：** 诊断区块 → 点击问题条目 → 展开详情列表 → 查看/返回
- **路径 C - 产品详情跳转：** 推荐列表 → 点击产品名称 → 跳转产品详情 → 返回
- **路径 D - 批量购买：** 推荐列表 → 勾选多个产品 → 跳转购物车

### 涉及页面/弹窗/抽屉

| 类型 | 名称 | 说明 |
|------|------|------|
| 页面 | 资产配置页面 | 承载六大模块的主页面 |
| 弹窗 | 下载格式选择弹窗 | 选择 PDF 或 PNG 格式 |
| 弹窗 | 确认下载弹窗 | 确认下载范围和数据快照信息 |
| 页面 | 产品详情页 | 外部页面，跳转展示 |
| 页面 | 购买页 / 购物车 | 外部页面，跳转展示 |

### 关键分支点

- 账号选择变更 → 所有模块联动刷新
- 时间区间变更 → 持仓表现模块刷新
- 诊断无问题 → 诊断模块不展示
- 推荐产品为空 → 推荐模块展示空状态
- 下载格式选择 → 区分 PDF/PNG 处理

## §3 主交互流程

### 节点 1：进入资产配置页面

- **用户动作：** 点击"资产配置"菜单项，或从持仓列表点击"资产配置"入口
- **系统反馈：** 页面加载，顶部账号选择器默认选中"全部"（菜单入口）或当前账号（持仓列表入口），各模块展示加载态
- **需要前置解释的信息：** 从持仓列表进入时，页面自动切换到对应账号，用户可直接看到该账号的配置数据
- **建议文案：** 页面标题"资产配置建议书"
- **下一步：** 用户选择账号或直接浏览

### 节点 2：选择/切换银行账号

- **用户动作：** 从账号下拉列表中选择账号（默认"全部"或继承过来的账号）
- **系统反馈：** 所有模块显示加载态 → 数据加载完成后各模块刷新为对应账号的数据
- **需要前置解释的信息：** 选"全部"时展示的是所有账号的综合概况（待确认具体含义）
- **建议文案：** 下拉选项按账号名称 + 账号尾号展示，如"{企业名称}—****1234"
- **下一步：** 用户浏览各模块数据

### 节点 3：浏览摘要区（顶部指标卡）

- **用户动作：** 浏览顶部摘要卡片 —— 时点资产 + 核心指标
- **系统反馈：** 展示当前账号的时点资产总额（自动换算单位），以及区间收益、年化收益率、持仓产品数等关键指标
- **需要前置解释的信息：** 摘要卡的数字是"一眼结论"，详细数据在下方的分段区块中
- **建议文案：** 时点资产展示"总资产 1,234.56 万元"，下方用小字标注取值时间点
- **下一步：** 用户向下滚动查看详情

### 节点 4：查看持仓表现

- **用户动作：** 滚动到持仓表现区块
- **系统反馈：** 展示时间区间筛选器 + 持仓金额、较期初、区间收益、年化收益率、购买/赎回笔数和金额、持仓变动趋势图、收益金额趋势图、产品收益排行
- **需要前置解释的信息：** 时间区间默认为近一个月，支持近两年数据范围自行定义；持仓表现仅支持理财业务
- **建议文案：** 时间区间筛选器用日期选择器实现，预置"近1月""近3月""近6月""近1年"快捷选项 + 自定义范围
- **下一步：** 用户可切换时间区间或继续下滚

**分支：** 用户切换时间区间
- 持仓表现区块单独刷新，展示加载态 → 更新数据
- 其他模块不受影响

### 节点 5：查看投资分布

- **用户动作：** 滚动到投资分布区块
- **系统反馈：** 默认展示理财投资的分布（按产品特点汇总持仓金额、占比、年化收益率及排名），Tab 切换可查看其他业务（公募基金、资管计划、信托计划按类型汇总的金额和占比）
- **需要前置解释的信息：** 标注"仅展示理财年化收益率及排名，其他业务按类型汇总金额和占比"
- **建议文案：** 区块标题"投资分布"，Tab 标签"理财"和"其他业务"
- **下一步：** 用户可切换 Tab 或继续下滚

### 节点 6：查看期限分布

- **用户动作：** 滚动到期限分布区块
- **系统反馈：** 默认展示理财产品的期限分布（按产品期限汇总持仓金额、占比及年化收益率），Tab 切换可查看其他业务的持有期分布
- **需要前置解释的信息：** 标注"仅展示理财年化收益率，其他业务按持有期汇总金额和占比"
- **建议文案：** 区块标题"期限分布"
- **下一步：** 用户继续下滚到诊断区块

### 节点 7：阅读持仓诊断

- **用户动作：** 滚动到持仓诊断区块
- **系统反馈：** 如存在诊断问题，展示诊断条目列表（集中度/到期/持仓时间过长），无问题则不展示该区块
- **需要前置解释的信息：** 持仓诊断仅支持理财业务，诊断结果帮助用户发现配置问题
- **建议文案：** 区块标题"持仓诊断"，每个诊断条目标注类型和严重程度
- **下一步：** 用户点击诊断条目查看详情，或继续下滚到推荐

**诊断配合推荐的设计：**
- 诊断区块底部或旁边设置关联引导文案，如"基于以上诊断，建议关注以下产品"
- 推荐区块应定位在诊断区块正下方，减少滚动距离

### 节点 8：查看产品推荐

- **用户动作：** 滚动到产品推荐区块
- **系统反馈：** 展示建议持有类型、产品列表（名称、代码、交易时间、期限、收益率、近一月最大回撤、推荐理由），每个产品附带购买按钮
- **需要前置解释的信息：** 产品推荐仅支持理财；推荐数据基于企业财富+资产配置的规则推荐
- **建议文案：** 区块标题"产品推荐"，推荐区域顶部加一行"基于您的持仓情况推荐以下产品"
- **下一步：** 用户点击购买、查看详情或下载建议书

### 节点 9：执行下载

- **用户动作：** 点击页面右下角悬浮下载按钮
- **系统反馈：** 弹出下载格式选择弹窗（PDF / PNG），用户选择后触发下载
- **需要前置解释的信息：** 下载内容为全部模块当前数据的静态快照
- **建议文案：** 按钮"下载建议书"
- **下一步：** 下载完成后用户可直接打开文件

## §4 次交互流程

### 次流程 A：下载建议书

- **触发条件：** 用户点击右下角悬浮下载按钮
- **用户动作：** 点击下载按钮 → 在弹窗中选择格式（PDF / PNG）→ 确认下载
- **系统反馈：** 弹窗展示 → 用户选择格式 → 文件生成中加载态 → 下载完成或失败提示
- **需要前置解释的信息：** 需要前置确认下载快照范围（待确认：按当前筛选条件还是全量数据？当前暂按当前账号 + 当前时间区间推进）
- **建议文案：**
  - 弹窗标题：下载建议书
  - 格式选择："PDF（适合打印分享）" / "PNG（适合图片查看）"
  - 范围提示："将下载当前账号下所有模块内容"
  - 确认按钮："开始下载"
- **下一步：** 下载成功后打开文件，失败则展示失败原因可重试

### 次流程 B：查看诊断详情

- **触发条件：** 诊断区块存在可点击的诊断条目
- **用户动作：** 点击诊断条目（如"活钱管理持仓占比过高"）
- **系统反馈：** 在当前页面展开详情区域或打开侧栏，展示问题产品列表
  - 集中度详情：活钱管理产品列表（名称、持仓金额、占比）
  - 到期详情：到期产品列表（产品名称/代码、持仓金额、持仓收益、最新净值及日期、产品到期日）
  - 持仓时间过长详情：超期产品列表（产品名称/代码、持仓金额、持仓收益、最新净值及日期、持仓时长）
- **需要前置解释的信息：** 无
- **建议文案：** 详情标题对应诊断条目名称，"共{X}只产品"
- **下一步：** 用户查看后关闭详情返回诊断区块

### 次流程 C：查看产品详情

- **触发条件：** 用户在推荐列表中点击产品名称或代码
- **用户动作：** 点击产品名称链接
- **系统反馈：** 跳转至产品详情页（外部页面）
- **需要前置解释的信息：** 跳转后将离开资产配置页面，可通过浏览器返回按钮回到当前页
- **建议文案：** 产品名称使用链接样式，标注跳转图标
- **下一步：** 用户在详情页查看产品信息，返回后继续浏览推荐列表

### 次流程 D：单个购买

- **触发条件：** 用户点击推荐产品后的"购买"按钮
- **用户动作：** 点击购买按钮
- **系统反馈：** 直接跳转至该产品的购买页面（外部页面）
- **需要前置解释的信息：** 无（购买页面为已有流程）
- **下一步：** 用户在购买页完成交易

### 次流程 E：批量购买

- **触发条件：** 用户需要购买多个推荐产品
- **用户动作：** 勾选多个推荐产品前的复选框 → 点击"加入购物车"或"批量购买"按钮
- **系统反馈：** 跳转至购物车页面（外部页面）
- **需要前置解释的信息：** 无（购物车为已有流程）
- **建议文案：** 底部固定栏展示已选数量，按钮"加入购物车（{N}件）"
- **下一步：** 用户在购物车完成结算

## §5 异常与阻断流程

### 异常 1：页面整体数据加载失败

- **发生时机：** 用户进入资产配置页面时
- **触发条件：** 企业财富+接口超时或返回错误导致无法获取数据
- **判断依据：** 接口响应超过 5 秒或返回错误码
- **反馈形式：** 全页空状态
- **系统反馈：** 尝试自动重试 3 次（每次间隔 1 秒），全部失败后展示全页空状态
- **用户下一步：** 点击"重新加载"按钮重试
- **恢复路径：** 点击重新加载后回到初始加载流程，无信息丢失（尚未加载任何数据）

### 异常 2：某模块数据加载失败

- **发生时机：** 用户浏览资产配置页面时，某模块数据请求失败
- **触发条件：** 该模块接口超时或返回错误
- **判断依据：** 模块级接口响应异常
- **反馈形式：** 该模块展示"功能暂时不可用"提示，其他模块正常展示
- **系统反馈：** 仅失败模块展示错误状态，可用数据正常展示
- **用户下一步：** 无需要执行的操作，后台会自动恢复
- **恢复路径：** 后台数据恢复后，用户刷新页面或切换账号/时间区间即可重新加载，无信息丢失

### 异常 3：下载失败

- **发生时机：** 用户点击下载后文件生成或下载过程中
- **触发条件：** 文件生成失败、网络中断、存储空间不足、浏览器拦截
- **判断依据：** 各环节的错误类型
- **反馈形式：** Toast 提示 + 弹窗提示（存储空间不足时）
- **系统反馈：** 根据失败类型展示对应提示
- **用户下一步：** 按提示处理 —— 重试、清理空间、允许浏览器下载
- **恢复路径：** 用户解决障碍后重新点击下载按钮，需要重新选择格式和确认，原操作内容不变

### 异常 4：用户无可选账号

- **发生时机：** 用户进入资产配置页面时
- **触发条件：** 当前登录用户名下没有有权限的有效账号
- **判断依据：** 账号列表 API 返回空
- **反馈形式：** 全页空状态，账号选择器禁用
- **系统反馈：** 展示"暂无可用账号"提示
- **用户下一步：** 联系管理员或切换登录账号
- **恢复路径：** 获得权限后重新进入页面即可，无信息丢失

## §6 页面 / 弹窗 / 抽屉设计

### 页面 1：资产配置主页面

**页面目标：** 让企业客户一站式了解资产配置情况，发现优化机会并执行操作

**进入条件：**
- 入口 1（菜单）：用户点击财富专区 → "资产配置"菜单项 → 页面加载
- 入口 2（持仓列表）：用户在持仓列表点击"资产配置"入口 → 页面加载，自动选中当前账号

**页面结构：**

```
┌──────────────────────────────────────────────────────────┐
│  资产配置建议书                           [下载建议书]   │  ← 顶部标题栏 + 悬浮下载按钮
├──────────────────────────────────────────────────────────┤
│  银行账号: [{全部账号/具体账号}]  ▼                       │  ← 账号选择器
├──────────────────────────────────────────────────────────┤
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐                    │
│  │总资产 │ │区间  │ │年化  │ │持仓  │                    │  ← 摘要卡片区
│  │{金额} │ │收益  │ │收益率│ │产品数│                    │
│  │ 万元  │ │{金额}│ │{%}   │ │{N}只 │                    │
│  └──────┘ └──────┘ └──────┘ └──────┘                    │
├──────────────────────────────────────────────────────────┤
```

## §7 状态与反馈文案

### 统一状态口径表

| 状态 | 含义 | 适用对象 | 用户可操作 | 统一反馈口径 |
|------|------|----------|-----------|-------------|
| 页面加载中 | 页面数据正在请求 | 资产配置页面 | 无 | 骨架屏加载 |
| 模块加载中 | 某模块数据正在请求 | 持仓表现/投资分布/期限分布/诊断/推荐 | 无 | 模块内展示加载骨架 |
| 数据加载完成 | 数据就绪 | 所有模块 | 浏览操作 | 正常展示数据 |
| 数据刷新中 | 切换账号/时间区间后重新加载 | 全页/持仓表现模块 | 无 | 模块展示加载态 |
| 无持仓数据 | 账号下无持仓 | 资产配置页面 | 点击"去购买" | "暂无持仓数据" + "购买理财产品，开启投资之旅" + 【去购买】 |
| 模块无数据 | 该模块无可用数据 | 投资分布/期限分布/走势图等 | 无 | 图标 + "暂无{模块名}数据" |
| 无诊断问题 | 诊断无异常 | 持仓诊断模块 | 无 | 不展示该模块 |
| 推荐为空 | 无符合条件的推荐产品 | 产品推荐模块 | 切换账号/补充持仓 | "暂无推荐产品" |
| 功能不可用 | 数据计算异常 | 出问题的模块 | 稍后重试 | "{模块名}暂时不可用" |
| 下载进行中 | 文件生成中 | 下载操作 | 等待 | "文件生成中，请稍候" |
| 下载完成 | 文件已下载 | 下载操作 | 打开文件 | "下载完成" |
| 下载失败 | 文件生成失败 | 下载操作 | 重试 | "文件生成失败，请稍后重试" |
| 网络中断 | 网络连接断开 | 下载操作 | 检查网络 | "网络异常，下载已中断" |
| 存储不足 | 设备空间不足 | 下载操作 | 清理空间 | "存储空间不足，请清理后重试" |
| 浏览器拦截 | 浏览器阻止下载 | 下载操作 | 允许下载 | "请允许浏览器下载文件" |

## §9 附录：设计指南消费说明

### 设计准则消费

| 准则 | 相关性 | 体验策略 | 落点章节 |
|------|--------|----------|---------|
| IA-02 分块（Chunking） | 高——六大模块同屏需要按语义分组 | 页面按"摘要→表现→分布→期限→诊断→推荐"的决策链顺序纵向分块 | §6 页面结构设计 |
| U-01 状态、进展与结果可见 | 高——多模块异步加载需要明确状态 | 模块级加载态 + 全页空状态区分处理；切换账号时明确展示刷新过程 | §7 状态口径表 |
| U-03 用户控制与自由 | 中——用户需要控制浏览节奏 | 模块采用垂直滚动而非强制分页，用户可自由选择浏览深度 | §3 主流程 |
| 异常修正可执行 | 中——下载失败等场景需要可操作的修复路径 | 下载失败按类型区分提示，提供可执行的重试/清理/允许操作 | §5 异常流程 |

### 业务知识消费

- **主域：** 财富管理 / 资产配置 —— 知识库无对应业务域
- **条件依赖域：** 无
- **已读 raw / 章节：** 设计准则（IA 系列、U 系列部分章节）、交互模式（容器与工作区、状态反馈与恢复的部分章节）
- **未扩读领域及业务理由：** 无需扩展，本次为信息展示类页面，不涉及审批、多角色协作等复杂工作流模式
- **体验策略与正文落点：** 页面按上下堆叠工作区模式组织，摘要卡片使用独立页面嵌入区块，投资/期限分布使用 Tab 切换——详见 §6

### 知识缺口

- 项目知识库不覆盖银行财富管理业务，无可用业务知识

### 上游承接追踪

| 上游判断 | 对体验意味着什么 | 体验设计决策 | 落点章节 |
|----------|---------------|-------------|---------|
| 六大模块同屏承载，信息密度高 | 用户可能迷失，需要浏览优先级引导 | 摘要卡片区 + 纵向分段，按决策链顺序排列 | §6 页面结构 |
| 账号"全部"选项语义未定 | 影响摘要卡展示方式 | 暂按汇总方案推进，标注待确认 | §6 摘要卡片 + §8 待确认 |
| 诊断和推荐应建立关联 | 用户需要感知推荐与诊断的关系 | 诊断区块底部增加"基于以上诊断"过渡文案，推荐区块紧接诊断下方 | §6 诊断+推荐区块 |
| 仅理财 vs 多业务范围不一致 | 用户可能困惑差异 | 投资分布/期限分布使用 Tab 分离理财和其他业务，标注差异说明 | §6 投资/期限分布区块 |
