# 体验蓝图：子管理员权限复制

---

## §0 本次关键设计判断

**判断：** 复制弹窗采用单页双区结构承接"复制什么"和"复制给谁"两个独立决策，结果反馈从一句 toast 升级为可核对的结果摘要。

**主要影响：** 弹窗内不设步骤条——两个决策区可自由切换，管理员可以先选人再回头调内容；结果摘要直接展示成功/失败/审批中三层结果，让 200 人的批量操作可追溯可核对。

**建议方案：** 复制弹窗顶部展示来源子管理员权限摘要（帮助确认复制内容）；中部分"复制信息"复选框区（默认全选）；下部"复制对象"人员选择区。确认后根据结果展示分层摘要——非互审模式直接展示成功/失败明细，互审模式额外标注审批中。

**不建议方案：** 步骤条式弹窗（两个决策没有强依赖，分步只会增加往返成本）；只靠 toast 收口（200 人操作不可核对，失去批量操作的体验底线）。

**关键待确认：** UXB §9 层级一的三个问题（权限扩散风险、"加入状态"口径、撤回能力）均基于推荐方案推进，其中权限扩散风险直接影响复制弹窗中是否展示来源权限摘要。

## §1 旅程图

### 角色：权限管理员

#### 阶段一：找到复制入口

- **用户目标：** 在子管理员列表中找到要复制的来源，快速发起复制操作
- **关键触点：** 子管理员列表页 → 目标行 → 操作列「复制」按钮
- **用户信心：** 中等。列表已经有编辑、删除等操作，复制作为新增项需要被快速识别
- **痛点：** 操作列项多时，新增的复制按钮可能被忽略；管理员需要确认"复制什么"才点下去

#### 阶段二：配置复制内容

- **用户目标：** 确认要复制哪些权限维度（组织/功能），并对来源权限有基本判断
- **关键触点：** 复制弹窗 → 复制信息区（两个复选框，默认全选）→ 来源权限摘要区
- **用户信心：** 较高。默认全选减少了决策，但需要确认来源权限当前状态
- **痛点：** 如果看不到来源子管理员当前到底有哪些权限，可能复制了错误的内容

> **关键转折：** 从"看列表点按钮"进入"弹窗内做决策"——弹窗的信息密度和分组决定了配置效率。

#### 阶段三：选择复制目标

- **用户目标：** 从组织人员中挑选本次复制的目标用户
- **关键触点：** 复制弹窗 → 复制对象区 → 人员选择器（复用现有组件）→ 已选列表
- **用户信心：** 中等。人员选择器是已有组件，但 200 人上限下需要批量筛选能力
- **痛点：** 大量用户时查找效率低；已选列表过长时难以核对

#### 阶段四：确认并提交

- **用户目标：** 确认复制内容和目标无误后提交，校验不通过时快速修正
- **关键触点：** 确认按钮 → 校验过程 → 校验失败提示 / 提交成功
- **用户信心：** 中低。担心复制错了没法撤回，尤其 200 人规模
- **痛点：** 确认弹窗如果只问"确定吗"而不展示影响范围，管理员在不确定后果下被迫确认

> **关键转折：** 从"配置"进入"执行"——这是不可逆的门槛，确认信息需要充分。

#### 阶段五：查看结果

- **用户目标：** 知道复制是否成功、哪些人有问题、后续怎么处理
- **关键触点：** 复制结果摘要 → toast → 操作记录
- **用户信心：** 高（如果结果可核对）/ 低（如果只有一句 toast）
- **痛点：** 只有 toast "复制成功"时，管理员无法确认 200 人是否全部成功；互审模式下不知道审批什么时候完成

## §2 交互流程总览

### 主交互流程（权限管理员）

**找到来源 → 配置复制 → 选择目标 → 确认校验 → 查看结果**

这条路径从子管理员列表的「复制」入口开始，到结果摘要展示结束。主路径中不改变子管理员权限模型，仅新增复制作为权限配置来源。

### 次交互流程

- **查看操作记录：** 管理员通过操作记录页面查看复制操作的审计留痕
- **跟踪审批进度：** 互审模式下，通过审批链路跟踪复制审批状态
- **重新提交（校验失败后）：** 校验失败后修正并再次提交

### 异常流程重点

- 校验阻断（复制信息为空 / 复制对象为空 / 加入状态不符 / 认证状态不符）
- 复制来源在执行时失效
- 互审审批被拒
- 人员选择器达到 200 人上限

## §3 主交互流程

### 节点 1：进入复制

- **用户动作：** 在子管理员列表页，找到目标来源行，点击操作列中的「复制」
- **系统反馈：** 打开复制弹窗，自动加载来源子管理员的当前权限配置
- **需要前置解释的信息：** 来源子管理员的姓名/手机号和当前权限摘要，帮助管理员确认"复制的是这个人、这些权限"
- **建议文案：**
  - 操作列按钮：`复制`
  - 弹窗标题：`复制子管理员权限`
- **下一步：** 节点 2

### 节点 2：确认复制内容

- **用户动作：** 查看来源权限摘要，确认或调整复制信息的勾选
- **系统反馈：**
  - 顶部展示来源子管理员信息（姓名/手机号）和当前权限摘要（可授权组织范围简述 + 可授权功能数量）
  - 复制信息区默认两项全选（可授权组织、可授权功能）
  - 取消勾选某项时，该项对应的权限不会被复制
- **需要前置解释的信息：** "复制的是这个子管理员当前的可授权范围，不是他本人的权限。复制后目标用户将获得相同的授权能力。"
- **建议文案：**
  - 来源信息区标题：`复制来源`
  - 复制信息区标题：`复制内容`
  - 复选框文案：`可授权组织` / `可授权功能`
  - 帮助提示：`至少选择一项`
- **下一步：** 节点 3

### 节点 3：选择复制目标

- **用户动作：** 点击人员选择器，搜索并选择目标用户
- **系统反馈：**
  - 打开人员选择弹窗（复用现有「选择员工」组件）
  - 已选用户展示在复制对象区，显示姓名和手机号
  - 支持移除单个已选用户
  - 达到 200 人上限时阻止继续添加
- **需要前置解释的信息：** "普通用户在复制后将成为子管理员；已有子管理员将在原有权限上叠加，不会覆盖现有配置。"
- **建议文案：**
  - 复制对象区标题：`复制对象`
  - 选择器入口：`选择员工`
  - 已选为空时：`暂未选择`
  - 上限提示：`最多选择 200 名员工`
- **下一步：** 节点 4

### 节点 4：确认并提交

- **用户动作：** 点击弹窗底部「确认」按钮
- **系统反馈：** 按序执行校验——
  - 校验 1（复制信息为空）：阻断，提示"请选择复制信息"
  - 校验 2（复制对象为空）：阻断，提示"请选择至少一名复制对象"
  - 校验 3（加入状态不符）：阻断，提示具体用户"加入状态不是已加入，不能成为子管理员"
  - 校验 4（认证状态不符）：阻断，提示具体用户"未完成实名认证，不能成为子管理员"
  - 全部通过：提交执行
- **需要前置解释的信息：** 校验失败时会列出所有不满足条件的用户，一次性展示，不需要分批修正
- **建议文案：**
  - 确认按钮：`确认复制`
  - 取消按钮：`取消`
  - 校验中 loading 文案：`正在校验...`
- **下一步：** 节点 5

### 节点 5：查看复制结果

- **用户动作：** 查看结果反馈
- **系统反馈（非互审模式——直接生效）：**
  - 关闭复制弹窗
  - 展示结果摘要：成功 N 人、失败 M 人（含失败原因）、共 K 人
  - 如果全部成功，toast "已成功复制给 N 名员工"
  - 如果部分失败，展示失败明细列表（用户 + 失败原因）
  - 同步生成操作记录
- **系统反馈（互审模式——审批生效）：**
  - 关闭复制弹窗
  - 展示提交结果：已提交审批，N 名员工待审批生效
  - toast "已提交复制审批，审批通过后生效"
  - 提供跳转审批链路的入口
- **需要前置解释的信息：** "在双管理员互审模式下，复制需要搭档审批后才生效。审批完成前，目标用户的权限不会改变。"
- **建议文案：**
  - 全部成功 toast：`已成功复制给 N 名员工`
  - 部分失败摘要标题：`部分复制失败`
  - 互审模式 toast：`已提交复制审批，审批通过后生效`
  - 查看审批链接：`查看审批进度`
  - 查看操作记录链接：`查看操作记录`
- **下一步：** 可关闭结果摘要，返回子管理员列表

## §4 次交互流程

### 次流程 1：查看操作记录

- **触发条件：** 复制成功或提交审批后，管理员点击「查看操作记录」
- **用户动作：** 跳转到操作记录页面
- **系统反馈：** 展示两条记录（如同时复制组织和功能）：
  - "复制-可授权组织：将子管理员【XXX】可授权组织复制给【目标列表】"
  - "复制-可授权功能：将子管理员【XXX】可授权功能复制给【目标列表】"
- **需要前置解释的信息：** 两条记录属于同一次复制操作，通过操作时间可以关联
- **建议文案：** 两条记录共用同一个操作时间戳，在列表中通过时间关联可识别为同次操作
- **下一步：** 返回子管理员列表

### 次流程 2：跟踪审批进度

- **触发条件：** 互审模式下提交复制后，管理员点击「查看审批进度」
- **用户动作：** 跳转到审批管理页面
- **系统反馈：** 展示该复制审批的当前状态（待审批/已通过/已拒绝）
- **建议文案：** 审批标题：`子管理员权限复制审批`
- **下一步：** 等待审批完成 / 审批通过后权限自动生效

### 次流程 3：校验失败后修正重提

- **触发条件：** 节点 4 校验不通过
- **用户动作：**
  - 查看校验失败的具体原因和涉及的用户
  - 如复制信息未选：勾选至少一项
  - 如复制对象为空：重新选择
  - 如加入/认证状态不符：移除不合格用户或等待用户完成加入/认证后再复制
- **系统反馈：** 校验失败信息在弹窗内直接展示（不关闭弹窗），列出所有不满足条件的具体用户
- **建议文案：**
  - 校验失败标题：`以下员工不满足条件`
  - 单条失败格式：`XXX（手机号）— 未完成实名认证`
- **下一步：** 修正后重新点击确认

## §5 异常与阻断流程

### 异常 1：复制信息未选择

- **发生时机：** 节点 4 点击确认时
- **触发条件：** 两项复制信息均未勾选
- **判断依据：** 校验规则第 1 条
- **反馈形式：** 弹窗内阻断，确认按钮可点击但触发校验提示
- **系统反馈：** 在复制信息区下方显示红色提示
- **用户下一步：** 勾选至少一项复制信息后重新点击确认

### 异常 2：复制对象未选择

- **发生时机：** 节点 4 点击确认时
- **触发条件：** 复制对象列表为空
- **判断依据：** 校验规则第 2 条
- **反馈形式：** 弹窗内阻断
- **系统反馈：** 在复制对象区下方显示红色提示
- **用户下一步：** 点击人员选择器添加至少一名目标后重新点击确认

### 异常 3：目标用户加入状态不符

- **发生时机：** 节点 4 点击确认时
- **触发条件：** 已选用户中存在加入状态不是"已加入"（或"已启用"，待产品统一口径）的用户
- **判断依据：** 校验规则第 3 条
- **反馈形式：** 弹窗内阻断，不关闭弹窗
- **系统反馈：** 红色提示列出所有不符合条件的用户，格式为"XXX、XXX 加入状态不是已加入，不能成为子管理员"
- **用户下一步：** 手动移除不符合条件的用户后重新提交，或等待这些用户完成加入流程后再复制

### 异常 4：目标用户认证状态不符

- **发生时机：** 节点 4 点击确认时
- **触发条件：** 已选用户中存在未完成实名认证的用户
- **判断依据：** 校验规则第 4 条
- **反馈形式：** 弹窗内阻断，不关闭弹窗
- **系统反馈：** 红色提示列出所有不符合条件的用户，格式为"XXX、XXX 未完成实名认证，不能成为子管理员"
- **用户下一步：** 手动移除不符合条件的用户后重新提交

### 异常 5：复制来源在执行时失效

- **发生时机：** 点击确认后，系统执行复制时
- **触发条件：** 来源子管理员在弹窗打开期间被其他管理员删除或禁用
- **判断依据：** 需后端在执行时做最终校验（方案推荐：阻断并提示，而非以最后有效配置为准——避免管理员在不知情的情况下复制了"已失效"的权限）
- **反馈形式：** toast + 弹窗不关闭
- **系统反馈：** "复制来源【XXX】的权限配置已失效，请关闭弹窗后重新选择来源"
- **用户下一步：** 关闭弹窗，回到列表重新选择来源子管理员

### 异常 6：人员选择器达到上限

- **发生时机：** 节点 3 选择目标时
- **触发条件：** 已选用户达到 200 人
- **判断依据：** 业务规则上限
- **反馈形式：** 选择器内阻止继续添加 + toast
- **系统反馈：** "最多选择 200 名员工"
- **用户下一步：** 移除部分已选用户后继续添加，或分批次复制

### 异常 7：互审审批被拒

- **发生时机：** 复制已提交审批后
- **触发条件：** 互审搭档拒绝了该复制审批
- **判断依据：** 审批流程结束，结果为拒绝
- **反馈形式：** 审批通知（站内消息/审批列表状态更新）+ [GAP] 是否主动通知发起人待产品确认
- **系统反馈：** 审批状态变为"已拒绝"，复制未生效，目标用户权限不变
- **用户下一步：** 查看拒绝原因，决定是否重新发起复制或联系审批人沟通

## §6 页面 / 弹窗 / 抽屉设计

### P1：子管理员列表页——复制入口

- **页面目标：** 在现有子管理员列表中新增复制操作入口
- **进入条件：** 用户为超级管理员或具有子管理员管理权限的权限管理员
- **页面结构（仅涉及变更部分）：**

```
操作列（每行）：
┌─────────────────────────────────────┐
│ [复制] [编辑] [删除] [更多...]       │
└─────────────────────────────────────┘
```

- **按钮：** 「复制」位于操作列最左侧，与其他操作等距排列
- **成功反馈：** 点击后立即打开复制弹窗（P2）
- **失败反馈：** 如来源子管理员数据加载失败，toast 提示"加载失败，请稍后重试"

### P2：复制弹窗

- **弹窗目标：** 在一个弹窗内完成复制内容选择和复制对象选择，提交后执行复制
- **触发条件：** 点击子管理员列表中某行的「复制」
- **弹窗结构：**

```
┌──────────────────────────────────────────┐
│  复制子管理员权限                     [X] │
│──────────────────────────────────────────│
│                                          │
│  ▸ 复制来源                             │
│  ┌──────────────────────────────────┐   │
│  │ 张建国  138****5678              │   │
│  │ 可授权组织：华东区（3个部门）     │   │
│  │ 可授权功能：12项                 │   │
│  └──────────────────────────────────┘   │
│                                          │
│  ▸ 复制内容                             │
│  ┌──────────────────────────────────┐   │
│  │ ☑ 可授权组织                     │   │
│  │ ☑ 可授权功能                     │   │
│  │ 至少选择一项                      │   │
│  └──────────────────────────────────┘   │
│                                          │
│  ▸ 复制对象                     已选 5人 │
│  ┌──────────────────────────────────┐   │

│  │                                  │   │

│                                          │
│──────────────────────────────────────────│
│                    [取消]    [确认复制]   │
└──────────────────────────────────────────┘
```

- **具体文案：**
  - 弹窗标题：`复制子管理员权限`
  - 来源摘要区标签：`复制来源`
  - 复制内容区标签：`复制内容`
  - 复选框：`可授权组织` / `可授权功能`
  - 帮助提示：`至少选择一项`
  - 复制对象区标签：`复制对象`
  - 选择器按钮：`选择员工`
  - 上限提示：`最多选择 200 名员工`
  - 底部提示：`已有子管理员的权限将叠加，不覆盖原有配置`
  - 确认按钮：`确认复制`
  - 取消按钮：`取消`
- **按钮：** 「确认复制」（主按钮，蓝色）/ 「取消」（次按钮，灰色）
- **成功反馈：** 关闭弹窗 → 展示结果摘要（P3）
- **失败反馈（校验失败）：** 弹窗不关闭，对应区域显示红色错误提示

**异常状态下的结构变化：**

- **校验失败时：** 错误信息直接显示在对应区域（复制信息区下方或复制对象区下方），不额外弹出 toast
- **来源加载失败时：** 弹窗内展示"加载来源信息失败"，确认按钮置灰

### P3：复制结果摘要

- **页面目标：** 让管理员清晰看到本次复制的执行结果
- **触发条件：** 复制执行完成（非互审模式直接生效 / 互审模式提交审批后）
- **展示形式：** 以 toast + 可展开的结果区域呈现。推荐使用全局结果提示区（页面顶部横幅）而非模态弹窗，避免打断管理员继续操作。

- **全部校验前置失败：** 不进入结果摘要，验证失败直接在复制弹窗内提示
- **执行中全部失败（极端情况）：** 展示"复制未成功"及全部失败原因列表
