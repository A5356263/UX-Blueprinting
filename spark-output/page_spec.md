# 页面生成规格：财富小助 Skill 管理

## 1. 页面摘要

- **产品领域**：企业财富+ — 智能化配置 / 财富小助
- **页面类型**：列表页（Skill 广场）、详情页（Skill 详情）、编辑页（Skill 编辑）、弹窗（创建方式选择、取消订阅确认、删除确认）

## 4. Skill 广场页面

### 页面目标

让用户浏览、搜索、筛选和订阅可用的 Skill，并管理自己发布的 Skill。面向两类角色：客户经理（发现可用 Skill）、产品经理（管理已发布 Skill）。

### 页面结构

```
┌─────────────────────────────────────────────────────┐
│  企业财富·Skill广场                      [发布技能] │
├─────────────────────────────────────────────────────┤
│  [搜索框...                          🔍]            │
│  Select:所属分行  Select:订阅状态  Select:排序方式  │
├─────────────────────────────────────────────────────┤
│  Tab:Skill共享广场  │  Tab:我发布的Skill             │
├─────────────────────────────────────────────────────┤
│  ┌──────────────┐  ┌──────────────┐                  │
│  │ Text:名称     │  │ Text:名称     │                  │
│  │ Tag:场景标签  │  │ Tag:场景标签  │                  │
│  │ Text:简述...  │  │ Text:简述...  │                  │
│  │ ────────     │  │ ────────     │                  │
│  │ Text:订阅{N}家│  │ Text:订阅{N}家│                  │
│  │ Text:发布者·{分行}│ Text:发布者·{分行}│            │
│  │ Text:更新时间  │  │ Text:更新时间  │                  │
│  │ Switch:已订阅 │  │ Switch:订阅   │                  │
│  └──────────────┘  └──────────────┘                  │
│  ┌──────────────┐  ┌──────────────┐                  │
│  │ ...          │  │ ...          │                  │
│  └──────────────┘  └──────────────┘                  │
└─────────────────────────────────────────────────────┘
```

### 区域说明

- **标题区**：页面标题「企业财富·Skill广场」+ Button「发布技能」
- **搜索筛选区**：Input（搜索框）+ Select（所属分行）+ Select（订阅状态）+ Select（排序方式：订阅量/最新发布/最近更新）
- **Tab 区**：两个 Tab——「Skill 共享广场」、「我发布的 Skill」
- **列表区（共享广场 Tab）**：卡片列表，每张卡片包含：名称(Text)、场景标签(Tag)、描述(Text)、订阅数(Text)、发布者(Text)、更新时间(Text)、订阅开关(Switch)
- **列表区（我发布的 Tab）**：列表视图，行内增加操作列（Button:编辑、Button:删除）、共享状态标签(Tag)

### Tab 差异

| 维度 | Skill 共享广场 | 我发布的 Skill |
|------|---------------|---------------|
| 展示内容 | 全行可用的 Skill | 所属分行创建的所有 Skill |
| 展示形式 | 卡片列表 | 列表视图 |
| 筛选项 | 所属分行、订阅状态、排序方式 | 共享状态、排序方式 |
| 操作 | 订阅开关、点击进详情 | 编辑/删除按钮、共享状态开关、点击进详情 |
| 定位 | 内容发现 | 内容管理 |

### 校验规则

| 场景 | 校验内容 | 阻断条件 | 失败反馈 |
|------|---------|---------|---------|
| 订阅操作 | 网络连接 | 网络异常 | Toast「操作失败，请重试」 |
| 取消订阅 | 用户确认 | 用户选择「再想想」 | 弹窗关闭，保持已订阅状态 |

### 状态表现

| 状态 | 触发条件 | UI 表现 | 文案 |
|------|---------|---------|------|
| 未订阅 | 分行未订阅此 Skill | Switch 灰色「订阅」 | — |
| 已订阅 | 分行已订阅此 Skill | Switch 红色「已订阅」 | — |
| 列表加载中 | 首次进入页面 | LoadingState 骨架屏 | — |
| 列表为空 | 无可用 Skill | EmptyState | 「暂无可用 Skill」 |
| 网络异常 | 操作时网络断开 | Toast | 「操作失败，请重试」 |
| 我发布的-已共享 | Skill 已共享给全行 | Tag：「已共享」(绿色) | — |
| 我发布的-未共享 | Skill 仅本分行可见 | Tag：「未共享」(灰色) | — |

### 关键操作

| 操作 | 触发方式 | 结果 |
|------|---------|------|
| 发布技能 | 点击右上角 Button | 弹出创建方式选择弹窗 |
| 订阅 Skill | 点击 Switch（灰色） | Toast 提示成功后 Switch 变红色 |
| 取消订阅 | 点击 Switch（红色） | 弹出取消订阅确认弹窗 |
| 查看详情 | 点击卡片 | 跳转至 Skill 详情页 |
| 搜索 | 输入关键字回车 | 列表实时刷新匹配结果 |
| 筛选 | 选择筛选条件 | 列表按条件刷新 |
| 排序 | 选择排序方式 | 列表重新排序 |

## 6. Skill 编辑页面

### 页面目标

让产品经理填写或修改 Skill 的全部内容（名称、描述、提示词、共享设置）。

### 进入条件

新建 Skill（选择创建方式后）或编辑已有 Skill（从详情页进入）。

### 页面结构

```
┌─────────────────────────────────────────────────────┐
│  Link:← 返回 Skill 广场          Button:保存 取消   │
├─────────────────────────────────────────────────────┤
│  Label:Skill名称 *                                   │
│  Input:{名称输入，最长50字符}          Text:{12}/50  │
│                                                     │
│  Label:Skill描述 *                                   │
│  Input:{描述输入，最长200字符}        Text:{45}/200  │
│                                                     │
│  Label:提示词内容 *                                  │
│  Textarea:{Markdown 文本域，最长10000字符}            │
│  {可折叠模板章节 — 仅在新建时预载}                   │
│                                                     │
│  Label:共享设置                                      │
│  Switch:共享给全行用户              （默认按角色）   │
└─────────────────────────────────────────────────────┘
```

### 区域说明

- **顶栏区**：返回链接 +「保存」Button +「取消」Button
- **名称区**：Label + Input（必填，最长50字符）+ 字数计数器
- **描述区**：Label + Input（必填，最长200字符）+ 字数计数器
- **提示词区**：Label + Textarea（必填，支持 Markdown，最长10000字符）
- **共享设置区**：Label + Switch（总行用户默认开启，分行用户默认关闭）

### 新建场景额外说明

- 提示词文本域预载编写模板（功能简述、意图识别规则、输入验证规则、业务处理流程、输出内容格式化、异常处理）
- 模板各章节可折叠（Collapse），默认展开核心章节，高级章节折叠

### 校验规则

| 场景 | 校验内容 | 阻断条件 | 失败反馈 |
|------|---------|---------|---------|
| 保存 | Skill 名称非空且≤50字符 | 为空或超限 | [保存] 置灰；字段下方 InlineError |
| 保存 | Skill 描述非空且≤200字符 | 为空或超限 | [保存] 置灰；字段下方 InlineError |
| 保存 | 提示词内容非空且≤10000字符 | 为空或超限 | [保存] 置灰；字段下方 InlineError |
| 上传文件（新建时） | 文件格式 | 非 .md | 上传区 InlineError「仅支持 .md 格式」 |
| 上传文件（新建时） | 文件大小 | > 1MB | 上传区 InlineError「文件大小不能超过 1MB」 |
| 上传文件（新建时） | 文件编码 | 非 UTF-8 | 上传区 InlineError「文件编码需为 UTF-8」 |

### 状态表现

| 状态 | 触发条件 | UI 表现 | 文案 |
|------|---------|---------|------|
| 新建模式 | 首次创建 | 提示词区预载模板 | — |
| 编辑模式 | 修改已有 Skill | 提示词区载入当前内容 | — |
| 字数接近上限 | 字数 > 80% | 计数器变为橙色 | — |
| 字数超限 | 字数 > 100% | InlineError + 保存置灰 | 「内容超长，请精简」 |

### 关键操作

| 操作 | 触发方式 | 结果 |
|------|---------|------|
| 保存 | 点击「保存」Button | 校验通过 → Toast → 提交审核 → 跳转至详情页 |
| 取消 | 点击「取消」Button | 返回 Skill 广场，不保留内容 |
| 返回 | 点击返回链接 | 返回 Skill 广场 |

## 8. 智能联想下拉列表

### 组件目标

让客户经理在财富小助中快速找到并调用目标 Skill。

### 触发条件

在财富小助输入框中输入「/」，且光标在输入框开头或紧接在空格后。

### 结构

```
┌─────────────────────────────────────┐
│  Input:/客 {光标}                     │
├─────────────────────────────────────┤
│  ┌─────────────────────────────┐    │
│  │ Text:客户画像查询             │    │
│  │ Text:快速查询基本信息与持仓   │    │
│  ├─────────────────────────────┤    │
│  │ Text:客户风险评测             │    │
│  │ Text:评估客户风险承受能力     │    │
│  ├─────────────────────────────┤    │
│  │ Text:理财产品推荐分析         │    │
│  │ Text:根据客户偏好推荐产品     │    │
│  └─────────────────────────────┘    │
│  HINT:（最多展示 10 条）             │
└─────────────────────────────────────┘
```

### 区域说明

- **输入区**：Input（财富小助输入框），当前输入内容保留在框中
- **列表区**：Dropdown list，每项两行——Skill 名称(Text) + 简短描述(Text)；名称中匹配「/」后关键字高亮
- **空状态**：列表为空时展示「暂无可用 Skill，请联系分行产品经理订阅」

### 交互规则

- 关键字高亮：列表中「/」后的输入内容在 Skill 名称中匹配并高亮
- 键盘操作：↑↓ 移动选项高亮，Enter 确认选择，Esc 关闭列表
- 选中后：输入框自动填充「/Skill名称」，用户可以继续编辑后发送
- 发送后系统跳过意图识别直接执行 Skill 调用
- 排序规则：个人常用 Skill → 本分行热门 Skill（按订阅量降序）→ 其余可用 Skill，最多 10 条

### 状态表现

| 状态 | 触发条件 | UI 表现 | 文案 |
|------|---------|---------|------|
| 列表弹出 | 输入「/」有可用 Skill | 显示下拉列表 | — |

## 12. 主交互流程

### 12.1 创建 Skill（新建 → 提交审核）

1. Skill 广场 → 点击「发布技能」→ 弹出创建方式选择弹窗
2. 选择「手动创建」→ 进入 Skill 编辑页，提示词区预载模板
3. 选择「上传文件」→ 选择 .md 文件 → 自动解析填充 → 进入编辑页
4. 填写/调整名称、描述、提示词、共享开关
5. 点击「保存」→ 前端校验（必填/字数）→ 校验通过

   **分支：**
   - 必填字段为空 → [保存] 置灰 + 字段下方 InlineError
   - 字数超限 → InlineError「内容超长，请精简」

6. 提交成功 → Toast「创建成功，正在提交审核」→ 跳转至 Skill 详情页
7. 详情页展示审核进度（待检测→检测中→已完成）

### 12.2 编辑 Skill（修改 → 重新审核）

1. Skill 详情页 → 点击「编辑」→ 进入编辑页，载入当前内容
2. 修改名称/描述/提示词
3. 点击「保存」→ 前端校验 → 提交成功
4. Toast「更新成功，正在提交审核」→ 回到详情页，展示审核进度
5. 审核期间旧版本继续可用
6. 审核通过后新版本自动生效

### 12.3 订阅/取消订阅

**订阅：**
1. Skill 广场 → 点击灰色「订阅」Switch
2. Toast「已订阅，本分行所有用户均可用」
3. Switch 变红色「已订阅」，订阅数 +1

**取消订阅：**
1. Skill 广场 → 点击红色「已订阅」Switch
2. 弹出取消订阅确认弹窗（含影响范围说明）
3. 点击「确认取消」→ Toast「已取消订阅」→ Switch 变灰色，订阅数 -1
4. 点击「再想想」→ 弹窗关闭，保持已订阅

### 12.4 删除 Skill

1. Skill 详情页 → 点击「删除」
2. 弹出删除确认弹窗
3. **有订阅场景**：弹窗追加「该 Skill 已被 {N} 家分行订阅」说明
4. 点击「确认删除」→ Toast「删除成功」→ 从广场移除，所有订阅解除
5. 点击「取消」→ 弹窗关闭

### 12.5 智能联想调用

1. 财富小助输入框 → 输入「/」
2. 弹出联想下拉列表（最多 10 条，按个人常用→热门排序）
3. 继续输入关键字 → 列表实时过滤匹配并高亮

   **分支：**
   - 无可用 Skill → 列表为空状态

4. ↑↓ 选择 → Enter 确认 → 输入框自动填充「/Skill名称」
5. 发送消息 → 系统跳过意图识别 → 加载提示词 → 执行 AI 交互
6. 展示 AI 结果

## 13. 校验规则汇总

| 触发时机 | 所属实体 | 校验内容 | 阻断条件 | 失败反馈 |
|---------|---------|---------|---------|---------|
| 保存 Skill（编辑页） | 编辑页 | Skill 名称非空且 ≤50字符 | 为空或超限 | [保存] 置灰 + InlineError |
| 保存 Skill（编辑页） | 编辑页 | Skill 描述非空且 ≤200字符 | 为空或超限 | [保存] 置灰 + InlineError |
| 保存 Skill（编辑页） | 编辑页 | 提示词内容非空且 ≤10000字符 | 为空或超限 | [保存] 置灰 + InlineError |
| 上传文件（创建时） | 编辑页（上传路径） | 文件格式 .md | 非 .md | InlineError「仅支持 .md 格式」 |
| 上传文件（创建时） | 编辑页（上传路径） | 文件大小 ≤1MB | > 1MB | InlineError「文件大小不能超过 1MB」 |
| 上传文件（创建时） | 编辑页（上传路径） | 文件编码 UTF-8 | 非 UTF-8 | InlineError「文件编码需为 UTF-8」 |
| 订阅操作 | 广场页 | 网络连接 | 网络异常 | Toast「操作失败，请重试」 |
| 取消订阅 | 广场页 | 用户确认 | 用户取消 | 弹窗关闭 |
| 删除操作 | 详情页 | 用户确认 | 用户取消 | 弹窗关闭 |

## 14. 异常恢复

| 异常场景 | 发生实体 | 触发条件 | 反馈形式 | 用户下一步 | 恢复路径 |
|---------|---------|---------|---------|-----------|---------|

| Skill 执行异常 | 财富小助 | 超时/内容异常 | Inline 提示 | 重试/切换 Skill | 输入保留，可继续对话 |
| 删除已订阅 Skill | 详情页 | 订阅数 > 0 | 确认弹窗(追加说明) | 确认或取消 | 删除不可逆，需重新创建 |
