# 页面生成规格：企业数字化产品员工权限自助申请

---

## 1. 页面摘要

- **产品领域**：企业数字化产品 — 权限管理
- **页面类型**：页面（权限中心首页/我的申请列表/我的权限页）、Drawer（权限申请）、嵌入式组件（无权限拦截提示条）
- **用户角色**：员工
- **核心任务**：员工自助查看已有权限、申请权限、追踪申请进度

---

## 2. 生成范围

### 生成

| 实体 | 类型 | 来源 |
|---|---|---|
| P3 权限中心首页 | Page | 体验蓝图 §6 P3 |
| P4 我的申请列表 | Page | 体验蓝图 §6 P4 |
| P5 我的权限页 | Page | 体验蓝图 §6 P5 |
| P2 权限申请 Drawer | Drawer | 体验蓝图 §6 P2 |
| P1 无权限拦截页 | 嵌入式提示条 | 体验蓝图 §6 P1 |

### 只引用不生成

| 实体 | 类型 | 原因 |
|---|---|---|
| OA 审批详情页 | Page | 由 OA 底座系统承载，本模块仅引用审批待办和结果回调 |
| 管理员可申请范围配置页 | Page | 属于管理员后台配置，不在本次员工侧页面生成范围 |

### 不生成

| 实体 | 类型 | 原因 |
|---|---|---|
| 功能操作页面 | Page | 属于已有系统能力，不在本次设计范围 |

## 3. 页面实体关系

```
权限中心首页 (P3)                功能操作页面（已有系统）
    ├── Tab: 我的权限 (P5)               │
    ├── Tab: 我的申请 (P4)         无权限拦截页 (P1)
    └── 入口: 申请权限                    │
            │                            └── 触发 →
            └── 打开 权限申请 Drawer (P2) ←──────────┘
                     │
                     └── 提交 → OA 审批详情页（引用，不生成）
```

## 4. 权限中心首页 (P3)

### 页面目标

作为员工侧权限操作的统一入口，聚合已有权限查看、申请权限、追踪申请进度三个核心能力。

### 进入条件

- 员工从工作台或全局导航进入

### 页面结构

```
┌─────────────────────────────────────────────────────┐
│  权限中心                                    用户头像 │
├─────────────────────────────────────────────────────┤
│                                                     │
│  ┌──────────────┐  ┌──────────────┐  ┌────────────┐ │
│  │  我的权限      │  │  我的申请     │  │  申请权限   │ │
│  │  {已有N项}    │  │  {N项处理中}  │  │   +        │ │
│  └──────────────┘  └──────────────┘  └────────────┘ │
│                                                     │
│  ── 快速操作 ──                                      │
│                                                     │
│  [ 搜索你想申请的权限或角色...           🔍 ]         │
│                                                     │
│  按角色探索：                                        │
│  [{角色A}] [{角色B}] [{角色C}]  查看更多 →            │
│                                                     │
│  ── 最近申请 ──                                      │
│  {权限名}  ·  [ 审批中 ]  ·  {处理时间}               │
│  {权限名}  ·  [ 已生效 ]  ·  {处理时间}               │
│  查看全部 →                                          │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 区域说明

- **页面标题区**
  - Text：权限中心
  - 用户头像（右上角）
- **快捷入口区**
  - Card（我的权限）：点击进入 P5
    - StatText：{已有N项}
  - Card（我的申请）：点击进入 P4
    - StatText：{N项处理中}
  - Card（申请权限）：点击打开 P2
    - Icon：+
- **快速操作区**
  - Input（搜索框）：搜索权限名称或角色名 → 跳转到 P2 并带搜索关键词
    - Placeholder：搜索你想申请的权限或角色...
- **角色探索区**
  - TagGroup：角色标签列表 [{角色A}] [{角色B}] [{角色C}]
  - Link（查看更多）：展开全部角色
    - 交互：点击任一角色标签 → 打开 P2 并筛选该角色包含的权限
- **最近申请区**
  - List：最近 {N} 条申请记录
    - 每条：{权限名} · Tag（状态）· Text（处理时间）
  - Link（查看全部）：跳转到 P4

### 提取备注

- 承载页面为本次新增页面，知识库中不存在对应的载体语义文件，结构来自体验蓝图 §6 P3
- 统计数字（{已有N项}/{N项处理中}）需从后端实时获取

### 关键操作

| 操作 | 触发 | 反馈 |
|---|---|---|
| 点击我的权限 | 跳转到 P5 | 页面切换 |
| 点击我的申请 | 跳转到 P4 | 页面切换 |
| 点击申请权限 | 打开 P2 | Drawer 展开 |
| 搜索权限 | 跳转到 P2 并带关键词 | Drawer 展开 + 自动填充搜索 |
| 点击角色标签 | 打开 P2 并筛选该角色权限 | Drawer 展开 + 自动筛选 |
| 点击最近申请条目 | 跳转到 P4 并定位该记录 | 页面切换 |
| 点击查看全部 | 跳转到 P4 | 页面切换 |

```
│  ─────────────────────────────────────               │
```

### 区域说明

  - Link（← 权限中心）：返回 P3
  - Button（+ 申请权限）：打开 P2
- **筛选区**
  - Tabs：[全部] [进行中] [已完成]
    - 选中态：高亮
    - 未选中态：常规
- **列表区**
  - ListGroup：按申请时间倒序排列
    - 每条记录包含：
      - Text：{权限名}

- 申请详情页（单条记录的完整流转历史）为本次范围外的细化页面，P4 作为列表页承载摘要信息

## 7. 权限申请 Drawer (P2)

### 弹窗目标

让员工选择和确认要申请的权限或角色，填写申请理由并提交。

### 进入条件

- 从 P1 点击"去申请"（权限预填）
- 从 P3 点击"申请权限"（手动选择）

- 从 P4 点击"+ 申请权限"

```
│                                                     │

│     可以做什么：{业务说明}                            │
│                                                     │

│     可以做什么：{业务说明}                            │

│                                                     │

```

### 区域说明

- **标题区**
  - Text：申请权限
  - Button（关闭 ×）：关闭 Drawer，不保存已选内容
  - Link（←）：返回（对应预填场景显示申请详情）
- **搜索区**
  - Input：搜索权限名称或关键词
    - Placeholder：搜索权限名称或关键词...
    - 输入后列表实时过滤
- **筛选区**
  - Select（全部权限）：按权限类型筛选
  - Select（按应用分类）：按应用维度筛选
- **权限列表区**
  - ListGroup：可申请权限项
    - 每项：
      - Checkbox：选中/未选中（已拥有项为 Circle 图标不可选）
      - Text：{权限名}
      - Text（次要）：可以做什么：{业务说明}
      - Tag（仅已拥有项）：已拥有
    - 角色权限包展开态：展示包含的具体权限列表
- **申请理由区**
  - Textarea：申请理由
    - Placeholder：请说明你需要此权限做什么...（选填）
    - 最大字数限制（如 500 字）
- **操作区**
  - Button（提交申请）：主按钮
    - 无选中权限时置灰
  - Text（提示）：提交后将通知你的上级 {审批人姓名} 处理

### 校验阻断态变化

| 场景 | 变化 |
|---|---|
| 未选择任何权限 | 提交按钮置灰，不可点击 |
| 申请理由超过字数限制 | 输入框下方显示 InlineError："申请理由不超过 {N} 字" |
| 提交失败（网络异常） | Toast："提交失败，请稍后重试"，Drawer 不关闭，已填信息保留 |

## 8. 主交互流程

### 8.1 缺口触发申请（主路径）

```
1. 员工在功能操作页面被拦截
   → P1 无权限拦截页展示
   → 显示缺少的具体权限名 + 可申请状态

2. 员工点击"去申请"
   → P2 权限申请 Drawer 打开
   → 该权限已预勾选、只读

3. 员工补充申请理由
   → Textarea 输入理由（选填）

4. 员工点击"提交申请"
   → 前端校验：至少选中 1 项权限
   → 校验通过 → 后端提交
   → Drawer 关闭
   → Toast："申请已提交，已通知你的上级 {审批人姓名} 处理"
   → P4 新增一条"审批中"记录
   → 同步推送待办至审批人（OA 底座）
```

### 8.2 目标驱动申请（分支路径）

```
1. 员工在 P3 首页点击"申请权限"（或搜索/点击角色标签）
   → P2 权限申请 Drawer 打开（手动选择模式）

2. 员工搜索或浏览权限列表
   → 实时过滤结果
   → 查看权限业务说明

3. 员工勾选所需权限项
   → 支持多选
   → 已拥有项不可选

4. 员工填写申请理由
   → Textarea 输入

5. 员工点击"提交申请"
   → 校验 → 提交 → 同 8.1 步骤 4
```

---

## 9. 校验规则

| 字段 | 规则 | 违反时 |
|---|---|---|
| 选中权限 | 至少选中 1 项可申请权限 | 提交按钮置灰 |
| 申请理由 | 选填，最多 500 字（暂定） | InlineError："申请理由不超过 {N} 字" |

## 10. 状态表现

| 状态 | 触发条件 | UI 表现 | 文案 key |
|---|---|---|---|
| 待提交 | 已选权限但未提交 | P2 打开，提交按钮可点击 | — |
| 审批中 | 提交成功，审批人未处理 | P4 Tag：蓝色"审批中" | apply.status.pending |
| 已批准 | 审批人批准，权限尚未生效 | P4 Tag：黄色"已批准" | apply.status.approved |
| 已生效 | 权限已生效 | P4 Tag：绿色"已生效"；P5 Tag：绿色"已生效" | apply.status.effective |
| 已拒绝 | 审批人拒绝 | P4 Tag：红色"已拒绝"，展示原因 | apply.status.rejected |
| 已撤销 | 员工主动撤销 | P4 Tag：灰色"已撤销" | apply.status.revoked |
| 已失效 | 权限过期或回收 | P5 Tag：灰色"已失效" | permission.status.invalid |
| 不可申请 | 权限系统排除 | P2 置灰 + Tooltip"此权限不可自助申请" | permission.not_applicable |

## 11. 异常恢复

### E1：从缺口到申请的链路失败

- **时机**：员工在 P1 点击"去申请"时
- **触发**：无法确定缺失的权限或权限信息不可达
- **反馈**：P1 降级文案
- **恢复**：原路恢复，无信息丢失。后续可从 P3 手动申请

### E2：搜索无结果

- **时机**：P2 搜索权限时
- **触发**：搜索关键词无匹配
- **反馈**：列表区显示 EmptyState
- **文案**："没有找到匹配的权限"
- **恢复**：提供"浏览全部"链接，清空搜索条件

### E3：权限不可申请

- **时机**：P2 浏览权限列表时
- **触发**：权限被系统排除或管理员未开放
- **反馈**：该项置灰 + Tooltip
- **文案**："此权限不可自助申请"
- **恢复**：员工继续选择其他可申请权限

### E4：提交校验失败

- **时机**：P2 点击提交时
- **触发**：未选权限或理由超长
- **反馈**：Drawer 不关闭，InlineError 提示
- **恢复**：修正后重新提交，已填信息保留

### E5：审批长时间未处理

- **时机**：提交后超过预设时限
- **触发**：审批人未在规定时间内操作
- **反馈**：P4 该记录下方增加提示文字
- **文案**：审批人暂未处理，已发送催办提醒
- **恢复**：系统自动催办或升级，申请信息不丢失

### E6：审批拒绝

- **时机**：审批人操作后
- **触发**：审批人拒绝
- **反馈**：P4 状态更新 + 展示拒绝原因
- **恢复**：员工查看原因后重新申请，或联系审批人

### E7：审批通过但权限未生效

- **时机**：审批人批准后
- **触发**：权限系统生效失败
- **反馈**：P4 状态显示"已批准"（非"已生效"），补充提示
- **文案**：权限生效中，请稍后查看
- **恢复**：系统自动重试生效，生效后状态更新

### 12.1 全部成功

- P2 Drawer 关闭

| 待确认项 | 影响 |

| 申请理由是否必填 | 影响 P2 表单校验规则 |
| OA 底座审批页面的自定义信息承载能力 | 影响审批上下文的展示方式 |
