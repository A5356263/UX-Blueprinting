# 页面生成规格：子管理员权限复制

---

## 1. 页面摘要

- **产品领域：** 企业权限管理 — 子管理员治理
- **页面类型：** 页面（列表页）+ 弹窗（复制弹窗）+ 全局提示区（结果摘要）
- **用户角色：** 权限管理员 / 超级管理员
- **核心任务：** 将已配置子管理员的权限信息（可授权组织、可授权功能）复制给一批目标用户

---

## 2. 生成范围

### 主生成

- 子管理员列表页（承载页）— 操作列新增「复制」按钮
- 复制弹窗 — 复制内容选择 + 复制对象选择 + 校验 + 提交
- 复制结果摘要 — 全局提示区（成功 / 部分失败 / 审批中）

### 关联不主生成

- 人员选择弹窗 — 复用现有「选择员工」组件，仅记录调用关系
- 操作记录页 — 引用已有页面，仅记录本功能产生的操作记录字段和文案
- 审批管理页 — 引用已有页面，仅记录跳转入口

### 不生成

- 复制历史独立页面
- 批量撤回入口
- 复制模板保存功能

---

## 3. 页面实体关系

```
子管理员列表页（承载页）
  ├─ [复制] 按钮 ──→ 复制弹窗（主实体）
  │                   ├─ [选择员工] ──→ 人员选择弹窗（复用，不主生成）
  │                   └─ [确认复制] ──→ 结果摘要区（全局提示）
  │                                       ├─ [查看操作记录] ──→ 操作记录页（引用）
  │                                       └─ [查看审批进度] ──→ 审批管理页（引用）
  └─ 操作列其他按钮（编辑、删除等，不做变更）
```

## 4. 子管理员列表页（承载页 — 实体 0）

### 页面目标

查看、检索和管理已配置的子管理员，支持增删改查及全局模式控制。本次仅改动操作列中的「复制」入口。

### 页面结构（知识库 ASCII 框图原文照搬）

```

| 【 顶部全局Tab切换区 】                                                                |
| [Left]:  [Tab: 子管理员模式] [Tab: 双管理员互审模式 (标签:未启用)] [Tab: 权限变更审批模式 (标签:未启用)] |
+---------------------------------------------------------------------------------------+
| 【 提示信息与状态控制区 】                                                             |
| [Left]:  {业务介绍提示文本...} [文本链接: 帮助文档]                        [Right]: [文本链接: 关闭子管理员模式] |
+---------------------------------------------------------------------------------------+
| 【 筛选查询区 】                                                                       |

+---------------------------------------------------------------------------------------+

+---------------------------------------------------------------------------------------+

|                                                                                       |
| [数据行内 Actions]: [复制] [编辑] [移除] [...]                                          |
+---------------------------------------------------------------------------------------+
| 【 底部分页区 】                                                                       |

```

### 列表字段

| 字段 | 元素类型 | 说明 |
| --- | --- | --- |
| 姓名 | 文本 | 子管理员姓名 |
| 手机号 | 数字文本 | 脱敏展示 |
| 部门 | 文本 | 所属部门 |
| 可授权组织 | 文本 | 组织范围概览（截断，如"全部"或具体组织名） |
| 可授权功能 | 文本 | 功能数量或功能名拼接（截断） |
| 操作 | Actions 组 | [复制] [编辑] [移除] [...]，复制位于最左侧 |

### 关键操作

| 操作 | 触发结果 |
| --- | --- |
| 复制 | 打开复制弹窗（实体 1），自动加载当前行子管理员的权限配置 |
| 编辑 | 进入子管理员配置页（不做变更） |
| 移除 | 移除该子管理员（不做变更） |

## 5. 复制弹窗（主实体 — 实体 1）

### 弹窗目标

在一个弹窗内完成复制内容选择和复制对象选择，提交后执行复制。

├──────────────────────────────────────────┤
│ 【 区 ②：复制内容 】                      │

├──────────────────────────────────────────┤

│ ┌──────────────────────────────────┐    │

│ │                                  │    │
│ │ {姓名}  {手机号}           [移除] │    │

### 区域说明

**区 ① 复制来源**

| 项 | 元素类型 | 业务规则 |
| --- | --- | --- |
| 姓名 | 文本 | 来源子管理员姓名，不可编辑 |
| 手机号 | 文本 | 脱敏展示，不可编辑 |
| 可授权组织 | 文本 | 当前组织范围简述（如"华东区（3个部门）"或"全部"），不可编辑 |
| 可授权功能 | 文本 | 当前功能数量（如"12项"），不可编辑 |

**区 ② 复制内容**

| 项 | 元素类型 | 业务规则 |
| --- | --- | --- |
| 可授权组织 | 复选框 | 默认勾选，可取消。至少保留一项勾选 |
| 可授权功能 | 复选框 | 默认勾选，可取消。至少保留一项勾选 |
| 帮助提示 | 辅助文本 | "至少选择一项"，仅在两项均取消时高亮为红色 |

**区 ③ 复制对象**

| 项 | 元素类型 | 业务规则 |
| --- | --- | --- |
| 选择员工 | 主按钮 | 点击打开人员选择弹窗（复用现有组件） |
| 已选列表 | 标签列表 | 每项显示姓名+手机号，右侧[移除]按钮。空时显示"暂未选择" |
| 上限提示 | 辅助文本 | "最多选择 200 名员工"，达上限时选择器阻止继续添加 |
| 已选计数 | 标签 | 区标题右侧显示"已选 {N}人" |

**区 ④ 底部提示**

| 项 | 元素类型 | 业务规则 |
| --- | --- | --- |
| 规则提示 | 辅助文本 | 固定文案"已有子管理员的权限将叠加，不覆盖原有配置"，始终可见 |

## 6. 主交互流程

| 步骤 | 用户动作 | 系统反馈 | 下一步 |
| --- | --- | --- | --- |
| 1 | 在列表页点击某行的「复制」 | 打开复制弹窗，加载来源子管理员权限信息，默认全选复制内容 | 步骤 2 |
| 2 | 查看来源权限摘要，确认/调整复制内容勾选 | 区 ① 展示来源信息，区 ② 复选框可操作 | 步骤 3 |
| 3 | 点击「选择员工」，搜索并选择目标用户 | 打开人员选择弹窗；已选用户追加到区 ③ 列表；达 200 人时阻止添加并提示"最多选择 200 名员工" | 步骤 4 |
| 4 | 点击「确认复制」 | 按序执行 4 项校验。全通过 → 提交执行。任一失败 → 弹窗不关闭，对应区展示红色提示 | 步骤 5（通过）/ 步骤 2-3（失败修正） |
| 5 | 查看结果 | 关闭复制弹窗，展示结果摘要（§10） | 关闭结果摘要 / 跳转操作记录 / 跳转审批 |

---

## 7. 校验规则

| 顺序 | 校验规则 | 阻断条件 | 阻断行为 | 恢复路径 |
| --- | --- | --- | --- | --- |
| 1 | 复制信息是否已勾选 | 两项均未勾选 | 弹窗不关闭，区 ② 下方红色提示"请选择复制信息" | 勾选至少一项后重新点击确认 |
| 2 | 复制对象是否已选择 | 已选列表为空 | 弹窗不关闭，区 ③ 下方红色提示"请选择至少一名复制对象" | 点击选择员工添加后重新点击确认 |
| 3 | 目标加入状态是否均为"已加入" | 存在未加入用户 | 弹窗不关闭，区 ③ 下方红色提示列出不满足条件的用户名和原因 | 手动移除不符合用户后重新点击确认 |
| 4 | 目标认证状态是否均为"已认证" | 存在未认证用户 | 弹窗不关闭，区 ③ 下方红色提示列出不满足条件的用户名和原因 | 手动移除不符合用户后重新点击确认 |

## 8. 状态表现

| 状态 | 触发条件 | UI 表现 | 文案 key |
| --- | --- | --- | --- |
| 待配置 | 弹窗打开 | 区 ① 展示来源信息，区 ② 复选框默认全选，区 ③ 已选列表为空，[确认复制] 可点击 | `modal.title` |
| 校验失败 | 点击确认后校验不通过 | 弹窗不关闭，对应区下方红色提示块，列出失败原因和用户名 | `validation.*` |
| 提交中 | 校验通过，正在执行 | 弹窗关闭，可能展示 loading 态（提交速度较快时可省略） | — |
| 已生效 | 非互审模式执行成功 | 结果摘要横幅（绿色），展示成功人数和操作入口 | `result.all_success` |
| 审批中 | 互审模式已提交审批 | 结果摘要横幅（蓝色），展示待审批人数和审批入口 | `result.audit_pending` |
| 部分成功 | 部分目标失败 | 结果摘要横幅（黄色），展示成功/失败统计和失败明细 | `result.partial_fail` |
| 来源失效 | 执行时来源子管理员不可用 | toast 红色提示，弹窗不关闭 | `error.source_invalid` |

## 9. 异常恢复

| 异常 | 触发条件 | 反馈形式 | 用户恢复路径 |
| --- | --- | --- | --- |
| 复制信息未选 | 两项复选框均未勾选时点确认 | 弹窗内红色 inline 提示 | 勾选至少一项 → 重新点击确认 |
| 复制对象为空 | 未选择任何目标时点确认 | 弹窗内红色 inline 提示 | 添加至少一名目标 → 重新点击确认 |
| 目标加入状态不符 | 已选用户中存在未加入者 | 弹窗内红色列表，逐条列出用户名和原因 | 手动移除不合格用户 → 重新点击确认 |
| 目标认证状态不符 | 已选用户中存在未认证者 | 弹窗内红色列表，逐条列出用户名和原因 | 手动移除不合格用户 → 重新点击确认 |
| 人员选择器达上限 | 已选达 200 人时继续添加 | 选择器阻止添加 + toast "最多选择 200 名员工" | 移除部分已选用户后继续 / 分批复制 |
| 来源执行时失效 | 执行时来源子管理员被删除或禁用 | toast "来源权限配置已失效，请重新选择" | 关闭弹窗 → 回到列表重新选择来源 |
| 互审审批被拒 | 审批人拒绝复制审批 | 审批状态变更为"已拒绝"，发起人收到通知 | 查看拒绝原因 → 决定是否重新发起 |

## 13. 不参与本次生成的待确认项

| 待确认项 | 影响 |
| --- | --- |
| "加入状态"口径（已加入 vs 已启用） | 校验提示文案中状态名称需统一 |
| 复制对象是否允许包含来源自身 | 人员选择器是否需要过滤来源 |
| 目标已是子管理员且权限完全相同时是否跳过 | 结果统计是否包含"无变化" |
| 操作记录合并为一条还是分两条 | 操作记录页展示方式 |
| 审批被拒后管理员通知方式 | 异常恢复路径中的通知设计 |
| 目标用户是否收到成为子管理员的通知 | 消息通知触发逻辑 |
| 复制撤回/回滚能力 | 首期不做，后续纳入权限变更回滚体系 |
