# 页面生成规格：员工自助申请权限

## 1. 页面摘要

- **产品领域**：权限管理 — 自助申请权限
- **页面类型**：Page（配置页、列表页、详情页）、Drawer（申请表单）、Modal（确认弹窗）
- **用户角色**：超级管理员、员工（申请人）、审批人
- **核心任务**：员工自助申请角色/功能权限，超管配置管控模式，审批人审批申请

---

## 3. 页面实体关系

```
权限管理模式选择页（承载页）
  └── 自助申请模式设置页（从"立即启用"进入，互斥校验通过后）
       ├── 选择角色弹窗（设置角色范围时引用）
       ├── 选择应用弹窗（设置应用范围时引用）
       └── 表单编辑子页面（修改审批流程时引用）
  └── 关闭模式确认弹窗（从已开启状态页点击关闭触发）

个人中心
  └── 我的权限页（入口位于"我的企业"下方）
       ├── 申请权限 Drawer（从点击"申请权限"触发）
       └── 申请记录列表页（Tab 切换）

OA 审批待办列表（外部）
  └── 审批详情页（从待办列表点击条目进入）
```

## 4. 权限管理模式选择页（承载页）

### 页面目标

超管在系统级全局治理模式中选择并启用"自助申请权限模式"，作为员工自助申请的总开关。

### 页面结构（ASCII + 区域说明）

```
+----------------------------------------------------------------------+
|              【页面中心】请选择权限管理模式                              |
|              {副标题：模式选择引导和说明...}                            |
|                                                                      |
| +------------------------+ +------------------------+ +---------------+ |
| | 【卡片】子管理员模式    | | 【卡片】双管理员互审    | | 【卡片】权限  | |
| | [插画]                 | | [插画]                 | | 变更审批模式   | |
| | {模式名称}             | | {模式名称}             | | [插画]        | |
| | {模式描述}             | | {模式描述}             | | {模式名称}    | |
| | [立即启用] [了解更多]   | | [立即启用] [了解更多]   | | {模式描述}    | |
| +------------------------+ +------------------------+ | [立即启用]    | |
|                                                       | [了解更多]    | |
| +-----------------------------------------------------+---------------+ |
| | 【卡片 4】自助申请权限模式                                             | |
| | [插画]                                                              | |
| | 自助申请权限模式                                                      | |
| | 员工可自助申请权限，工作流审批通过后，系统将自动分配权限                | |
| | [立即启用]  [了解更多]                                                | |
| +----------------------------------------------------------------------+ |
+----------------------------------------------------------------------+
```

**区域说明**：

- **页面标题区**：`[Title]` "请选择权限管理模式"
- **模式卡片组**：`[CardGrid]` 水平排列的 4 个模式卡片
  - 卡片 1：子管理员模式
  - 卡片 2：双管理员互审模式
  - 卡片 3：权限变更审批模式
  - 卡片 4：自助申请权限模式（本次功能入口）

每个卡片包含：`[Illustration]`、`[Title]`、`[Description]`、`[Button: 立即启用]`、`[Link: 了解更多]`

### 提取备注

- 承载页面结构来自 `knowledge-wiki` 权限管理 `15_页面载体语义.md` §4.1
- 自助申请权限模式为新增卡片（原有知识库中仅 3 个模式，本次新增第 4 个）

### 列表字段

无

### 关键操作

- 点击卡片"立即启用" → 触发模式启用流程（自助申请模式为互斥校验后进入设置页）
- 点击"了解更多" → 跳转帮助文档

## 5. 自助申请模式设置页

### 页面目标

超管完成自助申请模式的申请方式、范围和审批流程的三步配置。

### 页面结构（ASCII + 区域说明）

```
+------------------------------------------------------------------------------+
| 【页面标题】自助申请模式设置                                                    |
|                                                                              |
| 【步骤条】Step 1 ◉ ——— Step 2 ○ ——— Step 3 ○                                 |
|                                                                              |
| ═════════════════════════ 第一步 ════════════════════════════════════════════ |
|                                                                              |
| 选择员工申请权限的方式                                                        |
|                                                                              |
| (o) 申请角色                                                                 |
|     1. 申请通过后，员工将自动关联上申请角色                                    |
|     2. 如果启用常用角色进行授权，建议采用此方式                                |
|                                                                              |
| ( ) 申请功能权限                                                             |
|     1. 申请通过后，员工将自动授权功能权限                                     |
|     2. 如果企业常用用户直接授权的方式，建议采用此方式                           |
|                                                                              |
| ═════════════════════════ 第二步（申请角色时）════════════════════════════════ |
|                                                                              |
| 请选择允许员工自助申请的角色                                                  |
|                                                                              |
| (o) 全部角色                                                                 |
| ( ) 部分角色  →  [选择角色] → 弹窗选择后展示已选角色标签                      |
|                                                                              |
| [v] 后续新增角色自动加入员工可申请的范围                                        |
|                                                                              |
| ═════════════════════════ 第二步（申请功能权限时）═══════════════════════════ |
|                                                                              |
| 请选择允许员工自助申请权限的应用                                               |
|                                                                              |
| (o) 全部应用                                                                 |
| ( ) 部分应用  →  [选择应用] → 弹窗选择后展示已选应用标签                      |
|                                                                              |
| [v] 后续新添加的应用自动加入员工可申请的范围                                    |
|                                                                              |
| ═════════════════════════ 第三步 ════════════════════════════════════════════ |
|                                                                              |
| 设置审批流程                                                                  |
|                                                                              |
| 系统已预设了「员工申请权限」时的审批流程，                                      |
| 预设审批人为员工所在组织的组织负责人。如需调整，可点击修改审批流程。             |
|                                                                              |
| [修改审批流程]  → 打开表单编辑子页面                                           |
|                                                                              |
| ═══════════════════════════════════════════════════════════════════════════ |
|                                                                              |
|                                       [取消]        [启用]                    |
+------------------------------------------------------------------------------+
```

**区域说明**：

- **步骤条区**：`[Steps]` 三步步骤条，当前步骤高亮（◉），其余为灰色（○）
- **第一步-申请方式**：`[RadioGroup]` 申请角色/申请功能权限，默认选中申请角色；每个选项下方带 `[Text]` 提示文案
- **第二步-角色范围**（申请角色时）：`[RadioGroup]` 全部角色/部分角色；选择"部分角色"时显示 `[Button: 选择角色]` → 打开 `[Modal]` 选择角色弹窗
  - 角色弹窗：`[Search]`、`[Table]`（选项框/角色名称/角色说明/角色状态）、`[Pagination]`
  - `[Checkbox]` "后续新增角色自动加入员工可申请的范围"（默认选中）
- **第二步-应用范围**（申请功能权限时）：同角色范围结构，替换角色为应用
  - 应用弹窗：`[Search]`、`[Table]`（选项框/应用名称/应用终端/应用启用状态）、`[Pagination]`
  - `[Checkbox]` "后续新添加的应用自动加入员工可申请的范围"（默认选中）
- **第三步-审批流程**：`[Text]` 预设流程说明 + `[Link]` 修改审批流程（打开表单编辑子页面）
- **底部操作栏**：`[Button: 取消]`、`[Button: 启用]`

### 校验阻断态变化

- 启用时互斥校验失败 → 弹出 `[Modal]` 提示"企业已开启{冲突模式名称}，不能同时开启此模式"，阻止启用

### 列表字段

无

### 关键操作

- 点击"启用" → 再次校验互斥模式 → 通过后启用成功，Toast "开启成功"

## 6. 我的权限页

### 页面目标

员工查看自己已有的功能权限、数据权限和角色。

### 页面结构（ASCII + 区域说明）

```
+------------------------------------------------------------------------------+
| 【页面标题】我的权限                                                          |
|                                                                              |
| [Tab: 功能权限]  [Tab: 数据权限]  [Tab: 角色]                                |
|                                                                              |
| ═════════════════════════ 功能权限 Tab ═════════════════════════════════════ |
|                                                                              |
| 应用名称        | 功能权限                    | 操作                           |
| ───────────────┼────────────────────────────┼────────────────────────────── |
| {应用名}       | {功能权限列表}               | —                             |
| {应用名}       | {功能权限列表}               | —                             |
|                                                                              |
| 无数据时：                                                                   |
| ┌──────────────────────────────────────────────────────────────────────────┐ |
| │                              [插画]                                      │ |
| │                         您没有功能权限                                    │ |
| │                           [去申请权限]                                    │ |
| └──────────────────────────────────────────────────────────────────────────┘ |
|                                                                              |
| ═════════════════════════ 数据权限 Tab ════════════════════════════════════ |

```

**区域说明**：

- **Tab 切换区**：`[Tabs]` 功能权限（默认）/ 数据权限 / 角色
- **功能权限 Tab**：
  - `[Table]` 列：应用名称、功能权限、操作
  - 数据为空时：`[EmptyState]` 插画 + "您没有功能权限" + `[Button: 去申请权限]`
- **数据权限 Tab**：交互和数据与"用户授权-权限详情"一致（不展开）
- **角色 Tab**：交互和数据与"用户授权-权限详情"一致（不展开）

### 提取备注

- 功能权限列表包含全员应用和管理类应用
- 服务人员不展示此页面入口

### 列表字段

功能权限 Tab：应用名称、功能权限、操作

### 关键操作

- 空状态点击"去申请权限" → 打开申请权限 Drawer

## 9. 申请记录列表页

### 页面目标

员工查看自己的申请历史，追踪进度。

### 页面结构（ASCII + 区域说明）

```
+------------------------------------------------------------------------------+
| 【tab】我的权限    申请记录                                                    |
|                                                                              |
| [筛选]  申请日期: [日期选择]   审批状态: [下拉: 全部/已通过/已拒绝/审批中/已撤销] |
|                                                                              |
| ────────────────────────────────────────────────────────────────────────── |
| 申请时间          | 申请原因          | 申请内容      | 审批状态   | 操作    |
| ──────────────────┼──────────────────┼─────────────┼──────────┼───────── |
| {时间}            | {申请原因}        | {角色/权限}  | [标签]    | [撤销]  |
|                                                                              |
|                        共 {N} 条  < 1 2 3 >  {20条/页}                       |
+------------------------------------------------------------------------------+
```

**区域说明**：

- **Tab 切换**：`[Tabs]` "我的权限" / "申请记录"（当前选中）
- **筛选区**：`[DatePicker]` 申请日期 + `[Select]` 审批状态（全部/已通过/已拒绝/审批中/已撤销）
- **列表区**：`[Table]` 申请时间、申请原因、申请内容（角色名或"[查看详情]"链接）、审批状态（`[Tag]`）、操作（`[Button: 撤销]`，仅审批中可见）
- **分页区**：`[Pagination]` 共 {N} 条

**状态标签样式**：
- 审批中：`[Tag]` 蓝色/进行中
- 已通过：`[Tag]` 绿色/成功
- 已拒绝：`[Tag]` 红色/失败
- 已撤销：`[Tag]` 灰色/中性

### 校验阻断态变化

- 撤销按钮仅审批中的记录可见，其他状态隐藏

### 列表字段

申请时间（年月日时分秒）、申请原因、申请内容（角色名称或"查看详情"超链接）、审批状态（Tag）、操作（撤销）

## 11. 主交互流程

### 流程 P1：超管配置并启用自助申请模式

1. **进入模式页**：进入"权限管理模式选择页"，找到"自助申请权限模式"卡片
2. **点击启用**：点击卡片"立即启用"按钮
3. **互斥校验**：系统校验双管理员互审和权限变更审批模式是否已开启
   - 校验失败：弹窗提示冲突模式，停止进入
   - 校验通过：进入设置页
4. **第一步-选择方式**：选择"申请角色"或"申请功能权限"（默认申请角色）
5. **第二步-设置范围**：
   - 角色范围：全部或部分（默认全部），选择部分时弹窗选角色
   - 应用范围：全部或部分（默认全部），选择部分时弹窗选应用
   - 勾选"后续新增角色/应用自动加入可申请范围"
6. **第三步-审批流程**：查看预设审批人或点击修改审批流程
7. **启用**：点击"启用"，再次校验互斥
   - 校验通过：Toast "开启成功"，员工端出现"我的权限"入口
   - 校验失败：弹窗提示冲突

### 流程 P2：员工申请权限

1. **进入我的权限**：个人中心 → "我的权限"入口
2. **查看已有权限**：浏览功能权限/数据权限/角色 tab
3. **申请权限**：点击"申请权限" → 打开 Drawer
4. **选择申请内容**：
   - 角色模式：从角色列表中勾选目标角色
   - 功能权限模式：选择应用和功能权限
5. **填写申请原因**：必填，最多 500 字
6. **提交申请**：点击"提交申请" → 后端校验
   - 校验通过：Drawer 关闭 → Toast "提交成功" → 申请记录新增"审批中"
   - 校验失败：Drawer 不关闭 → InlineError 展示具体原因

### 流程 P3：审批人审批申请

1. **接收待办**：在 OA 审批待办列表中找到权限申请
2. **查看详情**：进入审批详情页，查看申请人、申请内容、权限说明、申请原因
3. **做出决策**：点击"同意"或"否决"
   - 同意：系统自动分配权限 → 通知申请人
   - 否决：填写否决原因 → 流程终止 → 通知申请人

|---------|---------|---------|---------|

| 提交申请时 | 实名要求校验 | 校验不通过 | InlineError 展示具体原因 |
| 提交申请时 | 特殊身份默认权限校验 | 校验不通过 | InlineError 展示具体原因 |

## 14. 异常恢复

| 异常 | 阻断点 | 反馈形式 | 恢复路径 | 信息丢失 |
|------|-------|---------|---------|---------|
| 启用时模式互斥 | 点击启用后 | 弹窗提示冲突 | 关闭冲突模式后重新启用 | 无信息丢失 |
| 提交时后端校验失败 | 点击提交后 | Drawer 内 InlineError | 根据错误提示修正后重新提交 | 不丢失已填写内容 |
| 审批人长时间未处理 | 审批中等待 | 系统催办通知 | 审批人处理后自动恢复 | 无影响 |
| 审批人否决 | 审批人提交后 | 通知 + 状态更新 | 查看拒绝原因后重新申请 | 重新申请可复用历史信息 |
| 自动分配权限失败 | 审批通过后 | 系统通知 | 超管人工介入修复 | 审批结果保留 |
| 关闭模式时有在途 | 确认关闭后 | 弹窗提示 | 等待在途完成后重试关闭 | 无影响 |
| 撤销申请 | 列表操作 | Toast "撤销成功" | 重新发起申请 | 需重新填写 |
