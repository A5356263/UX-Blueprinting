# 页面生成规格：员工自助申请权限

## 1. 页面摘要

- **产品领域**：企业权限管理 — 员工自助申请权限
- **页面类型**：Page（我的权限、申请记录、自助申请配置）、Drawer（权限申请）、Modal（申请详情、关闭确认）
- **用户角色**：普通员工、超级管理员
- **核心任务**：员工查看自有权限并提交权限申请，超管配置自助申请范围和审批流程

---

## 2. 生成范围

### 生成

| 实体 | 类型 | 说明 |
|------|------|------|
| 我的权限 Page | Page | 员工查看自有权限的首页 |
| 权限申请 Drawer | Drawer | 员工选择和提交权限申请 |
| 申请记录 Page | Page | 员工查看申请进度和历史 |
| 申请详情 Modal | Modal | 员工查看单条申请的完整信息 |
| 自助申请配置 Page（管理端） | Page | 超管开启/关闭能力并配置范围和审批流程 |
| 关闭确认 Modal | Modal | 超管关闭能力前的二次确认 |

### 只引用不生成

| 实体 | 类型 | 原因 |
|------|------|------|
| 功能受限页面 | Page | 现有业务功能页面，"申请权限"入口以文字链接/按钮嵌入其中，本规格不生成该实体 |

### 不生成

| 实体 | 类型 | 原因 |
|------|------|------|
| 审批卡片 | Card | 复用现有审批流程中的审批卡片结构，仅补充内容字段，不生成新的审批页面 |

---

## 3. 页面实体关系

| 实体 | 类型 | 父页面 | 触发条件 |
|------|------|--------|---------|
| 我的权限 Page | Page | — | 员工从工作台/导航进入 |
| 权限申请 Drawer | Drawer | 我的权限 Page / 功能受限页面 | 员工点击"申请权限"按钮 |
| 申请记录 Page | Page | — | 员工从导航或申请成功后跳转进入 |
| 申请详情 Modal | Modal | 申请记录 Page | 员工点击"查看详情" |
| 自助申请配置 Page（管理端） | Page | — | 超管从管理后台导航进入 |
| 关闭确认 Modal | Modal | 自助申请配置 Page（管理端） | 超管关闭能力开关且有进行中申请 |

## 4. 我的权限 Page

### 页面目标

让员工查看自己当前拥有的所有权限，了解权限来源和生效状态。

### 页面结构

```
+------------------------------------------------------------------+
| 【 区域 A：页面标题区 】                                          |
| [Left]: 我的权限                               [Right]: [申请权限] |
|          查看你当前拥有的功能和数据权限                            |
+------------------------------------------------------------------+
| 【 区域 B：搜索与筛选区 】                                        |
| [Left]: [Input: 搜索权限名称]  [Select: 全部业务域 v]            |
+------------------------------------------------------------------+
| 【 区域 C：权限列表区 】                                          |
| ================== {业务域名} ({N}) ==================            |
| [ ] {权限名}                          [Tag: 来源标签]            |
|   用途：{一句话用途说明}              [Text: 来源详情]             |
| ------------------------------------------------------------------ |
| ...（更多权限项）                                                  |
| ================================================================ |
| [Text: 共 {N} 条权限，来自 {N} 个业务域]                          |
+------------------------------------------------------------------+
```

### 区域说明

- **区域 A：页面标题区**
  - Text：`我的权限`
  - Text：`查看你当前拥有的功能和数据权限`
  - Button：[申请权限] — 主按钮，点击打开权限申请 Drawer

- **区域 B：搜索与筛选区**
  - Input：搜索权限名称，placeholder `搜索权限名称`
  - Select：按业务域筛选，选项 `全部业务域` + 各业务域名

- **区域 C：权限列表区**
  - ListGroup：按业务域分组，每组标题 `{业务域名} ({权限数})`
  - 每条权限项包含：
    - Checkbox（选中态用于批量操作，如适用）
    - Text：`{权限名}`
    - Tag：来源标签（`自助申请` / `角色继承` / `系统授予`）
    - Text：用途说明 `用途：{一句话用途说明}`
    - Text：来源详情（如`由你于{日期}申请`、`角色：{角色名}`、`全员默认`）

### 状态变化

| 状态 | 变化 |
|------|------|
| 加载态 | 骨架屏占位，区域 A + B 固定，区域 C 展示骨架条 |
| 空状态 | 区域 C 展示 EmptyState："你暂无权限，可点击申请权限提交申请" |
| 失败态 | 区域 C 展示 EmptyState："暂时无法获取权限信息，请稍后重试" + [重试] 按钮 |

### 列表字段

| 字段 | 含义 | 来源 |
|------|------|------|
| {业务域名} | 权限所属的业务域 | 权限分类体系 |
| {权限名} | 权限的具体名称 | 权限定义 |
| {一句话用途说明} | 权限的通俗用途说明 | 权限定义（需补充） |
| {来源标签} | 权限的获取方式（自助申请/角色继承/系统授予） | 授权来源模型 |
| {来源详情} | 来源的补充说明（申请时间/角色名） | 授权来源模型 |

### 关键操作

| 操作 | 触发 | 结果 |
|------|------|------|
| 点击[申请权限] | 员工点击主按钮 | 打开权限申请 Drawer |
| 搜索权限名称 | 员工输入关键词 | 区域 C 过滤匹配项 |
| 筛选业务域 | 员工选择业务域筛选 | 区域 C 仅展示该域权限 |

## 5. 权限申请 Drawer

### Drawer 目标

让员工选择和提交要申请的权限。

### 入口条件

员工从我的权限 Page 点击[申请权限]，或从功能受限页面点击"申请权限"入口。

### 区域结构

```
+------------------------------------------------------------------+
| 【 区域 A：抽屉标题区 】                             [Icon: X]    |
| [Text: 申请权限]                                                  |
| [Text: 选择你需要使用的权限，提交后等待审批人审核]                 |
+------------------------------------------------------------------+
| 【 区域 B：搜索与分类区 】                                        |
| [Input: 搜索权限名称...]  [Select: 全部业务域 v]                  |
|                                                                  |
| [Tab: 全部] [Tab: {业务域名}] [Tab: {业务域名}] ...              |
+------------------------------------------------------------------+
| 【 区域 C：权限列表区 】                                          |
| [ ] {权限名}                                                     |
|     {一句话用途说明}                                              |
| [ ] {权限名}                                                     |
|     {一句话用途说明}                                              |
| ...                                                               |
| [Text: 已选 {N} 项权限]                                           |
+------------------------------------------------------------------+
| 【 区域 D：申请原因区 】                                          |
| [Label: 申请原因]                                                 |
| [Textarea: 请简要说明你为什么需要此权限...]          ({N}/{M}字)  |
| [Text: 提示：{示例描述}]                                          |
+------------------------------------------------------------------+
| 【 区域 E：底部操作区 】                                          |
| [Button: 取消]                    [Button: 提交申请（禁用/启用）] |
+------------------------------------------------------------------+
```

### 区域说明

- **区域 A：抽屉标题区**
  - Text：`申请权限`
  - Text：`选择你需要使用的权限，提交后等待审批人审核`
  - IconButton：[X] 关闭 Drawer

- **区域 B：搜索与分类区**
  - Input：搜索权限名称，placeholder `搜索权限名称...`
  - Select：按业务域筛选（如配置了多个业务域），option `全部业务域`
  - Tabs：`全部` + 各业务域名

- **区域 C：权限列表区**
  - CheckboxGroup：可多选，每项 Checkbox + Text（权限名）+ Text（用途说明）
  - Text：`已选 {N} 项权限`

- **区域 D：申请原因区**
  - Label：`申请原因`
  - Textarea：placeholder `请简要说明你为什么需要此权限...`
  - Text：`{N}/{M}字`（字符统计）
  - Text：`提示：{示例描述}`（示例引导）

- **区域 E：底部操作区**
  - Button：[取消] — 关闭 Drawer，无二次确认
  - Button：[提交申请] — 权限未选时禁用；点击后触发校验

### 校验阻断态变化

| 条件 | 区域变化 | 反馈形式 |
|------|---------|---------|
| 未选择任何权限 | 区域 E [提交申请] 置灰禁用 | 无额外提示 |
| 申请原因为空 | 区域 D Textarea 下方显示 InlineError | InlineError："请填写申请原因" |
| 所选权限不在可申请范围 | 区域 C 该项标记为不可选或提交时区域 D 下方 InlineError | InlineError："该权限暂不支持自助申请" |
| 审批流程配置异常 | 区域 E Toast | Toast："审批流程配置异常，无法提交，请联系管理员" |

### 不合规确认区结构

无不合规确认区（提交失败不弹窗，就地 InlineError 或 Toast 提示）。

## 6. 申请记录 Page

### 页面目标

让员工查看历史申请记录和当前进度。

### 页面结构

```
+------------------------------------------------------------------+
| 【 区域 A：页面标题区 】                                          |
| [Left]: 申请记录                                                  |
+------------------------------------------------------------------+
| 【 区域 B：筛选 Tab 区 】                                         |
| [Tab: 全部] [Tab: 进行中] [Tab: 已完成]                           |
+------------------------------------------------------------------+
| 【 区域 C：申请列表区 】                                          |
| +--------------------------------------------------------------+ |
| | {权限名} × {N}项                              [Tag: {状态}]   | |
| | 提交时间：{时间}                                               | |
| | 当前审批人：{姓名}    已等待：{时长}                            | |
| | [TextLink: 查看详情]                                           | |
| +--------------------------------------------------------------+ |
| ...（更多申请卡片）                                               |
+------------------------------------------------------------------+
```

### 区域说明

- **区域 A：页面标题区**
  - Text：`申请记录`

- **区域 B：筛选 Tab 区**
  - Tabs：`全部` / `进行中` / `已完成`

- **区域 C：申请列表区**
  - List：卡片式列表，每张卡片包含：
    - Text：申请权限名 `{权限名} × {N}项`
    - Tag：状态标签（`待审批` / `审批中` / `已通过` / `已拒绝` / `已撤回` / `已失效` / `授权异常`）
    - Text：`提交时间：{时间}`
    - Text：（进行中）`当前审批人：{姓名}    已等待：{时长}`
    - Text：（已完成）`审批人：{姓名}    审批通过：{时间}`
    - Text：（已拒绝）`原因：{拒绝原因}`
    - TextLink：[查看详情]
    - Button：（仅已拒绝）[重新申请]

### 状态变化

| 状态 | 变化 |
|------|------|
| 加载态 | 区域 C 展示加载骨架 |
| 空状态 | 区域 C 展示 EmptyState："你还没有提交过权限申请" |
| 失败态 | 区域 C 展示 EmptyState："暂时无法获取申请记录，请稍后重试" + [重试] 按钮 |

### 列表字段

| 字段 | 含义 | 来源 |
|------|------|------|
| {权限名} | 申请的权限名称 | 申请单 |
| {N} | 该次申请的权限项数量 | 申请单 |
| {状态} | 申请单当前状态（待审批/审批中等） | 申请单状态 |
| {时间} | 提交时间或审批时间 | 申请单时间戳 |
| {姓名} | 审批人姓名 | 审批流程 |
| {时长} | 已等待时间 | 实时计算 |
| {拒绝原因} | 审批人填写的拒绝理由 | 审批操作 |

### 关键操作

| 操作 | 触发 | 结果 |
|------|------|------|
| 切换 Tab | 员工点击筛选 Tab | 区域 C 按状态过滤列表 |
| 点击[查看详情] | 员工点击文字链接 | 打开申请详情 Modal |
| 点击[重新申请] | 员工点击按钮（仅已拒绝状态） | 打开权限申请 Drawer |

## 8. 自助申请配置 Page（管理端）

### 页面目标

让超管开启/关闭自助申请能力，配置可申请范围和审批流程。

### 页面结构

```
+------------------------------------------------------------------+
| 【 区域 A：页面标题区 】                                          |
| [Text: 自助申请权限配置]                                           |
+------------------------------------------------------------------+
| 【 区域 B：能力开关区 】                                          |
| [Text: 允许员工自助申请权限]              [Switch: 开启/关闭]     |
| [Text: 开启后，员工可在权限中心查看和申请权限]                     |
+------------------------------------------------------------------+
| 【 区域 C：可申请范围配置区 】                                    |
| [Text: [i] 不在范围内的权限，员工无法自助申请]                    |
|                                                                  |
| [Radio: 全部权限（谨慎选择）]                                     |
| [CheckboxGroup: 按业务域选择]                                     |
|     [v] {业务域名}           [TextLink: 展开 >]                   |
|         [v] {权限项名}                                           |
|         [v] {权限项名}                                           |
|     [ ] {业务域名}           [TextLink: 展开 >]                   |
|     ...                                                           |
|                                                                  |
| [Text: 已选 {N} 项权限]                                           |
+------------------------------------------------------------------+
| 【 区域 D：审批流程配置区 】                                      |
| [Text: 选择审批流程]                                              |
| [Select: 请选择一个审批流程 v]                                     |
|                                                                  |
| [Text: [i] 请先创建或选择一个已有的审批流程。未配置流程时，       |
|  员工无法提交申请]                                                |
| [TextLink: 去审批管理创建流程 >]                                   |
+------------------------------------------------------------------+
| 【 区域 E：底部操作区 】                                          |
| [Button: 保存]                                                    |
+------------------------------------------------------------------+
```

### 区域说明

- **区域 A：页面标题区**
  - Text：`自助申请权限配置`

- **区域 B：能力开关区**
  - Text：`允许员工自助申请权限`
  - Switch：开启/关闭
  - Text：`开启后，员工可在权限中心查看和申请权限`

- **区域 C：可申请范围配置区**
  - Text：`[i] 不在范围内的权限，员工无法自助申请`
  - Radio：`全部权限（谨慎选择）`
  - CheckboxGroup：按业务域选择，展开后显示具体权限项
  - Text：`已选 {N} 项权限`

- **区域 D：审批流程配置区**
  - Text：`选择审批流程`
  - Select：选项为已有审批流程
  - Text：`[i] 请先创建或选择一个已有的审批流程。未配置流程时，员工无法提交申请`
  - TextLink：`去审批管理创建流程 >`

- **区域 E：底部操作区**
  - Button：[保存]

### 状态变化

| 条件 | 区域变化 |
|------|---------|
| 开关关闭 | 区域 C + D 置灰不可编辑，显示"开启后即可配置" |
| 关闭开关且有进行中申请 | 弹出关闭确认 Modal |
| 未配置范围时点击保存 | Toast："请先选择可申请范围" |
| 未配置流程时点击保存 | Toast："请先选择审批流程" |
| 保存成功 | Toast："配置已保存" |

### 关键操作

| 操作 | 触发 | 结果 |
|------|------|------|
| 开启/关闭开关 | 超管点击 Switch | 开启：区域 C/D 可编辑；关闭：弹确认 Modal |
| 选择可申请范围 | 超管勾选 Checkbox | 更新已选计数 |
| 选择审批流程 | 超管从 Select 选择 | 关联审批流程 |
| 点击[保存] | 超管点击 | 校验 → 保存 → Toast 反馈 |

## 9. 关闭确认 Modal

### 弹窗目标

管理员关闭自助申请能力前二次确认，保护进行中申请不受影响。

### 触发条件

管理员关闭"允许员工自助申请权限"开关且存在进行中申请。

### 弹窗结构

```
+------------------------------------------------------------------+
| 【 区域 A：弹窗标题区 】                             [Icon: X]    |
| [Text: 关闭确认]                                                  |
+------------------------------------------------------------------+
| 【 区域 B：提示信息区 】                                          |
| [Text: 当前有 {N} 个进行中的申请。关闭后，新申请入口将隐藏，      |
|  已提交的申请将继续流转直至结束。]                                |
+------------------------------------------------------------------+
| 【 区域 C：底部操作区 】                                          |
| [Button: 取消]              [Button: 确认关闭]                    |
+------------------------------------------------------------------+
```

### 区域说明

- **区域 A：弹窗标题区**
  - Text：`关闭确认`
  - IconButton：[X] 关闭弹窗

- **区域 B：提示信息区**
  - Text：`当前有 {N} 个进行中的申请。关闭后，新申请入口将隐藏，已提交的申请将继续流转直至结束。`

- **区域 C：底部操作区**
  - Button：[取消] — 关闭弹窗，不执行关闭操作

## 10. 主交互流程

### 流程 1：员工提交权限申请

| 步骤 | 用户动作 | 系统反馈 | 状态变化 | 下一步 |
|------|---------|---------|---------|--------|
| 1. 触发申请 | 在功能受限页面或我的权限页点击"申请权限" | 打开权限申请 Drawer | — | 选择权限 |
| 2. 选择权限 | 浏览分类 Tab 或搜索，勾选要申请的权限项 | 选中项高亮，显示已选计数 | — | 填写原因 |
| 3. 填写原因 | 在 Textarea 中输入申请理由 | 字数实时统计，提供示例引导 | — | 提交申请 |
| 4. 校验并提交 | 点击[提交申请] | 校验权限范围 → 校验审批流程 → 创建申请单 → Drawer 关闭 → Toast 提示 | 新增"待审批"申请记录 | 跳转到申请记录页 |
| 5. 跟踪审批 | 查看申请记录页 | 状态标签显示"待审批"/"审批中"，状态变更时推送通知 | 待审批 → 审批中 | 等待或催办 |
| 6. 获得结果 | 收到审批通知 | （通过）状态变更为"已通过"，自动授权，通知员工；（被拒）状态变更为"已拒绝"，推送原因 | 待审批/审批中 → 已通过/已拒绝 | 通过：回到功能；被拒：查看原因 |

### 流程 2：管理员配置自助申请

| 步骤 | 用户动作 | 系统反馈 | 下一步 |
|------|---------|---------|--------|
| 1. 开启能力 | 进入配置页 → 打开 Switch | 区域 C/D 可编辑 | 配置范围和流程 |
| 2. 配置范围 | 选择业务域或勾选具体权限项 | 更新已选计数 | 配置流程 |
| 3. 配置流程 | 从 Select 选择审批流程 | — | 保存 |
| 4. 保存 | 点击[保存] | 校验 → Toast 反馈 | 完成 |

### 流程 3：管理员关闭自助申请

| 步骤 | 用户动作 | 系统反馈 | 下一步 |
|------|---------|---------|--------|
| 1. 关闭开关 | 点击 Switch 关闭 | 检测进行中申请数量 | 有 → 弹确认 Modal；无 → 直接关闭 |
| 2. 确认关闭 | 在 Modal 中点击[确认关闭] | 能力关闭，已有申请继续流转，Toast 提示 | 完成 |
| 3. 取消关闭 | 在 Modal 中点击[取消] 或 [X] | 弹窗关闭，开关保持原状态 | 回到配置页 |

## 11. 校验规则

| 规则 | 对象 | 条件 | 阻断 | 反馈 |
|------|------|------|------|------|
| 权限选择校验 | 权限申请 Drawer | 至少选择 1 项权限 | 是（[提交申请] 置灰禁用） | — |
| 申请原因非空校验 | 权限申请 Drawer Textarea | 原因不能为空 | 是（阻止提交） | InlineError："请填写申请原因" |
| 申请范围校验 | 权限申请 Drawer 提交时 | 所选权限在可申请范围内 | 是（阻止提交） | InlineError："该权限暂不支持自助申请" |
| 审批流程有效性校验 | 权限申请 Drawer 提交时 | 审批人存在且流程完整 | 是（阻止提交） | Toast："审批流程配置异常，无法提交，请联系管理员" |
| 配置范围校验 | 配置页保存时 | 至少选择 1 项权限 | 是（阻止保存） | Toast："请先选择可申请范围" |
| 配置流程校验 | 配置页保存时 | 已选择审批流程 | 是（阻止保存） | Toast："请先选择审批流程" |

## 13. 异常恢复

| 异常 | 触发 | UI 表现 | 恢复路径 |
|------|------|---------|---------|
| 所选权限不在可申请范围 | 员工提交申请时，权限不在管理配置的范围中 | Drawer 内 InlineError | 员工重新选择其他权限或关闭 Drawer，不丢失已填信息 |
| 审批人缺失或流程无效 | 员工提交申请时，审批人不存在或流程未配置 | Toast + 申请单不创建 | 管理员修复审批流程后，员工重新提交申请。已填信息丢失 |
| 自动授权失败 | 审批通过后，系统调用授权接口失败 | 申请单标记"授权异常"，通知管理员和员工 | 管理员手动处理或重试授权。员工无需重新申请 |
| 申请后权限被删除 | 申请进行中或已通过但未生效时，管理员删除该权限 | 申请单标记"已失效"，通知员工 | 无法自动恢复，员工联系管理员或重新选择其他权限 |
| 关闭能力时有进行中申请 | 管理员关闭开关，系统检测到待审批/审批中的申请 | 弹窗提示数量 + 确认关闭已提交申请继续流转 | 确认后关闭，已有申请不受影响 |

## 17. 不参与本次生成的待确认项

| 待确认项 | 影响 |
|---------|------|
| 功能页面的受限提示是否支持嵌入交互入口（按钮/链接） | 影响"现场触发"路径能否实现，当前按支持嵌入方案推进 |
