# 页面生成规格：员工自助申请权限

> 提取来源：`spark-output/experience_blueprint.md`
> 生成时间：2026-07-06

---

## 1. 页面摘要

- **产品领域**：企业权限管理 — 员工自助权限申请
- **页面类型**：Page（我的权限）、Drawer（权限申请）、Modal（申请详情）、Page/模块（申请记录列表、管理员配置页）
- **用户角色**：员工（权限申请人）、审批人、系统管理员/超管
- **核心任务**：员工查看自有权限并提交权限申请，审批人审查并处理申请，管理员配置自助申请能力

## 3. 页面实体关系

```
我的权限（Page）              ← 有独立菜单入口，顶层页面
  ├── 权限申请（Drawer）      ← 从我的权限页面"申请权限"按钮触发
  └── 申请记录列表（模块）    ← 内嵌在我的权限页面或独立页面进入

申请记录列表（Page/模块）
  └── 申请详情（Modal）       ← 从申请记录列表点击某条记录触发

管理员自助申请配置（Page/模块）← 管理后台内配置页
```

## 5. 权限申请（Drawer）

### 弹窗目标

让员工选择权限项、填写申请原因、提交申请。

### 触发条件

员工在"我的权限"页面点击"申请权限"按钮（页面右上角全局按钮或列表中某行的"申请"按钮）。

### 区域结构

```
+-----------------------------------------------------------------------+
| 【 区域 A：弹窗标题区 】                                       [X]     |
| [Left]:  申请权限                                                      |
+-----------------------------------------------------------------------+
| 【 区域 B：步骤指示区 】                                               |
| [Center]: 选择权限 → 填写原因 → 提交                                  |
+-----------------------------------------------------------------------+
| 【 区域 C：可申请权限选择区 】                                         |
| [搜索框: 搜索权限名称...]                                              |
|                                                                       |
| ── 应用：OA审批 ────────────────────────────────────────               |
| [ ]  审批单据      说明：审批单据的查看、提交与跟踪                     |
| [ ]  审批模板管理  说明：创建和编辑审批模板（需要管理员权限）           |
|                                                                       |
| ── 应用：智能薪酬 ────────────────────────────────────────               |
| [ ]  薪酬计算      说明：查看和计算员工薪酬数据                         |
| [ ]  报表查看      说明：查看薪酬报表和统计分析                         |
+-----------------------------------------------------------------------+
| 【 区域 D：申请原因区 】                                               |
| [Label]: 申请原因                                                      |
| [文本域]: 请说明为什么需要这些权限...                                  |
| [常用原因快速选择]:                                                     |
| [工作职责需要] [临时项目参与] [代岗/交接]                              |
+-----------------------------------------------------------------------+
| 【 区域 E：底部操作区 】                                               |
| [Center]: [取消] [主按钮: 提交申请]                                    |
+-----------------------------------------------------------------------+
```

### 区域说明

**区域 A：弹窗标题区**
- 元素类型：标题文本（"申请权限"）+ 关闭按钮 [X]
- 业务规则：点击关闭按钮等于取消，已填写内容不做自动保存（草稿态处理取决于产品策略）

**区域 B：步骤指示区**
- 元素类型：步骤指示器，三个步骤：选择权限 → 填写原因 → 提交
- 业务规则：步骤指示仅作为流程说明，不控制实际表单分步。用户在一个页面内完成所有填写后一次性提交

**区域 C：可申请权限选择区**
- 搜索框：按权限名称关键词筛选可选项
- 权限项按应用分组展示，每组显示应用名称作为分隔标题
- 每条权限项：checkbox（多选）+ 权限名称 + 简短说明文本
- 已拥有的权限项：灰态显示，checkbox 不可选，鼠标悬停提示"已拥有"
- 超出管理员配置的可申请范围的权限项：不显示

**区域 D：申请原因区**
- 文本域标签："申请原因"
- 文本域 placeholder："请说明为什么需要这些权限..."
- 常用原因快速选择：三个标签按钮，点击后填充对应文本到文本域
  - "工作职责需要"：填充"因工作职责需要，申请开通相关权限"
  - "临时项目参与"：填充"因临时项目需要，申请开通相关权限，项目结束后可回收"
  - "代岗/交接"：填充"因代岗/工作交接需要，申请开通相关权限"

**区域 E：底部操作区**
- [取消]按钮：关闭 Drawer，已填写内容不做自动保存
- [提交申请]主按钮：至少选择一项权限后可点击；不满足时置灰

### 校验阻断态变化

| 校验条件 | 阻断行为 | UI 变化 |
|---------|---------|---------|
| 未选择任何权限 | 阻止提交，提交按钮置灰 | [提交申请]按钮置灰不可点击 |
| 申请原因少于 10 字 | 提交时校验失败，不关闭 Drawer | 文本域下方出现 inline 提示："申请原因至少 10 个字" |
| 所选权限超出可申请范围（防御性校验） | 阻止提交 | Toast："所选权限不在可申请范围内" |
| 审批人配置异常 | 阻止提交 | Toast："审批人配置异常，暂时无法提交，请联系管理员" |
| 网络异常 | 阻止提交 | Toast："提交失败，请稍后重试" |

### 提交成功态

- Drawer 关闭
- "我的权限"页面显示 Toast："申请已提交，等待审批人处理"

### 不合规确认区结构

无不合规确认区（校验失败时使用 inline 提示或 Toast，不需要二次确认弹窗）。

## 6. 申请记录列表（Page / 模块）

### 页面目标

员工查看历史申请记录和当前审批状态。

### 进入条件

员工点击"申请记录"导航入口，或在"我的权限"页面点击"查看申请记录"链接。

```
+-----------------------------------------------------------------------+
| 【 页面标题区 】                                                       |
| [Left]:  申请记录                                                     |
+-----------------------------------------------------------------------+
| 【 筛选区 】                                                           |
| [状态筛选: 全部 v]   [时间范围: 最近三个月 v]                          |

| [申请原因]: 需要创建新的报销模板                                     |
| [处理人]: 张三      [处理时间]: 2026-07-05 14:30                    |
|                                                                       |
| ── 2026-07-03 ─────────────────────────────────────────────            |
```

### 列表字段

| 字段 | 元素类型 | 说明 |
|------|---------|------|
| 按日期分组 | 日期分隔标题 | 按申请提交日期将记录分组显示，如"今天""昨天""2026-07-05" |
| 申请内容 | 文本 | 格式："{应用名} - {权限名}"，可点击进入申请详情 Modal |
| 申请原因 | 文本（截断） | 申请原因摘要，过长时截断 |
| 状态 | 标签 | 类型：审批中（蓝色）、已通过（紫色）、已拒绝（红色）、已生效（绿色）、已撤销（灰色）、已作废（灰色） |
| 处理人 | 文本 | 当前审批人或已处理人姓名 |
| 处理时间 | 文本 | 最新处理时间 |
| 操作 | 按钮 | 审批中→[催办]；已拒绝→[重新申请]；其他→无操作按钮 |

### 关键操作

| 操作 | 触发结果 |
|------|---------|
| 点击申请内容 | 打开申请详情 Modal |
| 点击"催办"按钮 | 发送催办通知给审批人，按钮短暂置灰（防重复点击） |
| 点击"重新申请"按钮 | 打开权限申请 Drawer，预填上次申请的权限项和申请原因 |
| 切换状态筛选 | 按状态过滤申请记录列表 |
| 切换时间范围 | 按时间范围过滤申请记录列表 |

**区域 B：状态标识区**
- 状态标签（颜色同申请记录列表的状态标签）
- 提交时间文本

- 申请人姓名 + 部门/职位（如已提供）
- 申请内容：应用名 - 权限名
- 申请原因：完整展示

**区域 D：处理进度区**
- 按时间倒序展示处理节点
- 节点格式："{时间}  {动作}"
- 当前等待的节点显示"等待审批人处理..."（审批中状态）或"系统处理中..."（已通过状态）

**区域 E：审批信息区**
- 仅已处理（已通过/已拒绝）时显示
- 审批人姓名
- 审批意见：同意时显示审批人填写的意见；拒绝时显示拒绝原因
- 处理时间

**区域 F：授权结果区**
- 仅已生效时显示
- 授权状态文本
- 生效时间

**区域 G：底部操作区**
- [关闭]按钮
- 根据状态动态增加操作按钮：
  - 审批中→[催办]按钮
  - 已拒绝→[重新申请]按钮
  - 已生效→[查看权限]按钮（跳转到"我的权限"页面并定位到对应权限项）

## 8. 管理员自助申请配置（Page / 模块）

### 页面目标

管理员开启/关闭自助申请能力，配置可申请范围和审批流程。

### 进入条件

管理后台 → 通用权限管理 → 自助权限申请（或同级菜单入口）。

### 页面结构

```
+-----------------------------------------------------------------------+
| 【 区域 A：页面标题区 】                                               |
| [Left]:  自助权限申请                                                |
+-----------------------------------------------------------------------+
| 【 区域 B：能力开关区 】                                               |
| [Left]:  允许员工自助申请权限                                          |
|          [开关: 开启/关闭]                                             |
|          {说明文本: 开启后员工可在"我的权限"中发起权限申请}              |
+-----------------------------------------------------------------------+
| 【 区域 C：可申请范围配置区 】                                         |
| [Left]:  可申请的权限范围                                               |
|          {说明文本: 设置员工可以申请哪些权限，超出范围的申请将被拦截}     |
|                                                                       |
| [配置方式]: (o) 按角色配置  ( ) 按功能权限点配置  ( ) 按应用配置    |
|                                                                       |
| [已选范围列表]:                                                        |
| [标签: OA审批 x] [标签: 智能薪酬-薪酬计算 x]                          |
|                                                                       |
| [按钮: 添加范围]                                                       |
+-----------------------------------------------------------------------+
| 【 区域 D：审批流程配置区 】                                           |
| [Left]:  审批流程                                                      |
|          {说明文本: 设置申请提交后由谁审批}                              |
|                                                                       |
| [流程选择]: [下拉框: 请选择审批流程 v]                                  |
| [按钮: 前往审批管理配置新流程]                                         |
| [当前配置的审批人: 李四（技术部主管）]                                  |
+-----------------------------------------------------------------------+
| 【 区域 E：底部操作区 】                                               |
| [Right]: [按钮: 取消] [主按钮: 保存配置]                               |
+-----------------------------------------------------------------------+
```

### 区域说明

**区域 A：页面标题区**
- 标题文本："自助权限申请"

**区域 B：能力开关区**
- 开关标签："允许员工自助申请权限"
- 开关组件：开启/关闭
- 说明文本："开启后员工可在'我的权限'中发起权限申请"
- 状态联动：开关关闭时，区域 C 和区域 D 灰态不可操作，提示"请先开启能力"

**区域 C：可申请范围配置区**
- 配置方式选择：单选按钮组，三种互斥模式
  - "按角色配置"：选择已有角色作为可申请范围
  - "按功能权限点配置"：逐点选择可申请的功能权限
  - "按应用配置"：选择完整应用作为可申请范围
- 已选范围列表：已选范围以标签形式展示，每个标签带删除按钮 [x]
- 添加范围按钮：根据配置方式打开对应的选择器

**区域 D：审批流程配置区**
- 流程选择下拉框：展示已配置的审批流程列表
- 前往审批管理配置新流程：文本链接，跳转到审批中台配置页
- 当前配置的审批人：只读展示当前流程中的审批人信息

**区域 E：底部操作区**
- [取消]按钮：返回上一页，未保存的修改不生效
- [保存配置]主按钮：保存当前所有配置

### 校验阻断态变化

|---------|---------|---------|

| 能力开启但审批流程未配置 | 阻止保存 | 区域 D 出现 inline 提示："请选择审批流程" |

## 9. 主交互流程

### 9.1 员工查看自有权限 → 发起申请

| 步骤 | 用户动作 | 系统反馈 | 下一步 |
|------|---------|---------|--------|
| 1 | 进入"我的权限"页面 | 加载权限数据，展示按应用分组的权限列表；无权限时展示空状态 | — |
| 2 | 点击"申请权限"按钮（全局或行内） | 打开权限申请 Drawer | 进入步骤 3 |
| 3 | 在 Drawer 中浏览可申请权限列表，选择所需权限项（checkbox 多选） | 选中项 checkbox 变为勾选态；已拥有的权限项灰态不可选 | 进入步骤 4 |
| 4 | 填写申请原因（可点击常用原因快速选择） | 文本域显示已填内容 | 进入步骤 5 |
| 5 | 点击"提交申请"按钮 | 执行校验→通过则关闭 Drawer 并显示成功 Toast，推送通知给审批人 | 员工可查看申请记录 |

### 9.2 审批人审查与处理

| 步骤 | 用户动作 | 系统反馈 | 下一步 |
|------|---------|---------|--------|
| 1 | 收到审批通知，进入待办列表 | 待办列表中显示权限申请类待办（增强信息：申请人+权限名+原因） | 进入步骤 2 |
| 2 | 点击待办或进入申请详情 | 展示申请详情（申请人信息、申请权限、申请原因、申请人现有权限简览） | 进入步骤 3 |
| 3 | 点击"同意并授权"或"拒绝" | 点击同意→系统执行自动授权并通知申请人；点击拒绝→要求填写拒绝原因 | 进入步骤 4 |
| 4 | （如拒绝）填写拒绝原因后提交 | Toast 通知提交成功，通知申请人申请已被拒绝 | 流程结束 |

### 9.3 系统自动授权

| 步骤 | 系统动作 | 系统反馈 | 下一步 |
|------|---------|---------|--------|
| 1 | 审批人点击同意后，系统写入权限记录 | 写入成功→更新申请状态为"已生效"→通知员工和审批人；写入失败→标记"授权异常"→通知相关人员 | 成功→员工验证生效；失败→管理员处理异常 |

## 12. 异常恢复

| 异常 | 发生时机 | 阻断行为 | 通知方 | 恢复路径 |
|------|---------|---------|--------|---------|
| 提交时审批人不存在 | 员工提交申请时 | 阻止提交，不产生记录 | 通知管理员补配审批人 | 管理员重新配置审批人后，员工重新提交。原路恢复，无信息丢失 |
| 审批超时 | 申请提交后，审批人未在规定时间内处理 | 不阻断，持续等待 | 系统自动催办审批人；员工可手动催办 | 审批人处理申请后恢复正常流程。如审批人持续不处理，管理员可重新指派审批人后继续流转 |
| 自动授权失败 | 审批人同意后 | 不阻断前端，系统后台标记异常 | 通知员工、审批人、管理员三方 | 管理员手动完成授权后，申请更新为"已生效"。员工需重新验证权限是否生效。有信息丢失：员工需重新验证 |
| 授权部分成功 | 多权限项申请全部审批通过后 | 不阻断，成功项立即生效 | 通知员工成功项和失败项 | 管理员逐项处理失败项。已生效部分不受影响。原路恢复，部分信息丢失 |
| 重复申请 | 选择权限时 | 提交时提示，不自动阻止 | 提示员工 | 员工移除重复项后继续提交。原路恢复，无信息丢失 |
| 关闭能力时存在进行中申请 | 管理员关闭能力时 | 弹窗提示，要求选择策略 | 无（管理员操作中） | 管理员选择策略后确认关闭。策略A：流转继续；策略B：全部作废（通知员工）；策略C：转人工。已生效权限不受影响 |
