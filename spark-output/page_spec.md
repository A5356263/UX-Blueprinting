# 页面生成规格：子管理员复制

## 1. 页面摘要

- **产品领域**：通用权限管理 — 子管理员模式
- **页面类型**：列表页（承载页）、弹窗（主实体）、员工选择弹窗（引用）
- **用户角色**：权限管理员
- **核心任务**：将已有子管理员的权限配置（可授权组织/可授权功能）批量复制给其他用户

---

## 2. 生成范围

### 生成
- 子管理员列表页（承载页，实体 0）— 新增「复制」操作按钮
- 复制弹窗（实体 1）— 新增弹窗，含复制信息选择和复制对象选择

### 只引用不生成
- 员工选择弹窗 — 复用现有「添加子管理员」的员工选择弹窗，仅新增「当前身份」列

### 不生成
- 操作记录列表页 — 已有系统页面，本次仅新增记录条目
- 审批系统页面 — 已有系统页面，本次仅新增审批实例

---

## 3. 页面实体关系

- 子管理员列表页（实体 0）— 承载页，操作列含「复制」入口
- 复制弹窗（实体 1）— 从实体 0 的操作列「复制」点击触发
- 员工选择弹窗（引用）— 从实体 1 的复制对象选择器触发

---

### 校验阻断态变化

| 异常 | 区域变化 | 反馈组件 |
|------|----------|----------|
| 复制内容未选 | 确认按钮不激活 | Toast：「请选择复制信息」 |
| 复制对象未选 | 确认按钮不激活 | Toast：「请选择至少一名复制对象」 |
| 目标用户未加入 | 对应用户 Tag 标红，旁注 Text「未加入」 | Tag(red), InlineError |
| 目标用户未认证 | 对应用户 Tag 标红，旁注 Text「未认证」 | Tag(red), InlineError |
| 多重校验不通过 | 按顺序优先阻断最先不通过的校验，修正后继续下一项 | Toast + InlineError |

### 不合规确认区结构

不涉及不合规确认区（当前为前置校验，校验不通过不执行复制）。

## 6. 主交互流程

### 6.1 定位来源子管理员

- **用户动作**：进入子管理员列表页，搜索或浏览找到作为复制来源的子管理员
- **系统反馈**：列表正常展示
- **下一步**：点击操作列「复制」

### 6.2 打开复制弹窗

- **用户动作**：点击操作列「复制」
- **系统反馈**：打开复制弹窗，复制信息默认全选，复制对象区为空
- **下一步**：勾选复制内容或选择复制对象

### 6.3 选择复制对象

- **用户动作**：点击「选择」→ 在员工选择弹窗中查找并选择用户 → 确认
- **系统反馈**：员工选择弹窗关闭，已选用户以 Tag 展示，标注身份标签
- **下一步**：点击「确认」

### 6.4 确认并提交

- **用户动作**：点击「确认」
- **系统反馈**：四项顺序校验（复制信息→复制对象→加入状态→认证状态），校验通过后执行
- **下一步**：等待结果

### 6.5 校验通过执行（非互审）

- **用户动作**：等待处理
- **系统反馈**：对每个目标写入权限 → Toast「复制成功」→ 弹窗关闭
- **下一步**：在列表或操作记录中确认

### 6.6 校验通过执行（互审）

- **用户动作**：等待处理
- **系统反馈**：生成审批实例 → Toast「已提交审批，等待另一位管理员确认后生效」→ 弹窗关闭
- **下一步**：等待另一位管理员审批

---

## 7. 校验规则

| 规则 | 校验对象 | 条件 | 阻断 | 反馈 |
|------|----------|------|------|------|
| V-01 复制内容必选 | 复制信息区 | 至少勾选一项（可授权组织/可授权功能） | 是 | Toast「请选择复制信息」 |
| V-02 复制对象必选 | 复制对象区 | 至少选择一名目标用户 | 是 | Toast「请选择至少一名复制对象」 |
| V-03 加入状态校验 | 所有目标用户 | 加入状态均为「已加入」 | 是 | Toast「{名单}加入状态不是已加入，不能成为子管理员」+ Tag 标红 |
| V-04 认证状态校验 | 所有目标用户 | 认证状态均为「已认证」 | 是 | Toast「{名单}未完成实名认证，不能成为子管理员」+ Tag 标红 |

校验顺序：V-01 → V-02 → V-03 → V-04。依次执行，命中即阻断，修正后重新校验后续规则。

## 8. 状态表现

| 状态 | 触发条件 | UI 表现 | 文案 key |
|------|----------|---------|----------|
| 复制弹窗打开 | 点击「复制」 | 弹窗打开，复制信息默认全选，复制对象区为空 | copy_modal_title: "复制" |
| 校验中 | 点击「确认」 | 确认按钮变为加载态，不可重复点击 | — |

## 9. 异常恢复

| 异常 | 触发 | UI 表现 | 恢复路径 |
|------|------|---------|----------|
| 复制内容未选 | 点击确认时无勾选 | Toast 阻断，弹窗保留 | 勾选至少一项后重新确认。无信息丢失 |
| 复制对象未选 | 点击确认时无目标 | Toast 阻断，弹窗保留 | 选择至少一名用户后重新确认。无信息丢失 |
| 目标用户未加入 | 校验到未加入用户 | Toast + 对应 Tag 标红「未加入」，弹窗保留 | 移除未加入用户 Tag 后重新确认，或退出弹窗待用户加入后再操作 |
| 目标用户未认证 | 校验到未认证用户 | Toast + 对应 Tag 标红「未认证」，弹窗保留 | 移除未认证用户 Tag 后重新确认，或退出弹窗待用户完成认证后再操作 |
| 多重校验不通过 | 同时命中多个异常 | 按顺序阻断，修正一个后再暴露下一个 | 逐次修改后重新确认。已填信息不丢失 |
| 审批驳回 | 互审管理员拒绝 | 系统通知 | 查看驳回原因，重新发起完整复制流程 |
| 审批超时 | 审批人长期未处理 | 依赖审批系统超时机制 | 联系审批人处理，或视系统能力自行撤回 |

## 10. 结果态

### 10.1 全部成功（非互审）

- **Toast**：「复制成功」（绿色图标）
- **弹窗状态**：关闭
- **操作记录**：写入操作记录（按复制内容分条存储）
- **列表更新**：目标用户的子管理员状态已更新

### 10.2 审批提交成功（互审）

- **Toast**：「已提交审批，等待另一位管理员确认后生效」（蓝色图标）
- **弹窗状态**：关闭
- **操作记录**：写入操作记录
- **列表更新**：来源子管理员姓名旁显示「审批中」标签
