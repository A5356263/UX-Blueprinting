# 页面生成规格：子管理员权限复制

---

## 1. 页面摘要

- **产品领域**：企业权限管理 — 子管理员治理
- **页面类型**：弹窗式批量操作 + 数据列表页
- **用户角色**：权限管理员（超级管理员 / 子管理员）
- **核心任务**：以已有子管理员为模板，将其授权范围复制给其他人员

---

## 2. 生成范围

### 主生成
- 子管理员列表页
- 复制弹窗及其全部状态（就绪 / 校验阻断 / 不合规确认 / 执行中 / 全部成功 / 部分成功 / 系统异常）

### 关联不主生成
- 操作记录页：仅保留复制操作记录的字段说明和文案模板

### 不生成
- 选择员工弹窗内部结构（入口保留，内部复用现有组件）
- 双管理员互审审批页面
- 权限详情页

---

## 3. 页面实体关系

```
子管理员列表页
  → 点击操作列 [按钮：复制]
  → 打开复制弹窗
  → 确认来源 → 选择内容 → 指定目标 → 校验 → 执行
  → 查看结果 → 关闭弹窗
  → 列表刷新
```

---

## 5. 复制弹窗

### 弹窗目标
让管理员确认复制来源、选择复制内容、指定目标人员，完成复制操作并查看结果。

### 区域结构（就绪态）

```
+------------------------------------------------------------------------------------------+
| 【 弹窗标题区 】                                                            [X]           |

| 【 来源信息区 】                                                                          |
| {copy_source}                                                                            |
| {copy_org_all / copy_org_partial}                                                        |
| {copy_func}                                                                              |
+------------------------------------------------------------------------------------------+
| 【 复制信息选择区 】                                                                       |
| {copy_hint}                                                                              |
| [复选框] {checkbox_org}     [复选框] {checkbox_func}                                      |
+------------------------------------------------------------------------------------------+
| 【 复制对象选择区 】                                                                       |

|                                                                                          |

| [标签: 李四 X]  [标签: 王五 X]  [标签: 赵六 (已是子管理员) X] ...                           |
```

### 区域说明

**来源信息区**
- 复制来源：{姓名} / {手机号} — 文本
- 可授权组织摘要 — 文本（全部组织 / 已指定 N 个组织 + 前几个名称）
- 可授权功能摘要 — 文本（电脑端 N 项 / 移动端 M 项）

**复制信息选择区**
- [复选框] 可授权组织（默认选中）
- [复选框] 可授权功能（默认选中）
- 规则：至少保留一项，全部取消时阻断确认

**复制对象选择区**
- [人员选择入口] — 点击打开员工选择弹窗（复用现有），支持搜索多选
- [标签] 已选人员 × N — 每个标签可单独移除
- [标签] 已是子管理员 — 已是子管理员的用户标签旁展示此标记
- 已选计数：已选 {N}/200 人
- 规则：最多选择 200 人，超出时阻止添加

**底部操作区**
- [按钮：取消] — 关闭弹窗，不保存选择
- [按钮：确认] — 触发校验流程

### 校验阻断态变化

**未选复制信息**：复制信息区下方出现红色 inline `{copy_content_empty}`，弹窗不关闭

**未选复制对象**：复制对象选择区下方出现红色 inline `{copy_target_empty}`，弹窗不关闭

### 不合规确认区（底部操作区上方插入）

```
+------------------------------------------------------------------------------------------+
| 【 校验不合规确认区 】                                                                     |
| ⚠ {invalid_user_partial}                                                                |
|                                                                                          |
| 赵六 — {invalid_join_status}                                                              |
| 钱七 — {invalid_auth}                                                                    |
| 孙八 — {invalid_join_status}                                                              |
|                                                                                          |

+------------------------------------------------------------------------------------------+
```

## 6. 主交互流程

1. 在列表页点击 [按钮：复制] → 打开弹窗，加载来源子管理员授权摘要，默认全选两个复选框
2. 查看来源摘要，确认或调整复制信息勾选 → 复选框独立切换，取消最后一项时阻断
3. 通过人员选择入口搜索并选择目标用户 → 已选标签展示，超 200 人阻止添加 → 点击 [按钮：确认]
4. 系统按顺序校验：
   - 校验复制信息（至少 1 项）→ 不过则 inline 阻断
   - 校验复制对象（至少 1 人）→ 不过则 inline 阻断
   - 校验加入状态 → 部分不合规则展示确认区
   - 校验认证状态 → 与上一步合并展示
5. 确认跳过不合规者后执行复制，弹窗进入执行中状态
6. 执行完成，弹窗展示结果态（全部成功 / 部分成功）
7. 点击 [按钮：关闭]，弹窗关闭，列表刷新

---

## 7. 校验规则

- **校验步骤 1**：复制信息
  - 条件：可授权组织或可授权功能至少 1 项选中
  - 通过 → 进入步骤 2
  - 不通过 → 阻断，inline 红字 `{copy_content_empty}`，弹窗不关闭

- **校验步骤 2**：复制对象
  - 条件：已选目标用户 ≥ 1 人
  - 通过 → 进入步骤 3
  - 不通过 → 阻断，inline 红字 `{copy_target_empty}`，弹窗不关闭

- **校验步骤 3**：加入状态
  - 条件：遍历目标用户，加入状态为"已加入"
  - 全部通过 → 进入步骤 4
  - 部分不通过 → 展示不合规确认区，按钮 `{btn_skip_continue}` / `{btn_cancel}`
  - 全部不通过 → 展示不合规确认区，按钮 `{btn_got_it}`，不执行

- **校验步骤 4**：认证状态
  - 条件：对通过步骤 3 的用户校验实名认证
  - 全部通过 → 执行复制
  - 部分不通过 → 合并到不合规确认区（同步骤 3 部分不通过）

## 9. 异常恢复

- **复制信息未勾选**
  - 触发：确认时两项均未勾选
  - 反馈：inline 红字 `{copy_content_empty}`，弹窗不关闭
  - 恢复：勾选至少一项后重新确认

- **复制对象未选择**
  - 触发：确认时未选择目标用户
  - 反馈：inline 红字 `{copy_target_empty}`，弹窗不关闭
  - 恢复：选择目标用户后重新确认

- **加入状态不符**
  - 触发：目标用户加入状态非"已加入"
  - 反馈：不合规确认区展示姓名 + `{invalid_join_status}`
  - 恢复：跳过不合规者继续，或取消后手动移除

- **认证状态不符**
  - 触发：目标用户未完成实名认证
  - 反馈：不合规确认区展示姓名 + `{invalid_auth}`
  - 恢复：同上

- **全部不合规**
  - 触发：所有目标均不满足条件
  - 反馈：不合规确认区，仅 `{btn_got_it}`
  - 恢复：更换目标用户或处理人员状态

- **超出人数上限**
  - 触发：已选 200 人后继续添加
  - 反馈：选择器阻止添加，提示 `{selector_max}`
  - 恢复：移除部分人员后继续

- **系统执行异常**
  - 触发：网络或服务端异常导致复制中断
  - 反馈：弹窗内 `{system_error}`
  - 恢复：关闭弹窗，查看操作记录确认已执行情况

- **双管理员互审审批阻塞**
  - 触发：开启双管理员互审，审批流程中
  - 注：生效时机和反馈形式待确认，不参与本次生成

## 10. 结果态

### 10.1 全部成功
- 触发条件：所有合规目标均复制成功
- 页面变化：弹窗主体替换为结果区，隐藏配置区和操作区
- 展示内容：
  - 成功图标
  - `{copy_success_title}`
  - `{copy_success_summary}`
  - 双管理员互审提示（如开启）：`{audit_approval_hint}`
  - [按钮：{btn_close}]
- 关闭弹窗后：toast `{copy_success_toast}`，列表刷新

### 10.2 部分成功
- 触发条件：部分目标复制成功，部分因状态或认证问题被跳过
- 页面变化：弹窗主体替换为结果区，额外展示跳过明细
- 展示内容：
  - `{copy_partial_title}`
  - `{copy_partial_summary}`
  - 跳过明细表：列头 `{skip_detail_header}`，每行 {姓名} — {原因}
  - 双管理员互审提示（如开启）：`{audit_approval_hint}`
  - [按钮：{btn_close}]
- 关闭弹窗后：toast `{copy_partial_toast}`，列表刷新

## 12. 关联：操作记录页

不作为主生成页面。仅保留复制操作需记录的业务字段和文案：

### 记录字段
- 操作时间、操作人
- 操作类型（复制-可授权组织 / 复制-可授权功能 / 复制-全部权限）
- 复制来源（姓名 / 手机号）
- 目标人员

- 跳过原因（部分成功时）

### 操作内容文案

| key | 文案 |
|-----|------|
| audit_content_success | 将子管理员【{姓名}/{手机号}】{复制内容}复制给【{目标}】...，成功 {N} 人 |
