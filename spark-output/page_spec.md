# 页面生成规格：员工自助申请权限

## 1. 页面摘要
- **产品领域**：权限管理 — 权限治理模式扩展（自助申请）
- **页面类型**：配置页（分步向导）、列表页、抽屉、弹窗
- **用户角色**：超级管理员（超管）、普通员工、审批人（组织负责人）
- **核心任务**：超管配置自助申请模式 → 员工查看/申请权限 → 审批人处理申请

---

## 2. 生成范围
### 生成
- 自助申请模式配置页（超管端）
- 关闭模式二次确认弹窗
- 我的权限页面（员工端）
- 申请权限抽屉（员工端）
- 申请记录列表
- 撤销申请确认弹窗

### 只引用不生成
- 权限管理模式页 — 承载页面，提供自助申请模式的入口卡片和上下文，结构来自知识库页面载体语义
- 个人中心 — 系统级页面，提供"我的权限"入口，不参与本次任务闭环
- OA审批详情页/待办卡片 — 外部OA系统页面，审批人处理申请的承载页面

### 不生成
无。所有参与当前任务闭环的实体均已覆盖。

## 3. 页面实体关系
- `权限管理模式页` → 点击自助申请模式卡片 [立即启用] → `自助申请模式配置页`
- `自助申请模式配置页`（已开启状态）→ 点击 [关闭模式] → `关闭模式二次确认弹窗`
- `个人中心` → 点击 [我的权限] → `我的权限页面（员工端）`
- `我的权限页面（员工端）` → 点击 [申请权限] → `申请权限抽屉（员工端）`
- `我的权限页面（员工端）` → 切换到"申请记录"tab → `申请记录列表`
- `申请记录列表`（审批中记录）→ 点击 [撤销] → `撤销申请确认弹窗`

## 6. 关闭模式二次确认弹窗

### 弹窗目标
确认超管是否要关闭自助申请模式，并告知关闭后果。

### 区域结构

```
+-------------------------------------------------------------------+
| 关闭模式                                                     [X]  |
+-------------------------------------------------------------------+
|                                                                   |
| 关闭模式后，员工将无法自助查询和申请权限，已有权限不受影响，       |
| 当前未完成的申请将继续流转。请确认是否关闭自助申请模式？           |
|                                                                   |
|                               [不关闭]          [确认关闭]          |
+-------------------------------------------------------------------+
```

### 校验阻断态变化

当点击 [确认关闭] 但存在在途申请流程时，弹窗切换为关闭失败状态：

```
+-------------------------------------------------------------------+
| 关闭失败                                                     [X]  |
+-------------------------------------------------------------------+
|                                                                   |
| 当前有申请流程未完成审批，请联系审批人审批完成，再关闭模式。       |
|                                                                   |
|                                              [知道了]               |
+-------------------------------------------------------------------+
```

### 区域说明
- **标题区**：标题文字 + 关闭按钮
- **文案区**：关闭后果说明
- **操作区**：不关闭（取消）、确认关闭（提交）；失败态切换为"知道了"

### 区域说明
- **标题区**：标题"申请权限" + 关闭按钮
- **申请人信息区**：显示当前用户姓名（不可编辑，灰色背景）
- **申请原因区**：必填输入框，placeholder"请填写申请原因"，最多 500 字，下方显示字数限制提示
- **申请内容区**：根据超管配置动态渲染
  - 申请角色模式：可勾选的角色列表（复选框 + 角色名称 + 角色说明），角色范围限管理端设置的已启用角色

- **底部操作栏**：提交（主按钮）、取消

### 校验阻断态变化

| 错误场景 | 反馈位置 | 反馈内容 |
|---------|---------|---------|

## 11. 主交互流程

### P1：超管配置自助申请模式

1. 权限管理模式页 → 超管看到自助申请权限模式卡片
2. 超管点击 [立即启用]
3. 系统校验互斥模式（双管理员互审/权限变更审批是否已开启）
   - 异常：已开启 → 弹窗提示"无法启用"，阻止进入配置页
4. 校验通过 → 进入自助申请模式配置页（第一步）
5. 超管在对比卡片中选择申请方式（默认"申请角色"）→ 点击 [下一步]
6. 进入第二步—设置范围
   - 申请角色模式：选择全部角色/部分角色
   - 申请功能权限模式：选择全部应用/部分应用
   - 选择"部分"时打开对应选择弹窗
7. 超管点击 [下一步] → 进入第三步—审批流程
8. 超管查看预设审批流程，可选 [修改审批流程]
9. 超管点击 [启用]
10. 系统再次校验互斥模式
11. 校验通过 → Toast "开启成功" → 个人中心增加"我的权限"入口 → 页面刷新为已开启状态

### P2：员工查看权限并发起申请

1. 个人中心 → 员工点击 [我的权限]
2. 进入我的权限页面（默认功能权限 Tab）
3. 员工浏览当前权限
4. 点击右上角 [申请权限] → 打开申请权限 Drawer
5. 员工查看可申请的角色/功能 → 选择目标 → 填写申请原因
6. 点击 [提交申请]
7. 前端校验（原因必填、至少选择一项）
8. 后端校验（资金用户/子管理员/实名）
9. 校验通过 → 提交 OA 审批 → Drawer 关闭 → Toast "提交成功" → 申请记录新增"审批中"记录
   - 异常 E4（校验失败）→ Drawer 不关闭，显示对应错误提示
   - 异常 E2（审批人缺失）→ 申请单标记为"审批人待指定"

### P3：审批人处理权限申请

1. 审批人在 OA 待办列表中看到权限申请待办卡片
2. 点击待办 → 打开审批详情页
3. 查看申请人信息、申请内容、申请原因
4. 点击 [同意] 或 [拒绝]
   - 拒绝 → 必须填写拒绝理由
5. 确认提交
6. 同意 → 系统自动分配权限 → 申请人收到通知
   - 异常 E5（分配失败）→ 通知超管人工处理
7. 拒绝 → 申请人收到拒绝理由

### 次流程

**S1：超管编辑已开启的模式**
- 超管在已开启状态页点击 [编辑] → 页面变为可编辑 → 底部出现 [取消编辑] [确认编辑]
- 修改后点击 [确认编辑] → Toast "编辑成功" → 回到只读状态
- 不影响已在途申请

**S2：超管关闭自助申请模式**
- 超管点击 [关闭模式] → 弹出二次确认弹窗
- 确认关闭 → 校验在途流程
- 无在途 → Toast 关闭成功
- 有在途 → 弹窗提示关闭失败

**S3：员工撤销申请**
- 员工在申请记录列表中点击 [撤销]（仅审批中状态）
- 弹出确认弹窗 → 确认撤销 → Toast "已撤销" → 审批人收到通知

**S4：员工查看申请记录**
- 员工进入申请记录列表 → 可按日期和状态筛选 → 查看申请记录

## 12. 校验规则

| 触发时机 | 校验内容 | 阻断条件 | 失败反馈 |
|---------|---------|---------|---------|

| 超管点击"确认编辑" | 互斥模式校验 | 配置过程中互斥模式被外部开启 | 弹窗提示 |
| 超管点击"确认关闭" | 在途审批流程校验 | 存在未完成审批的申请 | 弹窗提示关闭失败 |

## 14. 异常恢复

| 异常 | 场景 | 反馈 | 恢复路径 | 信息丢失 |
|------|------|------|---------|---------|
| E1 | 互斥模式已开启，阻止启用 | 居中弹窗"无法启用" | 关闭互斥模式后重新操作 | 无信息丢失 |
| E2 | 审批人缺失（组织无负责人） | 系统递归查找上级 → 到顶层仍无 → 标记"审批人待指定"，通知超管 | 超管手动指定审批人，申请继续流转 | 已填信息不丢失 |
| E3 | 审批人等于申请人本人 | 系统自动跳过，递归到上级组织负责人 | 自动降级，无需干预 | 无感知 |
| E4 | 申请校验失败（资金用户/子管理员/实名） | Drawer 内 InlineError 或提示 | 修正后重新提交 | Drawer 不关闭，已填信息不丢失 |
| E5 | 审批通过但权限分配失败 | 状态更新为"已通过（分配异常）"；通知超管 | 超管人工分配权限 | 审批结果不丢失 |
| E6 | 申请提交后角色/应用被停用 | 审批人打开时看到提示 | 审批人拒绝，员工重新申请 | 申请历史保留 |
| E7 | 已停用角色展示 | 展示层过滤，不展示已停用角色 | 选择其他已启用角色 | 无 |

## 15. 结果态

### 15.1 全部成功
- 超管启用模式：Toast "开启成功"，页面刷新为已开启状态，个人中心新增"我的权限"入口

### 15.2 部分成功

- 申请原因超长：前端截断至 500 字（前端已限制，不涉及部分成功）
- 角色列表中部分角色已停用：已停用角色在列表过滤不展示，不影响其他角色选择
