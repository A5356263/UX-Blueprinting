# 页面生成规格：子管理员配置复制

## 1. 页面摘要

- **产品领域**：企业权限管理 — 子管理员治理
- **页面类型**：列表页、弹窗（Modal）、详情编辑页
- **用户角色**：超级管理员 / 权限管理员
- **核心任务**：将已有子管理员的配置（可授权组织 + 可授权功能）复制给目标用户

---

## 2. 生成范围

### 生成
- 子管理配置页（列表）— 父页面，展示子管理员列表和复制入口
- 复制弹窗 — 核心功能实体，包含编辑态、结果汇总态、审批提交态
- 子管理员编辑详情页 — 承载叠加配置来源展示

### 只引用不生成
- 员工选择弹窗 — 复用现有组件，仅标注引用关系
- 审批管理页 — 已有系统能力，仅跳转引用

### 不生成
- 操作记录详情页 — 蓝图仅规范记录内容，未给出页面结构

---

## 3. 页面实体关系

| 实体 | 类型 | 关系 |
|------|------|------|
| 子管理配置页（列表） | Page（承载页） | 顶级页面，有独立菜单入口 |
| 复制弹窗 | Modal | 通过子管理配置页操作列「复制」按钮触发 |
| 员工选择弹窗 | Modal | 通过复制弹窗「选择员工」触发，引用现有组件 |
| 子管理员编辑详情页 | Page | 通过子管理配置页操作列「编辑」按钮跳转 |
| 审批管理页 | Page | 通过复制弹窗审批提交态「查看审批进度」链接跳转 |

---

## 4. 子管理配置页（列表）

### 页面目标

展示所有子管理员列表，支持新建、编辑、复制、删除等操作。

### 页面结构（ASCII 线框 + 区域说明）

```
┌──────────────────────────────────────────────────────────┐
│  [A] 权限管理模式  >  子管理员配置                        │
│                                                          │
│  [B] [+ 添加子管理员]                   搜索框 [   ]      │
│                                                          │
│  [C] ┌────┬────────┬──────────┬──────────┬────────┬────┐ │
│      │ 姓名 │ 手机号 │ 可授权功能 │ 可授权组织 │ 来源标记 │操作│ │
│      ├────┼────────┼──────────┼──────────┼────────┼────┤ │
│      │{姓名}│{手机号}│ {N} 项   │ {N} 个部门 │{来源} │复制│ │
│      │{姓名}│{手机号}│ {N} 项   │ {N} 个部门 │{来源} │编辑│ │
│      └────┴────────┴──────────┴──────────┴────────┴────┘ │
│                                                          │
│  [D] 共 {总数} 个                         < 1  2  3 ... > │
└──────────────────────────────────────────────────────────┘
```

**区域说明：**

| 区域 | 内容 | 语义组件 |
|------|------|----------|
| A 导航区域 | 面包屑导航：权限管理模式 > 子管理员配置 | Breadcrumb |
| B 操作栏 | 「+ 添加子管理员」按钮 + 搜索输入框 | Button, Input |
| C 列表区域 | 表格：姓名、手机号、可授权功能、可授权组织、来源标记、操作 | Table |
| D 分页区域 | 总条数 + 分页器 | Pagination |

### 列表字段

| 字段 | 含义 | 来源 |
|------|------|------|
| 姓名 | 子管理员姓名 | 系统用户数据 |
| 手机号 | 子管理员手机号（脱敏显示） | 系统用户数据 |
| 可授权功能 | 该子管理员可授权的功能数量摘要 | 配置数据 |
| 可授权组织 | 该子管理员可管辖的组织数量摘要 | 配置数据 |
| 来源标记 | 手动创建 / 复制自 {来源姓名} / 待审批 | 配置来源记录 |

### 关键操作

| 操作 | 触发方式 | 结果 |
|------|----------|------|
| 添加子管理员 | 点击「+ 添加子管理员」按钮 | 打开新增子管理员弹窗 |
| 复制 | 点击行操作「复制」按钮（操作列最左侧） | 打开复制弹窗 |
| 编辑 | 点击行操作「编辑」按钮 | 跳转子管理员编辑详情页 |

### 提取备注

- 承载页面为顶级页面，无需额外父页面查找
- 列表审批中标记：当子管理员处于双管理员审批状态时，来源标记显示「待审批」

## 5. 复制弹窗

### 弹窗目标

超管选择复制内容和目标，执行复制操作。

### 区域结构（ASCII 框图 + 区域编号说明）

**编辑态：**

```
┌──────────────────────────────────────────────────┐
│  [A] 复制子管理员配置                       [×]  │
│                                                  │
│  [B] ━━━ 复制信息 ━━━                            │
│      ☑ 可授权组织    —— 从 {来源姓名} 复制       │
│      ☑ 可授权功能    —— 从 {来源姓名} 复制       │
│                                                  │
│  [C] ━━━ 复制对象 ━━━                            │
│      [选择员工 >]   已选 {N} 人                   │
│      {姓名}  {手机号}                            │
│      {姓名}  {手机号}                            │
│      ...                                         │
│                                                  │
│  ────────────────────────────────────────         │
│  [D]                     [取消]  [确认]           │
└──────────────────────────────────────────────────┘
```

| 区域 | 内容 | 语义组件 |
|------|------|----------|
| A 弹窗标题区 | 标题「复制子管理员配置」+ 关闭按钮 | Modal.Header, Button(close) |
| B 复制信息区 | 两个复选框：可授权组织、可授权功能，带来源说明 | CheckboxGroup, Text |
| C 复制对象区 | 「选择员工」按钮 + 已选数量 + 已选人员列表 | Button, List, Tag |
| D 底部操作栏 | 取消按钮 + 确认按钮 | Button(cancel), Button(primary) |

**结果汇总态（部分成功）：**

```
┌──────────────────────────────────────────────────┐
│  [A] 复制子管理员配置                       [×]  │
│                                                  │
│  [E] 复制完成（{成功数}/{总数}）                  │
│                                                  │
│  [F] ━━━ 复制成功 ━━━                            │
│      {姓名}  {手机号}  ✓                         │
│      {姓名}  {手机号}  ✓                         │
│                                                  │
│  [G] ━━━ 复制失败 ━━━                            │
│      {姓名}  {手机号}  {失败原因}                │
│      {姓名}  {手机号}  {失败原因}                │
│                                                  │
│  ────────────────────────────────────────         │
│  [H]    [重新复制失败项]  [关闭]                  │
└──────────────────────────────────────────────────┘
```

**审批提交态（双管理员模式）：**

```
┌──────────────────────────────────────────────────┐
│  [A] 复制子管理员配置                       [×]  │
│                                                  │
│  [I] 已提交审批                                   │
│      复制操作已提交，等待另一位管理员审批后生效。  │
│                                                  │
│      复制内容：可授权组织、可授权功能              │
│      复制对象：{姓名}、{姓名}（共 {N} 人）        │
│                                                  │
│      [查看审批进度]                               │
│                                                  │
│  ────────────────────────────────────────         │
│  [D]                                 [关闭]      │
└──────────────────────────────────────────────────┘
```

### 区域说明

**编辑态区域（弹窗默认展示）：**

| 区域 | 用途 | 包含 |
|------|------|------|
| A 弹窗标题 | 标识弹窗功能 | Text：「复制子管理员配置」；Button：[×] 关闭 |
| B 复制信息 | 选择复制内容，来源预填 | Checkbox：「可授权组织」「可授权功能」，默认全选；Text：「从 {来源姓名} 复制」 |
| C 复制对象 | 选择并展示目标用户 | Button：「选择员工 >」；Text：「已选 {N} 人」；List：已选用户（姓名 + 手机号） |
| D 底部操作 | 执行或放弃操作 | Button：「取消」（关闭弹窗不作操作）；Button：「确认」（触发校验和执行） |

**结果汇总态区域（校验执行后切换）：**

| 区域 | 用途 | 包含 |
|------|------|------|
| E 结果标题 | 展示汇总结果 | Text：「复制完成（{成功数}/{总数}）」或「复制失败」 |
| F 成功列表 | 展示复制成功的用户 | List：姓名 + 手机号 + ✓ 标记 |
| G 失败列表 | 展示复制失败的用户及原因 | List：姓名 + 手机号 + 失败原因文本 |
| H 底部操作 | 重试或关闭 | Button：「重新复制失败项」；Button：「关闭」 |

**审批提交态区域（双管理员模式）：**

| 区域 | 用途 | 包含 |
|------|------|------|
| I 审批状态 | 告知超管已提交审批 | Text：「已提交审批」+ 说明文字；Text：复制内容摘要、复制对象摘要；Link：「查看审批进度」 |

### 校验阻断态变化

| 阻断条件 | 弹窗状态变化 | 用户操作 |
|----------|-------------|----------|
| 复制信息未勾选 | 区域 B 下方出现 InlineError；确认按钮不可点击 | 勾选一项后恢复 |
| 复制对象未选择 | 区域 C 下方出现 InlineError；确认按钮不可点击 | 选择目标后恢复 |
| 复制中 | 确认按钮变为 Loading 态 | 等待完成 |

### 不合规确认区结构

批量部分失败时，结果汇总态中的「重新复制失败项」按钮触发仅对失败项重新执行校验和复制，成功项不受影响。弹窗展示更新后的结果汇总。

## 6. 主交互流程

| 步骤 | 触发 | 用户动作 | 系统响应 | 状态变化 | 下一步 |
|------|------|----------|----------|----------|--------|
| 1 | 超管进入子管理配置页 | 导航到权限管理→子管理配置页 | 展示子管理员列表（加载态→正常态/空态） | 列表加载完成 | 定位来源子管理员 |
| 2 | 点击操作列「复制」 | 点击某子管理员行的「复制」按钮 | 打开复制弹窗（编辑态），复制信息默认全选 | 弹窗打开 | 选择复制内容和目标 |
| 3 | 弹窗打开 | 勾选要复制的选项（可授权组织/可授权功能） | 勾选框响应选择；如取消全选，确认按钮保持可用（至少一项即可） | 复制内容确定 | 选择目标用户 |
| 4 | 点击「选择员工」 | 点击选择员工按钮 | 打开员工选择弹窗（引用现有组件） | 子弹窗打开 | 在员工弹窗中选择用户 |
| 5 | 员工弹窗确认 | 选择用户后点击确认 | 员工弹窗关闭，已选用户出现在复制弹窗的复制对象区 | 目标列表更新 | 点击确认执行复制 |
| 6 | 点击「确认」 | 点击确认按钮 | 触发顺序校验：复制信息→复制对象→加入状态→认证状态；校验通过后执行复制写入 | 弹窗编辑态→结果汇总态/审批提交态 | 查看结果 |
| 7 | 复制完成 | 查看结果汇总 | 全部成功→Toast+关闭；部分成功→结果汇总态；全部失败→结果汇总态；双管理员→审批提交态 | 弹窗切换 | 根据结果操作（重试/关闭/查看审批） |

## 7. 校验规则

| 规则 | 校验对象 | 条件 | 阻断 | 提示文案 |
|------|----------|------|------|----------|
| R01 | 复制信息 | 至少选择一项（可授权组织/可授权功能） | 是 | "请选择复制信息" |
| R02 | 复制对象 | 至少选择一名用户 | 是 | "请选择至少一名复制对象" |
| R03 | 目标加入状态 | 每个目标用户的加入状态为已加入 | 否（标记失败，继续处理其他目标） | "{姓名} 加入状态不是已加入，不能成为子管理员" |
| R04 | 目标认证状态 | 每个目标用户的认证状态为已认证 | 否（标记失败，继续处理其他目标） | "{姓名} 未完成实名认证，不能成为子管理员" |

校验顺序：R01 → R02 → R03（逐个目标） → R04（逐个目标）。上一步未通过则不进入下一步。

## 8. 状态表现

| 状态 | 触发条件 | UI 表现 | 文案 key |
|------|----------|---------|----------|
| 复制前（待操作） | 弹窗打开，编辑态就绪 | 弹窗展示编辑态，确认按钮可用 | — |
| 复制中（执行中） | 点击确认，校验通过 | 确认按钮 Loading 态 | "正在复制…" |
| 全部成功 | 所有目标复制成功 | Toast 提示，弹窗关闭 | "复制成功" |
| 部分成功 | 部分目标成功，部分失败 | 弹窗切换为结果汇总态（成功列表 + 失败列表） | "复制完成（{成功数}/{总数}）" |
| 全部失败 | 所有目标复制失败 | 弹窗切换为结果汇总态（全部失败列表） | "复制失败" |
| 审批中 | 双管理员模式下复制完成 | 弹窗切换为审批提交态 | "已提交审批" |
| 审批通过 | 审批通过，结果生效 | 审批管理页状态更新 | — |
| 审批驳回 | 审批未通过 | 审批管理页展示驳回原因 | — |

## 9. 异常恢复

| 异常 | 触发 | UI 表现 | 恢复路径 |
|------|------|---------|----------|
| 复制信息未选择 | 点击确认时未勾选 | 复制信息区下方 InlineError | 勾选一项后确认按钮恢复可点击，原路恢复，无信息丢失 |
| 复制对象未选择 | 点击确认时未选目标 | 复制对象区下方 InlineError | 选择目标后确认按钮恢复可点击，原路恢复，无信息丢失 |
| 目标加入状态异常 | 校验阶段检测到 | 该目标标记失败，继续处理其他目标 | 用户完成加入后通过「重新复制失败项」重试；或更换目标。已成功不受影响 |
| 目标认证状态异常 | 校验阶段检测到 | 该目标标记失败，继续处理其他目标 | 用户完成认证后通过「重新复制失败项」重试。已成功不受影响 |
| 全部目标状态异常 | 所有目标均校验失败 | 弹窗切换为结果汇总态，列出全部失败原因 | 关闭弹窗，解决问题后重新选择目标执行复制 |
| 复制来源异常 | 触发复制操作时 | Toast 提示来源异常，弹窗不打开 | 选择其他正常子管理员作为来源 |
| 批量复制超限 | 已选 200 人继续添加 | 选择器阻止添加，已选计数展示 200/200 | 移除部分目标后再添加，或分批操作 |
