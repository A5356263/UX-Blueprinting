# 页面生成规格：财富小助Skill广场

## 1. 页面摘要

- **产品领域**：企业财富+ — Skill 资产管理与分发
- **页面类型**：列表页 / 详情页 / 编辑页 / 弹窗 / 联想面板
- **用户角色**：Skill 创建者（总分行产品经理、开发人员）、分行普通用户与客户经理、总行管理者
- **核心任务**：创建、共享、浏览、订阅并调用 AI 提示词模板（Skill）

---

### 生成

- 财富小助对话 Page：属于独立外部应用（财富小助），蓝图仅引用其输入框作为联想面板的触发入口；当前任务可在联想面板操作结果处结束，无需在财富小助对话页界面内继续执行。

### 不生成

- 无

## 3. 页面实体关系

- 承载页面：Skill 广场 Page ── Tab ── 我的 Skill 视图

## 4. Skill 广场 Page（承载页面 / 实体 0）

### 页面目标

帮助用户发现全行已共享 Skill，判断来源、适用范围和本分行/个人状态，并完成查看、复制、分行开通或恢复使用。通过 Tab 切换进入"我的 Skill"管理个人创建的 Skill。

### 进入条件

用户已登录并拥有 Skill 广场查看权限。

```
+----------------------------------------------------------------------------------+
| 企业财富 · Skill 广场                                      [发布 Skill]          |
| 发现全行共享的 Skill；开通按分行生效，个人可按需停用                              |
+----------------------------------------------------------------------------------+
| [Tab: Skill共享广场 | 我的 Skill]                                                |
+----------------------------------------------------------------------------------+
| [搜索 {Skill名称}] [所属分行 v] [分行状态 v] [排序 v] [重置]                     |
+----------------------------------------------------------------------------------+
| {结果数} 个共享 Skill                                         {加载/刷新状态}     |
| +------------------------------+  +------------------------------+                |
| | {Skill名称}      [来源标签]   |  | {Skill名称}      [来源标签]   |              |
| | {Skill描述}                   |  | {Skill描述}                   |              |
| | 发布：{创建者}/{所属分行}     |  | 发布：{创建者}/{所属分行}     |              |
| | {订阅分行数}个分行已开通      |  | {订阅分行数}个分行已开通      |              |
| | [状态：本分行未开通]          |  | [状态：本分行已开通·我已停用] |              |
| | [查看详情] [复制] [为分行开通]|  | [查看详情] [复制] [恢复使用]  |              |
| +------------------------------+  +------------------------------+               |
|                                                                                  |
| [EmptyState: 暂无匹配 Skill] [清空筛选]                                           |
+----------------------------------------------------------------------------------+
| < 1 2 3 ... >                                                                    |
+----------------------------------------------------------------------------------+
```

### 区域说明

- **页面标题区**：Text："企业财富 · Skill 广场"；Button：[发布 Skill]
- **引导描述区**：Text："发现全行共享的 Skill；开通按分行生效，个人可按需停用"
- **Tab 切换区**：Tabs：[Skill共享广场] [我的 Skill]
- **筛选区**：Input：[搜索 {Skill名称}]；Select：[所属分行 v]；Select：[分行状态 v]；Select：[排序 v]；Button：[重置]
- **列表区**：List 含 N 个 Card，每 Card 展示：Text：{Skill名称}、Tag：[来源标签]、Text：{Skill描述}、Text："发布：{创建者}/{所属分行}"、Text："{订阅分行数}个分行已开通"、Text：[状态]、Button：[查看详情] [复制] [为分行开通/恢复使用]
- **分页区**：Pagination

### 关键状态

| 卡片状态 | 触发条件 | UI 表现 |
|---------|---------|--------|
| 本分行未开通 | 当前分行尚未订阅该 Skill | 显示"本分行未开通"，按钮"[为分行开通]" |

## 6. 创建方式 Dialog（实体 2）

### 弹窗目标

在不增加多余步骤的前提下选择创建起点。

### 触发条件

点击"发布 Skill"按钮（位于广场 Page 或我的 Skill 视图右上角）。

### 区域结构（ASCII）

```
+--------------------------------------------------------------+
| 创建 Skill                                              [×] |
+--------------------------------------------------------------+
| 选择一种创建方式                                             |
| +------------------------+  +------------------------------+ |
| | 手动创建               |  | 上传 Markdown               | |
| | 使用编写模板开始       |  | 解析文件后进入编辑页         | |
| | [选择]                 |  | [.md，不超过1MB] [选择文件]  | |
| +------------------------+  +------------------------------+ |
| 新 Skill 默认仅你可见，保存后可再共享到广场                  |
+--------------------------------------------------------------+
|                                              [取消]          |
+--------------------------------------------------------------+
```

### 区域说明

- **标题区**：Text："创建 Skill"；Button：[×]
- **选项区**：Card "手动创建"含 Text："使用编写模板开始"、Button：[选择]；Card "上传 Markdown"含 Text："解析文件后进入编辑页"、Text："[.md，不超过1MB]"、FileUpload：[选择文件]
- **提示区**：Text："新 Skill 默认仅你可见，保存后可再共享到广场"
- **底部操作区**：Button：[取消]

### 校验阻断态变化

| 异常 | 触发条件 | UI 变化 |
|------|---------|--------|
| 文件格式错误 | 上传非 .md 文件 | 上传卡片内 InlineError，弹窗不关闭 |
| 文件过大 | 文件超过 1MB | 上传卡片内 InlineError，弹窗不关闭 |

### 提取备注

- 知识库未找到企业财富+更底层的弹窗载体定义，结构来自体验蓝图 §6.3。

### 文件解析规则（HF-010 补漏）

上传 Markdown 文件后：
- Skill 名称：从文件名提取（可在编辑页修改）
- Skill 描述：从文件第一段提取（可修改，最长 200 字符）
- 提示词内容：文件全部内容

## 8. Skill 详情 Page（实体 4）

### 页面目标

解释 Skill 的归属、共享、分行开通、个人使用和运行版本，并承接管理、复制、版本及评分任务。

### 进入条件

用户对 Skill 可见（从广场卡片或我的 Skill 卡片点击"查看详情"）；总行管理者可进入全部 Skill。

### 页面结构（ASCII）

```
+----------------------------------------------------------------------------------+
| < 返回  {Skill名称} [已共享/未共享] [可使用/正在准备]                             |
| {Skill描述}                                                                       |
| 创建者 {创建者} · 所属分行 {所属分行} · 当前版本 {版本号} · {订阅分行数}分行开通  |
| 状态：{本分行未开通/本分行已开通·我正在使用/本分行已开通·我已停用}               |
| [编辑*] [共享/取消共享*] [为分行开通/停用我的使用/恢复使用] [复制] [...]           |
+----------------------------------------------------------------------------------+
| [Banner: {正在准备使用/上一版本仍可用/准备失败及下一步}]                           |
+----------------------------------------------------------------------------------+
| [Skill详情] [版本记录] [Skill评分**]                                               |
|                                                                                  |
| {当前Tab内容：提示词内容 / 版本列表与内容 / 对应版本评分}                          |
|                                                                                  |
| 版本记录：{版本号} {更新时间} {操作者} {运行状态} [查看] [还原为新版本*]           |
+----------------------------------------------------------------------------------+
| * 仅创建者或总行管理者；** 仅所属分行用户或总行管理者                             |
+----------------------------------------------------------------------------------+
```

### 区域说明

- **导航区**：Link：[< 返回]；Text：{Skill名称}；Tag：[已共享/未共享]；Tag：[可使用/正在准备]
- **元数据区**：Text：{Skill描述}；Text："创建者 {创建者} · 所属分行 {所属分行} · 当前版本 {版本号} · {订阅分行数}分行开通"
- **状态与操作区**：Text：[状态]；Button：[编辑*] [共享/取消共享*] [为分行开通/停用我的使用/恢复使用] [复制] [...]
- **Banner 区**：Banner：{正在准备使用/上一版本仍可用/准备失败及下一步}
- **Tab 内容区**：
  - Tab “Skill详情”：展示提示词内容
  - Tab “版本记录”：Table 展示版本号、更新时间、操作者、运行状态；Button：[查看] [还原为新版本*]
  - Tab “Skill评分**”：Select：[版本选择]；评分总结（综合得分、评估结论、建议）；评分雷达图；评估得分明细表；Button：[手工优化] [自动优化] [获取优化报告]

### 关键状态

| 视图状态 | 触发条件 | UI 表现 |
|---------|---------|--------|
| 详情 Tab | 默认选中 | 展示完整提示词内容和元数据 |
| 版本记录 Tab | 用户点击 | 版本列表 Table |
| 评分 Tab | 仅所属分行/总行管理者点击 | 评分信息与操作按钮 |
| 评分生成中 | 新版本评分未完成 | 评分区域显示独立状态 |
| 评分失败 | 评分服务异常 | 评分区域 EmptyState |
| Banner 持续状态 | 运行版本未就绪 | Banner 常驻显示状态文案 |

### 嵌套实体：优化报告弹窗（实体 11，HF-020 补漏）

**触发条件**：在 Skill 评分 Tab 中点击"获取优化报告"。

**弹窗目标**：展示优化前后的提示词对比，支持编辑调整后一键替换为新版本。

**结构描述**：
- 标题区：Text："【{版本号}】优化+{优化时间}"；Button：[×]
- 对比区：左右两栏布局，左侧为优化前内容，右侧为优化后内容，有颜色标注调整部分；右侧内容支持编辑调整
- 底部操作区：Button：[一键替换]

**操作结果**：[一键替换]保存为最新版本；[×]关闭不保存。

## 9. 分行订阅确认 Dialog（实体 5）

### 弹窗目标

让用户在组织级开通前理解影响范围。

### 触发条件

用户在 Skill 详情 Page 点击"为本分行开通"。

### 区域结构（ASCII）

```
+----------------------------------------------------------------+
| 为本分行开通 {Skill名称}                                  [×] |
+----------------------------------------------------------------+
| 确认后，{所属分行}全体用户都可在财富小助使用此 Skill。           |
|                                                                  |
| 影响范围：{所属分行}                                             |
| 当前状态：本分行未开通                                           |
| 开通后：订阅分行数 +1                                            |
|                                                                  |
| 个人后续可以停用自己的使用，但不会撤销分行开通。                  |
+----------------------------------------------------------------+
|                                      [取消] [确认开通]            |
+----------------------------------------------------------------+
```

### 区域说明

- **标题区**：Text："为本分行开通 {Skill名称}"；Button：[×]
- **影响说明区**：Text："确认后，{所属分行}全体用户都可在财富小助使用此 Skill。"；Text："影响范围：{所属分行}"；Text："当前状态：本分行未开通"；Text："开通后：订阅分行数 +1"；Text："个人后续可以停用自己的使用，但不会撤销分行开通。"
- **底部操作区**：Button：[取消] [确认开通]

### 关键状态

| 状态 | 触发条件 | UI 表现 |
|------|---------|--------|
| 初始 | 弹窗打开 | 显示影响范围和当前状态 |
| 并发重复订阅 | 提交时已存在订阅关系 | Toast 不为错误，刷新详情状态 |
| Skill 已失效 | 提交时 Skill 已删除或取消共享 | 关闭弹窗，刷新页面为"已不可用" |

## 15. 主交互流程

### 15.1 创建并共享 Skill

| 步骤 | 用户动作 | 系统反馈 | 下一步指向 |
|------|---------|---------|-----------|
| 1 | 在我的 Skill 视图点击"发布 Skill" | 打开创建方式 Dialog | 选择创建方式 |
| 2a | 选择"手动创建" | 进入 Skill 编辑 Page，带编写模板 | 填写内容 |
| 2b | 选择"上传 Markdown"并选择文件 | 校验文件，若通过则解析内容带入编辑页 | 核对并填写 |
| 2b-异常 | 上传非 .md 或超 1MB | 上传卡片 InlineError，弹窗不关闭 | 重新选择文件 |
| 3 | 填写名称、描述、提示词 | 实时显示字符数，必填项在字段附近校验 | 点击保存并发布 |
| 3-异常 | 必填为空或超长 | 字段 InlineError，不提交 | 就地修改后重新保存 |
| 4 | 点击"保存并发布" | 保存成功，进入 Skill 详情 Page，显示"正在准备使用" | 发起共享或继续编辑 |
| 5 | 在详情页点击"共享到广场" | 展示共享影响说明 | 确认或取消 |
| 6 | 确认共享 | 状态变为"已共享"，所属分行自动可用 | 查看广场展示或返回我的 Skill |

### 15.2 浏览并为分行订阅

| 步骤 | 用户动作 | 系统反馈 | 下一步指向 |
|------|---------|---------|-----------|
| 1 | 在广场搜索或筛选 Skill | 更新列表结果 | 点击 Skill 卡片 |
| 2 | 点击 Skill 卡片"查看详情" | 进入 Skill 详情 Page | 查看来源、状态 |
| 3 | 查看详情页的分行状态 | 展示三种结果之一：未开通/已开通·使用中/已开通·已停用 | 根据状态操作 |
| 4 | 点击"为本分行开通" | 打开分行订阅确认 Dialog | 确认影响范围 |
| 5 | 确认开通 | 建立分行订阅关系，Toast："已为{所属分行}开通"，状态刷新 | 去财富小助使用或继续浏览 |

### 15.3 财富小助联想并调用

| 步骤 | 用户动作 | 系统反馈 | 下一步指向 |
|------|---------|---------|-----------|
| 1 | 在财富小助输入框开头或空格后输入"/" | 联想面板 Loading，500ms 内显示可用 Skill | 继续输入或选择 |
| 2 | 继续输入关键词 | 实时筛选并高亮匹配名称 | 上下键或点击选择 |
| 3 | 上下键或点击选中 Skill | 输入框填入"/{Skill名称}"，面板收起 | 补充内容或发送 |
| 4 | 发送 | 跳过意图识别，执行 Skill | 返回 AI 结果 |
| 4-异常 | 执行超时 | 保留输入和目标 Skill，提示重试 | 重试或换 Skill |

### 15.4 次交互流程摘要

| 次流程 | 触发条件 | 用户动作 | 系统反馈 |
|-------|---------|---------|---------|
| 编辑版本 | 创建者/总行管理者在详情点击"编辑" | 修改内容并保存 | 生成新版本，当前版本标记"正在准备使用" |
| 复制 Skill | 用户对可见 Skill 点击"复制" | 确认复制规则，修改默认名称 | 创建独立私有 Skill，进入副本编辑页 |
| 查看版本评分 | 所属分行用户/总行管理者进入版本记录 | 选择目标版本 | 展示版本内容、评分和运行状态 |
| 还原历史版本 | 创建者/总行管理者点击"还原为新版本" | 确认还原 | 以历史内容生成新版本，重新评分 |
| 个人停用/恢复 | 分行已订阅用户 | 点击"停用我的使用"或"恢复使用" | 从本人联想中移除/重新加入 |
| 取消共享 | 创建者/总行管理者对已共享 Skill 操作 | 确认影响 | 从广场下架，阻止新订阅 |
| 删除 Skill | 创建者/总行管理者 | 输入名称确认 | 删除资产，解除关系，不可恢复 |
| 总行管理操作 | 总行管理者查看任意 Skill | 执行任意管理操作 | 操作入口标注"总行管理"，记录操作者 |

## 16. 校验规则

| 触发时机 | 校验内容 | 阻断条件 | 失败反馈 |
|---------|---------|---------|---------|
| 创建/编辑保存时 | Skill 名称必填 | 名称为空 | 字段 InlineError，不提交 |
| 创建/编辑保存时 | Skill 名称长度 | 超过 50 字符 | 字段 InlineError，不提交 |
| 创建/编辑保存时 | Skill 描述必填 | 描述为空 | 字段 InlineError，不提交 |
| 创建/编辑保存时 | Skill 描述长度 | 超过 200 字符 | 字段 InlineError，不提交 |
| 创建/编辑保存时 | 提示词内容必填 | 内容为空 | 字段 InlineError，不提交 |
| 创建/编辑保存时 | 提示词内容长度 | 超过 10000 字符 | 字段 InlineError，不提交 |
| 创建/编辑/复制保存时 | 名称唯一性 | 同一创建者范围内重复 | 名称字段 InlineError，建议修改 |
| 上传文件时 | 文件格式 | 非 .md 文件 | 上传卡片 InlineError，弹窗不关闭 |
| 上传文件时 | 文件大小 | 超过 1MB | 上传卡片 InlineError，弹窗不关闭 |
| 上传文件时 | 文件编码 | 非 UTF-8 | 上传卡片 InlineError，弹窗不关闭 |
| 删除时 | 输入名称确认 | 输入名称与 Skill 名称不一致 | 删除按钮不可用，提示正确名称 |
| 分行订阅提交时 | 分行订阅状态 | 已存在订阅关系 | 不重复计数，转为成功态解释 |

## 18. 异常恢复

| 异常 | 触发时机 | 系统处理 | 用户恢复路径 |
|------|---------|---------|-------------|
| 上传文件不符合要求 | 选择文件后、编辑前 | 不创建 Skill，不清空创建方式 | 重新选择文件，原路恢复 |
| 编辑内容校验失败 | 点击保存时 | 不提交，聚焦第一个错误字段 | 就地修改后重新保存 |
| Skill 名称冲突 | 创建/复制/编辑保存时 | 不保存当前名称，其他内容保留 | 修改名称后重新保存 |
| 无管理权限 | 进入编辑/共享/还原/删除入口 | 入口隐藏或禁用，不修改数据 | 返回只读详情或联系创建者/总行管理者 |
| 分行重复订阅 | 并发用户同时订阅 | 不重复计数，转成功态解释 | 直接使用或恢复个人使用 |
| Skill 在订阅/复制前失效 | 详情已打开后点击操作 | 不建立关系，刷新为不可用 | 返回广场选择其他 Skill |
| 新版本未就绪 | 创建/编辑/还原后 | 继续提供上一可用版本 | 等待或稍后刷新 |
| 评分未生成或失败 | 查看新版本评分 | 不伪造分数，不阻断使用 | 稍后重试或查看其他版本 |
| 历史版本还原失败 | 确认还原后 | 未创建则保持现状；已创建则保留新版本 | 重新还原或查看版本记录 |
| 联想为空或加载失败 | 输入"/"或筛选时 | 区分原因展示对应 EmptyState | 去广场、清空关键词或重试 |
| Skill 执行超时 | 发送调用后 | 终止执行，保留输入 | 重试或选择其他 Skill |

## 22. 不参与本次生成的待确认项
