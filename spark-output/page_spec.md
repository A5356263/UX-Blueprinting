# 页面生成规格：财富专区 — 资产配置面客版

## 1. 页面摘要

- **产品领域**：财富专区 — 资产配置
- **页面类型**：单页信息展示 + 弹窗（下载格式选择 / 批量购买确认）
- **用户角色**：企业客户
- **核心任务**：查看资产配置建议书，了解持仓情况、诊断结果和产品推荐，并执行购买操作

---

## 2. 生成范围

### 生成

| 实体 | 类型 | 原因 |
| --- | --- | --- |
| 资产配置建议书主页面 | Page | 核心页面，完整信息展示和操作入口 |
| 下载格式选择弹窗 | Modal | 挂载于主页面，选择下载格式 |
| 批量购买确认弹窗 | Modal | 挂载于主页面，确认预填购物车产品 |

### 只引用不生成

| 实体 | 原因 |
| --- | --- |
| 产品详情页 | 复用现有产品详情页，不做独立设计 |
| 购物车 | 复用现有购物车流程 |
| 产品列表页 | 无持仓时跳转，复用现有产品列表页 |

### 不生成

无

## 4. 资产配置建议书主页面

### 页面目标

企业客户在一页内完成"查看总览 → 分析表现 → 了解诊断 → 获取推荐 → 采取行动"的完整链路。

```

│ └───────────────────────────────────────────────┘   │
```

### 区域说明

| 区域编号 | 名称 | 包含内容 |
| --- | --- | --- |
| R1 | 顶部导航区 | Text：资产配置建议书 |
| R2 | 账号选择区 | Select：银行账号下拉（默认"全部账号"） |
| R3 | 总览卡片区 | StatCard：时点资产 {金额}{单位}；Tag：诊断摘要 {N} 项待关注 / 持仓状态良好 |
| R4 | 持仓表现区（可折叠） | Select：时间区间筛选器（近一月~自定义）；KPI 卡片组：持仓金额、较期初、区间收益、年化收益率；Statistics：购买/赎回统计；Chart：持仓变动趋势折线图、收益金额趋势折线图；List：产品收益排行（降序） |
| R5 | 投资分布区（Tab） | Tab：（投资分布 / 期限分布）；Chart：饼图；List：按业务类型汇总的金额、占比、年化收益率及排名 |
| R6 | 期限分布区（Tab） | Tab 内容切换后替代 R5 内容；List：按产品期限/持有期汇总的金额、占比、年化收益率及排名 |
| R7 | 诊断×推荐区（可折叠） | 联合卡片组，每张卡片含：Tag（诊断类型） + Text（问题描述） + Text（建议方向） + 推荐产品列表（ProductCard：产品名、收益率、最大回撤、推荐理由）+ Button（购买） |
| R8 | 底部合规区 | Text：理财非存款，产品有风险，投资需谨慎 |
| R9 | 悬浮操作区 | Button：下载（右下角悬浮） |

### 提取备注

- 主页面为顶级页面（有独立菜单入口），无需查找父页面
- 知识库中财富管理领域无对应载体语义文件，页面结构来自体验蓝图 §6
- [保存] 按钮位保留但本版本不做（标注为待确认）

### 关键操作

| 操作 | 触发元素 | 结果 |
| --- | --- | --- |
| 切换银行账号 | Select：银行账号下拉选择 | 以新账号重新请求所有模块数据，各模块独立重新加载 |

| 查看产品详情 | Link：产品名称/代码 | 跳转产品详情页（复用） |
| 下载建议书 | Button：右下角悬浮下载按钮 | 弹出下载格式选择弹窗 |
| 去购买（空状态） | Button：去购买 | 跳转产品列表页（复用） |

## 6. 批量购买确认弹窗

### 弹窗目标

让客户确认要批量购买的产品列表后跳转购物车。

### 触发条件

在推荐产品区勾选至少一个产品后点击"批量购买"。

### 区域结构（ASCII 框图）

```
┌─────── 确认批量购买产品 ───────┐
│                                │
│ 已选择 {N} 件产品：             │
│ ☑ 产品A    {金额} 元            │
│ ☑ 产品B    {金额} 元            │
│ ☐ 产品C    {金额} 元            │
│                                │
│ 预计总金额：{总金额} 元         │
│                                │
│        [取消]  [加入购物车]     │
└────────────────────────────────┘
```

### 区域说明

| 区域编号 | 名称 | 内容 |
| --- | --- | --- |
| M2-R1 | 标题区 | Text：确认批量购买产品 |
| M2-R2 | 产品清单区 | CheckboxGroup：产品列表（默认已勾选），每行含产品名 + 金额 |
| M2-R3 | 金额汇总区 | Text：预计总金额 {总金额} 元 |
| M2-R4 | 操作区 | Button：取消 / 加入购物车 |

### 校验阻断态变化

| 场景 | 变化 |
| --- | --- |
| 产品在确认过程中售罄/额度不足 | 弹窗不关闭，该产品行自动标记为"已售罄"并勾选移除，金额汇总同步更新 |

### 不合规确认区结构

不适用。

## 7. 主交互流程

### 流程一：进入页面并查看总览

**触发**：从菜单或持仓列表进入资产配置页面。

**流程节点：**

| 步骤 | 用户动作 | 系统响应 | 状态变化 | 下一步 |
| --- | --- | --- | --- | --- |
| 1 | 从菜单或持仓列表入口点击 | 页面框架渲染，各模块按优先级发起数据请求 | 各模块进入加载中状态 | 等待数据返回 |
| 2 | 等待加载完成 | 总览卡片区展示时点资产和诊断摘要 | 加载中 → 加载成功 | 浏览或切换账号 |
| 3 | 浏览总览信息 | 展示时点资产金额和诊断状态标签 | 无 | 进入持仓表现或折叠模块 |

### 流程二：查看持仓表现

**触发**：在持仓表现模块查看或筛选数据。

| 步骤 | 用户动作 | 系统响应 | 状态变化 | 下一步 |
| --- | --- | --- | --- | --- |
| 1 | 查看 KPI 卡片和图表 | 展示 4 个 KPI 卡片、购买/赎回统计、趋势图、收益排行 | 无 | 筛选时间区间 |
| 2 | 点击时间区间筛选器 | 展开预设选项（近一月/近三月/近半年/近一年/自定义） | 无 | 选择区间 |
| 3 | 选择预设或自定义起止日期 | 持仓表现模块（KPI+图表+排行）全部刷新 | 模块数据更新 | 查看更新后的数据 |

### 流程三：查看诊断与推荐

**触发**：浏览"诊断×推荐"联合卡片区。

| 步骤 | 用户动作 | 系统响应 | 状态变化 | 下一步 |
| --- | --- | --- | --- | --- |
| 1 | 展开诊断×推荐区 | 展示所有诊断类型的联合卡片组 | 无 | 浏览卡片 |
| 2 | 浏览诊断卡片 | 每张卡片展示问题描述、建议方向、推荐产品列表 | 无 | 购买/详情/批量购买 |
| 3 | 点击单件产品【购买】 | 跳转产品购买页（复用） | 页面跳转 | 在购买页完成交易 |
| 4 | 勾选产品，点击【批量购买】 | 弹出批量购买确认弹窗 | 弹窗打开 | 确认或取消 |
| 5 | 点击产品名称/代码 | 跳转产品详情页（复用） | 页面跳转 | 浏览详情 |

### 流程四：下载建议书

**触发**：点击主页面右下角下载按钮。

| 步骤 | 用户动作 | 系统响应 | 状态变化 | 下一步 |
| --- | --- | --- | --- | --- |
| 1 | 点击下载悬浮按钮 | 弹出下载格式选择弹窗 | 弹窗打开 | 选择格式 |
| 2 | 选择 PDF 或 PNG 格式，点击【下载】 | 弹窗关闭，开始生成文件，toast "正在生成文件，请稍候..." | 下载中 | 等待完成 |
| 3 | 等待下载完成 | 文件生成后触发浏览器下载 | 下载中 → 下载完成 | 查看本地文件 |

### 流程五：切换银行账号

**触发**：客户需要查看其他账号的配置情况。

| 步骤 | 用户动作 | 系统响应 | 状态变化 | 下一步 |
| --- | --- | --- | --- | --- |
| 1 | 点击账号选择器 | 展开银行账号下拉列表 | 无 | 选择目标账号 |
| 2 | 选择目标账号（或"全部账号"） | 以新账号重新请求所有模块数据，各模块独立重新加载 | 正常 → 加载中 → 加载成功 | 浏览新账号数据 |

## 8. 校验规则

本页面以信息展示为主，不含表单校验。主要校验发生在复用页面（购买页、购物车），不在本次规格范围内。

| 规则对象 | 条件 | 阻断性 | 处理方式 |
| --- | --- | --- | --- |
| 批量购买产品勾选 | 未勾选任何产品时点击批量购买 | 是 | 批量购买按钮置灰 |
| 批量购买确认（弹窗内） | 产品在确认过程中售罄 | 否 | 自动移除售罄产品，金额重新计算 |

## 9. 状态表现

| 状态 | 触发条件 | UI 表现 | 文案 key |
| --- | --- | --- | --- |
| 加载中 | 首次进入或切换账号，数据请求中 | 各模块独立骨架屏加载占位 | — |
| 加载成功 | 所有数据正常返回 | 正常展示所有模块内容 | — |
| 部分缺失 | 个别字段无数据 | 缺失字段展示 "--" | label.empty |
| 模块异常 | 单个模块接口失败 | 该模块展示空状态卡片，其他模块正常 | label.module_empty |
| 全页异常 | 核心接口全失败 | 全屏阻断页：图标 + 文案 | error.system_busy |
| 无持仓 | 账号下无持仓记录 | 全页空态：图标 + 文案 + 【去购买】按钮 | empty.no_position |
| 无诊断 | 无合格诊断问题 | 诊断模块不展示 | — |
| 无推荐 | 无合格推荐产品 | 推荐模块不展示 | — |
| 下载中 | 文件生成中 | Toast 提示 | toast.downloading |
| 下载失败 | 文件生成异常 | Toast 提示 | toast.download_failed |

## 10. 异常恢复

| 异常 | 触发条件 | UI 表现 | 恢复路径 |
| --- | --- | --- | --- |
| 企业财富+接口超时 | 任一模块接口响应 > 5 秒 | 该模块骨架保留，自动重试 3 次；3 次均失败后展示空状态卡片 + 文案 | 下拉刷新或重进入页面；筛选条件保留 |
| 企业财富+服务无响应 | 核心接口过半数连续失败 | 全屏阻断页：图标 + 文案 | 1-2 分钟后重试；原路返回无信息丢失 |
| 部分模块数据缺失 | 个别模块接口报错或返回空 | 失败模块展示空状态，其他模块正常 | 后台异步补全，下次进入时更新；可手动切换账号再切回 |
| 文件生成失败 | 文件生成接口异常 | 弹窗内提示文案，保留重试 | 点击重试；原路返回无信息丢失 |
| 下载网络中断 | 下载过程中网络断开 | 浏览器下载失败 + Toast 提示 | 网络恢复后重新下载；原路返回无信息丢失 |
| 批量购买部分失败 | 部分产品额度不足/已售罄 | 结算结果页：汇总成功/失败笔数 + 失败原因 + 移除按钮 + 提示文案 | 移除失败产品后重新选择替代产品；成功产品不受影响 |
