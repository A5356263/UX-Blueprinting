已检测到体验蓝图产出。

推荐直接基于体验蓝图提取页面规格，这会是当前最稳定的输入路径。

## 1. 页面摘要

- **产品领域**：财富专区 — 资产配置
- **页面类型**：信息展示页 + 弹窗
- **用户角色**：企业客户
- **核心任务**：查看资产配置建议书，了解持仓情况，发现配置问题，获取产品推荐并执行购买

---

## 2. 生成范围

### 生成

| 实体 | 类型 | 说明 |
|------|------|------|
| 资产配置主页面 | Page | 承载六大模块（摘要卡、持仓表现、投资分布、期限分布、持仓诊断、产品推荐）的主页面 |
| 下载格式选择弹窗 | Modal | 选择 PDF 或 PNG 格式后触发下载 |

### 只引用不生成

| 实体 | 原因 |
|------|------|
| 产品详情页 | 已有外部页面，本功能仅提供跳转链接 |
| 购买页 | 已有外部页面，本功能仅提供跳转按钮 |
| 购物车 | 已有外部页面，本功能仅提供批量跳转 |

### 不生成

| 实体 | 原因 |
|------|------|
| 持仓概览模块 | 本版本不做（DROP-001） |
| 历史建议书保存/列表/删除 | 本版本不做（DROP-002, DROP-003） |
| 其他业务投资分布细分类 | 本版本不做（DROP-004） |
| 其他业务期限分布细分类 | 本版本不做（DROP-005） |
| 到期诊断中开放期/可赎回产品 | 本版本不做（DROP-006） |

### 页面目标

### 区域说明

| 区域 ID | 名称 | 内容 |
|---------|------|------|
| R1 | 顶部标题栏 | Text：资产配置建议书；Button（悬浮右下角）：下载建议书 |
| R2 | 账号选择器 | Select：银行账号下拉列表，默认"全部"或选中账号 |
| R3 | 摘要卡片区 | StatCard×4：总资产、区间收益、年化收益率、持仓产品数 |
| R4 | 持仓表现区块 | 时间区间筛选器（Select 快捷选项 + DatePicker 自定义范围）+ 指标数据（持仓金额/较期初/区间收益/年化收益率/购买笔数/购买金额/赎回笔数/赎回金额）+ 趋势图×2（持仓变动/收益金额）+ Table（产品收益排行） |
| R5 | 投资分布区块 | Tabs（理财/其他业务）+ 饼图 + Table（产品类型/持仓金额/占比/年化收益率/排名） |
| R6 | 期限分布区块 | Tabs（理财/其他业务）+ Table（产品期限/持仓金额/占比/年化收益率） |
| R7 | 持仓诊断区块 | List（诊断条目），每条含跳转链接查看详情；无诊断问题时不展示 |
| R8 | 产品推荐区块 | Table（产品名/代码/期限/收益率/最大回撤/推荐理由），每行 Button（购买）；底部 Checkbox（全选）+ Button（加入购物车） |
| R9 | 底部风险提示区 | Text：固定风险提示文案 |

### 提取备注

- 页面结构来自体验蓝图 §6.1 和页面生成事实交接 FACT-P001~P006
- 字段详情装配自页面生成事实交接 FACT-F001~F021
- 交互联动装配自页面生成事实交接 FACT-I001~I009
- 账号选择器"全部"选项的数据语义未定（GAP-001），页面暂按汇总展示设计

### 列表字段

#### 产品收益排行（R4）

| 字段 | 含义 | 数据来源 |
|------|------|----------|
| 排名 | 按持仓收益降序的序号 | 计算 |
| 产品名称 | 持仓产品名称 | 企业财富+ |
| 持仓金额 | 持仓余额（自动单位换算） | 企业财富+ |
| 持仓收益 | 区间内持仓收益金额 | 企业财富+ |

#### 投资分布 — 理财（R5 Tab: 理财）

| 字段 | 含义 | 数据来源 |
|------|------|----------|
| 产品类型 | 按产品特点分类 | 企业财富+ |
| 持仓金额 | 该类产品持仓金额合计（自动单位换算） | 企业财富+ |
| 占比 | 该类产品占总资产比例（保留2位小数） | 计算 |
| 年化收益率 | 该类产品年化收益率（保留2位小数，正数+"+"） | 企业财富+ |
| 排名 | 按年化收益率排序 | 计算 |

#### 投资分布 — 其他业务（R5 Tab: 其他业务）

| 字段 | 含义 | 数据来源 |
|------|------|----------|
| 业务类型 | 公募基金/资管计划/信托计划 | 企业财富+ |
| 持仓金额 | 该类型持仓金额（自动单位换算） | 企业财富+ |
| 占比 | 该类型占总资产比例（保留2位小数） | 计算 |

#### 期限分布（R6 Tab: 理财/其他业务）

| 字段 | 含义 | 数据来源 |
|------|------|----------|
| 产品期限/持有期 | 理财：产品期限；其他：持有期 | 企业财富+ |
| 持仓金额 | 该期限产品持仓金额合计（自动单位换算） | 企业财富+ |
| 占比 | 该期限占总资产比例（保留2位小数） | 计算 |
| 年化收益率 | 仅理财展示（保留2位小数，正数+"+"） | 企业财富+ |

#### 产品推荐（R8）

| 字段 | 含义 | 数据来源 |
|------|------|----------|
| 产品名称/代码 | 产品名称 + 产品代码 | 企业财富+ |
| 交易时间 | 开放时间+赎回清算效率 | 企业财富+ |
| 产品期限 | 产品期限 | 企业财富+ |
| 收益率或业绩比较基准 | 收益率/业绩比较基准及描述 | 企业财富+ |
| 近一月最大回撤 | 近一月最大回撤值（活钱管理类不展示） | 企业财富+ |
| 推荐理由 | 推荐原因描述 | 企业财富+ |

### 关键操作

| 动作 | 触发 | 结果 |
|------|------|------|

| 切换投资分布 Tab | 点击 Tab 标签 | 切换理财/其他业务视图 |
| 切换期限分布 Tab | 点击 Tab 标签 | 切换理财/其他业务视图 |
| 查看诊断详情 | 点击诊断条目[查看] | 展开/跳转详情（FACT-I003, I004） |

## 5. 下载格式选择弹窗

### 弹窗目标

让用户选择建议书的下载格式

### 区域结构

```
┌──────────────────────────────────────────────┐
│  下载建议书                                   │  ← R1: 标题
├──────────────────────────────────────────────┤
│                                              │
│  请选择下载格式：                              │  ← R2: 说明文字
│                                              │
│  ┌────────────────────────────────────────┐  │
│  │ ○ PDF（适合打印分享）                  │  │  ← R3: 单选选项（Radio）
│  ├────────────────────────────────────────┤  │
│  │ ○ PNG（适合图片查看）                  │  │
│  └────────────────────────────────────────┘  │
│                                              │
│  将下载当前账号下所有模块内容                  │  ← R4: 范围提示
│                                              │
│         [取消]          [开始下载]            │  ← R5: 操作按钮
└──────────────────────────────────────────────┘
```

### 区域说明

| 区域 ID | 名称 | 内容 |
|---------|------|------|
| R1 | 弹窗标题 | Text：下载建议书 |
| R2 | 说明文字 | Text：请选择下载格式： |
| R3 | 格式选项 | RadioGroup：PDF（适合打印分享）、PNG（适合图片查看） |
| R4 | 范围提示 | Text：将下载当前账号下所有模块内容 |
| R5 | 操作按钮 | Button（次）：取消；Button（主）：开始下载 |

### 校验阻断态变化

- 未选择格式时：【开始下载】置灰不可点击

### 提取备注

- 弹窗结构来自体验蓝图 §6.2
- 下载范围提示需与最终确认的数据快照范围对齐（GAP-002）

## 6. 主交互流程

| 步骤 | 触发 | 用户动作 | 系统响应 | 状态变化 | 下一步 |
|------|------|----------|----------|----------|--------|
| 1 | 用户点击"资产配置"菜单或持仓列表入口 | 点击入口链接 | 页面加载，账号选择器默认选中，各模块展示 LoadingState | 页面加载中 | 选择账号或浏览 |
| 2 | 用户选择/切换账号 | 从 Select 下拉选择账号 | 所有模块展示 LoadingState → 数据加载完成后展示对应数据 | 数据刷新中 | 浏览各模块 |
| 3 | 用户选择时间区间 | 点击快捷选项或 DatePicker 选择 | 持仓表现模块展示 LoadingState → 更新数据 | 数据刷新中 | 浏览持仓表现 |
| 4 | 用户向下滚动 | 滚动操作 | 各区块依次进入视口展示内容 | 无 | 继续滚动 |
| 5 | 用户切换投资分布/期限分布 Tab | 点击 Tab 标签 | 切换展示理财或其他业务数据 | 无 | 浏览对应数据 |
| 6 | 用户点击诊断条目[查看] | 点击链接按钮 | 展开详情或跳转详情 | 无 | 查看详情后返回 |
| 7 | 用户点击推荐产品[购买] | 点击行内按钮 | 跳转购买页 | 无 | 在购买页交易 |
| 8 | 用户勾选产品后批量购买 | 勾选 Checkbox → 点击[加入购物车] | 跳转购物车 | 无 | 在购物车结算 |
| 9 | 用户点击[下载建议书] | 点击悬浮按钮 | 打开下载格式选择弹窗 | 无 | 选择格式下载 |
| 10 | 用户在弹窗选择格式 | Radio 选择 → 点击[开始下载] | 下载进行中（LoadingState）→ 下载完成（Toast） | 下载进行中 | 打开文件/重试 |

## 8. 状态表现

| 状态 | 触发条件 | UI 表现 | 文案 key |
|------|----------|---------|----------|
| 页面加载中 | 进入页面/刷新 | 全页骨架屏加载 | — |
| 模块加载中 | 某模块数据请求中 | 模块内加载骨架 | — |
| 数据刷新中 | 切换账号/时间区间 | 模块展示加载态 | — |
| 数据加载完成 | 所有数据就绪 | 正常展示数据 | — |
| 无持仓数据 | 账号下无持仓 | 空状态（图标+文案+按钮） | empty.no_holdings |
| 无持仓表现数据 | 持仓表现模块无数据 | 空状态 | empty.no_performance |
| 无投资分布数据 | 投资分布模块无数据 | 空状态 | empty.no_investment_dist |
| 无期限分布数据 | 期限分布模块无数据 | 空状态 | empty.no_term_dist |
| 无诊断问题 | 诊断无异常 | 不展示持仓诊断模块 | — |
| 推荐为空 | 无符合条件的推荐产品 | 空状态 | empty.no_recommendation |
| 功能不可用 | 数据计算异常 | 模块内"暂时不可用"提示 | error.module_unavailable |
| 下载进行中 | 文件生成中 | 加载提示 + 进度 | download.in_progress |
| 下载完成 | 文件已下载 | Toast 提示 | download.complete |
| 下载失败 | 文件生成失败 | Toast 提示 | download.failed |
| 网络中断 | 下载过程中断网 | Toast 提示 | download.network_error |
| 存储空间不足 | 设备空间不足 | 弹窗提示 | download.storage_insufficient |
| 浏览器拦截下载 | 浏览器阻止下载 | 引导提示 | download.browser_blocked |

## 9. 异常恢复

| 异常 | 触发条件 | UI 表现 | 恢复路径 |
|------|----------|---------|----------|
| 页面整体数据加载失败 | 接口超时/返回错误，自动重试 3 次后仍失败 | 全页 EmptyState，含【重新加载】按钮 | 点击重新加载回到初始加载流程，无信息丢失 |
| 某模块数据加载失败 | 模块级接口异常 | 该模块展示"功能暂时不可用"，其他模块正常 | 后台恢复后刷新页面或切换条件重试，无信息丢失 |
| 下载失败 | 文件生成失败 | Toast：下载失败提示 | 点击重试→重新打开弹窗→选择格式→下载 |
| 网络中断 | 下载过程中网络断开 | Toast：网络异常提示 | 检查网络后重新下载 |
| 存储空间不足 | 设备空间不足 | Modal 提示：存储空间不足 | 清理空间后重新下载 |
| 浏览器拦截下载 | 浏览器阻止弹出下载 | 引导提示：请允许浏览器下载 | 允许浏览器下载后重新点击下载 |
| 用户无可选账号 | 账号列表 API 返回空 | 全页 EmptyState："暂无可用账号"，账号选择器禁用 | 联系管理员或切换登录账号后重新进入 |
