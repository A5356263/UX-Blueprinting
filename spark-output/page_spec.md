# 页面生成规格：子管理员权限复制

---

## 1. 页面摘要
- **产品领域**：企业权限管理 — 子管理员治理
- **页面类型**：Page（子管理员列表）、Modal（复制弹窗、员工选择器）
- **用户角色**：权限管理员 / 超级管理员
- **核心任务**：将已有子管理员的可授权组织和可授权功能复制给其他用户（普通用户或已有子管理员）

---

## 2. 生成范围

### 生成
- 子管理员列表（承载页面 —— 修改，新增复制按钮+行内权限摘要）
- 复制子管理员权限弹窗（新增 Modal）
- 员工选择器弹窗（现有组件修改 —— 增加状态标签+不合格者灰显）

### 只引用不生成
- 操作记录页 — 仅在本功能中新增两种操作类型记录，页面本身为已有系统能力
- 子管理员配置页 — 点击编辑操作跳转至已有页面，不修改

### 不生成
- 双管理员互审审批流程 — 已有审批中台能力，仅对接
- 权限管理模式页 — 已有页面，不修改

---

## 3. 页面实体关系

```
子管理员列表 (Page)
  ├── 行操作 [复制] ──→ 复制子管理员权限弹窗 (Modal)
  │                       ├── [选择复制对象] ──→ 员工选择器弹窗 (Modal)
  │                       └── [确认复制] ──→ 校验 → Toast + 列表刷新
  ├── 行操作 [编辑] ──→ 子管理员配置页 (Page, 已有)
  ├── 行操作 [停用/启用] ──→ 状态切换
  └── [+ 添加子管理员] ──→ 子管理员配置页 (Page, 已有)
```

- **顶部全局 Tab 切换区**

- **提示信息与状态控制区**
  - Text：业务介绍提示文本
  - TextLink：「帮助文档」
  - TextLink：「关闭子管理员模式」（右对齐）
- **筛选查询区**
  - Input：「姓名」
  - Input：「手机号」
  - Select：「部门」
  - Button：「重置」
  - Button：「查询」
- **工具栏与操作区**
  - Button：「+ 添加子管理员」
  - Text：「共 {N} 条」（右对齐）
- **数据列表表格区**
  - 表头：姓名 | 手机号 | 可授权组织范围 | 可授权功能 | 状态 | 操作
  - 行数据：
    - Text：「{姓名}」
    - Text：「{手机号}」
    - Text：「{组织范围摘要}」— hover 时 Tooltip 展示完整列表
    - Text：「{N} 项功能」— hover 时 Tooltip 展示完整功能名称列表

  - Text：「共 {N} 条」
  - Pagination
  - Select：「{X}条/页」

### 关键操作

- **[复制]**：打开复制子管理员权限弹窗，带入当前行子管理员身份信息

- **[停用/启用]**：切换子管理员启用状态（已有）

- **搜索无结果**：「未找到匹配的子管理员。请调整搜索条件。」
- **加载态**：列表骨架屏 + Text「正在加载...」

## 5. 复制子管理员权限弹窗

### 弹窗目标
让管理员确认复制来源和内容、选择目标用户、预览操作后果、完成复制提交。

### 区域结构（ASCII 框图 + 区域编号说明）

```
+-----------------------------------------------------------------------+
| 复制子管理员权限                                                  [X]  |  ← 区域 A
+-----------------------------------------------------------------------+
| 【 复制来源 】                                                        |  ← 区域 B
| 将 {姓名 / 手机号} 的权限配置复制给其他用户                              |
+-----------------------------------------------------------------------+
| 【 复制内容 】                                                        |  ← 区域 C
| [✓] 可授权组织                                                        |
| [✓] 可授权功能                                                        |
| * 至少选择一项                                                         |
+-----------------------------------------------------------------------+
| 【 复制对象 】                                    已选 {N}/200 人       |  ← 区域 D
| +-------------------------------------------------------------+       |
| | 张三 - 138xxxx1234 - [新增为子管理员]                   [移除] |       |
| | 李四 - 139xxxx5678 - [叠加权限]                         [移除] |       |
| | 王五 - 137xxxx9012 - [新增为子管理员]                   [移除] |       |
| | ...                                                       |       |
| +-------------------------------------------------------------+       |
| [+ 选择复制对象]  [清空全部]                                          |
+-----------------------------------------------------------------------+
| 【 复制预览 】                                                        |  ← 区域 E
| 复制后：                                                              |
| - {N} 名用户将成为子管理员                                             |
| - {M} 名已有子管理员将叠加新权限                                        |
| - 复制内容：可授权组织、可授权功能                                       |

+-----------------------------------------------------------------------+

```

### 区域说明

- **区域 A — 弹窗标题与关闭**
  - Text：「复制子管理员权限」
  - Button：[X] 关闭（同取消行为）
- **区域 B — 复制来源信息**
  - Text：「将 {姓名 / 手机号} 的权限配置复制给其他用户」
- **区域 C — 复制内容选择**
  - Text 标题：「复制内容」
  - Checkbox：「可授权组织」（默认选中）
  - Checkbox：「可授权功能」（默认选中）
  - InlineNote：「至少选择一项」（所有勾选项均取消时出现）
- **区域 D — 复制对象选择与列表**
  - Text 标题：「复制对象」
  - Text 计数：「已选 {N}/200 人」
  - List：已选用户列表
    - 每一行为：Text「{姓名} - {手机号}」+ Tag「新增为子管理员」/「叠加权限」+ Button「移除」
  - Button：「+ 选择复制对象」
  - Button：「清空全部」
  - EmptyState：「暂未选择复制对象」
- **区域 E — 复制预览（后果摘要）**
  - Text 标题：「复制预览」
  - Text：「{N} 名用户将成为子管理员」
  - Text：「{M} 名已有子管理员将叠加新权限」
  - Text：「复制内容：可授权组织、可授权功能」
  - Text：「叠加不覆盖，原有权限不受影响」
- **区域 F — 校验错误列表（异常态）**
  - Text 标题：「以下 {K} 名用户不满足条件」
  - Button：「移除以上用户」
  - List：每条为 Text「{姓名} - {原因}」+ Button「移除」
- **区域 G — 操作按钮**
  - Button：「取消」（次要按钮）
  - Button：「确认复制」（主按钮，受区域 C 和 D 状态控制）

### 校验阻断态变化

| 触发条件 | 区域 F 状态 | 区域 G 变化 | 其他变化 |
|---------|-----------|-----------|---------|
| 区域 C 全取消 | 隐藏 | [确认复制] 置灰 | 区域 C 末尾出现 InlineNote「至少选择一项复制内容」 |
| 区域 D 为空 | 隐藏 | [确认复制] 置灰 | — |
| 校验失败（已加入/认证） | 显示 | [确认复制] 可用 | 区域 E 保留 |
| 网络异常提交失败 | 不适用 | [确认复制] 可用 | 区域 E 与 G 之间出现 Banner「提交失败，请检查网络后重试」+ Button「重试」 |

### 不合规确认区结构

当子管理员模式与双管理员互审模式同时开启时（且仅当此时）：

- 区域 E 尾部追加 Text：「提交后需另一方管理员审批通过方可生效」
- Toast 文案切换为「已提交复制审批，通过后生效」

## 6. 主交互流程

### 6.1 定位来源子管理员

- **用户动作**：在子管理员列表中浏览或搜索，定位目标子管理员行，查看行内组织范围和功能摘要
- **系统反馈**：列表展示姓名、手机号、可授权组织范围摘要、可授权功能数量摘要、启用状态；操作列「复制」在最左侧
- **下一步**：点击「复制」打开复制弹窗

### 6.2 配置复制信息与选择目标用户

- **用户动作**：
  - 在复制弹窗中查看来源信息
  - 确认复制信息勾选（可授权组织 / 可授权功能），可取消但至少保留一项
  - 点击「选择复制对象」打开员工选择器
  - 在员工选择器中搜索、浏览、勾选目标用户（查看状态标签）
  - 点击「确定」关闭选择器
- **系统反馈**：
  - 弹窗顶部展示复制来源
  - 复制信息区两个勾选项
  - 员工选择器中各行展示加入状态和认证状态标签，不合格者灰显+tooltip
  - 已选用户列表实时更新，计数「已选 {N}/200 人」
- **下一步**：查看后果摘要，准备提交

### 6.3 确认前查看后果摘要

- **用户动作**：在复制弹窗下半部分查看复制预览区，确认新增人数、叠加人数、复制内容
- **系统反馈**：预览区实时更新，区分「新增为子管理员」和「叠加权限」
- **下一步**：点击「确认复制」提交

### 6.4 系统校验与结果处理

- **用户动作**：点击确认后等待校验，查看结果
- **系统反馈**：
  - 校验通过：Modal 关闭
    - 无互审 → Toast「已成功复制给 {N} 名用户」
    - 有互审 → Toast「已提交复制审批，通过后生效」
  - 校验失败（加入/认证状态）：
    - Modal 不关闭
    - 区域 F 展示不满足条件的用户名和原因
- **下一步**：关闭弹窗回到列表验证

### 6.5 验证操作结果

- **用户动作**：在列表中检查目标用户状态，查看操作记录
- **系统反馈**：列表刷新，新子管理员出现，已有者权限更新；操作记录新增两条记录
- **下一步**：确认生效，任务完成

## 7. 校验规则

校验严格按以下顺序执行，任一失败即阻断：

| 顺序 | 校验对象 | 条件 | 阻断行为 | 错误提示 |
|------|---------|------|---------|---------|
| 1 | 复制信息 | 至少选中一项可授权组织或可授权功能 | 按钮置灰，不进入提交 | 「至少选择一项复制内容」 |
| 2 | 复制对象 | 至少选择一名目标用户 | 按钮置灰，不进入提交 | 「请选择至少一名复制对象」 |
| 3 | 加入状态 | 所有目标用户均为「已加入」 | Modal 不关闭，区域 F 展示 | 「{姓名} 加入状态不是已加入，不能成为子管理员」 |
| 4 | 认证状态 | 所有目标用户均为「已认证」 | Modal 不关闭，区域 F 展示 | 「{姓名} 未完成实名认证，不能成为子管理员」 |

校验 1 和 2 为前置阻断（按钮置灰），不触发请求。
校验 3 和 4 为提交后阻断（Modal 不关闭，展示错误列表区）。

额外校验（提交时一致性）：

| 校验对象 | 条件 | 阻断行为 | 错误提示 |
|---------|------|---------|---------|
| 复制来源状态 | 来源子管理员未被删除、停用、范围未被修改 | Toast 提示，不关闭 | 「复制来源已变更，请关闭弹窗后重新选择」 |
| 网络/服务端 | 请求正常返回 | Banner 提示，提供重试 | 「提交失败，请检查网络后重试」 |

## 9. 异常恢复

### 9.1 部分目标用户校验失败

- **触发条件**：存在不符合加入状态或认证状态要求的用户
- **反馈**：Modal 不关闭，区域 F 展示
- **恢复路径**：
  - 逐人移除：点击区域 F 或区域 D 中各用户行的「移除」按钮
  - 一键移除：点击「移除以上用户」按钮，批量移除所有不满足条件的用户
  - 取消操作：点击「取消」关闭弹窗
- **数据保留**：移除后重新提交不丢失其他已填内容

### 9.2 复制来源状态已变更

- **触发条件**：操作期间来源子管理员被删除、停用或权限范围被修改
- **反馈**：Toast「复制来源已变更，请关闭弹窗后重新选择」
- **恢复路径**：关闭弹窗回到列表重新选择来源；已选目标用户列表可尝试保留

### 9.3 目标用户数量达上限

- **触发条件**：已选 200 人
- **反馈**：选择器内提示「最多选择 200 名复制对象」，第 201 人起不可勾选
- **恢复路径**：移除部分已选用户后继续

### 9.4 网络异常提交失败

- **触发条件**：网络超时或服务端异常
- **反馈**：Banner「提交失败，请检查网络后重试」，提供「重试」按钮
- **恢复路径**：点击重试重新提交或取消后稍后重试，不丢失已填内容

## 10. 结果态

### 10.1 全部成功

校验通过 → Modal 关闭 → 列表刷新 → 操作记录生成

反馈文案：
- 未开启双管理员互审：Toast「已成功复制给 {N} 名用户」
- 开启双管理员互审：Toast「已提交复制审批，通过后生效」

### 10.2 部分成功

当前设计不支持「部分成功」模式。校验按序执行，任一失败即拦截并展示区域 F，用户选择移除不满足者后「全部成功」或取消操作。

若产品最终选择「过滤后继续」策略：移除不满足者后剩余用户全部成功。
若产品最终选择「全部回退」策略：任一失败则全部回退，不留部分成功态。
