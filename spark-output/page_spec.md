# 页面生成规格：员工自助申请权限

## 1. 页面摘要

- **产品领域**：权限管理 — 权限治理模式与员工自助授权
- **页面类型**：配置页、列表页、抽屉、弹窗
- **用户角色**：超级管理员、普通员工、审批人（组织负责人）
- **核心任务**：超管配置自助申请模式参数 → 员工查看权限并发起申请 → 审批人处理权限申请

- 第三步内容区：审批流程摘要展示，含"修改审批流程"入口
- 底部操作栏：上一步、下一步、取消、启用（根据步骤动态展示）

- 点击"启用"时校验互斥模式 → 校验失败弹出"无法启用弹窗"

- **应用列表**（选择应用弹窗内）：复选框、应用名称、应用终端、应用启用状态

| 操作 | 触发 | 结果 |

| 选择申请方式 | 点击对比卡片 | 高亮选中卡片，启用下一步 |
| 下一步 | 当前步骤完成后点击 | 进入下一步骤 |
| 上一步 | 点击 | 返回上一步骤（保留已填信息） |
| 启用 | 第三步点击"启用" | 校验互斥模式 → Toast 开启成功 |
| 取消 | 任意步骤点击 | 返回权限管理模式选择页 |
| 编辑（已开启态） | 点击"编辑" | 页面变为可编辑状态 |
| 确认编辑（已开启态） | 编辑完成后点击 | Toast 编辑成功 |
| 关闭模式（已开启态） | 点击"关闭模式" | 打开关闭模式二次确认弹窗 |
| 修改审批流程 | 第三步点击"修改审批流程" | 进入修改审批流程子页面 |

## 10. 关闭模式二次确认弹窗

### 弹窗目标

### 区域结构

```
+-------------------------------------------------------------------+
| 关闭模式                                                      [X]  |
+-------------------------------------------------------------------+
|                                                                   |
| [i] 关闭模式后，员工将无法自助查询和申请权限，已有权限不受影响，   |

```

### 区域说明

- 标题区：标题"关闭模式" + 关闭按钮

## 16. 主交互流程

### P1：超管配置自助申请模式

1. 超管进入权限管理模式选择页 → 看到"自助申请权限模式"卡片
2. 点击"立即启用" → 校验互斥模式
3. 校验通过 → 进入自助申请模式配置页（分步模式）
4. 第一步：选择申请方式（角色/功能权限），对比卡片展示，默认选中"申请角色"
5. 点击"下一步" → 进入第二步（根据选择展示角色范围或应用范围）
6. 第二步：选择全部/部分，选择部分时打开选择角色弹窗或选择应用弹窗
7. 点击"下一步" → 进入第三步
8. 第三步：查看预设审批流程摘要，可选"修改审批流程"进入子页面
9. 点击"启用" → 再次校验互斥模式
10. 校验通过 → Toast"开启成功" → 个人中心增加"我的权限"入口 → 页面刷新为已开启状态

**分支：**
- 互斥模式已开启 → 弹窗"无法启用"，阻止进入/启用
- 第二步选择"部分角色"/"部分应用" → 打开选择弹窗
- 点击"修改审批流程" → 打开修改审批流程子页面

### P2：员工查看我的权限并发起申请

1. 员工进入个人中心 → 点击"我的权限"
2. 我的权限页面加载，默认选中功能权限 tab
3. 点击右上角"申请权限" → 打开申请权限 Drawer
4. 填写申请原因，选择申请角色/功能权限
5. 点击"提交申请" → 前端校验 → 后端校验
6. 校验通过 → Drawer 关闭 → Toast"提交成功" → 申请记录新增"审批中"记录

**分支：**
- 未选择角色/功能 → 提交按钮置灰
- 申请原因为空 → 原因输入框显示 InlineError
- 后端校验不通过 → Drawer 不关闭，显示对应错误提示

### P3：审批人处理权限申请

*（OA 审批系统流程，本模块只引用不生成）*

### S1：超管编辑已开启的模式

1. 超管在已开启状态页点击"编辑" → 页面变为可编辑状态
2. 修改各步骤内容 → 点击"确认编辑" → Toast"编辑成功"
3. 页面回到不可编辑状态

### S2：超管关闭自助申请模式

1. 超管在已开启状态页点击"关闭模式"
2. 弹出关闭模式二次确认弹窗 → 点击"确认关闭"
3. 校验是否有在途流程
4. 无在途流程 → 关闭成功 → Toast 关闭成功
5. 有在途流程 → 关闭失败弹窗提示

### S3：员工撤销审批中的申请

1. 员工在申请记录列表找到审批中的记录 → 点击"撤销"
2. 弹出撤销申请确认弹窗 → 点击"确认撤销"
3. 申请单状态更新为"已撤销" → Toast"已撤销" → 审批人收到通知

### S4：员工查看申请记录

1. 员工进入申请记录列表（从我的权限页面切换 tab 或通过其他入口）
2. 筛选申请日期和审批状态 → 查看申请记录列表
3. 点击"撤销"对审批中的申请进行撤销操作

## 17. 校验规则

| 触发时机 | 校验内容 | 阻断条件 | 失败反馈 |
|----------|----------|----------|----------|
| 超管点击"立即启用"或"启用" | 双管理员互审模式/权限变更审批模式是否已开启 | 任一互斥模式已开启 | 无法启用弹窗，阻止进入/启用 |

| 员工点击"提交申请"（后端） | 资金用户校验 | 非资金用户申请代发付款相关权限 | Drawer 内提示 |

| 员工点击"提交申请"（后端） | 实名校验 | 申请人未实名 | Drawer 内提示 |
| 超管点击"确认编辑" | 互斥模式是否已被外部开启 | 编辑过程中互斥模式被开启 | 弹窗提示 |
| 超管在关闭确认弹窗中点击"确认关闭" | 是否存在在途审批流程 | 存在未完成审批的申请 | 关闭失败弹窗 |

## 19. 异常恢复

| 异常 | 反馈形式 | 信息丢失 | 恢复路径 |
|------|----------|----------|----------|

| 编辑时互斥模式被开启 | 弹窗提示 | 无 | 关闭弹窗，处理互斥模式 |
| 关闭模式时有在途流程 | 关闭失败弹窗 | 无 | 处理完成在途申请后再操作 |
