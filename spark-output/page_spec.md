# 页面生成规格：子管理员权限复制能力

---

## 1. 页面摘要
- **产品领域**：企业权限管理 — 子管理员治理
- **页面类型**：Page（用户授权页、权限复制页、复制结果页）、Drawer（权限全景预览）
- **用户角色**：企业超管（主管理员）
- **核心任务**：从现有子管理员复制权限到多个目标子管理员，并微调差异

---

## 2. 生成范围

### 生成
- 权限全景预览 Drawer
- 权限复制页
- 复制结果页

### 只引用不生成
- 用户授权页：已有页面，本次新增"复制权限"按钮和入口
- 权限编辑页：已有页面，本次作为微调跳转目标
- 操作记录页：已有页面，本次仅引用操作日志的字段和追溯入口

### 不生成
- 冲突原因码显示区域：复用知识库现有原因码体系，不新增独立页面或弹窗

---

## 3. 页面实体关系

```
用户授权 Page（承载页，已有）
  ├── [复制权限] 按钮（每个列表行 + 批量操作下拉）
  │   └──→ 权限全景预览 Drawer（新增）
  │         └──→ [确认使用此源] → 权限复制 Page（新增）
  │               ├── 区块1：源信息（只读）
  │               ├── 区块2：目标选择
  │               ├── 区块3：冲突策略
  │               └── 区块4：执行确认 → [执行复制]
  │                     └──→ 复制结果 Page（新增）
  │                           ├── [编辑权限] → 权限编辑 Page（已有）
  │                           ├── [撤销此变更]（行内操作）
  │                           └── [返回用户授权]
  └── [批量操作 ▼] → 含"批量复制权限"选项
```

## 4. 用户授权页（承载页）

### 页面目标
展示子管理员列表，提供检索、查看和复制权限的操作入口。

### 页面结构（区域 + 语义组件 + 字段）

- 筛选查询区
  - Input：姓名搜索
  - Input：手机号搜索
  - Select：角色筛选
  - Button：[重置] [查询] [更多筛选 ▼]
- 工具与操作区
  - Button：[+ 添加用户]、[关联角色]、[功能权限设置]、[数据权限设置]、[批量移除]、[导出权限]
  - 新增入口：[复制权限]（行内操作列 + 批量操作下拉"批量复制权限"选项）
  - TextLink：权限说明、操作文档
- 数据表格区
  - Checkbox：行选择
  - Text：姓名
  - Text：手机号
  - Tag：类型（内部/外部）
  - Text：来源
  - Text：角色
  - Tag：加入状态
  - Tag：实名认证状态
  - Actions：[功能权限] [数据权限] [复制权限] [...]
- 底部分页区
  - Pagination：共 {N} 条 < [1] 2 3 ... > [{X} 条/页 ▼]

### 关键操作
- 点击行操作列 [复制权限] → 打开权限全景预览 Drawer
- 批量操作下拉选择"批量复制权限" → 打开权限全景预览 Drawer（需先选中一个作为源）

### 提取备注
- 承载页面结构来自 knowledge-wiki `15_页面载体语义.md` 2.1 节
- 本次新增：[复制权限] 按钮出现在数据表格每行的操作列 Actions 固定字段中，同时在批量操作下拉中新增"批量复制权限"选项
- 本页不在本次生成范围内，仅列出修改点位

## 5. 权限全景预览 Drawer

### 弹窗目标
展示源子管理员的完整权限配置（菜单权限 + 数据权限），供用户确认该源是否适合作为复制来源。

### 触发条件
在用户授权页点击子管理员行操作列的"复制权限"按钮，或批量操作下拉的"批量复制权限"。

### 弹窗结构

```

│  Drawer 标题区                                │
│  [Left]:  权限全景预览 — {子管理员姓名}          │
├──────────────────────────────────────────────┤
│  菜单权限区域                                  │
│  ┌─ 标题行：菜单权限（共 {N} 项）              │
│  │                                             │
│  │  ├─ 应用分组 1 （可展开/收起）               │
│  │  │  ├ ☑ {权限名} {操作类型}                 │
│  │  │  ├ ☑ {权限名} {操作类型}                 │
│  │  │  └ ...                                  │
│  │  │                                         │
│  │  ├─ 应用分组 2 （可展开/收起）               │
│  │  │  ├ ☑ {权限名} {操作类型}                 │
│  │  │  └ ...                                  │
│  │  └─ ...                                    │
│  └─────────────────────────────────────────┘  │
│                                                │
│  数据权限区域                                  │
│  ┌─ 标题行：数据权限（共 {M} 项）              │
│  │                                             │
│  │  ├─ 应用分组 1                              │
│  │  │  范围：{数据范围描述}                     │
│  │  ├─ 应用分组 2                              │
│  │  │  范围：{数据范围描述}                     │
│  │  └─ ...                                    │
│  └─────────────────────────────────────────┘  │
├──────────────────────────────────────────────┤
│  底部操作栏                                    │
│  [Cancel: 取消] [Primary: 确认使用此源]         │
└──────────────────────────────────────────────┘
```

### 区域说明

| 区域 | 内容 | 组件类型 |
|------|------|----------|
| Drawer 标题区 | 标题文本 "权限全景预览 — {子管理员姓名}" | Text |
| 菜单权限区域 | 按应用分组展示菜单权限项，每组可展开/收起，默认收起细节只显示概览数量（如"库存管理应用（5项）"） | CollapseGroup, Checkbox (只读) |
| 数据权限区域 | 按应用分组展示数据权限范围描述 | ListGroup, Text |
| 底部操作栏 | 确认按钮 + 取消按钮 | Button (Primary + Default) |

### 校验阻断态变化

- **空权限态**：菜单权限和数据权限均为空时，Drawer 内容区展示空状态 EmptyState（插图 + 文案"该管理员暂无权限"），底部 [确认使用此源] 按钮置灰不可点击
- **加载态**：权限数据加载中展示 SkeletonLoadingState

### 按钮

| 按钮 | 文案 | 行为 |
|------|------|------|
| 确认使用此源 | "确认使用此源" | 关闭 Drawer，进入权限复制页 |
| 取消 | "取消" | 关闭 Drawer |

### 校验阻断态变化

- **空目标**：目标列表为空时，区块 3 和区块 4 不可见（或禁用），底部提示"请先选择目标子管理员"
- **执行中**：[执行复制] 按钮变更为加载态，文案变为 "正在复制（{当前}/{总数}）"，可点击取消
- **执行取消中**：进度区域显示 "正在回滚已处理的部分，请稍候"
- **数据过期**：点击执行时后端校验发现数据版本不匹配，Banner 提示 "权限数据已更新，请刷新后重新确认复制参数"

### 按钮

| 按钮 | 文案 | 行为 |
|------|------|------|
| 执行复制 | "执行复制" | 触发复制操作，按钮变为加载态 |
| 查看冲突详情 | "查看冲突详情" | 展开冲突详情区域（区块内展开，不跳转） |

```
└──────────────────────────────────────────────────┘
```

### 校验阻断态变化

- **全部变更**：正常展示变更摘要，无阻断
- **无变更态**：所有目标均无权限变更，顶部提示 "所有目标已具有相同权限，无需变更"
- **部分成功态**：失败的卡片用红色边框标记，失败 Tag 显示 "复制失败 — {原因码}"
- **全部失败态**：所有卡片均为红色失败态，顶部结果为 "复制失败，请检查后重新配置"

### 按钮

| 按钮 | 文案 | 行为 |
|------|------|------|
| 查看详情 ▾ | "查看详情" + 箭头 | 展开/收起该目标的差异对比详情（Toggle） |
| 编辑权限 | "编辑权限" | 跳转到该子管理员的权限编辑页 |
| 撤销此变更 | "撤销此变更" | 弹出确认弹窗 "确定撤销此项权限变更？"，确认后撤销并更新摘要 |
| 重试 | "重试" | 重新执行该目标的复制（仅失败态） |
| 返回用户授权 | "返回用户授权" | 返回用户授权页 |

## 8. 主交互流程

### 节点 1：选择源子管理员（用户授权页 → 预览 Drawer）

1. 用户在用户授权页的列表中选中一行，点击该行操作列的 [复制权限] 按钮
2. 系统打开权限全景预览 Drawer，开始加载该子管理员的权限数据
3. 加载完成后，Drawer 展示该子管理员在全部子应用下的菜单权限和数据权限总览
4. 用户查看权限全景，确认该子管理员是否适合作为复制源
5. 用户点击 [确认使用此源] → Drawer 关闭 → 跳转到权限复制页
6. 用户点击 [取消] → Drawer 关闭 → 停留在用户授权页

**分支**：
- 源权限为空 → Drawer 内展示空状态，[确认使用此源] 置灰
- 权限数据加载失败 → Drawer 内展示错误提示 + [重新加载]

### 节点 2：配置目标与策略（权限复制页）

1. 页面加载后，区块 1 源信息已自动填充（只读）
2. 用户在区块 2 中搜索或筛选目标子管理员，从结果列表中勾选
3. 系统自动检测各目标的已有权限状态，展示权限状态标签
4. 用户确认目标后，进入区块 3
5. 区块 3 展示冲突检测结果，用户选择冲突处理策略（RadioGroup）
6. 如选择"追加，遇冲突时逐项提示"且有冲突项 → 用户可点击 [查看冲突详情] 展开后逐项选择

**分支**：
- 目标列表为空 → 底部提示"当前无可选目标子管理员"
- 无冲突目标 → 区块 3 显示绿色标记"无冲突，可正常复制"，不出现在冲突详情

### 节点 3：确认并执行复制（权限复制页 → 复制结果页）

1. 区块 4 展示操作确认摘要（源、目标、策略、预计操作）
2. 用户点击 [执行复制]
3. 按钮变为加载态，展示进度 "正在复制（{当前}/{总数}）"
4. 系统逐目标执行权限复制
5. 全部完成后自动跳转到复制结果页

**分支**：
- 用户点击取消 → 确认弹窗后回滚已处理项 → 返回权限复制页
- 部分目标失败 → 跳转到复制结果页，失败项标记红色 + 失败原因
- 全部失败 → 复制结果页展示全部失败态
- 数据过期（执行前检测） → 弹窗提示刷新，不执行
- 执行超时 → Toast 提示异步处理，可离开页面后从操作日志查看

## 9. 校验规则

| 校验时机 | 校验条件 | 阻断 | 用户反馈 |
|----------|----------|------|----------|
| 确认源时 | 源权限数据是否为空 | 是 | Drawer 空状态提示，确认按钮置灰 |
| 选择目标时 | 是否有已勾选的目标 | 否（但复制按钮需至少 1 个目标才激活） | 提示 "请先选择目标子管理员" |
| 执行复制前 | 数据版本是否一致 | 是 | 弹窗 "权限数据已更新，请刷新后重新确认复制参数" |
| 执行复制中 | 各目标是否处理成功 | 否（部分失败继续处理剩余目标） | 结果页展示失败项 |

## 10. 状态表现

| 状态 | 触发条件 | UI 表现 | 文案 key |
|------|----------|---------|----------|
| 待配置 | 用户尚未进入复制流程 | 复制入口可用 | page_spec.copy.entry |
| 源确认中 | Drawer 打开，权限数据加载中 | Skeleton 加载态 | — |

## 11. 异常恢复

### 异常 1：源子管理员无任何权限

- **恢复路径**：关闭 Drawer → 回到用户授权页 → 重新选择其他源子管理员。原路返回，无信息丢失。

### 异常 2：所有目标均无权限变更

- **恢复路径**：确认提示后关闭复制结果页。无信息丢失，未做任何实际变更。

### 异常 3：执行复制操作超时

- **恢复路径**：操作进入异步处理，用户可离开当前页面。完成后通过操作日志追溯结果。中间状态不做回滚，以最终后端结果为准。

### 异常 4：部分目标复制失败

- **恢复路径**：已成功的项不做回滚。用户可点击失败卡片上的 [重试] 按钮重新处理失败项，或跳过失败项只处理成功项。

### 异常 5：微调时并发冲突

- **恢复路径**：关闭冲突弹窗 → 刷新权限编辑页查看最新配置 → 重新定位需要调整的权限项并再次编辑。丢失编辑界面的未保存更改，但不丢失业务意图。

### 异常 6：执行复制时数据已变更

- **恢复路径**：关闭弹窗 → 刷新权限复制页 → 重新确认复制参数（源、目标、策略）。无部分写入风险，因为执行被前置校验拦截。
