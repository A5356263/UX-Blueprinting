# 页面生成规格：员工自助权限申请

---

## 1. 页面摘要

- **产品领域**：企业权限管理 — 员工自助权限申请
- **页面类型**：页面（我的权限 / 申请记录 / 审批详情 / 自助申请配置）、Drawer（权限申请）、Modal（关闭确认）
- **用户角色**：员工、审批人、管理员
- **核心任务**：员工申请权限 → 审批人审批 → 系统自动授权

---

## 4. 我的权限 Page

### 页面目标

员工在此页面查看自己已有的权限列表、浏览可申请权限，并发起权限申请。

### 页面结构

```
┌─────────────────────────────────────────┐
│ R1 标题区                               │
│  Text: 我的权限                          │
│  Button: 申请权限 [Primary]             │
│  Text: 查看你已有的权限，或申请新的权限    │
├─────────────────────────────────────────┤
│ R2 已有权限区                           │
│  ┌─────────────────────────────────────┐│
│  │  Heading: 已有权限 (共 {已有权限总数}) ││
│  │                                     ││
│  │  CollapseGroup: 按 {应用名} 分组     ││
│  │    ├─ {应用名_1}                     ││
│  │    │   ├─ {权限名} —— {场景说明}     ││
│  │    │   └─ {权限名} —— {场景说明}     ││
│  │    ├─ {应用名_2}                     ││
│  │    │   └─ ...                        ││
│  │    └─ TextLink: 展开全部             ││
│  └─────────────────────────────────────┘│
├─────────────────────────────────────────┤
│ R3 可申请权限区                         │
│  ┌─────────────────────────────────────┐│
│  │  Heading: 可申请权限 ({可申请总数})   ││
│  │  Input: 🔍 搜索权限名称             ││
│  │  Tabs: [全部] [{应用名_1}] [{应用名_2}]│
│  │                                     ││
│  │  List:                              ││
│  │    ├─ {权限名} —— {场景说明}        ││
│  │    │  Button: 申请                  ││
│  │    └─ {权限名} —— {场景说明}        ││
│  │       Button: 申请                  ││
│  └─────────────────────────────────────┘│
└─────────────────────────────────────────┘
```

### 区域说明

- **R1 标题区**：页面标题 + 主操作按钮 + 副标题说明
- **R2 已有权限区**：按应用分组展示当前员工已有的权限，默认收起，可展开
- **R3 可申请权限区**：展示管理员开放给员工自助申请的全部权限，支持搜索和应用筛选

### 列表字段

已有权限列表：{权限名}、{场景说明}、所属 {应用名}
可申请权限列表：{权限名}、{场景说明}、所属 {应用名}

### 关键操作

- Button [申请权限]：右上角主按钮，点击打开权限申请 Drawer（§5）
- Button [申请]：可申请权限行内按钮，点击直接选中该权限并打开权限申请 Drawer（§5），权限项自动选中
- TextLink [展开全部]：展开已折叠的应用分组

### 状态反馈区

- LoadingState：骨架屏，权限列表按应用分组占位
- EmptyState（无任何权限）："暂无权限数据" + Text "如需申请权限，点击右上角 [申请权限]"
- EmptyState（无可申请权限）："当前无可申请的权限" + Text "如需其他权限，请联系管理员"
- InlineError（加载失败）："权限数据加载失败" + Button [重新加载]

### 提取备注

- 此页面为本次新增的员工端页面，知识库中不存在对应页面载体定义
- 结构来自体验蓝图 §6.1

## 5. 权限申请 Drawer

### Drawer 目标

员工在此 Drawer 中选择需要申请的权限、填写申请原因并提交。

### 触发条件

员工在"我的权限 Page"点击 [申请权限] 主按钮，或点击可申请权限行的 [申请] 按钮。

### 区域结构

```
┌───────────────────────────────────────┐
│ R1 标题区                            │
│  ← IconArrow: 返回                    │
│  Text: 申请权限                        │
│  IconButton: ✕ 关闭                   │
├───────────────────────────────────────┤
│ R2 权限选择区                        │
│  Input: 🔍 搜索权限名称               │
│                                     │
│  RadioGroup: 单选                    │
│    ├─ ◉ {权限名}                     │
│    │  Text: {场景说明}                │
│    ├─ ○ {权限名}                     │
│    │  Text: {场景说明}                │
│    └─ ○ {权限名}                     │
│       Text: {场景说明}                │
├───────────────────────────────────────┤
│ R3 申请原因区                        │
│  Textarea:                           │
│    placeholder: "请说明为什么需要     │
│    该权限，例如：因负责XX业务，需要   │
│    查看XX数据"                       │
│                                     │
│  Text: {当前字数}/{最大字数}          │
├───────────────────────────────────────┤
│ R4 底部操作区                        │
│  Text: 已选择：{权限名}               │
│  Button: 取消                         │
│  Button: 提交申请 [Primary]           │
│    disabled: 未选择权限 或 原因为空   │
└───────────────────────────────────────┘
```

### 区域说明

- **R1 标题区**：返回箭头 + 标题 + 关闭按钮
- **R2 权限选择区**：可申请权限列表，单选模式，支持搜索筛选
- **R3 申请原因区**：多行文本输入，含占位符引导，实时字数统计
- **R4 底部操作区**：已选权限摘要 + 取消/提交按钮

### 校验阻断态变化

- 未选择权限 → Button [提交申请] 置灰
- 申请原因为空 → Button [提交申请] 置灰
- 提交校验失败 → Drawer 不关闭，对应位置显示 InlineError：
  - 超出范围 → R2 该权限项下方显示 InlineError "该权限暂未开放自助申请"
  - 已有该权限 → R2 该权限项下方显示 InlineError "您已有该权限，无需重复申请"
  - 存在进行中申请 → R2 该权限项下方显示 InlineError "该权限已有一个进行中的申请"
  - 审批人缺失 → Toast "审批流程未配置有效审批人，请联系管理员处理"

### 提取备注

- 父页面：我的权限 Page（§4）
- 当前为单选设计；如后续支持多选，R2 的 RadioGroup 需改为 CheckboxGroup

│  ├─────────────────────────────────────┤│

### 区域说明

- **R1 标题区**：返回箭头 + 页面标题
- **R2 状态时间线**：垂直时间线展示完整状态流转，节点按时间倒序排列
- **R3 申请信息区**：申请权限名称和申请原因
- **R4 操作区**：返回、催办、撤销操作按钮

### 关键操作

- Button [返回列表]：回到申请记录列表
- Button [催办]：仅审批中状态可见，点击后 Toast "已催办审批人"，按钮置灰 24 小时
- Button [撤销申请]：仅审批中状态可见，点击弹出确认 Modal

### 状态反馈区

- 拒绝状态：R2 时间线中 "❌ 已拒绝 + 拒绝原因"
- 授权异常状态：R2 中 "✅ 已通过（授权异常）" + Text "自动授权失败，请联系管理员"
- 已撤销状态：R2 中 "↩️ 已撤销"

### 提取备注

- 此页面为本次新增页面，结构来自体验蓝图 §6.4

## 9. 自助申请配置 Page（管理端）

### 页面目标

管理员在此开启/关闭自助申请能力，配置可申请权限范围和审批流程。

### 进入条件

管理员进入权限管理 → 自助申请配置。

### 页面结构

```
┌─────────────────────────────────────────┐
│ R1 标题区                               │
│  Text: 自助申请配置                      │
├─────────────────────────────────────────┤
│ R2 启用状态区                           │
│  Switch: 启用状态 [● ON]                │
│  Text: 开启后，员工可在指定范围内        │
│        自助申请权限                      │
├─────────────────────────────────────────┤
│ R3 可申请范围区                         │
│  (enabled: Switch=ON)                   │
│  Heading: 可申请范围                     │
│  Select: 范围类型 ▾                     │
│    Options: 按功能权限 / 按角色          │
│             / 按应用                     │
│                                         │
│  Input: 🔍 搜索权限                     │
│                                         │
│  CheckboxGroup: 按 {应用名} 分组        │
│    ├─ ☑ ☐ 全部 (全选/取消全选)         │
│    ├─ ▸ {应用名_1}                      │
│    │   ├─ ☑ {权限名}                    │
│    │   └─ ☑ {权限名}                    │
│    └─ ▸ {应用名_2}                      │
│        ├─ ☐ {权限名}                    │
│        └─ ☐ {权限名}                    │
├─────────────────────────────────────────┤
│ R4 审批流程区                           │
│  (enabled: Switch=ON)                   │
│  Heading: 审批流程                       │
│  Select: 选择审批流程 ▾                 │
│  Text: 当前：{审批流程名}                │
│  TextLink: 编辑审批流程                  │
├─────────────────────────────────────────┤
│ R5 底部操作区                           │
│  Button: 员工视角预览                    │
│  Button: 保存 [Primary]                  │
└─────────────────────────────────────────┘
```

### 区域说明

- **R1 标题区**：页面标题
- **R2 启用状态区**：Switch 开关 + 功能说明
- **R3 可申请范围区**：范围类型选择 + 权限搜索 + 权限分组勾选（Switch=OFF 时置灰不可编辑）
- **R4 审批流程区**：审批流程选择 + 编辑链接（Switch=OFF 时置灰不可编辑）
- **R5 底部操作区**：预览 + 保存按钮

### 校验阻断态变化

- 未勾选任何权限 → Button [保存] 下方 InlineError "请至少选择一个可申请的权限"
- 未选择审批流程 → Button [保存] 下方 InlineError "请选择审批流程"

### 关键操作

- Switch [启用状态]：切换后校验是否与现有治理模式冲突；冲突时阻止切换并弹窗提示
- Select [范围类型]：切换时下方权限列表自动按所选类型重新组织
- Select [审批流程]：选择当前可用的审批流程
- TextLink [编辑审批流程]：跳转至审批管理进行流程配置
- Button [员工视角预览]：预览模式，展示员工端"我的权限 Page"效果（仅查看，不可操作）
- Button [保存]：保存全部配置

### 状态反馈区

- Switch=OFF 时：R3、R4 区域整体置灰，提示文字"请先启用自助申请"
- 保存成功：Toast "配置已保存"
- 关闭功能：Switch 切换为 OFF → 校验进行中申请 → 弹出关闭确认 Modal（§10）

## 10. 关闭确认 Modal

### Modal 目标

确认管理员的关闭意图，告知进行中申请不受影响。

### 触发条件

管理员在自助申请配置 Page 将 [启用] 开关切换为 OFF，且存在进行中的申请。

### 弹窗结构

```
┌─────────────────────────────────────┐
│ R1 标题区                          │
│  Text: 关闭自助申请                 │
├─────────────────────────────────────┤
│ R2 内容区                          │
│  Text: 关闭后，员工将无法提交新的   │
│        权限申请。                   │
│  Text: 当前有 {N} 个申请正在进行中，│
│        关闭后这些申请将继续正常     │
│        流转。已授予的权限不会被     │
│        收回。                       │
├─────────────────────────────────────┤
│ R3 操作区                          │
│  Button: 取消                       │
│  Button: 确认关闭 [Danger]         │
└─────────────────────────────────────┘
```

### 区域说明

- **R1 标题区**：Modal 标题
- **R2 内容区**：关闭说明 + 进行中申请数量提示
- **R3 操作区**：取消 + 确认关闭按钮

### 特殊情况

- 无进行中申请时：不弹出 Modal，直接关闭并显示 Toast "自助申请已关闭"

### 提取备注

- 父页面：自助申请配置 Page（§9）
- 结构来自体验蓝图 §6.7

## 11. 主交互流程

### 流程：员工提交权限申请

**实体**：我的权限 Page → 权限申请 Drawer → 申请记录列表 Page

1. **进入我的权限 Page**
   - 用户动作：从导航进入"我的权限"
   - 系统反馈：加载权限列表，展示已有权限和可申请权限
   - 下一步：点击 [申请权限]（右上角）或行内 [申请]

2. **打开申请 Drawer**
   - 用户动作：点击 [申请权限] 或行内 [申请]
   - 系统反馈：右侧滑出权限申请 Drawer
   - 行内 [申请] 触发时：Drawer 中该权限自动选中
   - 下一步：在列表中选择权限

3. **选择权限并填写原因**
   - 用户动作：点击选中一个权限项（单选），在输入区填写申请原因
   - 系统反馈：选中项高亮，底部"已选择"区域更新
   - 下一步：点击 [提交申请]

4. **提交申请（含校验）**
   - 用户动作：点击 [提交申请]
   - 系统反馈：依次校验——①是否在可申请范围 ②是否已有该权限 ③是否存在进行中相同申请 ④审批流程是否有有效审批人
   - 校验通过：Drawer 关闭 → Toast "申请已提交，请等待审批" → 申请记录列表新增"审批中"记录
   - 校验失败：Drawer 不关闭，对应位置显示 InlineError
   - 下一步：查看申请记录

5. **跟踪结果**
   - 用户动作：进入申请记录列表 → 点击 [查看详情]
   - 系统反馈：展示时间线 → 状态更新
   - 下一步：审批中 → 可催办或撤销；已生效 → 流程结束

### 流程：审批人审批申请

**实体**：审批通知/待办 → 审批详情 Page

1. **接收通知进入详情**
   - 用户动作：点击审批通知或从待办列表进入
   - 系统反馈：加载审批详情 Page
   - 下一步：查看申请信息

2. **评估并做出决定**
   - 用户动作：查看权限详情、影响范围、申请原因 → 点击 [同意] 或 [拒绝]
   - 拒绝时填写审批意见
   - 系统反馈：
     - 同意 → Toast "已同意，正在自动授权" → 状态变更为"已通过" → 系统自动授权 → 状态变更为"已生效"或"授权异常"
     - 拒绝 → Toast "已拒绝" → 状态变更为"已拒绝"
   - 下一步：返回待办列表

### 流程：管理员开启配置

**实体**：自助申请配置 Page

1. **切换启用**
   - 用户动作：切换 Switch 为 ON
   - 系统反馈：校验是否与现有模式冲突 → 无冲突时 R3/R4 区域解锁可编辑
   - 下一步：配置范围和审批流程

2. **配置范围**
   - 用户动作：选择范围类型 → 勾选权限
   - 系统反馈：权限列表按所选类型重新组织
   - 下一步：配置审批流程

3. **配置审批流程**
   - 用户动作：选择审批流程
   - 系统反馈：显示选中流程名
   - 下一步：点击 [保存]

4. **保存配置**
   - 用户动作：点击 [保存]
   - 系统反馈：校验范围+流程是否已选 → Toast "配置已保存，自助申请已启用"
   - 下一步：点击 [员工视角预览] 查看效果

### 流程：管理员关闭功能

**实体**：自助申请配置 Page → 关闭确认 Modal

1. **切换关闭**
   - 用户动作：切换 Switch 为 OFF
   - 系统反馈：校验是否存在进行中的申请
   - 有进行中申请 → 弹出关闭确认 Modal
   - 无进行中申请 → 直接关闭 → Toast "自助申请已关闭"

2. **确认关闭**
   - 用户动作：在 Modal 中点击 [确认关闭]
   - 系统反馈：Toast "自助申请已关闭" → 页面 R3/R4 置灰
   - 下一步：无需操作

## 12. 校验规则

| 触发位置 | 校验条件 | 校验失败处理 | 恢复路径 |
|---|---|---|---|
| 申请 Drawer - 提交 | 所选权限是否在可申请范围 | 权限项下方 InlineError "该权限暂未开放自助申请" | 重新选择 |
| 申请 Drawer - 提交 | 员工是否已有该权限 | 权限项下方 InlineError "您已有该权限，无需重复申请" | 重新选择 |
| 申请 Drawer - 提交 | 是否存在审批中相同申请 | 权限项下方 InlineError "该权限已有一个进行中的申请" | 查看现有申请 |
| 申请 Drawer - 提交 | 审批流程是否有有效审批人 | Toast "审批流程未配置有效审批人" | 联系管理员 |
| 申请 Drawer - 提交 | 是否已选择权限 | [提交] 按钮置灰 | 选择权限 |
| 申请 Drawer - 提交 | 申请原因是否为空 | [提交] 按钮置灰 | 填写原因 |
| 审批详情 - 拒绝 | 拒绝时是否填写审批意见 | [拒绝] 按钮置灰，Textarea InlineError "请填写拒绝原因" | 填写意见 |
| 配置页 - 保存 | 是否勾选了至少一个权限 | [保存] 下方 InlineError "请至少选择一个可申请的权限" | 勾选权限 |
| 配置页 - 保存 | 是否选择了审批流程 | [保存] 下方 InlineError "请选择审批流程" | 选择流程 |
| 配置页 - 开启 | 是否与现有治理模式冲突 | 弹窗提示"当前已开启{冲突模式}，不支持同时开启" | 关闭冲突模式 |

## 13. 状态表现

| 状态 | 触发条件 | UI 表现 | 文案 key |
|---|---|---|---|
| 草稿 | 员工已填写但未提交 | 不展示（提交后进入列表） | states.draft |
| 审批中 | 提交成功，等待审批人处理 | Tag: 审批中（蓝色） | states.pending |

| 已生效 | 系统自动授权完成 | Tag: 已生效（绿色）+ ✅ 图标 | states.effective |
| 已拒绝 | 审批人拒绝 | Tag: 已拒绝（红色）+ 时间线显示拒绝原因 | states.rejected |
| 已撤销 | 员工主动撤销 | Tag: 已撤销（灰色）+ ↩️ 图标 | states.revoked |
| 授权异常 | 审批通过但自动授权失败 | Tag: 已通过 + 黄色 ⚠️ 标记 + 提示联系管理员 | states.auth_failed |

## 14. 异常恢复

| 异常 | 影响 | 恢复路径 |
|---|---|---|
| 申请超出范围 | 无法提交该权限的申请 | 重新选择，无信息丢失 |
| 已有该权限 | 无法重复提交 | 重新选择，无信息丢失 |
| 存在进行中相同申请 | 无法重复提交 | 查看已有申请，无信息丢失 |
| 审批人缺失 | 无法提交申请 | 联系管理员配置审批人后重新提交，已填信息保留 |
| 审批通过但授权失败 | 申请停留在"已通过"状态，权限未生效 | 管理员手动授权，状态更新为"已生效" |
| 关闭期间的新申请 | 提交入口不可用 | 联系管理员重新开启 |
| 审批超时未处理 | 申请积压在"审批中" | 员工催办 / 管理员转派审批人 |
| 申请已被撤销时审批人操作 | 审批人操作区隐藏 | 返回待办列表 |
