# 页面生成规格：财富专区-资产配置面客版

## 1. 页面摘要
- **产品领域**：财富专区 — 资产配置
- **页面类型**：单页式建议书页面、弹窗
- **用户角色**：企业客户
- **核心任务**：查看资产配置建议书并根据诊断建议购买产品或下载建议书

---

## 2. 生成范围

### 生成
- 资产配置页面
- 下载格式选择弹窗

### 只引用不生成
- 产品详情页：从产品推荐列表的产品名称链接跳转进入
- 购买页：从产品购买按钮新开页签跳转进入
- 购物车：从批量购买按钮新开页签跳转进入
- 产品列表页：从无持仓数据空状态的[去购买]按钮跳转进入

### 不生成
- （无）

---

## 3. 页面实体关系

| 实体 | 类型 | 关系 |
|------|------|------|
| 资产配置页面 | Page | 主承载页面，包含所有数据模块和操作入口 |
| 下载格式选择弹窗 | Modal | 从资产配置页面浮动下载按钮打开 |
| 产品详情页 | Page（外部引用） | 从资产配置页面产品名称链接跳转（本页签） |
| 购买页 | Page（外部引用） | 从资产配置页面购买按钮跳转（新页签） |
| 购物车 | Page（外部引用） | 从资产配置页面批量购买按钮跳转（新页签） |
| 产品列表页 | Page（外部引用） | 从资产配置页面空状态[去购买]跳转 |

## 4. 资产配置页面

### 页面目标

企业客户在此页面查看完整的资产配置建议书——了解持仓全貌、发现问题、获得推荐、采取行动。

### 区域说明

| 区域 | 名称 | 用途 | 内容元素 |
|------|------|------|----------|
| A | 顶部导航区 | 页面标题和全局操作入口 | Text（返回）、Text（页面标题：资产配置）、Button（浮动下载） |
| B | 账号选择区 | 选择要查看的银行账号 | Select（账号选择器，选项：全部账号/{单个账号}） |
| C | 持仓表现模块 | 展示核心资产表现指标和趋势 | Tag（仅理财）、Select（时间区间）、StatCard×4、Chart×2、Table（收益排行） |
| C1 | 时间区间筛选器 | 选择近两年内的数据范围 | Select（预设区间/自定义起止日期） |
| C2 | 核心指标卡片 | 展示时点资产、区间收益、年化收益率、较期初增长 | StatCard×4 |
| C3 | 持仓变动趋势 | 展示持仓市值走势 | Chart |
| C4 | 收益金额趋势 | 展示收益金额走势 | Chart |
| C5 | 产品收益排行 | 按持仓收益降序排列的产品列表 | Table（产品名称/代码、持仓收益） |
| D | 投资分布/期限分布模块 | 展示多资产类型的分布情况 | Tag（含理财/基金/资管/信托）、Tabs（投资分布/期限分布） |
| D1 | Tab切换 | 在投资分布和期限分布间切换 | Tabs |
| D2 | 投资分布内容 | 饼图+列表展示各类资产占比 | Chart（饼图）、List |
| D3 | 期限分布内容 | 按产品期限汇总持仓 | List |
| E | 持仓诊断模块 | 展示诊断结果，有则展示无则不展示 | Tag（仅理财）、List（诊断卡片×N，可展开） |
| E1 | 诊断卡片 | 单项诊断结果及查看入口 | Text（诊断标题）、Tag（诊断描述）、Link（查看详情） |
| F | 产品推荐模块 | 推荐产品列表和购买操作 | Tag（仅理财）、List（推荐产品行）、Button（批量购买）、Text（精度提示） |
| F1 | 推荐产品行 | 单个推荐产品的信息和操作 | Checkbox、Text（产品信息）、Button（购买）、Link（详情） |
| F2 | 批量操作按钮 | 已勾选产品的批量购买入口 | Button（批量购买） |
| F3 | 精度提示 | 说明收益率数据仅供参考 | Text |
| G | 底部免责区 | 统一监管免责声明 | TextBlock |

### 提取备注

- 本页面为顶级页面，有独立菜单入口"资产配置"（原理财月报更名）
- 结构来自体验蓝图 §6，经 page-spec 整理为线框和区域说明
- 持仓诊断模块（区域 E）为条件展示模块——所有诊断规则未命中时整区域不展示
- 投资分布和期限分布共用同一模块区域 D，通过 Tab 切换视图

### 关键操作

| 操作 | 触发方式 | 结果 |
|------|----------|------|
| 选择账号 | 下拉选择器选择账号项 | 全页面数据切换为选中账号数据 |
| 调整时间区间 | 下拉选择器选择预设或自定义区间 | 持仓表现模块数据刷新 |
| 切换分布Tab | 点击 Tab 标签 | 切换投资分布/期限分布视图 |
| 查看诊断详情 | 点击 [查看详情] | 展开诊断对应的产品列表 |

| 批量购买 | 勾选产品后点击 [批量购买] | 新开页签跳转购物车 |
| 查看产品详情 | 点击产品名称/代码链接 | 本页签跳转产品详情页 |
| 下载建议书 | 点击浮动 [下载] 按钮 | 打开下载格式选择弹窗 |
| 去购买（空状态） | 点击 [去购买] | 跳转产品列表页 |

## 5. 下载格式选择弹窗

### 弹窗目标

让用户选择下载格式后触发文件生成和浏览器下载。

### 区域结构（ASCII 框图 + 区域说明）

```ascii
┌────────────────────────────────┐
│  下载建议书                     │  ← 区域 A：标题区
│                                │
│  请选择下载格式：               │  ← 区域 B：说明区
│  ○ PDF格式                     │  ← 区域 C：选项区
│  ● PNG图片                     │
│                                │
│   [取消]     [下载]             │  ← 区域 D：操作按钮区
└────────────────────────────────┘
```

### 区域说明

| 区域 | 名称 | 用途 | 内容元素 |
|------|------|------|----------|
| A | 标题区 | 弹窗标题 | Text（下载建议书） |
| B | 说明区 | 引导用户选择 | Text（请选择下载格式：） |
| C | 选项区 | 格式选择 | Radio×2（PDF格式、PNG图片） |
| D | 操作按钮区 | 取消或确认下载 | Button×2（取消、下载） |

### 校验阻断态变化

- 无校验阻断。用户选择任一格式后点击 [下载] 即可执行。

### 不合规确认区结构

- 不适用。弹窗不涉及合规确认场景。

## 6. 主交互流程

### 6.1 进入资产配置页面

| 字段 | 内容 |
|------|------|
| 触发 | 用户从财富专区菜单点击"资产配置"，或从持仓列表页面点击资产配置入口 |
| 用户动作 | 点击入口链接 |
| 系统反馈 | 进入资产配置页面，默认加载全部账号的资产数据 |
| 状态变化 | 页面及各模块进入加载态 |
| 下一步 | 用户选择账号或浏览数据 |

### 6.2 选择银行账号

| 字段 | 内容 |
|------|------|
| 触发 | 用户操作账号选择器 |
| 用户动作 | 在下拉选择器中选中一个银行账号或保持"全部账号" |
| 系统反馈 | 全页面数据切换为选中账号的数据，各模块独立展示加载态后更新 |
| 状态变化 | 各模块重新加载 |
| 下一步 | 查看更新后的持仓表现数据 |

### 6.3 调整时间区间

| 字段 | 内容 |
|------|------|
| 触发 | 用户操作时间区间筛选器 |
| 用户动作 | 选择预设区间（近一个月/近三个月等）或自定义起止日期 |
| 系统反馈 | 持仓表现模块内的数据卡片和趋势图独立加载更新 |
| 状态变化 | 持仓表现模块重新加载（其他模块不变） |
| 下一步 | 浏览更新后的持仓表现数据 |

### 6.4 查看诊断详情

| 字段 | 内容 |
|------|------|
| 触发 | 诊断模块存在诊断卡片 |
| 用户动作 | 点击诊断卡片的 [查看详情] |
| 系统反馈 | 展开或跳转至该诊断对应的产品列表 |
| 状态变化 | 诊断卡片展开/收起 |
| 下一步 | 用户查看具体产品信息 |

### 6.5 购买产品

| 字段 | 内容 |
|------|------|
| 触发 | 用户决定购买推荐产品 |
| 用户动作 | 点击行级 [购买] 按钮（单独购买），或勾选产品后点击 [批量购买] |
| 系统反馈 | 新开页签跳转购买页或购物车；原页签维持当前页面状态 |
| 状态变化 | 新页签打开 |
| 下一步 | 用户在新页签完成购买流程后关闭页签返回 |

### 6.6 下载建议书

| 字段 | 内容 |
|------|------|
| 触发 | 用户需要保存建议书离线查看 |
| 用户动作 | 点击浮动 [下载] 按钮 → 弹窗中选择格式（PDF/PNG）→ 点击 [下载] |
| 系统反馈 | 生成文件并触发浏览器下载，命名格式：`资产配置建议书{YYYYMMDDHHmmss}` |
| 状态变化 | 文件生成中→下载完成 |
| 下一步 | 用户收到文件，可在本地打开浏览 |

## 7. 校验规则

| 规则 | 对象 | 条件 | 是否阻断 | 文案Key |
|------|------|------|----------|---------|
| 账号权限校验 | 账号选择器 | 用户有权限的有效账号 | 阻断（无账号时） | err_no_account_access |
| 下载格式必选 | 下载格式选择弹窗 | 至少选中一种格式 | 阻断（格式未选时 [下载] 置灰） | （通过 UI 状态控制，不展示文案） |

## 8. 状态表现

| 状态 | 触发条件 | UI 表现 | 文案 Key |
|------|----------|---------|----------|
| 加载中 | 请求企业财富+数据中 | 模块级 skeleton / spinner | — |
| 加载完成 | 数据正常返回 | 展示完整数据 | — |
| 无持仓数据 | 账号下无持仓产品 | 空状态区域：图标 + 提示 + [去购买] 按钮 | state_no_position |
| 暂无表现数据 | 持仓表现数据为空 | 模块级空状态：图标 + 提示 | state_no_performance |
| 暂无分布数据 | 投资分布/期限分布数据为空 | 模块级空状态：图标 + 提示 | state_no_distribution |
| 无诊断问题 | 所有诊断规则未命中 | 诊断模块整体不展示 | — |
| 功能暂时不可用 | 数据计算异常 | 模块级空状态 | err_calc_unavailable |
| 数据加载中请稍后 | 接口超时降级 | 模块级提示条 | err_retry_timeout |
| 系统繁忙 | 接口无响应 | 页面级空状态 | err_system_busy |
| 登录已过期 | 401 错误 | 页面级提示引导重新登录 | err_login_expired |
| 暂无权限 | 403 错误 | 页面级提示引导联系管理员 | err_no_permission |
| 系统维护中 | 503 错误 | 页面级提示 | err_maintenance |
| 下载中 | 文件生成中 | Toast | info_downloading |
| 下载完成 | 文件生成并触发下载 | 浏览器下载触发 | — |
| 文件生成失败 | 下载时生成异常 | Toast | err_download_failed |
| 网络异常下载中断 | 下载时网络断开 | Toast | err_network_interrupted |
| 浏览器拦截下载 | 浏览器阻止下载 | Toast | err_download_blocked |
| 部分数据缺失 | 字段无值 | 字段级展示 "--" | — |

## 9. 异常恢复

| 异常 | 触发 | UI 表现 | 恢复路径 |
|------|------|---------|----------|
| 接口超时 | 接口响应 > 5 秒 | 模块级加载态 → 自动重试 3 次 → 失败后展示提示条 | 原路返回，无信息丢失。刷新页面或等待后重新进入 |
| 401 未授权 | 接口返回 401 | 页面级提示"登录已过期，请重新登录" | 重新登录后自动返回 |
| 403 无权限 | 接口返回 403 | 页面级提示"您暂无权限访问该功能" | 联系管理员获得权限后返回 |
| 500/503 服务异常 | 接口返回 500/503 | 页面级提示"系统繁忙/维护中，请稍后再试" | 服务恢复后自动可用，无信息丢失 |
| 接口无响应 | 网络不可达或服务宕机 | 页面级提示"系统繁忙，请稍后再试" | 服务恢复后自动可用，无信息丢失 |
| 部分数据缺失 | 个别字段无值 | 字段级展示 "--"，其他数据正常 | 后台异步补全，下次查看自动更新 |
| 无持仓数据 | 持仓产品数量为 0 | 空状态 + [去购买] 按钮 | 购买产品后返回即可看到数据 |
| 数据计算异常 | 计算服务内部异常 | 模块级空状态"该功能暂时不可用" | 原路返回，无信息丢失 |
| 文件生成失败 | 下载时生成异常 | Toast"文件生成失败，请稍后重试" | 点击下载按钮重新开始 |
| 网络中断下载 | 下载时网络断开 | Toast"网络异常，下载已中断" | 检查网络后重新下载 |
| 浏览器拦截下载 | 浏览器安全策略阻止 | Toast"请允许浏览器下载文件" | 在浏览器中允许下载后重试 |
