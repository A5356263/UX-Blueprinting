# 页面生成规格：子管理员支持复制

## 1. 页面摘要
- **产品领域**：通用权限管理 — 子管理员权限治理
- **页面类型**：子管理员列表页、复制弹窗、员工选择弹窗
- **用户角色**：复制操作人；双管理员互审人通过 OA 处理审批；具有操作记录菜单权限的查看者。目标员工须已加入且已完成实名认证
- **核心任务**：将来源子管理员的可授权范围批量复制给员工

---

## 2. 生成范围

### 生成

- **实体 0：子管理员列表页**。本期在现有列表的操作列增加「复制」入口。
- **实体 1：复制弹窗**。承载复制类别选择、目标员工选择入口、提交校验和本次处理结果。
- **实体 2：选择员工弹窗**。承载候选员工选择，并将选择结果回填实体 1。

### 只引用不生成

- **OA 审批任务**：由 OA 审批底座承载本次互审，审批人通过待办或消息进入现有审批任务。
- **操作记录查看页**：复用「管理后台 → 安全管理 → 操作记录」现有页面查看复制记录。

### 不生成

- 目标资格校验、权限范围叠加与去重、OA 审批创建和审批后授权生效均为系统处理，不单独生成页面。
- 复制操作记录由系统生成，不新增操作记录页面。

---

## 3. 跨实体任务流程

### 批量复制子管理员可授权范围

- 实体 0 —点击来源子管理员行「复制」→ 实体 1；关闭或取消返回实体 0 的原列表位置。
- 实体 1 —点击「选择员工」→ 实体 2；确认后关闭实体 2，将已选员工回填实体 1；取消返回实体 1 并保留进入选择前的内容。
- 实体 1 —确认复制且校验通过→ 系统按目标类型处理范围；互审开启时有效范围进入 OA 审批，审批双方通过后生效；处理结果在实体 1 内查看，完成后关闭返回实体 0。
- OA 审批 —双方通过→ 复制范围生效；任一审批结果为拒绝→ 复制范围不生效，审批任务仍在 OA 查看。
- 实体 1 —目标校验不通过→ 不合格目标跳过；合格目标继续处理；校验结果在实体 1 内查看。
- 实体 1 —无目标通过校验→ 停留实体 1，不产生复制或 OA 审批，用户可调整目标后重新提交。

## 5. 复制弹窗

### 弹窗目标

选择复制范围和接收员工，提交一次批量复制，并确认每名员工的处理状态。

### 区域结构

```text
+--------------------------------------------------------+
| 复制                                             [关闭] |
+--------------------------------------------------------+
| 复制来源：{来源子管理员姓名}/{手机号}                    |
|                                                        |
| 复制信息                                               |
| [✓] 可授权组织             [✓] 可授权功能               |
| 至少选择一项                                           |
|                                                        |
| 复制对象                                               |
| [已选员工摘要，可编辑]                                 |
| [选择员工]                                             |
| 最多可以复制给 200 名用户                              |
|                                                        |
|                              [取消] [确认复制]          |
+--------------------------------------------------------+
```

### 区域说明

- 「复制来源」取自打开弹窗的来源子管理员行，显示该行已有的姓名和手机号，帮助操作人核对复制对象。
- 「复制信息」提供「可授权组织」「可授权功能」两个多选项，默认均勾选，至少保留一项。
- 「复制对象」展示已选员工并提供「选择员工」入口；已选结果可再次编辑。
- 目标人数提示为「最多可以复制给 200 名用户」，本批最多选择 200 名。
- 操作区提供「取消」和「确认复制」。

### 信息与字段

- 复制来源：来源子管理员姓名、手机号。
- 复制信息：可授权组织、可授权功能。
- 复制对象：已选员工集合，最多 200 名。
- 目标员工在选择器中仅限已加入且已完成实名认证的员工；提交时仍按加入状态、认证状态复核。

### 关键操作

- 打开弹窗时默认勾选两个复制信息选项。
- 点击「选择员工」打开实体 2。确认选择后返回本弹窗，回填员工摘要；再次进入可调整选择。
- 点击「取消」关闭弹窗并返回实体 0。
- 点击「确认复制」按规定顺序校验复制信息、复制对象、加入状态和认证状态。
- 校验通过的目标继续处理；校验失败的目标跳过，批次中其他合格目标继续处理。
- 普通用户首次成为子管理员时同时继承来源的可授权组织与可授权功能，即使仅勾选其中一项；已有子管理员仅叠加本次勾选类别，并自动去重。
- 双管理员互审开启时，为通过校验的目标创建一条 OA 审批；审批双方通过后，按每名目标实际适用的范围生效。
- 本期复制每次都进入互审，不受双管理员互审配置中「子管理员模式」互审范围是否包含复制操作影响；同一批的组织与功能范围共用一条审批。
- 勾选某个复制类别时，复制来源子管理员该类别下的全部可授权范围，不在类别内部选择部分范围。
- 至少一个目标通过校验并成功处理后显示「复制成功」Toast；若互审开启，结果区同时标明审批处理中、权限尚未生效。该 Toast 表示本次复制处理已成功提交，不表示审批通过。
- 复制成功并生效后每次生成一条操作记录，可由具有操作记录菜单权限的用户从「管理后台 → 安全管理 → 操作记录」查看。功能为「子管理员模式」，操作对象为「权限管理模式」，操作类别按实际结果记录「复制-可授权组织」和/或「复制-可授权功能」，详情为「无」。操作内容呈现来源子管理员姓名和手机号、目标员工姓名和手机号及实际复制范围；普通用户首次成为子管理员时，记录同时覆盖其实际继承的组织与功能范围。审计数据保留操作者及角色、目标、操作与作用域、发生和生效时间、原因或备注、审批实例与状态、结果与冲突原因、可验算快照。快照可核对来源范围、目标复制前范围、复制后范围和逐目标结果；失败目标不得记为已授权。

### 校验与反馈

| 触发条件 | 处理结果 | 反馈文案 |
| --- | --- | --- |
| 未选择复制信息 | 阻止整次提交，停留本弹窗 | 请选择复制信息 |
| 未选择复制对象 | 阻止整次提交，停留本弹窗 | 请选择至少一名复制对象 |
| 部分目标加入状态不是已加入 | 跳过对应目标，其余合格目标继续；按目标姓名汇总展示 | XXX、XXX 加入状态不是已加入，不能成为子管理员 |
| 部分目标未完成实名认证 | 跳过对应目标，其余合格目标继续；按目标姓名汇总展示 | XXX、XXX 未完成实名认证，不能成为子管理员 |
| 全部目标均校验失败 | 不产生复制或审批，保留本弹窗供调整 | 显示对应失败原因 |

校验顺序固定为复制信息、复制对象、加入状态、认证状态。目标失败按原因分组反馈，失败目标不进入复制或审批范围。

### 状态与异常恢复

- **待提交**：用户可以调整复制类别和目标员工。
- **审批中**：互审开启且申请已创建；本次授权范围尚未生效，不论互审配置范围是否单独列出复制操作。待办或消息入口进入 OA 审批任务。
- **已生效**：不需要互审时复制处理完成；或互审双方通过后范围生效。
- **部分目标未处理**：合格目标继续处理，失败目标显示对应失败原因；本次处理结果不把失败目标标记为已授权。

### 条件结构（本次处理结果）

```text
+--------------------------------------------------------+
| 本次处理结果                                           |
|                                                        |
| {目标员工姓名}    {已生效 / 审批中 / 未处理}            |
| {目标员工姓名}    {已生效 / 审批中 / 未处理}            |
|                                                        |
| 未处理原因：{加入状态 / 实名认证失败原因}               |
|                                                        |
|                                          [完成]         |
+--------------------------------------------------------+
```

结果区逐人展示本批处理状态和未处理原因。审批中的目标明确显示尚未生效。点击「完成」关闭弹窗并返回实体 0。

## 6. 选择员工弹窗

### 弹窗目标

从符合资格的员工中选择一个或多个复制目标，并将结果带回实体 1。

### 区域结构

```text
+--------------------------------------------------------+
| 选择员工                                         [关闭] |
+--------------------------------------------------------+
| [员工候选列表，沿用添加子管理员选择器结构]             |
| [Checkbox] {员工信息}                                   |
| [Checkbox] {员工信息}                                   |
|                                                        |
| {已选员工摘要}                                           |
|                                                        |
|                              [取消] [确认选择]          |
+--------------------------------------------------------+
```

### 区域说明

- 候选员工使用现有「添加子管理员」选择器的员工项结构，只展示已加入且已完成实名认证的员工。
- 选择器支持多选，最多选择 200 名。已选员工在本弹窗中可核对。
- 「确认选择」关闭本弹窗并回填实体 1；「取消」关闭本弹窗并返回实体 1，保留进入前的已选结果。

### 信息与字段

- 候选员工：符合加入状态和实名认证条件的员工，展示字段沿用「添加子管理员」选择器。
- 已选员工集合：本次确认后带回实体 1 的目标员工，最多 200 名。

### 关键操作

- 选择或取消选择员工，更新已选员工集合。
- 达到 200 名后不允许继续增加目标。
- 点击「确认选择」回填结果并返回实体 1。
- 点击「取消」或关闭按钮返回实体 1，不覆盖进入前的选择结果。

### 文案与变量

| key | 文案 | 适用位置／状态 | 变量及含义、取值 |
| --- | --- | --- | --- |
| EMPLOYEE-PICKER-TITLE | 选择员工 | 实体 2 标题 | 无 |
| EMPLOYEE-PICKER-CLOSE | 关闭 | 实体 2 关闭操作 | 无 |
| EMPLOYEE-PICKER-CANCEL | 取消 | 实体 2 操作 | 无 |
| EMPLOYEE-PICKER-CONFIRM | 确认选择 | 实体 2 操作 | 无 |
