# 体验蓝图：子管理员权限复制

## §0 本次关键设计判断

**判断**：复制弹窗用 Modal、确认前在弹窗内嵌后果摘要区、选人器增加前置状态标签、结果反馈区分「直接生效」和「待审批」两条路径——这四项设计决策构成体验底线。

**主要影响**：Modal 结构决定信息承载方式（两区 + 预览区 + 底部按钮）；前置状态标签影响整个选人流程的效率和出错率；后果摘要直接决定「确认并提交」阶段的信心度从低提至中；结果双路径反馈是治理一致性的最后闭环。

**建议方案**：复制弹窗采用「上半部分配置、中部后果摘要、下半部分操作按钮」的三段式 Modal。选人器中目标用户行尾展示加入状态和认证状态标签（不合格者灰显+提示）。确认按钮上方固定展示后果摘要区（新增 N 人 / 更新 M 人 / 复制内容）。提交成功后根据治理模式分别展示 toast：无互审时「已成功复制给 N 名用户」；有互审时「已提交复制审批，通过后生效」。

**不建议方案**：不把复制拆成 Wizard 多步（操作单一、无强依赖分步、非高频不可逆——不符合流程模式原则的四条门禁）；不在提交后才统一报校验错误（违反 U-05 错误预防原则）；不把直接生效和待审批统一称为「复制成功」。

**关键待确认**：组织范围匹配策略未定（影响选人器是否需增加管辖范围过滤）；部分失败处理策略未定（影响后果摘要区和错误反馈的设计）。

## §1 旅程消费摘要

### 信心最低点 → §5 异常流程设计优先级

| 来源角色 | 阶段 | 信心度 | 核心原因 | 蓝图落点 |
|---------|------|-------|---------|---------|
| 权限管理员 | 确认并提交 | 低 | 缺少确认前后果预览，高风险盲操作 | §5.1 确认前后果预览未展示就提交 |
| 权限管理员 | 处理操作结果 | 低 | 双管理员互审下反馈模糊，toast 与实际状态脱节 | §5.3 双管理员互审下反馈不一致 |

信心越低的阶段，异常处理和阻断防护的设计优先级越高。以上两个低信心阶段对应的异常流程在 §5 中优先展开。

### 关键转折 → §3 / §4 前置说明

| 来源角色 | 转折 | 触发条件 | 蓝图落点 |
|---------|------|---------|---------|
| 权限管理员 | 定位来源 → 配置复制 | 点击子管理员列表「复制」按钮 | §3.1 节点前置说明 |
| 权限管理员 | 配置复制 → 确认提交 | 完成选择后点击确认 | §3.3 节点前置说明（后果摘要） |
| 权限管理员 | 确认提交 → 处理结果 | 系统校验完成 | §3.4 节点前置说明（分支判断） |
| 权限管理员 | 处理结果 → 验证追溯 | 关闭弹窗回到列表 | §3.5 节点前置说明 |

每个转折点在 §3 对应节点中配置「需要前置解释的信息」字段，确保用户在关键决策点有足够上下文。

### 流失风险 → §6 页面设计引导策略

| 来源角色 | 阶段 | 流失风险 | 蓝图落点 |
|---------|------|---------|---------|
| 权限管理员 | 识别需求与定位来源 | 找不到参照时放弃复制 | §6.1 列表增加行内权限摘要、筛选能力 |
| 权限管理员 | 配置复制参数 | 盲选导致提交后大量失败 | §6.2 选人器状态标签、§6.3 选人器内提示 |
| 权限管理员 | 确认并提交 | 不确定后果放弃操作 | §6.4 弹窗内后果摘要区 |
| 权限管理员 | 处理操作结果 | 反馈模糊导致重复操作 | §7 双路径 toast 文案 |
| 权限管理员 | 验证与追溯 | 记录碎片化降低信任 | §6.1 列表操作记录聚合入口 |

## §2 交互流程总览

本次设计包含 1 条主路径、4 条校验分支、2 条结果分支、2 条异常阻断路径。

### 主路径：管理员复制子管理员权限

```
子管理员列表 Page
→ 点击目标行操作列 [复制]
→ 打开 复制子管理员权限 Modal
→ 确认复制信息（可授权组织 / 可授权功能），默认全选
→ 点击 [选择复制对象]，打开 选择员工 Modal
→ 搜索并勾选目标用户，点击 [确定]
→ 回到 复制子管理员权限 Modal，查看已选用户列表
→ 确认前查看后果摘要区（新增 N 人 / 更新 M 人）
→ 点击 [确认复制]
→ 系统按序校验（复制信息 → 复制对象 → 加入状态 → 认证状态）
→ 校验通过
→ Modal 关闭
→ Toast 反馈（区分直接生效 / 待审批）
→ 操作记录生成
→ 列表刷新
```

### 校验分支

- 未勾选任何复制信息 → [确认复制] 置灰不可点击
- 未选择任何复制对象 → [确认复制] 置灰不可点击
- 目标用户中存在未加入者 → Modal 不关闭，错误列表区展示不满足条件的用户及原因
- 目标用户中存在未认证者 → Modal 不关闭，错误列表区展示不满足条件的用户及原因

### 结果分支

- 未开启双管理员互审 → Toast「已成功复制给 N 名用户」，权限即时生效
- 开启双管理员互审 → Toast「已提交复制审批，通过后生效」，权限待审批

### 异常阻断

- 复制来源在操作期间状态变更 → 提交时校验失败，Toast 提示「复制来源已变更，请重新操作」
- 双管理员互审审批被拒绝 → 操作记录标记为「已拒绝」，发起方可收到通知

## §3 主交互流程

### 3.1 节点：管理员定位来源子管理员

**用户动作**

在子管理员列表页中浏览或搜索，定位到目标子管理员行，查看行内展示的组织范围和功能配置摘要，确认其权限配置适合作为参照。

**系统反馈**

列表展示每个子管理员的姓名、手机号、可授权组织范围（摘要）、可授权功能数量（摘要）、启用状态。「复制」按钮出现在操作列最左侧。

**需要前置解释的信息**

- 「复制」是一次性动作——后续修改来源不影响已复制的目标
- 复制结果等价于手动逐项配置，不改变权限来源模型
- 叠加不覆盖——已有子管理员接收复制后保留原有权限

**建议文案**

- 操作列按钮：「复制」
- 行内组织范围摘要：「管辖 {N} 个组织」或直接展示组织路径

**下一步**

点击「复制」，打开复制弹窗。来源子管理员的姓名/手机号带入弹窗标题区。

---

### 3.2 节点：配置复制信息与选择目标用户

**用户动作**

在复制弹窗中：
- 查看复制来源信息（已带入）
- 确认复制信息勾选——默认可授权组织、可授权功能全选，可按需取消但至少保留一项
- 点击「选择复制对象」打开员工选择器
- 在员工选择器中搜索、浏览、勾选目标用户
- 查看每个候选用户的加入状态和认证状态标签
- 点击「确定」回到复制弹窗

**系统反馈**

- 弹窗顶部展示复制来源：「复制 {姓名/手机号} 的权限给其他用户」
- 复制信息区：两个勾选项，取消勾选后 [确认复制] 置灰
- 员工选择器：用户列表行尾展示「已加入 / 未加入」「已认证 / 未认证」标签
- 不符合条件的用户行灰显，hover 时 tooltip 说明：「该用户未完成实名认证，不能成为子管理员」
- 已选用户列表展示在弹窗中，可逐人移除或清空重选
- 已选人数实时显示：「已选 {N}/200 人」

**需要前置解释的信息**

- 选人器中的「未加入」或「未认证」用户不可选，hover 可见原因
- 最多选择 200 人
- 选人器复用了「添加子管理员」弹窗中的员工选择器，但增加了状态标签展示

**建议文案**

- 复制信息区标题：「复制内容」
- 勾选项：「可授权组织」「可授权功能」
- 已选用户区标题：「复制对象」
- 空状态：「暂未选择复制对象」
- 选人按钮：「+ 选择复制对象」

**下一步**

确认复制信息和目标用户已选，查看后果摘要区，准备提交。

---

### 3.3 节点：确认前查看后果摘要

**用户动作**

在复制弹窗下半部分查看后果摘要区：
- 确认本次复制将新增多少名子管理员
- 确认本次复制将更新多少名已有子管理员的权限
- 确认复制内容（可授权组织 / 可授权功能）
- 如有疑问，可点击目标用户列表中的姓名查看其当前状态
- 确认无误后点击 [确认复制]

**系统反馈**

后果摘要区实时更新（随复制信息和目标用户变化）：

```
复制后：
- {N} 名用户将成为子管理员
- {M} 名已有子管理员将叠加新权限
- 复制内容：可授权组织、可授权功能
- 复制模式：叠加不覆盖，原有权限不受影响
```

目标用户列表中区分展示：「新增为子管理员」「叠加权限」

**需要前置解释的信息**

- 「叠加不覆盖」的含义已在摘要区明确说明
- 如果目标用户的组织管辖范围与来源不匹配（待产品确认是否校验），此处应有提示

**建议文案**

- 摘要区标题：「复制预览」
- 确认按钮：「确认复制」
- 取消按钮：「取消」

**下一步**

点击「确认复制」，系统开始按序校验。

---

### 3.4 节点：系统校验与结果处理

**用户动作**

点击「确认复制」后等待系统校验。如果校验失败，查看错误信息，根据提示修正后重试。如果校验通过，查看结果反馈。

**系统反馈**

校验通过：
- 未开启双管理员互审 → Modal 关闭，Toast「已成功复制给 {N} 名用户」
- 开启双管理员互审 → Modal 关闭，Toast「已提交复制审批，通过后生效」
- 列表刷新，操作记录生成

校验失败（信息未选 / 对象未选）：
- [确认复制] 按钮置灰，不进入校验

校验失败（加入状态 / 认证状态）：
- Modal 不关闭
- 错误列表区以 Inline Error 形式展示不满足条件的用户名和原因
- 每条错误可点击，自动滚动到目标用户列表中对应行

**需要前置解释的信息**

- 双管理员互审模式下，审批通过后权限才生效
- 操作记录中可追踪审批进度

**建议文案**

- 校验中 Loading：「正在验证...」
- 直接生效 Toast：「已成功复制给 {N} 名用户」
- 待审批 Toast：「已提交复制审批，通过后生效」
- 加入状态错误 Inline：「{姓名} 加入状态不是已加入，不能成为子管理员」
- 认证状态错误 Inline：「{姓名} 未完成实名认证，不能成为子管理员」

**下一步**

关闭弹窗，列表刷新。管理员可在列表中验证结果。

---

### 3.5 节点：验证操作结果

**用户动作**

在子管理员列表中检查目标用户是否出现（新增者）或权限范围是否更新（叠加者）。如有需要，进入操作记录查看复制详情。

**系统反馈**

- 列表刷新后展示最新的子管理员列表
- 新成为子管理员的用户出现在列表中，可授权范围与复制内容一致
- 已有子管理员的权限范围更新为叠加后结果
- 操作记录中可见两条记录（复制-可授权组织、复制-可授权功能），通过批次 ID 关联

**需要前置解释的信息**

- 操作记录中两条记录通过同一批次 ID 关联，可在记录详情中切换查看
- 双管理员互审模式下，记录中的状态为「审批中」，审批通过后更新为「已生效」

**建议文案**

- 操作记录聚合入口：「查看本次复制记录」

**下一步**

确认权限生效，本次复制任务完成。

---

## §4 次交互流程

### 4.1 取消复制操作

**触发条件**：管理员在复制弹窗中点击「取消」或点击弹窗外区域。

**用户动作**：点击取消。

**系统反馈**：弹窗关闭，不保存任何已填写内容。列表不变。

**下一步**：回到子管理员列表。

### 4.2 复制信息取消全部勾选

**触发条件**：管理员在复制弹窗中取消所有复制信息勾选。

**系统反馈**：[确认复制] 按钮置灰。复制信息区下方显示 Inline 提示「至少选择一项复制内容」。

**建议文案**：「至少选择一项复制内容」

**下一步**：至少勾选一项后，[确认复制] 按钮恢复可点击。

### 4.3 从已选列表中移除单个用户

**触发条件**：管理员在复制弹窗的已选用户列表中点击某用户的「移除」图标。

**用户动作**：点击移除。

**系统反馈**：该用户从已选列表消失，后果摘要区数字实时更新。已选人数减 1。

**下一步**：继续调整选择或提交。

### 4.4 清空全部已选用户

**触发条件**：管理员在复制弹窗中点击「清空」。

**系统反馈**：全部已选用户清空。后果摘要区恢复为空状态。[确认复制] 按钮置灰。

**建议文案**：清空按钮文案「清空全部」

**下一步**：重新选择目标用户。

### 4.5 查看已选用户详情

**触发条件**：管理员在复制弹窗的已选用户列表中点击某用户名。

**用户动作**：点击用户名。

**系统反馈**：以 tooltip 或轻量弹出层展示该用户的加入状态、认证状态、当前是否已是子管理员。

**下一步**：关闭详情继续操作。

## §5 异常与阻断流程

### 5.1 提交时部分目标用户校验失败

**发生时机**：管理员点击「确认复制」后，加入状态或认证状态校验阶段。

**触发条件**：目标用户中存在加入状态非「已加入」或未完成实名认证的用户。

**判断依据**：UXB §6 异常清单 + U-09 可行动错误恢复原则。

**反馈形式**：Modal 不关闭。错误列表区（弹窗内下半部分）展示不满足条件的用户列表，逐条给出用户名和原因。每一行可点击，点击后自动滚动到目标用户列表中对应行，并高亮。

**系统反馈**：错误列表区标题为「以下 {K} 名用户不满足条件」。列出格式为：「{姓名} - {原因}」，如「张三 - 未完成实名认证」。

**用户下一步**：
- 逐人移除：在已选列表中移除不满足条件的用户，修正后重新点击确认
- 一键移除全部不满足者：错误列表区提供「移除以上用户」按钮，点击后从已选列表中批量移除所有不满足条件的用户，后果摘要区自动更新
- 取消操作：关闭弹窗放弃本次操作

**恢复路径**：移除不满足用户后重新提交，一步完成。不丢失已填内容。

> 注：当前「一键移除不满足用户」策略基于「过滤后继续」的产品假设推进。如果产品最终选择「全部回退」，则移除此功能，改为全部回退 + 用户重新选择。

### 5.2 提交时复制来源状态已变更

**发生时机**：管理员在复制弹窗中操作期间，来源子管理员被其他管理员删除、停用或权限范围被修改。

**触发条件**：提交时系统检测到来源子管理员状态与打开弹窗时不一致。

**判断依据**：UXB §6 异常清单（复制来源状态变更）+ U-05 错误预防原则。

**反馈形式**：Toast 提示，Modal 不关闭（保留已填内容）。

**系统反馈**：Toast「复制来源已变更，请关闭弹窗后重新选择」。

**用户下一步**：关闭弹窗，回到列表确认来源状态，必要时重新选择来源。

**恢复路径**：需关闭弹窗重新选择来源，但原则上员工选择器的已选列表可尝试保留（取决于实现复杂度，如果保留则用户只需重新选来源）。

### 5.3 双管理员互审下反馈与状态不一致

**发生时机**：管理员提交复制后，系统开启了双管理员互审。

**触发条件**：复制成功生成审批，但权限未即时生效。

**判断依据**：UXB §7 ER4（治理模式下的状态一致性）+ RISK-006（治理模式引入流程不确定性）+ 知识库 24_治理状态模型。

**反馈形式**：
- Toast：「已提交复制审批，通过后生效」（不是「复制成功」）
- 操作记录中状态标记为「审批中」，显示审批进度链接
- 列表中被复制的目标用户暂不出现或暂不更新（取决于系统实现：审批通过前暂不变化，或变化但标注「待生效」）

**系统反馈**：不同于直接生效的反馈路径。审批通过后如有通知机制，告知发起人「复制审批已通过，权限已生效」。审批被拒绝后告知发起人「复制审批被拒绝」，并附审批人备注（如有）。

**用户下一步**：等待审批完成。可通过操作记录跟踪审批进度。

**恢复路径**：审批通过即恢复（自动）。审批被拒绝后需重新发起复制。

### 5.4 双管理员互审审批被拒绝

**发生时机**：复制生成的审批进入互审链路后。

**触发条件**：另一位管理员拒绝了审批。

**判断依据**：知识库 24_治理状态模型（rejected 状态）+ C-07 峰终定律（结尾需明确结果与下一步）。

**反馈形式**：
- 发起人收到通知（消息中心 / 站内信 / 列表标记）
- 操作记录中状态更新为「已拒绝」
- 权限不生效

**系统反馈**：通知内容「你于 {时间} 发起的复制操作审批已被拒绝。原因：{审批人备注}。」

**用户下一步**：查看被拒绝原因，决定是否重新发起复制或联系审批人沟通。

**恢复路径**：需重新发起复制，从头开始。不可从拒绝状态直接恢复。

### 5.5 目标用户数量达到上限

**发生时机**：管理员在员工选择器中勾选用户时。

**触发条件**：已选人数达到 200 人上限。

**判断依据**：UXB §6 异常清单（数量超限）+ I-02 约束与防呆。

**反馈形式**：员工选择器中勾选框置灰。底部显示「已达到上限（200 人）」。

**系统反馈**：勾选超过 200 人时，第 201 人起不可勾选。选择器底部显示橙色提示「最多选择 200 名复制对象」。

**用户下一步**：确认当前已选的 200 人，或移除部分后替换。

**恢复路径**：原路恢复，移除部分已选用户即可继续选择。

### 5.6 网络异常导致提交失败

**发生时机**：管理员点击「确认复制」后，提交请求期间。

**触发条件**：网络超时或服务端异常。

**判断依据**：U-01 系统状态可见 + U-09 可行动错误恢复。

**反馈形式**：Modal 不关闭。弹窗内以 Banner 形式展示错误提示。

**系统反馈**：Banner 文案「提交失败，请检查网络后重试。如多次失败，请联系技术支持。」提供「重试」按钮。

**用户下一步**：点击「重试」重新提交（保留已填内容）。或取消后稍后重试。

**恢复路径**：点击重试，一步完成。不丢失已填内容。

## §7 状态与反馈文案

### 统一状态口径

| 状态 | 含义 | 适用对象 | 用户可操作 | 统一反馈口径 |
|------|------|---------|-----------|------------|
| 操作中 | 管理员正在填写复制弹窗 | 复制弹窗 | 选择/取消/关闭 | — |
| 校验中 | 系统正在校验复制信息与对象 | 确认按钮点击后 | 等待 | 按钮展示 Loading：「正在验证...」 |
| 校验拦截 | 校验未通过，弹窗不关闭 | 弹窗错误列表区 | 移除不满足用户后重试 / 取消 | 见下方错误文案 |
| 复制成功-直接生效 | 校验通过，权限即时生效 | 子管理员列表 | 在列表中查看结果 | Toast：「已成功复制给 {N} 名用户」 |

| 审批通过 | 互审审批通过，权限生效 | 操作记录 → 子管理员列表 | 在列表中查看结果 | 通知：「复制审批已通过，权限已生效」 |
| 审批拒绝 | 互审审批被拒绝，权限不生效 | 操作记录 | 查看拒绝原因 / 重新发起 | 通知：「复制审批被拒绝。{原因}」 |
| 复制失败 | 系统异常导致提交失败 | 复制弹窗 | 重试 / 取消 | Banner：「提交失败，请检查网络后重试」 |
