# 页面事实补充

## 页面与载体

- 子管理员模式列表页（复制入口所在页面）
- 复制弹窗（点击复制后打开）
- 选择员工弹窗（点击选择器后打开，样式与添加子管理员弹窗一致）

## 模块与字段

- 复制弹窗——复制信息：可授权组织、可授权功能
- 复制弹窗——复制对象：选择一名或多名用户
- 子管理员模式列表——操作列：复制（置于操作项最左侧）
- 选择员工弹窗：与添加子管理员弹窗样式一致

## 明确页面约束与文案

- 复制入口：子管理员模式列表页"操作"列最左侧
- 复制信息默认值：弹窗打开时默认全部勾选
- 复制信息必填：至少选择一项
- 复制信息可选多选：支持
- 复制对象上限：最多 200 名
- 校验顺序：1.复制信息是否已勾选 → 2.复制对象是否已选择 → 3.复制对象加入状态是否均为已启用 → 4.复制对象认证状态是否均为已认证
- 提示文案（校验失败）：
  - "请选择复制信息"
  - "请选择至少一名复制对象"
  - "XXX、XXX 加入状态不是已加入，不能成为子管理员"
  - "XXX、XXX 未完成实名认证，不能成为子管理员"
- 提示文案（复制成功）："复制成功"（toast）
- 操作记录-功能：子管理员模式
- 操作记录-操作：复制-可授权组织 / 复制-可授权功能
- 操作记录-操作对象：权限管理模式
- 操作记录-操作内容：将子管理员【XXX/手机号】可授权组织复制给【XXX/手机号】【XXX/手机号】【XXX/手机号】
- 操作记录-详情：无
- 双管理员互审模式：复制完成时生成一条审批
