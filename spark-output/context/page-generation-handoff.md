## 2. 字段与内容事实

- [FACT-F001] 银行账号：展示用户下所有有权限的有效账号列表，默认选择"全部"（来源：§3.1.5 业务要素）
- [FACT-F002] 时点资产：最新时间的时点资产，单位按元/万元/亿元自动换算（来源：§3.1.5 业务要素）
- [FACT-F003] 区间收益：自定义区间的持仓收益（来源：§3.1.5 业务要素）
- [FACT-F004] 区间年化收益率：按公式 (区间收益 / 区间平均持仓市值) × (365 / 区间天数) × 100% 计算（来源：§3.1.5 业务要素）
- [FACT-F005] 购买笔数：自定义区间内购买成功笔数（来源：§3.1.5 业务要素）
- [FACT-F006] 购买金额：自定义区间内购买成功金额之和（来源：§3.1.5 业务要素）
- [FACT-F007] 赎回笔数：自定义区间内赎回成功笔数（来源：§3.1.5 业务要素）
- [FACT-F008] 赎回金额：自定义区间内赎回成功到账金额之和（来源：§3.1.5 业务要素）
- [FACT-F009] 持仓变动趋势：自定义区间内的持仓市值走势图（来源：§3.1.5 业务要素）
- [FACT-F010] 收益金额趋势：自定义区间内的收益金额走势图（来源：§3.1.5 业务要素）
- [FACT-F011] 产品收益排行：自定义区间内的持仓产品及持仓收益，按持仓收益降序排序（来源：§3.1.5 业务要素）
- [FACT-F012] 持仓金额：自定义区间结束时间的时点余额（来源：§3.1.6 持仓表现）
- [FACT-F013] 较期初：区间结束时间余额相比开始时间的增长率，期初为 0 时展示"-"（来源：§3.1.6 持仓表现）
- [FACT-F014] 金额单位换算：0~9,999元 → 元；10,000~99,999,999元 → 万元；≥100,000,000元 → 亿元；均保留2位小数（来源：§3.1.4.3 展示规则）
- [FACT-F015] 百分比展示：占比保留2位小数；收益率/年化收益率保留2位小数，正数显示"+"，负数显示"-"（来源：§3.1.4.3 展示规则）
- [FACT-F016] 空值处理：金额类/比例类/收益率类/日期类展示"--"；文本类不展示该字段（来源：§3.1.4.3 展示规则）
- [FACT-F017] 数值精度：所有数值保留2位小数，四舍五入（来源：§3.1.4.3 展示规则）
- [FACT-F018] 区间年化收益率特殊场景：天数为0或平均持仓市值为0时展示"--"（来源：§3.1.5 业务要素）
- [FACT-F019] 底部风险提示文案1："理财非存款，产品有风险，投资需谨慎"（来源：§3.1.6 业务操作规则）
- [FACT-F020] 底部风险提示文案2：关于净值延迟和收益率精度的详细说明（来源：§3.1.6 业务操作规则）
- [FACT-F021] 下载文件命名格式：资产配置建议书YYYYMMDDHHmmss（来源：§3.1.6 业务操作规则）
