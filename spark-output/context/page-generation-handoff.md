# 页面事实补充

## 页面与载体
- 管理端-权限管理模式宣传页（自助申请权限模式入口）
- 管理端-自助申请模式设置页（三步设置流程）
- 管理端-选择角色弹窗（支持搜索、分页、选项框）
- 管理端-选择应用弹窗（支持搜索、分页、选项框）
- 管理端-表单编辑子页面（修改审批流程）
- 管理端-关闭模式二次确认弹窗
- 管理端-关闭失败提示弹窗
- 个人中心-"我的权限"入口（位于"我的企业"下方）
- 我的权限页面（含功能权限/数据权限/角色 三个 tab）
- 申请权限抽屉
- 申请记录列表（含筛选、列表内容、分页）

## 模块与字段

### 自助申请模式设置页
- **第一步-选择申请方式**：申请角色（单选，默认选中）、申请功能权限（单选）；申请角色下方提示文案、申请功能权限下方提示文案
- **第二步-设置角色范围**（申请角色时）：全部角色（单选，默认选中）、部分角色（单选）；提示语："请选择允许员工自助申请的角色"
- **选择角色弹窗**：搜索框、选项框、角色名称、角色说明、角色状态、分页展示；设置项"后续新增角色自动加入员工可申请的范围"（默认选中）
- **第二步-设置应用范围**（申请功能权限时）：全部应用（单选，默认选中）、部分应用（单选）；提示语："请选择允许员工自助申请权限的应用"
- **选择应用弹窗**：搜索框、选项框、应用名称、应用终端、应用启用状态、分页展示；设置项"后续新添加的应用自动加入员工可申请的范围"（默认选中）
- **第三步-设置审批流程**：提示文案"系统已预设了「员工申请权限」时的审批流程，预设审批人为员工所在组织的组织负责人。如需调整，可点击修改审批流程"；点击"修改审批流程"进入表单编辑子页面

### 我的权限页
- **功能权限 tab**：展示用户有权限的应用、功能权限列表（含全员应用、管理类应用及对应功能）
- **数据权限 tab**：交互和数据与"用户授权-权限详情"一致
- **角色 tab**：展示用户关联的所有角色，交互和数据与"用户授权-权限详情"一致
- 空状态提示语："您没有功能权限"、"您没有数据权限"、"您没有关联的角色"

### 申请权限抽屉
- **申请人**：默认带出当前用户名称，不可编辑
- **申请原因**：必填，提示词"请填写申请原因"，最多 500 字
- **申请功能权限**：提示语"提交申请后，默认申请功能的所有数据权限。如需申请部分数据权限，请联系企业管理员授权。"；内容与功能权限设置组件一致，应用范围只包括管理端设置的"应用范围"
- **申请角色**：表格字段（勾选项、角色名称、角色说明）；角色范围是管理端设置的"角色范围"中的已启用角色

### 申请记录列表
- **筛选条件**：申请日期、审批状态（已通过/已拒绝/审批中/已撤销）
- **列表字段**：申请时间（年月日 时分秒）、申请原因、申请内容（角色名称或"查看详情"超链接）、审批状态（已通过/已拒绝/审批中/已撤销）、操作（撤销）
- 分页展示

## 明确页面约束与文案
- 服务人员不展示"我的权限"入口
- "我的权限"无需授权，属于全员功能
- 自助申请模式开启后，个人中心增加"我的权限"入口
- 自助申请模式已开启状态提示语："此模式已开启，员工可以自助查询和申请个人权限。申请通过后，系统自动分配权限。帮助文档"
- 启用时互斥校验文案："企业已开启「双管理员互审模式」，不能同时开启此模式"
- 关闭模式二次确认文案："关闭模式后，员工将无法自助查询和申请权限，请确认是否关闭自助申请模式？"；按钮："不关闭"、"确认关闭"
- 关闭失败弹窗文案："当前有申请流程未完成审批，请联系审批人审批完成，再关闭模式"；按钮："知道了"
- Toast 提示："开启成功"、"关闭「自助申请权限模式」成功"、"编辑成功"
- 审批中的申请可点击撤销；其他状态不支持撤销
