# 页面生成事实补充

## 入口变更

- 原理财月报菜单项改名为"资产配置"
- 持仓列表增加"资产配置"入口，点击后跳转到资产配置页面并自动选中当前查看的账号
- 去掉白名单逻辑

## 资产配置页面顶部

- 银行账号选择器：展示用户下所有有权限的有效账号列表，默认选择"全部"
- 去掉月份选择器（原月报的月份切换）
- 历史建议书入口：本版本不做

## 持仓表现模块（仅支持理财）

- 时间区间筛选器：支持近两年数据范围，自定义区间，默认近一个月
- 持仓金额：取自定义区间结束时间的时点余额
- 较期初：区间结束时间余额相比开始时间的增长率；期初为0时展示 "-"
- 区间收益：取自定义区间的持仓收益
- 区间年化收益率：(区间收益 / 区间平均持仓市值) × (365 / 区间天数) × 100%
- 购买笔数/购买金额：取区间内购买成功笔数和金额之和
- 赎回笔数/赎回金额：取区间内赎回成功笔数和到账金额之和
- 持仓变动趋势：取区间内的持仓市值走势图
- 收益金额趋势：取区间内的收益金额走势图
- 产品收益排行：取区间内持仓产品及持仓收益，按持仓收益降序排序

## 投资分布模块

- 理财：按产品特点汇总的持仓金额、占比、年化收益率及排名
- 其他业务（公募基金、资管计划、信托计划）按类型汇总持仓金额、占比——本版本不做子类型展开
- 饼图展示资产类型分布

## 期限分布模块

- 理财：按产品期限汇总的持仓金额、占比、年化收益率及排名
- 其他业务（公募基金、资管计划、保险资管、信托计划）按持有期汇总持仓金额、占比——本版本不做子类型展开

## 持仓诊断模块（仅支持理财）

### 持仓集中度过高
- 触发条件：活钱管理持仓占比 ≥ 60%
- 展示内容：活钱管理类持仓占比 XX%，金额 XX 元/万元/亿元
- 无数据：不展示该模块

### 产品到期
- 触发条件：存在未来两周内到期的封闭式产品
- 展示内容：产品简称/代码、持仓金额（统计全量卡）、持仓收益（统计全量卡）、最新净值及日期、产品到期日
- 无数据：不展示该模块

### 持仓时间过长
- 触发条件：产品期限为0且持续持仓超2个月，或产品期限≤31天且持续持仓超3个月
- 展示内容：产品简称/代码、持仓金额（统计全量卡）、持仓收益（统计全量卡）、最新净值及日期、持仓时长（按卡中最大连续持有天数）
- 无数据：不展示该模块

## 产品推荐模块（仅支持理财）

- 数据来源：企业财富+资产配置模块的产品推荐功能（使用规则推荐）
- 过滤规则：过滤当前不可购买、额度不足的产品
- 推荐列表字段：建议持有类型、产品代码/名称、交易时间、产品期限、收益率或业绩比较基准及描述、近一月最大回撤、推荐理由
- 交易时间格式：开放时间 + 赎回清算效率（例：工作日23:59:59后收市，最快T+1到账）
- 近一月最大回撤：活钱管理类不展示
- 操作：产品代码/名称可点击跳转产品详情；每个产品有单独的购买按钮跳转购买页；勾选多个产品跳转购物车

## 建议书下载

- 悬浮按钮位置：右下角
- 保存按钮：本版本不做
- 下载按钮：支持 PDF 和 PNG 格式
- 文件命名格式：`资产配置建议书{YYYYMMDDHHmmss}`（例：资产配置建议书20260629161415）
- 下载内容：所有内容（分页、分Tab）全部平铺展示

## 底部风险提示文案（不可随意改写）

> 理财非存款，产品有风险，投资需谨慎
> 
> 本报告持仓市值、平均持仓成本、持仓天数、收益、持仓年化收益率等数据均由管理机构提供的最新净值测算，由于管理机构净值下发可能会延迟，为提升数据准确性，当发生净值下发延迟时，系统会对相关日期的数据做重算处理，所以可能会存在着相同生成条件下在不同时间生成的结果不一致的情况。
> 
> 本报告中收益率数据使用产品最新净值测算，因管理机构提供的产品净值精度有限，故计算结果仅供参考。该测算不会影响您的实际收益，实际收益请以管理机构确认金额为准。

## 单位换算与精度规则

- 金额 0~9,999 元展示元；10,000~99,999,999 元展示万元；≥100,000,000 元展示亿元；均保留2位小数，四舍五入
- 占比、收益率、年化收益率均保留2位小数，四舍五入；收益率和年化收益率正数显示"+"，负数显示"-"
- 空值：金额类、比例类、收益率类、日期类空值展示 "--"；文本类空值不展示该字段

## 空状态

- 无持仓数据：图标 + "暂无持仓数据" + "购买理财产品，开启投资之旅" + 【去购买】按钮跳转产品列表页
- 无持仓表现/投资分布/期限分布数据：图标 + "暂无{对应数据}"，无引导操作
- 无诊断问题：持仓诊断模块不展示
- 无历史建议书：图标 + "暂无历史建议书记录"，无引导操作（本版本可暂不实现）

## 接口异常降级（页面级表现）

- 接口超时(>5秒)：自动重试3次，失败后展示缓存数据或空状态，"数据加载中，请稍后重试"
- 接口返回错误码：按错误码映射表展示对应提示
- 接口无响应：展示空状态页面，"系统繁忙，请稍后再试"
- 部分数据缺失：展示可用数据，缺失字段显示"--"，无用户提示
- 数据计算异常：该模块展示空状态，"该功能暂时不可用"
