# 页面生成事实

- 项目名：员工自助申请权限
- 需求来源：需求文档_员工自助申请权限2.md
- 事实总数：40

### HF-001
- 类型：页面
- 事实：权限管理模式中新增"自助申请权限模式"，此功能属于超管专属功能，其他用户不可授予权限
- 来源：§3.1-1

### HF-002
- 类型：文案
- 事实：自助申请权限模式宣传页说明文案："员工可自助申请权限，工作流审批通过后，系统将自动分配权限"
- 来源：§3.1-2-1

### HF-003
- 类型：动作
- 事实：点击"了解更多"，跳转至帮助文档
- 来源：§3.1-2-2

### HF-004
- 类型：动作
- 事实：点击"立即启用"：校验双管理员互审模式和权限变更审批模式是否开启，如已开启则提示"企业已开启「双管理员互审模式」，不能同时开启此模式"；如未开启则进入自助申请权限模式设置页面
- 来源：§3.1-2-3

### HF-005
- 类型：页面
- 事实：自助申请模式设置页面，此时模式仍为未开启状态，设置页面点击"开启"后才变为已启用状态
- 来源：§3.1-2-3B

### HF-006
- 类型：模块
- 事实：第一步标题"选择员工申请权限的方式"，两个选项：申请角色、申请功能权限；默认选中"申请角色"；必选，单选
- 来源：§3.1-3-1A

### HF-007
- 类型：文案
- 事实：申请角色下方提示文案："1. 申请通过后，员工将自动关联上申请角色 2. 如果启用常用角色进行授权，建议采用此方式"
- 来源：§3.1-3-1B

### HF-008
- 类型：文案
- 事实：申请功能权限下方提示文案："1. 申请通过后，员工将自动授权功能权限 2. 如果企业常用用户直接授权的方式，建议采用此方式"
- 来源：§3.1-3-1C

### HF-009
- 类型：模块
- 事实：第二步标题"设置角色范围"（当第一步选了"申请角色"时显示）；提示语"请选择允许员工自助申请的角色"；选项：全部角色、部分角色；默认选中"全部角色"；必选，单选
- 来源：§3.1-3-2

### HF-010

- 事实：选择"部分角色"时打开选择角色的弹窗：支持搜索角色；角色列表展示字段：选项框、角色名称、角色说明、角色状态；分页展示；设置完成后展示角色名称，需要限制最多展示个数
- 来源：§3.1-3-2D

### HF-011
- 类型：权限
- 事实：角色范围为企业中已启用+已停用角色
- 来源：§3.1-3-2E

### HF-012

- 事实：设置项"后续新增角色自动加入员工可申请的范围"，默认选中

### HF-013

### HF-014

### HF-016

### HF-017

### HF-019
