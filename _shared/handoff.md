# 交接话术模板

## 3 层结构

每个 Skill 完成后，按以下 3 层结构输出交接话术。

### 第 1 层：完成摘要

用 1-2 句话说明完成了什么、关键产物是什么。

格式：`✅ {Skill中文名} 已完成，产出 {关键产物简述}。`

示例：

- `✅ 需求定案已完成，产出统一需求定案文档（10 章 + 附录）和结构化数据。`
- `✅ 体验蓝图已完成，产出交互设计方案（含旅程图、主/次/异常流程、页面设计、状态文案）。`

### 第 2 层：推荐下一步

读取 `_shared/skill-graph.json` 中当前 Skill 的 `next_hint.preferred[0]`，说明下一步建议。

格式：`下一步建议进入 {next_skill_zh}，{reason}。`

示例：

- `下一步建议进入体验蓝图，基于需求定案生成交互设计方案。`

### 第 3 层：触发语

给出用户可以直接使用的触发语。

格式：`你可以说："{trigger_phrase}"`

示例：

- `你可以说："进入体验蓝图"`

## 终端节点处理

当 Skill 是链路终端（`next_hint.preferred` 为空数组）时：

- 第 2 层改为：`当前链路已完成，无下游 Skill。`
- 第 3 层省略。

## 完整示例（UXB 完成时）

```text
✅ 需求定案已完成，产出统一需求定案文档（10 章 + 附录）和结构化数据。

下一步建议进入体验蓝图，基于需求定案生成交互设计方案。

你可以说："进入体验蓝图"
```
