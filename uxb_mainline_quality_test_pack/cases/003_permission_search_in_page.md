# 测试用例 003：功能权限设置支持页面内查找定位

## 1. 用例定位

- 用例 ID：`uxb-qc-003-permission-search-in-page`
- 输入文档：`inputs/功能权限设置支持筛选已勾选权限_需求文档.md`
- 需求类型：局部体验优化 / 页面内交互增强
- 推荐领域：权限管理、可用性、反馈与报错、信息查找、性能风险
- 推荐输出深度：通常不应过度走完整复杂业务蓝图，由 UXB 判断单决定

## 2. 为什么选这个样本

该需求虽然发生在权限设置页面，但本质不是权限规则变化，而是大量权限项下的页面内查找定位能力。

它适合测试 AI 是否能避免“看到权限就全量消费权限治理知识”的固定习惯。

## 3. 重点测试问题

### 3.1 需求理解

检查 AI 是否识别：

1. 这是页面内查找定位，不是筛选权限数据。
2. 查找行为不改变数据范围。
3. 查找行为不改变勾选状态。
4. 查找只是帮助定位文字和当前命中项。
5. 折叠节点内命中需要展开定位。
6. 大量命中和短关键词会带来性能问题。
7. 查看模式和编辑模式是否都支持仍需确认。

### 3.2 知识选择

| 知识类型 | 应关注内容 |
|---|---|
| 权限能力地图 | 仅确认功能权限设置页面位置，不应过度展开治理模式 |
| 设计准则 / 可用性 | 页面内查找、认知负担、焦点定位 |
| 反馈与报错 | 无命中、当前命中、清空关键词 |
| 流程模式 | 查找、切换、回到编辑状态 |
| 性能风险 | 大量节点高亮、折叠展开、滚动定位 |

### 3.3 固定习惯风险

重点检查是否出现：

- 把“页面内查找”写成“筛选已勾选权限”。
- 写成改变权限列表数据范围。
- 过度设计权限规则、审批、治理状态。
- 忽略未保存编辑状态保护。
- 忽略折叠节点内命中的展开逻辑。
- 忽略命中项计数和上下切换。
- 忽略性能风险。

## 4. 预期评估重点

### 4.1 route_decision

应识别这是局部体验增强，底层权限规则没有变化，重点在页面内查找、焦点定位、编辑状态保护、性能风险。不应自动选择大量权限 raw。

如果 AI 判断为完整新增业务能力，应记为严重问题。

### 4.2 business

如输出 business，应聚焦能力边界：查找定位，不改变数据范围和授权结果；使用对象；适用范围；风险；不应展开审批、权限来源、治理模式等无关内容。

### 4.3 experience

应至少覆盖：查找入口、输入关键词后的高亮、第一个命中自动定位、上一个 / 下一个命中切换、当前命中与其他命中的视觉区分、无命中提示、清空关键词恢复、折叠节点自动展开、未保存勾选状态保护、短关键词大量命中时的性能和提示策略。

## 5. 主要失败信号

| 失败信号 | 严重度 |
|---|---|
| route_decision 误判为复杂业务能力 | 高 |
| 选择大量权限治理 raw，但没有选择可用性 / 反馈类设计准则 | 高 |
| 把查找写成筛选或过滤 | 高 |
| 查找导致列表范围变化 | 高 |
| 未处理编辑状态保护 | 中 |
| 未处理折叠节点内命中 | 中 |
| 未处理大量命中性能 | 中 |

## 6. 耗时关注

该用例理论上应耗时较短。重点观察是否因过度消费权限知识导致 route_decision / assemble 变慢。
