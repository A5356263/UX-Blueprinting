# 智能报表

## 这是什么

这是智能报表子域的二级路由入口，用来说明这个目录里各编号段分别承载什么知识、遇到什么问题该优先看哪些文件。

它不承载正式业务事实正文，也不承载主链路消费说明。

## 编号段

- `00-09`：领域定义、范围与边界
- `10-19`：智能报表全功能产品知识（查阅、订阅、预警、权限管控）

## 任务触发索引

- 需要理解智能报表子域的边界与覆盖范围：读 `00_领域概述.md`
- 需要理解全部功能能力：读 `10_智能报表.md`

## 维护原则

- README 只做领域内路由，不写正式业务规则正文
- 正式业务事实写入对应编号文件
- 新知识优先落到对应编号模块
- 报表创建和数据集管理属于智数平台，不在本域
- 不在本目录中沉淀主链路消费地图、蓝图移交说明或下游执行指令
- 做结构替换时不保留兼容层，确认替换后直接移除旧知识位
