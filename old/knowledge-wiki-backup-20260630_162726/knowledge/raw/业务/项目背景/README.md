# 项目背景

## 这是什么

这是项目背景知识库的二级路由入口，用来说明这个目录里各编号段分别承载什么知识、遇到什么问题该优先看哪些文件。

它不承载正式业务事实正文，也不承载主链路消费说明。

## 编号段

- `00-09`：领域定义、范围与边界
- `01-05`：产品定位、平台角色与终端、产品能力版图、产品优势与服务模式、管理控制台能力概览

## 任务触发索引

- 需要理解项目背景域的目标与边界：读 `00_领域概述.md`
- 需要理解平台定位与角色终端：读 `01_产品定位.md`、`02_平台角色与终端.md`
- 需要理解能力版图与服务模式：读 `03_产品能力版图.md`、`04_产品优势与服务模式.md`
- 需要建立管理后台能力全景：读 `05_管理控制台能力概览.md`

## 维护原则

- README 只做领域内路由，不写正式业务规则正文
- 正式业务事实写入对应编号文件
- 不在本目录中写具体后台配置规则和页面实现细节
- 不在本目录中沉淀主链路消费地图、蓝图移交说明或下游执行指令
- 做结构替换时不保留兼容层，确认替换后直接移除旧知识位
