# 账户与企业生命周期

## 这是什么

这是账户与企业生命周期领域的二级路由入口，用来说明这个目录里各编号段分别承载什么知识、遇到什么问题该优先看哪些文件。

它不承载正式业务事实正文，也不承载主链路消费说明。

## 编号段

- `00-09`：领域定义、范围与边界
- `10-19`：开通路径、企业创建与认证、企业状态与变更、超级管理员变更、账号常见问题、个人账号安全

## 任务触发索引

- 需要理解本域边界：读 `00_领域概述.md`
- 需要理解启用与建企主链路：读 `10_开通路径.md`、`11_企业创建与认证.md`
- 需要理解企业状态与管理员变更：读 `12_企业状态与变更.md`、`13_超级管理员变更.md`
- 需要理解账号问题与个人安全：读 `14_账号常见问题.md`、`15_个人账号安全.md`

## 维护原则

- README 只做领域内路由，不写正式业务规则正文
- 正式业务事实写入对应编号文件
- 不在本目录中写组织主数据或应用内部业务规则
- 不在本目录中沉淀主链路消费地图、蓝图移交说明或下游执行指令
- 做结构替换时不保留兼容层，确认替换后直接移除旧知识位
