# 反馈形式选择原则

## 3. 反馈形式选择速查

| 场景 | 推荐反馈形式 | 是否保留弹窗 |
| --- | --- | --- |
| 操作权限不足 | 操作入口说明/置灰，兜底提示 | 兜底时保留 |
| 数据权限不足 | 数据区域空状态或占位 | 否 |
| 登录/会话失效 | Toast 或轻量状态提示，并引导重新登录 | 否 |
| 网络异常/超时，页面加载失败 | 页面占位 + 重试按钮 | 否 |
| 网络异常/超时，操作提交失败 | Toast 或轻量提示 | 否 |
| 服务繁忙 | Toast 或轻量提示 | 否 |
| 外部系统失败 | Toast 或弹窗，视关键信息复杂度决定 | 条件保留 |
| 必填为空 | 输入框红字 | 否 |
| 格式/长度错误 | 输入框红字 | 否 |
| 唯一性/重复 | 输入框红字，提交后冲突可兜底提示 | 条件保留 |
| 文件上传校验 | 上传区域红字 | 否 |
| 单字段金额/数值错误 | 输入框红字 | 否 |
| 跨字段金额勾稽 | 弹窗或集中校验区，展示相关数值 | 是 |
| 数据不存在，列表进入 | 页面占位 + 返回列表 | 否 |
| 数据不存在，外部链接进入 | 弹窗或空状态 + 返回引导 | 是 |
| 重复操作/已处理 | Toast + 页面状态更新 | 否 |
| 状态不允许操作 | 操作入口提示；兜底弹窗说明状态 | 是 |
| 流程中/处理中 | 操作入口说明/置灰；兜底提示 | 条件保留 |
| 已锁定/冻结/结账 | Banner 或状态区提示 + 操作置灰 | 否 |
| 配置缺失 | 页面占位 + 设置引导 | 否 |
| 税局/外部交互失败 | 弹窗，保留必要外部原因 | 是 |

## 6. 体验时机选择原则

这里的“时机”是体验层面的用户感知位置，不是技术实现要求。

### 6.1 操作前说明

适合：

- 权限不足。
- 状态不允许操作。
- 流程中、处理中。
- 已锁定、已冻结、已结账。
- 配置缺失。

体验目标：

- 减少用户点击后才知道不能做。
- 让用户在行动前理解限制。

### 6.2 输入过程中或字段附近说明

适合：

- 必填为空。
- 格式错误。
- 长度超限。
- 单字段金额/数值错误。
- 名称或编码重复。

体验目标：

- 让用户就地修正。
- 避免提交后返工。

### 6.3 文件选择或上传区域说明

适合：

- 文件格式不支持。
- 文件过大。
- 文件名不合法。
- 文件内容解析失败。

体验目标：

- 让用户直接替换或修正文件。

### 6.4 提交后轻量反馈

适合：

- 网络异常。
- 服务繁忙。
- 重复操作已处理。
- 异步处理中。

体验目标：

- 告知结果，不额外制造重阻断。

### 6.5 提交后强阻断反馈

适合：

- 跨字段复杂关系错误。
- 状态在操作过程中发生变化。
- 外部系统返回重要失败原因。
- 税局、财务等需要用户核对具体原因的失败。

体验目标：

- 保留必要信息。
- 给出明确修正或返回路径。
