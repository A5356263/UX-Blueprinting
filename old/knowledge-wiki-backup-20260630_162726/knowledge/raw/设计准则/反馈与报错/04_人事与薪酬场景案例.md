# 人事与薪酬场景案例

## 2. 报错类型与推荐体验处理

### 2.16 考勤相关规则限制

原始分类：

- 大类：业务规则限制类
- 小类：考勤相关
- 当前形式：弹窗提示

任务场景：

- 考勤打卡。
- 排班。
- 请假、加班。
- 调店、借调。

问题原因：

- 考勤周期未设置。
- 排班不存在。
- 时间冲突。
- 员工不在考勤组。

现状体验问题：

- 配置缺失无引导。
- 时间冲突不展示冲突时间。
- 条件不满足只提示失败。

推荐反馈形式：

- 配置缺失：页面占位或状态提示，并引导设置。
- 时间冲突：弹窗或阻断提示，展示冲突详情。
- 不在考勤组：轻量提示并说明联系对象。

推荐文案：

```text
尚未设置考勤周期，请先前往「考勤设置」配置。
该时间段已存在{类型}记录（{开始日期}～{结束日期}），请调整时间后重新提交。
该员工不在考勤组中，请联系考勤管理员。
```

原文案问题示例：

```text
未设置考勤周期。
该调店时间段内已经存在其他调店记录。
```

建议处理：

- 配置缺失要给设置路径。
- 时间冲突要给起止日期和冲突类型。

需确认信息：

- 设置入口名称。
- 考勤管理员角色。
- 时间冲突应展示哪些记录细节。

体验影响方向：

- 帮助用户完成配置。
- 减少因时间冲突导致的反复提交。

### 2.17 薪资和算税相关规则限制

原始分类：

- 大类：业务规则限制类
- 小类：薪资/算税相关
- 当前形式：弹窗提示

任务场景：

- 薪资计算。
- 个税申报。
- 工资单查看。

问题原因：

- 薪资组锁定。
- 正在算税中。
- 个税已申报。

现状体验问题：

- 算税中用弹窗阻断过重。
- 锁定状态缺少解锁路径。
- 个税已申报后的补救动作不清楚。

推荐反馈形式：

- 锁定/已申报：banner、状态提示或必要弹窗，说明负责角色或补救动作。
- 算税中：toast 或轻量状态提示。

推荐文案：

```text
薪资组已锁定，无法修改薪酬数据。如需解锁，请联系薪酬管理员。
算税正在进行中，请稍后查看结果。
该员工个税已申报，无法删除。如需更正，请先作废申报。
```

原文案问题示例：

```text
当前正在算税中，不能进行算税。
薪资组已锁定，无法计算薪资。
```

建议处理：

- 算税中不宜使用重阻断。
- 锁定状态补充解锁路径。
- 已申报状态补充更正路径。

需确认信息：

- 谁可以解锁。
- 已申报后的更正路径是否成立。
- 算税中是否可查看进度或结果。

体验影响方向：

- 减少计算类任务的打断。
- 让用户理解等待、解锁或更正路径。
