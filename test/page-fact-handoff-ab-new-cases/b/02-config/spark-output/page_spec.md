# 页面生成规格：展馆导览设备绑定

## 1. 页面摘要

- **产品领域**：展馆导览线路与讲解器配置
- **页面类型**：列表页、抽屉、弹窗
- **用户角色**：展馆运营员
- **核心任务**：为单条导览线路选择讲解器并保存自动分配设置。

---

## 2. 生成范围

### 生成

- E0 导览线路（Page），承载线路行操作和保存结果。
- E1 绑定讲解器（Drawer），维护当前线路的已选设备和自动分配设置。
- E2 选择讲解器（Modal），在 E1 上方完成候选多选和选择回填。

### 只引用不生成

无。

### 不生成

- 多条线路的批量绑定操作，本期按单条线路配置。
- 绑定及自动分配设置的保存处理，用户在抽屉发起并在线路表接收结果。

---

## 3. 跨实体任务流程

### 绑定讲解器

- 顶级菜单 —点击“导览线路”→ E0 导览线路。
- E0 —点击线路行的“绑定设备”→ E1 绑定讲解器（带入触发行的线路）。
- E1 —点击“选择设备”→ E2 选择讲解器（抽屉保持打开，保留当前编辑）。
- E2 —点击“应用选择”→ E1（关闭弹窗，回显本次应用的全部设备编号）。
- E2 —点击“取消”→ E1（关闭弹窗，保留进入弹窗前的选择）。
- E1 —点击“保存绑定”且保存成功→ E0（关闭抽屉，原线路行显示更新后的已绑定数量）。
- E1 —点击“取消”→ E0（关闭抽屉，丢弃未保存更改，原行显示已保存结果）。

---

## 4. 导览线路（E0）

### 页面目标

展馆运营员从同名顶级菜单进入页面，可逐行查看线路和当前绑定数量，并配置所选线路。

### 页面结构

```text
+----------------------------------------------------------------+
| 导览线路                                                       |
|                                                                |
| 线路名称                 已绑定数量                操作        |
| {线路名称}               {已绑定数量}              [绑定设备]  |
+----------------------------------------------------------------+
```

### 区域说明

- 标题区显示“导览线路”。主区域为线路 Table，每行对应一条线路，“绑定设备”位于本行“操作”列。

### 信息与字段

- “线路名称”为当前行线路的名称。
- “已绑定数量”为当前行线路已保存的设备绑定数量。
- “操作”承载本行的“绑定设备”。

### 关键操作

- 点击“绑定设备”时以当前行所对应线路为配置对象。

### 状态与异常恢复

- 保存成功回到本页时更新原线路行“已绑定数量”，展示 Toast `routes.saved`。用户可继续查看线路表或再次配置线路。

### 文案与变量

| key | 文案 | 适用位置／状态 | 变量及含义、取值 |
| --- | --- | --- | --- |
| `routes.title` | 导览线路 | 顶级菜单、页标题 | 无 |
| `routes.bound_count` | 已绑定数量 | 线路表头 | 无 |
| `routes.actions` | 操作 | 线路表头 | 无 |
| `routes.bind` | 绑定设备 | 线路表行级 Button | 无 |
| `routes.saved` | 设备绑定已保存 | 保存成功后，线路页 Toast | 无 |

本页线路名称列使用 `common.route_name`。

## 5. 绑定讲解器（E1）

### 抽屉目标

在所选线路的上下文中编辑拟绑定的讲解器与自动分配设置，单次保存两项设置。

### 区域结构

```text
+--------------------------------------------------+
| 绑定讲解器                                       |
| 线路名称  {线路名称}                             |
|--------------------------------------------------|
| 设备      [选择设备]                             |
|                                                  |
| 启用自动分配  [Switch: {开关状态}]                |
|--------------------------------------------------|
|                           [取消] [保存绑定]      |
+--------------------------------------------------+
```

### 条件结构（存在已选设备）

在设备区的选择入口下方展示编号列表。

```text
| 设备      [选择设备]                             |
| {已选设备编号列表}                               |
```

### 条件结构（保存未通过设备校验）

在设备区追加校验提示。存在已选设备时，提示位于编号列表下方。

```text
| 设备      [选择设备]                             |
| {已选设备编号列表（有已选时）}                   |
| InlineError · binding.required / binding.limit  |
|               binding.disabled_selected         |
```

### 区域说明

- Drawer 顶部是标题和只读线路名称。中部可编辑区含设备区和自动分配开关。设备区含选择 Button，以及逐项显示全部已选设备编号的 List，未选时无编号条目。
- 底部放置“取消”和“保存绑定”。

### 信息与字段

- “线路名称”只读，值取触发行。
- “设备”是拟绑定的讲解器集合，保存要求一至五台。已有绑定进入时显示已绑定设备，选择应用后显示本次完整选择。
- “启用自动分配”使用 Switch。新增绑定默认关闭，编辑已有绑定时回显当前设置，两个取值为开启和关闭。

### 关键操作

- 点击“选择设备”可进入或再次进入选择，应用后在设备区回显所有已选编号，仍可继续编辑自动分配设置。
- 切换“启用自动分配”改变抽屉内待保存设置。
- 点击“保存绑定”触发数量及可用性校验。成功保存时更新同一条线路的设备绑定及自动分配设置。
- 点击“取消”放弃抽屉中未保存的设备和自动分配更改。

### 校验与反馈

- 点击“保存绑定”时未选设备，在“设备”区展示 `binding.required` 并阻断保存。保留当前编辑，用户可打开选择弹窗补选。
- 点击“保存绑定”时选择超过五台，在“设备”区展示 `binding.limit` 并阻断保存。保留已选，用户可打开选择弹窗减少已选数量。
- 若保存时有已选设备已变为停用，在“设备”区展示 `binding.disabled_selected` 并阻断保存。保留已选，用户可重开选择弹窗调整。

### 状态与异常恢复

- 设备校验失败后抽屉保持打开，当前线路及编辑内容留在原位置。设备区按条件结构保留反馈和选择入口，调整后可重新保存。

### 文案与变量

| key | 文案 | 适用位置／状态 | 变量及含义、取值 |
| --- | --- | --- | --- |
| `binding.title` | 绑定讲解器 | 抽屉标题 | 无 |
| `binding.devices` | 设备 | 设备区标签 | 无 |
| `binding.select` | 选择设备 | 设备区 Button | 无 |
| `binding.selected_id` | {设备编号} | 已选 List 中每项 | `{设备编号}` 为当前抽屉已选讲解器的标识 |
| `binding.auto` | 启用自动分配 | Switch 标签 | 无 |
| `binding.save` | 保存绑定 | 抽屉底部 Button | 无 |
| `binding.required` | 请至少选择一台讲解器 | 保存时设备为零，设备区 InlineError | 无 |
| `binding.limit` | 最多可绑定五台讲解器 | 保存时设备超过五台，设备区 InlineError | 无 |
| `binding.disabled_selected` | 部分设备已停用，请重新选择 | 保存时有已选设备变为停用，设备区 InlineError | 无 |

顶部只读线路名称使用 `common.route_name`，底部取消 Button 使用 `common.cancel`。

## 6. 选择讲解器（E2）

### 弹窗目标

从候选讲解器列表多选设备，并将所选集合回填到保持打开的绑定抽屉。

### 区域结构

```text
+------------------------------------------------------------------+
| 选择讲解器                                                       |
|------------------------------------------------------------------|
|        设备编号              所在展厅            可用状态        |
| [ ]    {设备编号}            {所在展厅}          {可用状态}      |
|------------------------------------------------------------------|
|                                          [取消] [应用选择]      |
+------------------------------------------------------------------+
```

### 条件结构（停用候选）

对应候选行的选择控件禁用。

```text
| [ ] Checkbox 禁用   {设备编号}    {所在展厅}    停用            |
```

### 区域说明

- Modal 叠加在 E1 上方。候选 Table 的每行使用 Checkbox 承载选择，表中保留所有候选的状态信息，包括停用的讲解器。
- 底部放置“取消”和“应用选择”。

### 信息与字段

- “设备编号”为候选讲解器的设备标识。“所在展厅”为候选设备所属展厅。
- “可用状态”只显示“可用”或“停用”。可用候选支持勾选或取消勾选。停用候选继续显示于列表，Checkbox 禁用。

### 关键操作

- 打开弹窗时，抽屉中已选且当前可用的设备回显为已勾选，停用设备无法纳入本次应用的选择。勾选变化在弹窗内暂存。
- “应用选择”将本次勾选的全部设备作为完整选择，关闭弹窗。保存绑定仍须由抽屉的“保存绑定”发起。
- “取消”放弃本次弹窗内勾选变化，关闭弹窗并保留抽屉原有选择。

### 状态与异常恢复

- 重选时，若设备当前已停用，候选行仍显示“停用”且禁用勾选。运营员可选择其他可用设备后应用，或取消本轮选择保留抽屉原状。

### 文案与变量

| key | 文案 | 适用位置／状态 | 变量及含义、取值 |
| --- | --- | --- | --- |
| `picker.title` | 选择讲解器 | 弹窗标题 | 无 |
| `picker.device_id` | 设备编号 | 候选表头 | 无 |
| `picker.hall` | 所在展厅 | 候选表头 | 无 |
| `picker.availability` | 可用状态 | 候选表头 | 无 |
| `picker.available` | 可用 | 候选设备可选 | 无 |
| `picker.disabled` | 停用 | 候选设备不可选 | 无 |
| `picker.apply` | 应用选择 | 弹窗底部 Button | 无 |

底部取消 Button 使用 `common.cancel`。
