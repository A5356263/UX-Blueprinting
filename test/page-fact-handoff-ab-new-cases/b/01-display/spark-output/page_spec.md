# 页面生成规格：温室监测工作台

## 1. 页面摘要

- **产品领域**：温室环境监测
- **页面类型**：只读工作台
- **用户角色**：温室管理员
- **核心任务**：查看当日温室环境读数、告警记录和探头状态。

---

## 2. 生成范围

### 生成

- E0 温室监测工作台（Page），包含三个页签及各自内容区的状态。

### 只引用不生成

无。

### 不生成

- 告警处置界面，本期只提供告警查看。
- 监测数据读取处理，界面仅承载读取结果、读取失败和重试入口。

---

## 3. 跨实体任务流程

### 查看当日监测

- 顶级菜单 —点击“温室监测”→ E0 温室监测工作台（首次进入显示“实时读数”）。

---

## 4. 温室监测工作台（E0）

### 页面目标

温室管理员从顶级菜单“温室监测”进入同名工作台，可查看全部页签。其他角色不显示该菜单入口。工作台只读，查看、切换和重试均无业务写入。

### 页面结构

```text
+-------------------------------------------------------------------+
| 温室监测                                                          |
| [实时读数] [告警记录] [探头状态]                                     |
|                                                                   |
| 最近采集时间  {最近采集时间}                                        |
| 分区           温度（℃）         相对湿度（%）                       |
| {分区}         {温度}           {相对湿度}                         |
+-------------------------------------------------------------------+
```

### 条件结构（选中“告警记录”且有当日告警）

替换当前页签内容区。

```text
| 发生时刻       告警级别          恢复时刻                           |
| {发生时刻}     {告警级别}        {恢复时刻}                         |
```

### 条件结构（选中“探头状态”）

替换当前页签内容区。

```text
| 探头编号       安装分区          联机状态                           |
| {探头编号}     {安装分区}        {联机状态}                         |
```

### 条件结构（选中“告警记录”且当日无告警）

替换当前页签内容区。

```text
| 今日暂无告警                                                      |
```

### 条件结构（选中的“实时读数”读取失败）

替换当前页签内容区。

```text
| 读数加载失败     [重试]                                            |
```

### 区域说明

- 标题区显示“温室监测”。Tabs 按“实时读数”“告警记录”“探头状态”排列，首次进入选中“实时读数”。
- 当前页签内容区只显示选中页签所属内容。实时读数的“最近采集时间”位于标题下方、读数表上方，其余页签内容区不展示该字段。三份列表使用只读 Table。

### 信息与字段

- 实时读数区域信息“最近采集时间”为时间。读数表的“分区”为分区名称，“温度（℃）”为摄氏温度数值，“相对湿度（%）”为相对湿度百分比数值。
- 告警记录表的“发生时刻”为告警发生时间，“告警级别”为告警级别标签，“恢复时刻”为告警恢复时间，未恢复时使用 `greenhouse.no_recovery`。
- 探头状态表的“探头编号”为设备标识，“安装分区”为探头安装位置对应分区，“联机状态”仅显示 `greenhouse.online` 或 `greenhouse.offline`。

### 关键操作

- 点击任一页签时保持当前页面，只切换选中页签和对应内容区。
- “重试”重新加载当前的“实时读数”页签。页签仍选中，成功后恢复正常读数内容。

### 状态与异常恢复

- 告警空态仅在“告警记录”内容区显示 EmptyState `greenhouse.empty_alerts`，其他两个页签仍可切换。
- 实时读数加载失败时，按本页条件结构在“实时读数”内容区显示 `greenhouse.readings_failed` 和“重试”。用户可就地重试或切换页签。重试仍失败时保留失败提示和重试入口。
