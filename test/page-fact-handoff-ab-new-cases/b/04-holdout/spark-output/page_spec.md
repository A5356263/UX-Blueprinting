# 页面生成规格：社团排练室预约

## 1. 页面摘要

- **产品领域**：社团排练室预约
- **页面类型**：房间列表页、个人预约列表页、预约确认弹窗、预约凭据抽屉
- **用户角色**：社团成员
- **核心任务**：查看房间排期，提交排练时段预约，并查看本人预约的凭据。

---

## 2. 生成范围

### 生成

- E0「排练室预约」Page。同名菜单进入，承载房间排期、预约入口和提交后的时段更新。
- E1「我的预约」Page。同名菜单进入，承载本人预约列表、列表空态和凭据入口。
- E2「确认预约」Modal。由 E0 的时段操作打开，承载选中时段核对、备注输入、提交和时段冲突恢复。
- E3「查看凭据」Drawer。由 E1 的预约记录操作打开，承载该记录的只读凭据。

### 只引用不生成

- 无。

### 不生成

- 保存预约、提交时核验时段和刷新房间时段属于系统处理，无独立界面。
- 「排练室预约」页取消已提交预约的操作超出本期范围。

---

## 3. 跨实体任务流程

### 提交预约

- 「排练室预约」菜单 —点击→ E0「排练室预约」（查看房间列表）。
- E0 —点击可约时段的「预约」→ E2「确认预约」（带入所选房间和时段，E0 保留在弹窗下）。
- E2 —点击「取消」→ E0 原房间列表位置。
- E2 —点击「确认预约」且保存成功→ E0 当前房间列表（弹窗关闭，原时段变为已约）。
- E2 —点击「确认预约」且时段已被其他人预约→ E2 时段冲突状态（弹窗保持打开）。
- E2 时段冲突状态 —点击「返回选择」→ E0 原房间列表（弹窗关闭，刷新排期后可选择其他可约时段）。

### 查看预约凭据

- 「我的预约」菜单 —点击→ E1「我的预约」（可查看本人的预约，包括提交成功后的对应记录）。
- E1 —点击已确认记录的「查看凭据」→ E3「查看凭据」（展示所选记录，E1 保留在抽屉下）。
- E3 —点击「关闭」→ E1 原预约列表。

## 4. E0 排练室预约

### 页面目标

社团成员查看房间排期和容量，从可约时段发起预约，并核对提交后的时段变化。

### 页面结构

```text
+--------------------------------------------------+
| 排练室预约                                       |
+--------------------------------------------------+
| 房间列表 List                                    |
| +----------------------------------------------+ |
| | 房间名 {房间名}   可容纳人数 {可容纳人数}      | |
| | 可预约时段                                   | |
| | {时段}                             [预约]   | |
| +----------------------------------------------+ |
| 按房间重复信息块，块内按时段重复显示时段行       |
+--------------------------------------------------+
```

### 条件结构（时段已约）

```text
房间列表 > 对应时段行
+----------------------------------------------+
| {时段}                             [已约 Tag] |
+----------------------------------------------+
```

### 区域说明

- 标题区显示当前页面名称。
- 房间列表以房间为单位组织。每个信息块上方显示房间资料，下方为排期，每个时段在同一行显示时段信息和对应操作或状态。
- 预约成功的即时反馈 Toast 由本页显示。

### 信息与字段

- 「房间名」为对应房间的名称。
- 「可容纳人数」为对应房间的可容纳人数，类型为人数。
- 「可预约时段」为对应房间的排期展示项。每条使用对应的时段值，入口与状态归属该条时段。

### 关键操作

- 社团成员点击某一可约时段的「预约」，打开「确认预约」弹窗，带入该房间和时段。

### 状态与异常恢复

- **可约**。该时段允许预约时，操作位显示「预约」，成员可进入确认弹窗。
- **已约**。已被预约的时段显示标签「已约」，隐藏该时段的「预约」入口。使用「条件结构（时段已约）」，其他时段仍按各自状态显示。
- **提交成功回流**。停留在当前房间列表，原选中时段应用已约状态，同时显示 Toast `room.reservationSubmitted`。成员可通过同名菜单进入「我的预约」，在对应记录查看凭据。
- **取消与重新选择**。从确认弹窗点击「取消」后，保留当前房间列表位置。时段冲突后通过「返回选择」回到原列表，刷新后以最新排期显示各时段状态，成员可改选其他可约时段。

### 文案与变量

| key | 文案 | 适用位置／状态 | 变量及含义、取值 |
| --- | --- | --- | --- |
| room.title | 排练室预约 | 同名菜单入口、页面标题 | 无 |
| room.capacityLabel | 可容纳人数 | 房间信息 | 无 |
| room.capacityValue | {可容纳人数} | 可容纳人数值 | 对应房间的可容纳人数 |
| room.slotsLabel | 可预约时段 | 房间排期区标签 | 无 |
| room.reserve | 预约 | 可约时段行操作位 | 无 |
| room.booked | 已约 | 已约时段行状态标签 | 无 |
| room.reservationSubmitted | 预约已提交 | 保存成功回到房间列表的 Toast | 无 |

房间信息使用 `shared.roomNameLabel`、`shared.roomNameValue`，排期行使用 `shared.slotValue`。

## 5. E1 我的预约

### 页面目标

社团成员查看本人的预约记录及状态，从已确认记录查看对应凭据。

### 页面结构

```text
+--------------------------------------------------------------------+
| 我的预约                                                           |
+--------------------------------------------------------------------+
| 我的预约列表 Table                                                 |
| 预约编号   | 房间名    | 时段   | 预约状态   | 操作                 |
| {预约编号} | {房间名}  | {时段} | {预约状态} | [查看凭据]           |
+--------------------------------------------------------------------+
```

### 条件结构（记录状态不是已确认）

```text
我的预约列表 > 对应记录
+--------------------------------------------------------------------+
| {预约编号} | {房间名} | {时段} | {预约状态} |                      |
+--------------------------------------------------------------------+
```

### 条件结构（本人无预约记录）

```text
我的预约列表 > 表体
+--------------------------------------------------------------------+
| EmptyState：reservation.empty                                      |
+--------------------------------------------------------------------+
```

### 区域说明

- 标题区显示当前页面名称。
- 预约列表每行对应一条本人预约记录，表头顺序如上。操作列放置当前记录可执行的查看入口。

### 信息与字段

- 「预约编号」列显示当前记录的预约编号。
- 「房间名」列显示当前记录关联的房间名称。
- 「时段」列显示当前记录的预约时段。
- 「预约状态」列显示当前记录的状态。保存成功的记录初始为「已确认」。
- 「操作」列用于放置凭据入口，按记录的预约状态决定是否显示。

### 关键操作

- 社团成员在本人已确认记录的「操作」列点击「查看凭据」，打开同名抽屉并展示该条记录。关闭抽屉后回原预约列表。

### 状态与异常恢复

- **已确认记录**。成员预约成功后，该记录以「已确认」状态出现在本人列表，「操作」列显示「查看凭据」。
- **其他记录状态**。仅「已确认」记录显示「查看凭据」。状态不满足时，按「条件结构（记录状态不是已确认）」留空该记录的操作列。
- **本人无预约记录**。当成员没有自己的预约时，在表体显示 `reservation.empty`，没有记录行或行级操作。使用「条件结构（本人无预约记录）」；成员仍可通过「排练室预约」菜单进入房间列表。

### 文案与变量

| key | 文案 | 适用位置／状态 | 变量及含义、取值 |
| --- | --- | --- | --- |
| reservation.title | 我的预约 | 同名菜单入口、页面标题 | 无 |
| reservation.statusLabel | 预约状态 | 列表表头 | 无 |
| reservation.statusValue | {预约状态} | 记录状态值 | 对应预约记录的当前状态 |
| reservation.confirmed | 已确认 | 成功保存的记录初始状态 | 无 |
| reservation.actionLabel | 操作 | 列表表头 | 无 |
| reservation.empty | 你还没有预约记录 | 本人无预约记录时的表体 EmptyState | 无 |

列表使用 `shared.reservationIdLabel`、`shared.reservationIdValue`、`shared.roomNameLabel`、`shared.roomNameValue`、`shared.slotLabel`、`shared.slotValue`。已确认记录的操作使用 `shared.viewCredential`。

## 6. E2 确认预约

### 弹窗目标

社团成员核对从房间列表选中的房间和时段，可填写排练备注并提交预约。

### 区域结构

```text
+----------------------------------------------+
| 确认预约                                     |
+----------------------------------------------+
| 房间名    {房间名}                            |
| 日期      {日期}                              |
| 开始时间  {开始时间}                          |
| 结束时间  {结束时间}                          |
+----------------------------------------------+
| 排练备注（选填）                              |
| [Textarea]                                   |
+----------------------------------------------+
|                        [取消] [确认预约]      |
+----------------------------------------------+
```

### 条件结构（提交时时段冲突）

```text
时段摘要下方至底部操作区
+----------------------------------------------+
| InlineError：confirmation.slotConflict       |
| [返回选择]                                   |
+----------------------------------------------+
| 排练备注（选填）                              |
| [Textarea 原值]                              |
+----------------------------------------------+
|                  [取消] [确认预约 / 禁用]    |
+----------------------------------------------+
```

### 区域说明

- 标题区显示弹窗名称。
- 时段摘要区按顺序显示房间名、日期、开始时间和结束时间，全部为只读文本。时段冲突时的反馈与恢复操作紧邻该区。
- 备注区使用 Textarea。底部操作区提供「取消」和主要提交操作「确认预约」。

### 信息与字段

- 「房间名」为从房间列表选中的房间名称，只读。
- 「日期」为选中时段对应日期，只读。
- 「开始时间」为选中时段的开始时刻，只读，采用 24 小时制。
- 「结束时间」为选中时段的结束时刻，只读，采用 24 小时制。
- 「排练备注」为成员填写的可编辑文本，选填，留空仍可提交。

### 关键操作

- 成员在「排练备注」输入排练说明。
- 点击「确认预约」发起提交，系统核验本次选择的时段。保存成功后关闭弹窗。
- 点击「取消」关闭弹窗，回到原房间列表位置。
- 时段冲突时点击「返回选择」，关闭弹窗并返回原房间列表，同时刷新时段。

### 校验与反馈

- **提交时核验时段占用**。成员点击「确认预约」后，若该时段已被其他人约走，系统阻断提交，本次预约不保存。弹窗保持打开，在时段摘要下显示 `confirmation.slotConflict` 和「返回选择」。若时段仍可约，系统保存预约并关闭弹窗，结果由房间列表接收。

### 状态与异常恢复

- **时段冲突**。提交时命中占用校验后进入「条件结构（提交时时段冲突）」。弹窗保留当前摘要和已填备注，禁用对同一时段的「确认预约」。成员点击「返回选择」回到刷新后的房间列表，可从其他可约时段重新发起预约。「取消」仍可关闭弹窗并保留原列表位置。

### 文案与变量

| key | 文案 | 适用位置／状态 | 变量及含义、取值 |
| --- | --- | --- | --- |
| confirmation.titleSubmit | 确认预约 | 弹窗标题、提交按钮 | 无 |
| confirmation.dateLabel | 日期 | 时段摘要标签 | 无 |
| confirmation.dateValue | {日期} | 日期值 | 选中时段对应日期 |
| confirmation.startLabel | 开始时间 | 时段摘要标签 | 无 |
| confirmation.startValue | {开始时间} | 开始时间值 | 选中时段的开始时刻，24 小时制 |
| confirmation.endLabel | 结束时间 | 时段摘要标签 | 无 |
| confirmation.endValue | {结束时间} | 结束时间值 | 选中时段的结束时刻，24 小时制 |
| confirmation.noteLabel | 排练备注 | Textarea 字段标签 | 无 |
| confirmation.optional | 选填 | 排练备注标签旁 | 无 |
| confirmation.cancel | 取消 | 弹窗底部操作 | 无 |
| confirmation.slotConflict | 当前时段已被预约，请改选其他时段 | 提交时时段冲突，时段摘要下方 InlineError | 无 |
| confirmation.chooseAgain | 返回选择 | 时段冲突时的恢复操作 | 无 |

摘要中的房间名称使用 `shared.roomNameLabel`、`shared.roomNameValue`。

## 7. E3 查看凭据

### 抽屉目标

社团成员查看所选本人预约记录的凭据信息。

### 区域结构

```text
+----------------------------------------------+
| 查看凭据                            [关闭]   |
+----------------------------------------------+
| 预约编号  {预约编号}                          |
| 房间名    {房间名}                            |
| 时段      {时段}                              |
+----------------------------------------------+
```

### 区域说明

- 抽屉叠加在「我的预约」页上，标题区包含抽屉标题和关闭按钮。
- 凭据内容区从上到下展示三项只读记录信息。

### 信息与字段

- 「预约编号」为当前预约记录的编号。
- 「房间名」为该记录的房间名称。
- 「时段」为该记录的预约时段。

### 关键操作

- 点击「关闭」，关闭凭据抽屉并返回原「我的预约」列表。

### 文案与变量

| key | 文案 | 适用位置／状态 | 变量及含义、取值 |
| --- | --- | --- | --- |
| credential.close | 关闭 | 抽屉标题区按钮 | 无 |

抽屉标题使用 `shared.viewCredential`。内容使用 `shared.reservationIdLabel`、`shared.reservationIdValue`、`shared.roomNameLabel`、`shared.roomNameValue`、`shared.slotLabel`、`shared.slotValue`。
