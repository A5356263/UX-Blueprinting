# 候选规则 B
仅用于隔离 A/B 的 Page Spec 交接实验。来源是绑定的完整正式格式测试基线。
1. 业务知识消费与方案推导前，逐节扫描 §2 至 §9，并用 §11 反查遗漏。依次按页面、Tab、区域、弹窗、抽屉或任务归组，从已明确提及的内容里拆出可分别遗漏的页面事实。处理入口、层级、标签、字段、选项、默认值、权限、可见与可操作条件、固定文案、校验、状态、反馈、跨角色结果、返回与恢复。逐条在运行内部记录原文定位与完整事实，每个已明确的同类成员独立可核对，例如分别处理每一个 Tab 和字段。相同事实去重。基线 §10 仍按原规则单独吸收。
2. 保持现行 Page Spec 判定与输出合同。以已建立的内部清单取代 Step 3 的外置 HF 读取，按现行逐事实完整覆盖标准检查草稿，找到每条在正式结构、字段、操作、状态或文案的落点。入口无法替代完整实体。未落地则先修草稿再写盘，写盘后按同一清单复核。
3. 清单属于本次运行内部。测试工作区没有外置 HF。不得读取另一组的输入或产物，也不在 Page Spec 正文输出内部清单。
