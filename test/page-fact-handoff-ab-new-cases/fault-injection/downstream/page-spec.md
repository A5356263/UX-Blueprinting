# 页面生成规格：剧场票务稽核

## 1. 页面摘要
- 产品领域：剧场票务
- 页面类型：只读工作台
- 用户角色：票务稽核员
- 核心任务：对照核销场次和异常订单。

## 2. 生成范围
### 生成
- E0「票务稽核」，同名菜单进入的只读页面。
### 只引用不生成
- 无。
### 不生成
- 订单或票据的写入操作。

## 3. 跨实体任务流程
- 票务稽核员 —点击「票务稽核」菜单→ E0，首次进入显示「核销总览」。

## 4. E0 票务稽核

### 页面目标
仅票务稽核员可访问。查看核销总览和异常订单。

### 页面结构

```text
票务稽核
Tabs [核销总览*] [异常订单]
核销总览内容区
  仅看未核销 [Switch 关闭]
  Table 演出场次 | 已核销数 | 未核销数
```

### 条件结构（选中异常订单）
```text
当前内容区
  Table 订单号 | 异常原因
```

### 条件结构（异常订单为空）
```text
异常订单 Table > 表体
  EmptyState 当前没有异常订单
```

### 区域说明
顶部是页签，顺序为「核销总览」「异常订单」。页签切换只替换当前内容区，始终停留在本页。开关仅在「核销总览」的内容区顶部显示。

### 信息与字段
- 核销总览显示「演出场次」「已核销数」「未核销数」；「仅看未核销」首次进入默认关闭，关闭时展示所有场次。
- 异常订单显示「订单号」「异常原因」。

### 关键操作
- 点击页签切换内容，当前页面不离开。
- 开启「仅看未核销」时只展示存在未核销票的场次；切换关闭则展示全部场次。

### 状态与异常恢复
- 异常订单列表没有记录时，列表内显示 `orders.empty`。
