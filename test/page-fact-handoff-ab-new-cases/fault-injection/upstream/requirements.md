# 原始需求 · 校园工坊设备借用

工坊管理员从「借用审核」菜单进入设备借用审核页。仅工坊管理员能查看本页和办理审核。

列表按行显示「借用单号」「设备名称」「借用人」「预计归还时间」「安全认证编号」和「审核状态」。安全认证编号取自借用单，只读，可用于管理员核对借用人的设备安全认证。预计归还时间用 24 小时制显示。

只在「待审核」的行显示「同意借用」。管理员点击后打开「确认同意」弹窗，弹窗只读显示借用单号和设备名称，提供「确认」和「取消」。「取消」关闭弹窗并保留原行。「确认」成功后关闭弹窗，原行状态为「已同意」，隐藏「同意借用」，提示「借用已同意」。

没有借用单时，在列表内显示「暂无借用记录」。本期不支持批量审核。
