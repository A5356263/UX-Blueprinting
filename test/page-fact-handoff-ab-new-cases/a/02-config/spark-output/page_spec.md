# 页面生成规格：展馆导览设备绑定

## 1. 页面摘要

- **产品领域**：展馆导览 — 线路设备绑定
- **页面类型**：抽屉、列表页、选择弹窗
- **用户角色**：展馆运营员
- **核心任务**：为指定导览线路绑定讲解器并设置自动分配。

---

## 2. 生成范围

### 生成

- E0 导览线路（Page）。顶级菜单进入，在线路表的行内发起绑定。
- E1 绑定讲解器（Drawer）。由 E0 的线路行打开，编辑当前线路的设备绑定和自动分配。
- E2 选择讲解器（Modal）。由 E1 的设备区打开，覆盖在仍保持打开的 E1 上方，返回 E1。

### 只引用不生成

- 无。

### 不生成

- 多条线路批量绑定，本期明确排除。
- 保存时的设备可用性校验和写入，为系统处理。

---

## 3. 跨实体任务流程

### 配置指定线路的讲解器

- 展馆运营员 —点击顶级菜单“导览线路”→ E0 线路表。
- E0 —点击目标行“绑定设备”→ E1，保留该线路行作为返回位置。
- E1 —点击“选择设备”→ E2，E1 保持打开。
- E2 —点击“应用选择”→ 关闭 E2，回填 E1；点击“取消”→ 关闭 E2，回到原选择仍在的 E1。
- E1 —点击“保存绑定”且保存成功→ 关闭 E1，回 E0 原线路行已更新状态；校验未通过→ 停留 E1。
- E1 —点击“取消”→ 关闭 E1，丢弃本次未保存修改，回 E0 原线路行。

---

## 4. 导览线路（E0）

### 页面目标

展馆运营员查看各导览线路当前保存的讲解器绑定数量，并进入指定线路的绑定配置。

### 页面结构

```text
+--------------------------------------------------+
| 导览线路                                         |
+--------------------------------------------------+
| Table 线路名称 | 已绑定数量 | 操作                 |
| {线路名称}     | {已绑定数量} | [绑定设备]          |
+--------------------------------------------------+
```

### 区域说明

- 标题区显示页面名，从同名顶级菜单进入。
- 主区域为线路 Table。操作列中的“绑定设备”归属当前线路行。

### 信息与字段

- 线路名称来自当前行的线路记录。已绑定数量为该线路当前已保存绑定的讲解器台数。
- 操作列提供当前行的“绑定设备”。

### 关键操作

- 展馆运营员点击某行“绑定设备”，带入该行线路打开 E1。

### 状态与异常恢复

- 保存成功返回。E1 关闭后更新当前线路行的已绑定数量，在 E0 显示 Toast `route.saved`。可继续查看或打开同一行的配置。
- 取消返回。E1 关闭后原行显示已保存的数量，用户仍可打开该行配置。

### 文案与变量

| key | 文案 | 适用位置／状态 | 变量及含义、取值 |
| --- | --- | --- | --- |
| route.title | 导览线路 | 顶级菜单、页面标题 | 无 |
| route.quantity | 已绑定数量 | 线路表列头 | 无 |
| route.actions | 操作 | 线路表列头 | 无 |
| route.bind | 绑定设备 | 线路表行级按钮 | 无 |
| route.saved | 设备绑定已保存 | E0 保存成功 Toast | 无 |

共用文案 `common.routeName` 用于线路表列头。

## 5. 绑定讲解器（E1）

### 抽屉目标

在 E0 某条线路的上下文中查看、编辑设备选择及自动分配设置，并提交当前线路的配置。

### 区域结构

```text
+----------------------------------------------+
| 绑定讲解器                                   |
+----------------------------------------------+
| 线路名称 {线路名称}                           |
+----------------------------------------------+
| 设备                              [选择设备] |
| 启用自动分配                       [Switch]  |
+----------------------------------------------+
|                              [取消] [保存绑定] |
+----------------------------------------------+
```

### 条件结构（设备区有已选设备）

```text
可编辑区 > 设备
├─ 设备                            [选择设备]
└─ List {设备编号} 逐项展示
```

### 条件结构（保存时设备校验未通过）

```text
可编辑区 > 设备
├─ 设备                            [选择设备]
├─ 已选设备列表（有已选时保留）
└─ InlineError 校验提示
```

### 区域说明

- 标题下方显示只读的当前线路。可编辑区依序为设备区和自动分配 Switch。设备区同时承载选择入口、已选设备列表和校验提示。
- 底部动作区提供“取消”和“保存绑定”。

### 信息与字段

- 线路名称为 E0 所触发行的线路名称，只读。
- 设备的已选项显示设备编号，全部已选编号逐项展示。编辑已有绑定时载入该线路当前已绑定设备。可保存数量为一至五台。
- “启用自动分配”为开关。新增绑定时默认关闭，编辑已有绑定时回显已保存设置。

### 关键操作

- 点击“选择设备”打开 E2。E1 继续保留线路、已选设备及开关编辑值。E2 应用选择后，回填当前已选设备编号。再次点击可修改选择。
- 切换“启用自动分配”修改当前抽屉内的设置。
- 点击“保存绑定”校验当前设备并提交。成功后保存设备绑定和自动分配设置，关闭抽屉，结果显示在 E0。
- 点击“取消”直接关闭抽屉并丢弃全部未保存更改。

### 校验与反馈

点击“保存绑定”时按当前选择做以下检查。阻断时按“条件结构（保存时设备校验未通过）”回显提示，保留已选设备和本次编辑内容。用户可点击“选择设备”调整，再次保存。

- 未选择设备时阻断，设备区显示 `binding.min`。
- 选择超过五台时阻断，设备区显示 `binding.max`。
- 已选设备中有设备在保存时已变为停用时阻断，设备区显示 `binding.inactive`，保留已停用设备的已选回显，允许重新选择。全部使用当前可用设备且数量符合时可提交。

### 状态与异常恢复

- 已选回填。E2 应用选择后按“条件结构（设备区有已选设备）”展示全部已选编号，有至少一个已选项时保留设备列表。用户可以重开选择弹窗或继续保存。
- 临时取消选择。E2 取消后恢复 E1 的原有选择和编辑上下文，可继续编辑或保存。

### 文案与变量

| key | 文案 | 适用位置／状态 | 变量及含义、取值 |
| --- | --- | --- | --- |
| binding.title | 绑定讲解器 | 抽屉标题 | 无 |
| binding.devices | 设备 | 设备区标签 | 无 |
| binding.pick | 选择设备 | 设备区按钮 | 无 |
| binding.auto | 启用自动分配 | Switch 标签 | 无 |
| binding.save | 保存绑定 | 抽屉底部提交按钮 | 无 |
| binding.min | 请至少选择一台讲解器 | 保存时未选择设备的设备区提示 | 无 |
| binding.max | 最多可绑定五台讲解器 | 保存时超过五台的设备区提示 | 无 |
| binding.inactive | 部分设备已停用，请重新选择 | 保存时已选设备变为停用的设备区提示 | 无 |

共用文案 `common.routeName` 用于只读字段标签，`common.cancel` 用于抽屉底部按钮。

## 6. 选择讲解器（E2）

### 弹窗目标

在保留 E1 编辑上下文的情况下浏览候选讲解器，应用多选结果后继续绑定配置。

### 区域结构

```text
+----------------------------------------------+
| 选择讲解器                                   |
+----------------------------------------------+
| Table                                        |
| 选择 | 设备编号   | 所在展厅   | 可用状态       |
| [ ]  | {设备编号} | {所在展厅} | 可用          |
+----------------------------------------------+
|                              [取消] [应用选择] |
+----------------------------------------------+
```

### 条件结构（候选行停用）

```text
候选 Table > 停用行
Checkbox 禁用 | {设备编号} | {所在展厅} | 停用
```

### 区域说明

- 弹窗覆盖在仍打开的 E1 上方。标题下方为候选 Table，首列为多选 Checkbox。底部提供取消和应用操作。
- 候选列表仅在本次选择过程中呈现。停用候选留在原列表中并禁用对应 Checkbox。

### 信息与字段

- 候选行展示设备编号、所在展厅和可用状态。可用状态取“可用”或“停用”。仅“可用”的候选可进入本次选择结果。
- 弹窗内选中项为本次临时选择，打开时由 E1 当前所选的可用项初始化。

### 关键操作

- 勾选或取消勾选可用候选行，可选择多台。停用行不能勾选。
- 点击“应用选择”，关闭 E2 并将本次选择结果回填 E1。E1 仍需点击“保存绑定”才会写入。
- 点击“取消”，关闭 E2 并丢弃本次弹窗内的选择变化，E1 仍保留打开前的选择。

### 状态与异常恢复

- 停用候选。候选为停用时按“条件结构（候选行停用）”展示 `picker.inactive` 并禁用选择。因保存时停用而重开 E2 时，以当前可用状态呈现候选，用户改选可用设备后应用，或取消返回原选择。

### 文案与变量

| key | 文案 | 适用位置／状态 | 变量及含义、取值 |
| --- | --- | --- | --- |
| picker.title | 选择讲解器 | 弹窗标题 | 无 |
| picker.select | 选择 | 候选表勾选列头 | 无 |
| picker.id | 设备编号 | 候选表列头 | 无 |
| picker.hall | 所在展厅 | 候选表列头 | 无 |
| picker.status | 可用状态 | 候选表列头 | 无 |
| picker.active | 可用 | 可选择候选的状态单元格 | 无 |
| picker.inactive | 停用 | 禁用候选的状态单元格 | 无 |
| picker.apply | 应用选择 | 弹窗底部应用按钮 | 无 |

共用文案 `common.cancel` 用于弹窗底部按钮。
