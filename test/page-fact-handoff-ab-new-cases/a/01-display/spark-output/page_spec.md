## 4. 温室监测工作台（E0）

### 页面目标

温室管理员从同一工作台查看三个类别的监测信息。温室管理员可访问工作台和全部页签。其他角色不显示“温室监测”菜单入口。

### 页面结构

```text
+-----------------------------------------------+
| 温室监测                                      |
| Tabs [实时读数*] [告警记录] [探头状态]         |
+-----------------------------------------------+
| 当前内容区                                    |
| 实时读数                                      |
| 最近采集时间 {最近采集时间}                    |
| Table 分区 | 温度（℃） | 相对湿度（%）         |
+-----------------------------------------------+
```

### 条件结构（选中告警记录且当日有告警）

```text
Tabs [实时读数] [告警记录*] [探头状态]
当前内容区
└─ Table 发生时刻 | 告警级别 | 恢复时刻
```

### 条件结构（选中告警记录且当日无告警）

```text
Tabs [实时读数] [告警记录*] [探头状态]
当前内容区
└─ EmptyState 今日暂无告警
```

### 条件结构（选中探头状态）

```text
Tabs [实时读数] [告警记录] [探头状态*]
当前内容区
└─ Table 探头编号 | 安装分区 | 联机状态
```

### 条件结构（实时读数读取失败）

```text
Tabs [实时读数*] [告警记录] [探头状态]
当前内容区
├─ 实时读数
└─ 读数加载失败 [重试]
```

### 区域说明

- 标题区显示页面标题。Tabs 固定从左到右为“实时读数”“告警记录”“探头状态”。星号在结构图中表示当前选中项。
- Tabs 下方只有一个当前内容区。实时读数可读时，其局部标题下显示最近采集时间，下方为读数 Table。告警和探头的 Table 各自在所选页签下占用同一内容区。

### 信息与字段

- 实时读数的最近采集时间取当前读数的最近一次采集时刻。Table 的分区为读数所在分区，温度显示摄氏读数，相对湿度显示百分比读数。
- 告警记录的发生时刻、告警级别、恢复时刻分别取当日告警的对应数据。尚未恢复时，恢复时刻单元格显示“—”。
- 探头状态按探头展示探头编号、安装分区和联机状态。联机状态仅取“在线”“离线”。
- 各列表及工作台均为只读，无业务记录写入。

### 关键操作

- 首次点击菜单进入 E0 时选中“实时读数”。点击任一未选页签切换选中项，并在当前内容区替换对应列表或该页签的已定义状态，始终停留 E0。
- 实时读数失败时点击“重试”，重新加载当前实时读数页签。成功后恢复读数结构，仍失败时可再次重试。

### 状态与异常恢复

- 告警为空。加载当日告警且结果为空时，按“条件结构（选中告警记录且当日无告警）”展示 `alert.empty`，可继续切换实时读数或探头状态。
- 读数加载失败。按“条件结构（实时读数读取失败）”在实时读数内容区显示 `reading.failed` 和 `reading.retry`。重试仅重新读取实时读数，页签仍可切换。
