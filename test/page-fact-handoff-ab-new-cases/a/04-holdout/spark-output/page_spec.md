# 页面生成规格：社团排练室预约

## 1. 页面摘要

- **产品领域**：社团排练室 — 时段预约与凭据查看
- **页面类型**：列表页、确认弹窗、凭据抽屉
- **用户角色**：社团成员
- **核心任务**：预约排练室时段，查看自己的预约和预约凭据。

---

## 2. 生成范围

### 生成

- E0「排练室预约」顶级列表页，包含可约和已约时段，以及提交成功后返回的列表反馈。
- E1「我的预约」顶级列表页，包含有记录、无记录及按预约状态显示操作的列表状态。
- E2「确认预约」弹窗，包含提交前的默认状态和提交时段被占的弹窗内阻断状态。
- E3「查看凭据」抽屉，显示当前预约的只读凭据。

### 只引用不生成

- 无。

### 不生成

- 时段占用校验、预约保存和时段刷新属于系统处理，结果由对应页面和弹窗呈现。
- 本期排练室预约页排除取消已提交预约的操作。

---

## 3. 跨实体任务流程

### 提交预约

- 同名菜单 —点击「排练室预约」→ E0 房间列表。
- E0 —点击可约时段的「预约」→ E2（带入该房间及所选时段，E0 保留原列表位置）。
- E2 —点击「取消」→ E0 原房间列表位置（关闭弹窗，本次未提交）。
- E2 —点击「确认预约」且保存成功→ E0 当前房间列表（关闭弹窗，原时段变为已约，展示成功 Toast）。
- E2 —点击「确认预约」且该时段已被其他人预约→ E2 时段被占状态（弹窗保留，本次预约未保存）。
- E2 —点击「返回选择」→ E0 原房间列表（关闭弹窗并刷新时段，可另选可约时段）。

### 查看自己的预约与凭据

- 同名菜单 —点击「我的预约」→ E1（包含成功提交的本人预约，按当前列表数据呈现有记录或空状态）。
- E1 —点击已确认记录的「查看凭据」→ E3（显示所选记录的凭据，E1 保留原列表）。
- E3 —点击「关闭」→ E1 原预约列表。

## 4. 排练室预约（E0）

### 页面目标

社团成员通过「排练室预约」菜单查看房间排期，从可约时段发起预约，并在原列表核对提交后的时段状态。

### 页面结构

```text
+-----------------------------------------------------+
| 标题：排练室预约                                    |
+-----------------------------------------------------+
| 房间列表 [List]                                     |
|   房间名 {房间名}   可容纳人数 {可容纳人数}         |
|   可预约时段                                        |
|     {时段}                        [预约]            |
|     ...                                             |
|   ... 其他房间                                       |
+-----------------------------------------------------+
```

### 条件结构（已约时段）

```text
房间列表 > 对应房间 > 可预约时段 > 对应时段项
+-----------------------------------------------------+
| {时段}                            [Tag 已约]        |
+-----------------------------------------------------+
```

### 区域说明

- 顶部是 Page 标题。主体为房间 List，每个房间项先显示房间信息，再显示该房间下的时段项。
- 时段项的操作位置与该项的时段值相邻。可约时显示 Button「预约」，已约时依「已约时段」条件结构改为 Tag。

### 信息与字段

- 「房间名」显示当前房间名称。
- 「可容纳人数」显示当前房间的容量人数。
- 「可预约时段」按房间显示排期，每个时段项呈现该时段及对应的状态或操作。

### 关键操作

- 点击可约时段的「预约」，在当前列表上打开 E2，向弹窗带入对应房间和时段。
- 提交成功后，当前列表显示 `room.booking_success` Toast，原时段按「已约时段」条件结构更新。

### 状态与异常恢复

- **可约时段**。当前时段可预约时显示「预约」，点击进入 E2。
- **已约时段**。时段已被预约时显示 `room.slot_booked`，隐藏该时段的「预约」。成功提交时原时段进入此状态，成员仍可浏览房间排期，或通过「我的预约」菜单进入 E1 查看自己的预约。
- **从占用阻断返回**。E2 的「返回选择」关闭弹窗后，原房间列表刷新时段，并根据刷新后的可约状态更新入口。成员可从可约时段重新发起。

### 文案与变量

| key | 文案 | 适用位置／状态 | 变量及含义、取值 |
| --- | --- | --- | --- |
| `room.title` | 排练室预约 | 顶级菜单和页面标题 | 无 |
| `room.capacity` | 可容纳人数 | 房间信息标签 | 无 |
| `room.capacity_value` | {可容纳人数} | 房间信息容量值 | `{可容纳人数}` 为该房间的容量人数 |
| `room.slots` | 可预约时段 | 房间内时段区标签 | 无 |
| `room.book` | 预约 | 可约时段项按钮 | 无 |
| `room.slot_booked` | 已约 | 已约时段项 Tag | 无 |
| `room.booking_success` | 预约已提交 | E0 中的预约成功 Toast | 无 |

共用文案 `common.room_name`、`common.room_name_value` 用在房间信息，`common.slot_value` 用在时段项。

## 5. 我的预约（E1）

### 页面目标

社团成员通过「我的预约」菜单查看自己的预约记录，并查看已确认记录的凭据。

### 页面结构

```text
+--------------------------------------------------------------------------+
| 标题：我的预约                                                           |
+--------------------------------------------------------------------------+
| 预约列表 [Table]                                                         |
| 预约编号       | 房间名   | 时段   | 预约状态     | 操作                 |
| {预约编号}     | {房间名} | {时段} | [Tag 已确认] | [查看凭据]           |
| ...                                                                      |
+--------------------------------------------------------------------------+
```

### 条件结构（记录状态非已确认）

```text
预约列表 > 对应记录行
+--------------------------------------------------------------------------+
| {预约编号}     | {房间名} | {时段} | [Tag {预约状态}] |                   |
+--------------------------------------------------------------------------+
```

### 条件结构（没有自己的预约）

```text
预约列表 > 表体
+--------------------------------------------------------------------------+
| [EmptyState record.empty]                                                |
+--------------------------------------------------------------------------+
```

### 区域说明

- 顶部是 Page 标题。主体为预约 Table，行内容限当前成员自己的预约。
- 「预约状态」用 Tag 显示。「操作」列承载该行的 Button「查看凭据」，按记录状态决定是否显示。

### 信息与字段

- 「预约编号」显示本条预约的编号。
- 「房间名」显示预约对应的房间。
- 「时段」显示本条预约的时段。
- 「预约状态」显示本条记录的当前业务状态。预约成功产生的记录初始状态为「已确认」。
- 「操作」列仅在该行状态为「已确认」时显示「查看凭据」。

### 关键操作

- 点击已确认记录行的「查看凭据」，带入当前记录，在原列表上打开 E3。

### 状态与异常恢复

- **已确认**。预约成功保存后，成员可在自己的记录中看到 `record.confirmed`，并通过本行操作打开凭据。
- **记录状态非已确认**。当该行当前状态不是「已确认」时，按同名条件结构保留记录信息并隐藏该行的「查看凭据」。
- **没有自己的预约**。当前成员没有自己的预约时，按同名条件结构在列表表体呈现 `record.empty`，没有记录行或凭据操作。

### 文案与变量

| key | 文案 | 适用位置／状态 | 变量及含义、取值 |
| --- | --- | --- | --- |
| `record.title` | 我的预约 | 顶级菜单和页面标题 | 无 |
| `record.state` | 预约状态 | 列头 | 无 |
| `record.actions` | 操作 | 列头 | 无 |
| `record.confirmed` | 已确认 | 已确认记录的状态 Tag | 无 |
| `record.state_value` | {预约状态} | 非已确认记录的状态 Tag | `{预约状态}` 为该记录的实际状态名称 |
| `record.empty` | 你还没有预约记录 | 本人无预约时的列表内空状态 | 无 |

共用文案 `common.booking_id`、`common.room_name`、`common.slot` 用作列头，`common.booking_id_value`、`common.room_name_value`、`common.slot_value` 用作行内值，`common.view_receipt` 用作已确认行的操作名称。

## 6. 确认预约（E2）

### 弹窗目标

社团成员核对在 E0 选定的房间和时段，可填写排练备注并确认提交。

### 区域结构

```text
+-----------------------------------------------------+
| 标题：确认预约                                      |
+-----------------------------------------------------+
| 时段摘要 [只读]                                     |
|   房间名 {房间名}    日期 {日期}                     |
|   开始时间 {开始时间}    结束时间 {结束时间}         |
| 排练备注 [Textarea]                                 |
+-----------------------------------------------------+
|                             [取消] [确认预约]       |
+-----------------------------------------------------+
```

### 条件结构（时段被占）

```text
弹窗内容区 > 时段摘要下方
+-----------------------------------------------------+
| [InlineError confirm.slot_taken]                    |
| [返回选择]                                          |
+-----------------------------------------------------+
弹窗底部操作区
+-----------------------------------------------------+
|                         [取消] [确认预约 · 禁用]    |
+-----------------------------------------------------+
```

### 区域说明

- Modal 覆盖在 E0 上。标题下先放只读时段摘要，再放「排练备注」Textarea。
- 底部操作区包含「取消」「确认预约」两个 Button。时段被占时，摘要与备注之间增加 InlineError 和 Button「返回选择」，原摘要及备注仍在同一弹窗中。

### 信息与字段

- 「房间名」「日期」「开始时间」「结束时间」取自 E0 所选时段及其房间，均为只读。
- 「开始时间」「结束时间」以 24 小时制 `HH:mm` 展示。
- 「排练备注」为可输入的选填文本，留空也可提交。

### 关键操作

- 输入「排练备注」可补充本次排练说明。
- 点击「确认预约」提交所选房间、时段及已填写的备注。保存成功关闭弹窗，由 E0 提示成功。时段被占时按「校验与反馈」处理。
- 点击「取消」关闭弹窗，保留 E0 当前房间列表位置。
- 时段被占后，点击「返回选择」关闭弹窗，返回原房间列表并刷新时段。

### 校验与反馈

- **提交时段占用校验**。点击「确认预约」时，系统检查选中的时段是否已被他人预约。若已被占，则阻断保存、保留弹窗，并在时段摘要下以 `confirm.slot_taken` 说明原因，提供「返回选择」以刷新候选时段。预约保存成功后，关闭弹窗并由 E0 接收结果。

### 状态与异常恢复

- **待确认**。打开后显示本次选择的时段摘要和可编辑的备注，可提交或取消。
- **时段被占**。提交时发现所选时段已被他人预约，本次预约未保存。按「时段被占」条件结构保留当前弹窗及原选摘要，提示阻断并禁用「确认预约」。点击「返回选择」后在刷新过的房间列表另选时段。

### 文案与变量

| key | 文案 | 适用位置／状态 | 变量及含义、取值 |
| --- | --- | --- | --- |
| `confirm.title_action` | 确认预约 | 弹窗标题、提交按钮 | 无 |
| `confirm.date` | 日期 | 只读时段摘要标签 | 无 |
| `confirm.date_value` | {日期} | 只读时段摘要日期值 | `{日期}` 为所选时段日期 |
| `confirm.start` | 开始时间 | 只读时段摘要标签 | 无 |
| `confirm.start_value` | {开始时间} | 只读时段摘要开始时间值 | `{开始时间}` 为所选时段的起始时间，以 24 小时制 `HH:mm` 展示 |
| `confirm.end` | 结束时间 | 只读时段摘要标签 | 无 |
| `confirm.end_value` | {结束时间} | 只读时段摘要结束时间值 | `{结束时间}` 为所选时段的结束时间，以 24 小时制 `HH:mm` 展示 |
| `confirm.note` | 排练备注 | 选填文本字段标签 | 无 |
| `confirm.cancel` | 取消 | 弹窗底部取消按钮 | 无 |
| `confirm.slot_taken` | 当前时段已被预约，请改选其他时段 | 提交受阻时的时段摘要下方 | 无 |
| `confirm.reselect` | 返回选择 | 提交受阻时的时段摘要下方按钮 | 无 |

共用文案 `common.room_name`、`common.room_name_value` 用在只读时段摘要。

## 7. 查看凭据（E3）

### 抽屉目标

社团成员查看自己在 E1 选中的已确认预约凭据，关闭后回原列表。

### 区域结构

```text
+---------------------------------------+
| 标题：查看凭据                 [关闭] |
+---------------------------------------+
| 预约编号 {预约编号}                   |
| 房间名   {房间名}                     |
| 时段     {时段}                       |
+---------------------------------------+
```

### 区域说明

- Drawer 叠加在 E1 上。标题区包含「查看凭据」和 Button「关闭」，内容区纵向排列三项只读凭据信息。

### 信息与字段

- 「预约编号」「房间名」「时段」均取自触发本抽屉的预约记录。

### 关键操作

- 点击「关闭」收起抽屉并回到原预约列表。

### 文案与变量

| key | 文案 | 适用位置／状态 | 变量及含义、取值 |
| --- | --- | --- | --- |
| `receipt.close` | 关闭 | 抽屉标题区关闭按钮 | 无 |

共用文案 `common.view_receipt` 用作抽屉标题，`common.booking_id`、`common.room_name`、`common.slot` 用作凭据字段标签，`common.booking_id_value`、`common.room_name_value`、`common.slot_value` 用作凭据字段值。
