# 审批列表新增状态筛选

## 需求背景

审批管理列表中待处理、处理中、已完成、已失效的申请混在一起，管理员查找效率低。

## 改动目标

新增审批状态筛选，支持按待处理、处理中、已完成、已失效筛选。

## 影响对象

影响审批列表筛选条件、状态说明和空状态文案。

## 用户操作路径

用户进入审批列表，选择状态筛选项，列表刷新对应状态的数据。

## 权限 / 审批 / 状态 / 数据范围

涉及审批状态含义和可见范围，但不改变审批流本身。

## 异常与边界

需要定义每个状态的业务含义，以及筛选后无结果时的说明。

## 期望判断

期望为 standard，重点关注状态含义和信息表达。
