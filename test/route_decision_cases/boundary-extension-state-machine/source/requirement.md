# 看起来是功能扩展但实际影响状态机

## 需求背景

费用审批希望增加“暂缓处理”按钮，让审批人可以先不通过也不驳回。

## 改动目标

在审批详情页新增暂缓处理能力，暂缓后申请单保持在当前审批人处，后续可继续审批。

## 影响对象

影响审批详情页、审批状态、审批时效、通知和待办列表。

## 用户操作路径

审批人打开申请单，点击暂缓处理，填写原因。系统记录暂缓状态，并在待办中保留该申请。

## 权限 / 审批 / 状态 / 数据范围

涉及审批状态机变化、审批时效、待办状态和通知规则。

## 异常与边界

需要定义暂缓次数、超时规则、申请人是否可见、管理员是否可催办。

## 期望判断

应从 standard 升级 full，重点关注状态机和审批治理。
