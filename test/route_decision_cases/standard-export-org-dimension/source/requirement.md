# 导出增加组织维度选择

## 需求背景

员工列表导出目前只能按当前筛选结果导出，HR 希望导出时可以选择组织维度，减少重复筛选。

## 改动目标

在导出弹窗中增加组织维度选择，支持按当前组织、含下级组织、全部可见组织导出。

## 影响对象

影响员工列表导出范围、导出弹窗和结果反馈。

## 用户操作路径

用户进入员工列表，点击导出，选择组织维度，确认后生成导出任务。

## 权限 / 审批 / 状态 / 数据范围

涉及数据范围和用户可见组织范围，不能导出超出当前权限的数据。

## 异常与边界

需要处理无权限组织、导出任务失败和大数据量导出延迟。

## 期望判断

期望为 standard，重点关注数据范围、权限边界和结果反馈。
