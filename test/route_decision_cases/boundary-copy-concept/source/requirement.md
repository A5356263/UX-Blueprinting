# 看起来是文案问题但实际是概念边界问题

## 需求背景

成员管理页中“外部人员”和“临时员工”的说明经常被用户混淆，业务希望改几句文案解决。

## 改动目标

优化两个概念的页面说明，让管理员知道应该把哪类人员加入外部人员，哪类人员加入临时员工。

## 影响对象

影响成员类型理解、邀请入口选择、权限范围和后续合同/考勤流程。

## 用户操作路径

管理员在添加人员时阅读概念说明，选择外部人员或临时员工入口。

## 权限 / 审批 / 状态 / 数据范围

两个概念背后对应不同权限范围和人事流程，不只是文案差异。

## 异常与边界

如果概念定义不清，单纯改文案可能掩盖业务边界问题。

## 期望判断

不能简单判 fast；应输出信息结构与概念澄清压力，可能为 standard。
