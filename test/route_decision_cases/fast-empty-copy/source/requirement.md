# 表格空状态文案优化

## 需求背景

权限查询页面在没有筛选结果时只显示“暂无数据”，用户不知道是没有权限记录，还是筛选条件过窄。

## 改动目标

优化空状态文案，提示用户可以清空筛选条件或检查权限名称关键字。

## 影响对象

只影响列表空状态文案和一个清空筛选按钮，不改变查询能力。

## 用户操作路径

用户进入权限查询页面，输入筛选条件后没有匹配结果，页面展示新的空状态说明。

## 权限 / 审批 / 状态 / 数据范围

不改变用户可查询的数据范围，不新增权限规则。

## 异常与边界

如果接口异常，仍沿用现有错误反馈，不在本需求内处理。

## 期望判断

期望为 fast，重点关注文案理解。
