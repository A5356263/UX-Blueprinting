# 看起来是小改动但涉及数据范围

## 需求背景

权限查询页希望把“仅看我的权限”改成默认勾选“查看我管理范围内所有成员权限”。

## 改动目标

调整默认筛选值，让管理员进入页面时直接看到管理范围内所有成员的权限。

## 影响对象

影响权限查询默认结果、数据范围和页面说明。

## 用户操作路径

管理员进入权限查询页，系统默认展示管理范围内的成员权限。

## 权限 / 审批 / 状态 / 数据范围

涉及数据范围扩大和默认暴露范围，需要判断当前角色是否允许查看这些数据。

## 异常与边界

如果用户没有管理范围，应回退到仅看本人还是展示空状态，需要明确。

## 期望判断

不能简单判 fast；至少应 standard，并输出升级风险。
