# 组织树支持拖动宽度

## 需求背景

组织架构页面左侧组织树在层级较深时，部门名称经常被截断，用户需要反复悬停查看完整名称。

## 改动目标

支持用户拖动组织树区域宽度，并记忆本次浏览器内的默认宽度。页面刷新后可以恢复到默认宽度，不要求跨设备同步。

## 影响对象

只影响组织架构页面左侧树区域展示，不新增组织、成员、角色或权限能力。

## 用户操作路径

用户进入组织架构页面后，拖动左侧组织树和右侧列表之间的分隔线，调整展示宽度。

## 权限 / 审批 / 状态 / 数据范围

不涉及权限、审批、数据范围和状态机变化。

## 异常与边界

需要定义最小宽度、最大宽度、长部门名称展示和窗口缩小时的响应方式。

## 期望判断

期望为 fast，重点关注布局交互。
