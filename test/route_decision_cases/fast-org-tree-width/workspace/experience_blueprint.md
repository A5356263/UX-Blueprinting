# 体验蓝图

## 0. 本次关键设计判断

- 路线说明：fast 路线，本次只承接组织树宽度调整，不改变权限、数据范围、审批、状态机或业务对象关系。

## 1. 交互流程总览

- 用户进入组织架构页面。
- 用户拖动左侧组织树与右侧列表之间的分隔线。
- 系统实时调整组织树宽度，并保持右侧列表可读。
- 页面刷新后恢复本浏览器内默认宽度。

## 2. 主交互流程

- 鼠标悬停到分隔线，光标变为可拖动状态。
- 按下并拖动分隔线。
- 达到最小宽度或最大宽度时停止继续缩放。
- 松开后保存本浏览器内的宽度偏好。

## 3. 次交互流程

- 窗口缩小时，优先保持右侧列表可操作，再压缩组织树到最小宽度。
- 长部门名称在宽度不足时保留截断和悬停查看。

## 4. 异常与阻断流程

- 本地宽度记忆失败时，不阻断页面使用。
- 权限不足、组织加载失败、数据异常不在本次范围。

## 5. 页面 / 弹窗 / 抽屉设计

- 页面：组织架构页面。
- 区域：左侧组织树与右侧列表之间的分隔线。
- 操作：拖动调整宽度。
- 状态反馈：拖动时实时变化，达到边界后不再继续变化。
- 异常处理：本地记忆失败时下次恢复系统默认宽度。

## 6. 状态与反馈文案

- 状态：可拖动。
- 状态：达到最小宽度。
- 状态：达到最大宽度。
- 文案：已恢复默认宽度。

## 7. 待确认问题

- 无阻断问题。
