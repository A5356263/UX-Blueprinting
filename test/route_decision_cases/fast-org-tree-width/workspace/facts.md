# Facts

## 任务概述

- 输入来源：source/requirement.md 与 source/background.md。
- 组织架构页面左侧组织树在层级较深时，部门名称容易被截断。
- 用户希望拖动组织树区域宽度，并在本浏览器内记忆默认宽度。

## 功能范围

- 支持组织树区域宽度调整。
- 支持页面刷新后恢复本浏览器内默认宽度。
- 不要求跨设备同步。

## 关键业务规则

- 不新增组织、成员、角色或权限能力。
- 不改变组织数据、成员数据或权限规则。

## 状态流转

- 不新增业务状态。
- 仅涉及界面展示宽度的本地记忆。

## 异常与边界

- 需要定义最小宽度、最大宽度、长名称展示和窗口缩小时的响应方式。

## 依赖与前置条件

- 依赖现有组织架构页面和左侧组织树。

## 开放问题与缺口

- 无阻断问题。
