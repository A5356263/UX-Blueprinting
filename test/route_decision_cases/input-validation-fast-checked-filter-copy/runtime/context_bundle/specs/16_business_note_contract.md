# Business Note Contract

`business_note.md` 是 fast 路线的轻量业务依据产物，用于证明体验输出没有跳过业务判断。

## 1. 适用边界

- 仅用于 route 为 `fast` 的局部、低风险体验改动。
- 不替代 `business_blueprint.md`。
- 不承载完整价值分析、能力形态比较或复杂业务方案推导。

## 2. 必需章节

```text
## 0. 路线说明
## 1. 业务依据
## 2. 核心业务规则影响
## 3. 体验可承接内容
## 4. 升级信号
## 5. 待确认问题
```

## 3. 合格标准

- 必须说明本次业务依据来自哪些事实、输入或已知规则。
- 必须明确判断是否影响权限、数据范围、审批、状态机、业务对象关系。
- 必须说明 experience 可以直接承接的局部目标。
- 如果存在核心规则影响或规则不确定，必须给出升级到 `standard` 或 `full` 的信号。
- 不得把 route 判断当作业务结论；route 只能作为执行路线建议。

## 4. 禁止事项

- 不得空泛写“无影响”而不列明检查维度。
- 不得编造输入中不存在的业务规则。
- 不得输出页面布局、交互细节或前端实现方案。
- 不得把语义判断规则固化为代码分类结论。
