# 禁用按钮补 tooltip

## 需求背景

审批列表中部分“撤回”按钮处于禁用状态，但用户不知道为什么不能点击。

## 改动目标

在禁用按钮上补充 tooltip，说明当前审批已进入终审节点，不能再撤回。

## 影响对象

只补充按钮禁用原因说明，不改变撤回规则和审批流转。

## 用户操作路径

用户进入审批列表，鼠标悬停在禁用的撤回按钮上，看到不可操作原因。

## 权限 / 审批 / 状态 / 数据范围

涉及已有审批状态的解释，但不改变审批状态机和撤回规则。

## 异常与边界

需要确保 tooltip 文案来自已有规则，不新增业务判断。

## 期望判断

期望为 fast 或 standard 边界判断；如判 fast，必须说明规则不变。
