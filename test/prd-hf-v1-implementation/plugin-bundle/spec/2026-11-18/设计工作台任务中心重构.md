# 设计工作台 · 任务中心重构 Spec

- 日期：2026-11-18
- 状态：待确认（确认后执行）
- 范围：个人使用，不做多人协作
- 关系：替代当前“会话中心”工作台；任务成为内容与产物的归属单位

## 1. 目标

把工作台从“会话中心”改为“任务中心”：

- 任务页：以 Skill 卡片为入口，选技能、填输入、执行；
- 沉淀页：按任务查看历史产物，继续任务；
- 右栏：当前任务的动态、对话和下一步；
- 底部输入：保留现有完整能力，只做视觉弱化和位置调整。

任务 ID 对用户可见，但不要求用户填表创建。

## 2. 非目标

- 不做多人协作、共享权限、组织记忆；
- 不做卡片自由拖拽重排、拖拽导出；
- 不做示例数据和一键清空；
- 不删除现有输入框功能；
- 不改变 Skill 的 Markdown 产物契约。

## 3. 已确认决策

1. 左上角两个选项：**任务 / 沉淀**。
2. 任务页展示全部 Skill，直接分三组：探索与定义、设计与交付、分析与证据；放不下自动折行。
3. 卡片：顶部抽象渐变/几何插画，中间是 Skill 简述，左下是 Skill 名；卡片大小一致、轻微倾斜、上下错落。
4. 整页可平移，但有边界；卡片聚焦时轻微抖动；不支持卡片拖拽排序或导出。
5. 点击卡片或卡片右下角「使用 Skill」，只把技能回填到底部输入框；**只有点「执行任务」才正式创建/执行任务**。
6. 底部输入框固定在任务画布底部，采用竞品的底部输入条形态；功能不减，只做 UI 弱化。
7. 右侧一列：任务头 → 任务动态/对话 → 下一步；宽度 320–360px；上下叠。
8. 任务复用当前会话；任务记录保存 `sessionId + segments`（每段 start/end 事件序号），用事件区间隔离任务；暂停/恢复/完成会开闭区间。
9. 产物按任务存放：`spark-output/design-workbench/<taskId>/<skill>.md`。
10. 旧数据迁移：每个旧会话文件夹迁移成一个历史任务，进入沉淀。
11. 沉淀默认展示全部任务（含进行中），按时间倒序。
12. 没有示例数据；沉淀没有任务时显示空状态。
13. UI 完全采用竞品实现方式：DSH 主题 token + glass + elevation；浅色呈现暖白，深色自适应。
14. 任务状态：`active / paused / completed`；同一时间只有一个 `active` 任务。
15. 新建任务时，当前任务转 `paused`；结束任务转 `completed`；从沉淀继续任务时恢复为 `active`。
16. 活动任务 ID 持久化到本地，刷新后恢复。
17. `submit_design_artifact` 只接受 `active` 任务；`paused / completed` 拒绝写入。
18. 任务支持重命名：任务头可直接编辑标题，Host 提供 rename 接口。

## 5. 任务模型

```json
{
  "id": "T-20261118-01",
  "title": "权限需求分析",
  "status": "active",
  "sessionId": "session-...",
  "segments": [
    { "startSeq": 123, "endSeq": null }
  ],
  "createdAt": "...",
  "updatedAt": "...",
  "skills": ["prd-review", "page-spec"],
  "artifacts": {}
}
```

规则：

- 任务 ID：`T-YYYYMMDD-NN`，按工作区递增；
- 标题：首条用户输入前 40 字；没有输入时用 Skill 名；任务头可重命名；
- 状态：`active` / `paused` / `completed`；
- 同一时间只有一个 `active` 任务；
- 任务复用当前会话；创建时追加事件段 `{startSeq: 当前seq, endSeq: null}`；
- 暂停/完成时关闭最后一段 `endSeq = 当前seq`；
- 恢复时追加新段；动态/对话取所有事件段的并集；
- 旧任务没有 `segments` 时，按 `{startSeq: 0, endSeq: 当前seq}` 兼容；
- 任务进行中切换会话时，提示先结束当前任务或新建任务，不静默串会话；
- 「新建任务」把当前任务转为 `paused`，清空当前任务选择；下一次执行时创建新任务；
- 「结束任务」把当前任务转为 `completed`，下一次执行自动开新任务；
- 从沉淀恢复任务时，若已有其他 `active` 任务，先把它转 `paused` 并关闭其事件段，再恢复目标任务；
- 沉淀页打开任务：若任务为 `paused`，恢复为 `active`；若为 `completed`，仍可查看产物，但继续执行前需显式恢复；
- 任务头支持重命名，`id` 不变；

## 6. 任务创建与执行流程

1. 用户点卡片/「使用 Skill」→ 只回填 Skill 到输入框；
2. 用户填文字、附件、会话；
3. 点「执行任务」：
   - 没有当前任务 → 创建任务，绑定当前会话，打开事件段；
   - 已有当前任务 → 使用当前任务；
4. Host 返回 `taskId + prompt`；
5. 客户端把 prompt 发送到任务绑定的会话；
6. 模型调用 `submit_design_artifact(taskId, skill, markdown)`；
7. Host 写入任务目录、更新任务 manifest；
8. 右栏动态、对话、下一步刷新；沉淀页出现该任务。

补充规则：

- 没有会话时，先创建会话，再创建任务；
- 当前任务为 `paused` 时，执行前先恢复为 `active`；
- 当前任务为 `completed` 时，从沉淀点「恢复任务」后才能继续；
- 任务进行中切换会话：阻止切换并提示「先结束/暂停当前任务」，或由用户显式新建任务；不得静默改变任务绑定会话。


## 7. 存储与迁移

### 新结构

```
spark-output/design-workbench/
  tasks.json                     # 任务索引
  T-20261118-01/
    manifest.json
    prd-review.md
    page-spec.md
```

- `tasks.json`：任务摘要数组，支持快速列表；
- 每个任务目录内按 Skill 覆盖 `<skill>.md`，不做版本堆积；
- `manifest.json` 记录当前 Skill 产物、哈希、依赖、stale、origin。

### 7.1 任务索引 `tasks.json`

```json
{
  "version": 1,
  "next": 3,
  "tasks": [
    {
      "id": "T-20261118-01",
      "title": "权限需求分析",
      "status": "active",
      "sessionId": "session-...",
      "segments": [
        { "startSeq": 123, "endSeq": null }
      ],
      "createdAt": "...",
      "updatedAt": "...",
      "skills": ["prd-review", "page-spec"],
      "lastSkill": "page-spec"
    }
  ]
}
```

- `next` 用于生成当天下一个任务序号；
- 索引写入与任务/manifest 更新同一把任务锁；
- 索引缺失时从任务目录扫描重建；
- 任务状态变更、重命名、产物登记都更新 `updatedAt`。

### 7.2 Host API

| 方法/动作 | 用途 |
|---|---|
| `GET ?workspace` | 工作区、会话列表、任务索引 |
| `GET ?workspace&task=` | 任务详情 + 任务 manifest |
| `GET ?workspace&task=&skill=` | 读取任务产物 |
| `POST {action:'create-task'}` | 创建任务、绑定会话、打开事件段、返回 taskId + prompt |
| `POST {action:'pause-task'}` | 当前任务转 `paused` |
| `POST {action:'complete-task'}` | 当前任务转 `completed` |
| `POST {action:'resume-task'}` | `paused/completed` 任务恢复 `active` |
| `POST {action:'rename-task'}` | 修改任务标题 |
| `POST {action:'create-session'}` | 无会话时创建新会话 |

创建任务请求包含：`workspaceId`、`sessionId`、`skill`、`title`。Host 在校验会话后打开首个事件段，再返回任务及本轮 prompt；暂停/完成时关闭段，恢复时追加新段。



### 旧数据迁移

- 迁移在首次读取工作区任务索引时执行，按工作区只执行一次；
- 每个旧会话文件夹 `spark-output/design-workbench/<sessionId>/` 迁移为一个历史任务；
- 任务 ID：`T-legacy-<短ID>`；
- 复制旧 manifest 和产物到新任务目录；没有 manifest 时，从 `runs.json` 取每个 Skill 最新一份；
- 状态设为 `completed`；
- `sessionId` 使用旧文件夹名；事件段按 `{startSeq: 0, endSeq: 当前seq}` 兼容；
- 迁移幂等，重复执行不重复创建；
- 迁移失败保留旧目录，不删除源文件。

## 8. 工具契约

```text
submit_design_artifact({
  taskId,
  skill,
  markdown,
  title?
})
```

Host 校验：

- 任务存在且属于当前工作区；
- 任务状态必须是 `active`；`paused / completed` 拒绝写入并返回原因；
- 调用会话 === 任务 `sessionId`；
- Skill 合法；
- Markdown 通过校验；
- 写入 `<taskId>/<skill>.md`，更新任务 manifest；
- 计算 stale，返回 path / sha256 / stale / next。

## 9. 任务页

- 三组卡片，横向排列，自动折行；
- 卡片固定尺寸（约 240×300），顶部插画、标题、简述、左下 Skill 名；
- 插画按 Skill ID 生成确定性渐变/几何图案，不引入外链图片；
- 卡片轻微倾斜（约 -2° 到 2°），组内上下错落；
- 卡片 hover/focus 显示右下角「使用 Skill」；
- 点击卡片或按钮只回填输入框，不创建任务；
- 画布可平移，边界=内容包围盒+一屏留白，不能无限拖；
- 聚焦时 1–2px 短抖动，尊重 `prefers-reduced-motion`。

## 10. 沉淀页

每张任务卡：

```
权限需求分析
T-20261118-01 · 进行中 / 已完成
PRD 审查 → 页面规格
当前产物：页面规格
[查看产物] [进入会话] [继续任务]
```

- `paused` / `completed` 任务显示「恢复任务」；恢复后变为 `active`；
- 点击任务 = 设为当前任务，加载会话、manifest、动态、对话、下一步；
- 若任务会话已不存在，产物可查看，但「进入会话」「动态/对话」显示不可用。
- 默认全部任务，按更新时间倒序；
- 筛选：状态、Skill、关键词；
- 空状态：无任务时显示引导，不放示例数据。


## 11. 右栏

从上到下：

1. 任务头：ID、标题、状态；「重命名」「新建任务」「结束任务」；`paused`/`completed` 任务显示「恢复任务」；
2. 「动态 / 对话」子 Tab：
   - 动态：节点流（接收任务、加载技能、阅读材料、查知识、当前阶段输出）；
   - 对话：只显示当前任务所有事件段内的真实用户/助手消息；过滤 `runtime-context`、`skill-catalog`、`time-context`、`user-approval`、`compact-checkpoint` 等合成消息；
3. 下一步：主建议 + 备选 + 理由；
4. 宽度 320–360px；动态约 60%，下一步约 40%；各自内部滚动。

## 12. 底部输入

- 固定在左侧任务画布底部；
- 保留：附件、技能标签、会话选择、进入会话、执行任务、停止；
- 视觉更小、更轻；不减少功能；
- 技能回填后显示 `Skill: 名称`，可移除；
- 执行任务才创建/启动任务。

## 13. 视觉与动效

完全采用竞品的实现方式，不写死浅色：

- 页面：`--dsw-alias-bg-base`；
- 卡片：`--dsw-alias-bg-layer-2`；
- 边框：`--dsw-alias-border-l2`；
- 文字：`--dsw-alias-label-primary / secondary`；
- 圆角：`--dsw-radius-lg`（16px）、`--dsw-radius-xl`（20px）；
- 阴影：`--dsw-elevation-soft`；
- 顶栏/浮层：`color-mix` 半透明卡片 + `backdrop-filter: blur(...) saturate(...)`；
- 浅色主题自然呈现暖白；深色主题自动适配；
- 卡片 hover 轻微上浮，选中/聚焦用细描边 + 轻投影；
- 卡片插画：CSS/SVG 渐变或几何图形，按 Skill 稳定生成；
- 动效：focus 抖动、右栏展开/折叠；
- 全部动效尊重 `prefers-reduced-motion`。

## 14. 响应式

- ≥1100px：左画布 + 右栏 320–360px；
- 760–1100px：右栏变窄或抽屉；
- <760px：单列，右栏变 Tab/抽屉，输入条全宽；
- 画布平移在触屏可用，卡片不响应拖拽排序。

## 15. 数据流

- Host 持有任务索引、manifest、产物；
- 客户端只做展示和操作；
- 任务创建、结束、暂停、恢复、重命名、产物登记由 Host 处理；
- 本地持久化 `workspace / sessionId / activeTaskId`；恢复时以任务记录的 `segments` 为准；
- 右栏刷新优先由会话事件触发；保留一次兜底刷新；
- 任务复用会话时，动态/对话取 `segments` 并集，不按单一 anchor 过滤。

## 19. 风险

- 任务复用会话时，`segments` 开闭必须准确；暂停后开新任务、再恢复旧任务时不能串消息；
- 旧数据迁移需要幂等，不能删源文件；
- 画布平移与卡片点击/hover 需要区分拖拽阈值；
- 三组卡片在窄窗口的折行与倾斜可能拥挤；
- 任务 ID 可见但不喧宾夺主，避免增加用户负担。
