# 页面生成规格：农产市集批次追踪

## 1. 页面摘要

- **产品领域**：市集管理 · 进货批次追踪
- **页面类型**：顶级只读列表工作台
- **用户角色**：市集质检员
- **核心任务**：查看当前批次，按类别核对批次流向。

## 2. 生成范围

### 生成

- E1 · 批次追踪工作台，包含三个 Tab 的列表视图及适用的空态、失败和恢复状态。

### 只引用不生成

无。

### 不生成

- 批次新增、验收人修改、退回处置、导出、任务转交和新增审批，均在本期工作台范围之外。
- 批次数据读取属于后台处理，用户可见结果显示在 E1 的当前 Tab。

## 3. 跨实体任务流程

### 核对进货批次流向

- 市集管理导航 —质检员点击「批次追踪」顶级入口→ E1「在途批次」初始视图（查看或切换批次，核对结束后留在 E1）。
- 市集管理导航 —用户无质检员权限→ 留在原位置（工作台入口隐藏，未打开 E1）。

## 4. E1 · 批次追踪工作台

### 页面目标

质检员从「市集管理」顶级入口进入，查看任意一类当前批次。查看过程留在同一工作台。

### 页面结构

主结构：

```text
批次追踪 Page
├─ 标题：批次追踪
├─ Tabs：在途批次（初始） | 已到场 | 退回批次
└─ 当前 Tab 内容区
   └─ Table：批次号 | 来源农场 | 预计到场时间
```

切换到「已到场」且读取成功时，替换内容区：

```text
当前 Tab 内容区
└─ Table：批次号 | 验收人 | 到场时间
```

切换到「退回批次」且读取成功时，替换内容区：

```text
当前 Tab 内容区
└─ Table：批次号 | 退回原因
```

「在途批次」读取成功且没有批次时，替换该 Tab 内容区：

```text
在途批次内容区
└─ EmptyState：暂无在途批次
```

当前 Tab 读取失败时，替换该 Tab 内容区：

```text
当前 Tab 内容区
└─ InlineError：批次读取失败
   └─ Button：重试
```

### 区域说明

- 标题与 Tab 条在三个视图中保持可见。Tab 从左到右排列为「在途批次」「已到场」「退回批次」。
- 首次打开工作台选中第一个 Tab「在途批次」，让首屏与既定排列的起点一致。
- 内容区只承载当前 Tab 的列表或适用的就地反馈。

### 信息与字段

- 在途批次的 Table 列依次为「批次号」「来源农场」「预计到场时间」。「预计到场时间」使用 24 小时制。
- 已到场的 Table 列依次为「批次号」「验收人」「到场时间」。
- 退回批次的 Table 列依次为「批次号」「退回原因」。

### 关键操作

- 点击任一 Tab，选中该 Tab 并在内容区呈现对应的批次列或该 Tab 的就地反馈。标题和 Tab 条留在原位。
- 在当前 Tab 读取失败后点击「重试」，系统仅重新加载这个 Tab。重试期间保留当前选中项。
- 质检员只能读取和查看批次。工作台没有新增、编辑、处置、导出或其他写入动作。

### 状态与异常恢复

- **访问受限**。质检员可看到导航入口并打开工作台。其他角色看不到该入口，尝试直接访问时不打开工作台，也不展示批次内容。
- **读取中**。当前 Tab 内容区使用 LoadingState，标题与 Tab 条保持可用。
- **读取成功**。按当前 Tab 展示对应表格。核对完成后保持当前工作台与选中的 Tab。
- **在途批次为空**。只在「在途批次」成功读取且没有批次时显示 `in_transit_empty`。质检员可继续点击「已到场」或「退回批次」。
- **Tab 读取失败**。任一 Tab 加载失败时在所属内容区显示 `tab_read_error` 和 `tab_retry`，工作台与当前选中项保持。点击重试仅重新读取失败的 Tab。成功时回到该 Tab 对应列表或适用的在途空态，再次失败时回到该 Tab 的失败状态。
