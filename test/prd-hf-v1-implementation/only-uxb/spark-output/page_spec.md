# 页面生成规格：农产市集批次追踪

## 1. 页面摘要

- **产品领域**：市集管理 · 进货批次追踪
- **页面类型**：带 Tab 的只读列表工作台
- **用户角色**：市集质检员
- **核心任务**：切换批次分类并查看进货批次。

## 2. 生成范围

### 生成

- E0 · 批次追踪工作台，含「市集管理」下的顶级入口接入与工作台状态。

### 只引用不生成

无。

### 不生成

- 新增批次、修改验收人、处置退回及导出界面，均在本期范围外。
- 批次数据的后台读取，无独立界面。

## 3. 跨实体任务流程

### 查看进货批次

- 「市集管理」导航 —点击顶级入口「批次追踪」／具备质检员权限→ E0（读取首屏数据后停留工作台）。

## 4. E0 · 批次追踪工作台

### 页面目标

市集质检员在同一个工作台查看三类进货批次，完成日常流向核对。

### 页面结构

首次打开默认选中「在途批次」。

```text
Page 批次追踪
├─ 页面标题区
│  └─ 批次追踪
├─ Tabs
│  ├─ 在途批次（默认选中）
│  ├─ 已到场
│  └─ 退回批次
└─ 选中 Tab 的内容区
   └─ Table（列见「信息与字段」）
```

条件结构只替换选中 Tab 的内容区。

- 「在途批次」读取成功且没有批次。

```text
选中 Tab 的内容区
└─ EmptyState [in-transit-empty]
```

- 任一 Tab 读取失败。

```text
选中 Tab 的内容区
└─ InlineError [batches-read-error]
   └─ Button 重试
```

### 区域说明

- 标题区标识当前工作台。Tab 栏提供三个常驻平级视图，并标明当前选中项。
- 内容区承载当前分类的批次表或对应反馈。

### 信息与字段

- 「在途批次」表列依次为「批次号」「来源农场」「预计到场时间」。「预计到场时间」采用 24 小时制。
- 「已到场」表列依次为「批次号」「验收人」「到场时间」。
- 「退回批次」表列依次为「批次号」「退回原因」。

### 关键操作

- 点击任一 Tab，更新选中态并仅替换工作台内容区，按该 Tab 展示读取结果。工作台只读，查看与切换均不写入业务记录。
- 点击当前失败内容区的「重试」，仅重新读取当前 Tab。读取结果按「状态与异常恢复」显示。

### 状态与异常恢复

- **访问控制**：仅市集质检员可见「批次追踪」顶级入口。无权访问时保留所在界面，拦截进入工作台或读取批次数据。
- **读取中**：首次打开、切换至需读取的 Tab 或点击「重试」后，选中 Tab 的内容区显示 LoadingState（`batches-loading`），保留标题及 Tab 栏，质检员仍可切换其他 Tab。读取完成后，仍按当前选中 Tab 渲染结果。
- **读取成功**：内容区显示该 Tab 的 Table。「已到场」或「退回批次」无记录时保留本表列头和空数据区。
- **在途空态**：「在途批次」读取成功且无数据时，显示对应条件结构。另两个 Tab 仍可访问。
- **读取失败**：任一 Tab 加载失败时，显示对应条件结构，质检员仍停留在工作台并可点击「重试」或切换 Tab。重试成功时恢复当前 Tab 的相应结果，重试失败时保留该 Tab 的失败状态及重试入口。

| in-transit | 在途批次 | 第 1 个 Tab | 无 |
| arrived | 已到场 | 第 2 个 Tab | 无 |
| returned | 退回批次 | 第 3 个 Tab | 无 |
