# 原始需求 · 农产市集批次追踪

## 范围与角色
市集质检员每天核对进货批次的流向。现有「市集管理」包含本期新增的「批次追踪」顶级工作台入口。仅质检员可打开并查看工作台，工作台只读。

## 已确认的页面事实
本期在「批次追踪」同一页提供三个 Tab，按「在途批次」「已到场」「退回批次」排列。切换只替换内容区。默认打开哪一个 Tab 留待设计定案，三个都可作为初始视图。
「在途批次」显示「批次号」「来源农场」「预计到场时间」三列，预计到场时间为 24 小时制。「已到场」显示「批次号」「验收人」「到场时间」。「退回批次」显示「批次号」「退回原因」。
没有在途批次时，只在该 Tab 内显示「暂无在途批次」，另外两个 Tab 仍可访问。加载某个 Tab 失败时，该 Tab 内显示「批次读取失败」及「重试」，重试只重新加载该 Tab。

## 范围排除
不提供新增批次、修改验收人、处置退回或导出。工作台读取当前批次数据，不写入业务记录。未规定产品转交或新增审批，不影响查看任务完成。

## 验收
质检员能进入并切换三类批次，每个 Tab 呈现自己的列。无在途数据或读取失败时，按上述状态提示，仍留在同一个工作台。
