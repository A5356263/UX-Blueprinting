# 看起来像小交互，实际涉及数据范围

## 需求背景
用户希望在列表页新增一个快捷筛选，看起来只是多一个筛选条件。

## 需求描述
新增“只看我能处理的数据”筛选，但未明确它是否改变现有数据范围。

## 已知边界
表面像小交互。
实际可能影响数据范围解释。

## 预期需求类型
不确定，需要补充判断

## 预期处理方式
先补关键确认，不应直接按小需求处理。

## 预期重点维度
权限治理
评审风险

## 预期用户侧引导
现在还不能直接当成局部体验优化，因为它可能影响数据范围解释。我建议先确认这个筛选是在展示现有范围，还是在改变范围边界，再决定是轻量处理还是继续展开。这里最需要确认的是：筛选是否会改变用户当前可见的数据集合？

## 不应出现的判断
不应直接判成局部体验优化。
不应在没确认数据范围前直接给页面方案。
