# 原始需求 · 剧场场务设备转交

## 范围与角色
场务主管从「设备台账」菜单进入现有工具页。本期新增本场次设备转交能力。只有场务主管能看到该操作。每次转交一件当前场次设备给一名该场次的在岗接收人。跨场次设备、离岗接收人均不可提交。无需审批或二次人工确认。

## 已确认的操作与文本
设备行「发起转交」打开「设备转交」弹窗。只读显示「设备编号」和「当前保管人」，并提供必须选择一人的「接收人」字段。弹窗三个独立选项为「携带说明」「通知接收人」「保留交接备注」，支持多选，允许全不选，默认仅选「通知接收人」。选项定义：携带说明表示连同设备使用说明交接；通知接收人表示保存后向该人发送站内通知；保留交接备注表示将当前记录中的交接备注一同保留。未勾选的内容不随本次转交。
点击「取消」关闭弹窗并保留原行及业务记录。点击「确认转交」时按设备仍属于当前场次、接收人仍为本场次在岗人员的顺序校验。未选接收人时拦截并在接收人字段下显示「请选择接收人」。资格在提交时变化则不保存，弹窗保持打开且保留其他输入，提示「设备或接收人状态已变化」，允许刷新候选后重新选择或取消。
成功时关闭弹窗，回到设备列表原行，更新「当前保管人」并提示「设备已转交」。系统保存新保管人和三项勾选状态；选了通知时发送一次站内通知。失败或取消不改变保管人、选项记录或通知结果。

## 范围排除
不支持批量转交、跨场次转交、短信通知。未指定多选控件外形、页面布局和提示组件，具体方案留待设计。
