# 企业财富+设计语言基线

除非任务明确属于其他产品，生成企业财富+桌面业务页面时必须遵循本基线。设计语言基线先于内容 Pattern 生效；没有匹配的 Pattern，不代表页面可以忽略企业财富+的应用结构、视觉层级和组件规则。

本基线面向约 1440px 的高信息密度银行财富管理后台，不推导移动端、暗色模式或营销页面。业务需求可决定内容和流程，但不得覆盖品牌、框架及基础组件规则；用户最新明确要求的页面规则优先于旧样例。

## 应用结构

默认：

- 使用 `template.wealth-plus.application-frame`。
- Application Frame 至少占满 viewport，高 `56px` 的 Top Navigation sticky 在顶部。
- Top Navigation 展示品牌、一级菜单和用户工具区；一级菜单激活项使用品牌红文字和 `3px` 底边。
- 不生成左侧或右侧菜单栏，不沿用 XFT 的侧边主导航、`workspaceTop` 或固定底部 dock。
- 页面内容是主要纵向滚动区域，业务内容不得使顶部导航随页面滚动离开。
- Workspace 使用浅灰背景，上边距 `16px`、左右边距 `64px`、下边距 `24px`。
- Workspace 内默认只有一个 Primary Panel：白底、`1px` 中性边框、`4px` 圆角、无阴影；内部上/左右 `20px`、下 `24px`。
- 短页面保持完整工作区高度，长页面自然纵向滚动。

例外：

- 抽屉、下拉、弹窗等浮层可以使用规定层级的阴影；普通内容面板不得使用阴影。
- 仅当业务明确要求操作持续可用时设计 sticky 操作区；普通表单操作位于内容末尾。

检查：

- 顶部只出现一级菜单，不出现任何侧边菜单栏或 XFT 品牌元素。
- 标准业务页只有一个主要白色面板，不拆成同权卡片墙。
- 顶栏固定，页面内容独立纵向滚动。

## 页面入口与标题

按页面任务选择一种入口，不重复表达同一层级：

- 列表/管理页：可选页面标题 → 查询筛选 → 表格工具栏 → 表格 → 分页。
- 带子类型的列表页：内层 Tabs → 查询筛选 → 表格工具栏 → 表格，不重复页面大标题。
- 详情/编辑页：返回面包屑 → 对象 Hero 或真实步骤条 → 内容区块。
- 产品研究页：主搜索 → 多维筛选 → 已选条件 → 批量操作 → 结果表格。

标题规则：

- 页面大标题固定为 `18px / 26px / 600`。
- 只有当前对象没有被 Tabs、面包屑或 Hero 表达时才显示页面大标题。
- 二级区块标题使用 `14px / 22px / 600`，左侧可使用 `3px` 品牌红竖线。
- 弹窗和抽屉标题使用 `16px / 24px / 600`。
- 标题保持简短，不生成“欢迎使用”“数据概览中心”等无业务价值文案，不使用营销型超大标题。

## 视觉语言

默认：

- 颜色、字号、行高、间距、圆角、尺寸、阴影和层级优先使用已 staged 的企业财富+ Token。
- 不硬编码 hex、不使用内联 style；现有 Token 无法表达新语义时，先提出 Token 或受保护资产变更，不在页面内发明临时颜色。
- 品牌红只用于主行动、激活导航/Tab、关键上涨值和必要的品牌识别；一个操作组通常只有一个 primary action。
- 链接使用数智蓝，与品牌红区分。
- 普通选择、分段控件选中、开关开启以及表单 hover/focus 使用中性灰，不使用品牌红。
- 业务内容区不使用装饰渐变；白色至浅红渐变只属于统一顶部导航 chrome。
- 中文 UI 使用微软雅黑；金额、收益率、产品代码、日期、时间、份额和 KPI 使用 CMB Sans 与等宽数字。
- 正文统一使用常规字重 `400`，不加粗；只允许标题、区块标题和必要的强调信息使用 `600`。
- 间距从 `4 / 8 / 12 / 16 / 20 / 24 / 32px` 中选择。
- 所有带圆角的 UI 元素圆角不得小于 `2px`；输入与按钮使用 small radius，面板使用 regular radius，所有标签统一使用 `2px` small radius。
- 所有按钮，包括一级菜单、Primary、Default、Text、Icon 和 Danger 按钮，统一使用 small radius。

禁止：

- 玻璃拟态、夸张圆角、大面积插画、营销式 Hero、多彩卡片墙或内容区装饰渐变。
- 用品牌红表达普通选中或输入焦点。
- 用颜色作为涨跌、风险、错误或状态的唯一信息载体。

## 查询与筛选

默认：

- 查询筛选项不显示控件前面的字段名或 `Form.Item` 可见 label。
- 在 Input 或 Select 内使用 placeholder 表达筛选条件，例如管理机构筛选只显示 `placeholder="管理机构"` 的选择框。
- 虽不显示可见名称，每个筛选控件仍必须具有可访问名称，例如 `aria-label="管理机构"`。
- 输入框、InputNumber、日期控件和 Select 的宽度不得小于 `300px`，不得大于 `480px`。
- 1–2 个筛选条件使用横向查询行；3 个及以上可使用多列查询网格，空间不足时换行，不压缩到最小宽度以下。
- 查询/重置位于筛选区域末端；新建、导出属于表格全局工具栏，不混入查询按钮组。
- 有筛选的列表必须支持重置；已应用条件可用 chips 表达。
- 枚举少且需要快速比较时可平铺展示；互斥短选项使用 Radio 或 Segmented；选项多时使用 Select。

检查：

- 筛选控件前没有“管理机构：”之类的重复字段名。
- placeholder 与可访问名称都能准确表达筛选条件。
- 控件宽度保持在 `300–480px`，查询操作与全局操作作用域清楚。

## 数据录入表单

默认：

- 所有录入表单采用左右结构：字段标签在左，输入/选择控件在右。
- 不生成标签在上、控件在下的上下表单结构；标签右对齐并与控件首行对齐。
- 输入框、InputNumber、日期控件和 Select 的宽度不得小于 `300px`，不得大于 `480px`。
- 必填标记位于标签前；帮助文本与错误信息紧邻对应控件。
- 表单控件默认高 `32px`、正文 `14px`、small radius；hover、focus 使用中性灰边框，focus 必须有可见 ring。
- 只有存在阶段依赖、跨角色交接、阶段校验或可恢复进度时才显示 Steps；字段多不等于多步骤。
- 明细数据使用可编辑表格，新增入口可使用全宽虚线按钮。
- 内容末尾操作按“取消 / 暂存 / 提交”排列，提交是该操作组唯一 primary。
- 只读信息使用 Descriptions 或描述网格，不渲染成大量 disabled 输入框。

检查：

- 所有可见表单标签都位于控件左侧，没有上下排列。
- 必填、校验、disabled、loading 和恢复路径完整。
- 标签与控件保持程序化关联。

## 表格

默认：

- 表头高度固定为 `40px`，使用中性灰背景。
- 表格内容行高度固定为 `50px`，不使用斑马纹；hover 只使用极浅品牌色混合。
- 表格容器使用 `1px` 中性边框和 regular radius，无阴影。
- 文本默认左对齐；金融数值可按列语义右对齐，同列必须保持一致。
- 代码、日期、金额和比例使用等宽数字；金额显示单位并遵循一致的千分位规则。
- 复选框列只用于真实批量操作；批量操作仅在存在选择时显示或启用。
- 行操作位于末列；主对象名称可使用蓝色链接进入详情。
- 只有真实可排序列显示排序图标。
- Empty、Loading 和 Error 状态占据表格内容区域并保留列上下文。
- 分页位于表格下方，至少表达总数、当前页、前后页和必要的跳页能力。

检查：

- 表头均为 `40px`，内容行均为 `50px`。
- 金融数值的对齐、单位、正负号和格式一致。
- 全局、批量与行操作没有混为一个工具栏。

## 内容组织与容器

默认：

- 同一业务责任内优先使用留白、对齐、区块标题和 Divider 分组，不自动嵌套 Card。
- 表格、图表、抽屉和描述网格可以拥有独立边界，但不建立第二个页面级主面板。
- Inner Tabs 随页面内容滚动；没有内容类别切换时不渲染 Tabs 或空占位。
- Tab 用于同层内容类别切换，不代替流程步骤；激活态使用品牌红文字和底边。
- 详情页对象名位于紧凑 Hero 内，不在主面板外重复大标题。
- 抽屉只承载不应打断主列表上下文的关联信息；复杂编辑、深层导航和大型图表进入独立页面。

## 操作与状态

默认：

- Primary 推进或提交当前主要任务；同一操作组最多一个。
- Default 用于取消、暂存、导出等次要操作；Text/Link 用于行操作和轻量工具；Danger 用于不可逆操作。
- 操作按“恢复/取消 → 次要 → 主要”排列，右对齐操作区的主要按钮位于最右。
- 所有交互控件至少覆盖 default、hover、focus、disabled；提交型操作还覆盖 loading。
- 有数据请求的区域覆盖 loading、empty、error；危险操作提供确认或可恢复机制。
- 状态文本必须独立表达含义，不能只依赖颜色或图标。

## 金融数据与图表

默认：

- 金融涨跌遵循涨红跌绿，同时显示明确正负号，不能只依赖颜色。
- 每个统计值说明单位、时间范围或比较基准。
- 本产品/组合使用品牌红；基准依次使用蓝、金、紫、绿及扩展图表色板。
- 网格线、坐标轴和辅助文字使用中性色，不与数据系列争夺注意力。
- 净值/收益趋势使用折线图，最大回撤使用面积图，区间收益比较使用分组柱状图，资产配置使用环形图；其他图表按分析任务选择，不为装饰添加图表。
- 图表默认高度 `280px`；只有内容可比较且标签不拥挤时才使用两列布局。
- Tooltip 显示系列名、值、单位和日期或区间；图例顺序与系列顺序一致。
- 展示历史业绩时，将合规声明放在相应图表附近。

## 桌面响应与可访问性

默认：

- 基线按约 `1440px` 桌面工作台设计，内容最大宽可使用 `1312px`。
- 较窄桌面优先让查询网格降列、Toolbar 换行、表格横向滚动，不把表格列或表单控件压缩到不可读。
- 所有图标按钮具有可访问名称；输入与标签关联；无可见标签的查询控件使用 `aria-label`。
- 抽屉具有标题关联、关闭入口、Esc/遮罩关闭与焦点恢复。
- Focus 状态清晰可见且不只依赖颜色；文本与背景保持足够对比。
- 原型数据贴合财富管理语境，并覆盖长名称、大金额、负收益、空值等边界情况。

## 完成检查

- 使用企业财富+顶部一级菜单与单主面板，不出现 XFT 品牌、侧边菜单或默认底部 dock。
- 页面标题为 `18px`，没有与 Tabs、面包屑或 Hero 重复表达。
- 查询筛选无前置字段名，placeholder 与可访问名称完整。
- 数据录入表单全部为标签在左、控件在右的左右结构。
- 输入和选择类控件宽度保持在 `300–480px`。
- 表头 `40px`、内容行 `50px`；表格状态、分页和操作作用域完整。
- 圆角不小于 `2px`，所有按钮和标签使用 small radius。
- 品牌红使用克制，普通选中与输入 focus 使用中性灰。
- 页面默认只有一个主白色面板，无主面板阴影、卡片墙、玻璃拟态或内容区装饰渐变。
- 金融数据包含单位、时间范围、正负号和一致格式；历史业绩附近有合规声明。
