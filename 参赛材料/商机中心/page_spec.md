# 页面生成规格：商机中心

---

## 1. 页面摘要

- **产品领域**：企业财富+｜商机中心
- **页面类型**：策略包列表页、策略包详情页、客户列表页、客户详情页、数据回检入口页、说明弹窗、确认弹窗、失败弹窗
- **用户角色**：总行产品经理、分行产品经理；分行客户经理仅作为 CRM 协同角色
- **核心任务**：查看规则，筛选并判断商机客户，确认命中事实和期限，必要时跳转 CRM 乘流

---

## 2. 生成范围

### 生成

- P1 商机策略包列表
- P2 策略包详情
- P3 商机客户列表
- P4 客户详情
- P5 数据回检入口
- D1 去做营销前说明
- D2 数据变化确认
- D3 CRM 跳转失败

### 只引用不生成

- CRM 乘流策略新建页：只提供跳转目标和返回承接，不生成 CRM 内部页面。
- 知几商机经营看板：只提供跳转入口和权限/数据说明，不生成知几页面。

### 不生成

- CRM 内部客户选择、渠道配置、审批、活动和执行页面。
- 观流自动营销、客户综合评分、综合营销建议、历史商机、导出和列个性化。

---

## 3. 页面实体关系

- 商机中心
  - P1 商机策略包列表 → P2 策略包详情
  - P2 策略包详情 → P3 商机客户列表（带入策略包筛选）
  - P3 商机客户列表 → P4 客户详情
  - P4 客户详情 → P2 策略包详情 / P3 商机客户列表
  - P3 做营销 Tab → D1 去做营销前说明 → 外部 CRM 乘流
  - P3 / P4 → D2 数据变化确认
  - 外部 CRM 跳转失败 → D3 CRM 跳转失败 → P3 / P4
  - P5 数据回检入口 → 外部知几商机经营看板

### 页面结构（ASCII 线框 + 区域说明）

```text
┌ 商机中心 / 看规则 ───────────────────────────────────────────────┐
│ 商机策略包（{策略包总数}）                         数据更新：{时间} │
│ [分类 Select] [优先级 Select] [营销方式 Select] [搜索 Input]      │
├─────────────────────────────────────────────────────────────────┤
│ 策略包名称 | 分类 | 规则摘要 | 优先级 | 跟进期限 | 建议渠道/物料 │
│ 当前客户 | 新进入 | 即将过期 | 操作                                 │
├─────────────────────────────────────────────────────────────────┤
│ {策略包名称} | ... | {规则摘要} | {优先级} | {期限} | [详情 Button] │
└─────────────────────────────────────────────────────────────────┘
```

### 区域说明

- 页面标题区：Text 页面标题；Text 数据更新时间；Text 只读说明。
- 筛选区：Select 分类、优先级、营销方式；Input 策略包名称搜索。
- 策略包列表区：Table 展示策略包字段；Button 详情。
- 数据状态区：LoadingState、InlineError、EmptyState。

### 列表字段

- 策略包名称：{策略包名称}
- 分类：{分类}
- 商机规则摘要：{规则摘要}
- 优先级：{优先级}
- 跟进期限：{跟进期限}
- 建议渠道：{建议渠道}
- 建议物料：{建议物料}
- 当前客户：{当前客户数}
- 新进入：{新进入数}
- 即将过期：{即将过期数}
- 操作：详情

### 关键操作

- 点击详情 → P2。
- 修改筛选并查询 → 仅刷新列表和统计，不改变策略包内容。
- 页面首次加载 → LoadingState；加载失败 → InlineError + 重试。
- 无策略包 → EmptyState；无权限 → 不展示菜单或页面内容。

### 提取备注

- 策略包只读；不生成新增、编辑、启停、删除和审批操作。
- 示例数量全部变量化。

## 5. P2 策略包详情

### 页面目标

说明单个策略包的触发规则、业务解释、期限和当前客户覆盖。

### 页面结构（ASCII 线框 + 区域说明）

```text
┌ ← 返回策略包列表  {策略包名称} [{优先级}]  [只读 Tag] ──────────────┐
│ 规则说明：{规则摘要}                                                │
│ 命中条件：{命中条件}                                                │
│ 业务解释：{解释文本} [查看完整解释 Button]                         │
├────────────────────────────────────────────────────────────────────┤
│ 跟进期限 {期限} | 建议渠道 {渠道} | 建议物料 {物料}                 │
│ 当前客户 {数量} | 新进入 {数量} | 即将过期 {数量}                  │
├────────────────────────────────────────────────────────────────────┤
│ [查看商机客户 Button]                                               │
└────────────────────────────────────────────────────────────────────┘
```

### 区域说明

- 标题区：Button 返回；Text 策略包名称、优先级；Tag 只读。
- 规则区：Text 规则摘要、命中条件、业务解释；可展开完整解释。
- 经营统计区：StatCard 当前客户、新进入、即将过期。
- 操作区：Button 查看商机客户。
- 状态区：LoadingState、EmptyState、InlineError、PermissionState。

### 关键操作

- 点击查看商机客户 → P3，带入策略包筛选。
- 点击返回 → P1。
- 点击查看完整解释 → 展开/收起长文本，不改变页面状态。
- 策略包无当前客户 → 统计区 EmptyState，不代表策略包失效。

### 提取备注

- 规则解释必须保留关键数值、时间和比较关系。
- 无权限或详情不存在时不展示缓存内容。

## 6. P3 商机客户列表

### 页面目标

按客户聚合当前商机，帮助用户按权限、星级、期限和命中规则找到待判断对象。

### 页面结构（ASCII 线框 + 区域说明）

```text
┌ 商机中心 / 做营销 / 商机客户 ──────────────────────────────────────┐
│ 客户 {客户总数} | 公金五星 {数量} | 新进入 {数量} | 即将过期 {数量} │
│ [待处理 Tab] [营销中 Tab] [已完成营销 Tab] [未营销已过期 Tab]      │
│ 组织： [分行 Select] [综支机构 Select] [客户经理 Select]          │
│ 商机： [策略包 Select] [公金星级 Select] [财富星级 Select]         │
│ 时效： [命中状态 Select] [最近过期 DateRange] [查询 Button] [重置] │
│ 数据更新时间：{时间}                                [去做营销]    │
├────────────────────────────────────────────────────────────────────┤
│ 客户名 | 客户号 | 命中商机 | 最近过期 | 状态 | 公金星级 | 财富星级 │
│ 年日均余额 | 当前余额 | 历史最高余额 | 分行 | 综支 | 客户经理 | 详情 │
├────────────────────────────────────────────────────────────────────┤
│ {客户名} | ... | {N}项 | {日期} | {状态} | ... | [详情 Button]       │
└────────────────────────────────────────────────────────────────────┘
```

### 区域说明

- 顶部统计区：StatCard 客户总数、公金星级分布、新进入、即将过期。
- 状态区：Tabs；状态由当前商机和可确认执行证据计算；未接入证据时显示暂无法确认。
- 筛选区：Select 分行、综支机构、客户经理、策略包、公金星级、财富星级、命中状态；DateRange 最近过期；Button 查询、重置。
- 操作区：Button 去做营销，仅在待处理 Tab 展示；Button 详情。
- 列表区：Table 客户字段；命中商机摘要可展开。
- 数据状态区：数据更新时间、LoadingState、EmptyState、InlineError、权限状态、弱网状态。

### 列表字段

- 客户名称：{客户名称}；左固定；脱敏展示；点击进入 P4。
- 客户号：{客户号}；脱敏。
- 企银编号：{企银编号}；缺失显示 `--`。
- 命中商机：{最高优先级商机名称} 等 {N} 项；展开后查看全部。
- 最近过期：{日期} / 剩余 {N} 天 / 已超期 {N} 天。
- 营销状态：{营销状态}。
- 公金星级：{公金星级}；缺失显示 `--`，排序排在一星之后。
- 企业财富星级：{企业财富星级}；缺失显示 `--`。
- 年日均余额：{年日均余额}。
- 当前时点余额：{当前余额}；显示数据日期。
- 历史最高时点余额：{历史最高余额}；口径未确认时显示“统计口径待确认”。
- 分行：{分行}。
- 综支机构：{综支机构}；缺失显示 `--`。
- 客户经理：{客户经理}；缺失显示“未分配”。
- 操作：详情。

### 关键操作

- 进入页面 → 默认待处理 Tab，默认排序：公金星级降序、最近过期升序、新进入优先、客户名称升序。
- 选择筛选 → 机构层级联动；组间 AND，多选内部 OR。
- 点击查询 → 同步刷新数量、列表、状态和数据更新时间。
- 点击数量卡 → 在现有条件上叠加对应条件。
- 点击重置 → 恢复当前 Tab 默认条件。
- 点击命中商机摘要 → 展开每条商机的策略包、优先级、命中状态、首次命中、期限、命中事实和解释。
- 点击详情 → P4。
- 点击去做营销 → D1；确认后执行 CRM 权限校验和跳转；不改变营销状态。
- 修改已有筛选 → 已应用条件以 Tag 展示；无结果时保留筛选并提供重置。

### 未来乘流承接约束

- 普通浏览态不显示选客复选框。
- 后续乘流可复用本页筛选、排序、字段、权限和稳定客户 ID；本期不自动把当前页面选择带入 CRM。
- 页面查询状态和滚动位置在 CRM 跳转失败或返回后保留。

- 点击去做营销 → D1。
- 客户已退出当前商机 → EmptyState；刷新后重新计算。
- 权限失效 → 不展示缓存敏感内容，返回 P3。

## 10. D2 数据变化确认

### 弹窗目标

当客户权限、商机命中、期限或筛选结果在查看期间发生变化时，阻止用户继续使用旧数据。

### 区域结构

```text
┌ 商机数据已更新 ─────────────────────────────────┐
│ 客户名单或商机状态已更新，请按最新结果重新判断。  │
│ [查看最新结果 Button] [返回列表 Button]           │
└─────────────────────────────────────────────────┘
```

### 交互

- 点击查看最新结果 → 刷新当前页面，以最新快照重算。
- 点击返回列表 → P3，保留可恢复的查询条件。
- 刷新失败 → 转入页面级错误状态，不展示旧结果为最新结果。

## 11. D3 CRM 跳转失败

### 弹窗目标

解释 CRM 无权限、认证失效、网络错误或目标系统不可用，并提供恢复路径。

### 区域结构

```text
┌ 暂时无法进入 CRM 乘流 ──────────────────────────┐
│ {失败原因}                                       │
│ 商机状态未发生变化。                              │
│ 请求号：{请求号}                                  │
│ [重新认证 Button] [申请权限 Button]               │
│ [稍后重试 Button] [返回商机中心 Button]            │
└─────────────────────────────────────────────────┘
```

### 交互

- `crm_checking` 超时 → D3。
- 无权限 → 展示申请权限；点击后进入权限申请路径。
- 认证失效 → 展示重新认证；认证完成后按已确认回跳策略返回。
- 网络/系统错误 → 展示稍后重试；重试不清空 P3/P4 查询上下文。
- 目标地址配置错误 → 展示请求号，返回商机中心；不暴露技术堆栈。

## 12. 主交互流程

### 规则理解

1. P1 加载策略包。
2. 用户筛选或搜索策略包。
3. 点击详情进入 P2。
4. 点击查看商机客户进入 P3，并带入策略包筛选。

### 客户判断

1. P3 默认加载待处理范围。
2. 用户选择筛选条件并点击查询。
3. 系统按权限、最新数据批次和筛选规则返回结果。
4. 用户展开命中商机或进入 P4。
5. 用户查看每条当前商机的命中事实、期限、解释和数据来源。

### CRM 跳转

1. 用户在 P3/P4 点击去做营销。
2. 首次打开 D1；已保存偏好时跳过 D1。
3. 用户确认后进入 CRM 权限校验。
4. 校验成功跳转外部 CRM 乘流；校验失败进入 D3。
5. 跳转成功、取消或失败均不改变企业财富+营销状态。

### 回检

1. 用户进入 P5。
2. 系统展示各数据源更新时间、覆盖率、未知和观察中。
3. 用户点击去知几查看。
4. 有权限则跳转外部知几；无权限或失败则留在 P5。

## 13. 校验规则

- 所有客户、策略包、商机和外部记录按稳定 ID关联。
- 服务端按机构、管户和客户权限过滤；前端不承担权限裁剪。
- 查询筛选组之间为 AND，多选项内部为 OR。
- 机构筛选按分行 → 综支机构 → 客户经理联动。
- 最近过期时间支持今日、未来 3 天、未来 7 天和已过期；起止边界包含。
- 默认排序：公金星级降序 → 最近过期升序 → 新进入优先 → 客户名称升序。
- 公金星级为空时显示 `--`，排在一星之后；不使用企业财富星级补位。
- 缺失金额、企银编号、机构和客户经理不阻断商机展示；分别显示 `--`、`未分配`或“统计口径待确认”。
- P3/P4 的当前商机只展示最新有效快照；历史商机不生成页面区域。
- 点击去做营销、打开说明、成功跳转、返回和取消均不计营销发起。
- 知几指标分母为 0 时显示 `--`；未知不计成功或失败；观察中不计未购买。
- CRM 跳转目标必须通过环境配置和域名白名单校验。
- 跳转凭证、客户号、企银编号、余额和营销记录不得写入 URL、普通日志或前端埋点。

## 15. 异常恢复

- P1/P2 加载失败：保留页面上下文，展示重试；详情失败可返回列表。
- P3 筛选无结果：保留条件，支持删除条件和重置；不清空用户已选筛选。
- P3 超大数据：使用服务端分页和筛选；提示继续缩小范围，不一次性加载全部客户。
- P3/P4 权限失效：不展示缓存敏感内容，返回授权范围内列表或申请权限。
- P3/P4 商机变化：打开 D2，刷新后按最新快照判断。
- P4 CRM 关联缺失：记录区显示暂无法确认，不推断营销成功或失败。
- P5 知几无权限：展示申请路径；无数据时显示空状态，不展示伪造指标。
- D1 取消：关闭弹窗，留在原页面，不产生业务状态变化。
- D3 无权限：申请权限或返回；认证失效：重新认证；网络错误：稍后重试；配置错误：显示请求号并联系负责人。
- 所有跨系统失败均保留 P3/P4 的 Tab、筛选和滚动位置。
