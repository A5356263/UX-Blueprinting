# 页面生成规格：智能收文

## 1. 页面摘要

- **产品领域**：公文 — 收文办理（协同办公）
- **页面类型**：列表页（收文管控）+ 弹窗（智能收文）
- **用户角色**：收文办理人员
- **核心任务**：选择收文流程并上传公文原始文件，系统识别生成表单字段后填入收文表单

---

## 2. 生成范围

### 生成

- 收文管控页面：承载页面，本期新增"智能收文"入口按钮。
- 智能收文弹窗：选择收文流程、上传文件、识别、结果展示、自动填入表单。

### 只引用不生成

- 收文表单（收文登记页）：现有页面本期不修改结构；智能收文填充后由现有收文登记页面承接后续编辑与提交。

### 不生成

- 无。

---

## 3. 页面实体关系

- 收文管控页面 → 智能收文弹窗（点击 [智能收文]）
- 智能收文弹窗 → 收文表单（点击 [自动填入表单]）
- 智能收文弹窗 → 收文管控页面（点击 [取消]）

---

## 4. 收文管控页面

### 页面目标

查看和筛选收文记录，发起收文并维护收文的处理与公示信息。本期新增"智能收文"入口，用于发起智能化识别收文。

### 页面结构（ASCII 主结构）

```
+---------------------------------------------------------------------------------------+
| 【 筛选查询区 】                                                                       |
| [Left]: 标题 [输入框: 请输入]   字号 [下拉框: 请选择]   来文单位 [下拉框: 请选择]          |
| [Right]: [按钮: 重置] [主按钮: 查询] [按钮: 更多筛选 v]                                  |
+---------------------------------------------------------------------------------------+
| 【 工具与操作区 】                                                                     |
| [Left]: [主按钮: + 收文] [按钮: + 录入历史数据] [按钮: + 智能收文(本期新增)] [按钮: 导出 v] |
| [Right]: [图标按钮: 表头设置]                                                           |
+---------------------------------------------------------------------------------------+
| 【 收文数据表格区 】                                                                   |
| [表头列名]: 标题 | 字号 | 来文单位 | 状态 | 发文日期 | 收文日期 | 操作                     |
| [列内组件]: {文} | {文或-} | {文} | [标签: 公示中] | {日期或-} | {日期或-} | [Actions]     |
+---------------------------------------------------------------------------------------+
| 【 底部分页区 】                                                                       |
| [Right]: < [1] > [20 条/页 v]                                                          |
+---------------------------------------------------------------------------------------+
```

### 区域说明

- 筛选查询区：标题输入框、字号下拉、来文单位下拉、重置按钮、查询按钮、更多筛选按钮。
- 工具与操作区：+收文主按钮、+录入历史数据按钮、+智能收文按钮（本期新增，位于录入历史数据右侧）、导出按钮、表头设置图标按钮。
- 收文数据表格区：标题、字号、来文单位、状态、发文日期、收文日期、操作。
- 底部分页区：分页与每页条数选择。

### 信息与字段

- 收文数据表格列：标题、字号、来文单位、状态（标签：公示中）、发文日期、收文日期、操作（删除、置顶、阅读记录、下载配置）。
- 智能收文入口按钮：位于工具与操作区，录入历史数据按钮右侧。

### 关键操作

- 点击 [智能收文] → 打开智能收文弹窗（本期新增）。
- 点击 [收文] → 打开收文表单（现有功能）。
- 点击 [录入历史数据]、[导出] → 现有功能，本期不变。
- 无收文管控菜单功能权限 → 不展示 [智能收文] 按钮。

## 5. 智能收文弹窗

### 弹窗目标

让收文办理人员选择收文流程、上传公文原始文件，由系统识别生成表单字段并填入收文表单。

### 区域结构（ASCII 主结构 + 条件结构）

主结构（初始状态）：

```
+-----------------------------------------------------------+
| 智能收文                                                   |
| 您可以上传公文原始文件，智能化生成收文表单                    |
+-----------------------------------------------------------+
| 收文流程 [下拉框: 请选择收文流程]                           |
| 公文文件 [上传区: 点击上传 / 拖拽文件，支持 PDF/JPG/PNG/     |
|          WORD，不超过 100M]                                |
+-----------------------------------------------------------+
| [按钮: 取消] [主按钮: 开始识别]                            |
+-----------------------------------------------------------+
```

条件结构（识别中）：

```
+-----------------------------------------------------------+
| 智能收文                                                   |
| 您可以上传公文原始文件，智能化生成收文表单                    |
+-----------------------------------------------------------+
| 收文流程 [下拉框: {所选流程}(锁定)]                         |
| 公文文件 [上传区: {文件名}(锁定)]                           |
| [提示: 正在识别公文内容，请稍候…]                          |
+-----------------------------------------------------------+
| [按钮: 取消] [主按钮: 开始识别(禁用，显示"识别中")]        |
+-----------------------------------------------------------+
```

条件结构（识别成功）：

```
+-----------------------------------------------------------+
| 智能收文                                                   |
| 您可以上传公文原始文件，智能化生成收文表单                    |
+-----------------------------------------------------------+
| 收文流程 [下拉框: {所选流程}]                              |
| 公文文件 [上传区: {文件名}]                                |
| 识别结果                                                   |
|   公文标题: {识别标题}                                     |
|   来文单位: {识别来文单位}                                 |
|   字号: {识别字号}                                         |
|   …（其余识别出的字段）                                    |
+-----------------------------------------------------------+
| [按钮: 取消] [主按钮: 自动填入表单]                        |
+-----------------------------------------------------------+
```

条件结构（识别失败）：

```
+-----------------------------------------------------------+
| 智能收文                                                   |
| 您可以上传公文原始文件，智能化生成收文表单                    |
+-----------------------------------------------------------+
| 收文流程 [下拉框: {所选流程}(保留)]                         |
| 公文文件 [上传区: {文件名}(保留)]                           |
| 识别结果                                                   |
| [提示: 识别失败，请重新上传文件或重新识别]                  |
+-----------------------------------------------------------+
| [按钮: 取消] [主按钮: 开始识别(可重新发起)]                 |
+-----------------------------------------------------------+
```

### 区域说明

- 标题区：标题"智能收文"、副标题"您可以上传公文原始文件，智能化生成收文表单"。
- 收文流程区：下拉框，仅展示启用状态的收文流程，单选。
- 公文文件区：文件上传控件，支持 PDF、JPG、PNG、WORD，单文件不超过 100M，每次 1 个。
- 识别结果区：识别完成后单独展示识别生成的表单字段与取值；识别失败时展示失败提示。
- 操作区：[取消] [开始识别]（初始）；[取消] [自动填入表单]（识别成功后）。

### 信息与字段

- 收文流程：下拉框，单选，仅展示启用状态流程；占位文案"请选择收文流程"。
- 公文文件：上传控件，格式 PDF、JPG、PNG、WORD，单文件不超过 100M，每次 1 个。
- 识别结果字段：动态展示识别生成的收文表单字段与取值（如公文标题、来文单位、字号等，字段取决于所选流程对应表单及识别结果）。

### 关键操作

- 选择收文流程 → 回填所选流程。
- 上传公文文件 → 校验格式与大小；通过后上传区展示文件名，[开始识别] 变为可用。
- 点击 [开始识别] → 进入识别中状态，锁定收文流程与文件上传区。
- 点击 [自动填入表单] → 打开所选收文流程对应的收文表单并填充识别字段，上传文件自动作为正文或附件带入，弹窗关闭。
- 点击 [取消] → 关闭弹窗，返回收文管控页面，本次上传与识别内容不保留，不生成收文记录。

---

## 6. 跨页面交互流程

### 主流程：智能收文生成收文表单

收文管控页面 →（点击 [智能收文]）→ 智能收文弹窗 →（选择收文流程 → 上传公文文件 → 校验通过 → 点击 [开始识别] → 查看识别结果 → 点击 [自动填入表单]）→ 收文表单（识别字段已填充，文件自动作为正文或附件带入）→ 用户在收文表单继续编辑 → 提交或存草稿（现有收文登记流程）

### 回流：取消智能收文

智能收文弹窗 →（点击 [取消]）→ 收文管控页面（放弃本次操作，不生成收文记录）

---

## 7. 校验规则

| 触发时机 | 校验内容 | 阻断条件 | 失败反馈 |
|---|---|---|---|
| 上传公文文件后 | 文件格式属于 PDF、JPG、PNG、WORD 之一，且文件大小不超过 100M | 格式不支持或文件超过 100M | 上传区就地显示错误提示（copy.error_format / copy.error_size），不执行识别，可重新上传 |
| 弹窗打开至上传完成前 | 开始识别前置条件 | 未选择收文流程，或未上传通过校验的文件 | [开始识别] 置灰不可用 |

---

## 8. 状态表现

| 状态 | 触发条件 | UI 表现 | 文案 key |
|---|---|---|---|
| 待识别 | 弹窗打开，流程与文件尚未就绪 | 展示流程下拉框、上传区、[取消] [开始识别]（开始识别置灰） | copy.ready |
| 识别中 | 点击 [开始识别] 后 | 展示识别中提示，收文流程与文件上传区锁定，[开始识别] 禁用并显示"识别中" | copy.recognizing |
| 识别成功 | 识别生成表单字段 | 展示识别结果区（字段与取值），操作区切换为 [取消] [自动填入表单] | copy.recognize_success |
| 识别失败 | 识别未成功生成表单字段 | 展示识别失败提示，保留已选流程与文件，操作区 [取消] [开始识别]（可重新发起） | copy.recognize_fail |
| 文件校验失败 | 上传格式或大小不合规的文件 | 上传区就地显示错误提示，不执行识别，可重新上传，保留已选流程 | copy.error_format / copy.error_size |

---

## 9. 异常恢复

- 文件格式或大小校验失败（EX-001）：上传区就地提示，不执行识别；用户重新选择符合格式与大小限制的文件，校验通过后继续点击 [开始识别]；已选择的收文流程保留，弹窗与已填内容不丢失。
- 识别失败（EX-002）：弹窗内展示识别失败提示；用户可重新上传文件或重新识别，任务重新开始；也可点击 [取消] 关闭弹窗，返回收文管控页面改用 [收文] 手工登记。
- 前置条件未满足：未选择收文流程或未上传通过校验的文件时，[开始识别] 置灰，完成前置条件后变为可用。
