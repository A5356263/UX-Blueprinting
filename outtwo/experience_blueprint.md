# 体验蓝图：智能收文

## §0 本次关键设计判断

### D-001 · 智能收文用弹窗承载前置识别

**体验判断**

智能收文是收文登记前的智能化识别入口，用弹窗承载"选择流程 + 上传文件 + 识别 + 展示结果"的轻量前置步骤。

影响范围：收文管控页面、智能收文弹窗。

**具体做法**

在收文管控页点击"智能收文"打开弹窗；弹窗内完成流程选择、文件上传与识别结果展示；识别后离开弹窗进入收文表单，不回到弹窗。

避免出现：把智能收文做成独立全页面，打断收文登记主链路；或完成后仍滞留弹窗导致用户找不到去向。

### D-002 · 弹窗内单页顺序组织，不拆分步骤

**体验判断**

流程选择、文件上传、开始识别与结果展示在同一弹窗内按任务顺序呈现，识别结果展示是动作结果而非独立阶段。

影响范围：智能收文弹窗结构。

**具体做法**

弹窗按"收文流程 → 公文文件 → 操作区"顺序组织；点击开始识别后进入识别中状态，识别完成在同一弹窗内展示结果与"自动填入表单"操作，不引入步骤条。

避免出现：把"选择流程→上传→识别"拆成多步骤条，增加往返成本且无实质阶段依赖。

### D-003 · 识别前前置约束，避免无效识别

**体验判断**

未选择收文流程或未上传通过校验的文件时，"开始识别"不可用，前置拦截可预见的无效识别。

影响范围：智能收文弹窗操作区。

**具体做法**

[开始识别] 在收文流程已选且文件上传并通过格式、大小校验前保持不可用；识别中锁定流程选择与文件上传，防止中途修改导致识别与所选不一致。

避免出现：未选流程或文件不合格仍可点击识别，等到识别阶段才报错。

### D-004 · 识别结果单独展示，确认后填入表单

**体验判断**

识别生成的表单字段在弹窗内单独展示，用户核对后再通过"自动填入表单"进入收文表单，避免识别偏差直接落入表单。

影响范围：智能收文弹窗识别结果区、收文表单。

**具体做法**

识别完成后弹窗出现"识别结果"区，列出识别出的字段与取值；操作区切换为 [取消] [自动填入表单]；点击后打开所选收文流程对应的收文表单并填充，上传文件自动作为正文或附件带入。

避免出现：识别结果不展示、用户看不到识别了哪些字段就盲目填入表单。

### D-005 · 识别与校验异常就地恢复

**体验判断**

文件校验失败在文件上传区就地提示，识别失败在弹窗内反馈并可重新开始，任务不中断、可自助恢复。

影响范围：智能收文弹窗上传区与反馈区。

**具体做法**

文件格式或大小不通过时，上传区就地提示限制并支持重新选择；识别失败时弹窗内展示失败反馈，用户可重新上传或重新识别；失败前已选择的流程与已上传的文件保留。

避免出现：校验失败无提示、识别失败只报错无恢复路径，用户只能反复尝试或放弃。

### D-006 · 收文表单沿用现有登记流程

**体验判断**

自动填入后进入所选收文流程对应的现有收文表单，识别字段可继续编辑，沿用现有收文登记提交或存草稿流程。

影响范围：收文表单（复用引用）。

**具体做法**

智能收文填充后，用户在原收文表单页面核对、修改字段，按现有收文登记流程提交或存草稿；智能收文不新增独立收文记录类型。

避免出现：为智能收文再造收文表单或提交链路，与现有收文登记流程分叉。

## §2 旅程消费摘要

### 信心最低点：收文办理人员 · 识别结果确认

**旅程信号**

识别完成后，用户对识别出的字段是否正确、是否覆盖全部必要字段缺少把握，此时信心最低。

**设计落点**

- §7：识别结果在弹窗内单独展示，字段与取值可见，供用户核对后确认填入。

### 关键转折：收文办理人员 · 进入智能收文

**旅程信号**

用户从"手工填写收文表单"切换到"上传文件智能识别"，需要先理解智能收文的用途与前置要求。

**设计落点**

- §7：弹窗副标题说明"上传公文原始文件，智能化生成收文表单"，并明确收文流程与文件要求。
- §4：进入弹窗后先选择流程、上传文件，再开始识别，顺序引导任务推进。

### 流失风险：收文办理人员 · 识别失败

**旅程信号**

识别失败时用户可能因缺少恢复路径而放弃智能收文，退回手工填写。

**设计落点**

- §6：识别失败在弹窗内反馈，明确可重新上传或重新识别，任务可重新开始。
- §7：识别结果区失败状态下保留已选流程与文件，减少重复操作。

## §3 交互流程总览

本次设计包含 1 条主路径和 3 条分支路径。

### 主路径 1 · 收文办理人员智能收文生成收文表单（FN-001）

→ 收文管控页面
→ 点击 [智能收文]
→ 打开 智能收文弹窗
→ 选择收文流程（下拉单选，仅启用状态流程）
→ 上传公文文件
→ 系统校验文件格式与大小
→ 点击 [开始识别]
→ 进入识别中状态
→ 识别成功，弹窗内单独展示识别结果（字段与取值）
→ 点击 [自动填入表单]
→ 打开所选收文流程对应的收文表单，识别字段已填充
→ 上传的公文原始文件自动作为正文或附件带入收文表单
→ 用户在收文表单继续编辑
→ 提交或存草稿（沿用现有收文登记流程）

**分支**

- 文件格式不属于 PDF、JPG、PNG、WORD 或超过 100M → 上传区就地提示，不执行识别，可重新上传
- 未选择收文流程或未上传通过校验的文件 → [开始识别] 不可用，不进入识别
- 识别失败 → 弹窗内展示失败反馈，任务重新开始，可重新上传或重新识别
- 点击 [取消] → 关闭智能收文弹窗，放弃本次智能收文，不生成收文记录

### 分支路径 · 文件校验失败（BR-001、BR-002）

→ 智能收文弹窗文件上传区
→ 上传不符合格式或大小限制的文件
→ 上传区就地显示错误提示
→ 重新选择符合要求的文件
→ 校验通过后继续 [开始识别]

- 承载说明：错误就地显示在上传区（InlineError），保留弹窗与已填内容，任务停留在弹窗上传阶段。

### 分支路径 · 识别失败（EX-002）

→ 智能收文弹窗识别结果区
→ 识别未成功生成表单字段
→ 弹窗内展示识别失败反馈
→ 重新上传或重新识别
→ 回到可重新开始状态

- 承载说明：失败反馈在弹窗内展示，保留已选流程与文件，用户可重新开始。

### 分支路径 · 取消智能收文（FN-001）

→ 智能收文弹窗
→ 点击 [取消]
→ 弹窗关闭
→ 回到收文管控页面

- 承载说明：弹窗常规关闭操作，无数据写入，未生成收文记录。

## §4 主路径详细流程

### 主路径 1 · 收文办理人员智能收文生成收文表单（FN-001）

**节点 1 · 从收文管控页发起智能收文**

- 【用户动作】：在收文管控页面点击 [智能收文]
- 【系统响应】：打开智能收文弹窗，展示标题"智能收文"、副标题"您可以上传公文原始文件，智能化生成收文表单"，以及收文流程下拉框、文件上传区和 [取消] [开始识别] 操作
- 【用户需要知道】：智能收文用于上传公文原始文件自动生成收文表单，需先选择收文流程并上传文件
- 【建议文案】：副标题"您可以上传公文原始文件，智能化生成收文表单"
- 【下一步】：在弹窗内选择收文流程

**节点 2 · 选择收文流程**

- 【用户动作】：打开收文流程下拉框，从启用状态的收文流程中选择一个
- 【系统响应】：下拉框仅展示启用状态的收文流程，支持单选；选中后回填所选流程
- 【用户需要知道】：所选收文流程决定后续打开并填充的收文表单
- 【下一步】：上传公文文件

**节点 3 · 上传公文文件**

- 【用户动作】：在文件上传区选择 1 个公文文件（PDF、JPG、PNG、WORD，不超过 100M）
- 【系统响应】：上传后校验文件格式与大小；通过后上传区展示文件名，[开始识别] 变为可用
- 【用户需要知道】：每次仅支持上传 1 个文件，格式限 PDF、JPG、PNG、WORD，大小不超过 100M
- 【下一步】：点击 [开始识别]

**节点 4 · 开始识别**

- 【用户动作】：点击 [开始识别]
- 【系统响应】：进入识别中状态，[开始识别] 禁用并显示识别进度；收文流程与文件上传区锁定，防止中途修改
- 【用户需要知道】：识别需要一定时间，处理期间请勿关闭弹窗
- 【建议文案】：按钮状态"识别中"
- 【下一步】：等待识别完成

**节点 5 · 查看识别结果**

- 【用户动作】：查看弹窗内单独展示的识别结果
- 【系统响应】：识别成功，弹窗出现"识别结果"区，列出识别生成的表单字段与取值；操作区切换为 [取消] [自动填入表单]
- 【用户需要知道】：识别结果将填入所选收文流程对应的收文表单，可在填入前查看确认
- 【下一步】：点击 [自动填入表单]

**节点 6 · 自动填入表单**

- 【用户动作】：点击 [自动填入表单]
- 【系统响应】：打开所选收文流程对应的收文表单，识别字段已填充；上传的公文原始文件自动作为正文或附件带入；智能收文弹窗关闭
- 【用户需要知道】：已进入收文表单，识别字段可继续编辑
- 【下一步】：在收文表单核对并编辑字段

**节点 7 · 完成收文登记**

- 【用户动作】：在收文表单继续编辑，点击 [提交] 或 [存草稿]
- 【系统响应】：沿用现有收文登记流程处理，形成收文记录
- 【用户需要知道】：识别字段填充后仍需按收文登记要求确认内容
- 【下一步】：进入现有收文处理流程（提交进入审批，或存草稿后续处理）

## §5 次交互流程

### 次流程 1 · 取消智能收文（FN-001）

- 【触发条件】：用户在智能收文弹窗内点击 [取消]
- 【用户动作】：点击 [取消]
- 【系统反馈】：智能收文弹窗关闭，返回收文管控页面；本次上传与识别内容不保留，不生成收文记录
- 【下一步】：停留在收文管控页面，可重新点击 [智能收文] 或改用 [收文] 手工登记

## §6 异常与阻断流程

### 异常 1 · 文件格式或大小校验失败（EX-001）

- **发生时机**：在智能收文弹窗上传公文文件后
- **触发条件**：文件格式不属于 PDF、JPG、PNG、WORD，或文件大小超过 100M
- **判断依据**：上传后系统按格式与大小校验（BR-001、BR-002）
- **反馈形式**：文件上传区就地错误提示（InlineError）
- **系统反馈**：上传区显示错误原因，不执行识别；已选择的收文流程保留
- **如何处理**：用户重新选择符合格式与大小限制的文件，校验通过后继续点击 [开始识别]；任务停留在弹窗上传阶段，弹窗与已填内容不丢失

### 异常 2 · 识别失败（EX-002）

- **发生时机**：点击 [开始识别] 后
- **触发条件**：智能化识别未能成功生成收文表单字段
- **判断依据**：外部识别能力返回失败或无结果
- **反馈形式**：弹窗内失败反馈区
- **系统反馈**：弹窗内展示识别失败提示，说明识别未成功；已选择的收文流程与已上传的文件保留
- **如何处理**：用户可重新上传文件或重新识别，任务重新开始；也可点击 [取消] 关闭弹窗，返回收文管控页面改用 [收文] 手工登记

### 异常 3 · 前置条件未满足（开始识别不可用）

- **发生时机**：弹窗打开至上传文件完成前
- **触发条件**：未选择收文流程，或未上传通过校验的公文文件
- **判断依据**：开始识别需收文流程已选且文件已通过格式与大小校验
- **反馈形式**：[开始识别] 置灰不可用
- **系统反馈**：[开始识别] 不可点击，避免无效识别
- **如何处理**：用户完成收文流程选择与合规文件上传后，[开始识别] 变为可用

### 7-2 智能收文弹窗

- **弹窗目标**：让收文办理人员选择收文流程、上传公文原始文件，由系统识别生成表单字段并填入收文表单。
- **触发条件**：在收文管控页面点击"智能收文"按钮。
- **适用角色**：收文办理人员（拥有收文管控菜单功能权限）。
- **结构**：弹窗承载，单页顺序组织，不拆分步骤。标题区（标题"智能收文"、副标题"您可以上传公文原始文件，智能化生成收文表单"）、收文流程区（下拉框，仅展示启用状态的收文流程，单选）、公文文件区（文件上传控件，支持 PDF、JPG、PNG、WORD，单文件不超过 100M，每次 1 个）、识别结果区（识别完成后单独展示识别生成的表单字段与取值）、操作区（[取消] [开始识别] 初始；[取消] [自动填入表单] 识别完成后）。

```
+-----------------------------------------------------------+
| 智能收文                                                   |
| 您可以上传公文原始文件，智能化生成收文表单                    |
```

## §9 附录：设计依据与设计推导

### 设计准则消费

| 使用依据 | 命中章节 | 转换结果 | 落点 |
|---|---|---|---|
| 弹窗承载轻量前置任务 | 交互模式 容器与工作区-弹窗 | 智能收文用弹窗承载，表单轻、需强制响应 | §0 D-001、§7 7-2 |
| 任务默认单页不拆分步骤 | 设计准则 BFM-01、BFM-02 | 弹窗内单页顺序组织，识别结果展示非独立阶段，不使用步骤条 | §0 D-002、§7 7-2 |
| 已知前置条件优先阻止错误 | 设计准则 U-05 错误预防与前置约束 | 未选流程或文件不合格时"开始识别"置灰 | §0 D-003、§6 异常3 |
| 状态与进展可见、异步结果分层 | 设计准则 U-01、交互模式 同步结果分层表达 | 识别中展示进度，识别成功或失败分层反馈 | §0 D-005、§8 |
| 局部可修正问题就地反馈 | 设计准则 F-06 按风险分级反馈、字段级校验反馈 | 文件校验失败在文件上传区就地提示 | §0 D-005、§6 异常1 |
| 异常可行动恢复 | 设计准则 U-09 可行动的恢复路径 | 识别失败可在弹窗内重新上传或重新识别 | §0 D-005、§6 异常2 |
| 子流程完成后回到原任务 | 交互模式 状态、反馈与恢复-结果返回原任务 | 自动填入后进入收文表单，沿用现有登记流程 | §0 D-006、§4 节点6-7 |
| 场景内触发入口 | 交互模式 入口与导航-场景内触发入口 | 智能收文入口放在收文管控页操作区 | §0 D-001、§7 7-1 |
| 候选直接选择 | 交互模式 对象选择与回填-直接选择 | 收文流程用下拉框直接单选，不引入复杂选择器 | §4 节点2、§7 7-2 |

| 上游来源 | 上游结论 | 对体验意味着什么 | 体验设计决策 | 落点章节 |
|---|---|---|---|---|

### 设计推导

| 已知输入 | 设计决定 | 正文落点 |
|---|---|---|
| 弹窗轻量、需强制响应、完成后离开原页 | 采用弹窗承载，排除抽屉（抽屉用于完成后回到原位置） | §0 D-001、§7 7-2 |
| 识别结果展示是动作结果，非独立配置阶段 | 单页内顺序呈现，不使用步骤条 | §0 D-002 |
| 识别为外部异步能力，用户需知道处理中状态 | 识别中展示进度并锁定输入 | §4 节点4、§8 |
