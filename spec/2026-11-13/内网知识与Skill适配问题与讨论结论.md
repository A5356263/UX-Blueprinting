# 内网知识与 Skill 适配问题与讨论结论

## 已确认的问题与方向

输出时间：2026-11-13 14:57:18 +08:00

- `only-x-cp` 用于内网 Agent 平台；平台已提供与 Agent 打通的知识检索能力，Skill 不需要指定平台名称或检索实现。
- 移除运行时 `knowledge-wiki` Skill，整理业务和设计知识，形成可整体导入平台的文件；知识维护、审核和索引工作由平台工程能力承接，不保留本地维护 Skill。
- 各 Skill 自行保留完成任务所需的知识消费规则，包括何时查询、查询内容、适用判断、来源与缺口处理。消除平台名称、本地知识目录、索引和文件导航等旧消费轨迹。
- 业务事实、业务规则和知识之间实际的业务关联均保留。`[GAP]`、`[QUESTION]`、`[CONFLICT]` 可作为明确标记的知识缺口或冲突保留；未经确认的候选事实不进入正式导入文件。
- README、索引和导航按内容判断：本地目录或维护指令不作为知识；包含独有正式知识时先完整迁入适当知识正文，不能随文件一并丢弃。
- 平台技术指南描述了语义切片、概念、事实、关系和溯源等机制；该描述不等于本次已验证内网部署的实际配置或导入、检索效果。

## 当前工作区已核对事实

输出时间：2026-11-13 14:57:18 +08:00

- 当前分支为 `only-x-cp`，`.agents/skills/` 有 16 个带 `SKILL.md` 的 Skill，其中包括 `knowledge-wiki`。
- 下游多个 Skill 已写有按任务检索知识的规则，但部分文件仍写有“萃知”、README、index、raw 或本地文件读取方式。
- `.agents/skills/knowledge-wiki/knowledge/raw/` 下现有 145 个 Markdown 文件，其中 34 个名为 README；知识正文存在顶部导航及跨文件引用。统计是当前工作区快照，不代表每个文件都应导入。
- `knowledge-wiki` 本身仍使用本地 index、raw、入库维护流程和脚本。仅将目录上传不能证明平台能正确切片、识别关联或保留规则语义。

## 源分支维护与变更记录的最新决定

输出时间：2026-11-13 15:37:34 +08:00

- `only-x-cp` 是持续产出内网版本的源分支，也是唯一知识维护源。内网知识库使用导入后的消费副本。
- 保留 `knowledge-wiki`，改为维护适合平台导入的源知识。业务 Skill 各自负责知识消费判断，由平台提供检索能力。本节更新此前移除维护 Skill 的结论。
- 对实际发生的知识变化做轻量记录，写清时间、增删改、内容与可定位的文件、章节或规则。删除及替换保留可识别旧知识的线索。
- 后续由 Agent 按用户指定范围提取变化，具体交付形式由用户当次决定。记录随源分支维护，知识正文单独交付内网。
