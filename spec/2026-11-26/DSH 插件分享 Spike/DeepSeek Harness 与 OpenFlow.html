DeepSeek Harness 插件能扩展什么？

从直接用、自己搭，到自己做模块。

  1. 直接用

    线上成品

    打开就能用，按已经设计好的界面和流程操作。

  2. 自己搭

    低代码平台

    用平台提供的表单、列表和流程节点，搭出自己需要的页面和流程。

  3. 自己做模块

    DSH 插件

    自己开发一块能力，决定它出现在哪里、能调用什么工具、按什么规则运行。

技能与工具
给 Agent 加做事方法和可以调用的动作。
运行逻辑
接入会话和工作区，让自己的规则运行起来。
产品界面
在客户端预留的位置加入口和专用页面。

和其他 Harness 怎么比？

看它开放了哪些扩展点。Claude Code 插件可以接工具和运行钩子。DSH 同时开放运行服务和客户端界面位置，开发者可以把两边接进同一个插件。

多个 Skill 接力，谁来交接？

上一个 Skill 做到哪了？下一步能不能开始、该用哪份结果？

实现方式怎么交接成本和稳定性

云端 Agent

怎么交接
主要用对话和 Skill 时，把规则写进 Skill。每次由 Agent 从对话和材料里判断进度、找交接的结果。
成本和稳定性
起步快。流程越长，交接越依赖 Agent 每次读对上下文、找到正确的材料。

支持工作区的 Agent

怎么交接
把状态和产物存到工作区，用脚本检查条件、把对应的文件交给下一个 Skill。
成本和稳定性
脚本判断可以做稳。还要接好谁来触发、怎么传入当前任务、用户在哪里确认。

DSH 插件

怎么交接
把用户操作接到业务代码。每次按当前任务的记录判断进度、走确认节点、交给下一步对应的材料。
成本和稳定性
前期要开发。交接规则可以反复验证，用户也能直接看到进度和下一步。

Skill 负责做好每一棒，程序负责记住跑到哪、什么时候能交棒、交哪份结果。
