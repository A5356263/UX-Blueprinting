# 领域：薪税代发

## 底层基座

- 员工
- 考勤结果
- 薪资项
- 算薪规则
- 计税规则
- 税务主体
- 银行账户
- 发薪批次
- 审批节点
- 工资单
- 对账 / 回单

## 核心链路

采集 → 算薪 → 核薪 → 报税 → 代发 → 工资单 → 对账 / 回单

## 关键元数据

- 薪资项
- 计税规则
- 发薪批次
- 批次状态
- 税务主体
- 税局
- 银行单
- 申报状态
- 代发状态
- 保密范围

## 高复杂度触发点

- 改算薪规则
- 改计税逻辑
- 改发薪批次状态机
- 改审批 / 生效机制
- 改多主体申报
- 改银行付款路径
- 改回单 / 对账链路
- 改工资明细保密和数据隔离方式

## 中等复杂度触发点

- 新增薪资项但复用现有计算引擎
- 增加失败明细查看
- 增加批次操作前确认说明
- 增加异常结果提示
- 增加工资条确认反馈
- 新增代发入口但沿用既有批次、主体和银行逻辑

## 低复杂度触发点

- 工资条布局
- 净额 / 应发字段展示
- 批次筛选布局
- 表头字段排序
- 结果态说明
- 失败提示文案
- 页面视觉强调

## UXB 判断提醒

- 不因为“工资、个税、银行”直接判高复杂度。
- 先看是否改算薪、计税、批次状态或外部回写。
- 如果只是工资条展示优化，按低复杂度处理。
