# 知识候选提醒规则

## 触发场景

- 知识问答
- 体验诊断
- 体验策略输出
- 正式蓝图完成
- 用户纠正 UXB 判断
- 讨论中形成可复用结论

## 触发条件

- 得到一个可复用判断
- 明确某类需求的判断边界
- 纠正现有规则或惯性误判
- 发现知识库缺少某类知识
- 发现现有知识容易误导后续判断
- 形成可复用的体验策略、业务判断或文案原则

## 不触发条件

- 一次性项目信息
- 用户个人偏好
- 结论不稳定
- 当前回复已经很长
- 同一轮对话已经提醒过
- 用户只需要一个非常短的答案

## 推荐格式

```md
这个结论可能值得沉淀进知识库：

- <可复用结论>

原因：它能帮助以后判断类似需求，避免重复讨论。
是否需要我整理成知识候选？
```

## 边界

- 不自动写入 `knowledge/`
- 不把聊天原文直接写入知识库
- 不把不稳定结论当成正式知识
- 用户确认后只整理为知识候选
