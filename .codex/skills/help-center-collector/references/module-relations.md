# 模块关系处理

如果页面出现跨模块关系，要同时记两层。

## 1. 在页面内记录

增加类似下面的小节：

```md
## 前置条件 / 依赖关系

- 使用该功能前，需要先完成 xxx。
- 当前配置会影响 xxx 模块。
```

## 2. 在全局索引记录

同时更新：

```text
help/_indexes/dependency-map.md
```

推荐表格：

```md
| 来源模块 | 依赖 / 影响模块 | 关系类型 | 原文依据 | 所在页面 |
|---|---|---|---|---|
```

关系类型可以包括：

- 前置条件
- 数据依赖
- 权限依赖
- 审批依赖
- 状态影响
- 配置影响
- 流程后置影响
