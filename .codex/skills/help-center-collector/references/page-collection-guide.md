# 单页采集与媒体处理

## 1. 页面模板

采集叶子页面时，默认使用 `assets/page-collection.template.md`。

至少要记录：

- 页面标题
- 所属模块和子模块
- 页面路径
- 面包屑
- 入口来源
- 内容类型
- 原始正文
- 操作流程
- 明确规则
- 字段或配置项
- 前置条件和依赖关系
- 图片信息
- 视频信息
- 注意事项
- 关联页面

## 2. 图片处理

当页面存在图片时：

1. 尽量拿到图片 URL。
2. 打开原图或截清晰图。
3. 用视觉能力识别图中的界面和文案。
4. 提取标题、按钮、字段、状态、提示文案和流程上下文。
5. 把识别结果写回对应的小节位置。

推荐记录格式：

```md
### 图片：图片说明

- 图片位置：
- 图片资源：
- 上下文：
- 可识别内容：
  - 标题：
  - 按钮：
  - 字段：
  - 状态：
  - 提示文案：
- 采集状态：已解析 / 部分解析 / 未解析
```

如果图片无法充分识别：

```md
> 图片存在，但当前工具无法完整识别图片细节。图片资源与上下文已记录到采集日志。
```

## 3. 视频处理

结合关键帧截图和周围文字说明做视频采集。

### 触发信号

- 页面上有视频播放器或视频教程入口
- DOM 中存在 `video`、`source` 或 `iframe`
- 网络请求中出现 `mp4`、`m3u8` 等视频资源
- 页面出现“视频教程”“播放”等入口词

### 采集步骤

1. 定位播放器或视频入口。
2. 截取开始、关键操作、结果状态等关键帧。
3. 识别关键帧中的界面和动作。
4. 结合周围文字补齐上下文。
5. 把解析结果写回对应文章位置。

### 输出格式

```md
### 视频：视频标题

- 视频位置：
- 视频资源：
- 解析状态：成功 / 部分成功 / 失败

#### 视频内容记录

按截图分析结果记录画面和关键操作。

#### 视频中的操作流程

1. xxx
2. xxx
3. xxx

#### 视频中的规则 / 注意事项

- xxx
```

### 降级方案

如果当前环境没有可用的多模态识别能力：

```md
> 视频存在，但当前模型不支持多模态，无法解析视频内容。视频入口、标题、上下文和资源地址已记录到采集日志。
```

详细失败说明放在 `help/_collection/failed-items.md`，不要写进正文。
