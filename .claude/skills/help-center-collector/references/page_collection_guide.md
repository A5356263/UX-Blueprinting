# 单页采集与媒体处理

## 1. 页面采集模板

采集每个页面时，使用 `assets/page_collection.template.md` 作为模板填充。

至少记录：页面标题、所属模块、页面路径、面包屑、入口来源、内容类型、原始内容、操作流程、明确规则、字段/配置项、前置条件/依赖关系、图片信息、视频信息、注意事项、关联页面。

---

## 2. 图片处理策略

当页面存在图片时：

1. 获取图片 URL。
2. 打开原图。
3. 保存图片或截图。
4. 使用当前模型的视觉能力识别图片内容。
5. 识别图片中的标题、按钮、字段、状态、提示文案、流程位置。
6. 将图片解析结果放回对应正文位置。

记录格式：

```md
### 图片：图片说明

- 图片位置：
- 图片资源：
- 上下文：
- 可识别内容：
  - 标题：
  - 按钮：
  - 字段：
  - 状态：
  - 提示文案：
- 采集状态：已解析 / 部分解析 / 未解析
```

如果无法识别：

```md
> 图片存在，但当前工具无法完整识别图片细节。图片资源与上下文已记录到采集日志。
```

## 3. 视频处理策略

利用当前模型的多模态视觉能力采集视频内容。

### 3.1 触发条件

- 页面存在视频入口或播放器
- DOM 中存在 `video` / `source` / `iframe`
- Network 中发现 `mp4` / `m3u8` / 视频资源
- 页面中出现"视频教程""播放""观看教程"等入口

### 3.2 采集步骤

1. 在浏览器中定位视频播放器。
2. 对视频关键帧截图（起始画面、关键操作步骤画面、结果画面等）。
3. 使用模型视觉能力直接分析截图中的界面、操作、文案。
4. 结合页面上视频周围的文字说明补充上下文。
5. 将解析结果放回对应页面、对应步骤或对应视频小节。

### 3.3 输出格式

```md
### 视频：视频标题

- 视频位置：
- 视频资源：
- 解析状态：成功 / 部分成功 / 失败

#### 视频内容记录

按截图分析结果记录画面、关键操作。

#### 视频中的操作流程

1. xxx
2. xxx
3. xxx

#### 视频中的规则 / 注意事项

- xxx
```

### 3.4 降级方案

如果当前模型不支持多模态、无法分析截图：

```md
> 视频存在，当前模型不支持多模态，无法解析视频内容。视频入口、标题、上下文、资源地址已记录到采集日志。
```

失败详情放到 `help/_collection/failed-items.md`，正文不写详细失败日志。
