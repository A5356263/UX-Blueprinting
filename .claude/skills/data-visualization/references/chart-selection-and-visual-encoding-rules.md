# 图表选择与视觉编码规则

## 1. 先确定表达意图

| 意图 | 优先图表 | 不应使用 |
| --- | --- | --- |
| 单个关键值 | metric_card + 口径说明 | 饼图、仪表盘 |
| 类别比较 | bar / grouped_bar | 面积难比较的气泡图 |
| 构成比较 | stacked_bar；类别少时可用表格 | 多层饼图 |
| 时间趋势 | line | 无时间顺序的连线图 |
| 分布与离群 | distribution | 只展示平均值 |
| 两变量关系 | scatter | 暗示因果的连线 |
| 阶段转化 | funnel | 无阶段顺序的数据 |
| 定量流量 | sankey | 无权重的关系 |
| 定性关系 | relationship_flow / mechanism_chain | 用线宽暗示规模 |

图表不适合或数据不足时，由调用方明确选择 `data_table`、`spec_only`，或在已有非空数据表与限制说明时选择 `degraded`；渲染器不得静默改写图表类型。

## 2. 正式渲染的必要语义

| 类型 | `formal` 必须具备 |
| --- | --- |
| `metric_card` | 单一数值、单位和时间窗口 |
| `bar` | 非空类别和非负数值 |
| `grouped_bar` | 至少两个非空系列；类别—系列组合唯一；各点有非负数值 |
| `stacked_bar` | 分组柱条件、非负数值及统一单位 |
| `line` | 不重复且有序的 X、数值 Y/value；数值 X 按单调顺序提供 |
| `distribution` | 上游已提供的明确分箱标签及其非负频数/比例；不得自行分箱或从原始样本计算频数 |
| `scatter` | 每点都有有限数值 X 和 Y；点之间不得连线 |
| `funnel` | 明确阶段、非负数值、不重复的顺序 X 和统一分母 |
| `data_table` | 非空列与至少一行 |

Objective 权威投影中既有的“核心指标卡组”和漏斗数组顺序继续由 Objective 专用报告消费；该兼容只限 `objective#/analysis_results/` 的确定性投影，不作为通用 chart-ready 输入的放宽规则。

## 3. 数值表达

- 百分比表示比例；百分点表示两个比例的绝对差。
- 同一图中的单位、分母、时间窗口和人群口径必须一致。
- 当前值、基线值、变化值和不确定区间分别编码。
- `observed`、`estimated`、`forecast`、`target`、`validated` 使用文字标签，不只靠颜色。
- 数值为零、缺失、不可比和未采集必须分别表达。
- 不截断坐标轴制造差异；确需截断时显著标注。
- 当前柱状图不提供正负发散编码；带符号值使用显式数据表，不得取绝对值绘制。

## 4. 图内标签

正式图表至少显示：

- 标题和表达意图；
- 指标名称、单位和时间窗口；
- 关键数值或可访问数据表；
- 来源引用；
- 限制和 epistemic status。

标签优先使用业务可理解名称。内部 ID 仅用于追溯，不作为默认展示标签。

## 5. 颜色与排序

- 同一状态在同一交付物中保持相同颜色。
- 正负、通过/失败、已验证/预测不得只靠红绿区分。
- 顺序来自时间、业务阶段或上游排序；Data Visualization 不重排优先级。
- 图例不超过读者可以直接辨识的数量；类别过多时显示 Top N 与“其他”，并保留完整表格。

## 6. 降级

- 无数值的 brief：输出选图与所需字段，不渲染虚构结果。
- 缺少可选维度：保留主图并写 caveat。
- 缺少该图表类型的必要语义：阻断 `formal`，返回具体缺项。
- `degraded` 必须同时有非空数据表和 caveat；只交付表格，不绘制原图形。
- 只有原始分布样本、没有已登记分箱时，不得发布 `formal distribution`；调用方可显式提交 degraded 数据表。
- 不支持的图表类型：拒绝输入；由调用方修正为受支持类型或明确提交数据表/规格。
- 不调用外部库补齐语义，不从现有数值推断分箱、顺序、转化率或关系权重。

## 7. 业务阶段与原始节点

- 原始事件或任务节点只有在上游提供明确业务阶段映射及其依据时，才能聚合并命名为“业务阶段”。
- 没有映射时可展示“任务节点流向”，但不得把节点图称为业务阶段桑基。
- Data Visualization 不猜测节点归并，不使用常见路径反推正式业务阶段。
