# 体验蓝图输出写作指南

这份指南只负责一件事：

**把 `experience_blueprint.md` 的写法固定下来。**

## 写作红线

1. 不重新裁决需求是否成立
2. 不绕过 UXB 自行判断能力形态
3. 不省略 UXB 明确强调的配置态、关闭态、回退态
4. 不用空泛表述替代具体页面结构和文案
5. 不在 `§6` 之外使用 ASCII 框图
6. 旅程图按角色独立绘制，阶段用目标命名，不混入 UI 操作词汇
7. 次交互流程保持步骤结构，不退化为概述
8. 状态文案使用统一口径表
9. 正文不暴露内部执行术语
10. 异常与阻断流程是正式内容，不是附录

## 失败条件

1. 缺少旅程图、主流程或异常流程
2. 把设计参考写成自动路由或内部判断说明
3. 页面文案是元指令而不是用户可见文本
4. 依赖未装配知识或自行脑补 guideline
5. 只展开单一路径主流程，异常与阻断明显薄弱
6. 在 `§6` 之外使用 ASCII 框图
7. 通过体验蓝图重新判断需求是否成立或能力形态
8. 页面设计停留在功能罗列，没有结构和反馈落点
9. 旅程图从展示层反推
10. 状态模块是长段流程复述而非统一口径表

## 合格标准

1. 读完后能清晰知道谁在什么场景下做什么、系统如何响应
2. 主流程、次流程、异常与页面承接清晰
3. 旅程图按角色独立存在，阶段划分清晰
4. 状态模块为统一口径表，而非长段流程复述
5. 正文不暴露内部执行术语
6. `§5` 不是附录，且至少说明触发条件、系统反馈、用户下一步
7. `§6` 能体现结构化空间、信息层级和异常状态下的结构变化
8. ASCII 框图只出现在 `§6`
9. 明确承接 UXB 中提出的边界、风险和保护策略

## 各章节写法

### `§0` 本次关键设计判断

- 用一句话说明本次体验方案准备怎么处理
- 再写主要影响、建议方案、不建议方案、关键待确认
- 开头只保留用户需要优先阅读的判断，不在 `§0` 展示完整承接追踪表

### `§1` 旅程图

- 一个角色一张旅程图
- 阶段名称用目标命名
- 每阶段写用户目标、关键触点、用户信心、痛点
- 补上阶段间过渡
- 旅程痛点必须来自 UXB 判断或体验阶段已消费的知识，不能凭空写

### `§2` 交互流程总览

- 展示分角色交互流程
- 单列异常流程重点
- 关键节点可与 `§3` 建立任务名称和角色路径对应

### `§3` 主交互流程

- 每个节点必须写用户动作、系统反馈、前置解释、建议文案、下一步
- 节点是完整任务，不是单次点击
- 必须覆盖 UXB 定义的核心角色和功能单元

### `§4` 次交互流程

- 每个次流程至少包含：触发条件、用户动作、系统反馈、下一步
- 复杂流程按需补充：需要前置解释的信息、建议文案
- 不需要为了凑格式把每个次流程都写满所有字段
- 不退化成纯数字步骤列表或概述段落

### `§5` 异常与阻断流程

- 每个异常写发生时机、触发条件、判断依据、反馈形式、系统反馈、用户下一步
- 如果需要补救路径，也要写清楚
- 必须覆盖 UXB 中对体验有影响的关键异常与阻断

### `§6` 页面 / 弹窗 / 抽屉设计

- 页面优先写明：页面目标、进入条件、页面结构、按钮、成功反馈、失败反馈
- 有加载态、空状态、审批中、已关闭、异常态时，应补“状态反馈区”
- 有按钮置灰、入口隐藏、阻断弹窗、错误校验时，应补“异常状态下的结构变化”
- 有关键提示、字段、弹窗或 toast 时，应补“具体文案”
- 弹窗优先写明：弹窗目标、触发条件、弹窗结构、具体文案、按钮、成功反馈、失败反馈
- 抽屉优先写明：抽屉目标、进入条件、抽屉结构、具体文案、按钮、成功反馈、失败反馈
- 表单类抽屉应补字段校验、提交前校验和提交失败反馈
- 如果当前场景没有合理内容，不要为了凑结构保留空字段或空小节
- 页面结构部分可使用 ASCII 框图

### `§7` 状态与反馈文案

- 用统一状态口径表
- 不重复完整流程说明
- 必须覆盖 UXB 已定义的核心状态与关键反馈口径

### `§8` 待确认问题

- 每条写问题标题、影响、建议确认方
- 若上游主方案未闭合，明确标注“基于推荐方案推进”

### `§9` 附录：设计指南消费说明

- 记录设计准则如何转成体验策略
- 记录业务知识如何影响设计判断
- 记录知识缺口及影响模块
- 命中知识后，从 index 按实际入口进入必要 README 或单一 raw，只读明确命中的文件或章节；不要把路由层当作正式事实
- 要能回看“UXB 判断 → 设计转译 → 正文落点”是否闭环
- 在附录中新增 `UXB 承接追踪` 表，固定包含：`UXB 判断 / 对体验意味着什么 / 体验设计决策 / 落点章节`
