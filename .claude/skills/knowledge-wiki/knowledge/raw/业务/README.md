# 业务知识库

## 这是什么

这是业务领域知识库的总路由入口，用来说明各业务域目录分别承载什么知识、遇到什么问题该优先进入哪个域。

它不承载正式业务事实正文，也不承载主链路消费说明。

## 业务域

- `权限管理/` — 谁在什么条件下对什么资源可以做什么，以及结果何时生效
- `组织架构/` — 企业组织视图、部门、岗位等结构知识
- `成员管理/` — 成员身份、接入、退出、成员组等基础知识
- `应用管理/` — 应用可见范围、功能权限、应用生命周期
- `审批管理/` — 审批流程、审批节点、审批规则
- `安全管理/` — 安全策略、访问控制、数据安全
- `企业设置/` — 企业级配置与管理设置
- `服务管理/` — 服务开通、服务配置、服务生命周期
- `工作台与全局入口/` — 平台公共入口、工作台承载内容、全局导航
- `账户与企业生命周期/` — 企业开通、账户管理、生命周期阶段
- `项目背景/` — 平台定位、产品范围、角色终端、能力版图
- `协同办公/` — 协同工具、智能报表等协同办公能力
- `费用管理/` — 差旅、报销、对公报账、通用配置
- `人事服务/` — 组织管理、员工管理、招聘、假勤、客户管理

## 任务触发索引

- 需要理解某个业务域的整体边界与事实：进入对应域目录，先读 `00_领域概述.md`
- 需要定位某个具体知识在哪个文件：进入对应域目录，先读 `README.md` 的编号段说明
- 需要跨域关联理解：先在各域 `00_领域概述.md` 中确认上游依赖关系，再进入对应域

## 维护原则

- README 只做域间路由，不写正式业务规则正文
- 正式业务事实写入对应域编号文件
- 新增业务域时，在下方新增目录并在本文档中追加条目
- 不在本目录中沉淀主链路消费地图、蓝图移交说明或下游执行指令
- 做结构替换时不保留兼容层，确认替换后直接移除旧知识位
