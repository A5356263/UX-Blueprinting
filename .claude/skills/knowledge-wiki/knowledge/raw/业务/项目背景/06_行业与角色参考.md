# 06_行业与角色参考

## 典型用户角色

| 角色 | 核心痛点 | 薪福通能力 |
|------|----------|------------|
| 老板 | 多维度数据监测、成本可控 | 多端审批、BI 看板、成本分析 |
| 财务 | 代发工资、个税管理、票财税一体化 | 秒级代发、个税统一管理、智能记账 |
| HR | 入转调离、考勤算薪、社保管理 | 一键办理、灵活考勤、复杂薪资规则 |
| IT | 系统对接、应用定制 | API、低代码、BI 可视化 |
| 员工 | 开卡、打卡、报销、查工资 | 扫码开卡、移动打卡、报销申请 |

## 行业方案参考

| 行业 | 核心痛点 | 关键能力 |
|------|----------|----------|
| 制造业 | 人员流动频繁、计时计件工资复杂 | 灵活排班、产量数据采集、计时计件工资 |
| 国有企业 | 政策合规、编制管控、数据安全 | 编制管控、人事任免、预算管理 |
| 科技行业 | 项目费用管控、多系统对接 | 弹性打卡、项目费用分摊、对接钉钉/飞书 |
| 零售连锁 | 总部-门店信息不通、算税发薪主体多 | 总部集中人事管理、门店调度、统一核算 |
| 集团企业 | 多主体统一管理、权限隔离 | 集团代发、多税局管理、权限隔离 |
| 人力资源 | 招聘入职、社保算薪、多角色协同 | 扫码入职、社保管理、个税算报缴 |
| 医院 | 药品耗材采购结算 | 采购下单、自动入库、线上对账、发票查验 |

## 技术特色

- 银行级安全：等保三级认证、CQC A 级认证、ISO20000 认证、数据安全分级保护。
- 开放集成能力：支持 API 接口、办公平台对接、配置化连接和低代码应用搭建。
- 数据能力：支持内置报表、多图表类型和多维度可视化。

## [GAP] / [CONFLICT] / [QUESTION]

- [QUESTION] API 数量、报表数量、图表数量等具体数字需要以最新官方材料复核后再作为稳定指标使用。
