# 工作台与全局入口

## 这是什么

这是工作台与全局入口领域的二级路由入口，用来说明这个目录里各编号段分别承载什么知识、遇到什么问题该优先看哪些文件。

本 README 承载领域契约与任务路由；具体业务规则仍保留在对应编号文件中。


## 领域契约

### 领域定义

工作台与全局入口领域回答的是：
平台的公共入口、工作台承载内容、全局导航和服务入口如何组织和呈现。

它覆盖的不是单一页面，而是一整套与平台入口架构相关的业务语义，包括：

- 工作台：平台的核心承载页面，聚合各业务域的入口和内容
- 全局导航：跨业务域的统一导航体系
- 服务入口：各业务服务的入口位置和呈现方式

### 解决的问题

工作台与全局入口领域主要用于解释以下问题：

- 平台工作台承载什么内容、扮演什么角色
- 全局导航如何组织各业务域的入口
- 服务入口如何布局和呈现
- 不同角色（管理员、员工）看到的工作台和入口有何差异

### 为什么独立成域

工作台与全局入口需要独立沉淀，是因为它同时具备以下特征：

- 是平台的公共入口层，不是某个业务域的内部页面
- 工作台的承载内容和入口布局影响所有用户的首次体验和日常导航
- 与各业务域有明确的上下游关系：工作台聚合各域的入口，但不定义各域的内部规则

### 与下游领域的关系

- 工作台聚合各业务域的入口卡片和内容区块
- 全局导航为各业务域提供统一的导航框架
- 服务入口的可见性依赖权限域的授权结果

这里描述的是下游聚合关系，工作台与全局入口作为平台入口层承载各业务域的入口。

### 稳定结论

- 工作台与全局入口是平台公共入口架构的承载域
- 其核心价值是为工作台承载、全局导航和服务入口布局提供稳定输入
- 它可以服务业务分析、产品设计、体验解释和排障分析，但本文件本身不承载下游消费说明

### 显式缺口

- [QUESTION] 工作台承载内容是否随角色和权限动态变化，其规则是否已完全清晰，需结合权限域持续校验
- [QUESTION] 全局导航的扩展机制是否已稳定，新增业务域入口的接入规范待明确
