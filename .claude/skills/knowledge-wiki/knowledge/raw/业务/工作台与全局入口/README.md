# 工作台与全局入口

## 这是什么

这是工作台与全局入口领域的二级路由入口，用来说明这个目录里各编号段分别承载什么知识、遇到什么问题该优先看哪些文件。

它不承载正式业务事实正文，也不承载主链路消费说明。

## 编号段

- `00-09`：领域定义、范围与边界
- `10-19`：工作台承载内容与全局导航服务入口

## 任务触发索引

- 需要理解本域的边界与主题：读 `00_领域概述.md`
- 需要理解工作台的承载内容与入口角色：读 `10_工作台.md`
- 需要理解全局导航与服务入口的组织方式：读 `11_全局导航与服务入口.md`

## 维护原则

- README 只做领域内路由，不写正式业务规则正文
- 正式业务事实写入对应编号文件
- 不在本目录中写业务域内部规则、审批细则或权限算法
- 不在本目录中沉淀主链路消费地图、蓝图移交说明或下游执行指令
- 做结构替换时不保留兼容层，确认替换后直接移除旧知识位
