## 公共按钮

### 打印

| 属性 | 说明 |
|------|------|
| 控制方式 | 纯前端控制 |
| 容器限制 | 薪福通 App、招银 App |
| 配置项 | `expBillInsDto.printStatus`（默认开启） |
| 显示状态 | 发起人同审批人：审批中、审批完成显示；撤回、退回、否决、作废、变更中等状态不显示 |

### 评论

| 属性 | 说明 |
|------|------|
| 控制方式 | 纯前端控制 |
| 配置项 | 系统设置 → 单据设置 → 评论管理 |
| 申请人显示 | 除否决和作废外均显示 |
| 审批人显示 | 审批中、审批完成、被退回、被否决、变更中 |

## 前置条件

- 提交审批前需要完成表单必填项与字段格式校验。
- 保存校验通过后，可触发智能审核，覆盖超标、超预算、费用合规性、发票合规性等企业自定义审核项。
- 强校验项必须修改后才能提交；弱校验项支持填写异常原因后提交。
- 支付、打印、评论等操作受单据状态、容器、配置项和角色影响。

## 审批流选择

- 企业可配置是否需要用户选择审批人。
- 配置多条审批流程时，用户可选择其中一条审批流。
- 没有多条审批流时，用户可直接选择审批人。
- 企业也可配置无需选择审批人，由默认规则自动分配。

- [QUESTION] 不同单据类型在移动端、Web 端、招银 App、薪福通 App 中的按钮可见性差异需要继续核对。
