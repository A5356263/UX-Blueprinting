## 员工提单

### 表单填写

| 功能 ID | 功能名称 | 功能说明 |
|---|---|---|
| EMP-FORM-01 | 提单入口 | 从工作台首页「我要报销」及其他企业自定义入口进入提单流程 |
| EMP-FORM-02 | 选择单据类型 | 选择报销单、申请单、借款单等单据类型（企业可配置展示对应单据类型的使用说明） |
| EMP-FORM-03 | 自动带入公司信息 | 提单时自动带入当前提单人的公司信息 |
| EMP-FORM-04 | 代理他人提单 | 支持授权代理人代为他人提单 |
| EMP-FORM-05 | 填写表单信息 | 表单字段由企业自定义配置（可能包含行程组件、费用组件、申请单组件、合同组件等） |
| EMP-FORM-06 | 保存草稿 | 保存当前填写进度，崩溃后可恢复 |
| EMP-FORM-07 | 退出二次确认 | 退出时弹窗确认，避免已填信息因误操作丢失 |

### 校验处理与 AI 辅助

| 功能 ID | 功能名称 | 功能说明 |
|---|---|---|
| EMP-CHK-01 | 保存时校验 | 点击【保存】时进行必填项校验和字段格式校验 |
| EMP-CHK-02 | 智能审核校验 | 保存校验通过后进行智能审核（超标、超预算、费用合规性、发票合规性等企业自定义审核项） |

| EMP-CHK-07 | 重新检测 | 处理后重新触发检测，通过后可提交 |
| EMP-CHK-08 | AI解释异常校验项 | 击中考评时，可通过AI辅助解释异常校验项 |
| EMP-CHK-09 | AI给出修改意见 | AI针对异常校验项给出修改意见 |
