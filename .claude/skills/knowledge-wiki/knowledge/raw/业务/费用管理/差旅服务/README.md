## 领域契约

### 领域定义

差旅服务领域回答的是：
企业如何通过薪福通平台完成出差申请、商旅预订、差旅报销和自动支付的全流程线上管理。

它覆盖的不是单一出差动作，而是一整套与差旅费用管控相关的业务语义，包括：

- 费用管控：差标政策、预算方案、超标预警
- 多平台对接：携程商旅、同程商旅、E餐通、美团商企通
- 外币报销：Visa/Master 商务卡、自动汇率或公司制定汇率
- 自动报销：出差结束自动创建报销单、智能填充、自动计算补贴
- 多次出差合并报销：发票行程一一对应、补助自动计算

### 解决的问题

差旅服务领域主要用于解释以下问题：

- 出差申请如何发起和审批
- 商旅预订如何对接携程、同程、美团等平台
- 差旅费用如何按差标政策和预算方案管控
- 出差结束后如何自动生成报销单
- 外币出差如何报销、汇率如何确定
- 多次出差如何合并报销

### 为什么独立成域

差旅服务需要独立沉淀，是因为它同时具备以下特征：

- 有完整的业务闭环：出差申请 → 商旅预订 → 报销 → 支付
- 涉及与携程、同程、美团等多个外部商旅平台的对接
- 具备强规则性：差标政策、预算方案、超标预警、汇率规则
- 支持外币报销和多次出差合并报销等复杂场景

### 与上游领域的关系

- 与 OA 审批集成：出差申请和报销单审批
- 与费用管理-通用配置交叉：差标政策、预算方案由通用配置定义
- 与招商银行代发集成：报销支付
- 与携程/同程/美团等商旅平台对接：所有费用对公月结

这里描述的是上游依赖事实，不等于具体规则已经由其他领域定义完成。

### 稳定结论

- 差旅服务是企业差旅费用管控的核心子域
- 其核心价值是为差旅申请、预订、报销和支付提供稳定输入
- 它可以服务业务分析、产品设计、体验解释和排障分析，但本文件本身不承载下游消费说明
