# 日常报销

## 这是什么

这是日常报销子域的二级路由入口，用来说明这个目录里各编号段分别承载什么知识、遇到什么问题该优先看哪些文件。

它不承载正式业务事实正文，也不承载主链路消费说明。

## 编号段

- `00-09`：领域定义、范围与边界
- `10-19`：日常报销全流程产品知识（提单、审批、支付、记账）
- `50-59`：日常报销、费用申请、借还款常见问题与外部口径

## 任务触发索引

- 需要理解日常报销子域的边界与覆盖范围：读 `00_领域概述.md`
- 需要理解日常报销产品功能：读 `10_日常报销.md`
- 需要查询费用报销、费用申请、借还款的常见问题：读 `50_常见问题.md`

## 维护原则

- README 只做领域内路由，不写正式业务规则正文
- 正式业务事实写入对应编号文件
- 新知识优先落到对应编号模块
- 不在本目录中沉淀主链路消费地图、蓝图移交说明或下游执行指令
- 做结构替换时不保留兼容层，确认替换后直接移除旧知识位
