## 核心事务总览

### 日常报销

员工形成报销单并关联费用、发票、订单或申请单等对象 → 执行适用校验 → 提交审批 → 财务处理 → 支付处理 → 形成支付结果和可查询记录。

### 费用申请与转报销

员工在费用发生前发起费用申请并记录预计费用 → 审批或预算处理 → 报销单关联已批准的申请与费用 → 按当前规则处理预算结果 → 进入报销审批和后续支付。

### 借款、还款与核销

员工或供应商发起借款或预付申请 → 审批完结后进入支付 → 通过还款或报销核销清偿金额 → 形成已结清、待处理或关闭结果。

### 差旅申请、预订与报销

员工发起出差申请并维护行程 → 申请达到企业配置的节点后进入预订或推送 → 形成订单、消费或费用对象 → 关联差旅报销单 → 审批、结算或支付。

### 企业支付

基于供应商、合同、对公报账或预付款形成付款事项 → 审批 → 对本次应付金额发起支付或完成核销 → 留存支付、回单或剩余付款结果。

### 消费订单与月结对账

第三方平台同步订单或企业上传月结账单 → 创建并执行对账任务 → 对账成功后结算，失败后按状态处理并重新对账 → 形成订单、结算和台账记录。

## 任务场景

### 典型任务

- 员工发起报销：形成报销单，关联费用、发票、订单或申请单，处理校验后提交审批。
- 员工发起出差：形成出差申请，维护行程，按企业差旅政策进入预订、报销和结算。
- 财务审核单据：查看单据详情、费用明细、发票详情和审核结果，处理修改、变更、支付和台账。
- 管理员配置费用体系：配置费用类型、表单、管控规则、预算、支付、核算和界面展示。
- 企业管理商旅消费：开通商旅平台，管理员工预订、订单、月结对账和商务卡。
- 管理层查看费用数据：查看员工、部门、流程效率、合规、借款、订单和预算相关报表。

### 触发条件

- 员工存在差旅、日常报销、借款、费用申请或企业消费需求。
- 企业需要对费用标准、预算、发票、审批或支付进行管控。
- 财务需要完成审核、支付、记账、对账或台账管理。
- 管理员需要配置单据、表单、流程、预算、支付或核算规则。

### 参与角色

- 员工：发起申请、报销、借款、预订和费用提交。
- 审批人：审批、退回、否决、加签、转派或评论单据。
- 财务人员：审核、修改、签收发票、处理借还款、台账和支付。
- 管理员：配置费用体系、表单流程、预算、支付、核算和商旅平台。
- 管理层：查看费用、预算、流程效率和合规分析报表。

## 事务补充

### 日常报销补充任务

#### 代理提单


1. 用户或管理员建立代理授权。
2. 代理人代被代理人发起并提交报销任务。
3. 单据记录被代理人为申请人、代理人为制单人。

代理资格和发票采集边界读取 [代理权限与归属](规则与权限.md#代理权限与归属)。

### 费用申请与转报销补充任务

#### 申请转报销与预算


1. 费用事前申请在费用发生前记录预计费用类型和金额。
2. 报销单关联费用申请后，可直接带入已申请费用。
3. 系统按当前预算规则和单据状态处理预算释放、冻结或占用结果。

预算条件读取 [预算管控](规则与权限.md#预算管控)，状态结果读取 [预算状态](状态与异常.md#预算状态)。

### 企业支付补充任务

#### 预付款核销与剩余付款


1. 员工提交对公报账单，录入费用、发票和付款明细。
2. 关联可核销的预付款，并确定本次核销金额。
3. 系统计算应付金额、核销预付款和本次实付金额。
4. 审批完成后，财务对本次实付金额发起支付；本次实付为零时只完成核销，不产生支付任务。

#### 分期支付

1. 首次对公报账单录入费用、发票和付款明细，并支付部分金额。
2. 未支付的剩余付款明细进入冻结状态。
3. 后续通过付款申请单关联该付款明细。
4. 付款申请审批完成后解除冻结，并进入后续支付处理。

#### 预付款关闭

- 已审批但取消支付的预付款，在预付关闭中处理；关闭后不再进入对公支付。

### 消费订单与月结对账补充任务

#### 月结对账与结算

1. 企业上传月结账单并创建对账任务。
2. 系统输出对账结果；失败账单按状态处理后重新对账。
3. 对账成功的账单可以进入结算。
4. 月结账单可在需要时关联对公报账单或费用报销单，并进入凭证结转。

### 借款、还款与核销补充任务

#### 借款支付

1. 借款单审批完结后进入待支付。
2. 员工借款进入对私支付；供应商借款进入对公支付。
3. 财务按企业已配置的支付方式发起支付。
4. 待支付状态下，管理员可以修改收款账户。
5. 审批未完结时，由当前审批人退回申请人修改后重新提交。

#### 还款


- 员工可以提交还款单，财务也可以在借还款管理中直接确认还款。
- 还款单启用自动还款时，流程完成后借款进入已结清。
- 未启用自动还款时，还款单审批完成后仍需财务执行还款复核并确认还款。

#### 借款核销


- 核销通过报销单清偿借款；还款通过归还资金清偿借款。
- 借款可以分多次核销，直至金额全部清偿。
- 财务可以在借还款管理中手动确认核销。

#### 借款关闭


- 已审批但不再支付的员工借款，由财务或有权限的管理员执行借款关闭。

#### 借款共享与代理


- 借款类型启用共享后，申请人可以把借款共享给其他员工并填写共享备注。
- 借款代理必须先建立代理授权；代理关系不等于借款共享关系。

### 差旅申请、预订与报销补充任务

#### 出差申请变更


1. 企业配置允许变更申请单。
2. 审批通过且未被关联的出差申请单可以发起变更任务。
3. 变更后重新提交审批。
4. 同一申请单支持多次变更。

#### 同行人任务关系


- 已加入申请单的同行人不需要重复提交出差申请。
- 同行人可以分别提交自己的报销单，但受申请单可关联次数约束。
- 一个报销单也可以为多个同行人一起报销；分别付款时，收款账户必须为个人账户。

#### 申请单与商旅预订


1. 企业按商旅平台设置预订所需的申请单类型和审批节点。
2. 申请单达到已配置节点后，可进入商旅预订或推送流程。
3. 申请单中心未自动推送时，只允许员工本人手动推送。
4. 推送失败且满足传输条件时，进入服务排查，不推断自动恢复结果。
