# 费用管理

## 这是什么

这是费用管理业务知识库的二级路由入口，用来说明各子域目录分别承载什么知识、遇到什么问题该优先进入哪个子域。

它不承载正式业务事实正文，也不承载主链路消费说明。

## 子域

| 子域 | 说明 |
|------|------|
| `差旅服务/` | 出差申请、商旅预订、差旅报销、自动支付全流程 |
| `日常报销/` | 员工日常费用报销全流程 |
| `企业支付/` | 供应商管理、合同管理、付款申请、对公付款 |
| `通用配置/` | 系统配置、支付管理和会计核算 |

## 任务触发索引

- 需要理解费用管理整体边界：读 `00_领域概述.md`
- 需要查看费用管理整体能力结构：读 `10_能力地图.md`
- 需要理解费用管理典型任务和角色路径：读 `11_任务场景.md`
- 需要理解单据状态、审批流转和操作状态：读 `13_状态与流程.md`
- 需要判断费用管理使用边界与不适用场景：读 `15_边界与限制.md`
- 需要判断需求归属、预算、移动端和集成规则：读 `20_决策规则.md`
- 需要理解某个子域的具体知识：进入对应子域目录，先读该子域的 `README.md`
- 需要跨子域关联理解：先在各自域的 `00_领域概述.md` 中确认关系，再进入对应子域

## 维护原则

- README 只做子域路由，不写正式业务规则正文
- 正式业务事实写入对应子域编号文件
- 按帮助中心产品模块结构组织，保持与用户可见产品语言一致
- 不在本目录中沉淀主链路消费地图、蓝图移交说明或下游执行指令
- 做结构替换时不保留兼容层，确认替换后直接移除旧知识位
