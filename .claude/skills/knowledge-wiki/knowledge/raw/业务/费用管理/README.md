# 费用管理

## 这是什么

这是费用管理业务知识库的文件级路由入口，用来说明领域边界、正式文件责任，以及如何在文件内定位业务主题。

本 README 承载领域契约与任务路由；具体业务规则仍保留在对应语义文件中。


## 领域契约

### 领域定义

费用管理领域回答的是：
企业如何通过薪福通平台完成从出差申请到报销支付、从对公采购到供应商付款的全链路费用管控。

它覆盖的不是单一报销动作，而是一整套与企业费用管控相关的业务语义，包括：

- 差旅服务：出差申请 → 商旅预订 → 报销 → 支付全流程
- 日常报销：提单 → 审批 → 支付 → 记账全流程
- 企业支付：供应商管理 → 合同管理 → 付款申请 → 对公付款
- 通用配置：系统配置、支付管理、会计核算

### 解决的问题

费用管理领域主要用于解释以下问题：

- 企业如何管控差旅费用（差标政策、预算方案、超标预警）
- 员工日常费用如何报销（发票验真验重、审批、支付、记账）
- 企业对公付款如何管理（供应商、合同、付款场景、外币支付）
- 费用管理系统如何配置（打印模板、预算方案、支付方式、会计核算）

### 为什么独立成域

费用管理需要独立沉淀，是因为它同时具备以下特征：

- 是薪福通平台的核心一级模块，覆盖企业费用管控全流程
- 涉及与多个外部系统深度集成：招商银行（代发/云直联/CBS）、国税局（发票验真）、携程/同程/美团（商旅平台）
- 差旅、日常报销、企业支付和通用配置高度关联，共同构成费用管控闭环
- 具备强规则性：差标政策、预算方案、费用政策、超标管控

### 与上游领域的关系

- 与 OA 审批集成：报销单审批流程通过 OA 审批配置
- 与招商银行代发/云直联/CBS 集成：支付能力
- 与智能记账集成：凭证自动生成推送
- 与国税局接口对接：发票验真验重
- 与携程/同程/美团等商旅平台对接

这里描述的是上游依赖事实，不等于具体规则已经由其他领域定义完成。

### 稳定结论

- 费用管理是企业费用管控的核心域，覆盖差旅、报销、对公付款、配置四大业务主题
- 其核心价值是为费用管控规则、报销流程、支付能力和凭证生成提供稳定输入
- 它可以服务业务分析、产品设计、体验解释和排障分析，但本文件本身不承载下游消费说明

## 条件依赖与回主域

- 先按问题确定直接负责的固定文件和业务主题，不因出现“费用”通读全部文件或全部主题
