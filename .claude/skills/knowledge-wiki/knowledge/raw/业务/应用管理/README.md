# 应用管理

## 这是什么

这是应用管理领域的二级路由入口，用来说明这个目录里各编号段分别承载什么知识、遇到什么问题该优先看哪些文件。

本 README 承载领域契约与任务路由；具体业务规则仍保留在对应编号文件中。


## 领域契约

### 领域定义

应用管理领域回答的是：
企业已启用应用的治理规则、应用可见范围管理和组装应用的业务语义。

它覆盖的不是单一应用配置，而是一整套与应用生命周期治理相关的业务语义，包括：

- 应用治理：企业已启用应用的管理规则
- 应用可见范围：谁能看到和使用哪些应用
- 组装应用：应用的组合与扩展方式

### 解决的问题

应用管理领域主要用于解释以下问题：

- 企业已启用应用如何治理和管理
- 应用的可见范围如何设定
- 组装应用的机制是什么
- 应用管理与权限域的关系是什么

### 为什么独立成域

应用管理需要独立沉淀，是因为它同时具备以下特征：

- 关注的是应用粒度的治理和可见性，与权限域的用户授权是不同的关注层面
- 组装应用是一种应用扩展机制，有独立的业务语义
- 应用可见范围是权限判断的上游输入

### 与上游领域的关系

- 应用可见范围是权限域授权判断的上游输入
- 应用管理依赖企业设置域的企业基础信息

这里描述的是上游依赖事实，不等于具体规则已经由其他领域定义完成。

### 稳定结论

- 应用管理是企业应用治理和可见范围管理的承载域
- 其核心价值是为应用治理、可见范围和组装应用提供稳定输入
- 它可以服务业务分析、产品设计、体验解释和排障分析，但本文件本身不承载下游消费说明

### 显式缺口

- [GAP] 组装应用的具体机制和约束待进一步明确
- [QUESTION] 应用管理与权限域在可见范围层面的分工边界是否已完全清晰，需持续校验
