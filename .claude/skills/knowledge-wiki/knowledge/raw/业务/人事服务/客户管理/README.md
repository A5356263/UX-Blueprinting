# 客户管理

## 这是什么

这是客户管理子域的二级路由入口，用来说明本子域承载什么知识、遇到什么问题该优先看哪些语义文件。

本 README 承载领域契约与任务路由；具体业务规则仍保留在对应语义文件中。


## 领域契约

### 领域定义

客户管理领域回答的是：
人力资源服务企业（劳务派遣/人力外包）如何通过薪福通平台管理客户的全生命周期。

它覆盖的不是单一客户记录，而是一整套与客户业务相关的语义，包括：

- 客户档案管理
- 合同管理
- 项目管理
- 用工管理
- 账单模板与账单管理
- 垫款管理

### 解决的问题

客户管理领域主要用于解释以下问题：

- 人力资源服务企业如何管理客户档案、合同和项目
- 人员如何分配到项目、用工记录如何关联花名册
- 薪资数据如何驱动账单生成
- 账单如何审批、推送账款、开票、回款和确认
- 垫款管理如何通过 OA 审批流驱动

### 为什么独立成域

客户管理需要独立沉淀，是因为它同时具备以下特征：

- 专为人力资源服务企业（劳务派遣/人力外包）设计，有独立的业务场景和用户群
- 有完整的业务闭环：客户档案 → 合同 → 项目 → 用工 → 薪资 → 账单 → 账款 → 回款
- 与智能算薪、账款管理、OA 审批等多个系统深度集成
- 与员工管理域存在用工记录交叉，但业务语义独立

### 与上游领域的关系

- 与智能算薪/税前工资算税深度集成：薪资数据驱动账单生成
- 与账款管理集成：推送应收单、回款/开票状态自动回写
- 与 OA 审批集成：账单审批流、垫款审批流
- 与员工管理交叉：花名册指定项目、用工记录

这里描述的是上游依赖事实，不等于具体规则已经由其他领域定义完成。

### 稳定结论

- 客户管理是人力资源服务企业的核心业务域，有完整的业务流程闭环
- 其核心价值是为客户生命周期管理、账单生成和账款追踪提供稳定输入
- 它可以服务业务分析、产品设计、体验解释和排障分析，但本文件本身不承载下游消费说明
