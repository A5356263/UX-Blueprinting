# 功能与操作清单

- 来源：help/modules/人事服务/员工管理/
- 来源类型：帮助中心产品介绍 + 15篇操作指引 + 已拆解旧raw
- 最近更新：2026-06-23

## 能力清单

### 1. 员工花名册管理

员工数据的核心载体，聚合展示员工档案、任职记录、合同档案、个税档案、项目用工记录五部分数据。

- 字段配置：三级属性（可见/可改/必填），支持系统预设字段和自定义字段（单行文本/多行文本/日期/单选/多选/数值/附件七种类型），自定义字段可关联OA表单
- 新增员工：单个新增 + 批量导入（三种模式：新增/修改/无则新增有则修改）
- 导入花名册：整合统一入口，支持AI智能解析（15秒）、多Sheet页、表头匹配、业务校验
- 导出花名册：全景档案导出 / 自定义导出 / 导出员工材料
- 批量修改：通过导入花名册的"修改"模式批量更新
- 筛选项：自定义筛选项和排序，可保存筛选方案
- 表头设置：自定义显示列、部门展示层级
- 员工档案库：单条新增或批量导入教育经历/工作经历/家庭成员/专业证书/奖惩记录等
- 同步工资卡/数币钱包：一键同步银行卡信息
- 历史花名册：支持下载历史备份

### 2. 员工关怀

- 员工生日和入职周年时自动发送消息提醒
- 支持发送生日红包和周年红包
- 提醒内容、提醒时间、适用范围可自定义编辑
- 可向汇报上级、组织负责人、审批主管、自定义人员同步发送提醒

### 3. 人事统计报表

新版基于智数报表平台，旧版已下架。

- 在职人员结构看板：部门、岗位、员工类型等分布
- 人员流动性分析看板：入离职对比、异动统计
- 员工预计退休时间表：基于延迟退休政策自动计算
- 支持图表钻取查看人员明细
- 功能权限+数据权限双控，按角色批量授权
- 数据时效：T+1更新（岗位/职级/入离职对比）；实时更新（其他报表）
- 数据来源：花名册/任职记录/员工档案

### 4. 人事提醒

- 系统预设提醒：业务提醒（转正、合同到期）+ 员工信息提醒（身份证到期、退休提醒、毕业到期、证件到期、生日、入职周年）
- 自定义提醒：可新增提醒类型，选择系统字段自定义规则
- 每个提醒可独立配置：通知范围、通知人、通知时间、通知方式、通知内容

### 5. 员工合同管理

纸质合同信息维护 + 电子合同签署（对接e签宝）。

- 合同模板：支持控件拖拽（人事控件/基础控件），设置必填/非必填、企业填写/员工填写、字符上限
- 签署场景：企业单方签、员工单方签、企业员工双方签
- 合同发起：入职新签 / 到期续签 / 自定义发起
- 合同审批：签署前审批，审批通过后发起签署
- 合同台账：汇总展示、导入导出、解除合同
- 电子合同三版：标准版 / 融合版 / 集团版
- 签署流程：HR发起→员工签署（短信/二维码）→企业签署（用印）→签署完成→回传花名册
- 合同临期提醒：可配置临期天数，到期续签列表自动展示

### 6. 任职管理

覆盖员工从入职到离职的全生命周期异动管理。

- 入职管理：扫码入职（员工自助）、HR录入入职、批量导入入职、录用审批入职、入职协同事项
- 转正管理：转正规则配置、消息提醒、批量办理转正
- 调动管理：调动表单及流程配置、调动记录查询、取消调动
- 兼任管理：同一员工多部门任职、新增兼任审批
- 借调管理：跨部门借调、借调审批流程
- 临时调店管理：连锁门店场景、临时调店审批
- 离职管理：单笔/批量离职、离职交接、黑名单管理、强校验/弱校验、取消离职
- 任职记录：主岗/兼任/借调/临时调店四类任职记录查询

### 7. 证明开具

- 模板管理：新增Word/Excel模板，拖拽模板变量自动填充员工信息
- 证明类型：在职证明、离职证明、收入证明、转正通知
- 开具流程：选择员工和模板 → 检查信息 → 预览并开具
- 支持电子签署、批量处理（同模板多员工）
- 员工可通过移动端发起申请

### 8. 学历学位验证

- 候选人登录学信网下载学历证书电子注册备案表PDF
- 通过花名册/扫码入职/学历学位验证页上传
- 系统OCR识别 → 与学信网比对 → 验证结果判定
- 验证通过自动标记"已验证"，异常可查看对比数据并人工核实

### 9. 自定义打印

- Excel在线编辑器：支持模板设置和字段取值
- 数据源：花名册数据源、自定义数据源
- 公式字段：引用花名册字段、插入公式、文本字符输入
- 合并单元格字段：多条记录合并展示（如奖惩记录、绩效考核）
- 数据排序和筛选：自定义排序规则、条件筛选
- 适用场景：干部任免审批表等复杂打印需求

### 10. 第三方对接

- 钉钉、企业微信、飞书：实时同步员工变动及信息更新数据

## 能力边界

- 花名册是数据载体，不替代组织管理域的组织架构定义
- 合同台账的"解除"操作仅变更状态，不具备法律效力
- 电子合同签署依赖e签宝的企业认证、印章和额度，非薪福通自建签署能力
- 任职异动的审批流依赖OA审批中台的流程引擎
- 员工关怀的红包发放依赖平台支付能力
- 第三方对接为单向或双向同步，具体冲突处理规则参见各对接平台文档
- 员工统计报表数据来源为主岗任职记录快照，若与花名册不一致需更新任职记录

## 与其他能力的关系

- 花名册是合同管理、任职管理、证明开具的数据底座
- 合同签署后信息自动回传花名册
- 任职异动结果写入花名册的任职记录分组
- 证明开具从花名册自动填充员工信息
- 人事提醒覆盖合同到期、转正、证件到期等跨能力节点
- 学历学位验证结果写入员工档案库
