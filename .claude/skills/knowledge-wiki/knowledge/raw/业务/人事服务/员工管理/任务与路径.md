## 查询路径

### 花名册查询

- 员工信息查看：员工花名册 → 筛选/搜索 → 点击员工姓名 → 详情页（员工档案/任职记录/合同档案/个税档案/项目用工记录）
- 历史花名册：员工花名册 → 更多操作 → 历史花名册 → 选择备份时间下载
- 部门全路径查看：员工花名册 → 表头设置 → 部门展示层级 → 勾选"部门全路径"
- 未上传头像员工：员工花名册 → 筛选（头像为空）
- 在职/离职合并导出：员工花名册 → 勾选"在职""离职"状态 → 导出

### 任职管理查询

- 待入职：任职管理 → 入职管理 → 待入职
- 已入职：任职管理 → 入职管理 → 已入职
- 放弃入职：任职管理 → 入职管理 → 放弃入职
- 待转正/转正中：任职管理 → 转正管理 → 转正中
- 已转正：任职管理 → 转正管理 → 已转正
- 调动中/已调动：任职管理 → 调动管理
- 兼任记录：任职管理 → 兼任管理
- 借调记录：任职管理 → 借调管理
- 临时调店：任职管理 → 临时调店管理
- 离职中/已离职：任职管理 → 离职管理
- 全部离职记录：任职管理 → 离职管理 → 全部离职记录
- 黑名单：任职管理 → 离职管理 → 黑名单管理
- 主岗任职记录：任职管理 → 任职记录 → 主岗任职记录
- 兼任/借调/临时调店记录：任职管理 → 任职记录 → 对应子页面

### 合同查询

- 合同台账：员工合同 → 合同台账（默认展示在职员工，支持切换离职/未填写）
- 签署中：员工合同 → 签署中（电子合同：待员工签/待企业签/用印审批中；普通合同：待确认签署）
- 全部签署记录：员工合同 → 全部签署记录（含企业撤回/员工拒签/员工拒填）
- 合同审批：员工合同 → 合同审批 → 待发起签署筛选

### 报表查询

- 统计报表：员工管理 → 首页（原"合同签订情况"报表已迁移至此）
- 新版报表：员工管理 → 员工统计报表（在职人员结构看板/人员流动性分析看板/员工预计退休时间表）
- 协同看板：任职管理 → 入职管理 → 协同事项看板

## 页面/菜单定位线索

- 员工管理类操作统一在"人事服务 → 员工管理"下，按功能分：员工花名册、任职管理、员工合同、员工关怀、员工服务、员工管理设置
- 审批流相关配置在"管理后台 → 审批管理 → 通用审批"下，按系统分组"员工管理"
- 权限相关配置在"管理后台 → 通用权限设置 → 用户授权 → 员工管理"
- "员工服务"子菜单承载证明开具、学历学位验证、自定义打印等非日常操作
- "员工管理设置 → 基础设置"是核心配置聚合入口，下设字段设置、任职管理设置、合同设置、人事提醒设置、工号设置、协同事项设置等
- 移动端入口：掌上薪福通APP / 招商银行APP / 招商银行薪福通微信公众号
- 扫码类入口（入职二维码、签署二维码、完善档案二维码）为生成式入口，非固定菜单
