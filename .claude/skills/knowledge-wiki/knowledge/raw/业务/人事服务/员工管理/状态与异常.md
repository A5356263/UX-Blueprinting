## 状态

### 员工任职状态

| 状态 | 含义 | 来源 |
|------|------|------|
| 待入职 | HR已添加但尚未确认入职 | 入职管理 |
| 在职 | 已确认入职，当前在职 | 入职管理 / 花名册 |
| 未填写 | 花名册中员工状态字段为空 | 花名册 |
| 转正中 | 转正流程中或流程结束但未到生效日期 | 转正管理 |
| 已转正 | 转正已生效 | 转正管理 |
| 调动中 | 调动流程进行中 | 调动管理 |
| 兼任中 | 兼任审批通过，兼任生效中 | 兼任管理 |
| 借调中 | 借调审批通过，借调生效中 | 借调管理 |
| 离职中 | 离职流程进行中 | 离职管理 |
| 已离职 | 离职已确认 | 离职管理 |
| 放弃入职 | 待入职人员被放弃入职 | 入职管理 |

### 合同签署状态

| 状态 | 含义 |
|------|------|
| 待员工签 | HR已发起，等待员工签署 |
| 待员工填 | 员工需填写合同中的必填字段 |
| 待企业签 | 员工已签，等待企业签署 |
| 待企业填 | 企业需填写合同中的必填字段 |
| 用印审批中 | 经办人无用印权限，等待印章管理员审批 |
| 待确认签署 | 普通合同模式下等待线下签署确认 |
| 签署完成 | 双方签署完成，信息已回传花名册 |
| 已解除 | 合同状态已变更为解除（仅状态变更，不具法律效力） |
| 企业撤回 | 企业撤回签署 |
| 员工拒签 | 员工拒绝签署 |
| 员工拒填 | 员工拒绝填写 |

### 异动审批状态

| 状态 | 含义 |
|------|------|
| 待审批 | 异动申请已提交，等待审批人处理 |
| 审批中 | 审批流程进行中 |
| 已通过 | 审批通过，等待生效或已生效 |
| 已拒绝 | 审批被拒绝 |
| 已撤销 | 发起人主动撤销 |
| 已取消 | 操作被取消（如取消离职、取消调动） |

### 花名册导入状态

| 状态 | 含义 |
|------|------|
| 智能解析中 | AI正在解析上传文件（约15秒） |
| 待确认 | 解析完成，等待用户确认表头匹配 |
| 校验中 | 正在进行业务字段校验 |
| 校验异常 | 存在字段格式或必填校验不通过 |
| 已导入 | 导入成功，数据已写入花名册 |

### 学历验证状态

| 状态 | 含义 |
|------|------|
| 已验证 | OCR识别+学信网比对通过，教育记录自动标记 |
| 验证异常 | 比对数据不一致，需人工核实 |

## 流程

### 入职流程

```
HR新增待入职（录入基本信息）
  → [可选] 员工扫码登记（填写补充信息）
  → [可选] 入职审批（审批人处理）
  → 确认入职（单人/批量）
  → 入职协同事项生成（合同签订/考勤/社保等）
  → 各协同事项处理 → 全部办结
```

分支：
- 录用审批入职：OA审批发起"录用" → 审批通过 → 自动进入待入职列表 → 确认入职
- 批量导入入职：下载模板 → 填写 → 上传 → 确认入职
- 重入职：系统识别"证件类型+证件号"与已离职人员重复 → 提示是否带出档案

### 扫码入职流程

```
创建入职二维码（设置入职规则）
  → 系统发送短信给员工
  → 员工扫码（招商银行App/微信/浏览器）
  → [可选] 身份验证
  → 员工填写入职登记表
  → 提交 → 信息同步至待入职界面
  → HR确认入职
```

### 转正流程

```
系统提前发送转正提醒（可配置提醒时间）
  → 系统推送转正待办至工作台
  → HR选择待转正员工 → 点击"办理转正"
  → 选择转正表单 → 填写内容
  → 提交审批 → 审批通过 → 按生效日期生效
  → 转正记录进入"已转正"
```

支持：取消转正（员工信息返回待转正页面）

### 调动流程

```
新增调动 → 选择员工和调动表单 → 填写调动信息
  → 提交审批 → 审批通过 → 调动生效
  → 调动记录进入"已调动"
```

支持：取消调动（进入"全部调动记录"，可重新发起）

### 离职流程

```
新增离职（单人或批量）
  → 选择离职表单 → 填写离职信息
  → [可选] 加入黑名单
  → 提交审批 → 审批通过
  → [可选] 离职交接（独立交接表单和审批流）
  → 确认离职
  → [强/弱校验] → 校验通过 → 离职生效
```

分支：
- 取消离职：员工从"离职中"恢复至正常状态
- 强校验阻断：存在未处理的费控/资产/福利数据时无法办理离职
- 弱校验提示：仅提示，可选择继续办理

### 合同签署流程（电子合同）

```
发起合同（入职新签/到期续签/自定义发起）
  → [校验员工授权状态：未授权→发送授权短信]
  → [可选] 合同审批 → 审批通过
  → 发起电子合同签署（跳转e签宝）
  → 员工签署（短信链接/二维码 → 手写或盖章 → 提交）
  → 企业签署（经办人用印或提交用印审批）
  → 签署完成 → 合同信息自动回传花名册
```

### 合同签署流程（普通合同）

```
发起合同 → [可选] 审批 → 进入"签署中"→ 线下签署
  → 管理员确认签署（填写签署日期/合同编号/上传附件）
  → 进入合同台账
```

### 花名册导入流程

```
选择导入模式（新增/修改/无则新增有则修改）
  → 下载模板或上传文件
  → 系统智能解析（15秒）
  → 确认导入任务
  → 表头匹配（系统记忆上次匹配关系）
  → 业务校验（在线编辑修正异常）
  → 确认导入 → 数据写入花名册
```

特殊规则：
- 个税导入：无表头匹配步骤，按国税模板字段展示
- 合同导入：需先在字段设置中开启合同档案开关
- 个税导入：需先授权个税服务权限

### 学历学位验证流程

```
候选人登录学信网下载"学历证书电子注册备案表"PDF（有效期30天）
  → 通过花名册/扫码入职/学历学位验证页上传
  → 系统OCR识别
  → 与学信网数据比对
  → 验证通过 → 教育记录自动标记"已验证"
  → 验证异常 → 查看对比数据 → 选择"确认更新员工档案"或人工核实
```

## 前置条件

| 流程 | 前置条件 |
|------|---------|
| 入职 | 字段设置（入职字段已勾选）；入职流程设置（HR新增/扫码登记/入职审批/确认入职已按需开启）；如需入职审批，OA审批中入职审批流已配置 |
| 扫码入职 | 入职二维码已生成且未过期；若开启"仅待入职员工可扫码"，员工需先在待入职列表 |
| 转正 | 转正表单及审批流已在OA审批中配置 |
| 调动 | 调动表单已在OA审批中配置（系统预置一个，可复制多个） |
| 离职 | 离职表单及流程已配置；离职交接规则已设置；强/弱校验开关已选择 |
| 电子合同签署 | e签宝企业注册并完成实名认证；印章已创建并授权；合同模板已配置并启用；员工已完成e签宝授权 |
| 证明开具 | 证明模板已创建；员工花名册信息已完善 |
| 学历学位验证 | 候选人已从学信网下载有效期内的备案表PDF |
| 批量导入 | 模板已下载并按格式填写；导入模式已确定 |
| 重入职 | 证件类型+证件号与已离职人员匹配 |

## 生效方式

| 流程 | 生效方式 |
|------|---------|
| 入职 | 确认入职后立即生效，员工进入花名册在职列表 |
| 自动确认入职 | 入职日期当天系统自动确认（需开启） |
| 转正 | 审批通过后按转正日期生效，生效前展示在"转正中" |
| 调动 | 审批通过后按调动日期生效 |
| 离职 | 确认离职后立即生效（通过强/弱校验后） |
| 自动确认离职 | 需开启，按规则自动确认 |
| 自动解除合同 | 离职后按合同设置规则自动解除（需开启） |
| 电子合同签署 | 双方签署完成后立即生效，信息实时回传花名册 |
| 合同临期提醒 | 按配置的临期天数在到期前触发 |
| 人事提醒 | 按配置的通知时间触发（转正/合同到期前可配置提前天数） |
| 花名册导入 | 校验通过后立即写入 |
| 任职信息轻管理模式 | 关闭后立即限制花名册直接修改关键字段 |
