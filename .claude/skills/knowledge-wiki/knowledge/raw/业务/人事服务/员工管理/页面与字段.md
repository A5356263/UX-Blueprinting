## 字段语义

### 花名册数据分组

| 分组 | 数据来源 | 说明 |
|------|---------|------|
| 员工档案 | 花名册录入/导入/员工自助完善 | 员工基本信息，核心分组 |
| 任职记录 | 任职管理模块 | 入职/转正/调动等异动自动写入 |
| 合同档案 | 合同台账 | 需开通合同台账权限，签署后自动回传 |
| 个税档案 | 个税人员 | 需开通个税服务权限 |
| 项目用工记录 | 客户管理/用工管理 | 外部项目用工信息 |

### 自定义字段类型

| 类型 | 说明 |
|------|------|
| 单行文本 | 短文本输入 |
| 多行文本 | 长文本输入 |
| 日期 | 日期选择 |
| 单选 | 下拉单选 |
| 多选 | 下拉多选 |
| 数值 | 数字输入 |
| 附件 | 文件上传 |

自定义字段可关联OA表单，实现字段内容跨模块传递。

### 合同模板控件

| 控件类别 | 说明 |
|---------|------|
| 人事控件 | 薪资、社保等人事业务控件组 |
| 基础控件 | 文本、数字、日期等基础控件 |
| 合同分组（推荐） | 业务控件组，用于台账回传字段匹配 |

每个控件可配置：
- 必填/非必填
- 企业填写/员工填写
- 控件名称
- 字体格式
- 对齐方式
- 字符上限（通过拖拽控件长度控制）

### 合同签署区

根据签署场景决定：
- 企业单方签署：至少一个企业签署区，不能设置员工签署区
- 员工单方签署：至少一个员工签署区，不能设置企业签署区
- 企业员工双方签：员工签署区和企业签署区各至少一个

### 劳动合同签订表单字段

| 区域 | 包含字段 |
|------|---------|
| 员工信息 | 姓名、部门、岗位、入职日期（选中员工后默认带出） |
| 合同信息 | 合同公司、合同类型、合同期限、合同起始日、合同到期日、合同附件 |
| 历史合同信息 | 员工在发起审批时的所有合同信息默认带出 |

### 入职登记表字段

入职登记表（员工扫码端）可展示的字段由"待入职字段设置"决定，管理员在入职设置中勾选。

### 证明模板变量

证明开具通过拖拽模板变量自动获取花名册中的员工信息。支持Word和Excel两种模板格式。

## 可见性/可编辑性说明

### 字段三级属性

| 属性 | 含义 |
|------|------|
| 可见 | 字段在对应端展示 |
| 可改 | 允许编辑修改 |
| 必填 | 必须填写才能保存 |

### 分场景设置

| 场景 | 设置路径 | 说明 |
|------|---------|------|
| 花名册HR端（员工档案） | 字段设置 → 员工档案设置 | 批量设置字段在花名册HR端的可见/可改/必填 |
| 员工端个人档案（移动端） | 字段设置 → 员工档案设置 | 批量设置字段在移动端个人档案的可见/可改/必填 |
| 入职登记表（扫码端） | 字段设置 → 入职字段设置 | 设置员工扫码入职界面的字段可见/可改/必填/审批属性 |
| 待入职PC端 | 字段设置 → 入职字段设置 | 设置HR在PC端添加待入职时的字段 |

### 特殊规则

- 系统默认开启的字段不支持用户关闭
- 个税申报信息相关字段默认关闭，需在字段设置中手动开启"个税档案"分组
- 合同档案需在字段设置中开启合同档案开关后才能在花名册中展示
- 自定义字段之间不能重名
- 系统字段之间不能重名
- 启用的字段与未启用的字段之间不能重名
- 未启用的系统字段与已启用的自定义字段允许重名
- 未启用的自定义字段与已启用的系统字段允许重名

### 合同控件可见性

- 审批人节点：可设置审批人可查看并修改的审批内容（路径：流程设计 → 审批人 → 字段权限设置）
- 抄送人节点：可设置抄送人可查看的审批内容（路径：流程设计 → 抄送人 → 字段权限设置）
- 办理人节点：同审批人节点逻辑

### 工号字段特殊规则

- 重入职员工根据工号规则决定是否复用原工号
- 若生成的工号被在职员工占用，序号自动+1直到可用
- 若序号生成至最大值，报错提示
- 可设置"在职员工和离职员工工号不允许重复"
