# 员工管理

## 这是什么

这是员工管理子域的二级路由入口，用来说明这个目录里各编号段分别承载什么知识、遇到什么问题该优先看哪些文件。

它不承载正式业务事实正文，也不承载主链路消费说明。

## 编号段

- `00-09`：领域定义、覆盖范围、核心对象与关系、上下游依赖
- `10-19`：能力地图、入口与路径、状态与流程、页面与字段、边界与限制
- `50-59`：常见问题与外部口径

## 任务触发索引

- 需要理解员工管理子域是什么、覆盖什么、有哪些核心对象：读 `00_领域概述.md`
- 需要理解有哪些能力、能力边界和关系：读 `10_能力地图.md`
- 需要查找操作入口、查询路径、配置路径：读 `12_入口与路径.md`
- 需要理解状态、流程、前置条件和生效方式：读 `13_状态与流程.md`
- 需要理解页面载体、字段语义和可见/可编辑规则：读 `14_页面与字段.md`
- 需要理解使用边界、限制条件和不适用场景：读 `15_边界与限制.md`
- 需要排查常见问题：读 `50_常见问题.md`

## 与成员域的关系

成员接入/退出/成员组等基础知识保留在 `knowledge/raw/业务/成员管理/` 中。本子域仅包含帮助中心"员工管理"模块中的产品知识。

## 维护原则

- README 只做领域内路由，不写正式业务规则正文
- 正式业务事实写入对应编号文件
- 不在本目录中写成员身份治理的通用抽象概念（这些保留在成员域）
- 不在本目录中沉淀主链路消费地图、蓝图移交说明或下游执行指令
- 有内容才建文件，不为编号完整批量造文件
- 如信息不足，使用 `[GAP] / [CONFLICT] / [QUESTION]`，不补造结论
