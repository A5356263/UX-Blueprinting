## 领域契约

### 领域定义

信息收集领域回答的是：
企业如何通过薪福通平台的信息收集完成问卷调查和补录表单。

信息收集支持问卷调查 + 补录表单，支持普通模式和下发模式。

### 解决的问题

信息收集领域主要用于解释以下问题：

- 信息收集如何通过问卷调查和补录表单完成
- 补录表单如何选择是否指定填写人
- 每人可填写一次还是多次
- 普通模式和下发模式有什么区别
- 如何管理共同管理、结果数据列表和统计分析

### 为什么独立成域

信息收集需要独立沉淀，是因为它同时具备以下特征：

- 信息收集是企业日常办公的数据收集工具，承载问卷与补录表单
- 涉及普通模式/下发模式、填写次数、共同管理等独立逻辑

### 与上游领域的关系

- 工具开通或使用授权补读权限管理

这里描述的是上游依赖事实，不等于具体规则已经由其他领域定义完成。

### 稳定结论

- 信息收集是企业日常办公协同的数据收集工具
- 其核心价值是为问卷调查、补录表单和结果管理提供稳定输入
- 它可以服务业务分析、产品设计、体验解释和排障分析，但本文件本身不承载下游消费说明
