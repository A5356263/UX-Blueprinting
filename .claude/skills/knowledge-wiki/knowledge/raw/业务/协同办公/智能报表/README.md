# 智能报表

## 这是什么

这是智能报表子域的二级路由入口，用来说明本子域承载什么知识、遇到什么问题该优先看哪些语义文件。

本 README 承载领域契约与任务路由；具体业务规则仍保留在对应语义文件中。


## 领域契约

### 领域定义

智能报表领域回答的是：
企业如何通过薪福通平台完成数据可视化展示、报表查阅、订阅推送、预警管理和权限管控。

它覆盖的不是报表创建，而是一整套与报表消费和权限管理相关的业务语义，包括：

- 报表中心：分类展示、收藏、查阅（含导出 Excel/PDF/图片）
- 报表授权：单张报表维度，支持用户和角色授权
- 报表停用与启用、报表修改（微调定制）
- 订阅推送（邮件，日/周/月频率）
- 预警规则（最多 5 条，更新后/定时触发）
- 市场薪酬查询、定制化报表验收

### 解决的问题

智能报表领域主要用于解释以下问题：

- 企业员工如何查阅、收藏和导出报表
- 报表权限如何按用户和角色分配
- 报表订阅和预警如何配置
- 报表如何微调定制
- 不同角色（普通员工、报表管理员、超管）的权限边界是什么

### 为什么独立成域

智能报表需要独立沉淀，是因为它同时具备以下特征：

- 有独立的角色体系和权限模型，不依赖报表创建端（智数平台）
- 支持订阅推送和预警规则等自动化能力，有独立的触发和通知逻辑
- 覆盖 5 种角色（普通员工、单张报表管理员、应用管理员、业务管理员、超管）
- 与权限域在报表授权层面存在交叉

### 角色体系

- 普通员工：仅查看被授权报表
- 单张报表管理员：对该报表进行授权
- 智数报表应用管理员：对其他员工授权
- 业务管理员：拥有"权限管理"菜单时可对企业下所有报表授权
- 超级管理员：最高权限，可查看所有报表和所有管理菜单

### 与上游领域的关系

- 与权限域交叉：报表权限控制和角色授权
- 与智数平台交叉：报表由智数平台创建和加工，本域只负责消费端

这里描述的是上游依赖事实，不等于具体规则已经由其他领域定义完成。

### 稳定结论

- 智能报表是企业数据可视化消费端的核心子域
- 其核心价值是为报表查阅、订阅推送、预警管理和权限分配提供稳定输入
- 它可以服务业务分析、产品设计、体验解释和排障分析，但本文件本身不承载下游消费说明

### 显式缺口

## 条件依赖与回主域

- 报表查阅、订阅、预警与报表侧角色以本域为主；最终授权判断涉及通用权限规则时补读权限管理
- 报表创建与数据集管理不属于当前本域；读完权限机制后必须回到本域确认报表角色、可见范围与消费结果
