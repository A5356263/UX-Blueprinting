# 日程

## 这是什么

这是日程子域的固定文件级路由入口，用来说明本子域承载什么知识、遇到什么问题该优先看哪些语义文件。

本 README 承载领域契约与任务路由；具体业务规则仍保留在对应语义文件中。

## 领域契约

### 领域定义

日程领域回答的是：
企业员工如何通过薪福通平台的日程完成日程的创建、订阅和设置。

日程支持创建/订阅/设置，月/周/日视图。

### 解决的问题

日程领域主要用于解释以下问题：

- 日程如何创建
- 团队/部门日程如何订阅
- 日历视图如何设置（月/周/日）
- 日程如何跨端同步和提醒
- 日程如何共享、查看他人忙闲
- 公共日历如何管理
- 会邀如何全流程自动提醒

### 为什么独立成域

日程需要独立沉淀，是因为它同时具备以下特征：

- 日程是企业日常办公的时间管理工具，承载日程创建与订阅
- 涉及公共日历管理、时间冲突提醒、会邀自动提醒等独立逻辑

### 与上游领域的关系

- 工具开通或使用授权补读权限管理

这里描述的是上游依赖事实，不等于具体规则已经由其他领域定义完成。

### 稳定结论

- 日程是企业日常办公协同的时间管理工具
- 其核心价值是为日程创建、订阅和跨端同步提供稳定输入
- 它可以服务业务分析、产品设计、体验解释和排障分析，但本文件本身不承载下游消费说明
