这是通讯录子域的固定文件级路由入口，用来说明本子域承载什么知识、遇到什么问题该优先看哪些语义文件。

## 领域契约

### 领域定义

通讯录领域回答的是：
企业如何通过薪福通平台的通讯录完成组织与成员的查找和联系。

通讯录与人事花名册数据实时互通，支持组织架构/我的部门/常用联系人三个视图。

### 解决的问题

通讯录领域主要用于解释以下问题：

- 企业通讯录如何与花名册实时互通
- 组织架构如何展示企业内组织及成员
- 如何查看我的部门、维护常用联系人
- 如何通过姓名、工号、电话、拼音搜索成员

### 为什么独立成域

通讯录需要独立沉淀，是因为它同时具备以下特征：

- 通讯录是企业日常办公的基础工具，承载组织与成员查找
- 通讯录与成员域花名册实时互通，有独立的数据同步逻辑

### 与上游领域的关系

- 通讯录与成员域花名册数据实时互通

这里描述的是上游依赖事实，不等于具体规则已经由其他领域定义完成。

### 稳定结论

- 通讯录是企业日常办公协同的基础工具
- 其核心价值是为组织与成员查找提供稳定输入
- 它可以服务业务分析、产品设计、体验解释和排障分析，但本文件本身不承载下游消费说明

- 当前暂无显式缺口
