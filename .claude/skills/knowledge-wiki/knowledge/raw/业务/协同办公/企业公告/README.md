# 企业公告

## 这是什么

这是企业公告子域的固定文件级路由入口，用来说明本子域承载什么知识、遇到什么问题该优先看哪些语义文件。

本 README 承载领域契约与任务路由；具体业务规则仍保留在对应语义文件中。

## 领域契约

### 领域定义

企业公告领域回答的是：
企业如何通过薪福通平台的企业公告完成公告的发布、范围控制和已读追踪。

企业公告支持文字/图片/附件多种形式，按部门/岗位/员工类型设置查看范围。

### 解决的问题

企业公告领域主要用于解释以下问题：

- 企业公告如何发布（文字、图片、附件）
- 公告如何按部门、岗位、员工类型控制查看权限
- 公告发布后如何在多端提醒
- 公告及已读/未读情况如何保存和追踪

### 为什么独立成域

企业公告需要独立沉淀，是因为它同时具备以下特征：

- 企业公告是企业日常办公的信息发布工具，承载公告发布与已读追踪
- 发布范围控制和已读追踪有独立的管理逻辑

### 与上游领域的关系

- 公告发布范围和权限控制涉及权限管理

这里描述的是上游依赖事实，不等于具体规则已经由其他领域定义完成。

### 稳定结论

- 企业公告是企业日常办公协同的信息发布工具
- 其核心价值是为公告发布、范围控制和已读追踪提供稳定输入
- 它可以服务业务分析、产品设计、体验解释和排障分析，但本文件本身不承载下游消费说明

### 显式缺口

- [GAP] 企业公告的详细操作指引未采集
- [GAP] 企业公告发布权限和审批流程未说明
