# 成员管理

## 这是什么

这是成员管理领域的二级路由入口，用来说明这个目录里各编号段分别承载什么知识、遇到什么问题该优先看哪些文件。

它不承载正式业务事实正文，也不承载主链路消费说明。

## 编号段

- `00-09`：领域定义、范围与边界
- `10-19`：成员加入与邀请、退出与离职交接、成员分组、外部人员治理

## 任务触发索引

- 需要理解成员域的边界以及成员已从组织模块独立出来：读 `00_领域概述.md`
- 需要理解成员进入与退出链路：读 `10_成员加入与邀请.md`、`11_成员退出与离职交接.md`
- 需要理解成员分类与外部人员治理：读 `12_成员分组.md`、`13_外部人员.md`

## 与组织域的关系

成员是独立模块，不再与组织模块混写。成员承载的是成员主体与身份关系，可通过挂载关系接入多维组织。

## 维护原则

- README 只做领域内路由，不写正式业务规则正文
- 正式业务事实写入对应编号文件
- 不在本目录中写组织主数据、组织视图或平台组织底座规则
- 不在本目录中沉淀主链路消费地图、蓝图移交说明或下游执行指令
- 做结构替换时不保留兼容层，确认替换后直接移除旧知识位
