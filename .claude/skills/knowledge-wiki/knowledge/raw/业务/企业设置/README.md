# 企业设置

## 这是什么

这是企业设置领域的二级路由入口，用来说明这个目录里各编号段分别承载什么知识、遇到什么问题该优先看哪些文件。

它不承载正式业务事实正文，也不承载主链路消费说明。

## 编号段

- `00-09`：领域定义、范围与边界
- `10-19`：企业信息展示、登录页自定义与企业文化表达

## 任务触发索引

- 需要理解企业设置域的边界与覆盖范围：读 `00_领域概述.md`
- 需要理解企业信息展示：读 `10_企业信息展示.md`
- 需要理解登录页个性化与企业文化表达：读 `11_企业登录页自定义.md`、`12_企业文化.md`

## 维护原则

- README 只做领域内路由，不写正式业务规则正文
- 正式业务事实写入对应编号文件
- 不在本目录中写组织、成员或权限治理规则
- 不在本目录中沉淀主链路消费地图、蓝图移交说明或下游执行指令
- 做结构替换时不保留兼容层，确认替换后直接移除旧知识位
