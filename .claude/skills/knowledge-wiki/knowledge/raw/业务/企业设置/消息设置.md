# 12_消息设置

消息设置属于企业设置模块，用于企业配置消息通知的发送渠道和业务消息规则。

- 来源：用户提供的产品事实
- 来源类型：产品交互规格
- 最近更新：2026-06-23

## 1. 页面结构

消息设置页面包含三个 Tab：

- 消息渠道设置
- 业务消息设置
- 企业内部消息收发

## 2. 消息渠道设置

向员工发送本企业所有相关信息的渠道设置。四种渠道均采用开启/关闭的交互方式。

包含四种渠道：

### 2.1 短信

企业通过短信为员工发送消息提醒。用户可开启或关闭。

- 默认状态：待确认

### 2.2 微信公众号

开启后支持两种消息类型推送：

| 消息类型 | 推送范围 |
|---------|---------|
| 待办事项提醒 | OA 审批、费控、人事等待办提醒 |
| 通知消息提醒 | OA 审批、费控、人事、薪酬、工资、福利、权限、抄送等提醒 |

开启前提：员工需要关注本公众号并登录。

### 2.3 邮件

开启后支持两种消息类型推送：

| 消息类型 | 推送范围 |
|---------|---------|
| 待办事项提醒 | OA 审批、费控、人事等待办提醒 |
| 通知消息提醒 | OA 审批、费控、人事、薪酬、工资、福利、权限、抄送等提醒 |

### 2.4 AI 电话语音

开启后支持以下消息类型推送：

| 消息类型 | 推送范围 |
|---------|---------|
| 待办事项提醒 | OA 审批待办提醒 |

## 3. 业务消息设置

业务消息设置包含通知设置和待办设置两部分。

### 3.1 通知设置

以表格展示，表格字段：

| 字段 | 说明 |
|------|------|
| 规则名称 | 通知规则的名称 |
| 设置操作 | 点击后弹出设置弹窗 |

**设置弹窗：**

用户可在弹窗中勾选各类关注的通知类型。

勾选为关注的通知后，将产生以下效果：

1. 关注的通知会展示在员工工作台「关注的通知」区域，供员工查看
2. 关注的通知提供弹窗提醒
3. 员工将默认订阅企业设置的关注的通知，且无法取消订阅

### 3.2 待办设置

以表格展示，表格字段：

| 字段 | 说明 |
|------|------|
| 消息名称 | 待办消息的名称 |
| 业务模块 | 所属业务模块 |
| 消息类型 | 消息的类型分类 |
| 范围 | 消息的覆盖范围 |
| 状态 | 当前启用状态 |
| 操作 | 编辑 / 删除 |

提供「新增规则」功能，新增/编辑规则的表单包含以下字段：

| 字段 | 可选值 |
|------|--------|
| 消息名称 | 待办汇总通知 / 待办超时汇总通知 |
| 业务板块 | OA 审批 / 所有待办 |
| 统计周期 | 天 / 周 / 月 |
| 提醒时间 | 0 点至 12 点之间选择整点汇总发送 |
| 提醒范围 | 全部成员 / 部分成员 |
| 提醒渠道 | 可多选，详见下方说明 |
| 状态 | 开关（开启 / 关闭） |

提醒渠道选项说明：

| 渠道 | 说明 |
|------|------|
| 平台消息 | 薪福通 PC、APP 通知提醒和 IM 通知助手 |
| 短信 | 请联系分行客户经理申请开通短信提醒 |
| 邮件 | 您的企业当前未开启邮件通知消息提醒，请先前往「消息渠道设置」开启功能 |

## 4. 企业内部消息收发

### 4.1 企业内部消息收发（聊天消息）

用户可自行开启或关闭。

- 包含 PC 端和移动端的私聊和群聊
- 关闭后全体成员无法发送或接收聊天消息
- 机器人消息不受此开关影响

### 4.2 群聊合规管理

**建群、入群合规内容提示：**

- 用户可开启或关闭
- 开启后，新建群及邀请新用户入群，当群组成员数达到提醒数量时，在会话窗口增加合规管理内容提示
- 群组成员人数小于等于 N 人时不会触发合规内容提示，N 值可由用户自行编辑

**建群合规管理提示文案：**

- 系统提供默认文案
- 用户可自行编辑

**入群合规管理提示文案：**

- 系统提供默认文案
- 用户可自行编辑
