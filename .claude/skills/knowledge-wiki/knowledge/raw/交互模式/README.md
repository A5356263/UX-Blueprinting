# 交互模式

## 这是什么

这是交互模式知识库的二级路由入口，用于存放跨业务、跨产品复用的任务组织方式与信息承载模式。

它服务的是页面结构推导、任务组织和形式选择，不服务业务规则定义，也不替代设计准则。

## 与设计准则的关系

- `设计准则` 回答为什么这样判断
- `交互模式` 回答这类任务通常怎么组织

读取顺序通常是：

1. 先读相关设计准则，判断当前问题类型
2. 再读交互模式，选择常见组织方式和承载形式

## 当前主题

- `反馈、报错与引导.md`：任务过程中的反馈、异常、恢复和引导模式

## 场景路由

- 需要判断“反馈还是引导”、什么时候前置说明、什么时候强阻断：先读 `设计准则/反馈与引导.md`
- 需要组织新手指引、任务引导、结果反馈、异常恢复：读 `反馈、报错与引导.md`
- 需要为某类任务选择更合适的承载形式：读 `反馈、报错与引导.md`

## 边界

- 放模式和形式边界，不放业务规则
- 放任务组织方法，不放组件实现 API
- 放常见承载方式，不放视觉样式规范
