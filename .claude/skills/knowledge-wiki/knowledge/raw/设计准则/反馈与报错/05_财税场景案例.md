# 财税场景案例

## 2. 报错类型与推荐体验处理

### 2.18 财务凭证相关规则限制

原始分类：

- 大类：业务规则限制类
- 小类：财务凭证相关
- 当前形式：弹窗提示

任务场景：

- 凭证录入。
- 账套管理。
- 科目设置。

问题原因：

- 凭证编号重复。
- 金额为 0。
- 账套不存在。
- 期间已结账。

现状体验问题：

- 多种问题混在弹窗中。
- 字段级问题没有回到字段。
- 状态级问题没有持续展示。

推荐反馈形式：

- 凭证重复：字段附近提示。
- 金额为 0：字段附近提示。
- 账套不存在：页面占位或弹窗并提供返回。
- 已结账：banner 或状态提示。

推荐文案：

```text
凭证【记-{编号}】已被使用，请更换编号。
借贷金额不能为0。
账套不存在或已被删除。
当前{期间}已结账，数据不可编辑。
```

原文案问题示例：

```text
凭证【记-7】已存在, 请检查。
当前期间已结账，公式不允许修改。
```

建议处理：

- 凭证重复贴近编号字段。
- 结账状态用持续提示。
- 不用“请检查”作为默认下一步。

需确认信息：

- 凭证编号是否允许手动修改。
- 结账后是否有反结账或联系路径。

体验影响方向：

- 减少财务录入返工。
- 提升状态限制的可见性。

### 2.19 发票和税务相关规则限制

原始分类：

- 大类：业务规则限制类
- 小类：发票/税务相关
- 当前形式：弹窗提示

任务场景：

- 发票开具。
- 税局登录。
- 发票查询。
- 发票上传或校验。

问题原因：

- 发票信息不匹配。
- 税局登录失败。
- 当前企业不支持某税号。
- 税务配置未完成。

现状体验问题：

- 税号不支持只告知失败，没有配置引导。
- 税局错误直接透出，用户不理解。
- 发票信息差异不清楚。

推荐反馈形式：

- 税号/配置问题：页面占位或状态提示，给出设置路径。
- 字段校验：字段附近提示。
- 税局交互失败：弹窗保留必要原因，并转成用户语言。
- 发票信息不匹配：弹窗或结果区展示差异项。

推荐文案：

```text
当前企业尚未开通此税号的发票服务，请前往「发票设置」配置。
电子税局登录失败：{具体原因}。请核对后重试。
发票信息与上传文件不一致：{差异项}，请核对后重新上传。
```

原文案问题示例：

```text
当前企业不支持该税号。
登录电子税局失败:...
```

建议处理：

- 给税号不支持增加配置引导。
- 税局失败保留关键原因，但转换为用户语言。
- 差异类问题列出差异项。

需确认信息：

- 发票设置入口名称。
- 税局返回原因哪些可展示。
- 发票差异项应展示哪些字段。

体验影响方向：

- 减少税号不支持类高频阻断。
- 提升发票提交和税局交互失败后的可恢复性。
