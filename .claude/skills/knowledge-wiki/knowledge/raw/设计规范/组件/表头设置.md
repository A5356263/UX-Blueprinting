## 表头设置 · 场景指南（知识整理）


> 适用场景：列表页 / 表格「表头设置（列设置）」交互的设计参考

### 一、何时使用

优化表头设置方案通用性，解决表头设置各业务不一致问题。

### 二、设计策略

1. 规范入口位置、名称；
2. 根据支持功能点，设计「**简洁模式**」「**复杂模式**」两种模式；
3. 在复杂模式支持更多的扩展功能。

#### 模式 / 功能点对照

| 模式 / 功能点 | 建议表头数量 | 拖曳排序 | 按分组显示字段 | 全选 | 冻结前列 | 表头字段搜索 | 查看/统计已选 | 更多设置入口 | 跨表单字段 | 恢复默认 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| **简洁模式** | ≤30 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | — | — | ✓ |
| **复杂模式** | 不限 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |

### 三、页面框架结构

#### 1. 简洁模式（入口 / 位置）

```
表格操作区：[字段名称 请输入][主操作][次操作][次操作][更多 …]
                     [表头设置入口（设置按钮，右侧弹出浮窗）]
浮窗：从设置按钮下方弹出，与设置按钮右对齐
┌─ 表头设置浮窗 ────────────────┐
│ [全选] [冻结前 1 列]          │
│  ☑字段名称  ☑字段名称         │
│  ☐字段名称  ☑字段名称（可置顶/删除）│
│ [恢复默认]      [取消][确定]   │
└──────────────────────────────┘
```

#### 2. 复杂模式（弹窗）

```
┌─ 表头设置 ─────────────────────────────────────┐
│ [Q 搜索字段]                     已选（7）[冻结前1列][恢复默认] │
│ ┌─ 字段列表（左区）──────────┐ ┌─ 已选区域（右区）──┐      │
│ │ 分组名称 ③                 │ │ 字段名称（可移除×） │      │
│ │  ☑字段名称  ☑字段名称       │ │ 字段名称           │      │
│ │ 分组名称 ③                 │ │ …（拖曳排序/置顶）  │      │
│ └───────────────────────────┘ └──────────────────┘      │
│ [全选]              [取消] [完成设置]                     │
└────────────────────────────────────────────────────────┘
```

### 四、页面解构

#### 1. 简洁模式

- 支持：全选、冻结前列、字段勾选、置顶、恢复默认、确定 / 取消；
- **浮窗弹出位置**：从设置按钮**下方**弹出，与设置按钮**右对齐**；点击「确定 / 取消」按钮或浮窗外其他区域关闭；
- 省略规则：字段名称超过部分省略显示"…"，hover 在气泡显示全部内容。

#### 2. 复杂模式

- 支持：字段搜索、分组显示（分组支持全选）、全选、冻结前列、拖曳排序、已选统计、恢复默认、更多设置入口、跨表单字段；
- 标注：
  - ③ 固定表头选中且禁用；
  - ④ 支持配置说明；
  - ⑫ **支持配置字段全选**（可配置；当字段有上限或会严重影响数据加载速度时，不建议使用）；
  - ⑬ **支持业务自定义更多表格相关设置项**（可配置，如人事「部门展示层级」、假勤「显示设置」）。

#### 3. 分组规则

- **只有一个分组**：字段平铺，无需显示分组标题；
- **有多个分组**：字段较多时建议按类型拆分分组，方便选择；
- **跨表单字段 Tab**：当字段来源于多个业务或表单时，可使用 Tab 拆分跨表单字段。

#### 4. 分组面板

- 分组使用小号折叠面板，默认**不折叠、不显示折叠 icon**；支持业务配置可折叠并显示折叠 icon（`默认` / `展开` / `收起`）。

#### 5. 省略规则

- 字段一行可显示 **5 个**，字段间间距 **8px**；
- 当字段内容 **>8 字符**时，第 8 个及超过部分省略显示（可展示 7 个字符 + `..`），hover 提示全部内容。

#### 6. 设置区域

- 设置项支持并排显示多个（**≤3**），间距 **16px**；
- 设置内容较多时建议**合并入口**；不需要设置项入口时无按钮；
- 点击打开弹窗或抽屉设置更多表格字段设置；
- 禁用状态 hover 提示原因。

#### 7. 弹窗适配规则

- 复杂模式弹窗根据左侧内容高度适配：最小 **600px**，最大为 **80% 屏幕高度**；
- 最小高度 = 600px（右侧内容区域可容纳 10 个已选项，不出现滚动条）；
- 最大高度 = 80% 屏幕高度（超出滚动）。

### 五、补充说明

#### 超限提示

- 默认不限制可勾选字段数，支持业务配置限制字段数；
- 配置后，勾选操作超限时提示：「已超过最大限制，最多支持 XX 个字段」。

### 六、关键交互要点（速记）

1. 两种模式：**简洁模式**（表头 ≤30，轻量浮窗）/ **复杂模式**（不限，功能全，弹窗承载）；
2. 入口统一：设置按钮，浮窗从按钮下方弹出、右对齐；
3. 支持搜索字段、分组（可全选）、全选、冻结前列、拖曳排序、置顶、恢复默认；
4. 固定表头选中且禁用；字段过长省略 + hover 显示全部；
5. 复杂模式弹窗高度 600px ~ 80% 屏高自适应；
6. 可配置勾选数量上限，超限明确提示。

## 表头设置 (Table Header Setting)


- **【表头设置 (Table Header Setting)】**
  - **设计策略**：支持列自定义、排序、筛选、全屏及导出。操作需即时反馈，设置项具有记忆能力。
  - **场景**：业务数据报表、列表页。
  - **状态**：默认、Hover、选中、排序（升/降）、全屏/缩放。
  - **关联**：内置“筛选配置”面板，支持多条件组合查询。
