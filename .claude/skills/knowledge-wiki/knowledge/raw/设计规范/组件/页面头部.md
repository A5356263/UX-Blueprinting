## 头部信息组件 · 场景指南（知识整理）


> 适用场景：详情页 / 信息页顶部「头部信息区」的设计参考

### 一、信息框架（框架区域 / 必选 · 选配）

| 区域 | 必选 / 选配 | 说明 |
| --- | --- | --- |
| 头像区 | 选配 | 默认不选（除员工管理的人员信息查看、编辑、审批场景外，其他场景都需要评审后确认必要性再做添加）；头像取值规则【姓名后两位，无姓名则为手机号后两位】 |
| 标题区 | **必选** | 员工信息一定展示姓名标题，其他场景为正常标题（时间场景允许点击切换） |
| 时间辅助说明区 | 选配 | 辅助说明区固定显示为时间日期 |
| 辅助说明区 | 选配 | 固定显示为（时间、业务名称：时间），如考勤周期：2024-01-01 至 2024-01-31 |
| 标签区域 | 选配 | 标签可多个，建议不超过 3 个，间隔 8px |
| 展开 / 收起 | 选配 | 常规场景无需添加（存在屏效问题时添加）；不需要时去掉即可 |
| 按钮区 | 选配 | 规格为小按钮，类型自定，个数建议不超过 3 个 |
| 表单字段区 | 选配 | 建议一行显示（内容跟随，字段不要超过 5 个）；多行为双列，按表单规则（不建议使用） |
| 分割线 | 选配 | 仅有表单时出现；**当表单区和数据区同时存在时必选** |
| 数据区 | 选配 | 当汇总数据超过 5 个时，才在辅助信息下方新增一行汇总数据（与数据统计组件合并使用） |

### 二、页面框架结构

```
┌──────────────────────────────────────────────────────┐
│ [头像区] 标题区（必选）    [时间辅助说明区]  [标签×N] [展开/收起] │
│          描述说明文字（保持一行内）         [按钮区（≤3）]      │
├──────────────────────────────────────────────────────┤
│ 表单字段区（字段不要超过5个 / 多行双列按表单规则）            │
├──────────────────────────────────────────────────────┤
│ 分割线（表单与数据同时存在时必有）                          │
├──────────────────────────────────────────────────────┤
│ 数据区（汇总数据超过5个时，在辅助信息下方新增一行）           │
└──────────────────────────────────────────────────────┘
```

- 标题区下描述说明文字保持一行内；
- 标题区、时间辅助说明区、标签区、按钮区、表单区、数据区上下排列；
- 表单字段区与数据区同时存在时用分割线分割。

### 三、典型场景

#### 1. 人员信息场景

- 头像默认不选（除员工管理的人员信息查看、编辑、审批场景外，其他场景都需要评审后确认必要性再做添加）；头像取值规则【姓名后两位，无姓名则为手机号后两位】；
- 标题区：员工固定展示姓名（如「薪小福」+ 员工状态标签）；
- 示例：`薪小福 员工状态` + `字段名称 123456789`、`部门 薪福通人事部`、`字段名称 任职受雇信息` + `链接按钮 ×2`（间距 12px）。

#### 2. 其他场景（标题 + 辅助信息）

- 标题 + 辅助信息根据场景搭配使用；
- 示例：`自定义文案` + `描述说明文字保持一行内` + `2023-06-30 至 2023-07-31` + `标签名称` + `链接按钮 ×2`。

#### 3. 标题 + 表单

- 表单内容少且固定、能一行展示完整时，内容跟随；
- 表单内容不固定、需多行展示时，按表单使用规则**双列展示**，可搭配展开收起；
- 字段按最长的算（如：`争议申诉风险提醒` / `任职受雇信息`）。

#### 4. 有数据类

- 表单与数据同时存在时需要**分割线**分割；
- 当汇总数据超过 5 个时，才在辅助信息下方新增一行汇总数据（与数据统计组件合并使用）；
- 示例：`自定义文案` + `字段名称 80人 ×5` + `C按钮` + `表单lable 这里是内容信息 ×N`。

#### 5. 收起场景 / 切换场景

- 收起场景：`自定义文案 展开` + `链接按钮 ×2`（收起时隐藏表单/数据内容）；
- 切换场景：时间辅助说明支持点击切换（如 `2024年02月 - 2023-06-30 至 2023-07-31`），配合标签、表单、数据区展示。

### 四、关键交互要点（速记）

1. **标题区必选**，员工信息场景固定展示姓名，时间场景标题可点击切换；
2. **头像区默认不选**，仅人员信息查看/编辑/审批等场景按需添加；
3. 标签建议不超过 3 个、间隔 8px；按钮区为小按钮、不超过 3 个；
4. 表单字段不要超过 5 个，多行按双列表单规则（不建议）；
5. 表单与数据同时存在时必须有分割线；
6. 描述说明文字保持一行内；展开/收起仅在存在屏效问题时使用。
