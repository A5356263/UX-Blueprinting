## 搜索与筛选 · 场景指南（知识整理）


> 适用场景：列表页 / 数据管理页面中「搜索与筛选」交互的设计参考

### 一、设计目标

在搜索和筛选功能方面，应用多种设计模式来确保系统高效、可扩展且易于维护。

### 二、设计策略

1. 根据使用场景，提供便捷、精确的搜索与查询方式；
2. 考虑页面的空间利用率，搜索与筛选应尽量减少占用页面空间；
3. 对复杂的查询支持更多扩展功能，使用户更快速地搜索与查询。

### 三、设计模式说明

#### 1. 搜索框

- 搜索框一般用来查询**一个或多个文本类字段**。用于筛选时，常跟不同筛选形式组合使用。
- 实时搜索框组成：
  - ① 搜索提示
  - ② 搜索框
  - ③ 搜索行动按钮（点击 / 回车触发）
- 示例：`Q 搜索关键字/关键字`

#### 2. 字段平铺式筛选

- **触发查询逻辑**：实时生效（搜索框是否使用实时，根据业务自行选用）。
- **位置**：位于表格左上区域，左对齐。
- **搜索框**：字段平铺式筛选常使用搜索框，可将多个关键文本类字段合并进行组合查询，搜索框常位于最左侧。
- **选择器**：选择器用于平铺式筛选时，一般不显示 label，指引文案显示于选择框未输入状态的提示文案；支持设置预置值。
- **筛选项个数**：建议 **< 5 个**；左侧查询区域跟右侧按钮区域安全距离限制为 **80px**。
- 示例布局：`搜索关键字/关键字 | 选择部门 | 选择类型 | 选择日期 | 主操作 | 次操作`
- 设置预置值示例：`全部部门`、`2023-6`

#### 3. 表单式筛选

- **触发查询逻辑**：非实时查询，需**点击查询**触发筛选。
- **占位规则**：单独占位至少一行；当筛选项多出一行时，有「展开、收起」两个状态。
- **适配规则**：根据页面宽度适配一行显示的选项个数，单个选项宽度最小值 **306px**，最大值 **426px**。
- 状态：`未超一行` / `收起状态` / `展开状态`。
- 操作：`重置`、`查询`（支持「更多筛选」/「收起筛选」）。
- **表单式查询项 Label 规则**：
  - 按照最大 label 宽度（例：页面中所有输入字段最长 4 个字时，本页面 label 宽度为 64px），但不得大于 **128px**；
  - 当查询项固定时，按照当前页面字段最大的 label 宽度；
  - 当查询项非固定（如支持自定义字段）时，按照当前页面系统默认字段最大的 label 宽度。

#### 4. 收纳式筛选（悬浮面板）

- **适用场景**：有较固定的筛选项时，为了节省页面空间，可使用该模式；一般在有大量筛选条件要展示、且页面空间有限的场景下使用。
- **两种形式**，可互相切换：
  - 【简单查找】固定筛选项，建议不超过 **3 项**；触发查询：**实时生效**。
  - 【精确查找】切换该模式后，打开悬浮面板，筛选内容平铺；触发查询：**点击查询生效**。
- **可见性**：由于已选项的可见性不太好，需要通过「当前筛选条件」弥补已选项可见性（当前筛选条件距离下方表格 **12px** 间距）。
- **触发查询条件**：不全统一，部分切换实时生效，部分点击查询生效。

##### 当前筛选条件（收纳式）

- 框架分区：`常用筛选方案区域` / `筛选内容展示区域` / `当前筛选条件状态 + 表格搜索/配置区域` / `数据展示区域`。
- 当前筛选条件展示区：**根据容器宽度展示固定的条数**。
- 操作区域：`展开/收起所有条件`、`另存为新的筛选方案`、`清空`、`可配置展示`。
- 状态示例：常用筛选方案（初始）；当前筛选条件：`摘要：公章 ×`、`审批名称：用章申请 ×`；`折叠-收起` / `折叠-展开`。
- **适配规则（首行展示条件个数）**：
  - 屏幕宽度 1280px → 1500px：第一行固定展示 **1 个**条件标签；
  - 屏幕宽度 1500px → 1800px：第一行固定展示 **2 个**条件；
  - 屏幕宽度 1800px 以上：第一行固定展示 **3 个**条件。
- **条件标签说明**：
  1. 第一行条件展示标签的最大宽度为 **280px**，超过省略显示，鼠标 hover 展示全部；
  2. 标签省略规则：默认省略在最后面；如果是「字段标题文字：第一个选项名选项名选…及 n 个选项」这种，省略在「及」以前；
  3. 省略的标签都支持 hover 展示，Tooltip 文字提示最大宽度 **320px**；最大高度超过 10 行出现滚动条（Max high **208px**）；
  4. 展开的所有条件最大高度为 **180px**，超过滚动显示；
  5. 每一个条件标签是否支持删除，根据业务配置。
- 展开示例：`查询主账套：测试企业× 会计期间：2025年12月～2026年1月× 账套范围：测试账套名及6个选项× 供应商：abv氨基酸及18个选项×`

### 四、页面框架结构

#### 1. 通用列表页骨架

```
┌──────────────────────────────────────────────────┐
│ 筛选/搜索区（按模式不同，见下）                       │
│  ├ 字段平铺式：[搜索框][选择器×N]       [主操作][次操作] │
│  ├ 表单式：  [字段名称 请输入/请选择×N]  [重置][查询]   │
│  └ 收纳式：  常用筛选方案 + 当前筛选条件 + 悬浮面板     │
├──────────────────────────────────────────────────┤
│ 表格搜索/配置区（Q 请输入、列配置等）                 │
├──────────────────────────────────────────────────┤
│ 数据表格：表头 | 正文 …（操作列：操作 / 详情）        │
├──────────────────────────────────────────────────┤
│ 分页：共1000条  1 2 3 4 5 … >   10/页               │
└──────────────────────────────────────────────────┘
```

#### 2. 字段平铺式筛选框架

- 筛选区位于**表格左上区域，左对齐**：`[搜索框][选择器×N]` + 右侧按钮区（主操作/次操作）；
- 查询区与按钮区安全距离 **80px**；
- 下方：数据表格 + 分页。

```
┌───────────────────────────────────────────────┐
│ [Q 搜索关键字/关键字][选择部门][选择类型][选择日期]  [主操作][次操作] │
├───────────────────────────────────────────────┤
│ 表头 | 表头 | 表头 | 表头 | 操作               │
│ 正文 | 正文 | 正文 | 正文 | 详情               │
├───────────────────────────────────────────────┤
│ 共1000条  1 2 3 4 5 … >   10/页                │
└───────────────────────────────────────────────┘
```

#### 3. 表单式筛选框架

- 筛选表单**独立占位一行**（未超一行 / 收起 / 展开状态），选项宽度 306~426px；
- 操作区：`[重置][查询]`（更多筛选 / 收起筛选）+ `[筛选项设置]`（入口位于查询、重置按钮左边）；
- 下方：数据表格 + 分页。

```
┌───────────────────────────────────────────────┐
│ [字段名称 请输入][字段名称 请选择]…  [筛选项设置][重置][查询] │
├───────────────────────────────────────────────┤
│ 数据表格（表头/正文…）                         │
├───────────────────────────────────────────────┤
│ 分页：共1000条  1 2 3 4 5 … >                  │
└───────────────────────────────────────────────┘
```

#### 4. 收纳式筛选框架（悬浮面板）

- 框架分区：

```
┌───────────────────────────────────────────────┐
│ 常用筛选方案区域（初始 | 自定义方案1 | 自定义方案2）  │
│ 当前筛选条件状态 + 表格搜索/配置区域              │
│  ├ 当前筛选条件展示区：根据容器宽度展示固定条数    │
│  └ 操作区域：展开/收起所有条件 | 另存为新的筛选方案 │
│              | 清空 | 可配置展示                │
│ 筛选内容展示区域（悬浮面板：简单查找 / 精确查找切换）│
├───────────────────────────────────────────────┤
│ 数据展示区域（表格 + 分页）                     │
└───────────────────────────────────────────────┘
```

- 当前筛选条件距下方表格 **12px**；
- 悬浮面板（精确查找）：`[字段名称 请输入/请选择×N] [重置][查询]`。

#### 5. 弹窗类框架

- **筛选项设置弹窗**：`搜索字段` → 字段列表（`分组名称` + `字段名称` 勾选，可`全选`）→ `已选（7）` → `[恢复默认]` / `[取消][完成设置]`
- **常用筛选方案管理弹窗**：左侧筛选方案列表（`初始`-默认 / `自定义方案1/2`，`+ 添加筛选方案`，最多 5 个）→ 右侧方案设置（`*筛选方案名称` + 筛选字段配置）→ `[取消][保存]`

### 五、补充说明

#### 1. 筛选项设置（详见「筛选项设置弹窗」规范）

- 表单式、收纳式筛选支持「筛选项设置」；
- 入口：位于表单式、收纳式筛选的**查询、重置按钮左边**，点击打开筛选项设置弹窗；
- 弹窗内容：`搜索字段`、`分组名称`、`字段名称`（勾选列表）、`全选`、`已选（7）`、`恢复默认`、`取消`、`完成设置`。

#### 2. 常用筛选方案

- 使用场景示例：`常用筛选方案 初始 | 自定义方案1 | 自定义方案2`；
- 常用筛选方案管理：
  - 筛选方案列表：**最多可添加 5 个**；
  - `初始`：默认，系统预设不可修改；
  - 自定义方案：可配置方案名称与筛选字段（如：标题、审批编号、摘要、发起人、审批名称、发起时间、创建时间、发起人所在组织、当前节点名称等）；
  - 操作：`+ 添加筛选方案`、`取消`、`保存`。

#### 3. 可支持查询「未填写」项

- **下拉面板**：「未填写」跟其他选项一起作为选项显示，**可同时选择**；
- **日期区间、输入框、选择人员**：在激活状态「未填写」**单独**作为选项显示，跟日期区间 / 输入内容 / 人员选择**互斥，不可同时选择**；
- 示例：下拉面板（未填写）、日期/时间（未填写，日历选择）、输入框（未填写 `×`）、选择人员（未填写，支持按姓名/工号模糊搜索）。

### 六、决策逻辑

按「筛选项数量」与「筛选频率」选择模式：

| 筛选项数量 | 筛选频率 / 触发方式 | 推荐模式 |
| --- | --- | --- |
| 特别多（≥15） | 筛选频率较高（点击触发查询） | 表单式筛选 |
| 特别多（≥15） | 部分字段筛选频率较低 / 节省页面空间（可支持个别字段实时查询） | 收纳式筛选 |
| 较多（5~14） | 筛选频率较高（点击触发查询）（1280 屏幕最多显示 5 行筛选） | 表单式筛选 |
| 较多（5~14） | 部分字段筛选频率较低 / 节省页面空间（可支持个别字段实时查询） | 收纳式筛选 |
| 较少（<5） | 点击触发查询 | 表单式筛选 |
| 较少（<5） | 实时查询 | 字段平铺式筛选 |

> 可选配置：表单式 / 收纳式筛选支持「筛选项设置」；可选配「常用筛选方案」。

## 筛选项配置 · 场景指南（知识整理）


> 适用场景：表单式 / 收纳式筛选中「筛选项设置」弹窗的设计参考

### 一、设计目标

规范表单筛选的筛选项设置方案，解决筛选项过多时的选择和展示问题。

### 二、设计策略

1. 规范入口位置、名称；
2. 支持全选、保存模版等扩展功能。

### 三、页面框架结构

#### 1. 入口位置

```
[字段名称 请输入][字段名称 请选择]×N   [筛选项设置][重置][查询/收起筛选]
                                      ↑
                        入口位于「查询、重置」按钮左侧，名称为「筛选项设置」
```

- 入口按钮状态：`正常` / `悬停` / `点击` / `禁用`（禁用状态 hover 提示原因）。

#### 2. 筛选项设置弹窗框架

```
┌─ 筛选项设置 ──────────────────────────────────┐
│ [Q 搜索字段]                   已选（7）[恢复默认] │
│ ┌─ 字段列表（左区）────────┐ ┌─ 已选区域（右区）──┐ │
│ │ 分组名称 ③               │ │ 字段名称（可移除×） │ │
│ │  ☑字段名称  ☑字段名称     │ │ 字段名称           │ │
│ │  ☐字段名称  ☑字段名称     │ │ …（可拖曳调整排序） │ │
│ └─────────────────────────┘ └──────────────────┘ │
│ [全选]  [取消] [保存为模版] [完成设置]               │
└────────────────────────────────────────────────┘
```

### 四、设计模式说明

#### 1. 入口、位置

- 入口位于查询组件「查询、重置」按钮**左侧**，名称为「筛选项设置」；
- 状态：`正常` / `悬停` / `图标按钮` / `禁用`。

#### 2. 筛选项设置（弹窗）

- ① **字段支持搜索**（Q 搜索字段）；
- ② **统计已选字段个数**（已选（7））；
- ③ **固定表头选中且禁用**；
- ④ **可按分组显示字段，分组支持全选**；
- ⑤ **支持配置说明**；
- ⑥ **恢复默认**；
- ⑦ **拖曳调整排序**（已选区域可拖拽调整顺序）；
- ⑩ **支持配置字段全选**；
- ⑪ **支持业务自定义更多相关设置项**；
- ⑫ **支持保存模版**；
- ⑬ **完成设置后生效**。

#### 3. 分组规则

- **只有一个分组**：字段平铺，无需显示分组标题；
- **有多个分组**：字段较多时，建议将字段按类型拆分为分组，方便用户选择。

#### 4. 分组面板

- 分组使用小号折叠面板，默认**不折叠、不显示折叠 icon**；
- 支持业务配置可折叠并显示折叠 icon（状态：`默认` / `展开` / `收起`）。

#### 5. 省略规则

- 字段一行可显示 **5 个**，字段间间距 **8px**；
- 当字段内容 **>8 字符**时，第 8 个及超过部分省略显示（可展示 7 个字符 + `..`），hover 提示全部内容。

#### 6. 设置区域

- 设置项支持并排显示多个（**≤3**），间距 **16px**；
- 设置内容较多时建议**合并入口**；不需要设置项入口时无按钮；
- 点击打开弹窗或抽屉设置更多表格字段设置；
- 禁用状态 hover 提示原因。

#### 7. 弹窗适配规则

- 复杂模式弹窗根据左侧内容的高度适配：最小 **600px**，最大为 **80% 屏幕高度**；
- 最小高度 = 600px（右侧内容区域可容纳 10 个已选项，不出现滚动条）；
- 最大高度 = 80% 屏幕高度（超出滚动）。

### 五、补充说明

#### 超限提示

- 默认不限制可勾选字段数，支持业务配置限制字段数；
- 配置后，在勾选操作**超限时提示**：「已超过最大限制，最多支持 XX 个字段」。

### 六、关键交互要点（速记）

1. 入口固定在「查询 / 重置」左侧，命名统一为「筛选项设置」；
2. 支持字段搜索、已选计数、恢复默认、全选、拖曳排序、保存模版；
3. 分组展示字段，分组可全选；只有一个分组时字段平铺；
4. 固定表头选中且禁用，保证关键列不可被移除；
5. 弹窗高度自适应（600px ~ 80% 屏幕高），避免遮挡过多内容；
6. 可配置勾选数量上限，超限给出明确提示。

## 筛选配置 (Filter Config)


- **【筛选配置 (Filter Config)】**
  - **设计策略**：提供便捷的入口（标签页、搜索框、高级筛选），支持“与或”条件逻辑。
  - **样式限制**：内容高度最小 `600px`，最大不得超过屏幕的 `80%` 以保证查看舒适度。
  - **状态**：折叠、展开、选中、勾选、清零、应用。
