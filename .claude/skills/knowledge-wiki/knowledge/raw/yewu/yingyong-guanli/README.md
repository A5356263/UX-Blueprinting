# 应用管理

## 这是什么

这是应用管理领域的二级路由入口，用来说明这个目录里各编号段分别承载什么知识、遇到什么问题该优先看哪些文件。

它不承载正式业务事实正文，也不承载主链路消费说明。

## 编号段

- `00-09`：领域定义、范围与边界
- `10-19`：应用治理、应用可见范围与应用组装

## 任务触发索引

- 需要理解应用管理域的范围与边界：读 `00_领域概述.md`
- 需要理解应用治理与可见范围：读 `10_应用管理.md`
- 需要理解组装应用相关知识：读 `11_应用组装.md`

## 维护原则

- README 只做领域内路由，不写正式业务规则正文
- 正式业务事实写入对应编号文件
- 不在本目录中写用户授权算法或审批流程内部实现
- 不在本目录中沉淀主链路消费地图、蓝图移交说明或下游执行指令
- 做结构替换时不保留兼容层，确认替换后直接移除旧知识位
