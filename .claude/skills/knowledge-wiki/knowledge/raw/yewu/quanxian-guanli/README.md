# 权限管理

## 这是什么

这是权限管理领域的二级路由入口，用来说明这个目录里各编号段分别承载什么知识、遇到什么问题该优先看哪些文件。

它不承载正式业务事实正文，也不承载主链路消费说明。

## 编号段

- `00-09`：领域定义、范围边界、术语、对象关系
- `10-19`：能力地图、任务场景、入口与路径、状态流程、页面字段、边界限制
- `20-29`：决策规则、来源模型、冲突原因、规则约束、治理状态、审计追踪
- `30-39`：体验风险、解释策略、体验翻译与文案线索
- `50-59`：FAQ、帮助文档差异、外部口径、异常排障

## 任务触发索引

- 需要先理解权限管理领域是什么、覆盖什么、不覆盖什么：读 `00_领域概述.md` 和 `01_范围与边界.md`
- 需要理解角色、对象、入口、路径、页面载体：读 `03`、`04`、`10-15`
- 需要做规则判断、来源判断、冲突判断、治理与审计判断：读 `20-25`
- 需要做用户解释、风险分析、体验翻译、文案说明：读 `30-32`
- 需要核对帮助文档、FAQ、历史外部口径或异常排障：读 `50_帮助文档权限差异.md`

## 维护原则

- README 只做领域内路由，不写正式业务规则正文
- 正式业务事实写入对应编号文件
- 不在本目录中沉淀主链路消费地图、蓝图移交说明或下游执行指令
- 做结构替换时不保留兼容层，确认替换后直接移除旧知识位
