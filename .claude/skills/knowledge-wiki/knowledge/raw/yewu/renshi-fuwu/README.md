# 人事服务

## 这是什么

这是人事服务业务知识库的二级路由入口，用来说明各子域目录分别承载什么知识、遇到什么问题该优先进入哪个子域。

它不承载正式业务事实正文，也不承载主链路消费说明。

## 子域

| 子域 | 说明 |
|------|------|
| `组织管理/` | 组织架构搭建、编制管控、岗位管理和职级管理 |
| `员工管理/` | 员工花名册、合同管理、任职异动和证明开具 |
| `招聘管理/` | Moka 招聘系统集成 |
| `考勤管理/` | 排班、打卡、请休假、加班、考勤核算 |
| `客户管理/` | 人力资源服务企业的客户档案、合同、项目、用工、账单管理 |

## 任务触发索引

- 需要理解人事服务整体边界：读 `00_领域概述.md`
- 需要理解某个子域的具体知识：进入对应子域目录，先读该子域的 `README.md`
- 需要跨子域关联理解（如招聘→入职衔接）：先在各自域的 `00_领域概述.md` 中确认关系，再进入对应子域

## 维护原则

- README 只做子域路由，不写正式业务规则正文
- 正式业务事实写入对应子域编号文件
- 按帮助中心产品模块结构组织，保持与用户可见产品语言一致
- 不在本目录中沉淀主链路消费地图、蓝图移交说明或下游执行指令
- 做结构替换时不保留兼容层，确认替换后直接移除旧知识位
