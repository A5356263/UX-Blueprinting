# 协同办公

## 这是什么

这是协同办公业务知识库的二级路由入口，用来说明各子域目录分别承载什么知识、遇到什么问题该优先进入哪个子域。

它不承载正式业务事实正文，也不承载主链路消费说明。

## 子域

| 子域 | 说明 |
|------|------|
| `智能报表/` | 报表查阅、订阅推送、预警规则、权限管控 |
| `协同工具/` | 通讯录、企业公告、公文、信息收集、必应、智能会议室、日程 |

> OA 审批知识保留在 `knowledge/raw/yewu/shenpi-guanli/`

## 任务触发索引

- 需要理解协同办公整体边界：读 `00_领域概述.md`
- 需要理解某个子域的具体知识：进入对应子域目录，先读该子域的 `README.md`

## 维护原则

- README 只做子域路由，不写正式业务规则正文
- 正式业务事实写入对应子域编号文件
- 按帮助中心产品模块结构组织
- 不在本目录中沉淀主链路消费地图、蓝图移交说明或下游执行指令
- 做结构替换时不保留兼容层，确认替换后直接移除旧知识位
