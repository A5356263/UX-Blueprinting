# 协同工具

## 这是什么

这是协同工具子域的二级路由入口，用来说明这个目录里各编号段分别承载什么知识、遇到什么问题该优先看哪些文件。

它不承载正式业务事实正文，也不承载主链路消费说明。

## 编号段

- `00-09`：领域定义、范围与边界
- `10-19`：协同工具全功能产品知识（通讯录、企业公告、公文、信息收集、必应、智能会议室、日程）

## 任务触发索引

- 需要理解协同工具子域的边界与覆盖范围：读 `00_领域概述.md`
- 需要理解全部 7 个工具的功能：读 `10_协同工具.md`

## 维护原则

- README 只做领域内路由，不写正式业务规则正文
- 正式业务事实写入对应编号文件
- 新知识优先落到对应编号模块
- 不在本目录中沉淀主链路消费地图、蓝图移交说明或下游执行指令
- 做结构替换时不保留兼容层，确认替换后直接移除旧知识位
