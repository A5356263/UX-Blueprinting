## 稳定结论
- 目录包含 3 个知识模块：00_领域概述、10_应用管理、11_应用组装
- 推荐阅读顺序：00 → 10 → 11（先了解域边界 → 再学应用治理 → 最后学组装扩展）
- **维护原则**：只记录应用治理、应用可见范围与应用组装相关知识；不在本目录中写用户授权算法或审批流程内部实现；尽量复用已有应用术语；新知识优先落到对应编号模块，不回写为大一统长文
- **迁移原则**：先沉淀应用台账与可见治理，再补充应用扩展与组装知识；与权限域交叉时只保留应用治理口径，不覆盖权限真源；后续新增应用管理材料按编号模块继续补齐
