## 定位
用于暂存归属不清、但值得保留的原始知识材料的临时目录。

## 触发信号
当有知识材料暂时无法稳定归类到 `业务/` 或 `设计准则/` 等正式目录时，先写入 inbox 并标记 `[QUESTION] 归属待确认`，后续确认归属后再合并到正式目录。

## 稳定结论
- inbox 是一个暂存区，不是正式知识目录
- 写入时需要显式标记 `[QUESTION] 归属待确认`
- 后续确认归属后必须合并到正式目录，不留孤岛
