# 知识问答规则

本文件用于约束 `knowledge-wiki` 的知识消费行为。

## 适用问题

适用于回答内嵌知识库中已有定义的：

- 业务规则
- 字段含义
- 状态定义
- 页面路径
- 菜单归属
- 权限规则
- 流程边界
- 设计准则

## 读取顺序

1. 先读 `knowledge/wiki/index.md`
2. 优先命中相关 `summary`
3. 读取命中的 `summary`
4. 必要时再根据 `source_path` 回查对应 `raw`
5. 基于已有知识回答，不补造不存在的结论

## 输出要求

回答时必须说明：

- 当前知识库如何定义
- 该定义能支撑什么结论
- 是否存在 `[GAP]` / `[QUESTION]` / `[CONFLICT]`
- 如果知识不足，明确说明缺口

## 边界

以下问题不在 knowledge-wiki 问答范围内：

- 需求是否合理
- 方案该怎么设计
- 体验问题怎么诊断
- 流程怎么优化
- 功能应该不应该做

遇到这些问题时，应提示进入 UXB，不直接给出需求判断或方案判断。
