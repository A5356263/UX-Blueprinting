## 维护边界

- README 只承载领域契约与路由，不展开具体业务规则正文。
- README 只路由到正式文件，不维护章节标题、锚点或正文摘要。
- 同一领域内的应用、模块和业务主题默认作为固定文件章节；只有通过物理子域四项门禁时才建立下级目录。
- 有内容才建文件，不为目录或形式完整批量造文件。
- 大文件可继续保留；行数只触发导航检查，不自动触发拆分。
- 信息不足时使用 `[GAP]`、`[CONFLICT]`、`[QUESTION]`，不得补造结论。
