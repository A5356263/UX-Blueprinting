# 实现与代码生成规则

本 skill 以评估为先。除非用户明确要求实现，否则不要在评估阶段生成代码。

## 允许的实现类输出

- 设计修改说明。
- 组件级验收标准。
- 带注释的 UI 规格。
- 最小 HTML / React 函数组件 / Vue 3 Composition API 实现。
- 从 UCATS 问题推导出的测试清单。

## 规则

1. 保持截图中呈现的业务目标不变。
2. 只实现能映射到已报告问题 id 或建议的改动。
3. 保留截图推导出的假设；不要虚构隐藏业务行为。
4. 包含可访问性考虑：语义结构、标签、焦点顺序、键盘路径、可见错误恢复。
5. 当截图包含移动端/平板/桌面变体时，包含响应式行为。
6. 提供集成说明，但实现保持最小且聚焦。

## 验收标准格式

```json
{
  "source_issue_id": "iss_1",
  "change": "在失败字段旁添加内联恢复提示。",
  "acceptance_criteria": [
    "错误文案指出失败字段和修正动作。",
    "错误出现后，主操作仍保持可见。",
    "键盘焦点移动到第一个无效字段。"
  ]
}
```
