# 按钮 Summary

## 1. 组件定位

- 按钮用于触发动作与流程推进。
- 按钮是页面中最直接的主次任务层级表达。

## 2. 默认结论

- 默认按钮档位使用中号。
- 主按钮只用于当前窗口主任务。
- 次级动作默认使用默认按钮、次按钮或文字按钮，不上升为主按钮。
- 危险按钮只用于明确破坏性动作，不与普通主按钮混用同一语义。

## 3. 改写边界

- 可改：文案、图标、有无前后缀、局部并排关系。
- 默认不改：尺寸档位、状态表现、基础视觉层级、主次按钮的默认语义。

## 4. 关联规则

- 同一窗口主按钮数量受 `checklists/page/page-consistency.md` 约束。
- 系统级按钮层级原则以 `design-systems/DESIGN.md` 为准。
- 真实默认实现以 `component.html` 为准。
