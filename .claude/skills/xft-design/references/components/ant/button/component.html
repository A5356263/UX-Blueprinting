基础形态

这一组用于表达主按钮、默认按钮、次按钮、文字按钮、危险按钮、禁用按钮的基础层级。

状态

hover、active、focus、disabled 四种关键状态。hover 时边框与文字变蓝，active 时颜色加深，focus 时出现 2px 蓝色轮廓，disabled 时整体弱化。

尺寸档位

小号、中号、大号按钮需要同时体现高度、字号和左右内边距差异。

24px 高度 / 12px 字号 / 8px 左右内边距
32px 高度 / 14px 字号 / 14px 左右内边距
40px 高度 / 16px 字号 / 16px 左右内边距

图标与文字组合

图标与文字之间保持 6px 间距，不要随按钮尺寸漂移。
