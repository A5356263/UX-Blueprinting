基础形态（line 型）

尺寸档位

标准 40px（14px 字号）与小号 32px（12px 字号）。间距 32px / 20px 对应缩放。

标准：40px 高度 / 14px 字号 / 32px 间距
小号：32px 高度 / 12px 字号 / 20px 间距

状态

激活态（蓝色文字 600 字重 + 下划线）、默认态（灰色 400）、hover 态（变蓝）、禁用态（浅灰不可点）。

card 型标签：激活项白色背景，其他灰色背景。适合需要明确边界的标签场景。可关闭标签带 × 按钮。
