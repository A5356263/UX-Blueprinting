# 标签页 Summary

## 1. 组件定位

- 标签页用于在同一内容区域内切换不同视图或内容分组。
- 标签页是区域内切换控件，不承担全局导航跳转职责。

## 2. 默认结论

- 默认标签页使用标准档位；紧凑场景可使用小号或 card 型变体。
- 标签页只切换同一主线下的相邻内容，不把不同页面主任务硬塞进同一组 tabs。
- 可关闭页签、card 型页签、内容区 tabs 仍属于同一组件族，但层级和语义不同于菜单导航。
- 标签页的激活项只能表达当前局部内容焦点，不替代页面主按钮。

## 3. 改写边界

- 可改：标签数量、标签文案、line/card 形态、是否可关闭、局部宽度与排列。
- 默认不改：导航栏与内容区基础关系、激活层级、尺寸档位、切换语义。

## 4. 关联规则

- 与 menu、breadcrumb、steps 的职责边界以“区域内切换”与“全局导航/流程表达”区分。
- 在框架级页签场景中优先继承 `references/chrome/page-tabs.html`。
- 真实默认实现以 `component.html` 为准。
