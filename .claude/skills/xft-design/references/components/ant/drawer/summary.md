# 抽屉 Summary

## 1. 组件定位

- 抽屉用于在保留当前页面上下文时，通过右侧全高容器完成临时任务。
- 抽屉与 Modal 使用同一套头体脚结构和 overlay runtime 契约。
- 抽屉的主要差异是右侧贴边与窗口全高。

## 2. 默认结论

- 宽度档位使用 `480 / 740 / 1060 / 1200`。
- 默认宽度档位使用 `740`，高频轻任务档位使用 `480`。
- `1060 / 1200` 只在内容信息量明显增加时使用。
- 抽屉默认保持右侧贴边、窗口全高、body 独立滚动。
- 打开关闭沿用 runtime overlay 契约。
- footer actions 保持完整默认实现。
- 其余结构能力与 Modal 对齐。

## 3. 改写边界

- 可改：标题、body 内容、宽度档位、底部动作文案、body 承载的详情/表单/配置内容。
- 默认不改：右侧贴边、全高关系、overlay 与 drawer 层级关系、header/body/footer 结构、body 滚动方式、footer 位置、runtime 契约。

## 4. 关联规则

- 抽屉作为覆盖层组件，使用边界继续受现有页面主线与覆盖层判断关系约束。
- 主按钮唯一性仍受页面级一致性约束。
- 真实默认实现以 `component.html` 为准。
