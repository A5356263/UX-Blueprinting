基础形态

默认基线使用 740 宽度档位，抽屉从右侧贴边展开，保持 header、body、footer actions 三段结构，打开关闭交给 runtime overlay 契约。

宽度档位

740 是默认主档位，480 是高频轻任务档位；1060 / 1200 只在内容信息量确实增加时再使用。

状态 / 内容承载

详情查看适合承载更长的只读内容，结构不变，只变化 body 内容类型。

高频变体

表单承载是抽屉高频场景，适合在保留页面上下文时完成更长的录入或配置任务。

基础抽屉

这里是默认抽屉正文，可承载详情、表单、配置项或较长说明内容。

简单确认

480 适合轻量确认、较短说明或少量配置项。

默认 740

740 适合标准后台配置、较完整表单与中等信息量任务。

复杂配置

1060 适合需要更丰富横向空间的配置、对比或复合信息查看场景。

宽内容查看

1200 只用于内容信息量明显增加时的查看或配置任务，不作为默认档位。
