# 标签 Summary

## 1. 组件定位

- 标签用于承接最小粒度的状态、分类与结果标记。
- 标签用于辅助识别信息，不承担主操作或导航职责。

## 2. 默认结论

- 标签默认使用单一标准尺寸。
- 标签优先表达状态与分类，不承担长文本说明。
- 状态标签、可关闭标签、多选结果标签仍属于同一组件族，但都保持弱交互层级。
- 标签不与按钮争夺主操作层级。

## 3. 改写边界

- 可改：文案、状态语义、是否可关闭、是否带前置图标、行内数量。
- 默认不改：标准尺寸、基础圆角、状态层级、弱交互属性。

## 4. 关联规则

- 表格状态列、筛选结果标签、多选结果展示都可复用标签组件，但具体位置受页面与模块规则约束。
- 标签只用于辅助识别，不替代按钮或导航。
- 真实默认实现以 `component.html` 为准。
