# 表单 Summary

## 1. 组件定位

- 表单用于录入、编辑、配置和补录。
- 表单负责组织字段项、字段关系、帮助信息、错误信息和表单动作。
- 表单不承担纯详情展示。
- 查询筛选场景使用 `filter-bar`，不把筛选区作为 Form 变体。

## 2. 默认结论

- 默认控件档位使用中号。
- 支持水平与垂直两种主要组织方式。
- 字段项保持 `label + control` 基础关系。
- 必填标识依附 label。
- 帮助信息与错误信息依附对应字段。
- 帮助信息与错误信息默认不同时叠加。
- 字段较多时允许在同一表单任务内分组。
- 整页表单的最终动作默认保持在当前表单主线中。
- 当 Form 位于 Modal / Drawer 内时，最终动作默认由外层覆盖层 footer 承接，Form 内部不重复承载一套最终 actions。

## 3. 改写边界

- 可改：字段数量、字段类型、水平/垂直布局、字段分组、帮助文案、错误文案、动作文案。
- 默认不改：`label + control` 基础关系、必填层级、帮助/错误信息归属关系、控件默认档位、字段状态层级、整页表单动作作为当前任务最终动作的关系、嵌入覆盖层时由外层 footer 接管最终动作的关系。

## 4. 关联规则

- 整页是否使用 Form，由 `rules/page-types/form-page.md` 判断。
- 查询筛选场景由 `filter-bar` 规则与资产承接。
- 具体控件实现继承对应 component 基线。
- 真实默认实现以 `component.html` 为准。
