# 分页 Summary

## 1. 组件定位

- 分页用于承接多页结果浏览与页码切换。
- 分页属于结果区导航控件，不承担页面主操作职责。

## 2. 默认结论

- 默认分页档位使用标准尺寸。
- 单页可承载全部数据时，默认不强行展示分页。
- 分页与总数信息默认服务同一结果集，不拆成无关区域。
- 页大小切换、快速跳页等扩展能力仍从属于分页，不改变其基础导航语义。

## 3. 改写边界

- 可改：总数字段、页码数量、是否显示页大小切换、是否显示快速跳页、局部布局对齐。
- 默认不改：当前页高亮层级、上一页/下一页基础关系、标准与迷你档位逻辑。

## 4. 关联规则

- 分页通常与表格、列表或结果区配套使用，位置受页面结构与结果区规则约束。
- 分页不参与页面级主按钮竞争。
- 真实默认实现以 `component.html` 为准。
