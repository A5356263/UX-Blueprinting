# 日期选择器 Summary

## 1. 组件定位

- 日期选择器用于完成日期、日期范围或日期时间的结构化选择。
- 日期选择器属于输入框族的扩展选择控件，不承担自由日期解析职责。

## 2. 默认结论

- 默认日期选择器档位使用中号。
- 触发器默认与输入框保持同级视觉档位，不单独漂移。
- 日期范围、日期时间、月份或年份选择仍属于日期选择器族，不改变其基础选择语义。
- 需要高度定制的时间轴或复杂排期时，不强行用标准日期选择器承接。

## 3. 改写边界

- 可改：placeholder、显示格式、日期类型、范围模式、局部宽度、是否带时间区域。
- 默认不改：触发器与面板的基础关系、尺寸档位、选中层级、今日与禁用日期的基础状态。

## 4. 关联规则

- 在表单区与筛选区中的使用位置受对应模块规则约束。
- 与输入框的职责边界以“结构化日期选择”与“自由文本录入”区分。
- 真实默认实现以 `component.html` 为准。
