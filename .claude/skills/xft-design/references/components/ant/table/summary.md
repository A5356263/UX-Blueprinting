# 表格 Summary

## 1. 组件定位

- 表格用于承接结构化结果数据。
- 表格是列表数据页常见的主信息载体。
- 表格组件负责数据展示、行列结构、选择状态和表格内部操作。
- 页面级操作工具区不属于表格组件。

## 2. 默认结论

- 默认表格密度使用标准档位。
- 表头与表体保持稳定结构关系。
- 行操作保持次级。
- 选择列、操作列、空状态和加载状态属于表格自身能力。
- 表格后需要分页时，使用 `references/components/ant/pagination/component.html`。
- 单元格中的状态标签优先继承 `references/components/ant/tag/component.html`。
- 页面级操作优先继承 `references/blocks/action-bar.html`。

## 3. 改写边界

- 可改：列数量、列标题、行数据、列宽、是否存在选择列、行操作数量与文案、单元格内容类型、是否展示空状态、是否展示加载状态、是否使用多级表头、是否需要横向滚动或固定列。
- 默认不改：表头与表体基础关系、密度档位、单元格基础间距、行 hover 与 selected 状态基线、表格容器与横向滚动的稳定处理、操作列的次级层级。

## 4. 关联规则

- 页面级操作不属于表格组件，结果区组织受 `rules/modules/action-bar.md` 和页面结构规则约束。
- 真实默认实现以 `component.html` 为准。
