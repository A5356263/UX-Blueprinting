# 选择器 Summary

## 1. 组件定位

- 选择器用于从预定义选项集合中完成结构化选择。
- 选择器替代自由输入，不承担开放文本录入职责。

## 2. 默认结论

- 默认选择器档位使用中号。
- 触发器默认与输入框保持同级视觉档位，不单独漂移成更重或更轻的控件。
- 选项较少且页面空间充足时，可优先考虑 `radio` 或 `checkbox`，不强制使用选择器。
- 多选、搜索、分组等变体仍属于选择器族，不改变其基础选择语义。

## 3. 改写边界

- 可改：placeholder、选项文案、选项数量、分组结构、多选标签、局部宽度。
- 默认不改：尺寸档位、触发器与面板的基础关系、状态表现、选中层级。

## 4. 关联规则

- 与输入框的职责边界以“结构化选择”与“自由输入”区分。
- 在表单区与筛选区中的使用位置受对应模块规则约束。
- 真实默认实现以 `component.html` 为准。
