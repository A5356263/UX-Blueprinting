Table List Page Layout 表格列表页布局规则

以下规则定义所有 TablePage 的布局结构和按钮放置规范。优先级高于具体业务内容。

必需区域

标题区、操作按钮区、筛选区、表格区、分页区。

可选模块

批量操作、汇总卡片、导入导出、空状态。

按钮放置规则

操作按钮（新增/导入/导出/批量操作等）统一放置在筛选区上方一行，所有按钮在同一侧从左至右按优先级排列（主操作→次要操作），不得用 flex: 1 spacer 拆分成左右两侧。

标题区只展示标题和辅助说明文字，不放操作按钮。批量按钮未选中时 disabled 置灰。

页面标题规则

一级列表页（从侧边导航直接进入）不展示页面标题——侧边导航高亮项和上下文页签已标识当前页面。

下钻二级/三级页面（从列表点击进入详情/编辑等）标题在返回按钮后方展示。

表格规范

表格必须使用 table.data-table + .data-table-wrap 标准结构，样式统一由 design-systems/components.html 定义：

  • 边框：四边 1px 实线 + 圆角 6px（border-collapse: separate; border-spacing: 0; border-radius: var(--border-radius-regular); overflow: hidden）
  • 表头：背景 #f3f4f6，颜色 95% #132240（--color-text-neutral-gray50），14px bold
  • 数据行：颜色 85% #132240（--color-text-neutral-gray40），14px，行高 40px，溢出省略
  • 不得在任何页面中覆盖表头颜色、数据行颜色、字体大小、行高。

行内操作 ≤3 个。批量操作依赖多选复选框。危险操作（删除/作废）必须使用确认弹窗。
