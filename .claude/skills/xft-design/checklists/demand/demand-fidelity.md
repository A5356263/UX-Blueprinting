# DEMAND_FIDELITY Checklist

## P0 必须通过

- `Design Spec` 中的界面设计对象是否全部生成，只有明确不生成的内容被排除。
- 关键业务状态与动作是否没有因资产或 Runtime 限制被省略或改写。

## P1 应该通过

- 字段数量、模块数量与需求复杂度是否基本匹配，没有明显过多或过少。
- 占位内容是否只出现在需求未提供的文案位置，没有用假业务数据冒充真实数据。
- 若需求只要求局部区域，结果是否没有擅自扩成整页主流程。
- 页面级业务 JS 是否只使用了 runtime 契约和 DOM class/data-* 切换，没有出现 fetch、setTimeout、自定义路由等超出范围的操作。

## P2 可选优化

- 在不偏离需求的前提下，信息组织是否进一步提升了可读性。
