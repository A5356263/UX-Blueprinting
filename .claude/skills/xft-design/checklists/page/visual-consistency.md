# VISUAL_CONSISTENCY Checklist

## P0 必须通过

- 颜色、字号、圆角、阴影和间距是否优先继承 `design-systems/`，没有脱离系统自写一套视觉语言。
- 同页主按钮、次按钮、输入控件、标题层级是否保持统一档位。
- 轻交互状态是否没有超出 `runtime/` 已支持的能力边界。
- 所有颜色值是否来自 `design-systems/tokens.css`，没有出现硬编码色值（如 `#333`、`rgb(51,51,51)`）。
- 控件高度是否保持在 `design-systems/DESIGN.md` §9 定义的档位内（xs:16 / sm:24 / md:32 / lg:40），没有被改为档位外的值。
- 页面中是否存在裸露在灰色背景上的功能区域（未被 `.xftv0-surface` 包裹的 data-region）。
- 同一页面内 Surface 之间的间距是否统一为 spacing-6（24px），Surface 内部区域间距是否统一为 spacing-4（16px）。
- 合成层的所有 CSS 值是否使用了 design-systems/ 的 token，不存在硬编码值。
- 是否存在无视觉边界（无背景/边框/阴影）但 padding >= 16px 的容器。

## P1 应该通过

- 同页控件尺寸是否稳定，没有明显大小漂移。
- 强调色是否节制使用，没有在同一视窗中滥用多个高强调动作。
- 页面是否没有出现孤立的视觉特例。

## P2 可选优化

- 在满足系统一致性的前提下，重点区域是否保留了足够清晰的视觉焦点。
