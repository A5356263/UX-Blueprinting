# PAGE_CONSISTENCY Checklist

## P0 必须通过

- 页面是否只存在一条清晰主线，没有把多个同层主任务并列堆放。
- 页面组织是否符合对应页面类型的主线结构，没有区域先后错位。
- 各区域职责是否清晰，没有把筛选、页面操作、结果主体、提交动作混到同一区域。
- 同一窗口内是否只存在一个主视觉主按钮，没有出现多个同层级主按钮互相竞争。
- 已使用的稳定资产是否没有被重新实现为同职责的第二套结构。
- 同一公共交互状态是否没有被 Runtime 与页面脚本重复维护。

## P1 应该通过

- 同层区域的对齐、间距和标题节奏是否一致。
- 相邻区域是否保持清晰分层，没有出现职责重复或视觉挤压。
- 次级信息是否没有压过主内容区。
- 次级动作是否已降为默认按钮、次按钮或文字按钮，没有与主按钮并列竞争主线。

## P2 可选优化

- 在不影响职责清晰的前提下，页面扫描路径是否更顺畅。
