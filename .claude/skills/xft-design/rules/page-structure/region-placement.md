# 区域落位规则

本文件用于定义页面组织方式确定后，内容应落在哪类区域。

## 基础规则

### Header 区域

Must:
- 承载页面标题
- 承载页面身份信息
- 在需要时承载简短上下文说明
- 仅在确实影响整个页面时承载顶层操作

Must Not:
- 不要承载长表单内容
- 不要承载表格主体

### Filter 区域

Must:
- 承载查询条件
- 承载轻量收窄条件
- 承载筛选重置与提交动作

Must Not:
- 不要承载行级操作
- 不要承载仅面向详情解释的说明

### Action 区域

Must:
- 承载与主工作集直接相关的页面级动作

Must Not:
- 除非是为了布局压缩，否则不要只放筛选动作

### Primary Content 区域

Must:
- 承载页面主信息载体
- 承载表格主体、表单主体、摘要主体或详情块

Must Not:
- 不要塞入削弱主任务的装饰性填充内容

### Footer Actions 区域

Must:
- 承载确认、取消、保存、提交、关闭或最终阶段动作

Must Not:
- 除非流程确有要求，否则不要机械重复顶部所有动作
