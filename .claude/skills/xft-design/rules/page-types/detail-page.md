# 详情页

## 页面类型标识

- `Page Type ID`：`PAGE_TYPE.DETAIL`

## 触发条件

- 主任务是查看单条记录、状态、结果或配置详情
- 页面核心内容是摘要、详情分组、元数据或过程信息

## 主线结构

- 默认主线为 `header -> summary -> detail sections -> footer or secondary actions`

## 区分边界

- 若主任务是录入与提交，不归入详情页
- 若主任务是批量浏览与筛选，不归入详情页
- 若详情只是在弹窗内短暂展示，优先判断是否属于弹窗页

## 失败回退

- 无法确认是否属于详情页时，不强行套用详情页主线
