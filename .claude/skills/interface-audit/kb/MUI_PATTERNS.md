# MUI / GenUI 模式指南

只有在证据 DSL 和 UCATS 问题已经可用后，才给出 MUI/GenUI 建议。

## 模式

- 固定页面：适合短任务、信息密集且主操作明确的界面。
- 引导式流程：适合证据集合展示多个步骤、前置条件或决策点的任务。
- 抽屉/模态任务：适合在不丢失列表或看板上下文的情况下完成轻量编辑。
- 对话式辅助：适合需要诊断、解释或领域指导的任务。
- AI 助手 / GenUI：适合自动填写、摘要、推荐、异常解释或复杂筛选。
- 多模态采集：适合用户需要提交图片、文档或音频证据的任务。

## 决策规则

- 如果主要问题是下一步隐藏或竞争操作过多，优先做固定页面重构，再考虑 GenUI。
- 如果任务包含三个及以上依赖步骤、可见进度不确定或重复输入，优先使用引导式流程。
- 如果用户需要保留上下文并编辑单个对象，优先使用抽屉/模态任务。
- 如果用户必须理解复杂数据或在大量选项中决策，可以考虑 AI 助手/GenUI。
- 如果风险较高，自动化前必须提供明确确认和可追溯解释。

## 必需的建议字段

```json
{
  "recommended_pattern": "guided_flow",
  "reason": "证据展示了多个依赖步骤，但没有可见进度指示。",
  "expected_benefits": ["减少流失", "明确恢复路径"],
  "risks": ["如果步骤拆得过细，可能增加感知流程长度"],
  "alternatives": ["fixed_page"]
}
```
