# 页面事实后置提取

只在 `uxb_output.md` 完成自检、`uxb.json` 写入且核心定案冻结后执行。

回看本轮正式需求材料，提取未被 UXB 明确修改或排除、但可能因业务与体验分析被压缩掉的页面确定性信息。

重点保留：

- 明确要求存在的页面、大模块及其内容模块
- 大模块下明确给出的子模块数量、名称清单和固定内容
- 字段名称、标签、单位、格式、数据口径、专业业务词和枚举
- 明确存在的操作、入口和输出
- 无需重新设计的微小交互，以及控件明确控制的对象、范围和联动
- 不可随意改写的业务或合规内容

保持原需求含义，按原需求中的业务区域或大模块简要分组。不要重新分析需求，不要修改已冻结的 UXB 产物，不要复制完整 PRD、业务分析或 `§7 体验蓝图承接要求`，也不要补充需求中没有的信息。

输出到 `spark-output/context/page-generation-handoff.md`，使用轻量纯 Markdown，不生成配套 JSON：

```markdown
# 页面生成事实补充

## {原需求中的业务区域或大模块}

- 明确包含 {N} 个子模块：{子模块清单}
- {需要页面生成继承的确定性信息}
```
