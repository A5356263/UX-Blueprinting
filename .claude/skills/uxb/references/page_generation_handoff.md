# 页面事实最小提取

只在 `uxb_output.md` 完成自检、`uxb.json` 写入且核心定案冻结后执行。

只回看本轮正式需求材料，按以下白名单摘录页面确定性信息：

- 明确存在的页面、弹窗、区域和模块
- 明确给出的字段、选项、操作名称和控件类型
- 明确给出的入口位置、展示条件和角色可见条件
- 明确给出的默认值、必填或可选、数量上下限、单位、格式、数据口径、枚举和校验顺序
- 明确指定的标题、标签、提示语、错误文案及业务或合规文案

白名单之外一律不写。不得写业务流程、审批、状态、异常、处理结果、体验方案或 UXB 已承接的业务规则；不得根据上下文推导控件、层级、因果、失败机制或原文没有的否定结论。

每条内容必须能直接指回正式需求中的原句或表格单元；不能直接指回时删除，不建立来源映射。保持原文含义，只做必要的简短分组。

输出到 `spark-output/context/page-generation-handoff.md`，使用轻量纯 Markdown，不生成配套 JSON。只输出存在内容的分组：

```markdown
# 页面事实补充

## 页面与载体
- {明确存在的页面、弹窗、区域或入口位置}

## 模块与字段
- {模块名称}：{字段、选项或操作名称}

## 明确页面约束与文案
- {默认值、必填、数量、格式、可见条件、校验顺序或原文文案}
```
