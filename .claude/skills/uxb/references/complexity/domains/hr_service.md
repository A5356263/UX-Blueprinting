# 领域：人事服务

## 底层基座

- 组织架构
- 员工主数据
- 岗位
- 职级
- 汇报关系
- 任职关系
- 合同关系
- 生命周期事件
- 敏感信息管理

## 核心链路

入职 → 转正 → 调岗 / 异动 → 离职 → 归档

## 关键元数据

- 员工状态
- 部门
- 岗位
- 职级
- 入职日期
- 离职日期
- 合同类型
- 汇报关系
- 人员标签
- 法人主体

## 高复杂度触发点

- 改员工生命周期状态机
- 改员工与组织 / 法人 / 岗位关系
- 支持一人多法人、多岗位、多项目任职
- 外部人、员工、实习生统一建模
- 人事异动联动薪资、考勤、权限和门户
- 集团组织树和汇报关系重构

## 中等复杂度触发点

- 新增自助信息维护
- 新增材料补传
- 新增合同模板
- 新增批量入职
- 增加局部自动通知
- 既有人事动作增加确认步骤

## 低复杂度触发点

- 员工档案页布局调整
- 字段展示顺序
- 时间轴样式
- 标签样式
- 填写提示
- 列表筛选位置
- 页面说明文案

## UXB 判断提醒

- 不因为“员工、档案、组织”直接判中高复杂度。
- 先看是否改主数据对象关系或生命周期状态。
- 纯展示调整不要误判成对象模型改造。
- 如果出现“外部人员、外包人员、顾问、供应商人员”，先确认它是独立对象，还是要进入员工主数据和组织 / 权限 / 门户体系。
