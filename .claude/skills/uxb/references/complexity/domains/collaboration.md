# 领域：协同办公

## 底层基座

- 待办
- 审批模板
- 消息
- 参与人
- 文档 / 表单对象
- 可见范围
- 归档机制

## 核心链路

发起 → 路由 → 通知 → 处理 → 沉淀 / 归档

## 关键元数据

- 发起人
- 参与角色
- 节点类型
- 处理状态
- 截止时间
- 抄送规则
- 提醒规则
- 来源应用
- 归档状态

## 高复杂度触发点

- 改审批或待办状态机
- 改流程定义权
- 改消息、待办与业务单据的主从关系
- 建设统一待办中心
- 跨系统状态回写
- 跨企业协同模型
- 多应用任务统一处理

## 中等复杂度触发点

- 新增催办
- 新增转交
- 新增批量处理
- 增加超时提醒
- 增加移动端补偿
- 外部系统审批接入现有协同容器，但不改流程引擎

## 低复杂度触发点

- 待办卡片排序
- 列表字段调整
- 空状态文案
- 红点 / 角标
- 按钮位置
- 局部错误提示
- 通知文案优化

## UXB 判断提醒

- 不因为"审批、待办、消息"直接判复杂。
- 先看是否改流程对象、状态一致性或回写关系。
- 如果只是展示层调整，按低复杂度处理。
