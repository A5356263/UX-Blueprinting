# 领域：财务费控

## 底层基座

- 费用申请
- 预算
- 成本中心
- 项目
- 发票 / 电子凭证
- 报销单
- 付款单
- 会计凭证
- 电子档案

## 核心链路

申请 / 消费 → 报销 → 审批 → 预算占用 → 付款 → 入账 → 归档 → 分析

## 关键元数据

- 费用类型
- 预算科目
- 成本中心
- 项目
- 发票状态
- 付款状态
- 入账状态
- 归档状态
- 凭证状态

## 高复杂度触发点

- 改预算占用 / 释放 / 结转 / 冲回规则
- 改发票验真链路
- 改入账链路
- 改会计凭证映射
- 改电子归档链路
- 打通银企直联
- ERP / 总账回写
- 费用、采购、付款、档案统一成业财模型

## 中等复杂度触发点

- 新增费用类型但复用预算和审批框架
- 新增差旅规则但不改底层预算口径
- 新增批量审核
- 新增对公报账入口
- 增加异常发票提醒
- 增加差异分析
- 增加批量补单

## 低复杂度触发点

- 报销单信息重排
- 表格字段显隐
- 卡片排序
- 筛选器布局
- 行内说明
- 结果态文案
- 视觉强调

## UXB 判断提醒

- 不因为“报销、发票、付款”直接判高复杂度。
- 先看是否改预算、付款、入账、归档或总账回写。
- 纯信息收纳和布局优化按低复杂度处理。
